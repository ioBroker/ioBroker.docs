Выпущено множество новых адаптеров; некоторые уже попали в стабильный репозиторий, а другие доступны в последнем репозитории и ждут, когда вы их протестируете.

## Новые адаптеры в стабильной версии
### **ioBroker.vis-2-widgets-icontwo**
<img src="https://raw.githubusercontent.com/inventwo/ioBroker.vis-2-widgets-icontwo/main/admin/vis-2-widgets-icontwo.png" width="100" height="100" />

**Категория:** Визуализация / Иконки

**Разработчик:** skvarel

Этот пакет добавляет набор иконок из inventtwo в VIS 2.

Иконки специально оптимизированы для сценариев умного дома и предлагают быстрый способ визуального улучшения визуализаций.

Нововведением является то, что эти значки теперь доступны непосредственно в селекторе значков VIS-2, что значительно упрощает их вставку в панели мониторинга. Поддерживаются только версии VIS-2 2.13.x и более поздние.

### **ioBroker.brightsky**
<img src="https://raw.githubusercontent.com/ticaki/ioBroker.brightsky/main/admin/brightsky.png" width="100" height="100" />

**Категория:** Погода

**Разработчик:** ticaki

Адаптер Brightsky интегрирует метеорологический сервис Bright Sky в ioBroker.

API предоставляет метеорологические данные от Немецкой метеорологической службы (DWD), подготовленные в удобном формате JSON.

**Особенности:**

— Данные обновляются каждые 30 минут и всегда поступают с ближайшей метеостанции DWD.
- Если станция не предоставляет никаких значений, адаптер автоматически переключается на ближайшую станцию или на несколько станций дальше (система резервного копирования).
— Помимо классических метеорологических данных, таких как температура, осадки, влажность и ветер, API также предоставляет значения солнечной радиации, которые особенно интересны операторам фотоэлектрических систем.
- API находится в свободном доступе, не требует ключа API и полностью основан на открытом исходном коде.

Ссылка на [Страница адаптера на GitHub](https://github.com/ticaki/ioBroker.brightsky)

### **ioBroker.pirate-weather**
<img src="https://raw.githubusercontent.com/ticaki/ioBroker.pirate-weather/main/admin/pirate-weather.png" width="100" height="100" />

**Категория:** Погода

**Разработчик:** ticaki

Pirate Weather — это API для прогнозирования погоды с открытым исходным кодом, разработанный в качестве замены прекратившего существование сервиса Dark Sky и основанный на данных NOAA.

Адаптер напрямую передает данные в ioBroker. Идеально подходит для пользователей, которые хотят наполнять свои автоматизированные системы достоверной информацией о погоде.

**Подробности с GitHub:**

— Для использования требуется API-токен, который можно получить на сайте `docs.pirateweather.net`.
- Адаптер поддерживает API Pirate-Weather версии 2 и предоставляет данные о температуре, влажности, осадках, ветре и фазах луны.
Такие значения, как `humidity`, `cloudCover`, `precipProbability` и `moonPhase`, выводятся непосредственно в виде процентных значений.
- Тексты, такие как направления ветра или сводки, автоматически адаптируются к системному языку ioBroker.
— Интервал опроса можно настроить в минутах. Ошибки обнаруживаются, и адаптер перезапускается в соответствии с заданным расписанием, не вызывая непрерывных циклов в журнале.

Ссылка на [Страница адаптера на GitHub](https://github.com/ticaki/ioBroker.pirate-weather)

### **ioBroker.pi-hole2**
<img src="https://raw.githubusercontent.com/oweitman/ioBroker.pi-hole2/main/admin/pi-hole2.png" width="100" height="100" />

**Категория:** Сеть

**Разработчик:** weweitman

Этот адаптер позволяет интегрировать установленную версию Pi-hole (6 и выше) в ioBroker.

Это позволяет отслеживать статистику блокировщиков рекламы, запросы и показатели блокировки, а также использовать эти данные для автоматизации.

**Особенности:**

- Поддержка специально для Pi-hole версии 6 (для более старых версий продолжайте использовать адаптер ioBroker.pi-hole).
— Домены можно блокировать или разблокировать напрямую через ioBroker, включая автоматическую повторную активацию по истечении заданного времени.
- Подробная информация о статистике и версиях хранится в виде точек данных и может быть включена/отключена по желанию.
— Интервалы запросов можно свободно настраивать — от 1 секунды до 24 часов.
- Команды можно отправлять непосредственно в Pi-hole с помощью функции sendTo().

Это означает, что адаптер подходит не только для мониторинга, но и для активного управления Pi-hole посредством автоматизации.

Ссылка на [Страница адаптера на GitHub](https://github.com/oweitman/ioBroker.pi-hole2)

### **ioBroker.energy-tracker**
<img src="https://raw.githubusercontent.com/energy-tracker/ioBroker.energy-tracker/main/admin/energy-tracker.png" width="100" height="100" />

**Категория:** Управление энергопотреблением

**Разработчик:** Energy Tracker

Этот адаптер позволяет автоматически передавать показания счетчика на платформу Energy Tracker.

Это значительно упрощает документирование потребления энергии или поставок в сеть.

**Подробности с GitHub:**

Для использования этой услуги требуется учетная запись Energy Tracker и создание персонального токена доступа.
- Любое состояние ioBroker может быть определено как источник (например, счетчики электроэнергии, газа или воды).
- Значения передаются соответствующим идентификаторам устройств через общедоступный REST API платформы.
Значения при желании могут быть округлены перед отправкой.
- Адаптер работает в режиме планирования: в ioBroker необходимо настроить расписание, указывающее, когда должны передаваться данные. Без расписания никакие значения отправляться не будут.
- Токен хранится в зашифрованном виде, связь односторонняя – на платформу передаются только значения, данные обратно не считываются.

Ссылка на [Страница адаптера на GitHub](https://github.com/energy-tracker/ioBroker.energy-tracker)

### **ioBroker.smartloadmanager**
<img src="https://raw.githubusercontent.com/quorle/ioBroker.smartloadmanager/main/admin/smartloadmanager.png" width="100" height="100" />

**Категория:** Логика / Управление энергопотреблением

**Разработчик:** quorle

Адаптер используется для динамического управления нагрузками на основе избытка энергии, вырабатываемой солнечными батареями. Цель состоит в том, чтобы потреблять избыточную энергию локально и избегать или полностью предотвращать ее передачу в общественную сеть.

**Подробности с GitHub:**

- Поддерживает как устройства, которые можно включать/выключать, так и те, которыми можно управлять с помощью процентного значения (например, тепловые насосы, зарядные устройства).
Также могут быть интегрированы системы хранения энергии на основе аккумуляторов.
- Управление основано на текущем значении подаваемой в сеть энергии; это позволяет автоматически включать потребителей, как только будет доступно достаточное количество солнечной энергии.
Гибкие настройки времени ожидания и расписания гарантируют, что устройства не будут постоянно включаться и выключаться.
- В текущих версиях (0.0.7) исправлены ошибки в функциях таймаута и улучшена конфигурация.

Ссылка на [Страница адаптера на GitHub](https://github.com/quorle/ioBroker.smartloadmanager)

Благодаря этому адаптер подходит для пользователей, желающих создавать высоко персонализированные визуализации на основе внешних данных или сложных JSON-структур.

### **ioBroker.sofarcloud**
<img src="https://raw.githubusercontent.com/ltspicer/ioBroker.sofarcloud/main/admin/sofarcloud.jpg" width="100" height="100" />

**Категория:** Управление энергопотреблением / Фотовольтаика

**Разработчики:** Itspicer / Daniel Luginbühl

Адаптер считывает данные с сервера SofarCloud и интегрирует их в ioBroker. SofarCloud — это официальная онлайн-платформа SofarSolar, позволяющая владельцам инверторов Sofar отслеживать работу своих фотоэлектрических систем. Теперь этот адаптер делает данные доступными в приложениях для умного дома.

**Подробности с GitHub:**

Для регистрации в приложении SofarCloud требуется указать адрес электронной почты и пароль.
— Данные включают, помимо прочего, мощность, выработку энергии и значения состояния инверторов.
— При желании данные также могут передаваться в другие системы через MQTT.
- Полученные значения также можно сохранить в виде JSON-файла (sofar_realtime.json).
- Безопасность: Пароли хранятся в зашифрованном виде; после 3 неудачных попыток входа в систему адаптер автоматически отключается.
— В более новых версиях улучшена обработка авторизации, обработка ошибок и качество данных (например, нормализованы значения, более точные роли и типы).
— Это делает `sofarcloud` практичным связующим звеном между учетными записями Sofar Cloud и системой умного дома.

Ссылка на [Страница адаптера на GitHub](https://github.com/ltspicer/ioBroker.sofarcloud)

Этот адаптер позволяет интегрировать данные о майнинге Monero из P2Pool в ioBroker.

P2Pool — это децентрализованный майнинговый пул, работающий без центрального оператора и организованный непосредственно между участниками.

Типичные значения включают хешрейт, количество акций или доходность майнинга.
- Текущая версия 1.1.0 содержит изменения в процессе и файле Readme.

Это позволяет напрямую отслеживать работу майнинговых установок и интегрировать их в системы автоматизации — например, для регистрации результатов добычи или оптимизации энергопотребления.

### **ioBroker.xsense**
<img src="https://raw.githubusercontent.com/arteck/ioBroker.xsense/main/admin/xsense.png" width="100" height="100" />

**Категория:** Системы Интернета вещей / Безопасность

**Разработчик:** arteck

Адаптер интегрирует устройства X-Sense (включая датчики дыма, угарного газа, тепла и воды, а также гигрометры) в ioBroker. Связь осуществляется через облако X-Sense; для работы требуется X-Sense Bridge SBS50 и учетная запись X-Sense.

**Полезно знать:**

- Примечание по использованию: Частый опрос (по умолчанию 5 мин) активно пробуждает устройства и может сократить срок службы батареи; адаптер не предназначен для использования в качестве системы сигнализации, а в первую очередь для мониторинга состояния/заряда батареи.
- Ограничение на количество одновременных входов: приложение и стороннее программное обеспечение не могут быть одновременно авторизованы. Рекомендуется использовать вторую учетную запись, к которой будут подключаться устройства из основной учетной записи; эти учетные данные вводятся в адаптер.
— Требуется Python: адаптер использует среду Python (автоматически в Linux/Docker, установите Python в Windows и укажите путь при необходимости). Информация по устранению неполадок приведена в файле README.
- Удобство: кнопка "forceRefresh" для ручного обновления; различные исправления/улучшения в новых версиях (например, роли, состояние времени).

Ссылка на [Страница адаптера на GitHub](https://github.com/arteck/ioBroker.xsense)

### **ioBroker.weathersense**
<img src="https://raw.githubusercontent.com/ltspicer/ioBroker.weathersense/main/admin/weathersense.png" width="100" height="100" />

**Категория:** Метеорологические / Измерительные системы

**Разработчик:** Ltspicer / Даниэль Лугинбюль

Адаптер считывает данные из облака WeatherSense, которое используется различными метеостанциями с поддержкой Wi-Fi (например, моделями из `Ideoon`/`Pearl`). Это позволяет напрямую интегрировать данные измерений в ioBroker.

**Подробности:**

— Войдите в систему, используя адрес электронной почты и пароль вашей учетной записи WeatherSense.
- Все измеренные значения (температура, влажность, атмосферное давление, осадки, ветер и т. д.) хранятся в центральной точке данных.
— При желании данные также могут передаваться в другие системы через протокол MQTT.
В более новых версиях (3.0.x) реализовано защищенное хранение паролей, улучшены типы данных и сортировка, а также добавлены дополнительные значения датчиков (например, гПа).

Благодаря этому адаптер отлично подходит для интеграции недорогих метеостанций с поддержкой Wi-Fi непосредственно в систему «умный дом».

### **ioBroker.hoymiles-ms**
<img src="https://raw.githubusercontent.com/mcm4iob/ioBroker.hoymiles-ms/main/admin/hoymiles-ms.png" width="100" height="100" />

**Категория:** Аппаратное обеспечение / Фотовольтаика

**Разработчик:** mcm1957

Адаптер интегрирует системы микрохранения Hoymiles – в настоящее время модель MS-A2 – в ioBroker. Эти компактные устройства сочетают в себе микроинвертор и встроенный аккумуляторный блок и специально разработаны для балконных электростанций и небольших фотоэлектрических систем. Это позволяет накапливать избыточную энергию и использовать ее позже в домохозяйстве, вместо того чтобы напрямую подавать ее в сеть.

**Подробности с GitHub:**

- Адаптер работает как MQTT-сервер (клиентский режим планируется, но пока не реализован).
- Настройка осуществляется через сетевой адрес и порт, которые задаются для локальной службы MQTT.
- Использует Sentry для автоматического обнаружения ошибок (начиная с js-controller 3.0).
Документация и инструкции по настройке доступны на немецком и английском языках.

Это позволяет владельцам систем Hoymiles MS-A2 интегрировать свои решения для хранения данных непосредственно в систему «умный дом» — например, для мониторинга состояния и процессов зарядки/разрядки.

### **ioBroker.steam**
<img width="100" height="100" src="https://raw.githubusercontent.com/bloop16/ioBroker.steam/main/admin/steam.png" />

**Категория:** Мультимедиа / Игры

**Разработчик:** bloop16 / Мартин Раушер

Адаптер интегрирует информацию из Steam API в ioBroker.

Это позволяет отслеживать профили и игры и использовать их для автоматизации.

**Функции:**

- Информация профиля: имя игрока, аватар, статус (онлайн, в игре, отсутствует), SteamID64.
- Мониторинг игры:
— Список игр, который можно определить, включая идентификатор приложения.
- Автоматическое определение воспроизводимых игр.
— Импортируйте все свои игры из Steam одним щелчком мыши.
- Отображение игровых значков, логотипов, ссылок на сообщества и статистики игрового времени.
- Новости об играх обновляются каждые 6 часов.
- Функция подсказок: в случае опечаток адаптер предложит до 5 похожих игр из базы данных Steam.
- Управление API:
- Интервал для запросов от игроков можно свободно регулировать (мин. 15 с, стандартный 60 с).
- Автоматически контролируется ограничение на максимальное количество API-запросов — 10 000 в день.
Запросы оптимизированы для предотвращения дублирования запросов.

Это позволяет геймерам просматривать свою активность в Steam или игровую статистику непосредственно в своей системе умного дома. Например, настроить уведомления о том, что игрок находится онлайн, или регистрировать время, проведенное за игрой.

Ссылка на [Страница адаптера на GitHub](https://github.com/bloop16/ioBroker.steam)
