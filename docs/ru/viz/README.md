# Визуализация
Визуализация - это интерфейс, с которым в конечном итоге взаимодействует пользователь: страница в браузере или на планшете, где отображаются и управляются помещения, устройства и измерения. Сам ioBroker не включает в себя визуализацию. Она создается с помощью адаптера, и таких адаптеров несколько, каждый из которых использует совершенно разные подходы.

## Два способа
**Создайте дизайн самостоятельно.** Вы создаете страницы, перетаскиваете на них элементы управления, связываете каждую с точкой данных и определяете ее размер, цвет и поведение.

В результате вы получите именно то, что хотите, и всю работу сделаете сами.

**Пусть будет сгенерировано.** Адаптер сам формирует интерфейс на основе информации, которую система знает об устройствах: из созданного [устройства](/docs/viz/devices.md) и из [Категории](/docs/basics/enums.md). Комнаты становятся страницами, функции - группами на них. Возможности настройки ограничены, но новое устройство автоматически появляется в нужном месте, как только оно назначено.

Те, кто выбирает второй подход, сначала управляют комнатами и функциями. Без четких назначений интерфейс остается пустым, независимо от используемого адаптера.

## Наиболее распространенные адаптеры
| Адаптер | Подход | Примечание |
| --- | --- | --- |
| **[вис-2](/docs/viz/vis-2.md)** | Создайте свой собственный дизайн | Преемник vis и лучший выбор для новых проектов. |
| **[веб-интерфейс](/docs/viz/webui.md)** | Создайте сами | Автономная система веб-компонентов. Мощная, но требует знания HTML. |
| **[адаптер устройства](/docs/viz/devices.md)** | Генерировать | Создает интерфейс на основе подключенных устройств. Самый быстрый способ получить удобный интерфейс. |
| **[Лавлейс](/docs/viz/lovelace.md)** | Создавайте собственные карты | Добавляет интерфейс Home Assistant в ioBroker. Готовые карты, встроенный редактор. |
| **[Lovelace](/docs/viz/lovelace.md)** | Создание карт | Переносит интерфейс Home Assistant в ioBroker. Готовые карты, встроенный редактор. |

Несколько из них можно использовать одновременно. Это удобно при тестировании: одна поверхность для планшета на стене, другая для телефона.

В случае с vis и vis-2 сам адаптер менее важен, чем то, какие **наборы виджетов** установлены. Их более тридцати; см. [Наборы виджетов](/docs/viz/widgetsets.md).

В репозитории содержится почти семьдесят адаптеров визуализации, а также наборы виджетов и коллекции символов. В таблице перечислены четыре адаптера, которые активно поддерживаются. Если вы ищете что-то конкретное, отфильтруйте результаты по группе **Визуализация** на вкладке [адаптер](/docs/admin/adapter.md). Стоит проверить дату последней публикации: для некоторых известных проектов прошло уже несколько лет.

## Что здесь должно быть
**Веб-сервер.** vis, vis-2 и webui не имеют собственного веб-сервера. Они предоставляются через экземпляр адаптера `web`, где также включен [Регистрация](/docs/config/login.md). Lovelace включает свой собственный веб-сервер.

При отображении диаграмм используются **зарегистрированные значения**. Точка данных знает только свое текущее значение. Исторические данные предоставляются с помощью `history`, `influxdb` или `sql` и отображаются с помощью `echarts` или `flot`.

**Доступ из любого места**, если интерфейс доступен не только дома. Инструкции доступны в разделе [Визуализация через облако](/docs/cloud/viz.md).

## Начиная
1. Номера и функции во вкладке

Поддерживайте [Категории](/docs/admin/enums.md). Это окупается с каждым адаптером.

2. Сгруппируйте точки данных на вкладке **Устройства** по типам устройств. Таким образом, вы будете знать...

Система уточнит, что считается лампой, а что - рольставней, и все последующие шаги станут проще. См. [адаптер устройства](/docs/viz/devices.md).

3. Сгенерируйте поверхность и понаблюдайте, какое расстояние она охватывает:

Адаптер устройств или с [Лавлейс](/docs/viz/lovelace.md).

4. И только если этого недостаточно, разработайте дизайн самостоятельно с помощью Vis-2.

Такой подход значительно упрощает работу. Во многих проектах можно обойтись без единой страницы чертежей, выполненных от руки.
