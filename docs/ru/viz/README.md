# Визуализация

Визуализация — это интерфейс, с которым в конечном итоге взаимодействует пользователь: страница в браузере или на планшете, где отображаются и управляются помещения, устройства и измерения. Сам ioBroker не включает в себя визуализацию. Она создается с помощью адаптера, и таких адаптеров несколько, каждый из которых использует совершенно разные подходы.

## Два способа

**Создайте дизайн самостоятельно.** Вы создаёте страницы, перетаскиваете на них элементы управления, связываете каждую с точкой данных и задаёте её размер, цвет и поведение. В результате получается именно то, что вы хотите, а вся работа ложится на ваши плечи.

**Пусть интерфейс генерируется автоматически.** Адаптер сам создает интерфейс, используя [категории](/docs/basics/enums.md) : комнаты становятся страницами, а функции — группами внутри них. Возможности настройки ограничены, но новое устройство автоматически появляется в нужном месте после его назначения.

Те, кто выбирает второй подход, сначала управляют комнатами и функциями. Без четких назначений интерфейс остается пустым, независимо от используемого адаптера.

## Стандартные адаптеры

| адаптер                               | Подход               | примечание                                                                                              |
| ------------------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------- |
| **[вис-2](/adapters/vis-2)**          | Создайте дизайн сами | Преемник vis. Лучший выбор для новых проектов.                                                          |
| **[вис](/docs/viz/vis.md)**           | Создайте дизайн сами | Более старая версия. Очень распространённая, много наборов виджетов.                                    |
| **[материал](/docs/viz/material.md)** | произвести это       | Создайте поверхность, исходя из пространства и его функций.                                             |
| **[Лавлейс](/adapters/lovelace)**     | произвести это       | Добавляет интерфейс Home Assistant в ioBroker.                                                          |
| **[контроль iQ](/adapters/iqontrol)** | Смешанный            | Ориентирован на конкретное устройство, позволяющий получить полезный результат с минимальными усилиями. |
| **[Джарвис](/adapters/jarvis)**       | Смешанный            | Также ориентирован на конкретные устройства и обладает широкими возможностями настройки.                |

Несколько из них можно использовать одновременно. Это удобно при тестировании: одна поверхность для планшета на стене, другая для телефона.

## Что там должно быть

**Веб-сервер.** vis и material не имеют собственных серверов. Доступ к ним осуществляется через экземпляр веб-сервера.`web` — Адаптер доставлен, и [регистрация](/docs/config/login.md) также активирована.

**Записанные значения используются** при отображении диаграмм. Точка данных знает только свое текущее значение. Предоставляются исторические данные.`history` ,`influxdb` или`sql` Он изображен с`echarts` или`flot` .

**Удаленный доступ возможен,** если интерфейс доступен не только из дома. Инструкции можно найти в разделе [«Визуализация через облако»](/docs/cloud/viz.md) .

## Начало

1. Управляйте комнатами и функциями на вкладке [«Категории»](/docs/admin/enums.md) . Это окупается с каждым адаптером.
2. Установите генераторный адаптер и посмотрите, на какое расстояние он передаёт сигнал.
3. Если этого недостаточно, разработайте его самостоятельно с помощью Vis-2.

Такой подход значительно упрощает работу. Во многих проектах можно обойтись без единой страницы чертежей, выполненных от руки.
