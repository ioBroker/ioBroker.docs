# Виджеты коллекций для vis-2

В то время как [Material](/docs/viz/widgets-material.md) представляет собой готовые устройства, такие как термостаты, жалюзи и пылесосы, **Collection** предоставляет сами элементы управления: кнопки, поля выбора, ползунки и таблицы. Этот набор является очевидным выбором, когда странице требуется что-то, что не охватывается готовым виджетом устройства.

Все эти компоненты объединены одним основным принципом: они не запрашивают фиксированный тип данных, а используют тот тип данных, который предоставляется самой точкой данных. Та же группа кнопок управляет переключателем.`true` /`false` , режим работы с числами от 0 до 3 и сцена с текстовыми значениями.

Адаптер установлен[`vis-2-widgets-collection`](/adapters/vis-2-widgets-collection) Затем перезагрузите редактор. Строительные блоки появятся на палитре в разделе **«Коллекция»** .

Тринадцатый компонент, **«Конфигурация темы»** , ничего не отображает. Он задаёт внешний вид всего проекта: цвета, шрифт, размер шрифта, межстрочный интервал, радиус скругления углов и межстрочный интервал. Тем, кто хочет создать единый стиль для страницы, не настраивая каждый виджет по отдельности, достаточно разместить этот виджет на странице один раз и настроить всё там.

## На что следует обратить внимание

**Список значений.** Для кнопок, переключателей и групп выбора значение, соответствующее каждой метке, вводится вручную. Рекомендуется предварительно проверить дерево объектов, чтобы узнать, какие значения фактически принимает точка данных.

**Направление ввода.** Все интерактивные виджеты записываются без подтверждения. Для тех случаев, когда ошибка может дорого обойтись, например, для ворот и замков отопления, диалоговое окно с проверкой PIN-кода — лучший выбор.

**Набор постоянно пополняется. Коллекция** постоянно расширяется; приведенный выше список отражает состояние на момент версии 2.6. После обновления стоит взглянуть на палитру.
