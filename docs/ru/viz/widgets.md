# Общие настройки виджета
Виджет - это строительный блок визуализации: он отображает значение, представляет изображение или диаграмму, либо принимает ввод. Виджеты используются для создания пользовательского интерфейса.

Доступные виджеты зависят от набора виджетов; включенные в него виджеты перечислены в разделе [Наборы виджетов](/docs/viz/basic.md) и на смежных страницах. На этой странице описаны настройки **каждого** виджета, независимо от того, к какому набору он принадлежит.

На изображениях показан редактор vis. В **vis-2** поля имеют в основном те же названия, но интерфейс выглядит иначе. Для новых проектов vis-2 - правильный выбор, см. [вис](/docs/viz/vis.md).

## В целом
![001_Widget_General](../../de/viz/media/vis_widgets_001_Widget_Generell.jpg)

| Атрибут|Описание|
|-----|----|

| Название|Введите уникальное название для этого виджета | Комментарий|Введите краткое описание

| Класс CSS | Пользовательский класс CSS для стилизации виджета с использованием таблицы стилей представления. |
| Фильтр по ключевому слову | Ключевое слово, используемое для отображения или скрытия виджетов в группах. |

| Отображать в представлениях | Здесь вы можете выбрать, должен ли этот виджет отображаться только в текущем представлении или в нескольких представлениях. |
| Неактивно (заблокировано) | Блокирует виджет в редакторе, чтобы предотвратить случайное перемещение. |

## Видимость
Видимость виджета может зависеть от состояния точки данных.

![002_Widget_Visibility](../../de/viz/media/vis_widgets-2_002_Widget_Sichtbarkeit.jpg)

| Атрибут|Описание|
|----|----|

| `Object ID`|Введите здесь идентификатор точки данных, которая управляет видимостью выбранного виджета. Вы можете найти точку данных с помощью кнопки.

| Условие|Виджет будет виден, если условие, введенное здесь для указанной выше точки данных...

| Значение условия|...совпадает со значением, введенным здесь.

## Собственные настройки виджета
![Раздел с собственными настройками виджета.](../../de/viz/media/vis_widgets_003_Widget_Allgemein.jpg)

Этот раздел выглядит по-разному для каждого виджета и описан в описании каждого виджета отдельно. Поле **ID объекта** всегда присутствует: оно используется для присвоения точки данных, которую виджет должен отображать или контролировать.

Следующие разделы относятся ко всем виджетам. Для определения внешнего вида виджета используются CSS.

## CSS в целом
![](../../de/viz/media/vis_widgets_004_CSS_allgemein.jpg)

| Атрибут|Описание|
|-----|----|

| `left`|Расстояние от левого края области просмотра | `top`|Расстояние от верхнего края области просмотра | `width`|Ширина виджета | `height`|Высота виджета | `z-index`|Указывает слой, на котором расположен виджет (0 = на фоне, положительные значения = чем выше значение, тем дальше вперед) | `overflow-y`|

| `overflow-y`|

| `opacity`|Прозрачность (0=непрозрачное -> изображение невидимо .. 1=прозрачное -> изображение видимо) |
