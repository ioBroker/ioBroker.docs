# вис

**вис** Долгое время визуализация ioBroker представляла собой интерфейс, где можно было создавать собственные пользовательские интерфейсы, используя строительные блоки вместо кода.

!> **Для нового проекта [вис-2](/adapters/vis-2) Правильный выбор.** Это преемник, и он находится в стадии дальнейшей разработки. На этой странице описывается редактор оригинального vis. Большая часть его функций по-прежнему применима в vis-2, но интерфейс выглядит иначе. Обзор визуализаций и их преимуществ можно найти по адресу: [обзор](/docs/viz/README.md).

## конфигурация

Для работы Vis требуется адаптер. **веб**которая автоматически включается в процессе установки. В остальном ничего настраивать не нужно, кроме лицензии. Она настраивается в учетной записи на
[iobroker.net](https://iobroker.net) Управляемый и бесплатный сервис для личного использования. Подробную информацию о том, как это работает, можно найти по адресу:
[Лицензии адаптера](/docs/licenses/adapter.md).

Это может только **один** Предоставьте экземпляр визуализации.

## операция

После установки доступ к адаптеру осуществляется через `<IPdesServers>:8082/vis/index.html`
Доступ к визуализации можно получить по гиперссылке на вкладке «Экземпляры» в административном адаптере.

Демонстрационный режим автоматически создается при первом запуске программы.

Проект содержит несколько представлений. Каждое представление позволяет свободно размещать несколько виджетов, используемых для отображения или взаимодействия. Визуализация создается и настраивается через редактор. Доступ к редактору осуществляется через `<IPdesServers>:8082/vis/edit.html` Редактор открывается после его закрытия с помощью значка закрытия окна (x) в правом верхнем углу. Последнее отредактированное представление отображается в окне функций. К нему можно получить доступ в любое время. `<IPdesServers>:8082/vis/index.html#ViewName`
Редактор разделен на несколько отделов.

## Всадники в области головы (1)

### Мнения

Если выбрана эта вкладка, вы можете выбрать редактируемый вид из существующих в выпадающем меню ниже.\
![](../../de/viz/media/iobroker_vis_Editor_Widgets_Header.jpg)

Четыре значка справа говорят сами за себя и относятся к представлениям. После щелчка по рабочей области представление в боковой панели свойств справа переключается на вкладку «Представления» и отображает настройки представления.

### Виджеты

При активации вкладки «Виджеты» панель инструментов под ней изменяется.
![](../../de/viz/media/iobroker_vis_Editor_Views_Header.jpg)

Отображаются инструменты для редактирования виджетов.

#### Выпадающее меню

Здесь вы можете выбрать виджет для редактирования, или же выбранный виджет будет отображен здесь.

#### Панель иконок

Три значка — «удалить», «копировать» и «информация» — становятся активными при выборе виджета.

#### Выравнивание виджетов

![](../../de/viz/media/iobroker_vis_Editor_Widgets_Ausrichten_Header.JPG)

Перетаскивая (или удерживая клавишу Ctrl) несколько виджетов, вы можете использовать эти значки для выравнивания групп (по левому краю, по правому краю, по верхнему краю, по нижнему краю, по центру, по вертикали). Вы также можете расположить несколько виджетов с одинаковым расстоянием (по горизонтали и вертикали) и отрегулировать размер нескольких виджетов с помощью последних двух значков. Выбор виджета переключает отображение в боковой панели свойств справа на вкладку «Виджеты», где отображаются настройки этого виджета. Функция множественного выбора позволяет одновременно изменять свойства нескольких виджетов через боковую панель справа.

#### Все виджеты

Эти два виджета используются для упрощения редактирования представлений. Первый предотвращает обновление значений виджета, второй — перемещение виджетов.

#### Экспорт виджета

Если виджет активирован, вы можете использовать эту кнопку для экспорта CSS-кода виджета.

#### Импорт виджета

И наоборот, здесь можно импортировать виджеты, которые не включены в vis. После щелчка по виджету, в боковой панели свойств справа откроется вкладка «Виджеты», где отобразятся настройки выбранного виджета.

### Инструменты

При активации вкладки «Инструменты» изменяется соответствующая панель инструментов.
![](../../de/viz/media/iobroker_vis_Editor_Tools_Header.JPG)

#### разрешение

Здесь отображается множество предустановленных разрешений экрана для мобильных устройств, но также есть опция «Пользовательские настройки», позволяющая задать собственные параметры. Выбор элемента в этой опции отобразит на рабочем пространстве рамку, соответствующую выбранному разрешению экрана.

#### по умолчанию

Если _по умолчанию_ Если этот флажок установлен, активное представление будет выбрано в качестве представления по умолчанию и будет загружаться, если представление VIS будет загружено с разрешением, указанным выше.
**Пример:**
Объявление будет показано. _Портретный режим iPad_ выбраны и находятся в поле зрения _начинать_ коробка
_по умолчанию_ Проверено. Предположим, проект теперь преобразован в представление с именем \[имя] на iPad. _Погода_ Приложение было загружено в альбомном режиме. Если затем iPad повернуть в портретный режим, автоматически будет применено ранее использованное разрешение по умолчанию для этого портретного режима._по умолчанию_) определенный вид _начинать_ отображается. На соответствующих мобильных устройствах возможно управление с помощью движений (например, «вернуться в главное меню» или _высокий_ показывает иную точку зрения, чем _через_).

#### Сетка

Вот возможные варианты. _неактивный_, _элементы_ и _Сетк&#x430;_&#x41F;ри выборе элементов виджеты автоматически прикрепляются к соседнему элементу при перемещении мышью. В настройках сетки также можно указать размер сетки (в пикселях), внутри которой будут располагаться виджеты.

#### Идентификатор экземпляра

Здесь отображается уникальный идентификатор, который можно проверить, например, с помощью VIS. [Команда управления](https://github.com/iobroker/ioBroker.vis/blob/master/README.md#control-interface) Это можно решить с помощью скрипта.

#### Идентификатор браузера

Нажатие этой кнопки генерирует новый идентификатор в предыдущем поле. Это позволяет идентифицировать каждый браузер на каждом устройстве индивидуально.

#### экспорт

Здесь вы можете экспортировать свой вид, чтобы использовать его, например, в другой установке. Нажатие кнопки открывает окно, отображающее вид в текстовом формате. Вы можете скопировать эти данные в буфер обмена с помощью Ctrl+C, вставить их в текстовый редактор, а затем сохранить.

#### импорт

После нажатия открывается пустое окно. Здесь вы можете выбрать функцию. _экспорт_ Скопируйте полученный текстовый файл в окно. Затем введите название для представления в левом нижнем углу и нажмите кнопку. _импорт_ Нажмите на него. После этого станет доступен новый вид. Эта функция подходит для импорта примеров с форума.

#### Приложение

При загрузке проекта все [Мнения](/docs/viz/vis.md#views) Этот проект загружается вместе с другими данными. Иногда это нецелесообразно и замедляет работу системы. Поэтому можно группировать связанные представления в разные проекты. Например, имеет смысл разделить их по типу устройства с разным разрешением экрана. Таким образом, можно создать проект. _Смартфон_ Создайте новую среду и определите в ней представления, оптимизированные для сенсорного управления и вертикальной ориентации. За счёт намеренного уменьшения количества виджетов проект остаётся небольшим по объёму данных и, следовательно, быстро загружается даже при удалённой работе (например, через VPN и мобильный интернет). Ещё один проект. _настенный лото&#x43A;_&#x41F;роект, который отображается только на планшете на стене, не требует загрузки каких-либо элементов из проекта «Смартфон». Основной проект _Основной_ Как правило, отображение и редактирование представлений осуществляется только с настольного компьютера. В этом случае объем данных и скорость обработки обычно не имеют значения. Если представления используются в нескольких проектах, ими можно управлять с помощью соответствующих команд. **экспорт** и **импорт** всадник
[Инструменты](/docs/viz/vis.md#tools) Их можно копировать. Создание ссылок между проектами с помощью навигационных виджетов невозможно.\
**Кончик**Создание тестового проекта также может быть полезно при экспериментировании с командами CSS.

#### Настройки... (7)

![](../../de/viz/media/iobroker_vis_Editor_Setup_Projekteinstellungen.JPG)

- _**Перезагрузите устройство, если соединение не устанавливается дольше:**_ Активное представление полностью перезагружается, если соединение между интерфейсом (планшетом) и сервером прерывается на время, превышающее заданное. Чтобы предотвратить это, это время также можно скорректировать. _**никогда**_ был задан вопрос.
- _**Интервал переподключения:**_ Время, в течение которого фронтенд должен попытаться связаться с сервером.
- _**Темный экран переподключения:**_ При попытке перезагрузки страница обычно отображается белой. Чтобы это не отвлекало в темных помещениях, экран можно переключить в темный режим с помощью этого флажка.
- _**Удаление неактивных представлений из оперативной памяти:**_ Чтобы сэкономить ценную оперативную память на стороне клиента, которая обычно составляет всего 1 ГБ на бюджетных планшетах, можно удалить из ОЗУ неиспользуемые представления. Однако в этом случае повторная загрузка этих представлений займет больше времени. Эта опция позволяет установить, как долго неиспользуемые представления должны храниться в ОЗУ.

## Боковая панель виджетов (2)

Она используется для выбора виджетов. Виджеты отображаются в виде значков, которые можно перетаскивать на рабочую область или выбирать с помощью кнопки. _Вставлять_ располагаться в точке 0,0 рабочей поверхности.\
![](../../de/viz/media/vis_iobroker_vis_Editor_Widgets_sidebar.jpg)

Поле под кнопкой _Вставлять_ Это поле фильтра. Здесь вы можете ввести поисковый запрос для значков, содержащих этот запрос. Будут отображены все значки, содержащие этот запрос. Если вы очистите последний фильтр (или отметите \*), появится выпадающий список возможных поисковых запросов. Ниже находится поле выбора фраз для виджета.\
Звездочкой (\*) обозначены все наборы виджетов.\
При фильтрации по ключевым словам поиск выполняется автоматически по всем наборам виджетов. В противном случае, в выпадающем меню также предлагаются различные наборы виджетов в качестве фильтров.

## Боковая панель настроек (4)

Здесь все настройки для представлений и виджетов вводятся через соответствующие вкладки. Кроме того, вкладка CSS предоставляет опытным пользователям возможность интегрировать собственные разработки.

- назначение точек данных
- Размер виджета
- Размер и цвет шрифта
- фон
- Рамка, цвет линии, стиль, толщина
- Параметры CSS

Для отображения точек данных или выполнения действий точку данных необходимо присвоить виджету. Эта запись находится в разделе _В целом_ найти.
