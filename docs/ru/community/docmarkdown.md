## Что здесь применимо

### Заголовок каждого файла

```
---
title:       "Kurzer Seitentitel"
lastChanged: "08.09.2026"
---
```

`title` — это название страницы. `lastChanged` дата последнего изменения содержимого в формате `TT.MM.JJJJ`. The **Имя в меню** Однако это происходит не отсюда, а из... `content.md`.

Поле `translatedFrom` Это означает: файл был переведен машинным способом и будет перезаписан при следующем запуске перевода. Не редактируйте такие файлы.

### Информационные блоки

Цветные прямоугольники создаются двумя строками в начале строки:

```
?> Ein Hinweis. Nützlich, aber nicht dringend.

!> Eine Warnung. Wer sie überliest, macht etwas kaputt.
```

Используйте с осторожностью. Страница, на которой выделено всё, ничего не выделяет.

### Фотографии

Изображения находятся в папке. `media` рядом с боковой стороной, и обращение к ним осуществляется оттуда:

```
![Kurze Beschreibung](../../de/community/media/dateiname.png)
```

Текст в квадратных скобках не является декоративным: он отображается там, где изображение не может быть загружено, и будет зачитан вслух. Если изображение должно быть уже текстовой области, этого можно добиться, указав ширину:

```html
<img src="media/dateiname.png" alt="Kurze Beschreibung" width="630" />
```

#### Слушать

Markdown поддерживает отсортированные (нумерованные) и неотсортированные списки (перечисления).

В несортированных списках в качестве маркеров используются звездочки, знаки плюса и тире — взаимозаменяемые:

```
*   Rot
*   Grün
*   Blau
```

всё то же самое:

```
+   Rot
+   Grün
+   Blau
```

И:

```
-   Rot
-   Grün
-   Blau
```

В отсортированных списках за цифрами следует точка:

```
1.  Hund
2.  Katze
3.  Maus
```

Важно понимать, что сами числа никак не влияют на вывод Markdown. Markdown генерирует следующий HTML-код из последнего списка:

```
<ol>
<li>Hund</li>
<li>Katze</li>
<li>Maus</li>
</ol>
```

Если же вы составите список следующим образом:

```
1.  Hund
1.  Katze
1.  Maus
```

Или даже:

```
3. Hund
1. Katze
8. Maus
```

Каждый раз генерируется один и тот же список. При желании вы можете правильно пронумеровать свои списки вручную. Но если вам лень, вы можете просто использовать один и тот же номер каждый раз.

Однако список всё же следует начинать с номера 1. В будущем Markdown может добавить возможность указания начального номера для первого элемента списка.

Записи в списке обычно начинаются с левого поля документа, но могут быть с отступом до трех пробелов вправо. Маркеры списка должны быть отделены от последующего текста одним или несколькими пробелами или табуляцией.

Для более удобного форматирования списков отдельные записи можно дополнительно отодвинуть, как показано здесь:

```
*   Lorem ipsum dolor sit amet, consectetuer adipiscing elit.
    Aliquam hendrerit mi posuere lectus. Vestibulum enim wisi,
    viverra nec, fringilla in, laoreet vitae, risus.
*   Donec sit amet nisl. Aliquam semper ipsum sit amet velit.
    Suspendisse id sem consectetuer libero luctus adipiscing.
```

Следующий пример генерирует тот же код, но он менее чистый:

```
*   Lorem ipsum dolor sit amet, consectetuer adipiscing elit.
Aliquam hendrerit mi posuere lectus. Vestibulum enim wisi,
viverra nec, fringilla in, laoreet vitae, risus.
*   Donec sit amet nisl. Aliquam semper ipsum sit amet velit.
Suspendisse id sem consectetuer libero luctus adipiscing.
```

Если элементы списка разделены пустыми строками, Markdown сгруппирует элементы списка по... `<p>` и `</p>` конверт.

Например, это позволит:

```
*   Warsteiner
*   König
```

к

```
<ul>
<li>Warsteiner</li>
<li>König</li>
</ul>
```

Но вот что:

```
*   Warsteiner

*   König
```

будет

```
<ul>
<li><p>Warsteiner</p></li>
<li><p>König</p></li>
</ul>
```

Элементы списка могут состоять из нескольких абзацев. Каждый последующий абзац в элементе списка должен иметь отступ не менее четырех пробелов или символа табуляции:

```
1.  Dies ist eine Listenpunkt mit zwei Absätzen. Lorem ipsum dolor
    sit amet, consectetuer adipiscing elit. Aliquam hendrerit
    mi posuere lectus.

    Vestibulum enim wisi, viverra nec, fringilla in, laoreet
    vitae, risus. Donec sit amet nisl. Aliquam semper ipsum
    sit amet velit.

2.  Suspendisse id sem consectetuer libero luctus adipiscing.
```

Хорошо бы смотрелось, если бы каждая строка следующего абзаца была с отступом, но, опять же, Markdown позволяет ленивому человеку сделать отступ только для первой строки:

```
*   Dies ist ein Listenpunkt mit zwei Absätzen

    Dies ist der zweite Absatz in diesem Listenpunkt. Nur die
erste Zeile muss eingerückt sein. Lorem ipsum dolor sit amet,
consectetuer adipiscing elit.

*   Ein weiterer Punkt in der selben Liste.
```

Чтобы использовать цитату в элементе списка, цитата должна быть с отступом:

```
*   Ein Listenpunkt mit einem Zitat:

    > Dies ist ein Zitat
    > In einer Liste.
```

Для использования блока кода в элементе списка необходимо, чтобы он соответствовал следующим требованиям. _дважды_
с отступом — 8 пробелов или две табуляции:

```
*   Ein Listenpunkt mit Codebeispiel:

        <hier Code einfügen>
```

Создание списков возможно непреднамеренно, например, при написании следующего кода:

```
1986. Was für ein wundervolles Jahr.
```

Другими словами: Последовательность _Число-период-пространство_ в начале строки. Чтобы избежать этой проблемы, точку можно экранировать обратной косой чертой:

```
1986\. Was für ein wundervolles Jahr.
```

<h3 id="precode">Code-Blöcke</h3>

Предварительно отформатированные блоки кода используются для перезаписи исходного кода программы или разметки. Вместо формирования обычных абзацев, строки внутри блока кода интерпретируются так, как они находятся. Markdown включает блоки кода с тегами \`\<code>\`. `<pre>` и `<code>`.

Чтобы создать блок кода в Markdown, просто сделайте отступ в каждой строке блока не менее чем на четыре пробела или табуляцию. Например, из следующего входного файла...

```
Dies ist ein normaler Absatz.

    Dies ist ein Code-Block.
```

...Markdown делает следующее:

```
<p>Dies ist ein normaler Absatz.</p>

<pre><code>Dies ist ein Code-Block.
</code></pre>
```

Из каждой строки отступа удаляется один уровень — 4 пробела или 1 табуляция. Например...

```
Ein Beispiel in AppleScript:

    tell application "Foo"
        beep
    end tell
```

...становится

```
<p>Ein Beispiel in AppleScript:</p>

<pre><code>tell application "Foo"
    beep
end tell
</code></pre>
```

Блок кода заканчивается на первой строке без отступа (или в конце документа).

В блоке кода амперсанд (`&`) и угловые скобки (`<` и `>`) автоматически преобразуются в HTML-сущности. Это значительно упрощает интеграцию HTML-фрагментов — просто скопируйте HTML в документ, сделайте отступ, и Markdown позаботится о кодировании амперсанда и угловых скобок. Например:

```
<div class="footer">
    &copy; 2004 Foo Corporation
</div>
```

становится:

```
<pre><code>&lt;div class="footer"&gt;
    &amp;copy; 2004 Foo Corporation
&lt;/div&gt;
</code></pre>
```

Обычный синтаксис Markdown не обрабатывается внутри блоков кода. Это означает, что звёздочки — это просто звёздочки внутри блока кода и не указывают на подсветку текста. Следовательно, легко... _выше_ говорить на языке Markdown.

### Span-Elemente

<a id="link"></a>

#### Левый

Markdown поддерживает два типа ссылок: _В соответствии_ и _Ссылки_.

В обоих стилях текст ссылки помечен \[квадратными скобками].

Для создания встроенной ссылки необходимо заключить её в обычные круглые скобки сразу после закрывающей квадратной скобки. Внутри этих скобок указывается URL-адрес, на который вы хотите сослаться, а также...
_необязательный_ Заголовок ссылки в кавычках. Примеры:

```
Dies ist [ein Beispiel](http://example.com/ "Der Linktitel") für
einen Inline-Link.

[Dieser Link](http://example.net/) hat kein Titel-Attribut.
```

В результате получается:

```
<p>Dies ist <a href="http://example.com/" title="Titel">
ein Beispiel</a> für einen Inline-Link.</p>

<p><a href="http://example.net/">Dieser Link</a> hat kein
Titel-Attribut.</p>
```

Если вы хотите ссылаться на контент, находящийся на том же сервере, вы можете использовать относительные пути:

```
Auf der Seite [Über mich](/about/) gibt es weitere Informationen.
```

Для создания ссылок используется второй набор квадратных скобок, в которых записывается произвольно выбранный идентификатор ссылки:

```
Dies ist [ein Beispiel][id] für einen Referenz-Link.
```

При желании между скобками можно также вставить пробел:

```
Dies ist [ein Beispiel] [id] für einen Referenz-Link.
```

Затем, где-то в документе, ссылка определяется на отдельной строке следующим образом:

```
[id]: http://example.com/  "Optionalen Titel hier eintragen"
```

Так:

- Квадратные скобки, содержащие идентификатор ссылки (опционально с отступом до трех пробелов);
- затем следует двоеточие;
- затем один или несколько пробелов (или табуляций);
- далее следует URL-адрес ссылки;
- Далее, по желанию, следует текст атрибута title ссылки, заключенный в скобки, одинарные или двойные кавычки.

Следующие три определения идентичны:

```
[foo]: http://example.com/  "Optionaler Titel"
[foo]: http://example.com/  'Optionaler Titel'
[foo]: http://example.com/  (Optionaler Titel)
```

**Примечание:** В Markdown 1.0.1 обнаружена известная ошибка, которая препятствует использованию одинарных кавычек в качестве разделителей для заголовков ссылок.

URL-адрес ссылки можно дополнительно заключить в угловые скобки:

```
[id]: <http://example.com/>  "Optionaler Titel hier"
```

Атрибут title также может быть установлен на следующую строку и иметь отступ с помощью дополнительных пробелов или табуляции. Это лучше смотрится с длинными URL-адресами:

```
[id]: http://example.com/langer/pfad/zu/seite
    "Optionaler Titel hier"
```

Определения ссылок используются только для создания ссылок в процессе обработки документа Markdown и удаляются из документа перед выводом HTML-кода.

В качестве элементов структуры ссылки могут использоваться буквы, цифры, пробелы и знаки препинания. _независимый_ Что касается написания заглавных букв:

```
[Link-Text][a]
[Link-Text][A]
```

Оба определения связи эквивалентны.

Он _подразумеваемые идентификаторы ссылок_ Позволяет опустить идентификатор ссылки. В этом случае в качестве идентификатора используется сам текст ссылки. Просто добавьте к тексту ссылки пустые квадратные скобки:

```
[Google][]
```

Затем определяется связь:

```
[Google]: http://google.com/
```

Поскольку идентификаторы ссылок могут содержать пробелы, это сокращение работает даже для нескольких слов в тексте ссылки:

```
Besuchen Sie [Daring Fireball][] für weitere Informationen.
```

Затем определяется связь:

```
[Daring Fireball]: http://daringfireball.net/
```

Ссылки можно размещать в любом месте документа Markdown. Как правило, лучше размещать их после абзаца, в котором они используются. Однако их также можно перечислить вместе в конце документа, как сноски.

Небольшой пример:

```
Ich bekomme zehn Mal mehr Traffic von [Google] [1] als von
[Yahoo] [2] oder [MSN] [3].

  [1]: http://google.com/        "Google"
  [2]: http://search.yahoo.com/  "Yahoo Search"
  [3]: http://search.msn.com/    "MSN Search"
```

Используя аббревиатуру через подразумеваемый идентификатор ссылки, можно также написать следующее:

Я получаю в десять раз больше трафика из \[Google]\[], чем из \[Yahoo]\[] или \[MSN]\[].

```
  [google]: http://google.com/       "Google"
  [yahoo]: http://search.yahoo.com/  "Yahoo Search"
  [msn]: http://search.msn.com/      "MSN Search"
```

В обоих примерах получится следующий HTML-код:

```
<p>Ich bekomme zehn Mal mehr Traffic von <a href="http://google.com/"
title="Google">Google</a> als von
<a href="http://search.yahoo.com/" title="Yahoo Search">Yahoo</a>
oder <a href="http://search.msn.com/" title="MSN Search">MSN</a>.</p>
```

Для сравнения, тот же абзац приводится ниже с использованием встроенных ссылок Markdown:

```
Ich bekomme zehn Mal mehr Traffic von [Google](http://google.com/ "Google")
als von [Yahoo](http://search.yahoo.com/ "Yahoo Search") oder
[MSN](http://search.msn.com/ "MSN Search").
```

Идея использования ссылок не в том, что их проще писать. Идея в том, что они делают документы гораздо более читабельными. Пример абзаца содержит всего 80 символов со ссылками, но без них его длина составляет целых 181 символ; в формате HTML это 239 символов, больше разметки, чем контента.

Ссылки в Markdown делают исходный документ более похожим на конечный формат, отображаемый в браузере. Возможность извлекать метаданные для разметки из абзаца позволяет интегрировать ссылки в текст, не нарушая его связность.

<a id="em"></a>

#### акцент

Markdown обрабатывает звездочки (`*`) и подчеркивания (`_`) как индикаторы акцента. В отдельности `*` или `_` Упакованный текст заключен в HTML-тег. `<em>` закрытый, двойной `*` или `_` всё будет в тот же день `<strong>` выделено. Например, следующий текст:

```
*Einzelne Sternchen*

_Einzelne Unterstriche_

**Doppelte Sternchen**

__Doppelte Unterstriche__
```

В результате будет выведено следующее:

```
<em>Einzelne Sternchen</em>

<em>Einzelne Unterstriche</em>

<strong>Doppelte Sternchen</strong>

<strong>Doppelte Unterstriche</strong>
```

Стиль можно выбирать свободно. Единственное ограничение заключается в том, что один и тот же символ должен использоваться для открытия и закрытия области выделения.

Выделение может быть использовано в середине слова:

```
Herr*gott*sakrament
```

Но если а `*` или `_` Если символ заключен в пробелы, он рассматривается как простая звездочка или подчеркивание.

Чтобы написать звездочку или нижнее подчеркивание в месте, где они будут восприняты как выделение, их можно замаскировать обратной косой чертой:

```
\*Dieser Text ist von Sternchen umschlossen.\*
```

<a id="code"></a>

#### код

Для обозначения диапазона кодов он заключается в обратные кавычки (`` ` ``В отличие от блока кода, область кода форматирует код внутри обычного абзаца:

```
Benutze die Funktion `printf()` um Text auszugeben.
```

Становится:

```
<p>Benutze die Funktion <code>printf()</code> um Text auszugeben.</p>
```

Если в области кода необходимо отобразить обратную кавычку, то до и после области кода можно использовать несколько обратных кавычек:

```
``Irgendwo hier (`) ist ein Backtick versteckt.``
```

В результате получится:

```
<p><code>irgendwo hier (`) ist ein Backtick versteckt.</code></p>
```

В качестве разделителей диапазона кодов обратными кавычками могут использоваться пробелы — один после открывающей обратной кавычки и один перед закрывающей. Это позволяет использовать обратные кавычки внутри диапазона кодов, даже в начале или конце.

```
Ein einzelner Backtick in einem Code-Bereich: `` ` ``

Ein Backtick-umschlossener String in einem Code-Bereich: `` `foo` ``
```

становится:

```
<p>Ein einzelner Backtick in einem Code-Bereich: <code>`</code></p>

<p>Ein Backtick-umschlossener String in einem Code-Bereich: <code>`foo`</code></p>
```

В разделах кода амперсанд (&) и угловые скобки кодируются как HTML-сущности.

```
Niemand benutzt `<blink>` Tags.
```

В результате получится:

```
<p>Niemand benutzt <code>&lt;blink&gt;</code> Tags.</p>
```

Также подойдет следующий вариант:

```
`&#8212;` ist das dezimal kodierte Äquivalent von `&mdash;`.
```

Это приведет к

```
<p><code>&amp;#8212;</code> ist das dezimal kodierte
Äquivalent von <code>&amp;mdash;</code>.</p>
```

#### Графика

Следует признать, что найти «естественный» синтаксис для встраивания графики в текст довольно сложно.

В Markdown для этого используется синтаксис, который призван имитировать стиль ссылок. Это позволяет использовать два типа ссылок: встроенные и ссылочные.

Встроенный синтаксис выглядит следующим образом:

```
![Alternativer Text](../../de/community/pfad/zum/bild.jpg)

![Alternativer Text](../../de/community/pfad/zum/bild.jpg "Optionaler Titel")
```

Так:

- Восклицательный знак: `!`;
- далее следуют квадратные скобки, определяющие значение
  `alt`-В графическое изображение были включены следующие атрибуты;
- Далее следуют скобки, содержащие URL-адрес или путь к изображению, а также значение необязательного параметра. `title`Атрибуты, заключенные в кавычки.

В стиле оформления ссылок изображения выглядят следующим образом:

```
![Alternativer Text][id]
```

Здесь "id" — это имя определенной ссылки на изображение. Ссылки на изображения определяются с использованием того же синтаксиса, что и ссылки на объекты:

```
[id]: url/zur/grafik  "Optionales title-Attribut"
```

В настоящее время в Markdown отсутствует синтаксис для указания размера изображения. При необходимости можно использовать стандартный HTML-тег.

#### Маскирование обратной косой черты

Markdown позволяет использовать экранирование обратной косой чертой для написания символов, которые в синтаксисе Markdown имеют определенное значение. Например, если вы хотите заключить слово в звездочки (вместо HTML-тега \`\`). `<em>`Перед звездочками можно ставить обратные косые черты:

```
\*Von Sternchen umgeben\*
```

Markdown предоставляет такую возможность для следующих символов:

```
\   Backslash
`   Backtick
*   Sternchen
_   Unterstrich
{}  Geschweifte Klammern
[]  Eckige Klammern
()  Runde Klammern
#   Raute
+	Plus-Zeichen
-	Minus-Zeichen (Bindestrich)
.   Punkt
!   Ausrufezeichen
```
