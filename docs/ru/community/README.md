# Участвовать

ioBroker создан волонтерами в свободное время. Нет компании, которая заказывает адаптеры, и никто не получает деньги за ответы на вопросы. Все, что работает, работает потому, что кто-то вложил в это усилия.

Для участия не требуются знания программирования. Список отсортирован по объему работы, а не по важности:

| Вклад                      | Что для этого необходимо?                                                                                                                     |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **Отвечая на вопросы**     | Опыт работы со своей собственной системой. Человек, который только что самостоятельно решил проблему, может объяснить её следующему человеку. |
| **Добавить решения**       | Пять минут. Сообщение на форуме, заканчивающееся фразой «проблема решена», никому не поможет.                                                 |
| **Сообщить об ошибке**     | Пожалуйста, будьте внимательны при описании вашей проблемы. См. [раздел «Сообщить об ошибках»](/docs/trouble/issue.md) .                      |
| **Переводить**             | Второй язык. Адаптеры и интерфейсы постоянно требуют перевода.                                                                                |
| **Написание документации** | Текстовый редактор и учетная запись GitHub. См. [раздел «Написание статьи»](/docs/community/doc.md) .                                         |
| **Разрабатывать адаптеры** | JavaScript или TypeScript. См. [разработку адаптера](/docs/dev/adapterdev.md) .                                                               |
| **Пожертвовать**           | И ничего больше. У многих адаптеров в настройках есть кнопка для пожертвований.                                                               |

## Где это происходит

**[Форум](https://forum.iobroker.net)** — это место для всего, что связано с работой устройства: вопросы, решения, объявления, обсуждения новых адаптеров. Информацию о том, как ваши сообщения отображаются на форуме, можно найти в разделе [«Форум»](/docs/trouble/forum.md) .

**[GitHub](https://github.com/ioBroker)** — это место, где размещается исходный код: адаптеры, JS-контроллер, административный интерфейс, скрипты установки и эта документация. Сообщения об ошибках и предложения по улучшению следует отправлять туда.

## Самое простое начало

Если вы не знаете, с чего начать: в следующий раз, когда вы решите проблему самостоятельно, запишите решение. Включите его в сообщение на форуме, где вы задали вопрос, или на страницу документации, где отсутствовал ответ. Это требует совсем немного усилий и именно то, чего не хватает большинству людей при поиске.
