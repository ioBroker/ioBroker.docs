# Расширенная конфигурация

Система ioBroker установлена и работает, но настроена для удобства, а не для непрерывной работы: нет авторизации, нет шифрования, нет резервного копирования, все данные хранятся во встроенных файловых базах данных. На начальном этапе это вполне приемлемо. Однако, как только система начнет использоваться всерьез, стоит обратить внимание на моменты, описанные в этой главе.

Если вы прочитаете только одну из этих страниц, пусть это будет [страница о резервном копировании данных](/docs/config/backup.md) . Все остальное можно сделать позже, а вот отсутствие резервной копии – нет.

Разумный порядок для системы, которая должна сохраниться:

1. **Настройте систему безопасности** и активируйте её вручную один раз.
2. **Пароль** пользователя`admin` Назначить и активировать **регистрацию** .
3. Если система должна быть доступна за пределами домашней сети, требуется **шифрование** , или, что еще лучше, передача данных через [IoT-адаптер](/docs/cloud/iot.md) .
4. Создайте **отдельные учетные записи пользователей** с ограниченными правами для других членов семьи.
5. Только когда система станет большой: **Redis** и, возможно, **многохостинговая архитектура** .
