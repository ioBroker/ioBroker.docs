# ioBroker.fyta

## Адаптер FYTA для ioBroker

Неофициальный адаптер для подключения ioBroker к [датчикам растений FYTA.](https://fyta.de/) Датчики можно приобрести в [магазине FYTA.](https://fyta.de/collections/all)
