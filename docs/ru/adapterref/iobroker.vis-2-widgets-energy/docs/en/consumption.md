# Потребление

![Потребление энергии](../../../../../en/adapterref/iobroker.vis-2-widgets-energy/img/consumption.png)

Одна полоса (или линия) на каждый час, день, будний день или месяц выбранного периода, отображающая до n точек данных одновременно. Данные поступают из исторического экземпляра, поэтому это единственный виджет в наборе, которому требуется такая полоса.

## Требования

- **Пример из истории** (`history`, `sql`, `influxdb` Виджет использует экземпляр истории по умолчанию из системных настроек ioBroker.
- Данные должны **регистрироваться** данным экземпляром объекта — включите ведение журнала в настройках объекта.
- Точка, см. [точку](/#/docs/adapterref/iobroker.vis-2-widgets-energy/docs/en/README.md#the-period) .

## Как месячные превращаются в бары

| Период | Бары                    | Этикетка |
| ------ | ----------------------- | -------- |
| День   | 24, по одному в час     | `HH:00`  |
| Неделя | 7, по одному в день     | `Mon` …  |
| Месяц  | 28–31, по одному в день | `DD.MM`  |
| Год    | 12, один раз в месяц    | `Jan` …  |

В экземпляр истории запрашивается ровно указанное количество агрегированных значений. Что именно будет включено в один столбец, определяется параметром _Aggregate_ .

## Счетчик или потребление?

Большинство данных об энергопотреблении в ioBroker представляют собой **счетчики** : числа, которые постоянно растут, например... `1234.5 kWh` Общий объем потребления с момента установки. График показывает ступенчатую динамику, а не фактическое потребление.

Включите параметр **«Рассчитать разницу»** для этих случаев. В этом случае виджет добавит один дополнительный интервал перед периодом и покажет разницу между двумя последовательными показаниями — то есть потребление за этот час или день. Используйте его вместе с _параметром «Агрегировать_ =». `max`.

Не указывайте это, если точка данных уже содержит информацию о потреблении за определенный период (например, что-то подобное). `statistics` адаптер изготовлен).

| Количество устройств                   | Сколько точек данных было выбрано                                                                                                  |
| Виджет для выбора временного интервала | На этом графике используется [селектор интервалов.](/#/docs/adapterref/iobroker.vis-2-widgets-energy/docs/en/interval-selector.md) |

### Агрегация

| Поле                      | Значение                                                                                                              |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Совокупность              | Как экземпляр истории сжимает один столбец: `max`, `min`, `average`, `total`, `integral` …                             |
| Рассчитайте разницу       | См. [выше](#counter-or-consumption) . Предложение действительно только для `max`, `min`, `average`, `none`, `integral` |
| Процентиль / Квантиль     | Параметр агрегации соответствия                                                                                       |
| Встроенный блок           | Единица измерения времени интеграла — секунды, например. `3600` в течение одного часа                                  |
| Интегральная интерполяция | Как заполняются промежутки между двумя образцами при интегрировании                                                   |

### Значение 1 … н

| Поле      | Значение                                                                                                  |
| --------- | --------------------------------------------------------------------------------------------------------- |
| ОИД       | Зарегистрированная точка данных. Название, цвет и единица измерения заполняются на основе данных объекта. |
| Имя       | Отображено в легенде и во всплывающей подсказке.                                                          |
| Цвет      | Цвет сериала                                                                                              |
| Единица   | Всплывающая подсказка показывает, что первый сконфигурированный элемент также обозначает ось Y.           |
| Множитель | Масштабирование, например `0.001` преобразовать Вт·ч в кВт·ч                                               |

## Рецепт: для домашнего использования, теплового насоса и настенной теплостанции в день.

1. _Количество устройств_ : 3, _столбцы с разметкой_ включены.
2. _Совокупный объем_ =`max` _Рассчитайте разницу_ — все три показателя являются показаниями счетчика.
3. Значение 1 = бытовой счетчик, значение 2 = счетчик теплового насоса, значение 3 = настенный счетчик.
4. Разместите над ним [селектор интервала](/#/docs/adapterref/iobroker.vis-2-widgets-energy/docs/en/interval-selector.md) и выберите его в _виджете для выбора временного интервала_ .

## Поиск неисправностей

- **Диаграмма остается пустой.** Экземпляр истории не регистрирует эту точку данных, или в системных настройках отсутствует экземпляр истории по умолчанию. Виджет ожидает ответа 10 секунд, а затем ничего не отображает — отсутствующий экземпляр истории вообще никогда не отвечает.
- **Лестница вместо счетчика потребления.** Включите функцию _«Рассчитать разницу»_ .
- **Одна полоса слишком большая.** Счетчик был сброшен, поэтому разница с предыдущим показанием огромна. Виджет ограничивает отрицательную разницу до 0, но сброс до меньшего значения все равно приводит к появлению одной неправильной полосы в следующем интервале.
- **Отсутствует текущий час.** Это была ошибка до версии 2.0.1: в режиме вычисления разницы отбрасывался последний интервал периода. Исправлено.
- **В феврале было 31 бар.** Также была исправлена ошибка — продолжительность месяца бралась из предыдущего месяца.
