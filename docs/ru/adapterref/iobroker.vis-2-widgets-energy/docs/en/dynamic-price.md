# Динамическое ценообразование на электроэнергию

![Динамическое ценообразование на электроэнергию](../../../../../en/adapterref/iobroker.vis-2-widgets-energy/img/dynamicPrice.png)

Почасовая биржевая цена в виде столбчатой диаграммы. Самые дешевые часы обозначены зеленым цветом, самые дорогие — красным, текущий час — синим, а пунктирная линия отмечает среднее значение за показанные часы.

## Требования

Один из элементов данных содержит цены в виде **массива JSON** . Все адаптеры, предоставляющие биржевые цены, делают это, но каждый из них называет поля по-своему — виджет же распознает обычные имена самостоятельно:

| Адаптер       | Типичная точка данных | Временное поле    | Поле цены     |
| ------------- | --------------------- | ----------------- | ------------- |
| `tibberlink`  | `…PricesToday.json`   | `startsAt`        | `total`       |
| `awattar`     | `…prices.json`        | `start_timestamp` | `marketprice` |
| `epex-spot`   | `…prices`             | `start`           | `price`       |
| `smartenergy` | `…prices`             | `date`            | `value`       |

Принимаются следующие варианты:

- массив записей, например `[{ "startsAt": "2026-09-24T12:00:00+02:00", "total": 0.246 }, …]`,
- массив, обернутый в объект, например `{ "prices": [ … ] }` (также `today`, `data`, `values`, `result`),
- Простой массив из 24 чисел, которые затем читаются как часы сегодняшнего дня, начиная с полуночи.

Время может быть представлено в виде строки ISO, метки времени в миллисекундах или в секундах.

Если ничего из этого не подходит, задайте **полям «Время»** и **«Цена»** имена, используемые вашим адаптером.

## Конфигурация

### Общий

| Поле                   | Значение                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------ |
| Без рамки / Имя        | Карточка и заголовок                                                                 |
| Цены OID               | Точка данных в виде JSON-массива                                                     |
| Временное поле         | Оставьте поле пустым; обычные имена распознаются автоматически.                      |
| Поле цены              | Оставьте поле пустым; обычные имена распознаются автоматически.                      |
| Множитель              | `100` переводит евро/кВтч в центы за кВтч. `1` оставляет цены как есть                |
| Единица                | Указывается после каждой цены, например: `ct/kWh`                                     |
| Десятичные дроби       | Десятичные дроби цен                                                                 |
| Количество часов       | Сколько часов отработано. `0` Отображает все данные, имеющиеся в данной точке данных. |
| Только с этого момента | Не учитывайте часы, которые истекли.                                                 |
| Показать текущую цену  | Цена за час работы указана выше графика.                                             |
| Показать средний       | Пунктирная линия                                                                     |

### Цвета

| Поле                                    | Значение                                                                            |
| --------------------------------------- | ----------------------------------------------------------------------------------- |
| Выделение                               | Как определяются цены (дешево и дорого), см. ниже.                                  |
| Самые дешевые часы / Самые дорогие часы | Сколько часов нужно, чтобы получить дешевый/дорогой цвет (режим "the n…")           |
| Допуск                                  | Процентное отклонение от среднего значения (мода «расстояние до среднего значения») |
| Дешевый / Обычный / Дорогой цвет        | Три цвета                                                                           |
| Цвет текущего часа                      | Продолжительность часа. Она превосходит по значимости выделение текста.             |

## Два режима подсветки

**n самых дешевых и n самых дорогих** часов ранжируют показанные часы и раскрашивают первые n и последние n. Используйте это, чтобы ответить на вопрос: «Когда следует включить посудомоечную машину сегодня вечером?».

**Расстояние до среднего значения** цветов в час, если оно превышает _допустимый_ процент, ниже или выше среднего значения за указанные часы. Используйте это, чтобы увидеть, насколько необычен сегодняшний день.

**Ни один из** вариантов не отображает все полосы обычным цветом; текущий час всё равно выделяется.

## Рецепт: когда заряжать автомобиль

1. _Prices OID_ = массив цен вашего тарифного адаптера, _Multiplier_ =`100`, _Единица измерения_ =`ct/kWh`.
2. _Только с этого момента_ , _количество часов_ =`12`.
3. _Выделение_ =`The n cheapest and most expensive` Самые _дешевые часы_ =`4` _Самые дорогие часы_ =`0`.

Четыре зелёных столбика обозначают четыре самых дешёвых показателя за следующие двенадцать часов.

## Поиск неисправностей

- **«Цены не найдены».** Точка данных пуста, не является допустимым JSON-объектом или записи используют имена полей, которые виджет не знает. Посмотрите значение в обозревателе объектов и установите поля _«Время»_ и _«Цена»_ .
- **Цены указаны с разницей в 100 раз.** Ваш адаптер выдает €/кВтч, а вам нужны центы, или наоборот. Установите _множитель_ .
- **Все полосы серые.** _Подсветка_ ... `None` Или же, если учитывать «расстояние до среднего», _допустимое отклонение_ настолько велико, что ни один час его не достигает.
- **Вечером график пуст.** _Только с этого момента из него_ исключается информация о прошлых ценах, а цены на завтра обычно публикуются в начале дня. Когда ничего не остаётся, виджет возвращается к отображению всей информации.
- **Текущий час не подсвечивается.** Полоса просто синяя, а текущий час находится внутри отображаемого окна — _только с этого момента_ это будет первый час.
