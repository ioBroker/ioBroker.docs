# Распределение

![Распределение энергии](../../../../../en/adapterref/iobroker.vis-2-widgets-energy/img/distribution.png)

Анимированная блок-схема. Дом расположен посередине, вокруг него по кругу размещены подключение к электросети и до десяти дополнительных узлов (солнечные батареи, аккумулятор, настенная коробка, тепловой насос, бассейн и т. д.). По каждой линии подключения перемещается точка; её направление показывает, куда течёт энергия, а скорость соответствует её значению.

Кольцо вокруг дома разделено на сегменты, по одному на каждый узел, размер которых определяется долей этого узла в общей структуре.

## Требования

Только текущие значения, без истории изменений. Одна точка данных на узел, плюс одна для дома и одна для сети.

## Конфигурация

### Общий

| Поле                           | Значение                                                                                       |
| ------------------------------ | ---------------------------------------------------------------------------------------------- |
| Без рамки                      | Возьмите карту без её использования.                                                           |
| Имя                            | Заголовок в верхней части карточки                                                             |
| Цвет по умолчанию              | Цвет линий и кругов, не имеющих собственного цвета.                                            |
| Размер круга по умолчанию      | В процентах от ширины виджета                                                                  |
| Размер расстояния по умолчанию | Расстояние между домом и узлами, в процентах от ширины виджета.                                |
| Размер шрифта по умолчанию     | В пикселях. Узел со своим собственным размером шрифта имеет преимущество перед этим.           |
| Размер радиуса по умолчанию    | Радиус, используемый кругами, не имеющими собственного размера, в процентах от ширины виджета. |
| Количество узлов               | Сколько узлов нарисовано, помимо сетки?                                                        |
| ширина строки                  | Толщина окружностей и сегментов кольца дома в пикселях.                                        |

| Показать неизмененные значения | Отключает автоматическое преобразование, см. [Единицы измерения.](#units)                      |

### Круг линии электропередачи

Всё, что связано с родным кругом, плюс:

| Поле                               | Значение                                                                                                       |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| ОИД линии электропередачи          | Электроэнергия потребляется из сети. **Отрицательное** значение означает, что энергия поступает в сеть.        |
| OID возврата линии электропередачи | Отдельная точка данных для входящего потока, если счетчик передает данные по двум направлениям отдельно.       |
| Возврат энергии цвета              | Цвет значения входного параметра внутри круга                                                                  |
| Скрыть, если меньше                | Затемняет кружок ниже этого значения. В пустом режиме он всегда отображается. В редакторе он остается видимым. |
| Инвертировать направление          | Изменяет направление движения точки.                                                                           |
| Скорость движения                  | Чем больше число, тем медленнее движется точка при том же значении.                                            |

### Узел 1 … n

Те же поля, что и на линии электропередачи, плюс:

| Поле       | Значение                                                                              |
| ---------- | ------------------------------------------------------------------------------------- |
| OID 2      | Внутри круга находится второе значение, например, уровень заряда батареи в процентах. |
| Блок OID 2 | Оставьте поле пустым, чтобы использовать единицу измерения для данной точки данных.   |

## Единицы

Точка данных, единицей измерения которой является `Wh` делится на 1000 и отображается как `kWh` а значение без единиц измерения получает `kWh` Запись идёт после этого. Это историческое поведение, сохраняющееся для того, чтобы существующие представления не менялись. Включите параметр « **Показывать неизменённые значения»** , чтобы получить значение и единицу измерения точки данных точно такими, какими они есть.

> Вплоть до версии 2.0.1 значение делилось, но единица измерения оставалась неизменной. `Wh` Таким образом, 1500 Вт·ч отображалось как "1,5 Вт·ч". Единица измерения исправлена вместе с фактическим значением.

## Направление точки

По умолчанию **положительное** значение поступает в дом, а отрицательное — от него. Это подходит для сетевого счетчика (положительное значение = потребление из сети) и инвертора фотоэлектрической системы (положительное значение = производство). Для точки данных, которая считает в обратном порядке — например, батарея, которая сообщает об разряде как об отрицательном значении, — включите функцию **«Инвертировать направление»** для этого узла.

## Рецепт: электросеть, солнечные панели, аккумулятор и настенная батарея.

1. _Количество узлов_ = 3.
2. _Идентификатор линии электропередачи (OID)_ = сетевой счетчик. Устанавливайте _идентификатор обратной линии электропередачи (OID)_ только в том случае, если линия электропередачи имеет собственную точку данных.
3. Узел 1: производство солнечной энергии. Стандартная иконка «Солнечная энергия».
4. Узел 2: уровень заряда батареи. _OID 2_ = состояние заряда, _OID 2 unit_ =`%` Включите _функцию инвертирования направления_ зарядки, если инвертор показывает отрицательный заряд.
5. Узел 3: настенный блок. _Скрыть, если меньше_ =`50` Таким образом, круг исчезает, пока ни одна машина не заряжается.

## Поиск неисправностей

- **Ничего не движется.** Точка рисуется только тогда, когда значение не равно 0. Также отметьте пункт _«Без анимации»_ .
- **Отсутствует кружок.** _Скрыть, если значение меньше_ текущего. В редакторе скрытые кружки остаются видимыми, чтобы их можно было настраивать.
- **Все значения в 1000 раз больше.** Установите _множитель_ равным `0.001` или отключите параметр _«Показывать неизмененные значения»,_ если точка данных действительно находится в Вт·ч.
- **Метка узла обрезана.** Уменьшите _размер шрифта по умолчанию_ или увеличьте расстояние до узла с помощью _параметра Distance_ .
