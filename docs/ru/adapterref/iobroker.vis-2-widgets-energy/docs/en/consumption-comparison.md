# Сравнение потребления

![Сравнение энергии](../../img/comparison.png)![Круговая диаграмма](../../../../../en/adapterref/iobroker.vis-2-widgets-energy/img/pie.png)

Сравнивает **текущие значения** нескольких точек данных друг с другом — в виде столбчатой диаграммы для ранжирования или круговой диаграммы для распределения долей целого. История изменений не требуется; значения считываются в режиме реального времени.

## Конфигурация

### Общий

| Поле                  | Значение                                                             |
| --------------------- | -------------------------------------------------------------------- |
| Без рамки / Имя       | Карточка и заголовок                                                 |
| Тип                   | Столбчатая диаграмма или круговая диаграмма                          |
| Количество устройств  | Сколько точек данных сравнивается, не менее 2?                       |
| Сортировка            | В зависимости от конфигурации, сначала наибольшее, затем наименьшее. |
| Десятичные дроби      | Десятичные знаки значений во всплывающей подсказке и в подписях.     |
| Без анимации          | Рисуйте сразу, вместо анимации.                                      |
| Длительность анимации | В миллисекундах                                                      |

### Гистограмма

| Поле              | Значение                                                          |
| ----------------- | ----------------------------------------------------------------- |
| Ориентация        | Горизонтальные планки (первое устройство сверху) или вертикальные |
| Показать значения | Напишите значение рядом с каждой черточкой столбика.              |

### Круговая диаграмма

| Поле                              | Значение                                                                            |
| --------------------------------- | ----------------------------------------------------------------------------------- |
| Внутренний радиус                 | Размер отверстия посередине, в процентах. 0 означает, что пирог заполнен полностью. |
| Внутренний заголовок              | Текст посередине, над внутренним значением.                                         |
| Идентификатор внутреннего объекта | В центре показана точка данных, например, итоговая сумма.                           |
| Внутренняя единица стоимости      | Записывается непосредственно после внутреннего значения                             |
| Легенда шоу                       | В таблице приведен список устройств с указанием их значений.                        |
| Высота легенды                    | Какова высота, которую занимает легенда, в процентах?                               |
| Скрыть метки                      | Не вписывайте проценты в сегменты.                                                  |
| Точность метки                    | Десятичные дроби этих процентов                                                     |

### Уровень 1 … н

| Поле      | Значение                                                              |
| --------- | --------------------------------------------------------------------- |
| ОИД       | Точка данных. Название и цвет заполняются на основе данных объекта.   |
| Имя       | Отображается на оси, в легенде и во всплывающей подсказке.            |
| Цвет      | Цвет полосы или сегмента                                              |
| Единица   | Оставьте поле пустым, и будет использована единица измерения объекта. |
| Множитель | Масштабирование, например `0.001` при Вт·ч → кВт·ч                     |

## Единицы

Каждое устройство имеет **свою** единицу измерения — всплывающая подсказка, подписи и легенда показывают единицу измерения этого устройства, а ось X обозначена первой настроенной единицей измерения.

> **Критическое изменение в версии 2.0.0:** этот виджет больше не преобразует Вт в Вт·ч или кВт в кВт·ч и больше не делит Вт·ч на 1000. Он отображает реальное значение с реальными единицами измерения. Если на вашей панели управления внезапно отображаются значения, в 1000 раз превышающие реальные, установите _множитель_ для этого устройства на `0.001`.
>
> Вплоть до версии 2.0.1 единицы устройств путались, как только в игре использовалось более одной единицы, потому что диаграмма отображала устройства в обратном порядке, но искала единицу по позиции в диаграмме. Исправлено.

## Рецепт: куда девается электричество?

1. _Тип_ =`pie` _Внутренний радиус_ =`55` _Количество устройств_ =`4`.
2. Уровень 1…4 = суточное потребление домохозяйства, теплового насоса, настенного теплораспределителя и бассейна.
3. _Идентификатор внутреннего объекта_ = общее потребление за день, _Внутренний заголовок_ =`Today`.
4. _Включите отображение легенды_ , чтобы абсолютные значения также были читаемы.

## Поиск неисправностей

- **Устройство показывает 0.** Его идентификатор объекта не задан, или точка данных еще не имеет значения.
- **Проценты в сумме не дают 100.** _Точность меток_ округляет значения; сама диаграмма отображает точное значение.
- **Неправильная единица измерения на шкале.** Установите _единицу измерения_ непосредственно на устройстве, а не полагайтесь на объект.
