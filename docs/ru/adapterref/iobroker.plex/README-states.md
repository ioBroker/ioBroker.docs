## С расширенными настройками

### с помощью Plex Pass или Tautulli

При получении события веб-хуком — будь то при использовании Plex Pass или при настройке Tautulli — будут получены следующие состояния.

**Примечание:** После настройки Tautulli состояния можно в значительной степени адаптировать под любые параметры. См. [инструкции по настройке веб-хука (шаг 4)](https://github.com/iobroker-community-adapters/ioBroker.plex#1222-webhook) .

При стандартной настройке Plex Pass или Tautulli будут получены и созданы следующие состояния:

- \* Указывает, что состояние отображается только при использовании Plex Plass.
- \*\*Указывает, что состояние задается только при использовании Tautulli

| Канал / Папка                                                               | Состояние                   | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------------------------------------------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
