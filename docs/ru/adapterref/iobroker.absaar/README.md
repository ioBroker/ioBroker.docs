# IoBroker.absaar
Адаптер ioBroker для инверторов Absaar EMS. Адаптер считывает данные об инверторах и станциях из облачного API Absaar EMS, используемого приложением Absaar EMS.

Информация о продукте и производителе доступна в разделе [Официальный сайт AdvanSol Power](https://www.advansol-power.com/).

Адаптер не содержит закрытых учетных данных, закрытых имен хостов или данных, специфичных для пользователя. Учетные данные хранятся в защищенных и зашифрованных полях собственной конфигурации ioBroker.

## Функции
- Опрос через облако с помощью `https://mini-ems.com:8081`
- Войдите в систему, используя учетные данные приложения Absaar EMS.
- Автоматическая обработка токенов и повторная аутентификация
- Настраиваемый интервал опроса
- Состояние станций по суточному, месячному и суммарному объему выработки энергии.
- Дополнительные параметры станции, такие как текущая мощность и счетчики дохода/окружающей среды.
- Состояние коллектора, такое как входная мощность, статус подключения, имя коллектора и время последнего подключения.
- Состояния инвертора для переменного тока, фотоэлектрических панелей, температуры, батареи и нагрузки.
- Дополнительные параметры: необработанные JSON-состояния для устранения неполадок.
- Административная конфигурация на основе JSON

## Требования
- ioBroker js-controller `>= 6.0.11`
- ioBroker Admin `>= 7.8.23`
- Node.js `>= 22`
- Учетная запись Absaar EMS, в которой как минимум один инвертор или станция настроены в приложении Absaar EMS.
- Сетевой доступ с хоста ioBroker к `mini-ems.com:8081`

## Конфигурация
Откройте конфигурацию экземпляра адаптера в административной панели ioBroker.

| Настройки | Описание |
| --- | --- |
| Адаптер активен | Включает или отключает опрос. |
| Имя пользователя Absaar | Имя пользователя, используемое в приложении Absaar EMS. В зависимости от учетной записи это может быть адрес электронной почты или имя пользователя. |
| Пароль Absaar | Пароль, используемый в приложении Absaar EMS. Хранится в зашифрованном и защищенном виде в конфигурации ioBroker. |
| Интервал опроса в секундах | Интервал опроса в секундах, от `30` до `86400`. Значение по умолчанию — `120`. Рекомендуется использовать это значение в умеренных количествах, чтобы избежать ограничений скорости облачных сервисов. |
| Базовый URL API | По умолчанию: `https://mini-ems.com:8081`. Обычно его не следует изменять. |
| Сохраняет необработанные данные в формате JSON | Записывает полный полученный JSON в состояния для устранения неполадок. По умолчанию отключено. |

## Штаты
Адаптер создает состояния, находящиеся ниже этой структуры:

```text
absaar.0.info.*
absaar.0.stations.<stationId>.*
absaar.0.stations.<stationId>.inverters.<inverterId>.*
```

### Информационные состояния
| Штат | Тип | Описание |
| --- | --- | --- |
| `info.connection` | логическое значение | `true` если последний опрос прошел успешно. |
| `info.lastError` | строка | Последнее сообщение об ошибке. Пусто после успешного опроса. |
| `info.lastError` | строка | Последнее сообщение об ошибке. Пусто после успешного опроса. |

## Поиск неисправностей
1. Проверьте `absaar.0.info.connection`.
2. Проверьте `absaar.0.info.lastError`.
3. Убедитесь, что те же учетные данные работают в приложении Absaar EMS.
4. Во время тестирования поддерживайте интервал опроса на уровне 120 секунд или выше.
5. Включайте необработанный JSON только временно, поскольку он может создавать большие состояния в зависимости от ответа API.
