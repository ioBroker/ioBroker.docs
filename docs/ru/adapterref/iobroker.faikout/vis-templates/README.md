# шаблоны vis для ioBroker.faikout

Готовые виды для **вида 1** (`iobroker.vis` 1.x) для двух кондиционеров. Они используют только точки данных из `faikout.0` и собственные виджеты VIS адаптера (установите _faikout_ ), поэтому они работают на любой установке этого адаптера: без скриптов, без других адаптеров, без адаптера графиков. Темный дизайн, 1280 × 800 пикселей для планшетов и настольных компьютеров, а также ширина экрана 412 пикселей для телефонов. Надписи на немецком языке (ниже приведено краткое описание на немецком языке).

## Требования

- `iobroker.faikout` В версиях **0.0.18 и новее** виджеты более ранних версий не отображались в среде выполнения vis (они ничего не показывали и выводили в лог). `missing ) after argument list`).
- После установки или обновления адаптера vis необходимо перестроить список виджетов: перезапустите `vis` один раз.

## Импорт

1. Замените заполнители во **всех** файлах перед импортом (в любом текстовом редакторе нажмите «Заменить все»):

   - `faikout.0.DEVICE_1` → ваш первый блок, например `faikout.0.Living_room`
   - `faikout.0.DEVICE_2` → ваш второй блок
   - необязательно: отображаемые имена `Gerät 1` /`Gerät 2`

   Объект устройства находится в папке, расположенной непосредственно внутри `faikout.0` (имя хоста модуля с `_` (вместо пробелов). Другой пример? Используйте, например, `faikout.1.` вместо.
2. Откройте редактор визуализаций (`http://<iobroker>:8082/vis/edit.html` Для каждого представления: вкладка **«Представления»** → **«Импорт представления»** , вставьте содержимое `view_<Name>.json` и введите имя **точно** так же, как в имени файла (`Faikout_Uebersicht`, `Faikout_Geraet1`, `Faikout_Geraet2`, `Faikout_Energie`, `Faikout_Handy` Навигационные кнопки ведут к этим названиям (`#Faikout_Geraet1` …).
3. Сохранить. Открыть. `…/vis/index.html#Faikout_Uebersicht` (таблетка) или `…#Faikout_Handy` (телефон).

Только один экземпляр? Импорт `Faikout_Geraet1` и `Faikout_Energie` Удалите вторую карточку в обзоре и второй блок в режиме просмотра для телефона.

## Что пишет, что только демонстрирует?

- Карточки отображения — это HTML-виджеты с привязкой vis — они никогда не записываются.
- Запись данных осуществляется только с помощью элементов управления адаптера (значки дуги − / +, выключатель, режим работы, скорость вентилятора, дополнительные функции). Запись производится в... `faikout.0.<unit>.control.*` То есть, данные сохраняются только в тех точках, которые адаптер создает как доступные для записи, и только в тех, которые устройство фактически передает. Устройство подтверждает данные примерно в течение секунды.
- В этих представлениях отсутствуют какие-либо другие элементы управления.

## Единицы измерения и пропущенные значения

- Компрессор (`status.comp`) и вентилятор (`status.fanfreq` Значения ) отображаются в **Гц** – значение по умолчанию для данного модуля. Если ваш модуль отображает обороты в минуту (в настройках), это означает, что он показывает обороты в минуту. `ha.comprpm` /`ha.fanrpm`), заменить каждый `Hz` в файлах по `rpm` – текст появляется только после этих двух значений (виджеты адаптера автоматически берут единицу измерения из объекта).
- Значение, которое устройство не отображает (например, влажность на многих моделях), показывает `–`.
- Значения энергопотребления берутся из раздела потребления адаптера (`consumption.<total|heating|cooling>.*` Они появляются после того, как модуль хотя бы один раз отправил данные со счетчиков энергии.

## Примечания для редактирования

- vis 1 treats every `{…}` в одной строке в качестве связующего элемента. Поэтому формулы в этих шаблонах не содержат `;`, `{` или `}`. Сохраняйте такое же состояние, если будете их редактировать.
- Представленные изображения были сгенерированы с помощью `werkzeuge/vis_vorlagen.py` в этом репозитории.

## немецкий

Fertige Ansichten für **vis 1** für zwei Klimaanlagen, nur mit Datenpunkten aus `faikout.0` и виджеты адаптеров – один скрипт, какой адаптер доступен. Dunkles Design, 1280 × 800 пикселей (планшет) и 412 пикселей (Handy).

- **Ansichten:** `Faikout_Uebersicht` (Начало, je Anlage eine Karte), `Faikout_Geraet1` /`Faikout_Geraet2` (Bedienung und alle Werte), `Faikout_Energie` (Сяулен 24 часа / 31 день / 12 месяцев, Таблица), `Faikout_Handy` (beide Anlagen untereinander).
- **Voraussetzung:** `iobroker.faikout` ab **0.0.18** (если вы не хотите видеть виджеты); После этого необходимо начать обновление адаптера с мгновенным запуском.
- **Импорт:** во все файлы `faikout.0.DEVICE_1` унд `faikout.0.DEVICE_2` durch die eigenen Geräteobjekte ersetzen (дополнительно die Namen) `Gerät 1` /`Gerät 2`), dann im vis-Editor unter _Ansichten → Ansicht importieren_ jede Datei mit genau dem Namen aus dem Dateinamen anlegen.
- **Schreiben** tun nur die Adaptor-Widgets (Bogen − / +, Ein/Aus, Betriebsart, Lüfter, Zusatzfunktionen) – ausschließlich auf die beschreibbaren Datenpunkte `control.*`. Die Karten zeigen nur an.
- **Einheiten:** Verdichter und Lüfter stehen в Гц (Werkseinstellung des Moduls). Meldet das Modul rpm, в режиме реального времени `Hz` дурч `rpm` ersetzen (kommt nur bei diesen beiden Werten vor). Феленде Верте Зейген `–`.
