# ioBroker.meteoalarm

## Добавьте это в свою визуализацию.

Самый простой способ добавить его в ваш виджет — использовать виджет basic-html и ввести там {meteoalarm.0.htmlToday}. Это даст вам предварительно разработанный HTML-виджет, который вы можете настроить в настройках адаптера.

# Настраивать

## Настройки

"Без фонового цвета в HTML-виджете": Возможность использовать HTML-виджет без фонового цвета (например, если вы хотите использовать объект цвета для заполнения всего виджета, а не только самого HTML-виджета).

"Используйте белые значки": Используйте белые значки вместо черных.

"Иконки": Задайте размер иконки в HTML-виджете.

"В виджете нет символов": Не используйте символ в HTML-виджете. Вы по-прежнему можете получить к нему доступ в объектах. Это полезно, если вы хотите отображать значок отдельно от виджета — например, в большем размере.

Вместо дня недели «сегодня», «завтра» или «вчера» в заголовке виджета будет отображаться «Сегодня» вместо дня недели.

"Задать цвета предупреждающих сигналов": Возможность задать цвета для различных уровней тревоги в шестнадцатеричном коде. Используется для HTML-виджета, а также для объекта цвета, позволяющего вручную назначить его другому виджету.

## Настройка типов оповещений

Здесь вы можете определить, какие уровни и типы тревожных сигналов будут отслеживаться. Это повлияет на объекты тревожных сигналов, на HTML-виджет и на JSON-объект.

## Уведомления

Можно настроить адаптер так, чтобы он отправлял вам уведомления по электронной почте, Telegram, Signal или Pushover.

- Сигнал
- Почта
- Слабак
- Телеграмма
- Синочат

Доступные настройки:

- Показать местоположение: Если этот параметр активирован, название местоположения добавляется в уведомление.
- Уровень предупреждения словами: Добавьте уровень предупреждения словами в дополнение к символам предупреждения.
- Нет подробностей: Не добавляйте описание предупреждения в уведомление — например, для Alexa.
- Отправлять «без предупреждений»: отправлять уведомление, если все оповещения отменены и в данный момент нет предупреждений.
- Символы уровня предупреждения: выберите, какие символы следует добавить в уведомление.

## Типы оповещений и сигналов тревоги

Здесь вы можете определить, какие уровни и типы оповещений будут использоваться для уведомлений. Важно: если уровень или тип не отслеживается в настройках «Типы оповещений», то вы не сможете отслеживать его в уведомлениях.

# Объекты

## Общие объекты

|   Название объекта   |                                                       Описание                                                      |
| :------------------: | :-----------------------------------------------------------------------------------------------------------------: |
|         JSON         | JSON-объект, содержащий все оповещения. Структура: Событие, Описание, Уровень, Дата начала, Значок, Тип оповещения. |
|         цвет         |                               Цветовая кодировка максимально возможного уровня тревоги                              |
|      htmlСегодня     |                                    Код HTML-виджета (можно изменить в настройках)                                   |
| последнее обновление |                                          Последнее обновление от Meteoalarm                                         |
|        уровень       |                                   Максимальный уровень доступных сигналов тревоги                                   |
|         связь        |                                                   Ссылка на ленту                                                   |
|     расположение     |                                               Название местоположения                                               |
|      noOfAlarms      |                                        Количество доступных сигналов тревоги                                        |
|      уведомление     |          Объект, изменяющийся при добавлении нового сигнала тревоги. Может использоваться для уведомлений.          |

## Объекты для каждого сигнала тревоги

Эти объекты создаются для каждого сигнала тревоги.

|      Объект Нане      |                                    Описание                                   |
| :-------------------: | :---------------------------------------------------------------------------: |
|          цвет         | Шестнадцатеричный код для сигнализации — можно настроить в параметрах уровня. |
|        описание       |                       Подробное описание сигнала тревоги                      |
|      эффективный      |                       Дата/время начала события тревоги                       |
|        событие        |                                  Тип события                                  |
|        истекает       |                      Дата/время окончания события тревоги                     |
|       заголовок       |                        Краткое описание сигнала тревоги                       |
|         икона         |                                Ссылка на иконку                               |
|        уровень        |                     Номер уровня (см. уровни тревоги ниже)                    |
|       levelText       |                                Уровень в словах                               |
|         связь         |                                 Ссылка на XML                                 |
|      отправитель      |             Кто послал тревогу (например, Deutscher Wetterdienst)             |
|        отправил       |                      Дата/время отправки сигнала тревоги                      |
|          тип          |       Тип сигнала тревоги в виде числа (см. типы сигналов тревоги выше).      |
|        типТекст       |          Тип сигнала тревоги словами (см. типы сигналов тревоги выше)         |
| обновитьИдентификатор |                                  Неактуально                                  |
