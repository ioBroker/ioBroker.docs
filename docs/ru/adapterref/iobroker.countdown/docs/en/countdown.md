# ioBroker.countdown

## Отображение обратного отсчета

Адаптер автоматически предоставляет вам JSON-таблицу и HTML-таблицу. Для JSON-таблицы выберите виджет "basic-table". Для HTML-таблицы выберите виджет "basic - string (unescaped)".

Можно отобразить либо короткий, либо длинный текст.![Логотип](../../../../../en/adapterref/iobroker.countdown/docs/en/admin/countdown_json.png)

## Сортировка обратных отсчетов по дате

По умолчанию таймеры обратного отсчета в HTML и JSON-выводе отображаются в порядке их создания. Если вы хотите отсортировать их хронологически по дате окончания, вы можете включить параметр «Сортировать таймеры обратного отсчета по дате» в настройках адаптера. Это упорядочит все таймеры обратного отсчета от самой ранней даты к самой поздней.

## Как добавить таймер обратного отсчета

Существует несколько способов настройки обратного отсчета:

- Создать таймер обратного отсчета можно в настройках адаптера, на вкладке "Создать таймер обратного отсчета".
- В настройках устройства можно создать состояние вручную. Имя объекта — это имя тревоги, а значение — дата. Дата должна быть в формате "ДД.ММ.ГГГГ ЧЧ:мм:сс".
- С помощью функции sendto можно создать оповещение. В нем можно отправить либо компоненты (минимум — год, месяц, дата), либо строковое представление даты. Формат строкового представления даты можно настроить в параметрах адаптера.![Логотип](../../../../../en/adapterref/iobroker.countdown/docs/en/admin/countdown_blocky.png)
- С помощью функции sendto вы можете добавлять дни, месяцы и годы к сегодняшней дате. Поэтому, пожалуйста, передайте компонент "name" и одно из следующих значений типа int: "addminutes", "addhours", "adddays", "addmonths" или "addyears".![Логотип](../../../../../en/adapterref/iobroker.countdown/docs/en/admin/countdown_blocky_add.png)

## Как настроить обратный отсчет

Обновить таймер обратного отсчета можно либо в настройках адаптера, либо с помощью параметра sendto. Поэтому просто используйте то же имя и отправьте его с новой датой. Это обновит таймер обратного отсчета.

## Как удалить таймеры обратного отсчета

С помощью функции sendto можно удалить таймер обратного отсчета. Поэтому отправьте адаптеру только имя с помощью sendto, и таймер будет удален автоматически.

## Повторяющийся обратный отсчет

Если вы хотите, чтобы обратный отсчет повторялся через определенный период (например, вы не можете каждый год запускать обратный отсчет до дня вашей свадьбы), вы также можете сделать это с помощью этого адаптера. Поэтому либо заполните поле «Период повторения» в настройках адаптера, либо добавьте точку после даты при создании обратного отсчета типа «дата». Отправка получателю будет выглядеть следующим образом для обратного отсчета, который должен закончиться 1 апреля 2020 года и повторяться каждый год:

sendTo("countdown.0", "send", { "name": 'Wedding Day', "date": '01.04.2020 00:01+1Y' });

Здесь представлены следующие параметры:

- Y: лет
- М: Месяцы
- Д: Дни
- Ч: Часы
- м: Минуты

## Отсчитайте вверх

Добавлена новая функция «обратного отсчета» — то есть подсчета дней от даты в прошлом. Это можно сделать либо в настройках адаптера, либо добавив символ «#» к строке с датой, например.

sendTo("countdown.0", "send", { "name": 'Birthdate', "date": '01.04.2020 00:01#' });

## Доступные выходные данные

|        Тип данных       |                                       Описание                                      |
| :---------------------: | :---------------------------------------------------------------------------------: |
|          минут          | До конца обратного отсчета осталось несколько минут (общее количество не указано!). |
|           часы          |             Количество часов до окончания обратного отсчета (не общее!)             |
|           дни           |       До конца обратного отсчета осталось дней (общее количество не указано!).      |
|         месяцев         |   До конца обратного отсчета осталось несколько месяцев (но не общее количество!).  |
|           годы          |          До конца обратного отсчета осталось лет (но не общее количество!).         |
|           имя           |                              Название обратного отсчета                             |
|      конечная дата      |    Дата окончания обратного отсчета — форматируется в соответствии с настройками.   |
|   в словах и краткости  |       Суммарное значение минут, часов и т.д. - например, 1 год 5 месяцев 4 дня      |
|       inWordsLong       |       Суммарное значение минут, часов и т.д. — например, 1 год 5 месяцев 4 дня      |
|        totalHours       |                       Общее количество часов до даты окончания                      |
|        totalDays        |                       Общее количество дней до даты окончания                       |
| общее количество недель |                      Общее количество недель до даты окончания                      |
|       totalMonths       |                      Общее количество месяцев до даты окончания                     |
|        totalYears       |                        Общее количество лет до даты окончания                       |

|reched|Логическое поле, определяющее, достигнута ли конечная дата или нет| |repeatEvery|Обратный отсчет повторяется через этот период после достижения конечной даты|

|totalsJson|JSON с общим количеством объектов за часы, дни, недели, месяцы и годы| |fullJson|JSON со всеми объектами|
