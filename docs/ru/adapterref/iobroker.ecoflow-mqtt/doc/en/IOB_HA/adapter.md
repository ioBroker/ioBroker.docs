Обновление адаптера

# Новая версия в репозитории ioBroker.

Внутри адаптерной карты представлена новая доступная версия.

# Новая версия доступна по адресу npm/github

Включите экспертный режим, если это еще не сделано.

![включить\_экспертный\_режим](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-25%20um%2021.34.26.png)

нажмите на значок Octacat

![октакат](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-25%20um%2021.34.55.png)

Выберите npm или github, найдите ecoflow и нажмите «Установить».

![github](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-25%20um%2021.36.14.png)

Адаптер обновлен (с версии 1.0.5 до 1.2.1).

![обновлять](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-25%20um%2021.36.53.png)

# Новая версия для тестирования размещена на GitHub (не в основной ветке).

Включите экспертный режим, если это еще не сделано.

![включить\_экспертный\_режим](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-25%20um%2021.34.26.png)

нажмите на значок Octacat

![октакат](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-25%20um%2021.34.55.png)

Выберите пользовательскую версию Ecoflow, вставьте правильный адрес в поле и нажмите «Установить», например, версию 1.4.0 <https://github.com/foxthefox/ioBroker.ecoflow-mqtt/tree/1.4.0>

![обычай](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-07-11%20um%2018.04.03.png)

отображается как установленное![кастомфин](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-07-11%20um%2018.09.35.png)
