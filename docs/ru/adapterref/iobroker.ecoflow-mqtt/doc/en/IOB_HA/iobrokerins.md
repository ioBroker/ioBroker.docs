Документация по установке ioBroker и подключению к Home Assistant.

# установка ioBroker

установить ioBroker

- Если у вас установлен Proxmox, используйте скрипт Proxmox <https://tteck.github.io/Proxmox/#iobroker-lxc>
- Ручная установка в Linux: curl -sLf <https://iobroker.net/install.sh> | bash -
- или найдите дополнительную информацию здесь [: https://www.iobroker.net/#en/download](https://www.iobroker.net/#en/download)

После установки необходимо перейти по адресу и порту: 8081.

После экрана приветствия пройдите аутентификацию и другие настройки.

Наконец вы увидите:

Перейдите на страницу настроек адаптера.

![заканчивать](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-24%20um%2021.48.02.png)

Нажмите «Готово»!

Возможно, вам потребуется разрешить IOB обнаружить ваш дом и запросить установку соответствующих адаптеров. Вы можете пропустить этот шаг, нажав кнопку «Закрыть».

# установка адаптера ecoflow-mqtt

Начать следует с раздела «Адаптеры» на боковой панели.

В поле поиска введите ecoflow

Появится карточка, нажмите на 3 точки.

![адаптер](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-24%20um%2021.51.08.png)

Нажмите кнопку «+», чтобы установить адаптер и добавить экземпляр.

![адаптер](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-24%20um%2021.52.08.png)

После установки процесс запускает непосредственно страницу администрирования адаптера.

![адаптер](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-24%20um%2021.55.45.png)

Вам нужно заполнить 3 вкладки.

- УЧЕТНЫЕ ДАННЫЕ И НАСТРОЙКИ ОТЛАДКИ -> доступ к MQTT-серверу EF (ваши учетные данные, полученные при использовании приложения EF)
- КОНФИГУРАЦИЯ УСТРОЙСТВА(УСТРОЙСТВ) -> тип и серийный номер вашего устройства
- HOMEASSISTANT -> доступ к MQTT-серверу Home Assistant

Нажмите «Сохранить и закрыть», чтобы запустить или перезапустить адаптер.

# Настройки Ecoflow

Вам необходимо получить учетные данные для доступа к серверу EF MQTT. У вас есть 3 варианта:

1. скрипт <https://github.com/mmiller7/ecoflow-withoutflow/blob/main/cloud-mqtt/ecoflow_get_mqtt_login.sh>
2. Источник: <https://energychain.github.io/site_ecoflow_mqtt_credentials/>
3. с помощью собственного алгоритма адаптера (нажатие кнопки), для этого необходимы имя пользователя и пароль приложения Ecoflow.

При использовании третьего метода учетные данные передаются непосредственно в раздел аутентификации MQTT.

В противном случае вам придётся скопировать и вставить значения в поля.

- mqtt userId (ваш адрес электронной почты, преобразованный в идентификатор, последняя часть mqtt clientId), например, 151.......
- Имя пользователя MQTT (MQTT User) начинается с app-.
- mqtt pwd (Пароль MQTT)
- mqtt clientId (идентификатор клиента MQTT (пример)) например, ANDROID\_666498788\_1....

Примечание: возможно, потребуется изменить адрес сервера по умолчанию (mqtts\://mqtt-e.ecoflow\.com) на другой. Проверить это можно на сайте <https://energychain.github.io/site_ecoflow_mqtt_credentials/> , проверив адрес сервера.

# Конфигурации устройств

Для каждого устройства предусмотрено несколько разделов.

Выберите свои устройства, например, электростанцию Delta 2 с серийным номером R331ZEB4ZEAL0528, и включите шлюз высокой доступности (HA). Затем добавьте новую строку со знаком "+", и она должна выглядеть примерно так:

![device\_config](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-25%20um%2023.03.33.png)

# настройки HA

Включите шлюз связи HA.

![ha\_enable](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-24%20um%2022.32.14.png)

Необходимо указать IP-адрес места установки HA, остальные настройки должны работать со значениями по умолчанию.

Для подключения по протоколу MQTT можно использовать исходного пользователя Home Assistant или другого пользователя. Пользователь, указанный в настройках аутентификации Home Assistant по протоколу MQTT, должен соответствовать конфигурации Home Assistant по протоколу MQTT.
