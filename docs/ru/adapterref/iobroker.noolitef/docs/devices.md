# Список настроек устройства

## Тип устройства

### выключатель

_Переключатель «Вкл/Выкл»_ — отдельные кнопки для управления включением и выключением.

Устройство имеет следующие состояния:

- onTurnOn - установить _значение true,_ если пользователь нажимает кнопку ВКЛ.
- onTurnOff - установить _значение true,_ если пользователь нажимает кнопку ВЫКЛ.
- onBrightUp - установить _значение true,_ если пользователь удерживает кнопку ВКЛ.
- onBrightDown - установить _значение true,_ если пользователь удерживает кнопку ВЫКЛ.
- onStopReq - _true,_ если пользователь перестал долго удерживать кнопки.
- onLowBattery - установить _значение true,_ если заряд батареи низкий

### Клавиатура включения/выключения

_Клавиатура включения/выключения_ — кнопка, содержащая команды как включения, так и выключения.

Устройство находится в следующих состояниях:

- onSwitch - изменяет значение _на true/false_ при нажатии пользователем этой кнопки
- onBrightBack - устанавливает значение _true,_ если пользователь удерживает эту кнопку.
- onStopReq - _true,_ если пользователь перестал долго удерживать кнопку.
- onLowBattery - установить _значение true,_ если заряд батареи низкий

### Кнопка «Сценарий»

_Кнопка «Сценарий»_ — кнопка сценария для предварительно настроенных устройств Noolite.

Устройство находится в следующих состояниях:

- onExecuteScenario - установить _значение true_ при коротком нажатии пользователем этой кнопки
- onSaveScenario - установить _значение true_ , когда пользователь удерживает эту кнопку
- onLowBattery - установить _значение true,_ если заряд батареи низкий

### Пульт дистанционного управления RGB

_Пульт дистанционного управления RGB_ — пульт дистанционного управления RGB с кнопкой включения/выключения, кнопкой выбора цвета и кнопкой переключения цвета.

Устройство находится в следующих состояниях:

- onSwitch - изменяет значение _true/false_ при нажатии пользователем кнопки включения/выключения.
- onSwitchMode - установить _значение true,_ когда пользователь нажимает кнопку _выбора режима_
- onSwitchColour - установить _значение true,_ когда пользователь нажимает кнопку _выбора цвета._
- onBrightBack - устанавливает _значение true_ при длительном нажатии пользователем кнопки ВКЛ/ВЫКЛ.
- onStopReq - _true_ , если пользователь перестал долго удерживать кнопку включения/выключения.
- onLowBattery - установить _значение true,_ если заряд батареи низкий

### Датчик двери

_Датчик двери_ — магнитный датчик двери.

Устройство находится в следующих состояниях:

- isOpen - _true,_ если дверь открыта, _false,_ если дверь закрыта
- onLowBattery - установить _значение true,_ если заряд батареи низкий

### Датчик воды

_Датчик воды_ — устройство, определяющее параметры воды.

Устройство имеет следующие состояния:

- Сигнал тревоги — _срабатывает_ при обнаружении утечки воды.
- onLowBattery - установить _значение true,_ если заряд батареи низкий

### Датчик движения

_Датчик движения_ — объект, представляющий собой датчик движения.

Устройство имеет следующие состояния:

- MotionDetect — установите значение _true,_ если датчик обнаружил движение, в противном случае — _false._
- onLowBattery - установить _значение true,_ если заряд батареи низкий

### Выключатель

_Переключатель_ — простой элемент реле.

- статус - если установлено значение _true,_ драйвер отправляет команду на реле _по_ команде, в противном случае - команда _выключения_

### Диммер

_Диммер_ — реле с функцией диммера.

Устройство находится в следующих состояниях:

- статус - если установлено значение _true,_ драйвер отправляет команду на реле _по_ команде, в противном случае - команда _выключения_
- яркость - отправить команду _setBrightness_ на реле со значением состояния. Значение измеряется в процентах.

### RGB-лента

_Лента RGB_ — объект контроллера RGB.

Устройство имеет следующие состояния:

- статус - если установлено значение _true,_ драйвер отправляет команду на реле _по_ команде, в противном случае - команда _выключения_
- currentColor - задает цвет для RGB-ленты. Цвет задается с помощью шаблонов _#RRGGBB._
