# Инструкция по установке

## Установите драйвер

- Откройте вкладку «Адаптеры».
- выбрать поддержку протокола устройства Noolite-F
- Нажмите (+)
- После установки адаптера iobroker автоматически откроет окно настройки.
- Создать список устройств. Подробности см. в [разделе «Список настроек устройств».](/#/docs/adapterref/iobroker.noolitef/docs/devices.md)
- Для каждого устройства вам следует:
- Нажмите на значок (+)
- Выберите тип устройства
- Выберите номер канала. Он должен быть уникальным для устройств дистанционного управления и реле.
- Выберите протокол _Noolite-F_ . Используйте _Noolite_ только для операций привязки/отвязки.
- Введите название устройства. Это любой символ без пробелов.
- Заполните описание. Укажите любую информацию об этом устройстве, например, «лампа в комнате».
- Для сопряжения с аппаратным устройством нажмите кнопку "Связать" и следуйте инструкциям для вашего устройства Noolite.
