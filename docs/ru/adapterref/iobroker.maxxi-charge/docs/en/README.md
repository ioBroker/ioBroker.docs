# ioBroker.Maxxi-Charge

**ioBroker.MaxxiCharge** — это адаптер для системы ioBroker, обеспечивающий интеграцию и управление устройствами MaxxiCharge CCU. Адаптер предоставляет ряд функций, включая чтение данных устройства, настройку конфигураций и отправку команд управления.

## Функции

- **Запрос данных** :
  - Считывает информацию, такую как IP-адрес, состояние или производительность блока управления центром обработки данных (CCU).
  - Автоматически создает динамические точки данных для информации об устройстве.
  - Поддерживает одновременное использование нескольких блоков CCU.
- **Конфигурация** :
  - Настраивает такие параметры, как максимальная выходная мощность, пороговые значения или режим зарядки.
  - **Летне-зимний режим** : динамически регулирует параметры зарядки в зависимости от времени года.
  - **Калибровка батареи** : Поддерживает автоматический процесс калибровки батареи.
  - **Управление подачей электроэнергии в сеть** : Настраивает максимальный заряд для включения или выключения подачи электроэнергии в сеть.
- **Команды управления** :
  - Динамические точки данных (`<deviceId>.sendcommand` Они используются для отправки команд в блок управления компьютером (CCU).
- **Фиксированный интервал запросов (облачный режим)** :
  - Интервал опроса данных CCU установлен на уровне 5 секунд.

## Требования

| Компонент                       | Описание                                          |
| ------------------------------- | ------------------------------------------------- |
| **Блок управления MaxxiCharge** | Поддерживаемые устройства с сетевым подключением. |
| **ioBroker**                    | Установлен экземпляр ioBroker.                    |
| **Node.js**                     | Node.js 22.x или более поздняя версия.            |

## Установка

1. **Настройте адаптер** :
   - Выберите режим API ( **Облачный** или **Локальный** ).
     - **Облако** :
       - Введите **название CCU** (например,`maxxi-XXXXXX-YYY` ).
     - **Локально:** Введите адрес ioBroker на веб-странице MaxxiCharge (`maxxi.local` ) под`Api-Route` :`http://"ioBroker IP":"PORT"` .

| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

| **Интервал запроса CCU**    | Устаревшая настройка. В облачном режиме интервал опроса CCU фиксирован на уровне 5 секунд и не подлежит настройке.                                                                                                                                           |
| **Летний/зимний режим**     | Автоматически регулирует параметры зарядки в зависимости от заданных зимних дат.                                                                                                                                                                             |
| **Порт для локального API** | Определяет порт, на котором локальный API будет прослушивать запросы.                                                                                                                                                                                        |

## Летний/Зимний режим

Летне-зимний режим динамически регулирует параметры зарядки:

- **Зимний режим** :
  - Минимальный платеж устанавливается на уровне 60% ежедневно в 8:00 утра.
  - Если уровень заряда (SOC) ≥ 55%, минимальный уровень заряда снижается до 40%.
- **Летний режим** :
  - Минимальная сумма к оплате составляет 10%.
  - Максимальный уровень заряда ограничен 95%.
- Активация осуществляется путем установки флажка в настройках адаптера, а временные рамки определяются датами начала и окончания зимнего сезона.

## Режим BKW

Режим BKW позволяет целенаправленно подавать избыточную энергию из системы хранения энергии в общественную электросеть. Когда уровень заряда батареи (SOC) достигает ≥ 97%, адаптер автоматически активирует режим BKW. В этом режиме в сеть непрерывно подается фиксированная мощность (например, 600 или 800 Вт) наряду с обычным бытовым потреблением. Это полезно, если система электроснабжения балкона (BKW) официально зарегистрирована и возможна компенсация за подачу энергии в сеть.

Если уровень заряда батареи падает ниже 97%, режим BKW автоматически отключается, а дополнительная подача электроэнергии в сеть сокращается или прекращается. Процесс выполняется полностью автоматически и не требует дальнейшего участия пользователя.

## Калибровка батареи

Функция калибровки батареи поддерживает автоматизированный процесс:

1. **Начинать** :
   - Адаптер уменьшает`minSOC` Установка значения 1% для разрядки батареи.
2. **Зарядка** :
   - После достижения содержания органического углерода <1%,`minSOC` Значение параметра увеличено до 99%.
3. **Завершение** :
   - После достижения 99% уровня заряда адаптер возобновляет нормальную работу.

Калибровку батареи можно активировать в экспертных настройках.

## Управление подачей

Функция управления подачей позволяет настраивать максимальный уровень заряда (`maxSOC` ) для определения того, подается ли избыточная энергия в сеть:

- **95% / 90% (активность при подаче)** :
  - Избыточная энергия подается в сеть, когда уровень заряда батареи превышает 90%.
- **100% (Подача электроэнергии отключена)**
  - В сеть не поступает избыточная энергия.

## Точки данных

Адаптер динамически создает точки данных на основе информации, возвращаемой CCU. Вот небольшой фрагмент структуры точек данных:

| Точка данных                | Описание                                                 |
| --------------------------- | -------------------------------------------------------- |
| `<deviceId>.SOC`            | Уровень заряда батареи.                                  |
| `<deviceId>.PV_power_total` | Общая мощность фотоэлектрических систем.                 |
| `<deviceId>.batteriesInfo`  | Информация о батарее.                                    |
| `<deviceId>.convertersInfo` | Статус конвертера.                                       |
| `<deviceId>.settings.*`     | Настройки, специфичные для устройства. (Только в облаке) |
| `<deviceId>.sendcommand.*`  | Команды управления для блока управления компьютером.     |

## Примечания

- Изменения в точках данных в`<deviceId>.sendcommand` Секции автоматически обнаруживаются и отправляются в CCU.
- Если возникнут проблемы с отсутствием данных или неожиданным поведением, перезапустите адаптер.

## Ошибки

- **Ошибка обработки данных** :
  - `deviceId` Недоступно → Перезагрузите адаптер после ввода информации о блоке управления.

- **Записи на сайте приложения (в режиме онлайн) будут сброшены** :
  - Используйте только`maxxi.local` Для ручного ввода данных используйте веб-сайт или IP-адрес CCU. При использовании команд управления sendCommand данные, введенные онлайн, будут перезаписаны.
