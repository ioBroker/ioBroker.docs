# Вики

Это небольшая вики-страница, посвященная адаптеру ioBroker Zigbee2MQTT.

zigbee2mqtt — это проект с открытым исходным кодом, который позволяет напрямую подключаться к устройствам Zigbee через MQTT без необходимости использования моста от производителя.
