### Настройка адаптера

| Вариант                                                                                      | Значение/Описание                                                                                                                                                                                                                                                                                                                                   |
| -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Выберите и настройте соединение Zigbee2MQTT.**                                             |                                                                                                                                                                                                                                                                                                                                                     |
| Выберите соединение Zigbee2MQTT                                                              | Рекомендуемая настройка: "Вебсокет"                                                                                                                                                                                                                                                                                                                 |
| Схема                                                                                        | Выберите между WebSocket (WS) через HTTP или HTTPS (WS SSL).                                                                                                                                                                                                                                                                                        |
| IP-адрес веб-сокета                                                                          | IP-адрес или DNS-имя сервера Zigbee2MQTT (в нашем случае IP-адрес хоста Docker).                                                                                                                                                                                                                                                                    |
| Порт WebSocket                                                                               | 8080 — это порт по умолчанию; если он был изменен в конфигурации Zigbee2MQTT, его необходимо изменить и здесь.                                                                                                                                                                                                                                      |
| Используйте токен авторизации                                                                | Включите сохранение токена авторизации/пароля на странице конфигурации. !!! ВНИМАНИЕ !!! Специальные символы не поддерживаются. Дополнительная информация на [Zigbee2MQTT](https://www.zigbee2mqtt.io/guide/configuration/frontend.html#advanced-configuration)                                                                                     |
| Создайте фиктивный MQTT-сервер для Zigbee2MQTT.                                              | Поскольку для работы Zigbee2MQTT нам нужен MQTT-сервер, мы можем установить этот флажок, и тогда у нас появится возможность создать его здесь, в адаптере.                                                                                                                                                                                          |
| Привязка IP-адреса MQTT-сервера/порта MQTT-сервера                                           | Эти настройки отображаются только в том случае, если установлен флажок для фиктивного MQTT-сервера. Если на ioBroker нет других MQTT-серверов, можно оставить настройки по умолчанию, в противном случае необходимо изменить как минимум порт. Эти настройки также должны быть сохранены в конфигурации Zigbee2MQTT.                                |
| Настройка подключения к веб-интерфейсу Zigbee2MQTT.                                          | Здесь можно настроить соединение, а также определить, как веб-интерфейс Zigbee2MQTT должен быть интегрирован в ioBroker. Важно отметить: если ioBroker вызывается по HTTPS, то здесь также необходимо установить соединение по HTTPS. В противном случае возникнет следующая ошибка: ( <https://github.com/arteck/ioBroker.zigbee2mqtt/issues/12> ) |
| **Настройка подключения к веб-интерфейсу Zigbee2MQTT**                                       |                                                                                                                                                                                                                                                                                                                                                     |
| Синхронизация цветовой температуры с цветом                                                  | Эта настройка гарантирует, что, например, в визуальном редакторе типа Lovelace цвет лампы изменится на заданный цвет.                                                                                                                                                                                                                               |
| Используйте значения Кельвина вместо Миреда.                                                 | Настройка цветовой температуры, например, для ламп.                                                                                                                                                                                                                                                                                                 |
| **Конфигурации состояний**                                                                   |                                                                                                                                                                                                                                                                                                                                                     |
| Создает простые состояния удержания и отпускания.                                            | При активации точки данных «Удержание» и «Освобождение» объединяются, и точка данных «Удержание» остается истинной до тех пор, пока не произойдет событие «Освобождение».                                                                                                                                                                           |
| Генерирует простые состояния «Движение» и «Остановка».                                       | При активации точки данных «Перемещение» и «Остановка» объединяются, и точка данных «Перемещение» остается истинной до наступления события «Остановка».                                                                                                                                                                                             |
| Создайте простые состояния «Нажатие» и «Отпускание».                                         | Если эта функция включена, состояния «Нажатие» и «Отпускание» объединяются, и точка данных «Нажатие» остается истинной до тех пор, пока не наступит событие «Отпускание».                                                                                                                                                                           |
| Регулировка яркости также должна включать или выключать свет.                                | Если эта функция включена, то при достижении нулевой яркости с помощью функции регулировки яркости лампа выключится. А когда лампа выключится, она снова включится.                                                                                                                                                                                 |
| Регулировка яркости также должна включать или выключать свет.                                | При активации, когда яркость, измеренная с помощью параметра «Яркость», достигает нуля, лампа выключается. И когда лампа выключена, она снова включается.                                                                                                                                                                                           |
| **Конфигурации образа устройства**                                                           |                                                                                                                                                                                                                                                                                                                                                     |
| Загрузите изображения устройств из Zigbee2Mqtt и используйте их в качестве значков объектов. | При такой настройке предварительный образ zigbee2MQTT загружается, сжимается и затем сохраняется в соответствующем объекте. ВНИМАНИЕ: первый запуск после установки этой настройки занимает больше времени в зависимости от количества устройств.                                                                                                   |
| Размер значков объектов в пикселях.                                                          | Размеры изображений: по умолчанию — 28. Увеличивать их можно только на свой страх и риск.                                                                                                                                                                                                                                                           |
| **Другие конфигурации**                                                                      |                                                                                                                                                                                                                                                                                                                                                     |
| Автоматическая проверка на наличие отсутствующих маршрутизаторов в памяти координатора.      | Эта опция проверяет все устройства, которые теоретически могут быть маршрутизаторами сети Zigbee, и перечисляет все, которые таковыми не являются. Дополнительную информацию можно найти по адресу <https://www.zigbee2mqtt.io/guide/usage/mqtt_topics_and_messages.html#zigbee2mqtt-bridge-request-coordinator-check>                              |
| Передача логов Zigbee2MQTT через прокси в ioBroker.                                          | Преобразует логи из Zigbee2MQTT в лог ioBroker.                                                                                                                                                                                                                                                                                                     |
