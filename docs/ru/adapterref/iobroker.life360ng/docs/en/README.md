#### требования ioBroker

1. Node.js 20.0 или более поздняя версия.
2. js-controller 6.0.11 (или более новая версия)
3. Admin-Adapter 7.6.20 (или более новая версия)
4. Веб-адаптер (только при использовании журнала)
