# Вкладка: Уведомления

На вкладке **«Уведомления»** вы настраиваете сообщения Telegram и объявления Alexa, которые автоматически отправляются, когда сотрудник Life360 прибывает в известное место.

---

## Телеграмма

Включайте или отключайте уведомления Telegram с помощью переключателя **«Включить уведомления Telegram»** .

> **Требование:** [адаптер ioBroker для Telegram](https://github.com/iobroker-community-adapters/ioBroker.telegram) должен быть установлен и запущен.

---

## Таблица получателей

Определите всех получателей Telegram, которые могут получать уведомления.

| Столбец                | Описание                                                                 |
| ---------------------- | ------------------------------------------------------------------------ |
| **Пример**             | Номер экземпляра адаптера Telegram (по умолчанию:`0` )                   |
| **Отображаемое имя**   | Дополнительная метка для идентификации этого получателя в фильтре "Люди" |
| **Идентификатор чата** | Идентификатор чата Telegram получателя                                   |

**Как найти идентификатор чата:**\
&#x20;Откройте адаптер Telegram в административной панели ioBroker → вкладка **«Сообщения»** . После того, как пользователь отправит сообщение вашему Telegram-боту, его идентификатор чата появится в списке авторизованных пользователей.

> **Примечание:** Отображаемое имя необязательно и используется только в качестве удобной метки для фильтра в таблице пользователей. Вы можете оставить его пустым и использовать вместо этого идентификатор чата непосредственно в качестве значения фильтра.

---

## Алекса

Включайте или отключайте объявления Alexa с помощью переключателя **«Включить объявления Alexa»** .

> **Требование:** [адаптер ioBroker Alexa2](https://github.com/Apollon77/ioBroker.alexa2) должен быть установлен и запущен.

---

## Таблица устройств Alexa

Определите устройства Echo, которые должны сообщать об изменении местоположения.

| Столбец                                                  | Описание                                                                                                                                                                                          |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Отображаемое имя**                                     | Дополнительная этикетка для идентификации данного устройства (например)`Office Echo` )                                                                                                            |
| **Произнесите по-разному: удостоверение личности штата** | Полный идентификатор состояния ioBroker точки данных speak (например)`alexa2.0.Echo-Devices.G090LF11806218AC.Commands.speak` )                                                                    |
| **Громкость (0–100)**                                    | Временная громкость объявления. life360ng отправляет заданное значение непосредственно в команде speak (`volume;text` ) и восстанавливает ранее прочитанное`Player.volume` ценность впоследствии. |

**Как найти идентификатор штата, в котором разрешено говорить:**\
&#x20;Откройте дерево объектов ioBroker →`alexa2.0` →`Echo-Devices` → Найдите папку вашего устройства →`Commands` →`speak` Скопируйте полный идентификатор объекта.

> **Примечание:** При настройке тома life360ng использует встроенный модуль.`volume;text` формат речи. Кроме того, он зачитывает текущий`Player.volume` перед тем, как заговорить, и восстанавливает его после этого.

## Стол для людей

Эта таблица **автоматически синхронизируется** из Life360 — данные о пользователях появляются здесь сразу после загрузки из облака Life360. Ввод данных вручную не требуется.

| Столбец                                    | Описание                                                                                                                                                                                                          |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Life360 имя**                            | Имя человека из Life360 (только для чтения, автоматическая синхронизация)                                                                                                                                         |
| **Текст префикса (на своих местах)**       | Текст, добавляемый перед названием места для собственных уведомлений о местах (например,`Nicole is at` )                                                                                                          |
| **Текстовый префикс (места в приложении)** | Текст, добавляемый перед названием места в уведомлениях о местах в приложении Life360.                                                                                                                            |
| **Получатели (только в Telegram)**         | Список имен получателей или идентификаторов чатов из таблицы получателей, разделенных запятыми. Пусто — отправить всем получателям Telegram. Уведомления Alexa всегда отправляются на все настроенные устройства. |
| **Собственные места**                      | Включите уведомления, когда этот человек прибудет в ваше собственное место (Мои места).                                                                                                                           |
| **Места приложений**                       | Включите уведомления, когда этот человек прибудет в место, указанное в приложении Life360.                                                                                                                        |
| **Неизвестные места**                      | Включите уведомления, когда местоположение этого человека станет неизвестным.                                                                                                                                     |
| **Сообщение о неизвестном местоположении** | Текст сообщения, отправляемый пользователем, если его местоположение неизвестно.                                                                                                                                  |

### Фильтр получателей (только в Telegram)

Столбец **«Получатели»** относится только к уведомлениям Telegram — он не влияет на объявления Alexa. Он позволяет ограничить круг получателей Telegram, которым отправляется сообщение для конкретного человека. Объявления Alexa всегда отправляются на все настроенные устройства.

- **Пусто:** Уведомление отправляется **всем** получателям в таблице получателей.
- **Заполнено:** Сообщение получат только указанные получатели.

## Переопределение уведомлений для конкретных мест

Ниже таблицы пользователей можно настроить параметры уведомлений для конкретных мест и пользователей. Это позволяет добавить пользовательский текст к сообщению по умолчанию.`prefix text + place name` ) или, если включена приоритезация, замените стандартное сообщение пользовательским текстом. Вы также можете отправлять сообщение, когда человек **покидает** место.

| Столбец                              | Описание                                                                                                                                                                         |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **+ Место**                          | Название места — выбирается из выпадающего списка, в котором представлены собственные места (⚑) и места из приложения Life360 (📍). Также возможен ручной ввод.                  |
| **Человек**                          | Имя человека из Life360 — выбрано из выпадающего списка известных лиц.                                                                                                           |
| **Приоритет отдается уведомлениям.** | При включении этой функции отображается сообщение по умолчанию (`prefix text + place name` ) подавляется. Вместо этого используется пользовательский текст прибытия или отъезда. |
| **Сообщите по прибытии**             | Отправить уведомление, когда человек прибудет в это место.                                                                                                                       |
| **Текст по прибытии**                | Текст сообщения, отправляемый по прибытии (например)`Nicole arrived home` ).                                                                                                     |
| **Уведомить об отпуске**             | Отправить уведомление, когда человек покинет это место.                                                                                                                          |
| **Текст в отпуске**                  | Текст сообщения, отправленного в отпуск (например)`Nicole left home` ).                                                                                                          |

### Как это работает

- **Точное совпадение с именем человека** имеет приоритет над вводом с использованием подстановочного знака (пустое поле для имени человека).
- Если включена **опция «Приоритет уведомления»** и задан пользовательский текст, стандартное сообщение из таблицы пользователей подавляется, и отправляется только текст, позволяющий переопределить действие.
- Если **параметр «Приоритет уведомления»** отключен, стандартное сообщение и текст для переопределения отправляются последовательно.
- Если включена **опция «Приоритет уведомления»** , но текстовое поле пустое, в качестве резервного варианта по-прежнему используется стандартное сообщение.
- При выезде из приоритетного места стандартное сообщение для нового места или состояния «неизвестно/в пути» также подавляется; без приоритезации оба сообщения отправляются последовательно.
- Telegram и Alexa используют одну и ту же логику. Если одно событие генерирует несколько текстовых сообщений от Alexa, они произносятся последовательно с небольшим перерывом.

### Пример

| Место | Человек           | Расставьте приоритеты | Уведомить о прибытии | Текст по прибытии     | Уведомить об уходе | Текст в отпуске     |
| ----- | ----------------- | :-------------------: | :------------------: | --------------------- | :----------------: | ------------------- |
| Дом   | Николь Мустерманн |           ✅           |           ✅          | Николь приехала домой |          ✅         | Николь ушла из дома |
| Дом   | _(пустой)_        |           ✅           |           ✅          | Кто-то приехал домой  |          ☐         |                     |

В этом примере: когда Николь прибывает домой, включение приоритезации отправляет только`Nicole arrived home` Без приоритезации адаптер сначала отправляет стандартное сообщение, а затем`Nicole arrived home` .

В качестве значения фильтра можно использовать либо **отображаемое имя** , либо **идентификатор чата** — принимаются оба варианта, и вы можете свободно их комбинировать.

**Примеры:**

- `Nicole` — отправлять только получателю с отображаемым именем "Николь"
- `123456789` — отправлять только получателю с идентификатором чата 123456789
- `Nicole, 987654321` — отправить Николь и получателю с идентификатором чата 987654321

### Уведомление

Уведомление формируется следующим образом:

```
[Prefix text] [Place name]
```

Если префиксный текст пуст, отправляется только название места.

**Пример:** Префикс =`Nicole is at` Место =`Home` → Сообщение:`Nicole is at Home`

> **Примечание:** Уведомления отправляются только тогда, когда человек прибывает в **известное место** (свое собственное место или место, указанное в приложении Life360). Если название местоположения неизвестно или поле пустое, сообщение не отправляется.

## Тестовые уведомления

Используйте кнопку **«Отправить тестовое сообщение»** (раздел Telegram) или кнопку **«Отправить тестовое объявление»** (раздел Alexa), чтобы проверить свою конфигурацию, не дожидаясь реального изменения местоположения.

> **Важно:** В ходе теста используется конфигурация, загруженная в работающий адаптер. Если вы внесли изменения, сначала **сохраните и перезапустите** адаптер, а затем воспользуйтесь кнопкой теста.

| Кнопка                            | Что это делает                                                                                                                                                                                   |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Отправить тестовое сообщение**  | Отправляет`[Life360ng] Test notification` всем настроенным получателям Telegram                                                                                                                  |
| **Отправить тестовое объявление** | Объявляет`Life360ng test notification one` а потом`Life360ng test notification two` На всех настроенных устройствах Alexa проверьте последовательное воспроизведение и восстановление громкости. |

## Государство уведомления

life360ng всегда записывает текст уведомления в специальное состояние ioBroker, независимо от того, включены ли Telegram или Alexa. Это позволяет реагировать на уведомления в скриптах Blockly или других автоматизациях — например, запускать объявление Sonos, когда человек приходит в определенное место.

| Состояние                                           | Тип      | Описание                                              |
| --------------------------------------------------- | -------- | ----------------------------------------------------- |
| `life360ng.<instance>.notifications.lastSpokenText` | `string` | Последний созданный и отправленный текст уведомления. |

Состояние создается при запуске адаптера и обновляется при каждом событии уведомления. Оно отражает точный текст, который был (или мог быть) произнесен или отправлен через Telegram/Alexa.

**Пример использования Blockly:**\
&#x20;Подпишитесь на`notifications.lastSpokenText` Когда состояние изменяется и значение не пустое, используйте адаптер Sonos для воспроизведения текста с помощью функции преобразования текста в речь.
