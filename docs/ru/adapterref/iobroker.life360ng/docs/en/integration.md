# Вкладка: Интеграция

На вкладке **«Интеграция»** вы можете управлять тем, какие данные Life360 будут обрабатываться адаптером и создаваться в виде объектов ioBroker.

**Функции:**

- **Круги, места, люди:** Вы можете выбрать, будут ли импортированы и синхронизированы круги, места и люди из Life360.
- **Отслеживание местоположения:** Включите опцию, позволяющую непрерывно обновлять текущее местоположение людей.
- **Неизвестное место:** Задайте название для мест, которые не распознаются Life360 (например, «Неизвестное»).

**Примечание:** Эти настройки помогут вам свести к минимуму количество объектов адаптера и трафик данных, а также обеспечить четкий обзор ситуации.
