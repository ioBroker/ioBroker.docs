# Вкладка: Дополнительные параметры

Вкладка **«Дополнительно»** содержит специальные настройки для диагностики и отладки.

**Функции:**

- **Подробное логирование:** Включите эту опцию, чтобы получать особенно подробные журналы событий. Это полезно, если вы хотите проанализировать проблемы или сообщить об ошибках разработчику.

**Примечание:** Расширенные журналы следует включать только при необходимости, поскольку они могут добавлять много дополнительной информации в журнал ioBroker.
