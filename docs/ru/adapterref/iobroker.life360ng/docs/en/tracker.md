# Вкладка: Судовой журнал

## Особенности бортового журнала и карты.

Адаптер ioBroker life360ng предоставляет исчерпывающие функции ведения журнала и отображения карты для каждого отслеживаемого человека:

- **Индивидуальные карты для каждого человека:** для каждого человека с включенным отслеживанием доступна отдельная карта, отображающая пройденные маршруты (на основе GeoJSON) и текущее местоположение.
- **Карта семьи:** Кроме того, на карте семьи отображаются маршруты всех пользователей, имеющих доступ к системе, в совокупности.
- **Встроенный календарь:** HTML-код карты включает календарь для выбора конкретного дня и отображения маршрута на этот день.
- **Гибкая интеграция:** карты можно открывать непосредственно в браузере или встраивать в визуализации в виде iframe (например, ioBroker VIS).
- **Внешний вид карты:** цвета, стиль маршрута, флажки мест и расположение настраиваются на вкладке [«Отображение карты»](/#/docs/adapterref/iobroker.life360ng/docs/en/mapdisplay.md) .

Все подробности о настройке и использовании можно найти ниже, а также в конфигурации адаптера.

## Использование карты личности и карты семьи

Адаптер ioBroker life360ng предоставляет два типа карт для визуализации данных о перемещении:

### 1. Карта людей

Каждый пользователь с включенной функцией отслеживания получает свою собственную карту. На этой карте отображаются пройденные маршруты в виде цветных линий (на основе GeoJSON) и текущее местоположение.

- **Активация:** Включите нужного человека в адаптере в разделе "Трекер" (`enabled` ).
- **Собственная карта:**`ownMap` Эта опция определяет, будет ли создана отдельная карта для этого человека.
- **Доступ:** URL-адрес карты можно найти в дереве объектов по адресу`life360ng.<instance>.tracker.<person>.url` .

### 2. Карта семьи

На семейной карте маршруты всех лиц, имеющих право на участие в программе, отображаются вместе на одной карте.

- **Активация:** По крайней мере, один человек должен иметь`familyMap` Эта опция включена в трекере.
- **Доступ:** URL-адрес карты с кругами доступен по адресу`life360ng.<instance>.tracker.circle.url` .

> Все настройки внешнего вида карты (цвета, стиль маршрута, флажки мест, расположение) находятся на вкладке **[«Отображение карты»](/#/docs/adapterref/iobroker.life360ng/docs/en/mapdisplay.md)** .

### 3. Выбор даты

HTML-код карты включает в себя элемент выбора даты. С его помощью можно выбрать конкретный день и отобразить маршрут на этот день. По умолчанию отображается текущий маршрут. Элемент выбора даты особенно полезен для просмотра перемещений в определенные дни.

**Примечание:** внешний вид может отличаться в зависимости от используемого браузера.

#### Диапазон обзора по умолчанию

В разделе **«Общие» → «Вид по умолчанию (дни)»** можно настроить, сколько дней будет отображаться по умолчанию при открытии карты.

| Ценить           | Эффект                                   |
| ---------------- | ---------------------------------------- |
| 1 (по умолчанию) | Отображается только сегодняшний маршрут. |
| 2                | Сегодня и вчера                          |
| Н                | Сегодня и N−1 предыдущих дней            |

При каждом открытии карты начальная дата устанавливается равной сегодняшнему дню минус (N−1) дней на основе заданного значения. Ручная настройка средства выбора даты изменяет отображение только для текущей сессии.

### 4. Меню гамбургеров (☰)

Нажмите на значок ☰ в правом верхнем углу, чтобы открыть панель настроек. Настройки сохраняются для каждой карты в хранилище сессии браузера и остаются активными до закрытия вкладки.

| Вариант                                    | Описание                                                                                                                                                                                             |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Маршрут**                                | Отображает пройденный маршрут в виде цветной линии на карте. При включении функции построения маршрута также отображается поле для выбора диапазона дат.                                             |
| **Места**                                  | На карте места, отмеченные знаком Life360, отображаются в виде флажков.                                                                                                                              |
| **Радиус мест**                            | Отображает заданный радиусный круг вокруг каждого объекта Life360.                                                                                                                                   |
| **Мои места**                              | Отображает пользовательские места (Мои места) в виде флажков на карте.                                                                                                                               |
| **Радиус моих мест**                       | Отображает радиус окружности вокруг каждого заданного места.                                                                                                                                         |
| **Главное событие дня**                    | Включает функцию интерактивного отображения событий дня (см. ниже).                                                                                                                                  |
| **Нижний колонтитул**                      | Отображает или скрывает легенду под картой.                                                                                                                                                          |
| **Размер карты**                           | Отображает текущие размеры карты в заголовке.                                                                                                                                                        |
| **Автоматическое обновление**              | Автоматически перезагружает страницу с заданным интервалом опроса. Включено по умолчанию. Отключение приводит к замораживанию текущего отображения.                                                  |
| **Следите за обновлениями в прямом эфире** | При каждой загрузке страницы карта автоматически переключается на последние GPS-данные выбранного человека. Включение функции Live Follow автоматически включает функцию автоматического обновления. |
| **↻ Перезагрузка**                         | Полностью перезагружает карту.                                                                                                                                                                       |

#### Следите за обновлениями в прямом эфире

При включении функции **Live Follow** карта автоматически переключается на самые последние GPS-координаты отслеживаемого человека после каждого обновления страницы. Это позволяет следить за человеком в режиме реального времени, не касаясь карты.

- Включение функции Live Follow **автоматически активирует функцию автообновления,** благодаря чему страница периодически перезагружается, чтобы отслеживать новые позиции.
- Отключение функции Live Follow **не** отключает автоматическое обновление — после этого они управляются независимо друг от друга.
- На **круговой карте** человек, за которым следует карта, определяется текущим активным пользователем (последним, на кого был сделан щелчок в легенде). Если активный пользователь не указан, карта следует за человеком, маршрут которого отображается.
- Отслеживаемая позиция — это последняя зарегистрированная точка GPS в выбранном диапазоне времени.

#### Основные моменты дня

При включении функции **подсветки по дням** маршруты на карте могут подсвечиваться в интерактивном режиме:

- **Наведение курсора мыши на линию:** маршрут за этот день временно подсвечивается — линия становится толще, а за все остальные дни исчезает. Убрав курсор, вы вернетесь в нормальное состояние. Подсказка показывает дату маршрута.
- **Щелчок по линии:** выделение блокируется. Маршрут остается активным, и появляется всплывающее окно с датой (для карты людей) или именем и датой (для карты семей). Повторный щелчок по той же линии или щелчок по фону карты снимает блокировку.
- **Щелчок по маркеру:** открывает всплывающее окно для этого маркера (начальная или конечная точка дня), не активируя выделение дня.

> **Примечание:** После блокировки маршрута щелчком мыши всплывающая подсказка на линиях скрывается — заблокированный вид остается неизменным.

> Сгенерированные HTML, CSS и JS файлы хранятся в файловой системе ioBroker. Вы можете просматривать или управлять ими в разделе **Администрирование → Файлы →`life360ng.<instance>/tracker/`** .

## Управление данными

Данные маршрута (`allTime.geojson` Размер файла со временем увеличивается. Адаптер предлагает два способа контроля размера файлов:

### Автоматическая очистка (срок хранения)

В разделе **«Общие» → «Сохранение (дней)»** можно указать, сколько дней должны храниться данные маршрута. Данные за более старые дни автоматически удаляются при каждом запуске адаптера и один раз в день. Значение`0` означает неограниченное хранение.

### Ручная очистка для отдельных лиц

В **таблице "Persons** " есть столбец **"Clear rec." (** Очистить запись). Установите флажок для конкретного человека и сохраните конфигурацию. Это позволит сохранить данные этого человека.`allTime.geojson` сводится к последнему известному положению.

> ⚠️ Поскольку карта семьи строится на основе данных по отдельным лицам, удаление записей о каком-либо человеке автоматически обновляет и карту семьи. Ежемесячные файлы GeoJSON (`currentYear.MM` ) никогда не подвергаются воздействию.
