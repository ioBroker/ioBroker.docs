# Документация по адаптеру SHRDZM

![Логотип](../../../../../en/adapterref/iobroker.shrdzm/admin/shrdzm.png)

## Обзор

Адаптер SHRDZM интегрирует интерфейс интеллектуальных счетчиков SHRDZM, предоставляемый компанией _SHRDZM IT Services eU,_ в систему ioBroker. Этот адаптер позволяет отслеживать данные о потреблении и производстве энергии с ваших интеллектуальных счетчиков через интерфейс SHRDZM.

**Важное примечание:** Данный адаптер никоим образом не связан с SHRDZM IT Services eU, и никаких коммерческих отношений с ним не существует. Это независимый проект, реализуемый силами сообщества.

## Функции

- **Мониторинг энергопотребления в режиме реального времени** : получение данных о потреблении и производстве энергии в режиме реального времени.
- **Поддержка нескольких кодов OBIS** : поддерживает все стандартные коды OBIS для счетчиков энергии.
- **Поддержка нескольких устройств** : обработка данных с нескольких устройств SHRDZM одновременно.
- **Исторические данные** : Настраиваемая частота обновления исторических данных об энергопотреблении и мощности.
- **Пересылка UDP-данных** : пересылка полученных данных в другие системы.
- **Фильтрация по устройствам** : Дополнительная функция фильтрации, позволяющая принимать данные только с определенных устройств.
- **Хранение необработанных данных** : Возможность сохранения необработанных UDP-пакетов для анализа.

## Установка

**⚠️ Важное уведомление об установке**

**НЕ** устанавливайте этот адаптер с помощью npm (`npm install iobroker.shrdzm` Адаптеры ioBroker **ни в коем случае** нельзя устанавливать напрямую с помощью npm.

**Правильный способ установки:**

1. Откройте административный интерфейс ioBroker.
2. Перейдите на вкладку «Адаптеры».
3. Найдите "SHRDZM" или просмотрите доступные адаптеры.
4. Нажмите кнопку «+», чтобы установить адаптер.
5. Настройте экземпляр адаптера, как описано ниже.

## Настройка устройства SHRDZM

### Требования к оборудованию

- Устройство интерфейса интеллектуального счетчика SHRDZM
- Интеллектуальный счетчик, совместимый с интерфейсом SHRDZM.
- Сетевое подключение для устройства SHRDZM
- ioBroker размещается в той же сети.

### Конфигурация устройства SHRDZM

1. **Установите и подключите устройство SHRDZM** в соответствии с инструкциями производителя.

2. **Получите доступ к интерфейсу конфигурации SHRDZM** с помощью веб-браузера:
   - Подключитесь к веб-интерфейсу вашего устройства SHRDZM.
   - Перейдите на страницу настроек.

3. **Настройка параметров облака** :![Конфигурация облака SHRDZM](../../../../../en/adapterref/iobroker.shrdzm/doc/shrdzm-cloud.png)
   - В интерфейсе SHRDZM выберите «Конфигурация облака».
   - В поле "Сервер" введите:
     - **IP-адрес** : IPv4-адрес вашего хоста ioBroker.
     - **Порт** : Номер порта, указанный в сетевом адаптере (по умолчанию: 9000).
   - **Активируйте функцию "Отправка UDP"**
   - **Сохраните** настройки облака

4. **Настройка интервала обновления** :
   - Перейдите на страницу «Настройки» в интерфейсе SHRDZM.
   - Установите желаемый интервал передачи данных.
   - Сохраните настройки

Устройство SHRDZM немедленно начнет отправлять данные на ваш адаптер ioBroker с заданным интервалом.

## Конфигурация адаптера

### Базовая конфигурация

1. **Откройте административный интерфейс ioBroker.**
2. **Перейдите в раздел «Экземпляры».**
3. **Найдите свой экземпляр адаптера SHRDZM** и нажмите кнопку «Настройка».

#### Сетевые настройки

- **Привязать IP-адрес** :
  - По умолчанию:`0.0.0.0` (прослушивать все сетевые интерфейсы)
  - Укажите конкретный IP-адрес, если хотите ограничить использование определенных сетевых интерфейсов.
- **Порт** :
  - По умолчанию:`9000`
  - Выберите любой свободный номер порта (1-65535)
  - Порт должен совпадать с портом, настроенным в вашем устройстве SHRDZM.

#### Фильтрация устройств (опционально)

- **Устройства** :
  - Оставьте поле пустым, чтобы принимать данные от всех устройств SHRDZM.
  - Введите конкретные идентификаторы устройств (разделенные запятыми) для фильтрации устройств.
  - Формат идентификатора устройства: например,`84CCA8A411EB`

### Расширенные настройки

#### Обновить тарифы

- **Скорость обновления энергетической информации** :
  - Определяет частоту обработки данных об энергопотреблении для сохранения исторических данных.
  - Более высокие значения снижают нагрузку на систему, но ухудшают разрешение данных.
  - Пример: Установка значения 15 означает, что каждая 15-я точка данных будет использоваться для истории.

- **Частота обновления информации о энергопотреблении** :
  - Управляет частотой обработки данных об энергопотреблении для сохранения истории.
  - Аналогично скорости потребления энергии, но для мгновенных значений мощности.

#### Варианты обработки данных

- **Хранение необработанных данных** :
  - Разрешить сохранение необработанных UDP-пакетов, полученных от устройств.
  - Полезен для отладки и анализа данных.
  - **Предупреждение** : Увеличение нагрузки на систему из-за частых обновлений.

#### Переадресация UDP

- **Включить пересылку UDP** : пересылать полученные данные в другую систему.
- **Адрес переадресации UDP** : Целевой IP-адрес для переадресации.
- **Порт переадресации UDP** : Целевой порт для переадресации.

## Поиск неисправностей

### Данные не получены

1. **Проверка сетевых настроек** :
   - Убедитесь, что устройство SHRDZM и ioBroker находятся в одной сети.
   - Убедитесь, что IP-адрес и параметры порта совпадают между устройством и адаптером.
   - Проверьте настройки брандмауэра на хосте ioBroker.

2. **Проверьте конфигурацию SHRDZM** :
   - Убедитесь, что функция "Отправка UDP" активирована в настройках облака SHRDZM.
   - Убедитесь, что настроены правильный IP-адрес и порт ioBroker.
   - Убедитесь, что интервал передачи данных установлен правильно.

3. **Проверьте журналы адаптера** :
   - Установите уровень логирования адаптера на «debug» или «silly».
   - Найдите в журналах сообщения о приеме UDP-трафика.
   - Проверьте наличие сообщений об ошибках.

### Высокая системная нагрузка

1. **Настройте частоту обновления** :
   - Увеличьте значения частоты обновления энергии и мощности.
   - Это снижает частоту обработки исторических данных.

2. **Отключить хранение необработанных данных** :
   - Отключите опцию "Сохранять необработанные данные", если она не нужна.
   - Хранение необработанных данных приводит к частым обновлениям состояния.

3. **Фильтрация устройств** :
   - Используйте фильтрацию устройств, чтобы обрабатывать только определенные устройства.
   - Снижает вычислительную нагрузку при наличии нескольких устройств.

### Обновления данных происходят слишком часто.

- Отрегулируйте интервал передачи в настройках устройства SHRDZM.
- Увеличьте частоту обновления в конфигурации адаптера.
- Подумайте, необходимы ли обновления в режиме реального времени для вашего случая.

## Техническая информация

### Стандарт кода OBIS

Этот адаптер соответствует стандарту OBIS (Object Identification System) для идентификации данных счетчиков электроэнергии. Коды OBIS обеспечивают стандартизированный способ идентификации различных типов измерений электроэнергии.

### Формат данных

Адаптер принимает UDP-пакеты в формате JSON, содержащие:

- Идентификатор устройства
- Отметка времени
- Значения кода OBIS
- Время безотказной работы устройства

### Сетевой протокол

- **Протокол** : UDP (протокол пользовательских дейтаграмм)
- **Версия IP** : только IPv4
- **Формат данных** : JSON
- **Диапазон портов** : настраиваемый (1-65535)
