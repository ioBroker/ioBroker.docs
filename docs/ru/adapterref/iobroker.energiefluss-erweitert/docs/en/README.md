# ⚡ Обзор функций рабочего пространства «Поток энергии»

## 🌐 Генерал

- [x] Настройка осуществляется через веб-интерфейс, а не через ioBroker.
- [x] Свободно регулируемая ширина и высота рабочего пространства
- [x] Для каждого элемента можно задать значения по умолчанию, чтобы не приходилось изменять их индивидуально каждый раз.
- [x] Все точки отображения данных можно настроить индивидуально:
  - Источник может быть в Вт или кВт.
  - Возможен перевод из Вт в кВт.
  - Единица измерения выбирается для каждого элемента.
  - Для каждого источника данных может быть установлено собственное пороговое значение.
  - Количество десятичных знаков можно выбрать (0, 1, 2).
- [x] Пользователи могут добавлять неограниченное количество точек данных через обозреватель объектов для использования в адаптере.
- [x] Пользовательские CSS-стили можно интегрировать для всего рабочего пространства.
- [x] Уведомление-напоминание при уходе со страницы с несохраненными изменениями.
- [x] Текущее состояние сохраняется во время настройки элемента, что позволяет восстановить его до исходного состояния.
- [x] Все страницы адаптивны и работают на ПК, планшетах и смартфонах, включая поддержку настроек.
- [x] Адаптер использует более быстрые WebSocket-соединения ioBroker, реагирующие примерно в 10 раз быстрее и при этом в 10 раз более эффективно использующие ресурсы браузера.
- [x] Можно задать различные основные параметры, включая предустановленные цвета, размеры и формы.

---

## 📑 Виды / Вкладки

- [x] Возможно создание представлений/вкладок.
- [x] Вкладки могут содержать значки и текст.
- [x] Вкладки и окна можно гибко отображать или скрывать.

---

## 🧩 Элементы

- [x] На рабочей области можно разместить **неограниченное количество** элементов (текст, точки данных, прямоугольники, круги, значки и т. д.).
- [x] Размер, положение, цвет, тень и прозрачность настраиваются.
- [x] Позиционирование осуществляется с помощью мыши, клавиатуры или ввода координат.
- [x] Привязывайте элементы мышью, чтобы перемещать несколько элементов одновременно.
- [x] Выровняйте элементы относительно друг друга (по центру, справа, слева, по верхнему краю, по нижнему краю, по вертикальному центру).
- [x] Прямоугольникам или кругам можно присвоить точку данных, и цвет заливки будет зависеть от значения (в процентах или по абсолютной величине):
  - **Процентное заполнение:** элемент заполняется пропорционально значению данных.
  - **Максимальное значение:** Элемент заполняется пропорционально максимальному значению. Пример: максимальное значение 4000, значение точки данных 3000. $\rightarrow 3000 / 4000 \times 100 = 75%$
- [x] Ссылки на веб-адреса могут быть использованы для запуска действий при клике/касании.
  - Доступны следующие варианты отображения: наложение, новая страница (вкладка) или та же страница.
- [x] Элементы могут быть продублированы.
- [x] CSS-классы могут быть назначены различным состояниям точек данных: Активное положительное, Активное отрицательное, Неактивное положительное и Неактивное отрицательное.

## 📝 Тексты

- [x] Можно отобразить время последнего обновления точки данных (относительно текущего момента, немецкая метка времени, американская метка времени).
- [x] Доступны параметры выравнивания текста (справа, по центру, слева).
- [x] Данные, содержащие как положительные, так и отрицательные значения, могут отображаться как положительные, даже если они отрицательные.

## 🎨 Иконки

- [x] Иконки из [Iconify](https://iconify.design/) можно интегрировать непосредственно в рабочую область «Энергетический поток».
- [x] Размер, положение, цвет, тень и прозрачность настраиваются.
- [x] Присвоить точку данных

## ✨ Анимация

- [x] Настраиваемый (цвет частиц, цвет линии)
- [x] Положительное или отрицательное значение точки данных
- [x] Поддержка порогового значения
- [x] Скорость или количество частиц можно регулировать в зависимости от нагрузки.
- [x] Возможны двунаправленные линии (при переключении с положительного на отрицательное направление анимации меняется на противоположное).

---

## 🔗 Связи

- [x] Элементы (круги или прямоугольники) могут свободно соединяться друг с другом. Поддерживаются **режимы «Элемент»** и **«Точка соединения»** .
  - **Элемент:** Линия автоматически прикрепляется к ближайшей подходящей точке входа и динамически перемещается при изменении положения элемента.
  - **Точка соединения:** Линия привязана к одной из 12 доступных фиксированных точек ввода и сохраняет её положение даже при перемещении элемента.
- [x] Любую линию можно повторно подключить, даже если к ней уже были применены настройки.

## 🧮 Расчеты
