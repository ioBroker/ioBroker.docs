# Стандартные виджеты

В состав vis-2 входят два набора виджетов для устройств, используемых в доме:

| Набор           | Для чего это нужно                                                                                               |
| --------------- | ---------------------------------------------------------------------------------------------------------------- |
| **родственник** | Карточки для страницы с разделами — каждый виджет заполняет целые ячейки сетки и следует ширине экрана.          |
| **абсолютный**  | Маркеры для плана этажа — каждый элемент представляет собой монету или капсулу в том месте, куда его перетащили. |

Оба устройства — это одни и те же двадцать семь устройств. Каждое устройство описывается в источнике один раз (`src-vis/src/Vis/Widgets/Standard/devices/`) и получается дважды, поэтому термостат — это один и тот же термостат на планшете в прихожей и на плане первого этажа: одинаковые состояния, одинаковые характеристики, одинаковые слова, две формы.

На изображениях ниже показана работа приложения в темной теме. Язык системы ioBroker, с которого они были взяты, — немецкий, поэтому виджеты говорят на немецком языке; каждое произносимое ими слово переводится на одиннадцать языков и соответствует языку установленного приложения.

## Одно устройство, две формы

![Маркеры абсолютного множества](../../../../../../en/adapterref/iobroker.vis-2/packages/iobroker.vis-2/docs/img/standard/markers.png)

Карточка говорит всё, что от неё требуется; маркер размером с монету должен сделать выбор. Какой выбор он сделает, определяется каждым устройством отдельно:

- Устройство с читаемым числом — диммер, термостат, индикатор уровня заполнения — превращается в **капсулу** , содержащую это число внутри;
- Всё остальное превращается в **монету** со своим символом, окрашенную в соответствии с тем, что она делает;
- Устройство, которое невозможно уменьшить до таких размеров — список, таблица, диаграмма, камера, плеер — превращается в монету, которая **открывает свою карту** одним щелчком.

Уровень считывается как высота, а не как число, поэтому метки диммера, жалюзи и уровня заполнения соответствуют высоте самого устройства.

## Что есть у каждого виджета

Помимо собственных состояний, каждый виджет из обоих наборов обладает следующими свойствами:

| Атрибут       | Берет    | Что это делает                                                                                                 |
| ------------- | -------- | -------------------------------------------------------------------------------------------------------------- |
| `layout`      | выбирать | Макет -`default` Имя сверху, значение снизу, `compact` Один ряд, `card` Цветная плитка (по умолчанию) `default`) |
| `widgetTitle` | текст    | Имя                                                                                                            |
| `icon`        | икона    | Икона                                                                                                          |
| `noCard`      | флажок   | Без рамки                                                                                                      |

Значения `layout` Различия между наборами объясняются особенностями форм:

| Набор       | `layout`                                                                                       |
| ----------- | ---------------------------------------------------------------------------------------------- |
| родственник | `default` Имя сверху и значение снизу ·`compact` один ряд ·`card` цветная плитка               |
| абсолютный  | `icon` один только символ ·`name` символ и название ·`state` символ, название и его назначение |

Любое устройство, которое что-либо меняет, может сначала запросить подтверждение — и запросить PIN-код:

| Атрибут       | Берет    | Что это делает                                                                                                           |
| ------------- | -------- | ------------------------------------------------------------------------------------------------------------------------ |
| `confirm`     | выбирать | Прежде чем менять, спросите —`none` Никогда, `on` При включении, `off` При выключении, `both` Всегда (по умолчанию) `none`) |
| `confirmText` | текст    | Вопрос                                                                                                                   |
| `pin`         | текст    | ПРИКОЛОТЬ                                                                                                                |

Каждый атрибут каждого виджета может быть привязан к состоянию, а не задан каким-либо значением; см. _раздел «Привязка объектов»_ в файле [README](https://github.com/iobroker/iobroker.vis-2/blob/master/packages/README.md) .

## Размеры

Карточка размещается в размере, заданном её виджетом (плитка, указанная под каждым заголовком ниже), и изменяется в редакторе с помощью маркера в её углу, в целых ячейках. Раздел имеет двенадцать столбцов, каждый столбец раздела по умолчанию имеет размер 56 пикселей, и оба параметра могут быть изменены для каждого представления и для каждого раздела.

Карточка может выйти за пределы отведенных ей строк, если ее содержимому требуется больше места — строки сетки являются `minmax(height, auto)` Карточка, которая должна сохранять свою высоту точно, получает необходимое количество рядов.

## Создание страниц на основе устройств

Редактор может самостоятельно заполнить целую страницу: **«Виды» → «Устройства»** считывает объекты установки с помощью детектора типов и предлагает все найденные устройства, сгруппированные по комнатам. Он формирует виджеты, расположенные ниже — в конце каждого раздела указывается, какой виджет получает тот или иной тип устройства.

Любой включенный или выключенный прибор: розетка, лампа, насос. Карта может запросить PIN-код перед переключением.

| Атрибут    | Берет     | Что это делает        |
| ---------- | --------- | --------------------- |
| `oid`      | состояние | Идентификатор объекта |
| `oid2`     | состояние | Обратная связь        |
| `onValue`  | текст     | Цена на               |
| `readOnly` | флажок    | Только для чтения     |

Ассистент выбирает этот виджет для типов устройств. `socket`, `light`, `fan`, `pump`, `airPurifier`, `unknown`.

## переключатель тем

`tplRelTheme` (установить _относительное значение_ ) `tplAbsTheme` (установить _абсолютное значение_ ) · плитка по умолчанию: 4 столбца × 2 строки

![переключатель тем](../../../../../../en/adapterref/iobroker.vis-2/packages/iobroker.vis-2/docs/img/standard/theme.png)

Панель управления в коридоре читается и днем, и ночью, и проект не может знать, какая тема должна быть включена. Переключение меняет саму среду выполнения, поэтому каждая карточка, каждый маркер и меню меняются вместе с ней, и выбор запоминается в браузере. Если окно всегда должно быть темным, устанавливается одна тема, а та, которая должна выглядеть как остальная часть устройства, следует за браузером.

| Атрибут     | Берет    | Что это делает                                                                                                                           |
| ----------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `mode`      | выбирать | Что это делает —`toggle` Выключатель, `fixed` Эта тема повторяется всегда. `system` Следуйте инструкциям браузера (по умолчанию) `toggle`) |
| `themeName` | выбирать | Тема -`light` Свет, `dark` Темный, `modernLight` Светильник (новый дизайн), `modernDark` Темный (новый дизайн) (по умолчанию) `dark`)       |
