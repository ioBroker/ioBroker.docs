# fancyswitch для vis-2

В набор fancyswitch входят семь виджетов для включения и выключения состояния: три ползунка, два качельки, кнопка iButton от Giva Labs и небольшой тумблер. На этой странице описывается версия **vis-2** . В версии vis (vis-1) используются те же виджеты с теми же настройками; там они загружаются с изображений и не могут быть изменены в размере без размытия.

## Общий

### Требования и миграция

Виджеты находятся в наборе виджетов **fancyswitch** в списке виджетов редактора vis-2. Для описанных здесь версий React требуется **vis-2 2.12.8** или новее. Более старые версии vis-2 отображают виджеты vis-1.

Проекты, созданные с помощью vis-1, продолжают работать без изменений. Обе версии используют одни и те же идентификаторы виджетов. `tplFancySwitch1`, `tplFancyGivaIButton` …) и те же названия атрибутов, а vis-2 автоматически выбирает версию React. Все настройки сохраняются.

В таблицах ниже **«Setting»** — это метка в редакторе vis-2, а **«Attribute»** — это имя, хранящееся в проекте. Используйте имя атрибута при редактировании проекта в формате JSON или при копировании настроек между виджетами.

### Значения, введенные в редакторе

При нажатии на виджет в состояние записываются _значения True_ и _False_ , и текущее значение состояния сравнивается с ними. Редактор сохраняет их в виде текста, а виджет преобразует этот текст следующим образом:

| Введенный текст  | Письмо в адрес государства |
| ---------------- | -------------------------- |
| _(пустой)_       | `1` ответ. `0`             |
| `true`           | булево значение `true`     |
| `false`          | булево значение `false`     |
| `0`, `1`, `23.5` | это число                  |
| `ON`, `closed` … | этот текст                 |

Значение состояния учитывается, **когда**

- Это число больше нуля, или текст, который читается как такое число, или
- Его текст в точности соответствует _истинному значению_ , именно поэтому существуют такие состояния, как... `ON` /`OFF` работа или
- это логическое значение `true` А _значение True_ означает «включено» (`true`, `1` или любое положительное число).

`null` и `undefined` рассматриваются как _ложное значение_ .

### Настройки, общие для всех пяти типов переключателей.

`tplFancySwitch1`, `tplFancySwitch2`, `tplFancyDarkAnAus`, `tplFancyDarkAnAusRev` и `tplFancyDarkAnAusWippe` Все они предлагают одинаковые настройки.

| Параметр                       | Атрибут                   | Описание                                                                                                                                                                                                |
| ------------------------------ | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Идентификатор объекта          | `oid`                     | Отображаемое и записываемое состояние. Без него виджет будет выглядеть только «выключенным» и на него нельзя будет нажать.                                                                              |
| Ложное значение                | `valFalse`                | Значение, записываемое при выключении переключателя. Значение по умолчанию. `0`.                                                                                                                        |
| Истинное значение              | `valTrue`                 | Значение, записываемое при включении переключателя. Значение по умолчанию. `1`.                                                                                                                         |
| Инвертировать состояние        | `invert`                  | Показывает и записывает противоположное — полезно для ситуации, когда `0` означает «вкл».                                                                                                                |
| Автоматическое отключение (мс) | `autoOff`                 | Спустя указанное количество миллисекунд противоположное значение записывается снова. `0` Отключает эту функцию.                                                                                          |
| Только для чтения              | `readOnly`                | Виджет отображает состояние, но не реагирует на клики.                                                                                                                                                  |
| Метка (слева/справа)           | `text_false` /`text_true` | Текст каждой половины. `text_true` Это всегда та половина, которая означает «включено», поэтому для _включения/выключения темного ползунка_ это левая половина. Оставьте пустым, если текст отсутствует. |

Нажатие на половину карты переключает состояние, метку которого эта половина несет, поэтому нажатие... `ON` включает состояние и щелчок `OFF` Отключает эту функцию. Виджет сохраняет соотношение сторон своего изображения, поэтому виджет, увеличенный в ширину или высоту, остается четким и центрированным в своем блоке.

## Выключатель света - tplFancySwitch1

![Выключатель света](../../../../../en/adapterref/iobroker.vis-fancyswitch/docs/img/switch1.svg)

Яркий переключатель: одна клавиша закреплена на шарнире посередине. Половина, отображающая текущее состояние, нажата, другая половина обращена к зрителю и отбрасывает тень; при изменении состояния клавиша наклоняется. Обе надписи остаются видимыми; ничего не подсвечивается.

Настройки: см. [Общие настройки для всех пяти типов переключателей](#settings-shared-by-the-five-switch-styles) .

## Slider dark - tplFancySwitch2

![Ползунок темный](../../../../../en/adapterref/iobroker.vis-fancyswitch/docs/img/switch2.svg)

Темный ползунок на темной панели. Ручка и обе надписи расположены на одной полоске, которая скользит за рамку, как на настоящем ползунковом переключателе: надпись текущего состояния видна, другая скрыта под рамкой. При изменении состояния полоска сдвигается. `ON` Надпись светится голубым цветом. Надпись может содержать любой короткий текст, например: `0` и `I`.

Настройки: см. [Общие настройки для всех пяти типов переключателей](#settings-shared-by-the-five-switch-styles) .

## Переключатель-качелька - tplFancyDarkAnAusWippe

![тумблерный переключатель](../../../../../en/adapterref/iobroker.vis-fancyswitch/docs/img/rocker.svg)

Одна клавиша имеет шарнирное соединение посередине, как [выключатель света](#switch-light---tplfancyswitch1) : половина, соответствующая текущему состоянию, нажата, другая половина поднята. При изменении состояния клавиша наклоняется, оставаясь в среднем положении. Половина, соответствующая состоянию «включено», загорается голубым цветом при нажатии. Верхний ряд соответствует темному стилю, нижний — светлому.

Помимо [общих настроек](#settings-shared-by-the-five-switch-styles) :

| Параметр      | Атрибут      | Описание                               |
| ------------- | ------------ | -------------------------------------- |
| Светлый стиль | `lightStyle` | Рисует светлый вариант вместо тёмного. |

## Giva Labs iButton - tplFancyGivaIButton

![iButton](../../../../../en/adapterref/iobroker.vis-fancyswitch/docs/img/ibutton.svg)

Ползунковый переключатель с синей поверхностью «включено». Рукоятку можно нажимать или перетаскивать.

| Параметр                   | Атрибут               | Описание                                                                                                                                                           |
| -------------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Идентификатор объекта      | `oid`                 | Состояние. Виджет записывает логические значения. `true` и `false`.                                                                                                 |
| Только для чтения          | `readOnly`            | Виджет отображает состояние, но не реагирует.                                                                                                                      |
| Тест                       | `test`                | Отображает переключатель в положении «включено», пока редактор открыт, что позволяет проверить внешний вид без указания состояния.                                 |
| Надпись «ВКЛ»/«ВЫКЛ»       | `labelOn` /`labelOff` | Два текста. По умолчанию `ON` и `OFF`.                                                                                                                              |
| Изменить размер ручки      | `resizeHandle`        | `auto` Размеры ручки определяются по этикеткам, как только они начинают отличаться от указанных. `ON` /`OFF`, `true` всегда, `false` никогда (33 px).                |
| Изменить размер контейнера | `resizeContainer`     | `auto` как указано выше; `false` Это позволяет задать панели такую же ширину, как и у виджета, что является самым простым способом установить фиксированный размер. |
| Включить перетаскивание    | `enableDrag`          | Вместо простого щелчка по ползуну, ползунок можно перетаскивать.                                                                                                   |
| Анимация                   | `enableFx`            | Ручка скользит, а не подпрыгивает.                                                                                                                                 |
| Длительность действия (мс) | `duration`            | Длительность анимации. По умолчанию. `200`.                                                                                                                        |

Высота полосы составляет 27 пикселей — высота оригинала — и она центрирована по вертикали в виджете.

## Переключатель - tplFancyToggleswitch

![Переключатель](../../../../../en/adapterref/iobroker.vis-fancyswitch/docs/img/toggleswitch.svg)

Две метки с небольшим ползунком между ними. Нажатие на метку или переключатели дорожек.

| Параметр                                         | Атрибут                       | Описание                                                               |
| ------------------------------------------------ | ----------------------------- | ---------------------------------------------------------------------- |
| Идентификатор объекта                            | `oid`                         | Состояние. Виджет записывает логические значения. `true` и `false`.     |
| Только для чтения                                | `readOnly`                    | Виджет отображает состояние, но не реагирует.                          |
| Тест                                             | `test`                        | Отображает переключатель в положении «включено», пока редактор открыт. |
| Метка для обозначения ложного/истинного значения | `text_false` /`text_true`     | Два текста. По умолчанию `OFF` и `ON`.                                  |
| Переключатель подсветки                          | `highlight_switch`            | Заполняет направляющую до самой ручки, пока переключатель включен.     |
| Ширина                                           | `width`                       | Ширина полосы между метками в пикселях. Значение по умолчанию. `40`.   |
| HTML до/после                                    | `html_prepend` /`html_append` | Свободный HTML-код слева и справа от переключателя, как в vis-1.       |

В отличие от vis-1, этому виджету больше не требуется таблица стилей jQuery UI: он использует цвета темы vis-2 и поэтому работает также в темной теме.

## Отличия от vis-1

- Виджеты отображаются в формате SVG, а не вырезаются из файла PNG, поэтому их можно свободно изменять в размерах.
- Теперь обозначения пяти типов переключателей представляют собой настройки; в vis-1 они были частью изображения.
- Переключатели двигаются при изменении состояния: ползунки сдвигаются, их надписи перемещаются вместе с ручкой, а качающиеся переключатели опускаются в среднее положение. В vis-1 изображение подпрыгнуло.
- Логическое состояние считается «включенным», если _значение True_ оставлено по умолчанию. `1` В vis-1 a `true` был сравнен с текстом `1` и никогда не совпадали, поэтому такой виджет оставался выключенным.
- В _режиме Slider dark ON/OFF_ обе половины переключаются в состояние, указанное на их метке. В vis-1 левая половина всегда записывала _значение False_ , хотя она содержит `EIN` этикетка.
- Цветная часть переключателя расширяется по мере приближения к положению «включено». В варианте vis-1 она заполняла всю дорожку, когда переключатель был выключен, потому что ползунок jQuery UI был настроен с учетом этого параметра. `range: "max"`.
- Каждый виджет имеет режим _"Только для чтения"_ .
- Подсветка кнопки переключателя осуществляется более тёмным голубым цветом, который хорошо читается на светлой поверхности.
