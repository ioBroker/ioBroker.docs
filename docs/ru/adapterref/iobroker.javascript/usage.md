Адаптер JavaScript позволяет удобно создавать, редактировать и управлять скриптами.

## конфигурация

[Вот более подробная информация об этом.](https://github.com/ioBroker/ioBroker/wiki/ioBroker-Adapter-javascript#konfiguration)

![Меню настроек Адаптер JavaScript](../../../de/adapterref/iobroker.javascript/img/javascript_Einstellungen-Javascript.png) Фактическая настройка заключается в вводе дополнительных модулей npm для загрузки (разделенных запятыми), а также географических координат, используемых для различных вычислений. Чтобы получить координаты, вы можете, например, сильно увеличить масштаб на _Google Maps_ и щелкнуть по нужному месту. После этого координаты отобразятся. После сохранения адаптер необходимо активировать с помощью красной кнопки воспроизведения.

## операция

Во время установки в _административном_ интерфейсе появляется дополнительная вкладка _«Скрипты»_ . Здесь создаётся новая папка, для чего нужно нажать на значок (+) на панели инструментов (красный кружок). Новый скрипт создаётся с помощью значка «пустой лист» слева от него. Откроется окно с запросом имени и местоположения в структуре папок.![JavaScript-адаптер](../../../de/adapterref/iobroker.javascript/img/javascript_Javascript-Adapter.png)

### Список папок и файлов

Структуру папок можно настроить по своему усмотрению. Место хранения не влияет на функциональность скрипта. Помимо древовидной структуры, имеется список файлов. Поле поиска позволяет легко находить скрипты. Для запуска скрипта его необходимо активировать, нажав красную кнопку _«Воспроизвести»_ в левой части структуры папок. Для остановки нажмите зеленую кнопку _«Пауза»_ . Для каждого скрипта создается новый объект, который имеет имя скрипта с суффиксом «script». `_enabled` и находится в папке `javascript.Instanz.ScriptEnabled` Объект отображается с (`true/false` Статус указывает, выполняется ли скрипт. Этот статус также можно установить для включения/отключения скрипта. Скрипты, хранящиеся в _глобальной_ папке, являются глобальными скриптами. Они внутренне копируются перед каждым другим скриптом, то есть выполняются первыми. Это позволяет применять глобальные функции к нескольким скриптам. Переменные в глобальных скриптах можно использовать в других скриптах. Однако следует помнить, что каждый скрипт имеет собственное пространство переменных. Поэтому переменные в глобальных скриптах нельзя использовать для обмена значениями между скриптами. Для этого необходимо использовать объекты (состояния).

### редактор

После создания скрипта справа откроется редактор _JavaScript_ . Примеры скриптов можно найти [здесь](http://www.iobroker.net/docu/?page_id=2786\&lang=de) .

#### имя

Если имя было присвоено ранее, оно будет отображено здесь и может быть изменено.

#### Место хранения

В этом выпадающем меню отображаются все созданные папки. В настоящее время они отсортированы в хронологическом порядке их создания.

#### Тип двигателя

Здесь вы можете выбрать, будете ли вы работать с движком _JavaScript_ или _CoffeeScript_ .

#### бревно

Окно журнала, в котором отображаются все записи, относящиеся к выбранному скрипту, находится в правом нижнем углу. Записи журнала отображаются после сохранения и перезапуска скрипта.

## Советы

### Резервная копия

Для возможности восстановления скриптов в случае необходимости рекомендуется создать резервную копию методом _копирования и вставки_ .

### Тестовый экземпляр

Доказано, что создание отдельного экземпляра JavaScript для тестирования новых скриптов и запуск скрипта в этом экземпляре является эффективным решением. Необходимый экземпляр можно выбрать из выпадающего меню рядом с именем скрипта. В случае критической ошибки в скрипте завершится только этот дополнительный тестовый экземпляр, а не рабочий.
