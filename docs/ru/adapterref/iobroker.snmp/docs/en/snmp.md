# Информация об адаптере SNMP

## Общая информация

Протокол SNMP (Simple Network Management Protocol) — это стандартный интернет-протокол для сбора и организации информации об управляемых устройствах в IP-сетях, а также для изменения этой информации с целью корректировки поведения устройств. К устройствам, обычно поддерживающим SNMP, относятся кабельные модемы, маршрутизаторы, коммутаторы, серверы, рабочие станции, принтеры и многое другое.

SNMP широко используется в управлении сетями для мониторинга сети. SNMP предоставляет управляющие данные в виде переменных на управляемых системах, организованных в базу управляющей информации (MIB), которые описывают состояние и конфигурацию системы. Затем эти переменные могут быть удаленно запрошены (и, в некоторых случаях, изменены) управляющими приложениями.

Было разработано и внедрено три значимые версии SNMP. SNMPv1 — это оригинальная версия протокола. Более поздние версии, SNMPv2c и SNMPv3, отличаются улучшенной производительностью, гибкостью и безопасностью. (Текст взят из Википедии, свободной энциклопедии)

SNMP-адаптер использует так называемые OID (идентификаторы объектов) для считывания этих значений с настроенного устройства.

## Конфигурация

Адаптер запрашивает указанные OID (идентификаторы объектов), которые группируются в группы OID, которые, в свою очередь, назначаются устройствам. Данные конфигурации вводятся на нескольких вкладках:

### Группы OID вкладок

Здесь вы указываете все OID, которые должны быть запрошены адаптером, по одному OID на строку.

<p align=center><img src="img/snmp_tab_oids.jpg" width="600" /></p>

| Параметр       | Тип        | Описание                                                            | Комментарий                                                                                                     |
| -------------- | ---------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| активный       | логический | Если установлено значение true, будет использоваться OID.           | может использоваться для отключения отдельного OID                                                              |
| OID-группа     | текст      | название группы OID                                                 | будет использоваться для назначения группы устройству                                                           |
| OID-Name       | текст      | имя, присвоенное OID                                                | будет использоваться для присвоения имени точке данных                                                          |
| ОИД            | текст      | строка oid (1.2.3.4.)                                               | строка OID, указанная производителем устройства                                                                 |
| записываемый   | логический | Следует установить значение true, если OID доступен для записи.     | зарезервировано для будущего использования                                                                      |
| необязательный | логический | Если OID является необязательным, следует установить значение true. | Если установлено значение true, ошибка не будет выдана, если OID неизвестен (эта функция недоступна в SNMP V1). |

Вы можете легко активировать/деактивировать любой OID, установив флаг активности. Обратите внимание, что идентификатор состояния ioBroker для хранения считанных данных обычно формируется путем объединения имени устройства (см. вкладку «Устройства») и имени OID, указанного здесь. Вы можете использовать точки внутри имени OID для построения структуры папок.

Если некоторые OID не всегда доступны, рассмотрите возможность установки необязательного флага, чтобы избежать ненужных ошибок. Обратите внимание, что для этого требуется использование протоколов SNMP v2c или SNMPv3.

### Авторизация TAB

На этой вкладке представлена информация об авторизации SNMP V3.

<p align=center><img src="img/snmp_tab_authorization.jpg" width="600" /></p>

| Параметр             | Тип   | Описание                                | Комментарий                                                              |
| -------------------- | ----- | --------------------------------------- | ------------------------------------------------------------------------ |
| Имя (идентификатор)  | текст | идентификатор данных авторизации        | должен совпадать с идентификатором авторизации на планшетных устройствах |
| Уровень безопасности | выбор | желаемый метод обеспечения безопасности | см. описание                                                             |
| Имя пользователя     | текст | имя пользователя для аутентификации     |                                                                          |
| Метод                | выбор | метод хеширования паролей               | Поддерживаемые методы: MD5 или SHA.                                      |
| Ключ авторизации     | текст | пароль для аутентификации               |                                                                          |
| Шифрование           | выбор | метод шифрования                        |                                                                          |
| Ключ шифрования      | текст | ключ шифрования                         |                                                                          |

Обратите внимание, что имя (идентификатор) должно быть уникальным.

При выборе протокола SNMP V3 требуется расширенная аутентификация. На устройстве имя блока аутентификации указывается в столбце Auth-Id. На этой вкладке необходимо выбрать желаемый уровень безопасности следующим образом:

- Минимальные требования - необходимо только имя пользователя.
- Аутентификация — требуется имя пользователя и пароль.
- Аутентификация и шифрование — требуются имя пользователя, пароль и ключ шифрования.

Обратите внимание, что указанный уровень безопасности должен поддерживаться целевым устройством, а имя пользователя, пароль и ключ шифрования должны совпадать с данными, введенными на целевом устройстве. Вы можете использовать один и тот же блок авторизации для нескольких устройств, если они используют одни и те же данные.

### Вкладка "Параметры"

Здесь вы указываете некоторые общие параметры.

<p align=center><img src="img/snmp_tab_options.jpg" width="600" /></p>

| Параметр            | Тип         | Описание                                                                         | Комментарий                                                                                                                           |
| ------------------- | ----------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Размер пакета       | целое число | максимальное количество OID, отправляемых в одном запросе                        | Уменьшите это значение в случае ошибок TOOBIG.                                                                                        |
| Режим совместимости | логический  | Если эта опция активирована, имена точек данных формируются на основе IP-адреса. | ПРИМЕЧАНИЕ: устарело — больше не используется. Этот флаг не будет работать с адресами IPv6. Возможно, будет удален в будущих версиях. |

Параметр «Размер пакета параметров» можно использовать для уменьшения количества запрашиваемых OID в одном запросе. В зависимости от целевого устройства количество запрашиваемых IOD в одном запросе может быть ограничено. В таком случае устройство может ответить ошибкой TOOBIG. В этом случае попробуйте уменьшить значение параметра «Размер пакета параметров».

## Примеры OID

Поиск производителя и MIB-файлов в большинстве случаев проходит успешно. Кроме того, вы можете использовать программу для просмотра MIB-файлов, чтобы запросить информацию о целевом устройстве, например, <https://www.ireasoning.com/mibbrowser.shtml>

### Принтеры

Для большинства принтеров существует стандартный MIB-файл (Printer MIB). <http://www.oidview.com/mibs/0/Printer-MIB.html>

Для цветного лазерного сканирующего устройства Samsung CLP320 допустимы, например, следующие OID.

Количество печатных страниц: 1.3.6.1.2.1.43.10.2.1.4.1.1

Черный тонер: 1.3.6.1.2.1.43.11.1.1.9.1.1

Голубой тонер: 1.3.6.1.2.1.43.11.1.1.9.1.2

Тональный пурпурный: 1.3.6.1.2.1.43.11.1.1.9.1.3

Желтый тонер: 1.3.6.1.2.1.43.11.1.1.9.1.4

Блок Life\_drum: 1.3.6.1.2.1.43.11.1.1.9.1.7

### NAS-системы - Synology

Synology: По умолчанию SNMP отключен на устройствах Synology Diskstation и должен быть включен в веб-интерфейсе. Важно, чтобы порт 161 по умолчанию оставался неизменным, а сообщество было настроено правильно. Чаще всего он является публичным.

<https://global.download.synology.com/download/Document/MIBGuide/Synology_DiskStation_MIB_Guide.pdf>
