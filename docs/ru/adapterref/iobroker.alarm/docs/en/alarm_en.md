## Сигнализация ioBroker

Этот адаптер позволяет настроить домашнюю систему сигнализации без обширных знаний в области программирования. Он предоставляет возможность настроить 3 цепи безопасности и контролировать их в ночное время, при включении или выключении. Кроме того, внутренние состояния адаптера могут быть напрямую связаны с внешними состояниями. Эти связи настраиваются на вкладке «Ярлыки». Для повышения защиты от взломщиков можно легко настроить простую имитацию присутствия. Также возможны уведомления о различных событиях, которые могут отправляться по различным каналам, таким как Telegram или электронная почта _(при условии установки соответствующего адаптера!)._

**Все состояния для мониторинга и зон должны быть типа «логическое значение»! _(истина, ложь, 1, 0)_**

---

### Вкладка «Основные настройки»

Здесь вы можете настроить такие параметры, как время ночного отдыха, продолжительность действия сирены, бесшумный режим тревоги и пароль.

- **Время активации** : Задержка перед активацией при использовании точки данных задержки.
- **Время срабатывания сирены при ограблении** : Во время ограбления точка данных alarm.0.status.siren / siren\_inside устанавливается в значение true на указанное время.
- **Частота мигания при взломе** : используется для управления лампой.
- **Время срабатывания сирены в режиме sharp-inside** : Во время кражи со взломом в режиме sharp-inside точка данных alarm.0.status.siren\_inside устанавливается в значение true на это время.
- **Начало и конец ночного сна** : Эти настройки используются для автоматического перехода в режим ночного сна (опционально).
- **Пароль** : Для активации/деактивации системы с помощью пароля.
- **Задержка срабатывания сигнализации** : время задержки до момента срабатывания сигнализации о взломе (в течение этого времени срабатывает бесшумная сигнализация).
- **Журнал** : При выборе этой опции в список информационного журнала записываются различные сообщения.
- **Игнорировать состояния** : Если во время активации открыто окно цепи сигнализации, это игнорируется, и система активируется с предупреждениями.
- **Наружная сирена для использования внутри помещения** : При выборе этой опции наружная сирена также включается при срабатывании сигнализации Sharp-Inside.
- **Режим «Покидание»** : При выборе этого параметра система сигнализации активируется до истечения обратного отсчета, если сработает соответствующий контакт (необходимо выбрать на вкладке «Мониторинг»).

#### Отложенное срабатывание

Датчики с режимом срабатывания «Задержка» (например, датчики движения, IP-камеры) не срабатывают немедленно. Вместо этого они вызывают тревогу только тогда, когда в течение заданного временного интервала срабатывает настраиваемое количество **различных** датчиков с задержкой. Это значительно снижает количество ложных срабатываний от ненадежных датчиков, сохраняя при этом эффективность системы безопасности.

**Конфигурация:**

- **Количество датчиков** : Сколько уникальных датчиков с задержкой должны сработать, чтобы сработала сигнализация (по умолчанию: 3)
- **Временной интервал (мин)** : временной интервал в минутах, в течение которого датчики должны сработать (по умолчанию: 2).

**Как это работает:**

1. Датчик с задержкой срабатывает и записывает данные с меткой времени.
2. Записи, сделанные после истечения заданного временного интервала, удаляются автоматически.
3. Если количество уникальных датчиков с задержкой, сработавших в течение заданного временного окна, достигнет установленного порогового значения, будет сгенерирована полная тревога.
4. При отключении системы сигнализации все зарегистрированные задержки срабатывания сбрасываются.

**Пример:** При настройках по умолчанию (3 датчика, 2 минуты) если 3 разных датчика движения обнаружат движение в течение 2 минут, сработает сигнализация. Три срабатывания одного датчика движения **не** соответствуют пороговому значению — это должны быть 3 **разных** датчика.

**Варианты использования:**

| Тип датчика             | Рекомендуемый режим | Причина                                               |
| ----------------------- | ------------------- | ----------------------------------------------------- |
| Контакты дверей/окон    | Прямой              | Необходима высоконадежная и незамедлительная реакция. |
| датчики разбития стекла | Прямой              | Необходима высоконадежная и незамедлительная реакция. |
| Датчики движения        | Отложенный          | Может давать ложные срабатывания.                     |
| Датчики присутствия     | Отложенный          | Может давать ложные срабатывания.                     |
| IP-камеры               | Отложенный          | Может давать ложные срабатывания.                     |

Каждую цепь можно настроить индивидуально на вкладке «Мониторинг», установив в столбце «Режим запуска» значение «Прямой» или «Задержанный».

### Уведомления вкладок

Уведомления через другие адаптеры, такие как Telegram, электронная почта и другие.

- **1:** Добавьте соответствующий адаптер или экземпляр. Можно также ввести напрямую!
- **2:** Для уведомлений в Telegram-адаптер можно использовать идентификаторы пользователей или чатов.

**Если в разделе «Зоны» выбрана зона, уведомление отправляется независимо от состояния системы!**

### Мониторинг вкладок

Здесь осуществляется настройка цепей системы. _Названия состояний можно изменить._

Цепь сигнализации имеет «высокий» приоритет и имеет приоритет над всеми остальными цепями при активации системы (режим «острый»). Она используется для фактического мониторинга системы, соответствующего полной защите системы сигнализации. Цепь «острый внутри» контролируется, когда система находится в режиме «острый внутри», соответствующем защите периметра. Цепь оповещения используется только для оповещений в режимах «острый», «острый внутри» и ночной покой. _Вполне возможно проверить все три цепи для одного и того же состояния._

- **1:** Добавить устройство
- **2:** Редактирование устройства
- **3:** Если необходимо активировать отдельные состояния не при _истинном_ , а при _ложном значении_ (например, датчики защиты от обрыва проводов), можно поставить галочку "negate".
- **4:** Цепь сигнализации
- **5.** Если у вас есть контакт, который не должен немедленно активировать цепь сигнализации, вы можете активировать «бесшумную сигнализацию». По истечении заданного времени (Основные настройки) сработает сигнализация.
- **6.** Если в разделе «Основные настройки» включена опция «Уйти», вы можете выбрать «Уйти» для соответствующей точки данных. Это означает, что при отложенной активации обратный отсчет не обязательно должен завершиться — достаточно закрыть дверь.
- **7:** Острая внутренняя схема
- **8:** При выборе этой опции также срабатывает бесшумная сигнализация при обнаружении острых предметов внутри.
- **9:** Схема оповещения
- **10:** Режим срабатывания — «Прямой» срабатывает немедленно, «Отложенный» требует подтверждения от нескольких датчиков в течение определенного временного интервала (см. [Отложенное срабатывание](#delayed-triggering) ).

### Вкладка Вывод речи

Если требуется голосовой вывод, например, при изменении состояния, его можно настроить здесь, указав нужные фразы. _Необходимо убедиться, что выбранная точка данных может быть записана текстом! Например, "sayit.0.tts"_

- **1:** Если вы хотите, чтобы имена объявлялись вместе с объявлениями, выберите эту опцию.
- **2:** Добавить устройство
- **3:** Время задержки вывода речи в миллисекундах (например, для разных помещений)

### Сочетания клавиш Tab

Здесь можно напрямую связать внутренние состояния адаптера с внешними состояниями. Это устраняет необходимость в скрипте или подобном обходном пути. Например, можно заблокировать дверь, когда начинается ночной отдых.

- **1:** Добавить устройство
- **2:** Выберите, какое внутреннее состояние должно инициировать реакцию.
- **3:** Выберите, при каком значении должно срабатывать событие.
- **4:** Необходимо установить идентификатор.
- **5:** Значение для записи в идентификатор
- **6:** Выберите идентификатор, который должен запустить реакцию.
- **7:** Триггер --> any = срабатывает при каждом изменении / ne = срабатывает только при изменении значения
- **8:** Выберите, при каком значении должно срабатывать событие.
- **9:** Выберите, в какое внутреннее состояние следует записать данные.

### Вкладка «Другие сигналы тревоги»

Доступны две свободно настраиваемые цепи мониторинга. Они постоянно контролируются независимо от состояния системы сигнализации! По умолчанию они обозначены как цепи пожарной и водоотводной сигнализации. В процессе настройки они обозначаются как цепи 1 и 2.

Если необходимо активировать отдельные состояния не при _истинном_ , а при _ложном значении_ (например, датчики защиты от обрыва проводов), можно поставить галочку напротив "negate".

#### Ни в коем случае не используйте состояния основных цепей мониторинга!

### Зоны вкладок

Для бесплатной настройки доступны 3 зоны. Обычно они используются для мониторинга и оповещения о менее важных объектах, таких как конюшня или что-то подобное. Эти 3 зоны работают независимо от основной цепи мониторинга. Если вы хотите интегрировать их в основную цепь, вы можете добавить соответствующее состояние зоны _, например, alarm.X.zone.one,_ в основную цепь (вкладка «Мониторинг»). Однако это означает, что уведомления для соответствующих зон будут игнорироваться.

С помощью параметра состояния _alarm.x.zone.one\_on\_off_ вы можете активировать или деактивировать зону в любое время без перезапуска адаптера! Это позволяет, например, более гибко интегрировать датчики движения в основную цепь.

_Примечание: При интеграции в основную схему эти элементы также отображаются в списках в деактивированном состоянии._

### Наличие вкладок

Здесь можно настроить имитацию присутствия для конкретного идентификатора, которую можно дополнительно активировать, когда система настроена на режим «четкий». В качестве опции доступна точка данных _alarm.X.presence.on\_off_ , позволяющая активировать или деактивировать имитацию без перезапуска адаптера.

Выполнение для каждого состояния происходит ТОЛЬКО ОДИН РАЗ! Если экземпляр перезапускается во время активной системы, моделирование присутствия НЕ будет продолжено до следующей активации! Если значение настроенного состояния изменяется во время моделирования, это не учитывается!

- **1:** Установка общего времени задержки перед началом моделирования (до вступления в силу настроек, специфичных для идентификатора).
- **2:** Добавить устройство
- **3:** Откройте конкретные настройки для идентификатора.

#### Настройки присутствия

- **Режим срабатывания:** время = временной диапазон, восход солнца = восход до полудня, закат солнца = закат до 22:00, освещенность = когда значение освещенности триггера падает ниже установленного порогового значения.
- **Временной диапазон от/до:** Временной интервал, в течение которого должно проводиться моделирование.
- **Продолжительность:** Как долго идентификатор должен оставаться включенным.
- **Случайный фактор:** Наибольшее (1-10) значение случайного фактора для данного времени.
- **Задержка по времени:** Задержка после срабатывания триггера режима.
- **Включение/выключение:** значения, которые необходимо записать при включении/выключении.
- **Срабатывание датчика освещенности:** идентификатор состояния датчика освещенности (для режима освещения)
- **Уровень освещенности:** пороговое значение в люксах, ниже которого устройство активируется.

_(Запрос на запуск выполняется каждую минуту)_

**Для имитации присутствия требуется настройка местоположения! Для корректной работы восхода и захода солнца необходимо правильно указать местоположение!**

### Штаты

Адаптер обеспечивает несколько состояний:

#### "alarm.x.use....."

Это фактические состояния, в которых работает система сигнализации.

- use.activate\_nightrest -> Активировать ночной отдых
- use.activate\_sharp\_inside\_circuit -> Активировать мониторинг цепи предупреждения (острый внутри)
- use.disable -> Деактивировать систему (цепь сигнализации)
- use.enable -> Активировать систему (цепь сигнализации)
- use.enable\_with\_delay -> Активировать систему (цепь сигнализации) с задержкой
- use.list -> Деактивировать/Активировать/Схема предупреждения/Активировать с задержкой
- use.quit\_changes -> Сброс состояний _info.notification\_circuit\_changes, info.sharp\_inside\_siren, status.activation\_failed, other\_alarms.one\_changes, other\_alarms.two\_changes_
- use.toggle\_password -> Деактивация/активация системы (сигнализации) с помощью пароля
- use.toggle\_with\_delay -> Деактивировать/активировать систему (цепь сигнализации) с задержкой
- use.toggle\_with\_delay\_and\_password -> Деактивировать/активировать систему (цепь сигнализации) с паролем и задержкой
- use.panic -> Ручное срабатывание сигнализации (от взлома), даже если она отключена.

#### "alarm.x.status...."

Здесь вы можете ознакомиться с состоянием системы.

- status.sleep -> Сигнализирует о состоянии автоматического ночного отдыха

#### "alarm.x.info...."

Предоставляет дополнительную информацию, например, какие «двери открыты» или состояние журнала. Состояние log\_today очищается в полночь.

#### "alarm.x.other\_alarms...."

Содержит информацию о "других" цепях сигнализации 1 и 2.

#### "alarm.x.zone...."

Показывает, сработал ли триггер в соответствующих зонах.
