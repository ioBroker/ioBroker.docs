# ioBroker.ai-assistant

## Обзор

Адаптер ioBroker AI Assistant запускает интеллектуального помощника в вашей системе ioBroker. Помощник может использоваться для взаимодействия с вашей системой ioBroker, установки инструкций на основе времени, инструкций на основе триггеров и вызова пользовательских функций. Помощник может быть настроен с использованием различных языковых моделей от разных поставщиков (например, OpenAI, Anthropic, Perplexity, OpenRouter) или пользовательских/самостоятельно размещенных моделей. Помощник может использоваться для автоматизации задач, управления вашим умным домом или предоставления информации.

## Функции

- Настройте имя и характер своего помощника.
- Получение списка, чтение и запись состояний ioBroker.
- Настройте тайм-ауты и задания cron для выполнения инструкций, привязанных ко времени.
- Настройте триггеры для состояний ioBroker с условиями, которые запускают инструкции при выполнении этих условий.
- Создавайте пользовательские функции, используя собственные данные и логику.
- Используйте вкладку «Администрирование», чтобы пообщаться со своим личным помощником.

## Быстрый старт

1. Установите адаптер.
2. Настройте поставщика услуг (например, OpenAI, Anthropic, Perplexity, OpenRouter) и получите API-токен.
3. Настройте адаптер с использованием токена API.
4. Выберите модель, которую вы хотите использовать в качестве ассистента.
5. Добавьте несколько состояний ioBroker в раздел`Objects` вкладка, которая будет доступна ассистенту.
6. Начните общаться со своим ассистентом, отправляя текстовые запросы на его экран.`text_request` изложить свою позицию и получить ответы от`text_response` Используйте вкладку администратора с названием "Помощник" или настройте её вручную.

## Конфигурация

### Помощник

Настройте своего ассистента, используя следующие параметры:

| **Параметр**                                  | **Описание**                                                                                                                                                          |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Имя**                                       | Имя вашего помощника.                                                                                                                                                 |
| **Модель**                                    | Выберите модель LLM, которую должен использовать ваш ассистент (настраивается в разделе «Поставщики»).                                                                |
| **Личность**                                  | Опишите характер вашего ассистента.                                                                                                                                   |
| **Язык**                                      | Выберите язык, который должен использовать ваш ассистент (в настоящее время поддерживаются только английский/немецкий).                                               |
| **Вывод отладки / CoT**                       | В активном состоянии внутренние мысли и процессы, используемые помощником, записываются в состояние text\_response.                                                   |
| **История сообщений**                         | Включать предыдущие сообщения (для работы в режиме чат-бота). Установите значение 0 для инструментов одноразового использования, чтобы минимизировать расход токенов. |
| **Температура**                               | Контролирует креативность/последовательность ответов.                                                                                                                 |
| **Макс. токенов**                             | Ограничивает количество токенов ответа.                                                                                                                               |
| **Задержка повторной попытки**                | Задержка между повторными попытками, если запрос не удался.                                                                                                           |
| **Максимальное количество повторных попыток** | Максимальное количество повторных попыток на один запрос.                                                                                                             |

### Объекты

### ВНИМАНИЕ: Будьте осторожны с тем, к каким состояниям вы предоставляете доступ помощнику, поскольку он может читать и записывать данные во все состояния, к которым у него есть доступ.

Настройте объекты и состояния ioBrokers, к которым ассистент должен иметь доступ.

**ПРИМЕЧАНИЕ: При импорте или добавлении объектов убедитесь, что добавляете только точки данных типа «состояние», которые можно напрямую контролировать или которые содержат значение для чтения!**

| **Параметр**             | **Описание**                                                                                                                          |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Импорт из Enum.Rooms** | Импортирует все ваши состояния из перечисления enum.rooms, сортируемого в ioBroker. (Перезаписывает все ранее установленные объекты!) |
| **Сортировка**           | Все объекты с одинаковым полем сортировки будут представлены ассистенту группой (например, комнатой).                                 |
| **Имя**                  | Используйте описательное название, чтобы помощник понимал функцию объектов.                                                           |
| **Объект**               | Идентификатор состояния ioBroker                                                                                                      |

### Функции

Настройте пользовательские функции, которые должны быть доступны помощнику. Ваши пользовательские функции должны записывать ответ в состояние, определенное вами.`State (Response)` поле после`State (Request)` Результат может быть в любом удобном для вас формате (например, JSON, обычный текст), просто убедитесь, что ассистент может его понять. Совет: Вы можете использовать [адаптер AI-Toolbox](https://github.com/ToGe3688/ioBroker.ai-toolbox) для интеграции вашего ассистента с пользовательскими инструментами ИИ.

**ПРИМЕЧАНИЕ: Если вы не ответите на`State (Response)` Если значение поля изменится через 60 секунд, вызов функции завершится неудачей!**

| **Параметр**              | **Описание**                                                                                          |
| ------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Сортировка**            | Все объекты с одинаковым полем сортировки будут представлены ассистенту группой (например, комнатой). |
| **Имя**                   | Используйте описательное имя для пользовательской функции.                                            |
| **Описание**              | Опишите, что делает ваша функция, чтобы ассистент понимал, когда её нужно вызвать.                    |
| **Штат (Запрос)**         | При вызове функции помощник запишет в эту строку данные о состоянии.                                  |
| **Государство (Реакция)** | Это состояние будет считано помощником для получения ответа от функции.                               |

## Использование

### Простой разговор

Вы можете взаимодействовать со своим ассистентом, отправляя текстовые запросы.`text_request` государство и получение ответов от`text_response` состояние.

#### Вызов функции

Ассистент может вызывать все доступные функции. Он делает это, определяя функцию для вызова на основе текстового запроса. Если у вас включен вывод отладки/CoT, вы можете увидеть внутренний процесс ассистента в`text_response` состояние.

#### Взаимодействие состояний

Помощник может одновременно отображать, считывать и записывать несколько состояний ioBroker. Вы можете использовать его.`Objects` Вкладка для определения того, к каким состояниям должен иметь доступ помощник.

#### Инструкции, основанные на времени

Помощник может устанавливать тайм-ауты для инструкций относительного времени и заданий cron для заданного времени. Задания cron будут отображаться в дереве объектов помощника в разделе`Cronjobs` Тайм-ауты будут временными и будут сняты после истечения срока действия тайм-аута или перезапуска адаптера. При срабатывании тайм-аута или cron-задания помощник будет разбужен, и инструкция будет выполнена.

#### Инструкции, основанные на триггерах

Помощник может устанавливать триггеры для состояний ioBroker с необязательными условиями, которые запускают инструкции при выполнении условий. Триггеры будут перечислены в дереве объектов помощника в разделе`Triggers` При срабатывании команды помощник активируется, и инструкция будет выполнена.

#### Пользовательские функции

Ассистент может вызывать пользовательские функции, которые вы определили в`Functions` Вкладка. Ассистент запишет запрос на вкладку.`State (Request)` в поле и ожидает ответа в`State (Response)` поле.

#### Последовательность функций

Этот помощник позволяет объединять несколько функций в цепочку. Например, можно настроить cron-задание, которое при выполнении запускает проверку состояний ioBroker, а затем вызывает пользовательскую функцию с полученными результатами.

#### Очистка истории чата

Иногда может быть полезно сбросить историю чата. Для этого попросите голосового помощника очистить историю. Это удалит все предыдущие сообщения из памяти помощника. (например)`Clear history` или`Forget the previous messages` )

## Дополнительная информация

### Статистика

Статистические данные для вашего ассистента регистрируются и могут быть просмотрены в`Statistics` дерево объектов.

| **Точка данных**                  | **Описание**                                                |
| --------------------------------- | ----------------------------------------------------------- |
| **.statistics.lastRequest**       | Отметка времени последнего запроса.                         |
| **.statistics.requestCount**      | Количество отправленных запросов помощнику                  |
| **.statistics.messages\***        | JSON-массив истории сообщений (если история сообщений > 0). |
| **.statistics.clear\_messages\*** | Кнопка «Очистить историю сообщений».                        |
| **.statistics.tokens\_input**     | Всего использовано входных токенов.                         |
| **.statistics.tokens\_output**    | Общее количество использованных выходных токенов.           |
