# ioBroker.zwift

## Адаптер Zwift для ioBroker

Опрашивает API Zwift для получения данных о тренировках в режиме реального времени и делает их доступными, как указано в описании ioBroker. Отслеживайте свою мощность, частоту сердечных сокращений, частоту вращения педалей, скорость и многое другое в режиме реального времени во время езды на Zwift.

### Функции

- Данные о пассажирах обновляются в режиме реального времени каждые 5 секунд (настраивается).
- Расчет зон мощности в реальном времени (6-зонная модель Coggan, FTP автоматически считывается из вашего профиля Zwift).
- Подробные данные профиля Zwift: личность, статистика езды на велосипеде, статистика бега, майки, отрывы, серии побед.
- Индикатор состояния соединения (`info.connection` )
- Автоматическое обновление токена с резервным вариантом повторной аутентификации.
- Зашифрованное хранилище учетных данных
- Обновления метаданных применяются автоматически при перезапуске адаптера (исправления единиц измерения, добавление новых полей).

#### Зоны мощности

Он`powerZone` В режиме State используется 6-зонная модель Coggan, которая рассчитывается автоматически на основе вашей текущей мощности и FTP. Значение FTP считывается из вашего профиля Zwift — ручная настройка не требуется.

| Зона | Имя                     | % от FTP |
| ---- | ----------------------- | -------- |
| 1    | Активное восстановление | < 55%    |
| 2    | Выносливость            | 55-75%   |
| 3    | Темп                    | 76-90%   |
| 4    | Лактатный порог         | 91-105%  |
| 5    | VO2 Max                 | 106-120% |
| 6    | Анаэробная емкость      | > 120%   |

Если в вашем профиле Zwift не указан FTP, то`powerZone` Состояние обновляться не будет.

### Как это работает

Адаптер выполняет аутентификацию в API Zwift, используя ту же конечную точку, что и приложение Zwift Companion.`client_id=Zwift_Mobile_Link` При запуске он получает ваш профиль Zwift (включая FTP), затем опрашивает статус райдера через игровой релейный сервер, декодирует ответ protobuf, преобразует необработанные значения в удобочитаемые единицы измерения и обновляет дерево состояний ioBroker.

Если в вашем профиле указано значение FTP, адаптер вычисляет значение в реальном времени.`powerZone` (1-6) при каждом цикле опроса с использованием модели энергетических зон Коггана. Ручная настройка FTP не требуется.

Когда вы не катаетесь активно в Zwift, адаптер комплектуется.`isRiding` к`false` и продолжает опрос без ошибок.

**Техническое примечание:** Объекты состояния создаются с помощью`extendObjectAsync` скорее, чем`setObjectNotExistsAsync` Это означает, что изменения метаданных (исправленные единицы измерения, переименованные состояния, новые поля) применяются автоматически при каждом перезапуске адаптера. Вам не нужно удалять и создавать объекты заново после обновления.

### Идеи для «умного дома»

Как заявляет ioBroker, благодаря доступу к данным Zwift вы можете создавать автоматизации, которые позволят вам тренироваться в помещении по всему дому.

**Иммерсивное освещение**

- Меняйте цвет светодиодных лент или ламп Hue в зависимости от зон сердечного ритма — синий для восстановления, зеленый для выносливости, желтый для темпа, красный для пороговой нагрузки, мигающий красный для VO2max.
- Используйте`powerZone` Используйте значения (1-6) для непосредственного управления цветовыми схемами — для самостоятельного расчета зон не требуется никаких скриптов.
- Изменяйте цвет подсветки в зависимости от мощности — чем сильнее вы нажимаете, тем интенсивнее свечение.
- Имитируйте высоту с помощью яркости освещения — приглушайте свет при наборе высоты и увеличивайте его при снижении.
- Включите свет в комнате, когда получите Ride On.

**Адаптивное аудио**

- Автоматическое переключение плейлистов в зависимости от вашей зоны частоты сердечных сокращений или мощности — расслабляющая музыка для разминки, высокий темп для интервальных тренировок.
- При пересечении круга или достижении определенного количества сожженных калорий будет воспроизводиться звуковой эффект.
- Регулярно озвучивайте свои текущие статистические данные с помощью функции преобразования текста в речь.

**Приборные панели и дисплеи**

- Отображайте в режиме реального времени мощность, частоту сердечных сокращений, скорость и частоту вращения педалей на настенном планшете или смарт-дисплее.
- Отображайте пройденное расстояние, набор высоты и количество сожженных калорий на информационной панели в вашей «зоне боли».
- Создайте панель мониторинга VIS с вашей общей статистикой на основе данных профиля — общее количество километров, общий набор высоты, уровень XP.

**Климат-контроль**

- Включайте «умный» вентилятор, когда частота сердечных сокращений превышает пороговое значение, и выключайте его во время перерывов между ударами сердца.
- Увеличивайте скорость вращения вентилятора пропорционально потребляемой мощности.
- Включайте кондиционер, когда количество сожженных калорий превысит определенное значение.

**Самодельное оборудование**

- Используйте данные о высоте/градиенте для управления самодельным механизмом качания или наклона тренажера — создайте свой собственный симулятор подъема в гору, похожий на Wahoo KICKR CLIMB.
- Управляйте сервоприводом или линейным актуатором через ioBroker, чтобы наклонять раму велосипеда в реальном времени в зависимости от изменения градиента в игре.

**Мотивация и геймификация**

- Запустите машину для конфетти или праздничную подсветку, завершив поездку или установив личный рекорд.
- Отправьте себе уведомление в Telegram или Pushover с кратким описанием поездки, когда`isRiding` переключается на`false`
- Отслеживайте пройденное расстояние за неделю на семисегментном дисплее или экране на электронных чернилах в коридоре.
- Загорится индикатор выполнения (светодиодная лента), показывающий процент завершения маршрута.

**Семья и домохозяйство**

- Включайте индикатор «Не беспокоить» снаружи своей комнаты всякий раз, когда`isRiding` является`true`
- Автоматическое отключение звука дверного звонка во время тренировки в Zwift.
- Отправьте сообщение на умную колонку вашей семьи: «Папа катается в Zwift, ориентировочное время финиша: X минут».
