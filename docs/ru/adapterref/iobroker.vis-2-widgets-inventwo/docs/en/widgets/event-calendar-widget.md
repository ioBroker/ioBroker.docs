# Виджет календаря событий

Виджет «Календарь событий» отображает события/встречи (например, из календаря iCal) в стиле календаря Google, на основе [FullCalendar](https://fullcalendar.io/) . Каждый цвет, размер шрифта и рамка настраиваются, и поддерживаются все режимы отображения, доступные в бесплатном/MIT-пакете FullCalendar: месяц, неделя, день, несколько месяцев (год) и четыре режима списка.

Ищете простой инструмент для выбора даты? Воспользуйтесь [виджетом календаря](/#/docs/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/widgets/calendar-widget.md) .

---

## Как добавить виджет

1. Перетащите **виджет «Календарь событий»** из списка виджетов **inventwo design** на свой экран.
2. Щелкните **«События» (точка данных)** и выберите точку данных, содержащую список событий в формате JSON (см. [раздел «Отображение событий»](#showing-events) ниже).
3. Выберите режим **просмотра** и настройте параметры заголовка/навигации/номеров недель и цвета.

## Настройки

### Общий

| Параметр                                        | Что это делает                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **События (точка данных)**                      | Точка данных, содержащая список событий в формате JSON (см. [раздел «Отображение событий»](#showing-events) ниже). Игнорируется, как только в группе _«Дополнительные календари»_ ниже настроен хотя бы один календарь.                                                                                                                                                                                                                           |
| **Первый день недели**                          | Начинается ли неделя в **понедельник** или **в воскресенье** .                                                                                                                                                                                                                                                                                                                                                                                    |
| **Вид**                                         | **Месяц** , **неделя** , **день** , **несколько месяцев (год)** (сетка/набор из нескольких месяцев) или один из четырех режимов просмотра **в виде списка** ( **список - день/неделя/месяц/год** , список предстоящих событий в формате расписания).                                                                                                                                                                                              |
| **Показать панель заголовка**                   | Включено по умолчанию. Отключите, чтобы полностью скрыть панель инструментов (заголовок + кнопки навигации).                                                                                                                                                                                                                                                                                                                                      |
| **Разрешить навигацию по месяцам/неделям/дням** | Отображается только при включенной **опции «Показать заголовок»** . Включено по умолчанию. Отключение позволяет сохранить заголовок видимым, но удалить кнопки «Предыдущий/Следующий/Сегодня», чтобы пользователь не мог переключиться на другой месяц/неделю/день.                                                                                                                                                                               |
| **Показать номера календарных недель**          | Добавляет значок с номером недели к каждой ячейке дня (в основном виден в режимах просмотра «Месяц»/«Несколько месяцев»).                                                                                                                                                                                                                                                                                                                         |
| **Тип календарной недели**                      | Видно только при отображении номеров недель. **ISO-8601** : недели начинаются с понедельника, неделя 1 — это неделя, содержащая первый четверг года (европейский стандарт). **Простой вариант** : нумерация недель зависит от локали.                                                                                                                                                                                                             |
| **Максимальное количество событий в день**      | Отображается и действует только в режимах просмотра **«Месяц»** / **«Многомесячный (год)»** режим. По умолчанию используется... `0` = без ограничений, количество ячеек дня продолжает расти с увеличением числа событий, как и раньше. При значении выше 0 отображается только указанное количество плиток событий за день; остальные находятся за ссылкой «+N еще», которая при нажатии открывает всплывающее окно со всеми событиями этого дня. |

### Дополнительные календари

По умолчанию виджет отображает события одной точки данных ( **События (точка данных)** выше). Чтобы отобразить несколько календарей одновременно — например, один календарь iCal для каждого члена семьи — перечислите их здесь. Каждому календарю присваивается свой цвет и подпись, которые отображаются в легенде под календарем.

После того как здесь будет настроен хотя бы один календарь, поле **«События» (точка данных),** указанное выше, полностью игнорируется и может быть оставлено пустым.

| Параметр                                    | Что это делает                                                                                                                                                                                            |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Количество календарей**                   | Сколько календарей нужно настроить ниже.                                                                                                                                                                  |
| **Легенда шоу**                             | Включено по умолчанию. Отображается только после настройки хотя бы одного календаря. Переключает цветовую/меточную легенду под календарем.                                                                |
| **События (точки данных)** _(по календарю)_ | Точка данных, содержащая список событий в формате JSON для этого календаря (в том же формате, что и выше, см. [раздел «Отображение событий»](#showing-events) ).                                          |
| **Цвет** _(по календарю)_                   | Переопределяет цвет всех событий в этом календаре (собственном). `color` /`_calColor` и резервный **цвет фона события** ). Оставьте поле пустым, чтобы сохранить цвет, предоставленный событием/адаптером. |
| **Метка** _(на календарь)_                  | Подпись к этому календарю в легенде. Оставьте поле пустым, чтобы исключить подпись из легенды (она все равно будет отображаться в календаре).                                                             |

Приведенные ниже [правила раскрашивания событий](#event-color-rules) по-прежнему применяются ко всем календарям и переопределяют цвет календаря при совпадении. Чтобы было понятно, из какого календаря поступило событие, каждый элемент события также получает левый край шириной 4 пикселя, окрашенный в цвет этого календаря, независимо от того, переопределило ли правило раскрашивания цвет заливки элемента. В представлениях списка (которые отображают события в виде строк таблицы) вместо этого используется цветная точка перед заголовком события, чтобы он оставался центрированным в своем столбце.

### Правила выбора цвета для мероприятий

Адаптер ioBroker **iCal** отображает только один цвет для каждого календаря. `_calColor`), а не для каждого события отдельно — в отличие от самого Google Календаря, который раскрашивает отдельные события. Поэтому события из одного календаря отображаются одним цветом и их невозможно различить. Правила раскрашивания событий позволяют назначать цвета вручную на основе названия события.

| Параметр                                    | Что это делает                                                                                                                                                                                                                                              |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Количество правил**                       | Сколько правил нужно настроить ниже?                                                                                                                                                                                                                        |
| **Заголовок содержит** _(согласно правилу)_ | Текст для сопоставления с заголовком мероприятия. Сопоставление нечувствительно к регистру и выполняется, если заголовок _содержит_ этот текст (а не просто точное совпадение) - например: `Geburtstag` соответствует «Geburtstag Mama» и «Geburtstag Papa». |
| **Цвет фона** _(согласно правилу)_          | Цвет, используемый для событий, название которых совпадает.                                                                                                                                                                                                 |

Правила проверяются по порядку (правило 1, затем правило 2, ...), и побеждает тот, кто первым найдет совпадение. Совпадающее правило переопределяет любой цвет, предоставленный самим событием (его собственный). `color` /`_calColor` (и резервный **цвет фона события** из группы _плиток событий_ ниже) — в этом и суть, поскольку собственный цвет адаптера бесполезен для различения событий.

| **цвет границы**           | Отображается только при включенных границах. Цвет линий сетки.         |

## Отображение событий

Виджет календаря событий не обрабатывает файлы iCal. `.ics`) сами данные. Вместо этого, укажите **Events (datapoint)** на точку данных, значение которой представляет собой JSON-массив событий. Каждое событие представляет собой объект, содержащий:

| Поле     | Альтернативное поле | Необходимый | Описание                                                                                                                                                                                                                                                     |
| -------- | ------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `title`  | `summary`, `event`  | Да          | Текст, отображаемый на плитке события.                                                                                                                                                                                                                       |
| `start`  | `_date`             | Да          | Начало мероприятия. Строка даты/времени в формате ISO (например) `2026-08-03T10:00:00`) или метка времени в миллисекундах.                                                                                                                                   |
| `end`    | `_end`              | Нет         | Завершение мероприятия, формат тот же, что и раньше. `start` По умолчанию используется `start` (однодневное мероприятие).                                                                                                                                      |
| `allDay` | `_allDay`           | Нет         | Установить на `true` для мероприятий, длящихся весь день. В соответствии со стандартным форматом iCal/FullCalendar, `end` /`_end` В этом случае рассматривается как **исключительный случай** — день _после_ последнего видимого дня, а не сам последний день. |
| `color`  | `_calColor`         | Нет         | Переопределяет **цвет фона события** для данного конкретного события.                                                                                                                                                                                        |

Столбец «альтернативное поле» существует потому, что виджет также принимает JSON, созданный непосредственно из JSON-данных адаптера ioBroker **ical** (например, `ical.0.data.table`) — скрипт преобразования не требуется, просто укажите на него **Events (точку данных)** . Пример исходной фигуры:

```json
[
  {
    "event": "Wertstoff",
    "_date": "2026-07-28T22:00:00.000Z",
    "_end": "2026-07-29T22:00:00.000Z",
    "_allDay": true,
    "_calColor": "#FF0000"
  }
]
```

Или, используя простую пользовательскую форму:

```json
[
  { "title": "Team meeting", "start": "2026-08-03T10:00:00", "end": "2026-08-03T11:00:00" },
  { "title": "Vacation", "start": "2026-08-05", "end": "2026-08-10", "allDay": true, "color": "#c0743c" }
]
```

Обратите внимание на эксклюзивное окончание для приведенного выше примера "Отпуск" на весь день: чтобы показать событие с 5 по 9 августа, `end` запланировано на 10 августа (следующий день).

## Советы

- **Язык:** Названия месяцев и дней недели автоматически соответствуют языку браузера.
- **Изменение размера:** Календарь сохраняет свой размер в режиме реального времени при изменении размера виджета в редакторе визуализации — перезагрузка страницы не требуется.
- **Режимы просмотра списка:** Отлично подходит для компактного виджета "предстоящие события" — выберите **"Список - неделя"** или **"Список - месяц"** и отключите панель заголовка/навигацию для просмотра фиксированной программы.
- **Повторное использование стилей:** используйте **виджет «От»** в каждой группе стилей, чтобы обеспечить визуальную согласованность нескольких календарей событий.
