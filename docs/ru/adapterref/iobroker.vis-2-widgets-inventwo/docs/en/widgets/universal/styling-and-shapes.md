# Универсальный виджет — стили и формы

Универсальный виджет обладает богатым набором параметров оформления, которые настраиваются непосредственно в боковой панели редактора VIS 2. Стили организованы в именованные группы. В большинстве групп есть поле **«Из виджета»** , позволяющее копировать настройки из другого универсального виджета.

---

## Как государства и стиль взаимодействуют

Группа **состояний по умолчанию** и каждая пронумерованная группа **состояний** определяют, как выглядит плитка, когда активно определенное значение точки данных. В каждом состоянии вы устанавливаете:

- Цвет **фона**
- **Цвет содержимого** (оттенок значка, фильтр изображения)
- **Цвет текста**
- **цвет границы**
- **Цвета внешней/внутренней тени**
- **Интервал мигания контента** (скорость мигания в мс — 0 = отсутствие мигания)
- **Отключить клик при активности** — если эта функция включена для состояния, клик по плитке игнорируется, пока это состояние активно. Полезно для навигационных плиток (предотвращает повторный клик по уже активному представлению) или селекторов с несколькими вариантами (предотвращает повторную запись одного и того же значения). Недоступно для типа **«Только для чтения»** .
- **Зеркальное отображение** — Переопределение зеркального отображения для каждого состояния: **По умолчанию (из содержимого)** используется глобальная настройка зеркального отображения из группы стилей содержимого; **Да —** принудительно отображает содержимое в этом состоянии; **Нет** — отключает зеркальное отображение.
- Значок, изображение, текст или встроенное представление для отображения

В группе « **Дизайн виджетов inventtwo»** (отображается при нажатии на группы штатов) настраиваются цвета для каждого штата.

## Стиливые группы

### inventwo — Текст

Управляет отображением текстовой метки внутри плитки.

| Параметр                                    | Что это делает                                            |
| ------------------------------------------- | --------------------------------------------------------- |
| **Оформление текста**                       | Подчеркнуть, перечеркнуть или зачеркнуть.                 |
| **Выравнивание текста**                     | Горизонтальное выравнивание текста: Начало, Центр, Конец. |
| **Поля: верхние / нижние / левые / правые** | Пространство вокруг текста внутри плитки.                 |

Семейство шрифтов, размер, толщина и цвет задаются в стандартных настройках CSS виджета VIS, а также в полях **«Цвет текста»** для каждого состояния.

---

### inventwo — Содержание

Управляет размером и положением содержимого (значка, изображения и т. д.) внутри плитки.

| Параметр                            | Что это делает                                                                                                            |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Размер содержимого**              | Размер значка или изображения. Может быть указан в пикселях или в процентах от размера плитки.                            |
| **Вращение**                        | Поворачивает содержимое на любой угол (в градусах).                                                                       |
| **Зеркало**                         | Переворачивает содержимое по горизонтали.                                                                                 |
| **Масштабировать для соответствия** | _(Только для просмотра в виджете)_ Уменьшает масштаб встроенного представления, чтобы оно соответствовало размеру плитки. |
| **Тип заливки**                     | _(Только изображение)_ Способ заполнения плитки изображением: Ограничить, Покрыть, Заполнить, Повторить.                  |
| **Позиция**                         | _(Только изображение)_ Положение изображения внутри плитки.                                                               |

---

### inventwo — Выравнивание

Определяет, как содержимое и текст располагаются относительно друг друга внутри плитки.

| Параметр                                      | Что это делает                                                                                   |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **Выравнивание содержимого**                  | Горизонтальное выравнивание элемента содержимого: Начало, Центр, Конец, Пространство между ними. |
| **Выравнивание текста (группа выравнивания)** | Вертикальное или горизонтальное выравнивание текста.                                             |
| **Инвертировать заказ**                       | Меняет местами содержимое и текст (например, текст над значком вместо текста под ним).           |

---

### inventwo — Прозрачность

| Параметр                     | Что это делает                                                                   |
| ---------------------------- | -------------------------------------------------------------------------------- |
| **Прозрачность фона**        | Прозрачность фона плитки (0 = полностью прозрачный, 1 = полностью непрозрачный). |
| **Прозрачность содержимого** | Прозрачность элемента контента (иконки, изображения и т. д.).                    |

---

### inventwo — Расстояние

Задает внутренний отступ плитки — пространство между границей плитки и ее содержимым.

| Параметр                                        | Что это делает                                                   |
| ----------------------------------------------- | ---------------------------------------------------------------- |
| **Верхняя/нижняя/левая/правая часть подкладки** | Расстояние от края плитки до содержимого внутри нее, в пикселях. |

---

### inventwo — Радиус границы

Управляет формой углов плитки. Каждый угол можно настроить независимо.

| Параметр                                                          | Что это делает                                                                                                                   |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Угловой стиль**                                                 | Способ оформления углов: **закругленные** (по умолчанию — плавная кривая) или **скошенные (фаска)** (прямой срез под углом 45°). |
| **Верхний левый / Верхний правый / Нижний правый / Нижний левый** | Размер угла в пикселях. Для _закругленных углов_ это радиус кривой; для _скошенных углов_ это длина среза фаски.                 |

> **Примечание:** Когда активна многоугольная фигура, параметры радиуса скругления углов не действуют. Вместо этого используйте параметр « **Радиус скругления углов»** в группе **inventtwo - Shape** .

---

### inventwo — Border

Добавляет рамку вокруг плитки.

| Параметр                               | Что это делает                                                                                        |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Стиль границы**                      | Тип линии: Нет, Сплошная, Пунктирная, Точечная, Двойная, Канавка, Гребень, Выступ.                    |
| **Размер верх / низ / левый / правый** | Толщина границы с каждой стороны в пикселях.                                                          |
| **цвет границы**                       | Цвет границы по умолчанию (также задается для каждого штата в группах «Штат по умолчанию» / «Штаты»). |

---

### inventtwo — Внешняя тень

Добавляет тень за пределами плитки.

| Параметр                | Что это делает                                                                                                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Цвет внешней тени**   | Цвет тени (состояние по умолчанию). Также задается для каждого штата в группах штатов.                                                                                                           |
| **смещение по оси X**   | Горизонтальное смещение тени в пикселях.                                                                                                                                                         |
| **Смещение по оси Y**   | Вертикальное смещение тени в пикселях.                                                                                                                                                           |
| **Размытие**            | Радиус размытия тени.                                                                                                                                                                            |
| **Размер**              | Размер распространения тени.                                                                                                                                                                     |
| **Дополнительные тени** | Количество (0–5) последующих теней. Каждая из них получает собственное смещение по осям X/Y, размытие, размер и цвет; первая тень рисуется поверх остальных. Смещения могут быть отрицательными. |

---

### inventwo — Внутренняя тень

Добавляет утопленную тень внутри плитки (создает эффект углубления/прижатия).

Настройки те же, что и для внешней тени, включая дополнительные тени (например, светлая тень в верхнем левом углу и темная в нижнем правом углу для создания неоморфного эффекта). Цвет для каждого состояния можно задать в группах состояний.

---

### inventwo — Shape

Система фигур позволяет обрезать плитку по геометрической форме. Все фигуры, кроме прямоугольника, используют CSS-свойство clip-path, поэтому фон, граница и тень остаются в выбранной фигуре.

![Обзор системы форм](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_shapes.png)

| Параметр                                  | Что это делает                                                                                                                                                                                                                                  |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Форма**                                 | Форма плитки: Прямоугольник (по умолчанию, без обрезки), Треугольник, Ромб, Пятиугольник, Шестиугольник, Семиугольник, Восьмиугольник, Звезда, Пользовательская.                                                                                |
| **Вращение формы**                        | Поворачивает форму полигонального фрагмента. Не зависит от поворота содержимого.                                                                                                                                                                |
| **Радиус скругления углов**               | Скругляет углы многоугольных фигур. Стандартная настройка радиуса скругления углов из **inventtwo — радиус скругления углов** игнорируется для многоугольных фигур — используйте вместо неё эту настройку.                                      |
| **Пользовательские точки многоугольника** | _(Только для пользовательской формы)_ Пары X%/Y%, разделенные запятыми, в порядке по часовой стрелке, например `40% 0%, 100% 50%, 40% 100%, 0% 50%`. The `%` Знак необязателен. Если путь недействителен, плитка будет заменена прямоугольником. |

> **Совет:** Создавайте пользовательские многоугольные фигуры визуально с помощью инструмента на [сайте bennettfeely.com/clippy](https://bennettfeely.com/clippy/) и вставляйте результат в поле **"Пользовательские точки многоугольника"** .

---

### Обратная связь по кликам

При нажатии на плитку может на мгновение измениться цвет, предоставляя пользователю визуальное подтверждение того, что клик был зарегистрирован.

| Параметр                 | Что это делает                                  |
| ------------------------ | ----------------------------------------------- |
| **Фон**                  | Цвет фона в момент нажатия кнопки.              |
| **Цвет содержимого**     | Цвет содержимого (иконки) в момент нажатия.     |
| **Цвет текста**          | Цвет текста в момент нажатия.                   |
| **цвет границы**         | Цвет рамки в момент прессования.                |
| **Цвет внешней тени**    | Цвет внешней тени в момент нажатия.             |
| **Цвет внутренней тени** | Цвет внутренней тени в момент нажатия.          |
| **Продолжительность**    | Время видимости нажатого цвета в миллисекундах. |

## Повторное использование стиля с помощью виджета "Из виджета"

В большинстве групп стилей вверху есть опция « **Из виджета»** . Когда вы выбираете здесь другой универсальный виджет, все настройки этой группы копируются из выбранного виджета во время выполнения.

**Как им пользоваться:**

1. Создайте один «главный» универсальный виджет и настройте его внешний вид именно так, как вам нужно.
2. На всех остальных плитках выберите этот главный виджет в каждом поле **«От виджета»** .
3. При каждом изменении стиля основного виджета все плитки, ссылающиеся на него, автоматически обновляются.

Это рекомендуемый подход для панелей мониторинга с большим количеством плиток, имеющих одинаковый внешний вид: настройте стиль один раз и используйте его везде.
