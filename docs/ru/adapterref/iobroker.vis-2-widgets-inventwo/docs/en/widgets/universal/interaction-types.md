# Универсальный виджет — Типы взаимодействия

Параметр **«Тип»** в группе **«Общие»** определяет, что происходит, когда пользователь нажимает на плитку «Универсальный виджет». Выберите тип, соответствующий вашему сценарию использования.

---

## Выключатель

**Применение:** Переключение точки данных между двумя значениями — включено/выключено, открыто/закрыто, авто/ручной режим или любая другая пара.

**Как это работает:** Каждый щелчок поочередно изменяет значение с **«Value true»** на **«Value false»** . Когда текущее значение точки данных равно **«Value true»** , щелчок записывает **значение «Value false»** , и наоборот.

**Настройки:**

- **Идентификатор объекта** — точка данных, в которую необходимо записать данные.
- **Значение true** — значение, записанное для состояния "включено".
- **Значение false** — значение, записанное для состояния «выключено».

**Совет:** В режиме **разделенных кнопок** каждая кнопка записывает значение своего собственного состояния — это позволяет универсальному виджету работать как многофункциональный селектор.

---

## Кнопка

**Применение:** Запуск действия — активация сцены, отправка команды, установка определенного значения.

**Как это работает:** Каждый клик записывает **значение true** в точку данных.

**Настройки:**

- **Идентификатор объекта** — точка данных, в которую необходимо записать данные.
- **Истинное значение** — значение, отображаемое при нажатии.
- **Значение сброса через (мс)** — Записывает **значение false** в точку данных по истечении указанного времени в миллисекундах (`false` (если **значение false** пустое). `0` Отключает эту функцию. Используйте её для точек данных, которые не сбрасываются автоматически, например, для триггера, который должен вернуться к исходному состоянию. `false` через одну секунду. Недоступно одновременно со **значением "Удерживать"** .
- **Функция «Удержание значения»** — если она включена, значение записывается при нажатии кнопки, а точка данных восстанавливается до предыдущего значения при отпускании кнопки. Это создает поведение «удержание для активации» (например, для действий, для которых кнопка удерживается до тех пор, пока она нажата).

---

## Навигация

**Применение:** Навигация между режимами просмотра VIS — плитки выбора комнат, плитки меню.

**Как это работает:** Нажатие на плитку переключает VIS на настроенный **вид** .

**Настройки:**

- **Вид** — Вид, открывающийся при нажатии. (Отображается, когда не включен режим **разделенных кнопок** .)
- **Значение true** — необязательно. Если задано, сравнение состояний плитки использует это значение для определения того, является ли целевое представление текущим активным (для визуального выделения).
- **Защита паролем** — Если эта функция включена, пользователь должен ввести пароль или PIN-код перед началом навигации. См. раздел [«Защита паролем/PIN-кодом»](#password--pin-protection) .

**Совет:** Настройте второе состояние, которое будет совпадать с состоянием, когда целевое представление активно (сравнение по представлению или по значению), и задайте для него другой цвет фона/границы. Это выделит активный элемент меню комнаты на панели навигации.

---

## Только для чтения

**Применение:** Индикаторы состояния, отображающие значение, но не реагирующие на клики.

**Принцип работы:** плитка считывает значение точки данных и переключается между настроенными визуальными состояниями, но все взаимодействия по клику полностью игнорируются.

**Настройки:**

- **Идентификатор объекта** — точка данных для чтения.

---

## Просмотреть в диалоге

**Применение:** Открытие подробного представления в виде всплывающего окна без перехода на другую страницу панели управления.

**Как это работает:** При нажатии на плитку открывается диалоговое окно с настроенным представлением VIS.

**Настройки (в группе «Общие»):**

- **Вид** — Вид VIS, отображаемый внутри диалогового окна.
- **Идентификатор объекта** — необязательный параметр. Позволяет скрипту или другому виджету открывать и закрывать диалоговое окно (см. ниже).
- **Значение true** — значение идентификатора объекта, по которому открыто диалоговое окно.

**Открытие и закрытие по точке данных:** если задан **идентификатор объекта** , диалоговое окно открывается в соответствии с его значением: оно открывается, как только точка данных принимает **значение true** , и закрывается при любом другом значении. Таким образом, скрипт может открыть диалоговое окно (например, при звонке в дверь) и снова закрыть его — на всех устройствах, отображающих это представление. Щелчок по плитке по-прежнему открывает диалоговое окно локально.

**Настройки диалогового окна (в группе "Тип — Отображение в диалоговом окне":**

## Увеличение/уменьшение значения

**Используется для:** кнопок с шагом «плюс» и «минус» — пошаговой регулировки заданного значения температуры, уровня яркости или аналогичного числового значения.

**Принцип работы:** Нажатие кнопки считывает текущее значение точки данных и добавляет заданную величину дельты. Используйте положительную дельту для увеличения (+), отрицательную дельту для уменьшения (–).

**Настройки:**

- **Идентификатор объекта** — числовой параметр, который необходимо увеличить/уменьшить.
- **Значение true** — это величина, добавляемая к текущему значению при каждом клике. Введите отрицательное число для уменьшения.

**Пример:** Чтобы создать пару кнопок +/– для установки заданного значения:

1. Разместите два универсальных виджета рядом друг с другом.
2. Первая клетка: Тип = Увеличение/уменьшение значения, Значение истинно =`0.5`
3. Вторая клетка: Тип = Увеличение/уменьшение значения, Значение истинно =`-0.5`

## Отправить HTTP-запрос / Открыть URL

**Применение:** Запуск HTTP-действий — управление устройствами через их локальный веб-API, открытие видеопотока с камеры или переход на внешнюю страницу.

**Настройки:**

- **URL** — Полный URL-адрес для вызова или открытия.
- **Тип HTTP:**
  - **Отправить запрос** — Отправляет HTTP GET-запрос в фоновом режиме. Переход по странице не происходит. Используйте это для вызова конечной точки API.
  - **Открыть URL** — Переходит по URL-адресу на текущую вкладку браузера.
  - **Открыть URL в новой вкладке** — Открывает URL в новой вкладке браузера.

---

## Защита паролем/PIN-кодом

**Применение: Для** плиток, которые не должны случайно или посторонними лицами активироваться — например, при отключении сигнализации, открытии дверного замка или гаражных ворот, выключении отопления.

**Как это работает:** При нажатии на плитку сначала открывается диалоговое окно ввода. Только после ввода правильного пароля или PIN-кода выполняется действие плитки: записывается значение, изменяется отображение, открывается диалоговое окно или отправляется HTTP-запрос. Неправильный ввод или **нажатие кнопки «Отмена»** ничего не делают.

Доступно для всех типов, кроме **«Только для чтения»** , и не для **кнопки** со **значением «Удерживать»** .

**Настройки (в группе «Общие»):**

- **Защита паролем** — включает защиту.
- **Тип ввода** — выберите между **паролем** (ввод скрытого текста) и **PIN-кодом** (цифровая клавиатура для ввода PIN-кода).
- **Пароль/PIN-код** — пароль или PIN-код, который пользователь должен ввести. Без ввода защита неактивна.

> **Примечание по безопасности:** пароль хранится в проекте vis в открытом виде и проверяется в браузере. Это предотвращает случайное или несанкционированное использование настенной панели, но не является реальной защитой доступа — любой, кто имеет доступ к ioBroker, все равно может записать данные.

## Одна кнопка против разделенных кнопок

Параметр **«Режим»** изменяет способ отображения состояний:

### Одна кнопка (по умолчанию)

Одна плитка, одно действие. Внешний вид плитки меняется в зависимости от текущего активного состояния (на основе значения точки данных). Нажатие всегда выполняет одно и то же действие (определяемое параметром **«Тип** »).

### Раздельные кнопки

Каждое состояние становится отдельной кнопкой, расположенной рядом (или сверху/снизу). Каждая кнопка отображает содержимое и стиль своего состояния. Нажатие кнопки записывает заданное значение этого состояния в точку данных.

Это эквивалентно списку переключателей — отлично подходит для выбора режимов, например. `Off / Low / Medium / High`.

Дополнительные настройки для отдельных кнопок:

- **Инструкция** — Расположите пуговицы в **ряд** (рядом друг с другом) или **в столбик** (внахлест).
- **Размер кнопки** — ширина (строка) или высота (столбец) каждой отдельной кнопки в пикселях.
- **Расстояние между кнопками** — промежуток между кнопками в пикселях.
