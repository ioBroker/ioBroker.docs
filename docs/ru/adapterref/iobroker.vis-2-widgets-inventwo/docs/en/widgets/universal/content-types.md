# Универсальный виджет — Типы контента

Параметр **«Тип содержимого»** (в группе **«Общие»** ) определяет, что отображается внутри плитки «Универсальный виджет». Содержимое и его внешний вид можно настроить отдельно для каждого состояния.

![Обзор типов контента](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_types.png)

---

## Икона

**Применение:** Символическое визуальное представление состояния — лампочка для включения/выключения, замок для обозначения безопасности/открытости, термометр для обозначения отопления и т. д.

**Как это работает:** Вы выбираете файл значка из библиотеки значков ioBroker (или загружаете свой собственный). Значок отображается в тайле и может быть окрашен в любой цвет.

![Тип содержимого значка](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_icon.png)

**Настройки для каждого штата (в группах «Штат по умолчанию» / «Штаты»):**

- **Значок** — Выберите значок, который будет отображаться в этом состоянии.
- **Цвет содержимого** — Оттенок, применяемый к значку в этом состоянии.
- **Цвет содержимого (истина)** — _(отдельные кнопки / состояние с истинным значением)_ Цвет оттенка для активного состояния.

**Оформление контента (в группе "inventtwo - Content":**

- **Размер содержимого** — Размер значка в пикселях или в процентах от размера плитки.
- **Вращение** — Поверните иконку под любым углом.
- **Зеркальное отображение** — переверните значок по горизонтали.

---

## Изображение

**Используйте для:** фотографий, фоновых изображений, пользовательских иллюстраций или любых графических файлов в качестве визуального контента для плитки.

**Как это работает:** вы вводите URL-адрес или путь к файлу изображения, и оно отображается внутри плитки.

![Тип содержимого изображения](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_image.png)

**Настройки для каждого штата:**

- **Изображение** — URL или путь к файлу изображения для данного штата.
- **Изображение истинно** — Изображение, используемое в активном/истинном состоянии (для плиток переключающего типа).

**Оформление изображений (в группе "inventtwo - Content":**

- **Тип заливки** — способ заполнения изображения областью плитки:
  - **Размер** — Изображение полностью помещается внутри плитки (может оставаться пустое пространство).
  - **Обложка** — Изображение полностью заполняет плитку (края могут быть обрезаны).
  - **Заливка** — Изображение растягивается, чтобы точно заполнить весь фрагмент.
  - **Повторение** — изображение повторяется, заполняя всю область.
- **Позиция** — место, где изображение располагается внутри плитки (используется с параметром «Содержать»).

---

## Текст html

**Применение:** Отображение форматированного текста, значений или простого HTML-контента внутри элемента интерфейса.

**Как это работает:** Вы вводите текст или HTML-разметку в поле **«Текст»** . Содержимое отображается в виде HTML-кода внутри плитки.

![Тип содержимого изображения](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_html.png)

**Настройки для каждого штата:**

- **Текст** — текстовое или HTML-содержимое для этого штата. Вы можете использовать `<b>`, `<i>`, `<span style="...">` и аналогичные теги.
- **Текст true** — Текстовое содержимое для активного/истинного состояния.

**Оформление текста** контролируется группой **параметров inventtwo - Text** (размер шрифта, толщина, выравнивание, оформление, поля).

> **Примечание по безопасности:** В поле «Текст HTML» используйте только доверенный контент. Не передавайте в это поле непроверенный пользовательский ввод напрямую.

---

## Просмотреть в виджете

**Применение:** Встраивание другого представления VIS в качестве содержимого плитки — например, мини-обзора или подпанели.

**Как это работает:** выберите название представления VIS, и оно отобразится внутри плитки.

**Настройки для каждого штата:**

- **Отображение в виджете** — Виджет VIS, который будет встроен в это состояние.
- **Отображение в виджете true** — Отображение, встроенное в виджет, в активном/истинном состоянии.

**Оформление контента:**

- **Масштабирование по размеру** — уменьшает размер встроенного представления, чтобы оно поместилось внутри плитки. Включите эту опцию, если размер встроенного представления превышает размер плитки.

---

## Выбор цвета

**Применение:** Интерактивное управление цветом — управление RGB-подсветкой, светодиодными лентами или любым устройством, принимающим цветовой ввод.

**Принцип работы:** внутри плитки отображается интерактивная палитра цветов. Выбранный цвет записывается в одну или несколько точек данных.

![Тип содержимого палитры цветов](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_colorpicker.png)

**Настройки (в группе "Содержимое виджета - Выбор цвета":**

| Параметр                                   | Что это делает                                                                                                                                                                                                                                        |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Идентификатор объекта (палитра цветов)** | Основной параметр для записи цвета (в формате, соответствующем вашей цветовой модели).                                                                                                                                                                |
| **Значение OID 1 / 2 / 3**                 | Дополнительные данные для отдельных цветовых компонентов (например, R, G, B по отдельности).                                                                                                                                                          |
| **Цветовая модель**                        | Формат записываемого значения: **HSV** , **HSL** , **RGB** , **RGB (масштабированное)** , **CIE** , **Hex** , **Hex 8** (шестнадцатеричное с альфа-каналом).                                                                                          |
| **Максимальное значение**                  | _(Только RGB (масштабированное значение))_ Максимальное значение для каждого канала R, G, B. По умолчанию: 1023. Используйте это значение для 10-битных контроллеров (0–1023) или любого устройства, которое не принимает стандартные значения 0–255. |
| **Выставочное колесо**                     | Показан круговой цветовой круг.                                                                                                                                                                                                                       |
| **Показать коробку**                       | Отображает поле выбора цвета/насыщенности.                                                                                                                                                                                                            |
| **Показать оттенок**                       | Отображает ползунок регулировки оттенка.                                                                                                                                                                                                              |
| **Показать насыщенность**                  | Отображает ползунок насыщенности.                                                                                                                                                                                                                     |
| **Показать значение**                      | Отображает ползунок яркости (значения).                                                                                                                                                                                                               |
| **Показать красный / зеленый / синий**     | Отображает отдельные ползунки R, G, B.                                                                                                                                                                                                                |
| **Показать альфа-канал**                   | Отображает ползунок прозрачности/альфа-канала.                                                                                                                                                                                                        |
| **Показать Кельвин**                       | Отображает ползунок цветовой температуры (в Кельвинах).                                                                                                                                                                                               |
| **Ширина**                                 | Ширина палитры цветов в пикселях.                                                                                                                                                                                                                     |
| **Размер ручки**                           | Размер ручек палитры цветов.                                                                                                                                                                                                                          |
| **Поле обработки**                         | Поле вокруг ручек.                                                                                                                                                                                                                                    |
| **Пространство компонентов**               | Вертикальное расстояние между компонентами палитры цветов.                                                                                                                                                                                            |
| **Ширина границы / Цвет границы**          | Добавляет рамку вокруг компонентов палитры цветов.                                                                                                                                                                                                    |
| **Направление**                            | Направление компоновки: **горизонтальное** или **вертикальное** .                                                                                                                                                                                     |

**Совет для RGB-светильников:** установите **цветовую модель** в **шестнадцатеричном формате** и свяжите **идентификатор объекта (палитру цветов)** с цветовой точкой вашего адаптера освещения. Включите только те элементы управления, которые поддерживает ваш светильник — например, только круг для оттенка и ползунок значения для яркости.

## Аналоговые часы

**Используется для:** отображения текущего местного времени на экране часов на панели управления.

**Принцип работы:** внутри тайла отображаются аналоговые часы в реальном времени, которые обновляются каждую секунду. Подключение к точке данных не требуется.

![Тип содержимого аналоговых часов](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_clock.png)

**Настройки (в группе "Содержимое виджета - Аналоговые часы":**

**Циферблат:**

| Параметр      | Что это делает                                                                                                                                                                                                                           |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Дизайн**    | Стиль шрифта: **Классический** (цифры + длинные деления), **Современный** (минималистичные деления), **Минималистичный** (очень чистый, без цифр), **Штрихи** (только деления), **Пользовательский** (настройка делений и цифр вручную). |
| **цвет лица** | Цвет элементов циферблата (отметок, цифр).                                                                                                                                                                                               |
| **Цвет фона** | Цвет заливки за циферблатом часов.                                                                                                                                                                                                       |

**Пользовательские настройки интерфейса** (только если для **параметра «Дизайн»** установлено значение **«Пользовательский»** ):

| Параметр                     | Что это делает                                                                                       |
| ---------------------------- | ---------------------------------------------------------------------------------------------------- |
| **Интервал между делениями** | Какие отметки отображать: **только часы** , и то, **и другое** (часы и минуты).                      |
| **Толщина клеща**            | Толщина мельчайших клещей.                                                                           |
| **Основная толщина деления** | Толщина часовых делений.                                                                             |
| **Длина клеща**              | Длительность минутных отметок.                                                                       |
| **Основная длина такта**     | Длительность часовых отметок.                                                                        |
| **Показать цифры**           | Какие числа отображать: **Все числа** (все 12), **Только основные часы** (12, 3, 6, 9), **Ничего** . |
| **Размер числа**             | Размер шрифта цифр времени.                                                                          |
| **Смещение числа**           | Расстояние от цифр до делений шкалы.                                                                 |

**Звонок часов:**

| Параметр             | Что это делает                       |
| -------------------- | ------------------------------------ |
| **Выставочный ринг** | Обводит кругом весь циферблат часов. |
| **толщина кольца**   | Толщина кольца.                      |

**Стрелки** (часовая, минутная, секундная — каждая отдельно):

| Параметр       | Что это делает                                                                                                                                               |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Показывать** | Видна ли эта рука.                                                                                                                                           |
| **Дизайн**     | Тип кисти: **Классический** (стандартная сужающаяся форма кисти), **Современный** (тонкая прямоугольная кисть), **Стреловидный** (форма наконечника стрелы). |
| **Цвет**       | Цвет этой руки.                                                                                                                                              |
