# Виджет таблицы
Виджет «Таблица» отображает данные из точки данных ioBroker в виде отформатированной таблицы. Точка данных должна содержать **массив JSON** - список объектов, где каждый объект представляет собой одну строку. Это идеально подходит для отображения показаний датчиков, списков устройств, журналов истории или любых структурированных данных, которые адаптер записывает в формате JSON.

![Виджет таблицы](../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/widget-table.png)

---

## Как добавить виджет
1. Перетащите **Таблицу** из списка виджетов **inventwo design** на ваше представление.
2. Щелкните **Идентификатор объекта** и выберите точку данных, содержащую массив JSON (см. раздел «Формат данных» ниже).
3. Таблица автоматически отображается с одним столбцом на каждый ключ JSON.
4. Чтобы настроить столбцы (заголовки, ширину, форматирование), увеличьте значение параметра **Количество столбцов** и настройте каждый столбец отдельно.

---

## Ожидаемый формат данных
Объект данных должен содержать JSON-массив объектов. Каждый объект представляет собой одну строку, а каждый ключ становится столбцом.

```json
[
  { "name": "Living Room", "temp": 21.3, "humidity": 58 },
  { "name": "Kitchen",     "temp": 22.1, "humidity": 62 },
  { "name": "Bedroom",     "temp": 19.8, "humidity": 55 }
]
```

Если значение точки данных не соответствует допустимому формату JSON, в таблице отобразится сообщение об ошибке.

## Настройки
### Общий
| Настройки | Что это делает |
|---------|-------------|
| **Идентификатор объекта** | Точка данных, содержащая массив JSON. |
| **Количество столбцов** | Количество столбцов, настроенных вручную. Установите значение **0** для автоматически настраиваемых столбцов (все ключи отображаются в порядке их появления в JSON). Увеличьте это значение, чтобы настроить каждый столбец индивидуально. |
| **Максимальное количество строк** | Максимальное количество отображаемых строк. Установите значение **0**, чтобы отобразить все строки. |
| **Показать заголовок** | Отображает или скрывает строку заголовка с заголовками столбцов. |
| **Пагинация** | При включении строки разбиваются на страницы с элементами навигации внизу таблицы, вместо отображения всех строк сразу. |
| **Строк на странице** | *(Только для постраничной навигации)* Количество строк на странице. |
| **Фиксированный заголовок** | При включении этой функции заголовок остается видимым при прокрутке нескольких строк. |
| **Строка суммирования** | При включении этой функции под предпоследней строкой отображается двойная нижняя граница, визуально отделяющая последнюю строку от строки итогов или сводки. |

### Сортировка
| Настройки | Что это делает |
|---------|-------------|
| **Столбец сортировки по умолчанию** | Ключ столбца, по которому будет производиться сортировка при первой загрузке таблицы. |
| **Порядок сортировки по умолчанию** | **По возрастанию** или **По убыванию**. |
| **Сортировка по нескольким столбцам** | Позволяет сортировать данные по нескольким столбцам одновременно. Щелкните заголовок столбца, чтобы добавить его в порядок сортировки. Щелкните еще раз, чтобы изменить порядок сортировки. Щелкните в третий раз, чтобы удалить этот столбец из сортировки. Числовой значок в заголовке показывает приоритет сортировки. |
| **Количество столбцов сортировки по умолчанию** | *(Только для множественной сортировки)* Сколько столбцов сортировки по умолчанию нужно настроить. |

Пользователи могут щелкать заголовки столбцов во время выполнения программы, чтобы изменить порядок сортировки (если для этого столбца включена функция **Sortable**).

### Настройки столбцов (для каждого столбца)
Если значение параметра **Count columns** больше 0, для каждого столбца применяются следующие настройки:

| Настройки | Что это делает |
|---------|-------------|
| **Скрыть столбец** | Скрывает этот столбец из таблицы, не удаляя его конфигурацию. |
| **Ключ** | Имя свойства JSON, которое будет отображаться в этом столбце, например, `temp`. Если оставить поле пустым, столбец будет использовать ключ, указанный в этой позиции в JSON. |
| **Формула** | Необязательное арифметическое выражение, вычисляемое на основе JSON-полей строки. Если задано, результат заменяет исходное значение ключа. JSON-ключи используются непосредственно в качестве переменных, например, `price *qty` или `value* 100`. Поддерживаемые операторы: `+` `-` `*` `/` `%` `**` и скобки `()`. Затем результат обрабатывается с помощью параметра **Формат** (например, округляется до числа). |
| **Заголовок** | Метка заголовка столбца. Если поле пустое, используется имя ключа JSON. |
| **Префикс** | Текст, добавляемый перед значением ячейки, например, `~`. |
| **Суффикс** | Текст, добавляемый после значения ячейки, например, ` °C`. |
| **Суффикс** | Текст, добавляемый после значения ячейки, например, ` °C`. |
| **Заполнитель** | Текст, отображаемый, когда значение ячейки пустое или равно нулю. |
| **Выравнивание заголовка** | Выравнивание заголовка колонки: слева, по центру, справа. |
| **Выравнивание содержимого** | Выравнивание значений ячеек: слева, по центру, справа. |
| **Целевая вкладка** | *(Только в формате URL)* Где открывается ссылка: **Новая вкладка** (`_blank`), **Та же вкладка** (`_self`), **Родительский фрейм** (`_parent`), **Верхний фрейм** (`_top`). |
| **Цель ссылки** | *(Только в формате URL)* Где открывается ссылка: **Новая вкладка** (`_blank`), **Та же вкладка** (`_self`), **Родительский фрейм** (`_parent`), **Верхний фрейм** (`_top`). |
| **Разделитель десятичных знаков** | *(Только для формата чисел)* Символ, используемый для разделения десятичных знаков, например, `.` или `,`. Оставьте пустым, чтобы использовать значение по умолчанию из локали браузера. |
| **Разделитель тысяч** | *(Только для числового формата)* Символ, используемый для разделения тысяч, например, `,` или `.`. Оставьте пустым, если разделитель отсутствует. |
| **Разделитель тысяч** | *(Только для числового формата)* Символ, используемый для разделения тысяч, например, `,` или `.`. Оставьте пустым, если разделитель отсутствует. |
| **Цвет (отмечено)** | *(Только логический формат)* Цвет флажка, когда значение истинно. |
| **Цвет (не отмечено)** | *(Только логический формат)* Цвет флажка, если значение неверно. |
| **Формат даты и времени** | *(Только формат даты и времени)* **Дата и время** (дата и время), **Дата** (только дата), **Время** (только время), **Пользовательский формат** (введите свой собственный шаблон). |
| **Пользовательский формат** | *(Только для пользовательской даты и времени)* Шаблон формата - см. таблицу токенов ниже. |
| **Сортируемый** | Добавляет стрелку сортировки в заголовок этого столбца, по которой пользователи могут кликнуть. |
| **Включить фильтр** | Добавляет значок фильтра в заголовок этого столбца. Нажатие на него открывает список для отображения/скрытия строк по значению. |

### Условия цвета ряда
Вы можете автоматически изменять цвет фона строки в зависимости от значения определенной ячейки. Это отлично подходит для выделения важных или значимых строк.

| Настройки | Что это делает |
|---------|-------------|
| **Количество условий** | Сколько цветовых правил добавить. |
| **Ключ или индекс столбца** | Имя ключа JSON или индекс столбца (начиная с 0) для оценки. |
| **Оператор сравнения** | Способы сравнения: **Равно**, **Не равно**, **Больше**, **Меньше**, **Больше равно**, **Меньше равно**. |
| **Значение** | Значение, с которым производится сравнение. |
| **Цвет строки** | Цвет фона применяется ко всей соответствующей строке. |
| **Цвет строки (всего текста)** | Цвет текста применяется ко всем ячейкам в соответствующей строке. |
| **Цвет значения (только для столбца)** | Цвет текста применяется только к ячейке в столбце условия. |

Первое условие совпадения имеет приоритет. Все остальные цвета строк (чередование четных и нечетных) переопределяются условием совпадения.

### Inventwo - Радиус границы
Закругляет углы контейнера таблицы. Настраивается отдельно для верхнего левого, верхнего правого, нижнего правого и нижнего левого углов. Используйте **Из виджета** для копирования из другого виджета таблицы.

---

### Inventwo - Border
Добавляет внешнюю рамку вокруг контейнера таблицы. Задайте стиль рамки (сплошная, пунктирная, точечная и т. д.), размер с каждой стороны и цвет. Используйте **Из виджета** для копирования из другого виджета таблицы.

---

### Inventwo - Внешняя тень
Добавляет тень вокруг контейнера таблицы. Задайте смещение по осям X и Y, размытие, размер и цвет. Используйте **Из виджета** для копирования из другого виджета таблицы.

## Советы
- **Начните с автоматического выбора столбцов:** Сначала оставьте **Количество столбцов** равным 0, чтобы увидеть исходные данные. Затем увеличьте это значение, чтобы контролировать заголовки, порядок и форматирование.
- **Температура с указанием единицы измерения:** Установите в столбце **Формат** на **Число**, **Количество десятичных знаков** на 1 и **Суффикс** на ` °C` - в ячейке отобразится `21,3 °C`.
- **Столбец «Изображение»:** Если свойство JSON содержит URL-адрес изображения, установите для столбца **Формат** значение **Изображение**, и ячейка отобразит изображение напрямую.
- **Столбец «Ссылка»:** Если свойство JSON содержит URL-адрес, установите для столбца **Формат** значение **URL**, чтобы отобразить кликабельную ссылку. Используйте **Цель ссылки**, чтобы управлять тем, откроется ли ссылка в новой вкладке или в той же вкладке.
- **Строка суммирования:** Поместите итоговые значения в последнюю строку массива JSON и включите параметр **Строка суммирования**, чтобы разделить их двойной чертой.
- **Большие наборы данных:** Включите **пагинацию** и установите **количество строк на странице**, чтобы большие таблицы оставались читаемыми, а не приходилось прокручивать сотни строк. **Максимальное количество строк** по-прежнему будет применяться в качестве общего ограничения перед началом постраничной навигации.
- **Сортировка по умолчанию:** Введите ключ JSON в поле **Столбец сортировки по умолчанию** (например, `temp`), чтобы предварительно отсортировать таблицу при загрузке представления.
