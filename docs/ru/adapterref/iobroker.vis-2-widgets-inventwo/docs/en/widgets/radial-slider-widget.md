# Виджет радиального ползунка

Виджет «Радиальный ползунок» представляет собой круговой регулятор для отображения числовых данных. Он работает как обычный виджет «Ползунок», но пользователь перемещает ползунок по круговой дорожке, а не по прямой линии. Он идеально подходит для термостатов, регуляторов громкости или любых элементов управления, где круглый циферблат уместен в дизайне.

![Виджет радиального ползунка](../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/widget-radial-slider.png)

---

## Как добавить виджет

1. Перетащите **элемент Radial Slider** из списка виджетов **inventwo design** на свой экран.
2. Измените размер виджета — он отображается как квадрат; размер виджета определяет размер циферблата.
3. Щелкните **«Идентификатор объекта»** и выберите числовую точку данных. Значения «Минимальное», «Максимальное» и «Шаг» заполняются автоматически на основе определения объекта.
4. Отрегулируйте **начальный** и **конечный углы** , чтобы определить форму дуги.
5. Настройте стиль направляющей и большого пальца в группах **inventwo - Radial track** и **inventwo - Radial thumb** .

## Настройки

### Общий

| Параметр                                    | Что это делает                                                                                                                                                                                                                     |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Идентификатор объекта**                   | Точка данных для чтения и записи. Минимальное, максимальное и шаговое значения заполняются автоматически из определения объекта при выборе OID.                                                                                    |
| **Минимальное значение**                    | Значение в начале дуги. По умолчанию: 0.                                                                                                                                                                                           |
| **Максимальное значение**                   | Значение в конце дуги. По умолчанию: 100.                                                                                                                                                                                          |
| **Шаг**                                     | Насколько изменяется значение за каждый шаг приращения. По умолчанию: 1.                                                                                                                                                           |
| **Начальный угол**                          | Угол (0–360°), с которого начинается дуга. 0° — это верхняя точка, углы увеличиваются по часовой стрелке. По умолчанию: 225 (нижний левый угол).                                                                                   |
| **Конечный угол**                           | Угол (0–360°), при котором заканчивается дуга. По умолчанию: 135° (внизу справа). Вместе с начальным углом по умолчанию это создает классическую форму циферблата "270°".                                                          |
| **Показать значение**                       | Отображает текущее числовое значение в центре циферблата.                                                                                                                                                                          |
| **Десятичные дроби**                        | _(Только при отображении значения)_ Количество десятичных знаков отображаемого значения. Оставьте поле пустым, чтобы отобразить значение без изменений.                                                                            |
| **Десятичный разделитель**                  | _(Только при отображении значения)_ Символ для десятичного разделителя, например `,` Оставьте пустым для `.`.                                                                                                                       |
| **Единица**                                 | _(Только при отображении значения)_ Текст добавляется непосредственно к отображаемому значению, например: `°C` или ` %`.                                                                                                            |
| **Показать метку**                          | Отображает текстовую метку под значением в центре. Видна только после ввода текста метки.                                                                                                                                          |
| **Этикетка**                                | Текст, который будет отображаться в качестве центральной метки, например: `°C` или `%` Отображается только при включенной **опции «Показать метку»** .                                                                               |
| **Второе значение (идентификатор объекта)** | Дополнительная необязательная точка данных отображается ниже значения/метки, например, заданное значение рядом с фактическим значением. Числа используют те же десятичные знаки и десятичный разделитель, что и основное значение. |
| **Префикс второго значения**                | _(Только со вторым значением)_ Текст перед вторым значением, например `Set: `.                                                                                                                                                     |
| **Вторая единица стоимости**                | _(Только со вторым значением)_ Текст, добавляемый ко второму значению, например: `°C`.                                                                                                                                             |
| **Показать последнее изменение**            | Ниже значения/метки отображается время последнего изменения параметра точки данных.                                                                                                                                                |
| **Формат последнего изменения**             | _(Только при отображении последнего изменения)_ Шаблон форматирования, например `DD.MM. hh:mm` Использует те же токены, что и виджет «Таблица» (`YYYY`, `MM`, `DD`, `hh`, `mm`, `ss`, `WD`, …).                                    |
| **Только для чтения**                       | При включении циферблат отображает текущее значение, но его нельзя перемещать. Полезно для индикаторов только для чтения.                                                                                                          |

### Цветовые зоны

Цветовые зоны изменяют цвет активной части в зависимости от текущего значения — например, зеленый, желтый и красный для температуры или уровня заполнения.

| Параметр                                       | Описание                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Количество цветовых зон**                    | Сколько зон настроено ниже. **0** отключает цветовые зоны.                                                                                                                                                                                                                                                                                                                                                                          |
| **Раскрашивание**                              | **Вся активная часть** (по умолчанию): активная часть полностью принимает цвет зоны, в которой находится текущее значение. **Только сегменты зоны** : каждая зона окрашивает только свой участок активной части, поэтому все пройденные зоны остаются видимыми. **Вся дорожка (шкала)** : зоны всегда видны вдоль всей дорожки, независимо от значения; активная часть не отображается, значение показывается пальцем или стрелкой. |
| **Переход между зонами**                       | _(Не для всей активной области)_ **Резкий переход** : цвет резко меняется в начале каждой зоны. **Градиент** : цвета плавно переходят друг в друга; каждая зона имеет свой точный цвет в начале.                                                                                                                                                                                                                                    |
| **Используйте цвет зоны и для значения тоже.** | Также окрашивает центральное значение в цвет зоны (не для градиентных строк).                                                                                                                                                                                                                                                                                                                                                       |
| **Исходя из стоимости** _(за зону)_            | Данная зона действует от этого значения до начального значения следующей более высокой зоны.                                                                                                                                                                                                                                                                                                                                        |
| **Цвет** _(по зонам)_                          | Цвет активной области, пока значение находится внутри этой зоны. Поддерживаются строковые градиенты.                                                                                                                                                                                                                                                                                                                                |

Побеждает зона с наибольшим **значением "От"** , не превышающим текущее значение, поэтому порядок зон не имеет значения. Ниже зоны с наименьшим значением используется обычный активный цвет.

В режимах **«Только сегменты зоны»** и **«Вся дорожка (масштаб)»** градиентные строки нельзя использовать в качестве цветов зон; такие зоны пропускаются. Ниже самой нижней зоны сегмент имеет обычный активный цвет.

**Пример:** зоны из `0` (зеленый), `60` (жёлтый) и `85` (красный) отображает зеленый цвет до 59, желтый — от 60 до 84, а красный — от 85.

## Понимание углов

Углы измеряются по часовой стрелке от верхней точки (положение «12 часов» = 0°).

| Угол | Положение на циферблате  |
| ---- | ------------------------ |
| 0°   | Верхняя часть (12 часов) |
| 90°  | Справа (на 3 часа)       |
| 180° | Внизу (на 6 часов)       |
| 270° | Слева (на 9 часов)       |

**Пример — Классический регулятор термостата:**

- Начальный угол: 225° (внизу слева, примерно на 7 часов)
- Конечный угол: 135° (внизу справа, примерно на 5 часов)
- Это создает большую дугу, которая идет от нижнего левого угла, вверх и через верхнюю часть, к нижнему правому углу.

**Пример — Полудуга правой стороны:**

- Начальный угол: 270 (влево)
- Угол на конце: 90° (справа)
- Это образует полукруг с правой стороны.

## Советы

- **Плитка термостата:** установите начальный угол 225°, конечный угол 135°, метку на `°C` и подключитесь к точке подключения системы отопления. Дуга охватывает 270° — классический вид термостата.
- **Индикатор заряда батареи:** установите начальный угол 180°, конечный угол 0°, активный цвет — зеленый, а цвет дорожки — темно-серый. Дуга заполняется слева направо по мере зарядки батареи.
- **Классический индикатор:** используйте режим цветовой зоны **«Вся шкала»** , установите **ThumbSize** равным 0, включите **«Показать деления шкалы»** и **«Показать стрелку»** — зоны образуют фиксированную шкалу, а стрелка указывает на значение.
- **Индикатор с пороговыми значениями:** включите режим **«Только для чтения»** , установите **ThumbSize** равным 0 и добавьте **цветовые зоны** — дуга будет менять цвет в зависимости от значения, например, зеленый/желтый/красный.
- **Повторное использование стиля:** используйте **виджет «Из»** , чтобы скопировать настройки трека и ползунка на несколько циферблатов.
