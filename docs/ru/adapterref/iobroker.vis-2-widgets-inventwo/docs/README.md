# vis-2-widgets-inventw — Документация

В этой папке находится пользовательская документация по набору виджетов **inventwo** для ioBroker VIS 2.

Виджеты позволяют создавать полностью стилизованные панели мониторинга — кнопки, ползунки, таблицы, выпадающие списки, прокручиваемый текст и многое другое — непосредственно в редакторе VIS 2, без написания какого-либо кода.
