# шаблоны визуализации для ioBroker.sungrow-local

Готовые виды для **vis 1** (`iobroker.vis` 1.x). Они используют только точки данных из `sungrow-local.0` Таким образом, они работают с любой установкой этого адаптера: никаких скриптов и других адаптеров не требуется. Темный дизайн, 1280 × 800 пикселей. Надписи на немецком языке.

| Файл                            | Содержание                                                                                                                                                                                                        |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `view_Sungrow_Fluss.json`       | Стартовая страница: анимированный поток энергии (солнечная батарея сверху, сеть слева, батарея справа, дом снизу, инвертор посередине). Линии движутся в направлении потока, ширина линии соответствует мощности. |
| `view_Sungrow_Akku.json`        | Батарея: состояние заряда, мощность, напряжение/ток, состояние здоровья, температура, циклы зарядки/разрядки, энергия за сегодняшний день, предельные значения (только на дисплее)                                |
| `view_Sungrow_WR.json`          | Инвертор и сеть: MPPT-контроллеры, фазы (напряжение, ток, счетчик, резервное питание), частота, коэффициент мощности.                                                                                             |
| `view_Sungrow_Diagnose.json`    | Диагностика адаптера: подключение, переподключения, время раунда/время ответа/тайм-ауты/ошибки/пропущенные запросы для каждой группы, статистика записи, последние ошибки.                                        |
| `widget_Akku-Symbol_blau.json`  | Символ батареи в виде отдельного виджета, синего цвета (как используется в представлениях).                                                                                                                       |
| `widget_Akku-Symbol_gruen.json` | Символ батареи в виде отдельного виджета, черная рамка / зеленая заливка для светлого фона.                                                                                                                       |

## Импорт

1. Откройте редактор визуализаций (`http://<iobroker>:8082/vis/edit.html`).
2. Для каждого представления: на вкладке **«Представления»** в редакторе нажмите **«Импорт представления»** , вставьте содержимое `view_<Name>.json` и введите имя **точно** так же, как в имени файла (`Sungrow_Fluss`, `Sungrow_Akku`, `Sungrow_WR`, `Sungrow_Diagnose` Навигационные кнопки ведут к этим названиям (`#Sungrow_Akku` …).
3. Только значок батареи: откройте любой виджет, на вкладке **«Виджеты»** нажмите **«Импорт виджетов»** , вставьте содержимое `widget_Akku-Symbol_<colour>.json`.
4. Сохранить. Открыть. `…/vis/index.html#Sungrow_Fluss`.

Другой экземпляр? Заменить `sungrow-local.0.` например `sungrow-local.1.` в файлах перед импортом.

## Расчетные значения

Все расчеты являются взаимозаменяемыми (`{a:id;b:id;formula}`) внутри HTML-виджетов.

- **Питание от батареи с управлением направлением:** регистрационный номер 43022 `Battery_power` Нет указателя. Направление определяется по знаку 43021. `Battery_current` ( **положительный = разряд, отрицательный = заряд** – проверено на эталонной установке: положительный ток, падение уровня заряда; исправлено в версии 0.4.0, в более ранних шаблонах направление было перевернуто). Батарея (+ разряд) =`43021 > 0 ? +43022 : (43021 < 0 ? −43022 : 0)` На экране отображения состояния батареи текущий уровень заряда батареи показан с перевернутым знаком (+ = зарядка), соответствующим легенде.
- **Потребление домохозяйства** =`max(0, 43034 Total_active_power_output + 35601 power_total-EnergyMeter)` (Выход переменного тока инвертора + сеть; 35601: положительный полюс = импорт, отрицательный полюс = экспорт). Он не содержит потерь инвертора и не зависит от состояния батареи. Генератор, мощность которого инвертор не измеряет (например, небольшая ветряная турбина), делает его слишком малым; общий блок питания («питание от») по-прежнему использует солнечную энергию + батарею + сеть. 43008 `Load_power` Этот параметр не используется, поскольку на нескольких устройствах он показывает 0.
- **Состояние батареи:** |мощность батареи| < 20 Вт → режим ожидания (без анимации), в противном случае — зарядка/разрядка. Световая полоса на индикаторе батареи поднимается вверх во время зарядки (3,5 с) и опускается/опускается влево во время разрядки (5 с). `prefers-reduced-motion` пользуется уважением.
- **Оставшееся время** (разрядка) = запасённая энергия ÷ мощность разряда; **полная** зарядка = (ёмкость − запасённая) ÷ мощность заряда. Запасённая энергия = 43023 SoC × 43039 ёмкость / 100.
- **Линии сетки:** оранжевый цвет = импорт (потоки в инвертор), зеленый цвет = экспорт. Линии ниже 10 Вт (батарея: 20 Вт) серые и не анимированы.

## Примечания

- Анимации — это CSS-ключевые кадры внутри HTML-виджета. vis 1 обрабатывает каждый `{…}` в одной строке в качестве привязки. В CSS, `{` и `}` Поэтому они никогда не находятся на одной строке. Сохраняйте это положение при редактировании CSS.
- На странице информации об эффективности батареи используются счетчики BMS 40746/40748 (`inputRegisters.2` Без блока BMS отображается "–".
- Эти окна отображают только значения. Они не содержат элементов управления, которые бы записывали данные в инвертор.
