# 1. Введение и основные принципы

Адаптер PoolControl автоматизирует и контролирует всю систему вашего бассейна:

- Управление насосом
- Регулирование температуры
- контроль солнечного излучения
- Поддержка фотоэлектрических систем
- Анализ датчика давления
- Отслеживание потребления и затрат
- Функции определения состояния и диагностики
- Подсказки о погоде и отдыхе у бассейна на основе искусственного интеллекта
- Обратная промывка, режим технического обслуживания и послеоткачка

Все точки данных структурированы в виде дерева объектов и доступны для VIS, Blockly и других адаптеров.

# 2. Общий обзор – Для чего нужен адаптер?

### ✔ Полностью автоматическое управление насосом

Солнечная энергия, фотоэлектрические системы, замерзание, режим по времени, техническое обслуживание, обратная промывка, откачка после откачки.

### ✔ Оценка температуры

До 6 датчиков с указанием минимальных/максимальных значений и разницы.

### ✔ Регулировка солнечного излучения с гистерезисом

Автоматическое включение/выключение насоса.

### ✔ Фотоэлектрический режим

Насос работает при наличии избытка солнечной энергии.

### ✔ Редактируемый коэффициент циркуляции

`general.min_circulation_per_day` — это коэффициент записи и постоянного базового оборота (от 0,5 до 3,0). Значение Admin является лишь начальным значением; изменения влияют на`circulation.daily_required` и`circulation.daily_remaining` .

При желании,`control.circulation.temperature_factor.*` Увеличивает эффективный коэффициент относительно заданного температурного порога. Базовое значение остается неизменным, эффективное значение отображается как`general.min_circulation_effective_per_day` и достигает максимального значения.`3.0` Выбранный датчик температуры должен быть активирован и выдавать допустимое значение.

### ✔ Интеграция датчика давления

Тренд, обучающие значения, нормальный диапазон, диагностика.

### ✔ Сброс значений обучения насоса

`pump.learning.reset` Сбрасывает значения, полученные в результате обучения, после изменения параметров насоса или некорректного обучения.`pump.learning.tolerance_percent` сохраняется; обучение остается пассивным и не переключает насос.

### ✔ Система искусственного интеллекта

Ежедневные сводки, советы по погоде, рекомендации по отдыху у бассейна, отчеты на выходные.

### ✔ Потребление и затраты

Автоматический сбор ежедневной, еженедельной, ежемесячной и годовой статистики.

### ✔ Система статуса

Центральный обзор для визуализации.

# 3. Настройки администратора (вкладки)

Настройка осуществляется через несколько вкладок в рамках данного экземпляра.

---

## 3.1 Общие настройки

**Название бассейна**\
&#x20;Чистый текстовый элемент для отображения.

**Объём бассейна (литры)**\
&#x20;Используется для расчета циркуляции.

**Минимальный коэффициент циркуляции в сутки**\
&#x20;Пример: цифра 2 означает, что весь объем бассейна следует циркулировать дважды в день.

**Сезон активен**\
&#x20;Важно для автоматических функций:

- **true** : Все автоматизации активны
- **false** : Автоматизация отключена, активна только защита от замерзания.

Фактическое состояние находится в дереве объектов в пределах...`status.season_active` .

---

## 3.2 Насос

**Вкл./Выкл.**\
&#x20;→`pump.pump_switch`

**Режим:**\
&#x20;→`pump.mode`

Возможные значения:

- `auto`
- `manual`
- `time`
- `off`
- `controlHelper` (устанавливается автоматически адаптером)
- `pv` (Фотоэлектрический режим)

**Дополнительные настройки:**

- Максимальная мощность (ватты)
- Максимальный расход (л/ч)
- Идентификатор объекта сокета
- Защита от замерзания активна + значение температуры

---

## 3.3 Управление температурой

До 6 датчиков:

- Поверхность
- Нижний
- Поток
- Возвращаться
- Коллекционер
- Температура наружного воздуха

Для каждого датчика:

- Отметьте галочкой «использовать»
- Выберите идентификатор объекта

Значения температуры используются для:

- контроль солнечного излучения
- защита от мороза
- Диагностика
- Тексты, созданные с помощью ИИ

---

## 3.4 Управление солнечной энергией

Настройки:

- Включить управление солнечной энергией
- Включить гистерезис
- Порог включения (`temp_on` )
- Порог выключения (`temp_off` )
- Включить предупреждения о солнечном свете

Функция управления солнечной энергией работает только в **автоматическом** режиме.

Дополнительные данные в режиме реального времени позволяют выявить текущие различия.`solar.collector_surface_delta` для стандартных солнечных батарей и`solar.extended.collector_pool_reference_delta` Для Solar Extended. Эти значения предназначены для визуализации, скриптов, панелей мониторинга и оценок.

Примечание: Изменения в справочной информации по бассейну Solar Extended (`solar.extended.pool_temperature_source` Обновления применяются автоматически во время работы. Перезагрузка адаптера не требуется. Поскольку Solar Extended работает с циклическим интервалом проверки, обновления в расчетах, логике управления и...`solar.extended.collector_pool_reference_delta` Завершение процесса может занять до 60 секунд.

---

## 3.5 Фотовольтаика (ФВ)

Настройки:

- Активная автоматизация фотоэлектрических систем
- Идентификатор объекта текущей мощности фотоэлектрической системы
- Порог включения (например, избыток 150 Вт)

Если активен:

- В режиме работы насоса отображается «Автоматический (PV)».
- Насос работает за счет избытка солнечной энергии.
- Автоматически отключается при снижении порогового значения.

## 3.6 Система ИИ

### **Главный выключатель (ai.enabled)**

| Точка данных | Значение                                                        |
| ------------ | --------------------------------------------------------------- |
| ai.enabled   | Главный выключатель для всей системы искусственного интеллекта. |

В настоящее время система искусственного интеллекта состоит из двух модулей:

- aiHelper (погода и ежедневные функции)
- aiForecastHelper (прогноз на завтра)

Система искусственного интеллекта автоматически генерирует ежедневные данные:

- Погодные подсказки
- Ежедневные сводки
- Советы по бассейну
- Отчеты за выходные
- Прогноз погоды на завтра

### **Переключатели (ai.weather.switches.)**

| Точка данных                                    | Значение                              |
| ----------------------------------------------- | ------------------------------------- |
| ai.weather.switches.allow\_speech               | Также выводит данные в`speech.queue`  |
| ai.weather.switches.daily\_summary\_enabled     | Ежедневный обзор                      |
| ai.weather.switches.daily\_pool\_tips\_enabled  | Советы по бассейну                    |
| ai.weather.switches.weather\_advice\_enabled    | Погодные подсказки                    |
| ai.weather.switches.weekend\_summary\_enabled   | Отчет за выходные                     |
| ai.weather.switches.debug\_mode                 | Дополнительные записи в журнале       |
| ai.weather.switches.tomorrow\_forecast\_enabled | Прогноз на завтрашний день (активный) |

### **Расписания (ai.weather.schedule.)**

- ежедневное\_сводное\_время
- ежедневное время для советов по бассейну
- время\_советов\_попогоде
- выходные\_краткое\_время
- завтрашнее\_прогнозное\_время

Все значения указаны в формате ЧЧ:ММ.

### **Выходы (ai.weather.outputs.)**

Здесь представлены тексты, которые могут использоваться VIS или другими адаптерами.

Для работы системы искусственного интеллекта требуются геоданные из **файла system.config** .

## 3.7 Речевой вывод

- Включить речь
- Тексты для запуска/остановки насоса
- Последняя произнесенная речь
- (Необязательно): включить уведомления по электронной почте
- Все выходные данные передаются через **speech.queue.**

---

## 3.8 Контроль времени

До **трех временных окон** :

- Время начала
- Конец времени
- Будни
- опциональный интервальный режим работы с указанием периода и времени выполнения

Активно только если`pump.mode = time` .

Интервальный режим работы включается отдельно для каждого окна.`timecontrol.timeX_interval_active` По умолчанию насос запускается каждые 60 минут и работает 15 минут; цикл всегда привязан к времени начала интервального режима. При отключении интервального режима работы существующий непрерывный режим работы остается неизменным.

Перекрывающиеся окна используют логику ИЛИ: насос остается включенным всякий раз, когда хотя бы одно окно запрашивает его работу. Интервал логически заканчивается не позднее времени окончания эксклюзивного окна; поскольку существующая 60-секундная проверка остается неизменной, физическое переключение может быть задержано почти на 60 секунд. Недопустимые значения интервала не изменяются, и происходит возврат к непрерывной работе в пределах окна.`timecontrol.status_text` Отображает текущее диагностическое состояние.

---

## 3.9 Отладка и проверка системы

Раздел`systemcheck.debug_logs` предоставляет:

- Выбор целевой области (насос, солнечная энергия, время работы, управление и т. д.)
- Непрерывный журнал
- Очистить журнал

Эта функция используется для диагностики, но должна оставаться отключенной во время нормальной работы.

# 4. Дерево объектов – пояснение точек данных

### Наиболее важные основные области:

- `pump.*`
- `pump.pressure.*`
- `temperature.*`
- `solar.*`
- `photovoltaic.*`
- `runtime.*`
- `circulation.*`
- `consumption.*`
- `control.*`
- `status.*`
- `info.*`
- `ai.*`
- `systemcheck.*`

Структура разработана таким образом, чтобы быть самоочевидной в древовидной структуре объектов.\
&#x20;Все штаты имеют описательные названия и описания.

### **Проверка достоверности расчета кровообращения**

Канал`circulation.plausibility` Содержит диагностические значения для расчета циркуляции. PoolControl проверяет, не выглядят ли измеренная мощность насоса, рассчитанный расход или скачки суточного объема циркуляции неправдоподобными.

Этот диагностический модуль предназначен только для анализа. Он не корректирует значения автоматически и не изменяет управление насосом, логику фотоэлектрических систем, логику солнечной энергии или расчет циркуляции. Сохраненные состояния помогают устранять неполадки, связанные с необычными значениями циркуляции, такими как внезапные скачки суточного объема.

# 5. Автоматизированная логика и вспомогательные средства

Адаптер содержит различные вспомогательные файлы, отвечающие за выполнение конкретных задач.

### **PumpHelper**

Управляет основными функциями насоса.

### **PumpHelper4 (датчик давления)**

Процессы:

- Текущее давление
- Предыдущее значение
- Тренд (восходящий/нисходящий/стабильный)
- Система обучения для определения минимума/максимума
- Диагностический текст

### **SolarHelper**

Контроллер работы солнечной батареи, включая гистерезис.

### **PhotovoltaicHelper**

Автоматическое управление насосом на основе избытка солнечной энергии.

### **FrostHelper**

Автоматически включает насос при температуре ниже заданной.

### **RuntimeHelper**

Вычисляет время работы и объем циркуляции. Также записывает диагностические значения, предназначенные только для анализа, в соответствующем разделе.`circulation.plausibility` сделать видимыми неправдоподобные входные или вычислительные значения.

### **Помощник по потреблению**

Ежедневное, еженедельное, ежемесячное и годовое потребление.

### **ControlHelper**

Функции:

- Обратная промывка
- Режим технического обслуживания
- После откачки (проверка циркуляции)
- Уведомления

Для достижения целевого суточного объема циркуляции используется автоматическая дополнительная откачка. Как правило, для этого не требуются значения температуры. Если система управления солнечной энергией активна и температура коллектора и бассейна соответствует норме, дополнительная откачка блокируется до тех пор, пока температура коллектора не будет выше температуры бассейна.

### **InfoHelper**

- Версия адаптера
- Сезонные поздравления, включая расчет пасхальных подарков.

### **AI-помощник**

- Получение метеорологических данных (Open-Meteo)
- Генерация текста
- Расписания
- Логика защиты от спама

### **DebugLogHelper**

- Мониторинг конкретных зон в режиме реального времени

## Двухуровневая ограниченная история химии

Существующие значения pH, TDS и ORP в формате samples\_json сохраняют 15-минутную краткосрочную историю: максимум 7 дней, 672 образца и 64 КБ данных в формате UTF-8 на каждое значение. Для существующих 30-дневных оценок адаптер дополнительно хранит один внутренний буфер daily\_json с локальными календарными днями для каждого типа химических веществ, содержащий значения min, max, avg, last и count, максимум 32 записи и 8 КБ данных.

Для сравнений за 24 часа и 7 дней используется samples\_json; для сравнения за 30 дней предпочтительно использовать последний результат из агрегированного daily\_json. Все существующие эталонные, дельта, трендовые и сводные состояния остаются доступными. Во время первоначальной настройки буфер дня заполняется действительным скалярным эталонным значением за 30 дней и читаемыми устаревшими выборками; впоследствии он обновляется для каждой вновь сохраненной действительной выборки. Слишком большие устаревшие значения отбрасываются перед анализом JSON. Компактные ежедневные агрегации не заменяют исходные исторические данные. Исходные долгосрочные данные хранятся в базе данных истории или временных рядов ioBroker.

Если файл states.jsonl, уже имеющий слишком большой размер, препятствует запуску js-контроллера, его необходимо сначала восстановить вручную или с помощью внешних инструментов восстановления. Адаптер сможет справиться с этой ситуацией только после успешного запуска контроллера.

# 8. Часто задаваемые вопросы и советы

**1. Почему ничего не происходит, несмотря на активность ИИ?**\
&#x20;→ Проверьте, содержит ли файл system.config данные о широте и долготе.

**2. Почему насос не включается, несмотря на наличие солнечной энергии?**\
&#x20;→ Режим должен быть **автоматическим** .

**3. Почему фотоэлектрический модуль не работает?**\
&#x20;→ Проверьте пороговое значение → PV должно быть выше этого значения.

**4. Почему датчик давления показывает 0 бар?**\
&#x20;→ Проверьте идентификатор объекта в настройках администратора.
