# Информация об адаптере ПИД-регулятора

## Общая информация

Этот адаптер предоставляет один или несколько настраиваемых ПИД-регуляторов для каждого экземпляра.

Общие принципы работы ПИД-регулятора описаны, например, в Википедии ( <https://en.wikipedia.org/wiki/PID_controller> ). Вкратце, ПИД-регулятор вычисляет выходное значение в зависимости от входного значения и трех параметров:

- пропорциональная составляющая
- интегральный компонент
- производный компонент

Этот адаптер ioBroker позволяет настраивать ПИД-регулятор, указывая несколько параметров, перечисленных [здесь](#controller-configuration) . Выходное значение вычисляется через регулярные интервалы, заданные как время цикла. Кроме того, вычисление может быть приостановлено, а внутренние значения могут быть сброшены по запросу.

Для удобства можно установить заданное значение выходного сигнала в ручном режиме.

Состояния, используемые в качестве входных данных и устанавливаемые выходными данными контроллера, перечислены в разделе [«Описание состояний».](#description-of-states)

## Конфигурация

### Вкладка "Конфигурация"

Эта вкладка позволяет указать один или несколько экземпляров контроллера, работающих независимо друг от друга.

<p align=center><img src="img/pid_tab_controllers.jpg" width="600" /></p>

#### Выбор режима конфигурации

Вы можете указать следующие параметры:

- режим конфигурации<br> Поле`configuration mode` Позволяет выбрать желаемый режим: Kp/Tn/Tv или Xp/tn/Tv. Рядом с выбранным режимом вы увидите формулу, используемую для расчета в зависимости от выбранного режима.

- игнорировать заданное значение для производной<br> Если это поле выбрано, значение разницы для производной рассчитывается только на основе фактического значения; в противном случае учитывается также заданное значение.

### Вкладка «Общие параметры»

Здесь вы указываете некоторые общие параметры.

<p align=center><img src="img/pid_tab_options.jpg" width="600" /></p>

- логарифмический расчет<br> Включение этой опции активирует запись в журнал данных, вычисленных в ходе регулярных перерасчетов.

- отключить папки для штатов<br> Обычно состояния структурируются с помощью папок. Если предпочтительнее плоская структура, активация этой опции отключает все папки. Обратите внимание, что изменение этой опции приведет к удалению всех существующих состояний. Это может иметь побочные эффекты, например, связанные с записью истории. Поэтому перед изменением этой опции необходимо подтвердить наличие предупреждения.

### Обработка гистерезиса и обновление выходных данных

Адаптер оценивает каждый входной сигнал, записанный в состояние «act», и вычисляет разницу для состояния «set». Если разница меньше значения гистерезиса, перерасчет не выполняется. Это позволяет минимизировать небольшие изменения на выходе, если состояние «act» изменяется незначительно.

Если для параметра состояния управления адаптера установлено значение true, новые вычисления не выполняются. Выходные данные замораживаются («на удержании»), пока значение параметра 'hold' установлено на true.

Если задано ненулевое время цикла (и параметр 'hold' имеет значение false), адаптер выполняет перерасчет каждые x мс, указанных параметром 'cycle'. Результат расчета записывается в соответствующие состояния. Вы также можете проверить внутренние значения.
