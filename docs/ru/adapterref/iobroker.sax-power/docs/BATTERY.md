# Модели батарей, эквивалентные полные циклы зарядки/разрядки и состояние батарей.

## Область применения и терминология

Все поддерживаемые в настоящее время системы SAX Power представляют собой системы хранения энергии с питанием от сети переменного тока. Поэтому адаптер обрабатывает значения энергии, возвращаемые API энергетической диаграммы SAX Power, как значения, полученные от сети переменного тока.

Адаптер намеренно разделяет:

- счетчик циклов, предоставленный компанией SAX Power (`data_cycle` )
- Эквивалентные полные циклы рассчитываются прозрачно на основе истории облачных данных.
- явно рассчитанное значение состояния батареи, вычисленное адаптером.

Эти значения не взаимозаменяемы.

## Поддерживаемые модели и возможности

| Идентификатор конфигурации | Модель                       | Номинальная мощность | Полезная вместимость |
| -------------------------- | ---------------------------- | -------------------: | -------------------: |
| `home-5.8`                 | SAX Power Home 5.8 kWh       |           5,76 кВт·ч |           5,20 кВт·ч |
| `home-plus-7.7`            | SAX Power Home Plus 7,7 кВтч |           7,68 кВт·ч |           7,00 кВт·ч |

Номинальная мощность используется для расчета цикла, поскольку сравнение с показаниями счетчика, предоставляемыми SAX, показывает, что SAX также использует номинальную мощность. Полезная мощность является эталонной мощностью для оценки состояния и остается доступной для последующих функций управления энергопотреблением.

В настоящее время API панели управления не предоставляет надежного идентификатора модели. Адаптер автоматически обнаруживает системы хранения данных, связанные с учетной записью SAX Power, и использует их серийные номера только в качестве внутренних стабильных идентификаторов. Пользователи не могут добавлять или переименовывать устройства в административном интерфейсе; они могут только назначать модель каждой обнаруженной системе хранения данных. Без назначения адаптер не предоставляет вычисляемые значения, зависящие от емкости, вместо того, чтобы гадать.

На странице состояния отображается счетчик сообщений, рассчитанные значения за день/месяц/год/всего и доступность состояния для каждой обнаруженной системы хранения. При наличии нескольких систем дополнительно отображаются значения суммарного цикла, взвешенные по емкости. Значение за неделю остается доступным в виде объекта ioBroker, но намеренно опущено в кратком обзоре администрирования.

## Сообщенное количество циклов

Область данных в реальном времени`data_cycle` раскрывается как:

```text
devices.<serialNumber>.battery.cycles.reported
```

Это неизмененное значение счетчика, сообщаемое компанией SAX Power. Оно может быть округлено и может использовать внутренние правила, которые не задокументированы публично.

## Рассчитанные эквивалентные полные циклы

Для каждого устройства и периода времени адаптер производит расчеты:

\[ EFC = \frac{E\_{charge} + E\_{discharge}}{2 \times C\_{nominal}} ]

Где:

- (E\_{charge}) — это энергия переменного тока, заряжаемая в кВт·ч за определенный период.
- (E\_{разряд}) — это количество энергии переменного тока, высвобождаемой за период \[указать период] в кВт·ч.
- (C\_{nominal}) — это заданная номинальная емкость батареи в кВт·ч.

Результат округляется до трех знаков после запятой. Точки — это...`day` ,`week` ,`month` ,`year` , и`total` .

Пример для системы Home 5.8:

```text
(2711.74 kWh + 2433.62 kWh) / (2 × 5.76 kWh) = 446.646 cycles
```

Вычисленная сумма отражает только исторические данные, предоставленные облаком SAX Power. Она может незначительно отличаться от реальных значений.`cycles.reported` из-за округления, недоступной истории, потерь при преобразовании AC или внутренних правил SAX.

## Несколько систем хранения

Значения циклов никогда не суммируются. Суммарная стоимость установки рассчитывается исходя из суммарной пропускной способности и суммарной номинальной мощности:

\[ EFC\_{system} = \frac{\sum\_i (E\_{charge,i} + E\_{discharge,i})} {2 \times \sum\_i C\_{nominal,i}} ]

Это эквивалентное значение полного цикла, взвешенное по емкости, для всей установленной системы хранения данных. Все обнаруженные устройства должны иметь сконфигурированную модель; в противном случае суммарный результат, зависящий от емкости, останется недоступным.

## Состояние батареи

В исследуемом трафике панели мониторинга SAX Power отсутствуют прямые значения состояния работоспособности. Поэтому адаптер вычисляет явно оценочное значение на основе квалифицированных испытаний разряда в реальных условиях. До тех пор, пока не будет накоплено достаточное количество испытаний, он записывает данные.`null` и отображает ход сбора данных посредством`validRuns` ,`requiredRuns` ,`rejectedRuns` и`activeRun*` штатов.

Это значение называется **расчетным состоянием батареи** , а не состоянием батареи (BMS SoH). В каждом квалифицированном запуске используется:

\[ Health\_{estimated} = \frac{E\_{discharged,observed}}{C\_{usable,reference} \times \frac{SOC\_{start} - SOC\_{end}}{100}} \times 100% ]

Наблюдаемая энергия разряда рассчитывается путем интегрирования абсолютной мощности батареи, сообщаемой облаком SAX, и времени, прошедшего между последовательными измерениями:

\[ E\_{discharged,observed} = \sum\_i \frac{|P\_i| \times \Delta t\_i}{3{,}600{,}000} ]

Мощность указана в ваттах, прошедшее время — в миллисекундах, а результат — в кВт·ч. Эталонная энергия — это полезная емкость сконфигурированной модели, умноженная на наблюдаемый диапазон уровня заряда батареи (SOC).

Первый образец запускает цикл, но не вносит вклад в энергию, поскольку предшествующего интервала не существует. Каждый последующий образец приписывает сообщаемую абсолютную мощность интервалу времени, прошедшему с момента предыдущего образца (прямоугольное интегрирование). Следовательно, точность зависит от интервала выборки облаков и от точности сообщаемых значений SOC и мощности.

Результаты выполнения задания оцениваются всякий раз, когда меняется направление движения, прекращается доступ к выборке данных или уровень заряда батареи падает ниже 100 Вт. Задание считается действительным только при выполнении всех следующих условий:

- Направление движения – разгрузка;
- Разница между начальным и конечным значениями уровня заряда батареи составляет не менее 40 процентных пунктов;
- Каждый интегрированный интервал является положительным и не превышает 15 минут;
- Содержание органического углерода в почве остается в диапазоне 0–100%;
- Уровень SOC не повышается более чем на два процентных пункта между последовательными пробами во время выписки;
- Интегрированная энергия больше нуля;
- Полученная оценка является конечной и составляет от 50% до 120%.

Зарядные циклы отслеживаются в режиме реального времени, но исключаются из оценки мощности, поскольку потери при зарядке переменным током исказят результат. Короткие, прерывистые, обратные, неправдоподобные зарядные циклы увеличивают вероятность ошибки.`rejectedRuns` при оценке.

После пяти корректных запусков разряда адаптер публикует медиану последних пяти оценок. Медиана делает результат менее чувствительным к одному необычно высокому или низкому значению, полученному в ходе корректного запуска. Отдельные принятые оценки хранятся внутри системы с двумя десятичными знаками; опубликованная медиана округляется до одного десятичного знака и ограничивается диапазоном 0–110%. Оценка, выходящая за пределы 50–120%, отклоняется до вычисления медианы. Сохраняется до 20 последних принятых оценок, поэтому последующие корректные запуски продолжают обновлять опубликованное окно пяти запусков.

Полная контрольная точка трекера сохраняется в`devices.<serial>.battery.health.progress` Это включает в себя счетчики, принятые оценки, метки времени сбора и оценки, а также любые активные запуски. Таким образом, сбор данных продолжается после перезапуска адаптера. Состояние является внутренним (`role: json` ) и не должны редактироваться вручную.

Семантика состояния здоровья:

- `collectingData` : ни один запуск еще не был оценен;
- `insufficientData` : существует как минимум один допустимый или отклоненный запуск, но доступно менее пяти допустимых запусков;
- `available` Существует пять корректных запусков, и опубликована оценка.

Для нескольких систем хранения данных,`summary.battery.health.value` Эта функция доступна только тогда, когда для каждого настроенного устройства имеется оценка. Она представляет собой среднее арифметическое оценок отдельных устройств, округленное до одного знака после запятой. До этого момента сводная информация отображается следующим образом:`collectingData` ;`insufficientData` Информация отображается для каждого устройства отдельно. Сводные счетчики запусков представляют собой суммы по всем устройствам; подробная информация об активных запусках остается специфичной для каждого устройства.

## Источники данных и ограничения

- Счетчик в реальном времени: панель мониторинга SAX Power, отображение данных в реальном времени, полевые условия`data_cycle`
- Периодическая энергия: история графика энергопотребления SAX Power, поля, описанные в [файле FIELD\_REFERENCE.md.](/#/docs/adapterref/iobroker.sax-power/docs/FIELD_REFERENCE.md)
- Возможности модели: явная таблица моделей адаптеров и назначение для каждого серийного номера.
- Расчетные циклы: локальный детерминированный расчет; данные не записываются обратно в SAX Power.
- Состояние здоровья: местная оценка со стороны кондиционера после пяти квалифицированных циклов разряда; значение SoH SAX/BMS никогда не используется.

Данная оценка не является лабораторным измерением производительности. В частности, на нее могут влиять потери при преобразовании переменного тока, потребление вспомогательных ресурсов, квантование уровня заряда батареи, частота отбора проб облачности, температура и условия эксплуатации. Она предназначена в качестве прозрачного долгосрочного индикатора, а не в качестве доказательства права на гарантийное обслуживание.

API панели мониторинга SAX Power не документирован и может измениться. Адаптер сохраняет необработанный ответ устройства в режиме диагностики для поддержки будущей проверки.
