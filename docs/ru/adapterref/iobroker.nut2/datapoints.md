# Точки данных

Адаптер не поставляется с фиксированным списком параметров. Он запрашивает у сервера NUT информацию о том, что сообщает ваш ИБП (источник бесперебойного питания). `LIST VAR`), и строит дерево на основе ответа — поэтому две разные модели UPS приводят к двум разным деревьям. Далее объясняются части, которые всегда остаются неизменными, и как переменная NUT становится точкой данных ioBroker.

Каждая точка данных, название которой еще не говорит само за себя, сопровождается кратким пояснением. `common.desc` Списки значений, тексты состояния и уровни серьезности отображаются на языке вашей системы ioBroker.

## Преобразование названия нуклеотидной единицы в идентификатор объекта.

В NUT переменные обозначаются точками: `battery.charge.low` ioBroker использует точки для своей иерархии, поэтому адаптер это отражает:

- **Первая** точка разделяет канал —`battery`
- Каждая последующая точка заменяется дефисом —`charge-low`

`battery.charge.low` Эта земля находится под `ups0.battery.charge-low` и команда `test.battery.start` под `ups0.commands.test-battery-start` Переменная без точки не имеет канала и размещается непосредственно под устройством.

Адаптер сохраняет фактическое имя NUT внутри себя, так что операция записи отправляет правильное имя обратно на сервер — даже если сопоставление необратимо (например, трехфазные имена...). `input.L1-L2.voltage` (они сами содержат дефис).

## точки данных ширины адаптера

| Точка данных           | Значение                                                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `info.connection`      | Адаптер взаимодействует с сервером NUT. Это ничего не говорит об учетных данных для входа.                                           |
| `info.upsTotal`        | Сколько источников бесперебойного питания (ИБП) предлагает сервер?                                                                   |
| `info.upsReachable`    | Сколько из них ответили на последний вопрос?                                                                                         |
| `info.allUpsReachable` | Одно значение вместо каждого устройства. **Неверно** , если ничего не было обнаружено вообще — «0 из 0» не означает «все в порядке». |
| `notify`               | Записываемый триггер. Каждая операция записи немедленно активируется; см. часто задаваемые вопросы.                                  |

## Каждый ИБП

Каждый ИБП, подключенный к серверу, становится устройством. Его название происходит от... `desc`, который вы в `ups.conf` сервером; без такой настройки адаптер получает информацию о производителе и модели непосредственно от ИБП.

### `info`

| Точка данных | Значение                                                                                                                                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `reachable`  | Этот ИБП ответил на последний запрос. Значение также отображает символ "в сети" в объекте устройства и изменяется на false, когда адаптер останавливается — остановленный адаптер не должен продолжать работу, указывая на то, что все в порядке. |
| `notify`     | Последнее событие upsmon, связанное с этим ИБП.                                                                                                                                                                                                   |

### `status` — оцененное состояние

NUT сообщает о состоянии ИБП в виде последовательности аббревиатур, например: `OL CHRG` Это затрудняет работу с ним в скрипте, поэтому адаптер упрощает задачу:

| Точка данных           | Значение                                                                                                                                                                                                                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `raw`                  | Исходная строка без изменений.                                                                                                                                                                                                                         |
| `display`              | Та же информация, что и в виде читаемого текста на вашем языке, например, «Работа сети, Загрузка».                                                                                                                                                     |
| `severity`             | Одна цифра, от 0 до 4, или пустое поле (см. ниже).                                                                                                                                                                                                     |
| 19 значений истинности | По одному для каждого известного флага состояния: `online`, `onBattery`, `lowBattery`, `charging`, `discharging`, `replaceBattery`, `overloaded`, `bypass`, `calibrating`, `forcedShutdown`, `alarm`, `ecoMode`, `testing`, `overheat` и многое другое. |

`charging` и `discharging` также будет изготовлено из `battery.charger.status` заряжен, потому что некоторые модели ИБП отображают уровень заряда там, а не с помощью флажков. `CHRG` /`DISCHRG`.

Сокращение, которое адаптер не распознает, **не** теряется — оно остается в коде. `raw` и `display` видимо. Спецификация NUT явно разрешает драйверам использовать собственные сокращения, и было бы целесообразно придумать для каждого из них значение истинности.

#### Уровни тяжести

| Уровень | Значение              | Запущено по                                   |
| ------- | --------------------- | --------------------------------------------- |
| 0       | ХОРОШО                | В сети                                        |
| 1       | информация            | Напряжение понижается/повышается, калибровка. |
| 2       | предупреждение        | Батарея, замена батареи, обход                |
| 3       | Критический           | Батарея **и** слабый заряд батареи            |
| 4       | Чрезвычайная ситуация | Принудительное отключение                     |
| пустой  | —                     | В статусе отсутствует источник питания.       |

Уровень серьезности описывает только **ситуацию с электропитанием** . Флаги неисправности, такие как... `overloaded`, `alarm` и `off` Они намеренно не поднимают этот вопрос — у них свои собственные значения истинности, и их включение означало бы, что одно число означало бы две разные вещи. Статус, в котором даже не упоминается источник питания (`OFF` один, `WAIT` (При запуске драйвера, если PDU не отображает статус) уровень серьезности остается пустым вместо указания «OK».

### Измерительные каналы

Наличие тех или иных вариантов полностью зависит от вашего водителя ИБП:

| канал     | Содержит                                                                                                                                                |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `battery` | Заряд, оставшееся время работы, напряжение, тип, температура                                                                                            |
| `device`  | Производитель, модель, серийный номер, тип устройства                                                                                                   |
| `driver`  | Какой драйвер NUT используется для этого ИБП, его версия и параметры.                                                                                   |
| `input`   | Что поступает из сети — напряжение, частота, пороги переключения.                                                                                       |
| `output`  | Что выдает ИБП — напряжение, частота, ток.                                                                                                              |
| `ups`     | Сам ИБП — нагрузка, мощность, температура, задержки, обратный отсчет.                                                                                   |
| `outlet`  | Переключаемые выходы и группы выходов, если модель их имеет.                                                                                            |
| `ambient` | Датчики окружающей среды, если они предусмотрены источником бесперебойного питания (ИБП) или подключенным устройством электромагнитного импульса (ЭМИ). |

Значения хранятся в том виде, в котором они есть на самом деле: числа с единицами измерения (В, Гц, А, Ач, %, Вт, ВА, с, мин, °C, °), ответы «да/нет» в виде значений истинности, фиксированные словари (`enabled` /`disabled` /`muted`, `charging` /`discharging` /…) в виде списков выбора. Измерение, поступившее без числа, остается числовой точкой данных и **пустым** : Водители пишут слова, например: `LoadTooLow` или `NA` в него (или вообще ничего), то есть «никакого измеренного значения» — состояние, а не ошибка. Все остальное, что не является числом, например... `26,9` Если поставить запятую —, поле останется пустым с предупреждением, вместо того чтобы быть сохраненным как мусор; ни одна диаграмма не может ничего сделать с текстом.

Обратный отсчет (`ups.timer.shutdown` (и родственные элементы) остаются **пустыми** , пока не запущен обратный отсчет. Водители сообщают об этом по-разному — некоторые сообщают `-1` остальные — это слово `NotActive` —, и ни фраза «минус одна секунда», ни опечатка не подойдут.

### `commands`

ИБП предоставляет одну кнопку на каждую команду — она создается только в том случае, если включена функция **«Активировать мгновенные команды»** _и_ сохранены данные доступа. Одно нажатие кнопки отправляет сообщение. `INSTCMD` и перезагружается. ИБП без команд не получает канал. `commands` Клавиша, команда которой больше не отображается в списке драйверов, будет удалена.

`commands.execute` выполняет команду **со значением** , записанным как в `upscmd`: `load.off.delay 120` Действуют те же правила, что и для ключей, а значение представляет собой одно слово.

Предупреждающий символ в начале объявления обозначает любую команду, которая может отключить питание подключенных устройств, оставить их без защиты или завершить работу драйвера NUT: выключение или перезапуск нагрузки, розетки или группы розеток, каждая из которых... `shutdown.*` кроме `shutdown.stop`, `bypass.start`, `experimental.bypass.ecomode.start`, `input.off` команды драйвера, завершающие работу драйвера, и запись в необработанный регистр. `experimental.ve-direct.set` Включение чего- **либо** никогда не обозначается опознавательными знаками.

## Кому принадлежат эти предметы?

Имя, описание, тип, роль и единица измерения всех точек данных принадлежат адаптеру — любое переименование в дереве объектов сбрасывается во время следующей синхронизации. Исключением являются ваши **настройки записи** , а также **назначения помещений и функций** : они принадлежат вам, никогда не затрагиваются, и если адаптер переименовывает одну из своих собственных точек данных, обе точки данных переносятся вместе с ней.

Для каждого устройства отображается пиктограмма, обозначающая его тип в системе NUT (ИБП, блок распределения питания, контроллер заряда солнечной батареи, блок питания, выключатель); для типов устройств, которые не описаны в системе NUT, символ остается без изменений.

Источник бесперебойного питания (ИБП), исчезающий с сервера NUT, немедленно помечается как недоступный и теряет свои объекты после трех запросов без него — перезагрузки сервера или повторной загрузки. `ups.conf` Это не приводит к потере истории. При запуске адаптера ИБП, которого сервер не отображает в списке, немедленно удаляется.
