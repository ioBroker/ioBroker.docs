# Точки данных

Доступ: **\`r\` ** — только для чтения, **\`w\` ** — только для записи (одна команда), **\`rw\` ** отображает текущее значение и изменяет его при записи. Скорость указывается в МБ/с, размер — в ГБ, время — в миллисекундах — для каждой программы, независимо от используемой ею единицы измерения. Точка данных создается только там, где программа предоставляет значение: таблица под программой и уровнями загрузки показывает, какая программа имеет какую точку данных. `–` Это означает, что программа не располагает этим значением, и точка данных отсутствует. JDownloader 2 относится как к локальному интерфейсу, так и к My.JDownloader.

## `info` — адаптер

| Точка данных             | тип        | доступ | Значение                                                                        |
| ------------------------ | ---------- | ------ | ------------------------------------------------------------------------------- |
| `info.connection`        | логический | р      | По крайней мере одна программа для скачивания ответила на последний запрос.     |
| `info.programsTotal`     | число      | р      | Количество установленных и включенных программ для скачивания.                  |
| `info.programsOnline`    | число      | р      | Количество программ для скачивания, ответивших на последний запрос.             |
| `info.programsAllOnline` | логический | р      | Верно, если каждая настроенная программа загрузки ответила на последний запрос. |

## `summary` — по всем программам

| Точка данных                | тип               | доступ | Значение                                                                                                         |
| --------------------------- | ----------------- | ------ | ---------------------------------------------------------------------------------------------------------------- |
| `summary.downloading`       | логический        | р      | Да, это верно, пока загружается или обрабатывается любая программа.                                              |
| `summary.active`            | число             | р      | Загрузки, которые загружаются или редактируются во всех программах.                                              |
| `summary.queued`            | число             | р      | Загрузки, находящиеся в очереди, во всех программах.                                                             |
| `summary.downloadSpeed`     | количество (МБ/с) | р      | Суммарная скорость загрузки всех программ, для каждой из которых указано её последнее значение.                  |
| `summary.uploadSpeed`       | количество (МБ/с) | р      | Суммарная скорость загрузки всех торрент-программ, для каждой из которых указано актуальное значение.            |
| `summary.pauseAll`          | логический        | рв     | Значение True приостанавливает все доступные программы, значение False продолжает их выполнение.                 |
| `summary.last.finished`     | нить              | р      | Название последней завершенной загрузки; записывается при каждом завершении, даже если название остается тем же. |
| `summary.last.finishedTime` | число             | р      | Когда загрузка завершилась.                                                                                      |
| `summary.last.failed`       | нить              | р      | Название последней неудачной загрузки.                                                                           |
| `summary.last.failedTime`   | число             | р      | Когда загрузка не удалась.                                                                                       |

`summary.pauseAll` Эта функция возвращает true, если каждая программа, которую можно приостановить, была приостановлена во время последнего запроса. Пока программа недоступна, количество загрузок и общее количество сохраняют значения, которые она вернула в последний раз; только `online` и счетчики под `info.*` изменять.

## `<programm>-<stück>.downloads.<download>` — загрузка

Загрузка — это то, что вы добавили: пакет JDownloader или pyLoad, торрент, задание NZB, загрузка aria2, задача из Download Station или Freebox. Канал имеет название загрузки, и название каждой точки данных начинается с него. `ubuntu.iso: Fortschritt`), так что даже списки, отображающие только название, могут различать две загрузки.

| Точка данных  | тип               | доступ | Значение                                                                                                                                                                          |
| ------------- | ----------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `status`      | нить              | р      | Одно из значений статуса, указанных ниже.                                                                                                                                         |
| `progress`    | число (%)         | р      | Прогресс.                                                                                                                                                                         |
| `size`        | число (ГБ)        | р      | Размер; пусто, пока программа его не знает (магнит без метаданных).                                                                                                               |
| `downloaded`  | число (ГБ)        | р      | Загружено.                                                                                                                                                                        |
| `speed`       | количество (МБ/с) | р      | Скорость.                                                                                                                                                                         |
| `uploadSpeed` | количество (МБ/с) | р      | Скорость загрузки.                                                                                                                                                                |
| `ratio`       | число             | р      | Сумма загруженных данных, деленная на сумму скачанных данных; `-1` = бесконечность (∞).                                                                                            |

## Значения статуса

Ценность `status` Этот же список применяется ко всем программам; дерево объектов отображает имя на вашем языке.

| Ценить           | Обозначение            | Значение                                                                                                                                                                           |
| ---------------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `queued`         | Ждать                  | Оно находится в очереди программы.                                                                                                                                                 |
| `downloading`    | Загрузка               | Загрузка.                                                                                                                                                                          |
| `waiting`        | Прогресса нет          | Предполагается, что файл должен загрузиться, но загрузка не продвигается — время ожидания или капча на хостинге, торрент без аналогов, NZB-файл, который всё ещё распространяется. |
| `paused`         | Остановлено            | Остановлено либо вами, либо программой.                                                                                                                                            |
| `checking`       | Проверено              | Программа проверяет или подготавливает данные — проверяет торренты, метаданные, резервирует место для хранения, проверяет хеш.                                                     |
| `postprocessing` | Будет отредактировано  | Загружено; программа восстанавливает, распаковывает или перемещает его.                                                                                                            |
| `seeding`        | Будет перераспределено | Завершено, и файл распространяется среди других пользователей (через торренты).                                                                                                    |
| `completed`      | Готовый                | Полный.                                                                                                                                                                            |
| `failed`         | Неуспешный             | Программа прекратила своё существование — причина в... `error`, где программа указывает один из вариантов.                                                                         |

`summary.downloading`, `downloading` программы и счетчиков `active` считать `downloading` и `postprocessing`.
