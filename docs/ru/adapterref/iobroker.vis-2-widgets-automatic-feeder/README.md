## Виджеты vis-2 для автоматической подачи корма

Готовый **виджеты панели управления vis-2** для
[ioBroker.automatic-feeder](https://github.com/ssbingo/ioBroker.automatic-feeder) Адаптер — карточки с функцией перетаскивания для кормушки для рыб/карпов кои/прудовых кормушек. Есть **Не нужно искать идентификаторы объектов и писать HTML-код.**&#x412;ы выбираете экземпляр фидера и переключатель фидера. **благодаря своему дружелюбному названию** из выпадающего списка, и каждый виджет самостоятельно считывает и управляет нужными точками данных.

Этот пакет отправляется **шесть виджетов** Вместе они образуют полноценную панель управления, выполненную в темном, удобном для планшетов дизайне в виде карточек с акцентным цветом, который можно изменить. Всего четыре виджета. _отображать_ данные; два также позволяют вам _действовать_ (Запустить разовое кормление или приостановить кормление).

(В более широком семействе «умных прудов» есть родственный продукт) _аэрация пруда_ Например, адаптер может приостанавливать аэрацию во время подачи корма — но это настраивается там, а не здесь.

## 1. Что такое виджеты vis-2?

**вис-2** ioBroker — это современный инструмент визуализации (преемник классической версии). _вис &#x31;_&#x41F;анели мониторинга («представления») создаются путем перетаскивания. **виджеты** — кнопки, индикаторы, карточки — на холсте и связывайте их с состояниями вашего устройства.

Обычно связь виджета с состоянием устанавливается вручную: для этого используется идентификатор объекта (например, такой:
`automatic-feeder.0.switches.sw-0.status.feedingActive`) и введите его в поле привязки. Это подходит для одного значения, но для хорошей карты-податчика требуется дюжина таких карт, работающих вместе.

А **набор виджетов** Вот, например, это решает данную проблему: это дополнение, которое поставляется в комплекте. **специально разработанные виджеты** Для одного адаптера. Каждый виджет уже знает, какие состояния ему нужны. Вам нужно только указать ему. **какой корм** Чтобы показать — всё остальное уже настроено за вас. Так что вместо десятка ручных настроек вам не придётся ничего делать вручную. **два щелчка** (экземпляр + переключение) и получить готовую карту.

## 3. Требования

- **ioBroker** с **вис-2** Установлены (современные виджеты Vis). Это виджеты Vis-2, и они делают следующее: **нет** работа в классической визуализации 1.
- Он **ioBroker.automatic-feeder** адаптер, установлен и настроен с помощью **как минимум один переключатель** (Переключатель — это один из фидеров в конфигурации адаптера; у него есть понятное имя, например, _KoiTeich Ponto&#x6E;_&#x420;екомендуемые версии адаптеров:
  - **версия 1.4.0 или новее** — для числовых временных меток требуется следующее: `blockReasonCode` и `feedFor` команда, от которой зависят виджеты.
  - **версия 1.5.0 или новее** — рекомендуется, дополнительно обеспечивает прямую трансляцию **обратный отсчет времени выполнения** в FeederStatus ( `status.feedingEndsTs` точка данных).
  - **версия 1.6.0 или новее** — рекомендуется для точного отсчета времени с помощью кольца обратного отсчета. **Анимированный кормушка** (
    `status.feedingDurationSec` точка данных).

Вам никогда не придется вводить идентификатор объекта вручную: виджеты считывают и записывают только идентификатор выбранного переключателя. `status.*` и
`settings.*` Точки данных, полученные из выбранного вами экземпляра + переключателя.

## 5. Быстрый старт

1. В vis-2 переключитесь на **режим редактирования**Откройте окно просмотра и перетащите **FeederStatus** виджет из **Автоматическая подача**
   группа на него.
2. Выбрав виджет, откройте **Атрибуты** В правой панели заполните два поля. **общий**
   группа:
   - **Экземпляр фидера** — выберите свой `automatic-feeder` например (обычно) `0`(Это стандартный инструмент выбора экземпляра).
   - **Выключатель** — Выберите фидер из выпадающего списка. В нем перечислены настроенные вами коммутаторы. **по их дружелюбному имени**
     (например _KoiTeich Ponton_), считывается непосредственно из собственной конфигурации адаптера.
3. На карточке мгновенно отображаются данные в режиме реального времени. Повторите то же самое для любого другого виджета — выбор экземпляра/переключателя работает совершенно одинаково для всех шести.

Вот и всё: никаких идентификаторов объектов, никаких ручных привязок, никаких скриптов. Пока оба поля не будут заданы, виджет отображает понятное сообщение.

## 6. Виджеты подробно.

Для каждого виджета требуются одни и те же две настройки — **Экземпляр фидера** и **Выключатель** — в **общий** группа атрибутов (см. [Конфигурация и привязки](#7-configuration--bindings)). Параметры внешнего вида для каждого виджета указаны ниже. Все скриншоты показывают данные в реальном времени из кормушки для карпов кои.

### 6.1 Статус фидера

![виджет FeederStatus](../../../en/adapterref/iobroker.vis-2-widgets-automatic-feeder/img/feederstatus.png)

Главная карточка. Сверху вниз отображается:

- А **статус таблетка**: **Готовый** (зеленый) или **заблокировано** (янтарный). «Заблокировано» означает, что адаптер в данный момент не может подавать питание (ночь, слишком низкая температура, слишком низкий уровень кислорода, пауза и т. д.).
- Ан **анимированная графика кормушки**Во время подачи корма вентилятор вращается и — с адаптером версии 1.5.0+ — **обратный отсчет времени выполнения** (например `5 s`Рядом с ним появляется значок ) и начинается обратный отсчет до конца текущего кормления.
- Он **следующее кормление**большой обратный отсчет (_примерно за 27 минут_, или `1 h 05 min` последний час), точное время и режим (_динамический интервал_ когда включена динамическая подача, в противном случае _расписание_).
- Он **последнее кормление** с маркером ✓ (успех, зеленый) или ✗ (ошибка, красный) и адаптером **результат** текст.
- Он **астрономическое окно** (Восход – закат) используется для логики смены дня и ночи.
- При блокировке добавляется дополнительный **причина** строка с удобочитаемым обоснованием блока (выделено желтым цветом).

Карточка обновляется раз в секунду, поэтому обратный отсчет остается активным.

**Параметры внешнего вида** (группа _Появление_):

| Вариант                            | Тип                      | По умолчанию | Значение                                                                  |
| ---------------------------------- | ------------------------ | ------------ | ------------------------------------------------------------------------- |
| **Акцентный цвет**                 | цвет                     | `#33c1cf`    | Выделите цвет карточки и изображения.                                     |
| **Позиция таймера выполнения**     | выбрать (Вправо / Влево) | Верно        | Отобразите обратный отсчет времени кормления слева или справа от графика. |
| **Анимированная графика кормушки** | флажок                   | на           | Включить/выключить анимацию вращающегося вентилятора.                     |
| **Без фона карточки**              | флажок                   | выключенный  | Отобразить без фона карточки (чтобы разместить её на собственной панели). |

Размер виджета по умолчанию: 320 × 340 пикселей.

### 6.2 Управление подачей

![Виджет FeedControl](../../../en/adapterref/iobroker.vis-2-widgets-automatic-feeder/img/feedcontrol.png)

Плата управления:

- **Накормите сейчас** — а **двухшаговый** кнопка. Первый клик. _оружие_ и этикетка меняется на _Подтверждение: N s ?_; второй щелчок срабатывает точно **один** кормление выбранной продолжительности и краткое описание процесса. _Запущено ✓_&#x415;сли вы не подтвердите это в течение примерно 4 секунд, устройство самоотключится.
- **Часть (ручная)** — ползунок, устанавливающий продолжительность кормления в секундах, из `1` до _Максимальная продолжительность_ (по умолчанию начинается с 5 секунд).
- **Приостановить кормление** — главный выключатель, который немедленно приостанавливает работу. **все** Подача сигнала на этот переключатель продолжается до тех пор, пока вы его не выключите. Это записывает данные адаптера. `settings.pauseNow`, что отменяет все режимы и все паузы, основанные на времени.

| **Показать переключатель паузы**       | флажок         | на           | Показать/скрыть главный _Приостановить кормление_ выключатель. |

### 6.4 Динамическая подача

![Виджет DynamicFeeding](../../../en/adapterref/iobroker.vis-2-widgets-automatic-feeder/img/dynamicfeeding.png)

Показывает **температурная модель Q10** Адаптер используется для регулировки подачи воды в зависимости от её температуры. Четыре плитки:

- **Средняя температура** — средняя температура, на основе которой построена модель (°C).
- **Ставка (Q10)** — результирующий коэффициент скорости (× относительно эталонной температуры).
- **Интервал** — результирующий интервал кормления в минутах.
- **Часть** — результирующая продолжительность кормления в секундах.

### 6.5 Сезонный баннер

### 6.8 Настройки количества корма

Он **редактор** Для модели с регулировкой количества подаваемого вещества — панель настроек освещения, которая записывает данные непосредственно в записываемое пространство адаптера.
`switches.<id>.settings.*` штаты (потребности) **автоматическая подача v1.16.0+** для зеркала настроек, и **v1.17.0+** (для переключателя профилей фидов). Используйте его на панели управления рядом с панелью только для чтения. **Количество корма** карта.

Оно предлагает:

- а **модель включена/выключена** выключатель (`amountModelEnabled`);
- а **список рыб** с иконкой для каждого размера, фиксированным эталонным весом и редактируемым количеством для каждой размерной категории (15/20/30/40/50/60 см), с отображением в реальном времени. **общий вес**;
- ан **активный переключатель питания** Создается на основе профилей каналов, определенных вами для коммутатора в административной панели адаптера — одним касанием выбирается активный профиль (запись). `settings.activeFeed`) и скорость дозирования (г/с) определяет режим управления;
- семь **процентное содержание температуры** (`<15°` … `>30°`);
- а **управление включением/выключением** переключатель (фаза B) и, когда он включен, дополнительный **суточный максимум** в граммах.

Каждое поле в виджете обновляется мгновенно и записывается в адаптер, который применяет изменения и перезапускает экземпляр (с небольшим дребезгом), так что модель пересчитывается. Панель соответствует vis-2. **цветовой режим** (темный/светлый). Размер виджета по умолчанию: 470 × 620 пикселей.

## 10. Устранение неполадок и часто задаваемые вопросы

**В виджете отображается только надпись «Выберите канал переключения фидера…».**
Установите оба **общий** поля (экземпляр) _и_ (переключатель). Выпадающий список переключателя заполняется из выбранного экземпляра, поэтому сначала выберите экземпляр.

**Выпадающее меню переключателя пусто.**
Избранный `automatic-feeder` В экземпляре еще не настроены коммутаторы, или номер экземпляра указан неверно. Сначала настройте коммутатор в адаптере.

**Значения показывают `–`.**
Убедитесь, что адаптер **версия 1.4.0 или новее** (Версия 1.5.0 и выше для обратного отсчета во время выполнения). Более старые версии не предоставляют числовые метки времени и данные команд, на которые полагаются виджеты. **Глубокая вода** плиточные стойки `–` если только вы не установили второй, более глубокий датчик; **О₂** Таблетка скрыта, если не установлен датчик кислорода — оба варианта являются нормальными.

**Обратный отсчет времени выполнения так и не появляется.**
Для этого нужен адаптер. **v1.5.0+** (`status.feedingEndsTs`) и отображается только _во время фактического кормления_.

**Кольцо обратного отсчета AnimatedFeeder не совсем пропорционально.**
Для этого кольца нужен адаптер. **v1.6.0+** (`status.feedingDurationSec`); В случае со старыми адаптерами продолжительность оценивается по времени начала кормления, поэтому кольцо является приблизительным.

**Новые/обновлённые виджеты не отображаются, или видны только некоторые из них.**
Это почти всегда устаревший пакет виджетов в браузере/запуске. Запуск
`iobroker upload vis-2-widgets-automatic-feeder`Перезапустите vis-2 (или хост) и выполните принудительное обновление страницы в браузере (Ctrl+F5).

**Заменяет ли это адаптер?**
Нет. Это только виджеты панели управления. Все настройки расписания, логика работы с температурой, паузы и уведомления находятся в самом меню.
**ioBroker.automatic-feeder** адаптер; виджеты представляют собой одновременно и интерфейс для просмотра, и пульт управления для него.

* (ssbingo) **FeedingAmountSettings** now selects the active feed from the adapter's **central feed list** (`native.feeds`) via a dropdown, written id-based to `settings.activeFeed` — replacing the deprecated per-switch feed profiles (needs **automatic-feeder v1.18.0+**). **FeedingAmount** additionally shows the active feed's pellet size (`status.activeFeedSize`)

### 0.4.2 (2026-09-01)
* (ssbingo) **FeedingAmountSettings** now has an **Accent colour** option (Appearance group), just like the FeedingAmount widget — the accent drives the toggles, active borders and highlighted values, so both widgets can be given the same accent for a consistent design. In light mode the accent is darkened for readable text; in dark mode it is used directly

### 0.4.1 (2026-09-01)
* (ssbingo) **FeedingAmountSettings** now follows the vis-2 **colour mode** (dark/light) like the other widgets — it reads `context.themeType` and renders a dark panel in dark mode and the light panel in light mode (previously it was always light)
* (ssbingo) The **No card background** option of FeedingAmountSettings now actually works (transparent background) instead of doing nothing

### 0.4.0 (2026-09-01)
* (ssbingo) New separate **FeedingAmountSettings** widget — a light settings panel matching the agreed design: a model on/off switch, a fish list with per-size icons + reference weights and editable counts (with a live total weight), the seven temperature percentages, a Phase-B control switch and the optional daily maximum. All fields write to the adapter's writable `switches.<id>.settings.*` states (**automatic-feeder v1.16.0+**)
* (ssbingo) FeedingAmountSettings has an **active-feed switcher** built from the feed profiles configured for the switch in the adapter admin; one tap selects the active profile and its dispense rate (writes `settings.activeFeed`, needs **automatic-feeder v1.17.0+**)
* (ssbingo) The **FeedingAmount** widget is now purely a **read-only** display card again; all editing moved to the new FeedingAmountSettings widget. It also shows the active feed-profile name (`status.activeFeedName`)

### 0.3.2 (2026-09-01)
* (ssbingo) Housekeeping: keep only the latest 7 entries in `common.news` (repository checker W1032). No widget changes

### 0.3.1 (2026-09-01)
* (ssbingo) Housekeeping (repository checker): bumped `@alcalzone/release-script-plugin-license` to 5.2.2 (S0064), removed the unneeded `prepublishOnly` script (W0095) and the unnecessary **admin** dependency — this is a pure widget set with no admin config UI (S1091) — and unpinned the CI deploy action to `@v1` (S3044). No widget changes

### 0.3.0 (2026-09-01)
* (ssbingo) New widget **FeedingAmount**: shows the adapter's feeding-amount model for a switch — recommended daily ration, the feeding percentage for the current water temperature, estimated total weight and, in control mode, the per-feeding portion and motor run-times. It uses the adapter's `status.feedTargetPortionGrams` / `status.feedingsPerDayToday` for an exact per-feeding amount (**automatic-feeder v1.16.0+**)
* (ssbingo) The FeedingAmount widget is **editable**: an *Edit* toggle lets you change the fish counts, the temperature percentages, the Phase-A/B switches and the dispense rate; the changes are written to the adapter's writable `switches.<id>.settings.*` states (needs **automatic-feeder v1.16.0+** for the amount-model settings mirror)

### 0.2.1 (2026-07-07)
* (ssbingo) Fixed **AnimatedFeeder** showing nothing in Firefox: the built-in feeder image now uses a base64 data URI (Firefox rejects the non-standard `;utf8,` form that Chrome tolerated) and the canvas 2D context is initialised from the `<canvas>` ref callback, so it binds reliably regardless of mount order. A failed or zero-size custom image can no longer blank the whole widget

### 0.2.0 (2026-07-07)
* (ssbingo) New sixth widget **AnimatedFeeder**: a large animated feeder (canvas) with falling pellets, a countdown ring and pause symbols (manual / time-based / winter); tap it to trigger a one-off feeding. The exact countdown ring uses the adapter's new `status.feedingDurationSec` (**automatic-feeder v1.6.0+**)
