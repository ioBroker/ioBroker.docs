# Стол

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/table.md)

Встроенная таблица VIS 2 для строк JSON с настраиваемыми индексированными столбцами. Идентификатор шаблона:`tplVis2-materialdesign-Table` .

<img src="../../media/vis2_table_runtime.png" alt="Material Design table in VIS 2">

## Настройки редактора

На скриншотах показаны общие/макетные группы и один индексированный столбец. Настройки, не указанные ниже, понятны сами собой. Пользовательский интерфейс редактора соответствует системному языку ioBroker, поэтому скриншоты сделаны на немецком языке.

<img src="../../media/vis2_table_editor_overview.png" width="340" alt="Table general and layout options">

**Общий**

- **Идентификатор объекта** — состояние, значение которого представляет собой JSON-массив строк.
- **Данные в формате JSON** — те же данные, которые вводятся непосредственно в виде текста, если состояние их не содержит. Идентификатор объекта имеет приоритет сразу после его установки.
- **количество столбцов** – количество групп индексированной **компоновки столбцов \[n]** .

**макет**

- **Схема расположения столов** –`standard` ,`card` или`cardOutlined` (Карточка с контуром вместо тени).
- **show row heading** – строка заголовка, содержащая метки столбцов.
- **Фиксированный заголовок таблицы** – строка заголовка остается на месте при прокрутке.
- **Закругленные края** – закругленные углы; в выключенном состоянии рамка остается квадратной.
- **Высота заголовка строки / размер текста заголовка строки / семейство шрифтов заголовка строки** – применяются только к строке заголовка, **высота строки** применяется только к строкам данных.

**цвета**

- **Цвет фона в строке / цвет фона в нечетной строке** – если задан второй цвет, они чередуются по строкам; если оставить поле пустым, первый цвет будет применяться ко всем строкам.
- **Цвет фона строки при наведении курсора мыши** – цвет строки под указателем мыши.
- **Разделительная линия** — линия между рядами; последний ряд не разделяется.
- **Цвет рамки** – обрамление стола.

Каждый столбец настраивается в собственной индексированной группе **расположения столбцов \[n]** :

<img src="../../media/vis2_table_editor_2.png" width="340" alt="Indexed table column options">

- **Функция «Показать столбец»** — если она отключена, столбец удаляется без перенумерации оставшихся.
- **Метка** — текст заголовка столбца. Она только указывает название столбца, но не определяет, какое именно свойство JSON будет отображаться в этом столбце.
- **тип столбца** –`text` или`Image` . С`Image` Значение ячейки представляет собой URL-адрес, а **размер изображения** ограничивает его ширину.
- **Имя объекта для сортировки** – свойство JSON, по которому выполняется сортировка при щелчке по заголовку этого столбца. Если оставить поле пустым, будет использоваться свойство, отображаемое самим столбцом. Второй щелчок изменит направление сортировки на противоположное.
- **Ширина столбца (перенос текста должен быть активен) / выравнивание текста / без переноса текста** – изменение размера столбца и поведение текста.
- **Префикс/суффикс** — текст, добавляемый вокруг значения ячейки. Оба варианта могут содержать`#[obj.name]` который заменяется`name` имущество в том же ряду.

Столбцы представляют собой свойства **первой** строки в указанном порядке: **расположение столбцов \[0]** показывает первое свойство, **\[1]** — второе и так далее.

```json
[{ "device": "Temperature", "room": "Living room", "value": "22.4 °C" }]
```

Каждая последующая строка считывается по этим столбцам: если свойство строки отсутствует, ячейка в ней остается пустой, и остальные столбцы не сдвигаются.

В таблице отображается только содержимое этого JSON. Чтобы перечислить отдельные состояния друг под другом без предварительного создания JSON, можно использовать [список](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/list.md) с привязками в текстах строк (см. раздел [«Отображение значений внутри текстов»)](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md#show-values-inside-texts) .
