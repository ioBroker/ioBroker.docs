# Флажок

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/checkbox.md)

Флажок, встроенный в VIS 2 Material Design, который считывает и записывает логические значения или пользовательские значения «вкл/выкл». Идентификатор шаблона:`tplVis2-materialdesign-CheckBox` .

<img src="../../media/vis2_checkbox_runtime.png" alt="Material Design checkbox in VIS 2">

## Настройки редактора

На скриншоте показаны две соответствующие группы ( **Общие** и **Метки** ) в развернутом виде. Настройки, не указанные ниже, понятны сами собой. Пользовательский интерфейс редактора соответствует системному языку ioBroker, поэтому скриншоты сделаны на немецком языке.

<img src="../../media/vis2_checkbox_editor_overview.png" width="340" alt="Checkbox editor options">

**Общий**

- **тип переключателя** –`boolean` читает и пишет`true` /`false` ;`Value` Вместо этого считывает и записывает **значение для выключенного состояния** / **значение для включенного состояния** .`boolean` только строгий`true` Считается включенным, все остальное выключено.
- **укажите, если значение не равно условию «включено»** — применяется только к`Value` переключать:`on` рассматривает каждое значение, кроме выключенного, как включенное.`off` принимает только точное значение.
- **Вибрация на мобильных устройствах \[мс]** – длительность тактильной обратной связи при нажатии в миллисекундах (только для мобильных устройств), по умолчанию 50;`0` Отключает вибрацию.
- **Воспроизведение звука щелчка** / **Громкость звука щелчка** – тон щелчка при переключении, его громкость от 0 до 1 (по умолчанию 0,5).
- **Только для чтения** – отображает состояние, но никогда не записывает его.

**Этикетка**

- **Метка false / Метка true** – текст, отображаемый рядом с полем в выключенном/включенном состоянии.
- **Положение метки** – слева, справа или вне поля зрения.
- **Активировать щелчок по метке** — позволяет щелчку по метке изменять значение, а не только по полю. Включено по умолчанию.
- **Value font / Value font size** – шрифт метки.

Группа параметров « **Цвета»** управляет **цветом флажка** , **цветом границы** , **цветом при наведении курсора на флажок** , **цветом метки** и **цветом активной метки** .

**Функция «Блокировка»** накладывает блокировку на виджет: **«Включить блокировку» включает** её, щелчок по значку разблокирует, а **«Автоматическая блокировка через \[с]»** (по умолчанию 10) снова блокирует. **«Серый фильтр при блокировке** (по умолчанию 30 %)» делает заблокированный виджет менее заметным; для его **значка** можно выбрать значок или изображение, а **расстояние от символа до верхнего/левого угла \[%]** позволяет его разместить.

<img src="../../media/vis2_checkbox_editor_lock.png" width="340" alt="Locking group icon field">

## Стиль дизайна

**Классический** (слева) и **Material 3** (справа) стили расположены рядом, см. [раздел «Стиль дизайна](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md#design-style) : флажок и переключатель: выключено, включено, метка слева, только для чтения, заблокировано, определенный цвет и галочка Material 3 внутри ручки переключателя».
