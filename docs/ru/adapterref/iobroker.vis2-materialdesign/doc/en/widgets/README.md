# Каталог виджетов

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/README.md)

Выберите виджет по задаче. Видимые в редакторе варианты намеренно остаются отдельными, чтобы каждый виджет было легко найти и настроить.

Исторические идентификаторы шаблонов остаются неизменными для существующих проектов. Названия, такие как...`Adition` ,`Vuetify` или`view-in-widget8` Не описывают текущие зависимости и не должны изменяться.

Каждый параметр, указывающий на **количество элементов** — наборы данных, пункты меню, столбцы, элементы списка, значения выбора, идентификаторы объектов, представления — является счетчиком: 3 дает три записи в группах от \[0] до \[2]. VIS 1 хранил там последний индекс, где 3 означало четыре записи, поэтому проверьте значение один раз при перестроении виджета VIS 1.

## Переключитесь и навигируйте

- [Кнопки](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/buttons.md) — открывают представление или ссылку, или задают состояние.
- [Вертикальное расположение кнопок](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/buttons-vertical.md) – те же действия при вертикальном расположении.
- [Кнопки с иконками](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/icon-buttons.md) – компактные действия, выполняемые только с помощью иконок.
- [Флажок](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/checkbox.md) — переключатель логических или пользовательских значений включения/выключения.
- [Переключатель](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/switch.md) – управляет состоянием как переключателем.

## Введите значения

- [Ввод](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/input.md) – ввод текста или чисел
- [Выбор и автозаполнение](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/select.md) – выберите значение из списка
- [Ползунок](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/slider.md) — изменение числового значения по горизонтали или вертикали.
- [Круглый ползунок](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/slider-round.md) — изменение числового значения на круглом элементе управления.

## Отображение значений и содержимого

- [Значение](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/value.md) – отображение одного отформатированного состояния
- [HTML-карточка](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/html-card.md) – сочетание заголовка, текста, изображения и действия.
- [Прогресс](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/progress.md) – отображение значения в виде линейного прогресса.
- [Круговой индикатор прогресса](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/progress-circular.md) – отображение значения в виде кругового индикатора прогресса.
- [Иконки и вспомогательные инструменты Material Design](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/material-design-icons-and-images.md)

## Отображение данных

- [Список](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/list.md) – строки с текстом, кнопками, переключателями или флажками.
- [IconList](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/iconlist.md) – значки, зависящие от состояния, в виде сетки.
- [Таблица](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/table.md) – строки JSON в столбцах
- [Диаграммы](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) – столбчатые, круговые, JSON или линейные.
- [Календарь](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/calendar.md) – события в формате JSON с отображением месяца, недели или дня.
- [Оповещения](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/alerts.md) – отображение и подтверждение очереди сообщений.

## Виды и расположение

- [Верхняя панель приложений](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/top-app-bar.md) – навигация с помощью панели приложений и выдвижного меню.
- [Адаптивная верстка](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/responsive-layout.md) – несколько вариантов отображения в режиме кирпичной кладки или сетки.
- [Расширенный режим просмотра в виджете](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/html-widgets.md) — выберите один дочерний виджет по состоянию.
