# HTML-карточка

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/html-card.md)

Карточка Material Design, созданная на основе VIS 2, с заголовком, подзаголовком, основным текстом, изображением и дополнительной ссылкой или действием записи состояния. Идентификатор шаблона:`tplVis2-materialdesign-Card` .

<img src="../../media/vis2_html_card_runtime.png" alt="Material Design card in VIS 2">

## Настройки редактора

На скриншотах показаны группы макетов/изображений и группа действий с карточками. Настройки, не указанные ниже, понятны сами собой. Пользовательский интерфейс редактора соответствует системному языку ioBroker, поэтому скриншоты на немецком языке.

<img src="../../media/vis2_html_card_editor_overview.png" width="340" alt="Card layout and image options">

**Общий**

- **Метод ввода данных списка** –`via editor` (заголовок, подзаголовок, текст и изображение отображаются непосредственно в полях) или`JSON string` (В одном штате они есть).
- **JSON-строка: идентификатор объекта** – состояние объекта`JSON string` метод. Его значением является объект, содержащий`title` ,`subTitle` ,`body` и`image` Если JSON-данные недействительны, вместо заголовка на карточке отображается красное сообщение об ошибке.
- **макет** -`Basic` (изображение сверху, заголовок снизу),`BasicHeader` (заголовок над изображением),`BasicHeaderOverlay` (заголовок внутри изображения) или`Horizontal` (изображение слева).
- **стиль** –`default` или`outlined` (контур вместо тени).
- **show scrollbar** – позволяет прокручивать текстовый раздел, если он выше карточки.

**заголовок / текст**

- **Показать заголовок / Показать подзаголовок / Показать текст** – скрыть три раздела по отдельности.
- **Заголовок / Подзаголовок / HTML** – содержимое. Они принимают HTML и привязки, см. [раздел «Показ значений внутри текста»](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md#show-values-inside-texts) . Используйте только проверенный HTML.
- **Размер шрифта заголовка / размер текста** – в соответствии с принципами типографики Material Design, а не фиксированными значениями в пикселях.
- **Высота подзаголовка / высота текста** – фиксированная высота для этого раздела.

**изображение**

- **Изображение** – источник изображения (путь, URL или URL данных).
- **Идентификатор объекта для обновления** — при изменении этого состояния изображение перезагружается. Это работает только для URL-адреса или абсолютного пути, а не для URL-адреса данных.
- **Задержка обновления по идентификатору объекта** – ожидание в миллисекундах перед перезагрузкой, максимум 180000.
- **Длительность анимации обновления в зависимости от идентификатора объекта** – длительность плавного перехода.
- **Обновление после пробуждения / обновление при изменении вида** – дополнительные триггеры перезагрузки.

Группа **действий с карточкой** делает карточку кликабельной:

<img src="../../media/vis2_html_card_editor_2.png" width="340" alt="Card action options">

- **Область, на которую можно нажать** –`none` Отключает действие; все остальные настройки (`card` ,`Image` ,`text` ) делает всю карточку кликабельной.
- **действие по клику** –`link` открывает **URL-адрес** в новой вкладке.`state` Записывает **значение, которое необходимо записать** в **идентификатор объекта для выполнения действия** .
