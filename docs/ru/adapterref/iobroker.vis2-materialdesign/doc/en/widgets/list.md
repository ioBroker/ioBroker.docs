# Список

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/list.md)

Настраиваемый список VIS 2 с текстовыми строками, кнопками, переключателями или флажками. Строки могут поступать из индексированных полей редактора или из состояния JSON. Идентификатор шаблона:`tplVis2-materialdesign-List` .

<img src="../../media/vis2_list_runtime.png" alt="Material Design list in VIS 2">

## Настройки редактора

На скриншотах показаны группы, относящиеся ко всему списку, и одна индексированная строка. Настройки, не указанные ниже, понятны сами собой. Пользовательский интерфейс редактора соответствует системному языку ioBroker, поэтому скриншоты на немецком языке.

<img src="../../media/vis2_list_editor_overview.png" width="340" alt="List layout and data options">

**структура списка**

- **Тип списка** – применяется ко всем строкам:`text` ,`Button State` ,`toggle Button` ,`toggle Button (read only)` ,`Button Navigation` ,`Button Link` ,`switch` ,`Switch (read only)` ,`checkbox` или`checkbox (read only)` Варианты, доступные только для чтения, отображают состояние, но ничего не записывают.
- **макет** -`standard` ,`card` или`cardOutlined` .
- **стиль разделителя** –`standard` ,`padded` или`inset` .

**заголовок списка**

- **Заголовок** — заголовок над списком, имеющий собственное выравнивание, высоту, отступы, цвет, шрифт и иконку. Если оставить поле пустым, заголовок не отображается.

**данные списка**

- **Метод ввода данных списка** –`via editor` (индексированные группы строк) или`JSON string` (Каждый ряд представлен одним штатом).
- **Редактор: количество элементов списка** – сколько существует индексированных групп строк.
- **JSON-строка: идентификатор объекта** – состояние, содержащее JSON-массив, только для`JSON string` метод.

Каждая строка имеет собственную индексированную **структуру группы элементов списка \[n]** :

<img src="../../media/vis2_list_editor_2.png" width="340" alt="Indexed list item entry">

- **oid** – состояние, управляемое строкой (переключатель, флажок, кнопка). Оно не отображает значение — для этого добавьте привязку к одному из текстов, см. раздел [«Отображение значений внутри текстов»](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md#show-values-inside-texts) .
- **Заголовок** – сгруппировать заголовки над этой строкой, чтобы разделить список на разделы.
- **Метка / второй текст / текст справа / второй текст справа** – четыре текста в ряду.
- **значок / цвет значка** и **активный значок / цвет активного значка** – значок строки, замененный для активного состояния. Без активного значка остается обычный.
- **разделитель** – разделитель под этой строкой.
- **Состояние кнопки: значение** – значение`Button State` строка записывает.
- **Навигация с помощью кнопок: Вид** – целевой вид`Button Navigation` ряд.
- **Ссылка на кнопку: URL** – адрес`Button Link` ряд.

С`JSON string` В этом методе состояние содержит массив объектов, ключи которых названы иначе, чем поля редактора:

```json
[{ "objectId": "0_userdata.0.light", "text": "Light", "subText": "Living room", "image": "lightbulb" }]
```

| Ключ                              | Поле редактора                          |
| --------------------------------- | --------------------------------------- |
| `objectId`                        | оид                                     |
| `text` /`subText`                 | Метка / второй текст                    |
| `rightText` /`rightSubText`       | текст справа / второй текст справа      |
| `image` /`imageColor`             | иконка / цвет иконки                    |
| `imageActive` /`imageActiveColor` | активный значок / цвет активного значка |
| `header`                          | заголовок                               |
| `showDivider`                     | разделитель                             |
| `buttonStateValue`                | Состояние кнопки: значение              |
| `buttonNavView`                   | Навигация с помощью кнопок: Вид         |
| `buttonLink`                      | Ссылка на кнопку: URL                   |

Ключи, оставленные без присмотра, останутся пустыми; без них`text` в строке написано`Item n` Все записи, превышающие 100, обрезаются, а в случае некорректного JSON вместо списка отображается красная строка с ошибкой.

## Стиль дизайна

**Классический** (слева) и **Material 3** (справа) стили расположены рядом (см. [раздел «Стиль дизайна»](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md#design-style) ): список с простым текстом, макет карточки и макет карточки с контуром, вставные разделители, ряды переключателей и флажков, а также список значков.
