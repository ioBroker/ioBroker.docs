# Расширенный просмотр в виджете

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/html-widgets.md)

Дочерний контейнер представления, который встраивает полные представления VIS 2 и выбирает одно из них из заданного состояния.

Идентификаторы шаблонов:`tplVis2-materialdesign-view-in-widget` и`tplVis2-materialdesign-view-in-widget8` .

<img src="../../media/vis2_html_widgets_runtime.png" alt="Embedded VIS 2 view">

## Настройки редактора

На скриншоте показана группа **«Общие»** . Настройки, не указанные ниже, понятны сами собой. Интерфейс редактора соответствует системному языку ioBroker, поэтому скриншоты сделаны на немецком языке.

<img src="../../media/vis2_html_widgets_editor_overview.png" width="340" alt="Advanced view in widget general options">

**Общий**

- **Идентификатор объекта** — состояние, значение которого определяет встроенное представление. Для`view-in-widget` Значением является **имя** представления (строка, точно такое же, как в редакторе);`view-in-widget8` это **индекс**`0 … n` из представлений, настроенных ниже (число,`true` /`false` считать как`1` /`0` ).
- **Длительность появления/исчезания \[мс] / длительность исчезновения \[мс]** – переход при переключении между представлениями, по умолчанию 50 мс для каждого.

`view-in-widget` только (представление формируется на основе значения состояния):

- **эффект затухания** –`swing` (по умолчанию) или`linear` Оба значения в редакторе не переведены.
- **Отображение всех представлений** одновременно с **представлениями, отображаемыми при загрузке,** позволяет предварительно смонтировать дополнительные представления: количество открываемых полей **представления** в группе **предварительной отрисовки** равно этому числу. Без этого переключателя список не имеет никакого эффекта, и монтируется только выбранное представление.
- **Скрыть сообщение об ошибке** — подавляет сообщение "Ошибка: представление не найдено". Когда состояние указывает на отсутствие представления, виджет просто остается пустым.

`view-in-widget8` только (изображение формируется из списка):

- **количество представлений** – сколько полей **представления** открывает группа **представлений** . Значение состояния — это индекс именно в этом списке.
- **Функция keep loaded** – все настроенные представления остаются смонтированными, что обеспечивает мгновенное переключение. Без нее отображается только выбранное представление.
- **Не в невидимом состоянии** — пока виджет скрыт, его представления отключаются, а не продолжают работать в фоновом режиме.

В случаях, когда необходимо одновременно разместить несколько дочерних элементов, используйте [адаптивный макет](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/responsive-layout.md) .

Обычно выбор представления осуществляется через меню: [верхняя панель приложения](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/top-app-bar.md) записывает индекс выбранного пункта меню, а затем`8` Вариант отображает соответствующее представление.
