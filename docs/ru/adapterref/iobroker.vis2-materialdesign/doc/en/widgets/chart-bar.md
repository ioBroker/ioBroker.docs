# Гистограмма

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) › [Диаграммы](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/chart-bar.md)

Сравнивает текущие значения в виде вертикальных или горизонтальных полос. Идентификатор шаблона:`tplVis2-materialdesign-Chart-Bar` .

## Источник данных

- **Ввод данных редактором:** каждый набор данных ссылается на собственное состояние. Количество наборов данных создает индексированные группы.
- **JSON-строка/объект:** Идентификатор объекта указывает на состояние, содержащее JSON-массив. Наборы данных и их представление берутся из этого состояния.
- **Тип диаграммы:** горизонтальная ось категорий и значений свопов; значения min/max по-прежнему применяются к оси значений.

При вводе данных редактором каждая группа наборов данных содержит идентификатор объекта, метку оси, необязательный цвет, текст замещающего значения и тексты всплывающих подсказок. При отсутствии фиксированных пределов оси виджет масштабируется автоматически и включает ноль.

## Настройки редактора

Интерфейс редактора соответствует системному языку ioBroker, поэтому скриншоты сделаны на немецком языке. Настройки, не указанные ниже, понятны сами собой.

<img src="../../media/vis2_chart_bar_editor.png" width="340" alt="Bar chart general and bar layout options">

- **Общие параметры** – источник данных (наборы данных редактора или одно состояние JSON), количество наборов данных, идентификатор объекта и **тип диаграммы** (вертикальная или горизонтальная). Для каждого набора данных редактора индексированная группа добавляет свой идентификатор объекта, метку оси, цвет и текст всплывающих подсказок.
- **Макет столбчатой диаграммы** – толщина и расстояние между столбцами.

<img src="../../media/vis2_chart_bar_editor_2.png" width="340" alt="Bar chart axis and tooltip options">

- **Ось Y** — заголовок оси, положение (слева/справа), линии сетки и видимость оси/метки. **Минимальное/максимальное** значение оси значений находится в группе «Макет диаграммы» (пустое значение = автоматическое масштабирование).
- **Всплывающая подсказка** — включите всплывающую подсказку и задайте ее цвета; для каждого набора данных.`tooltipText` Переопределяет сгенерированный текст.

Подписи значений на столбцах находятся в **разделе «Средства на столбчатой диаграмме» (** см. « [Значения, отображаемые на диаграмме»)](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md#values-drawn-on-the-chart) .

Здесь также применяются общие элементы **макета диаграммы** , **легенды** и группы цветовой схемы из [раздела «Диаграммы»](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) .

## формат JSON

Состояние должно содержать массив. При отсутствии значений в представлении используются цветовая схема и глобальные настройки виджета.

| Свойство        | Значение                                                                                  |
| --------------- | ----------------------------------------------------------------------------------------- |
| `label`         | метка оси категорий                                                                       |
| `value`         | числовое значение столбца                                                                 |
| `dataColor`     | цвет этой полосы                                                                          |
| `valueText`     | текст пользовательского значения во всплывающей подсказке, сгенерированной автоматически. |
| `valueAppendix` | суффикс после текста значения всплывающей подсказки                                       |
| `tooltipTitle`  | пользовательский заголовок всплывающей подсказки                                          |
| `tooltipText`   | пользовательский текст всплывающей подсказки                                              |

```json
[
    { "label": "PV", "value": 4.8, "dataColor": "#f9a825", "valueAppendix": " kW" },
    { "label": "Grid", "value": 1.2, "dataColor": "#44739e", "tooltipTitle": "Grid import" }
]
```

## Соответствующие параметры макета

- Ограничения по оси значений определяются минимальным и максимальным значениями. Пустые поля сохраняют автоматическое масштабирование.
- Текст всплывающей подсказки для каждого набора данных заменяет автоматически сгенерированную метку.
- Горизонтальное представление функционально меняет местами оси X и Y: X содержит значения, Y — категории.
