# Адаптивная верстка

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/responsive-layout.md)

Адаптивные контейнеры VIS 2 для представлений Masonry Views, Grid Views и встроенных представлений с управлением состоянием.

Идентификаторы шаблонов:`tplVis2-materialdesign-Masonry-Views` ,`tplVis2-materialdesign-Grid-Views` ,`tplVis2-materialdesign-view-in-widget` и`tplVis2-materialdesign-view-in-widget8` .

<img src="../../media/vis2_responsive_layout_runtime.png" alt="Responsive Material Design layout in VIS 2">

## Настройки редактора

На скриншоте показана группа **«Общие»** и одна индексированная **запись представления** контейнера «Клетчатка». Настройки, не указанные ниже, понятны сами собой. Пользовательский интерфейс редактора соответствует системному языку ioBroker, поэтому скриншоты сделаны на немецком языке.

<img src="../../media/vis2_responsive_layout_editor_overview.png" width="340" alt="Responsive layout general and view options">

**Обычная** (каменная)

- **количество столбцов** (по умолчанию 3, максимум 12) и **расстояние между представлениями** – базовая сетка, используемая на настольных компьютерах.
- **количество представлений** – сколько индексированных групп **представлений \[n]** существует, по умолчанию 3.
- **выравнивание** -`left` ,`center` (по умолчанию),`right` или`justify` для содержимого столбцов.

В **режиме Common** (Grid) количество столбцов заменяется **диапазоном** от 1 до 12 в качестве значения по умолчанию для каждого представления, а также выравниванием **по вертикали** и **горизонтали** . В режиме Grid всегда используется 12-колоночная сетка: представление с диапазоном 3 занимает четверть ширины.

Группы **настроек для мобильных телефонов** и **планшетов** отображаются только после установки флажка **«Показать расширенные параметры»** . Для каждой контрольной точки (портретная и альбомная ориентация) они задают ширину переключения, для Masonry — количество столбцов и расстояние между ними, для Grid — размер столбца. Значения по умолчанию: телефон в портретной ориентации — до 393 пикселей (1 столбец), в альбомной — до 754 пикселей (2), планшет в портретной ориентации — до 768 пикселей (2), в альбомной — до 1024 пикселей (3), значения для настольных компьютеров выше этого уровня.

**Просмотреть \[н]**

- **Представление** – встроенное представление VIS 2. Пустое поле отображает пунктирный заполнитель.
- **Высота области видимости** – фиксированная высота; пустое значение означает, что плитка измеряет собственное содержимое. **Ширина области видимости** существует только в Masonry, **ширина столбца** (с четырьмя сегментами для телефонов/планшетов) – только в Grid.
- **Порядок сортировки** — позиция в сетке; без него учитывается индекс.
- **Видно при разрешении больше** / **меньше** – скрывает область за пределами ширины виджета. Оба поля необязательны.
- **Идентификатор объекта для обеспечения видимости** , **условие для обеспечения видимости** (`==` ,`!=` ,`<=` ,`>=` ,`<` ,`>` ,`consist` ,`not consist` ,`exist` ,`not exist` ) и **значение для видимости** – условие, которое выполняется, **показывает** представление:`==` с`1` означает «показывать только тогда, когда государство находится в состоянии...»`1` «До версии 1.0.0 это было наоборот; любой, кто изменил свое состояние тогда, меняет его и сейчас».

**В режиме расширенного просмотра** выбирается одно встроенное представление на основе значения состояния; см. [раздел «Расширенный просмотр» в виджете](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/html-widgets.md) .

Встроенный контент использует собственный механизм дочерних представлений VIS 2; он не изменяет активное представление верхнего уровня.

**Выберите один из вариантов:** используйте Masonry или Grid для одновременного размещения нескольких представлений. Используйте [расширенный режим просмотра в виджете,](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/html-widgets.md) если в состоянии выбрано ровно одно дочернее представление.
