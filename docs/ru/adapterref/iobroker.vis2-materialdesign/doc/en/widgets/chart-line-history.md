# График истории линии

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) › [Диаграммы](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/chart-line-history.md)

Загружает несколько временных рядов из экземпляра истории ioBroker. Идентификатор шаблона:`tplVis2-materialdesign-Chart-Line-History` .

Для корректной работы требуется настроенный экземпляр History, SQL или InfluxDB и включенная запись для каждого состояния, используемого виджетом.

## Диапазон времени и обновление

- **Экземпляр адаптера истории:** источник всех временных рядов.
- **Временной интервал для отображения:** скользящее окно, заканчивающееся в текущий момент времени.
- **Управлять интервалом с помощью объекта:** переопределяет фиксированное окно во время выполнения.
- **Обновление:** в режиме реального времени, с фиксированным интервалом или с помощью объекта-триггера.
- **Время ожидания графика:** максимальное время ожидания запроса истории в секундах.

Эти параметры находятся в группе **«Общие»** . Интерфейс редактора соответствует системному языку ioBroker, поэтому скриншоты сделаны на немецком языке.

<img src="../../media/vis2_chart_line_history_editor.png" width="340" alt="Line history general options">

В разделе «Управление интервалом с объектом» принимаются два типа значений:

- Строка: предлагаемая метка интервала, например`30 seconds` ,`10 minutes` ,`1 day` или`1 year` .
- Число: время начала в миллисекундах в формате Unix-метки времени. Время окончания остается текущим.

Изменение состояния ручного запуска инициирует новый запрос; его фактическое значение не имеет значения. Интервал обновления составляет не менее одной секунды, даже если задано меньшее значение.

## Запрос на наборы данных и историю

Каждая индексированная группа описывает одно записанное состояние и соответствующий запрос. Параметры представления с одинаковым индексом относятся к этому временному ряду. Без пользовательского текста легенды отображается идентификатор объекта.

<img src="../../media/vis2_chart_line_history_editor_2.png" width="340" alt="Line history dataset and line options">

| Параметр                             | Эффект                                                                                  |
| ------------------------------------ | --------------------------------------------------------------------------------------- |
| Идентификатор объекта                | состояние с включенной записью истории                                                  |
| Совокупность                         | пасы`minmax` ,`min` ,`max` ,`average` или`total` к экземпляру истории                   |
| Максимальное количество точек данных | ограничивает количество возвращаемых баллов; по умолчанию 50.`minmax` , иначе 100       |
| Минимальный временной интервал       | Шаг запроса в секундах; пустой или`0` позволяет экземпляру истории принять решение.     |
| Умножить                             | преобразует каждое допустимое значение перед отображением, например.`0.001` от Вт к кВт |

Нечисловые и`null` Значения опущены. Диаграмма остается пустой, если не выбран ни один экземпляр истории или API истории недоступен. Для установки таймаутов сначала проверьте запись и выбранный диапазон, а затем увеличьте время ожидания диаграммы.

## Линии и оси

- `steppedLine` Отображает изменения состояния в виде шагов, а не прямых связей.
- Цвет заливки определяет оттенок области под линией; если цвет заливки не задан, используется прозрачный цвет линии.
- Вновь настроенные наборы данных по умолчанию используют одну общую ось Y. Ее положение, заголовок и границы берутся из первой группы наборов данных. Пустые поля min/max сохраняют автоматическое масштабирование.
- В формате времени по оси X используются токены формата Moment, например.`HH:mm` Для отображения информации в 24-часовом формате. Тот же формат применяется к секундам, минутам, часам и дням.
- Цвет, шрифт и размер подписей оси X задаются автоматически, как и для подписей оси Y. Если оставить поле пустым, будут применяться значения по умолчанию.
- режим всплывающих подсказок`index` Сравнивает наборы данных при одинаковом значении X;`nearest` показывает ближайшую точку.
- Значения меток точек находятся в той же группе данных, что и линия, фон, граница и радиус скругления углов (см. [раздел «Значения, отображаемые на диаграмме»)](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md#values-drawn-on-the-chart) .
