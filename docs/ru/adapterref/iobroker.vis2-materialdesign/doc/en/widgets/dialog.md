# Диалог

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/dialog.md)

Два диалоговых окна VIS 2, открываемые при заданном состоянии: одно содержит встроенное представление VIS 2, другое — URL-адрес iFrame.

Идентификаторы шаблонов:`tplVis2-materialdesign-Vuetify-Dialog-View` и`tplVis2-materialdesign-Vuetify-Dialog-iFrame` .

<p>
<img src="../../media/vis2_dialog_runtime.png" alt="Opened view dialog in VIS 2" width="300">
<img src="../../media/vis2_dialog_iframe_runtime.png" alt="Opened iFrame dialog in VIS 2" width="300">
</p>

Слева: диалоговое окно, в которое встроен интерфейс VIS 2 (панель управления помещением). Справа: диалоговое окно, в которое встроена страница iFrame.

## Настройки редактора

На скриншотах показаны группа **«Общие»** и группа «iFrame» диалогового окна просмотра. Настройки, не указанные ниже, понятны сами собой. Пользовательский интерфейс редактора соответствует системному языку ioBroker, поэтому скриншоты сделаны на немецком языке.

<img src="../../media/vis2_dialog_editor_overview.png" width="340" alt="View dialog general options">

**Общий**

- **способ отображения диалога** –`button` (его открывает собственная кнопка виджета) или`datapoint` .
- **Логический переключатель для отображения диалогового окна** – состояние для`datapoint` метод:`true` открывает диалоговое окно, закрывает запись`false` назад.
- **Если разрешение ниже указанного, диалоговое окно будет отображаться в полноэкранном режиме** — при разрешении меньше этой ширины окна в пикселях диалоговое окно будет заполнять весь экран.
- **Вид** – представление VIS 2, отображаемое внутри диалогового окна (только для варианта просмотра).

Вариант с **использованием iFrame** заменяет встроенное представление веб-страницей:

<img src="../../media/vis2_dialog_editor_2.png" width="340" alt="iFrame dialog settings">

**Настройки iFrame**

- **источник** – URL-адрес, отображаемый в iFrame. Только`http:` и`https:` количество адресов (плюс)`mailto:` /`tel:` ); а`data:` или`javascript:` Значение отбрасывается, и кадр остается пустым.
- **Отключить песочницу** — снимает песочницу с iFrame; только для доверенного контента, который иначе не запускается.
- **Горизонтальная прокрутка / Вертикальная прокрутка / Бесшовная прокрутка** – полосы прокрутки и бесшовное встраивание.

**Макет диалогового окна**

- **Максимальная ширина / высота / расстояние до границы** – размер диалогового окна; ширина также может быть значением CSS, например:`96vw` .
- **Функция закрытия по щелчку мыши** — отключена, остается только кнопка закрытия.
- **Цвет фона / прозрачность** – затемненная область за диалоговым окном.
- **высота заголовка / высота нижнего колонтитула / отображение разделителя / z-Index** – рамка вокруг содержимого.

**Параметр «Макет кнопок»** задает стиль кнопки-триггера ( **текст кнопки** , **стиль кнопки** , значок, цвета), **параметр** **«Макет заголовка** » — без него отображается название представления, а **параметр «Макет кнопок нижнего колонтитула диалогового окна»** — кнопку закрытия ( **текст кнопки закрытия** , положение, размер, полная ширина).

Для отображения контента, постоянно встроенного в виджет без диалогового окна, см. [раздел «Расширенный просмотр в виджете»](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/html-widgets.md) .
