# Оповещения

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/alerts.md)

Отображает очередь оповещений в формате JSON в виде уведомлений Material Design. Оповещения можно закрыть, и обновленная очередь будет записана обратно в состояние. Идентификатор шаблона:`tplVis2-materialdesign-Alerts` .

<img src="../../media/vis2_alerts_runtime.png" alt="Material Design alerts in VIS 2">

## Настройки редактора

На скриншоте показаны развернутые группы **«Общие»** и **«Макет»** . Настройки, не указанные ниже, понятны сами собой. Пользовательский интерфейс редактора соответствует системному языку ioBroker, поэтому скриншоты сделаны на немецком языке.

<img src="../../media/vis2_alerts_editor_overview.png" width="340" alt="Alerts general and layout options">

**Общий**

- **Идентификатор объекта** – состояние, содержащее массив JSON-оповещений.
- **show max alerts** – количество оповещений, отображаемых одновременно, по умолчанию 3. Пусто или`0` Отображает все оповещения в очереди (максимум 100).
- **Скрыть виджет, если его ширина меньше ширины экрана \[px]** – скрывает виджет, если его ширина меньше этой ширины экрана. Правило применяется только к этому виджету, поэтому несколько виджетов оповещений в одном представлении могут использовать разную ширину.

**макет**

- **макет** -`normal` ,`outlined` или`tile` Значения в редакторе не переведены.`outlined` рисует границу вместо закрашенной поверхности.`tile` Удаляет закругленные углы.
- **компактность / тень / расстояние между оповещениями** – степень компактности (включено по умолчанию), глубина тени 0–24 и расстояние под каждым оповещением в пикселях.
- **рамка** — с какой стороны каждое оповещение получает цветную полосу шириной 6 пикселей.`borderColor` : нет, сверху, справа, слева или снизу.
- **Значок закрытия** / **цвет значка закрытия** / **цвет значка закрытия при наведении курсора / выбранный** – значок закрытия, его цвет и цвет при удержании кнопки. Закрытие удаляет оповещение из состояния.

```json
[
    {
        "text": "Window is open",
        "icon": "alert-outline",
        "backgroundColor": "#fff8e1",
        "borderColor": "#ffc107",
        "iconColor": "#ffc107",
        "fontColor": "#333333"
    }
]
```

Каждый объект недвижимости является необязательным.`text` может содержать HTML (`<b>` ,`<br>` (ссылки); скрипты и атрибуты событий удаляются перед отображением.`borderColor` Эффект проявляется только в том случае, если **рамка** не установлена.`none` .

Состояние должно содержать массив JSON. Недопустимый JSON отображается как ошибка в виджете. Пустое состояние не отображает ничего.
