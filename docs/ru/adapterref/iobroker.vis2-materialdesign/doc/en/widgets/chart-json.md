# JSON-диаграмма

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) › [Диаграммы](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/chart-json.md)

Создает столбчатую, линейную или смешанную диаграмму на основе одного состояния JSON. Идентификатор шаблона:`tplVis2-materialdesign-Chart-JSON` .

## Формат данных

В поле «Идентификатор объекта» выбрано состояние, содержащее объект, обладающий следующими свойствами:`axisLabels` и`graphs` .`axisLabels` Названия указывают на общие позиции по оси X. Каждая запись в`graphs` создает один набор данных.

```json
{
    "axisLabels": ["Mon", "Tue", "Wed", "Thu"],
    "graphs": [
        {
            "type": "bar",
            "legendText": "Consumption",
            "color": "#44739e",
            "data": [4.2, 5.1, 4.8, 6.0],
            "barIsStacked": true,
            "barStackId": 1
        },
        {
            "type": "line",
            "legendText": "PV",
            "color": "#f9a825",
            "data": [2.1, 4.7, null, 5.4],
            "line_spanGaps": false,
            "line_Thickness": 3
        }
    ]
}
```

Некорректное отображение JSON`Error in JSON string` Отсутствующие, пустые или нечисловые значения данных рассматриваются как пробелы.

## Настройки редактора

Большая часть этого графика управляется состоянием JSON; редактор устанавливает только исходные и глобальные значения по умолчанию. Пользовательский интерфейс редактора соответствует системному языку ioBroker, поэтому скриншот сделан на немецком языке.

<img src="../../media/vis2_chart_json_editor.png" width="340" alt="JSON chart general and chart layout options">

- **Общие параметры** – идентификатор объекта состояния JSON, описанного выше, и глобальный **тип диаграммы** (`bar` или`line` ) используется наборами данных, не имеющими собственных`type` .

- **Ось X** / **Ось Y** – заголовок, положение, цвета, **отображение линий сетки** и **цвет линий сетки** . **Смещение линий сетки по оси X** размещает линии между категориями, а не через них — именно то, что нужно столбчатым диаграммам.

- **Макет значений столбчатой диаграммы:** – отображает значения на столбцах и точках (см. [раздел «Значения, отображаемые на диаграмме»)](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md#values-drawn-on-the-chart) . По умолчанию используется следующее:`no` Здесь, если ни один из этих параметров не задан, подпись на диаграмме по-прежнему не отображается.

Применяются параметры расположения карточек, а также общие группы **«Легенда»** и **«Всплывающие подсказки»** из [раздела «Диаграммы»](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) ; внешний вид для каждого набора данных определяется свойствами JSON, указанными ниже.

## Свойства набора данных

| Свойство                 | Значение                                                                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| `data`                   | соответствующие значения`axisLabels` порядок; число или `{ "y": number }`                                                        |
| `type`                   | `bar` или`line` ; переопределяет глобальный тип диаграммы                                                                        |
| `legendText`             | метка, указанная в легенде                                                                                                       |
| `color`                  | цвет линии или полосы                                                                                                            |
| `line_Thickness`         | ширина линии; также резервный вариант для ширины границы полосы.                                                                 |
| `line_steppedLine`       | соединяет значения строк с помощью шагов                                                                                         |
| `line_spanGaps`          | соединяет точки по всей`null` пробелы                                                                                            |
| `line_UseFillColor`      | заполняет область ниже линии                                                                                                     |
| `line_FillColor`         | пользовательский цвет заливки; в противном случае — прозрачный вариант. `color`                                                  |
| `barBorderWidth`         | ширина границы полосы                                                                                                            |
| `barIsStacked`           | включает возможность объединения данных по набору данных и его оси Y.                                                            |
| `barStackId`             | Наборы данных с одинаковым идентификатором образуют один стек.                                                                   |
| `yAxis_id`               | Наборы данных с одинаковым идентификатором используют общую ось Y; для всех пропущенных значений используется идентификатор. `0` |
| `yAxis_position`         | размещает эту ось Y слева или справа                                                                                             |
| `yAxis_min` ,`yAxis_max` | Для оси Y установлены фиксированные пределы; пустые значения сохраняют автоматическое масштабирование.                           |

## Смешанные графики и оси

Глобальный тип диаграммы применяется только к наборам данных, не имеющим собственных диаграмм.`type` Это позволяет разместить столбчатые и линейные диаграммы на одном графике. Для столбчатых диаграмм с накоплением требуется то же самое.`barStackId` Наборы данных без объединения остаются отдельными.

Назначить разные`yAxis_id` значения в различных единицах измерения, например`0` для кВт слева и`1` Для процентов справа. Наборы данных с одинаковой единицей измерения должны иметь общий идентификатор, чтобы избежать дублирования осей.

Виджет использует`axisLabels` в качестве категорий. Используйте [линейный график истории](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/chart-line-history.md) для оси реального времени, загружаемой непосредственно из экземпляра истории.
