# Круговая диаграмма

[Руководство пользователя](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Каталог виджетов](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) › [Диаграммы](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/chart-pie.md)

Отображает текущие значения в виде частей пирога или пончика. Идентификатор шаблона:`tplVis2-materialdesign-Chart-Pie` .

## Источник данных

- **Ввод данных редактором:** каждый сегмент считывает собственное состояние.
- **Строка/объект JSON:** в одном штате все сегменты представлены в виде массива JSON.
- **Пончик:** параметр cutout определяет размер пустой центральной части в процентах.

Отрицательные входные значения отображаются следующим образом:`0` Для данных, содержащих положительные и отрицательные значения, используйте столбчатую диаграмму или JSON-диаграмму.

## Настройки редактора

Интерфейс редактора соответствует системному языку ioBroker, поэтому скриншот сделан на немецком языке. Настройки, не указанные ниже, понятны сами собой.

<img src="../../media/vis2_chart_pie_editor.png" width="340" alt="Pie chart general and pie layout options">

- **Общие сведения** – источник данных (сегменты редактора или одно состояние JSON), количество сегментов, идентификатор объекта, **тип** (круговая диаграмма или кольцевая диаграмма) и **размер выреза** , определяющий размер пустой центральной части. Для каждого сегмента редактора индексированная группа добавляет свой идентификатор объекта, метку и цвет.

Значения на сегментах отображаются в **макете значений круговой диаграммы:** группа, см. [Значения, отображаемые на диаграмме](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md#values-drawn-on-the-chart) .

Здесь также применяются общие элементы **макета диаграммы** , **легенды** и **всплывающих подсказок** из [раздела «Диаграммы»](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) .

## формат JSON

Формат соответствует наборам данных [для столбчатых диаграмм](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/chart-bar.md) , за исключением того, что для круговых диаграмм это не требуется.`valueText` .

| Свойство        | Значение                                         |
| --------------- | ------------------------------------------------ |
| `label`         | Название сегмента и запись в легенде             |
| `value`         | числовая, неотрицательная часть                  |
| `dataColor`     | цвет этого сегмента                              |
| `valueAppendix` | суффикс после значения всплывающей подсказки     |
| `tooltipTitle`  | пользовательский заголовок всплывающей подсказки |
| `tooltipText`   | пользовательский текст всплывающей подсказки     |

```json
[
    { "label": "Self-consumption", "value": 68, "dataColor": "#43a047" },
    { "label": "Export", "value": 32, "dataColor": "#f9a825" }
]
```

## Соответствующие параметры макета

- Цвет отдельного сегмента имеет приоритет над цветовой схемой и общим цветом.
- В подсказке автоматически генерируются только значения минимального и максимального количества десятичных знаков. Пользовательский формат.`tooltipText` заменяет этот вывод.
- Легенда и диаграмма занимают одно и то же пространство. Для многих сегментов используйте верхнюю или нижнюю легенду с более широким виджетом.

## Стиль дизайна

**Классический** (слева) и **Материальный 3** (справа) стили расположены рядом, см. [Стиль дизайна](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md#design-style) : пирог и пончик, более широкая сердцевина пончика, с обозначениями значений и без них, обозначение значения в рамке, без легенды и внутри карточки.
