# Виджеты Material Design – руководство пользователя

[Обзор проекта](/#/adapters/vis2-materialdesign) · [Немецкий](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/README.md)

## Требования

- ioBroker Admin 7.6.20 или более поздняя версия
- Node.js 22 или новее
- установленный адаптер VIS 2
- В качестве целевой среды используется современный браузер на основе Chromium или Firefox.

Полная матрица совместимости браузеров и сред выполнения еще не протестирована.

## Установка и быстрый запуск

1. Установите **виджеты Material Design** (`vis2-materialdesign` ) из списка адаптеров администратора ioBroker.
2. Откройте редактор VIS 2 и выберите проект.
3. Откройте набор виджетов **Material Design** .
4. Перетащите виджет в область просмотра и выберите его.
5. На вкладке **«ВИДЖЕТ»** настройте идентификатор объекта и его поведение.
6. Сохраните проект и протестируйте его в режиме выполнения.

Для первого теста используйте **функцию «Значение»** : выберите объект в разделе`oid` Настройте единицы измерения и количество десятичных знаков, затем сохраните представление.

## Используйте тему

Использование темы оформления необязательно:

1. Откройте конфигурацию адаптера.
2. Настройте светлые и темные цвета, шрифты и размеры шрифтов в **редакторе тем** , затем сохраните изменения.
3. Выберите виджет в редакторе VIS 2.
4. Выберите **тему → используйте тему** и подтвердите.

Это позволяет разместить соответствующие ссылки на тему в выбранном виджете. Значения виджета, измененные впоследствии, остаются индивидуальными переопределениями. Глобальный JavaScript-скрипт в конфигурации адаптера необходим только в том случае, если скриптам требуется прямой доступ к значениям темы.

## Стиль дизайна

Каждый виджет отображается в одном из двух стилей, выбираемых на вкладке **«ВИДЖЕТЫ»** в разделе **«Общие» → «Стиль оформления»** :

- **Material 3** – Цветовые роли, слои формы, типа и состояния Material 3. Предустановлено для новых виджетов.
- **Классика** – устоявшийся стиль эпохи Material Design 2.
- **По умолчанию для проекта** — используется стиль, заданный на вкладке **«Дизайн»** адаптера, поэтому переключение между стилями всего проекта можно выполнить централизованно.

<img src="../media/vis2_style_editor_basic.png" width="300" alt="Design style in the General group">

Вновь добавленные виджеты отображаются в Material 3. Существующие проекты остаются классическими и без изменений, пока вы не замените виджет или не измените настройки проекта по умолчанию на вкладке **«Дизайн»** .

Оба стиля соответствуют темному режиму VIS 2: текст, поверхности, которые отображает сам виджет (карточка, меню, боковая панель навигации), и границы.`outlined` Варианты цветов меняются в зависимости от темы. Цвет, который вы установили в редакторе, остается неизменным в обоих режимах — поэтому отметьте его, если вы выбрали его для светлого режима.

В Material 3 изменяется только внешний вид. Идентификаторы объектов, имена параметров, значения, поведение при записи, таймеры и навигация идентичны в обоих стилях, и возврат виджета в исходное состояние также невозможен.`Classic` Восстанавливает старый внешний вид в точности. Цвета, шрифты и размеры, которые вы явно задали, остаются прежними — Material 3 заполняет только те значения, которые вы оставили пустыми, поэтому очистите эти поля, чтобы виджет соответствовал палитре Material 3.

Темный режим работает аналогично.`vis2-materialdesign.0.colors.darkTheme` Укажите, какой стиль уже используется в классическом варианте:`auto` заимствовано из собственной темы VIS 2.`light` и`dark` Принудительное использование первого варианта. На вкладке **«Дизайн»** полная цветовая схема Material 3 создается на основе одного базового цвета; оставьте поле «Базовый цвет» пустым для использования базовой палитры Google.

### Настройка схемы из скрипта

Завершённый проект реализуется в`vis2-materialdesign.0.colors.md3Scheme` Виджеты считывают данные в формате JSON напрямую — в отличие от заданного цвета, схема, созданная с помощью скрипта, вступает в силу немедленно, без сохранения вкладки **«Дизайн»** :

```json
{
  "light": { "primary": "#65558f", "on-primary": "#ffffff", "surface": "#fef7ff" },
  "dark":  { "primary": "#cfbdfe", "on-primary": "#36275d", "surface": "#141218" }
}
```

Оба блока являются необязательными и оцениваются независимо. Допускаются следующие 18 названий ролей:

`primary` ,`on-primary` ,`primary-container` ,`on-primary-container` ,`secondary` ,`secondary-container` ,`on-secondary-container` ,`tertiary` ,`error` ,`surface` ,`surface-container-low` ,`surface-container` ,`surface-container-high` ,`on-surface` ,`on-surface-variant` ,`outline` ,`outline-variant` ,`scrim`

Значение должно быть шестнадцатеричным значением цвета (`#abc` или`#aabbcc` Неизвестные названия ролей, другие форматы цветов и некорректный JSON игнорируются, и для каждой роли, которую вы не упомянули, используется базовая палитра Google — поэтому пустое состояние означает полную базовую палитру. Шрифт взят из`vis2-materialdesign.0.fonts.md3Font` Таким же образом.

На каждой странице виджета отображаются оба стиля рядом друг с другом в светлом и темном режимах.

**Кнопка «Показать расширенные параметры»** , расположенная прямо под стилем, отображает редко используемые группы параметров выбранного виджета. Виджет, который уже содержит такие значения, отображает их без этой кнопки.

### Известные пределы материала 3

- **Виджеты считывают экземпляр 0.** Состояния темы, темного режима, стиля дизайна и Material 3 считываются из`vis2-materialdesign.0.…` Адаптер является синглтоном, и ioBroker по умолчанию создает экземпляр 0, поэтому он есть в каждой стандартной установке — но экземпляр, намеренно созданный под другим номером, не будет распознан виджетами.
- **Заданный скриптом начальный цвет не пересчитывает цветовую схему.** Цветовой шаблон преобразуется в полную схему Material 3 при сохранении конфигурации адаптера, а не при изменении состояния. Запишите начальный цвет на вкладке **«Дизайн»** и сохраните.

## Отображение значений внутри текста

Идентификатор объекта виджета управляет его состоянием — он не записывает значение в текст. Значения поступают из привязки VIS 2: идентификатор объекта в фигурных скобках внутри текстового или HTML-поля заменяется значением этого состояния во время выполнения.

```
Temperature: {0_userdata.0.temp}°C
```

Это работает во всех текстовых и HTML-полях этих виджетов, а также в метке, подметке и правой метке каждой строки списка, в ячейках таблицы и в HTML-коде [HTML-карточки](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/html-card.md) . Таким образом, [список](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/list.md) отображает несколько значений друг под другом, тогда как в противном случае для каждого состояния потребовался бы отдельный виджет [«Значение»](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/value.md) .

Привязка обрабатывается VIS 2, а не этим адаптером. Значок цепочки рядом с именем поля ( **Использовать поле в качестве привязки** ) переключает поле в редактор привязок VIS 2, что помогает с форматированием (десятичные знаки, преобразование, условия).

## Поиск неисправностей

- **Отсутствует набор виджетов:** проверьте это.`vis2-materialdesign` После установки VIS 2 перезагрузите редактор VIS 2.
- **Тема оформления остается без изменений:** сохраните конфигурацию адаптера, запустите **«Тема» → снова используйте тему** и перезагрузите режим выполнения.
- **Изменения скрываются после переустановки той же версии:** выполните принудительную перезагрузку страницы в браузере.
- **Виджет не записывает данные:** проверьте, доступен ли объект для записи и активен ли режим только для чтения или блокировка виджета.
- **Список, таблица, календарь или диаграмма пусты:** сравните их JSON с примером на странице виджета.
- **Строка отображает свою метку, но не значение:** идентификатор объекта строки управляет только её состоянием. Значения берутся из [параметра «Показать значения внутри текста»](#show-values-inside-texts) .
- **Повторяющаяся группа (пункт меню, набор данных, столбец, представление) не увеличивается в размерах:** используйте кнопку **«+»** в заголовке последней из этих групп. Ввод числа в соответствующее поле подсчета не приводит к немедленному перестроению групп — VIS 2 перерисовывает их при нажатии кнопки или после изменения выделения. Последняя группа отображает только свой заголовок с кнопками: именно панель добавления, а не запись, сохраняет значение счетчика, означающее количество записей.

## Примечание браузера

Функция вибрации доступна не во всех браузерах и устройствах. См. [таблицу совместимости API вибрации](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate#browser_compatibility) .

Сообщайте о проблемах с версией адаптера, браузером, затронутым виджетом и прилагайте скриншот в [систему отслеживания ошибок](https://github.com/typhosj/ioBroker.vis2-materialdesign/issues) .
