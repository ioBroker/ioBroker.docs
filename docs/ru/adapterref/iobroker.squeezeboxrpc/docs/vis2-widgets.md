## Игроки

![Виджет игроков](../../../../en/adapterref/iobroker.squeezeboxrpc/widgets/squeezeboxrpc/img/players.png)

Выбирает активный проигрыватель LMS и публикует выбранный элемент для каждого виджета SqueezeboxRPC, на который есть ссылки.

| Параметр                           | По умолчанию         | Описание                                                                                            |
| ---------------------------------- | -------------------- | --------------------------------------------------------------------------------------------------- |
| Экземпляр SqueezeboxRPC            | —                    | Экземпляр адаптера, в котором загружены плееры.                                                     |
| Формат                             | Кнопки               | Отображает кнопки проигрывателя или компактное поле выбора.                                         |
| Настройки игрока                   | Обнаруженные игроки  | Изменяет порядок отображения, включает или отключает игроков и назначает данные для каждого игрока. |
| Wrap CamelCase                     | На                   | Позволяет переносить текст в формате CamelCase.                                                     |
| ширина / высота изображения        | `50` /`50` px        | Размер кнопок плеера.                                                                               |
| Непрозрачность                     | `0.5`                | Прозрачность неактивной кнопки.                                                                     |
| Ширина/стиль границы               | `2px` /`solid`       | Внешний вид рамки кнопки.                                                                           |
| Обычный / активный цвет границы    | `#2e2e2e` /`#87ceeb` | Указание выбора.                                                                                    |
| Радиус границы                     | `5px`                | Радиус скругления углов.                                                                            |
| Фон                                | `#000000`            | Кнопка и сгенерированный текстово-графический фон.                                                  |
| Отступы кнопки                     | `0px`                | Пространство вокруг кнопок игроков.                                                                 |
| Изображение/текст отдельной кнопки | —                    | Изображение и метка для замены каждого игрока.                                                      |

Настройки сохраняются, даже когда игроки временно исчезают; вновь обнаруженные игроки добавляются. Выделение публикуется через глобальную шину браузера, поэтому виджеты, на которые есть ссылки, могут располагаться в других представлениях.

## Избранное

![Виджет «Избранное»](../../../../en/adapterref/iobroker.squeezeboxrpc/widgets/squeezeboxrpc/img/favorites.png)

Отображает избранные элементы LMS и запускает избранный элемент на выбранном плеере.

| Параметр                                                | По умолчанию         | Описание                                                                                                    |
| ------------------------------------------------------- | -------------------- | ----------------------------------------------------------------------------------------------------------- |
| Справочник по виджету игроков                           | —                    | Виджет Players, предоставляющий информацию об экземпляре и активном игроке.                                 |
| Избранная конфигурация                                  | Нашли фаворитов      | Изменяет порядок, скрывает и настраивает избранные элементы, используя стабильные идентификаторы избранных. |
| Вспомогательная функция индекса в режиме редактирования | Выключенный          | В редакторе отображаются только индексы, начинающиеся с нуля.                                               |
| Wrap CamelCase                                          | На                   | Позволяет переносить сгенерированные метки на следующую строку.                                             |
| ширина / высота изображения                             | `50` /`50` px        | Любимый размер кнопки.                                                                                      |
| Непрозрачность                                          | `0.5`                | Прозрачность неактивной кнопки.                                                                             |
| Ширина/стиль границы                                    | `2px` /`solid`       | Внешний вид рамки кнопки.                                                                                   |
| Обычный / активный цвет границы                         | `#2e2e2e` /`#87ceeb` | Нормальный и активный индикатор предпочтения.                                                               |
| Радиус границы                                          | `5px`                | Радиус скругления углов.                                                                                    |
| Фон                                                     | `#000000`            | Фон кнопки.                                                                                                 |
| Отступы кнопки                                          | `0px`                | Пространство вокруг кнопок.                                                                                 |
| Любимое изображение/текст                               | —                    | Заменяющее изображение и метку для каждого избранного.                                                      |

Переполнение остается внутри виджета и использует узкую полосу прокрутки. В случае неудачной попытки отображения изображений вместо них используются сгенерированные текстовые изображения.

## Кнопка повтора

<img src="../widgets/squeezeboxrpc/img/repeat0.svg" width="128px" alt="Repeat button">

Отображает и изменяет выбранного игрока.`PlaylistRepeat` состояние.

| Параметр                                                   | По умолчанию   | Описание                                                   |
| ---------------------------------------------------------- | -------------- | ---------------------------------------------------------- |
| Справочник по виджету игроков                              | —              | Источник выбранного игрока.                                |
| Изображение в режиме выключения / режиме один / режиме два | Встроенный SVG | Дополнительное изображение для состояний повтора 0, 1 и 2. |
| Цвет заливки/обводки в формате SVG                         | `#ffffff`      | Встроенные цвета значков.                                  |
| ширина штриха SVG                                          | `0.3`          | Встроенная толщина обводки значка.                         |

## SyncGroup

![Виджет SyncGroup](../../../../en/adapterref/iobroker.squeezeboxrpc/widgets/squeezeboxrpc/img/syncgroups.png)

Управляет группой синхронизации LMS выбранного проигрывателя.

| Параметр                      | По умолчанию   | Описание                                                                        |
| ----------------------------- | -------------- | ------------------------------------------------------------------------------- |
| Справочник по виджету игроков | —              | Предоставляет список игроков, информацию об их внешнем виде и выбранном игроке. |
| Ширина/стиль границы          | `2px` /`solid` | Внешний вид рамки кнопки.                                                       |
| Отсутствие групповой границы  | `#2e2e2e`      | Плеер не синхронизирован.                                                       |
| Граница собственной группы    | `#87ceeb`      | Игрок принадлежит к группе выбранного игрока.                                   |
| Граница другой группы         | `#ff0080`      | Игрок принадлежит к другой группе.                                              |
| Радиус границы                | `5px`          | Радиус скругления углов.                                                        |
| Фон                           | `#000000`      | Фон кнопки.                                                                     |
| Отступы кнопки                | `0px`          | Пространство вокруг кнопок.                                                     |

Перекрывающиеся связи LMS объединяются в полные группы. Нажатие на проигрыватель синхронизирует или отменяет синхронизацию; сам выбранный проигрыватель отключается.

## Детали плейлиста

![Виджет PlaylistDetail](../../../../en/adapterref/iobroker.squeezeboxrpc/widgets/squeezeboxrpc/img/playlistdetail.png)

Отображает текущую очередь воспроизведения выбранного проигрывателя с обложкой, метаданными, продолжительностью и действиями.

| Параметр                              | По умолчанию              | Описание                                           |
| ------------------------------------- | ------------------------- | -------------------------------------------------- |
| Справочник по виджету игроков         | —                         | Запасы`Playlist` ,`PlaylistCurrentIndex` и команд. |
| Фон строки                            | `#f5f7fa`                 | Обычный фон строки.                                |
| Активный/при наведении курсора на фон | `#dbeafe`                 | Фон текущей строки и строки при наведении курсора. |
| Цвет/ширина/стиль границы             | `#cbd5e1` /`1px` /`solid` | Внешний вид границ строк.                          |
| Расстояние между строками             | `4px`                     | Вертикальное расстояние между рядами.              |
| Показать миниатюру                    | На                        | Шоу`ArtworkUrl` при наличии.                       |
| Показать указатель                    | На                        | Отображает индексы треков, начинающиеся с единицы. |

Функция воспроизведения сразу переходит к нужному треку. Функция удаления удаляет трек только из активной очереди и никогда не изменяет сохраненный плейлист. Длинный текст обрезается многоточием, а содержимое папки overflow можно прокручивать по вертикали.

## Браузер

<img src="../widgets/squeezeboxrpc/img/browser.svg" width="128px" alt="Browser widget">

Обеспечивает навигацию по разделам «Моя музыка», «Радио», «Избранное», «Приложения» и другим пунктам меню, доступным через LMS.

| Параметр                      | По умолчанию | Описание                                                              |
| ----------------------------- | ------------ | --------------------------------------------------------------------- |
| Справочник по виджету игроков | —            | Предоставляет экземпляр и выбранного плеера.                          |
| Отлаживать                    | Выключенный  | Содержит журналы диагностики браузера.                                |
| Отладка получения результатов | Выключенный  | При включенной отладке регистрирует необработанные ответы на команды. |

Навигационная цепочка перемещает курсор вверх. Затем кнопки воспроизведения и добавления появляются только тогда, когда LMS предоставляет соответствующее действие.
