# ioBroker Logitech/Lyrion Squeezebox Adapter over JSON/RPC-Protocol

**Тесты:**![Тестирование и выпуск](https://github.com/oweitman/ioBroker.squeezeboxrpc/workflows/Test%20and%20Release/badge.svg)

Это альтернативный адаптер, использующий`JSON/RPC` -протокол для получения данных и отправки команд на медиасервер Logitech/Lyrion ( [LMS](https://de.wikipedia.org/wiki/Lyrion_Music_Server) ) для управления подключенными устройствами, такими как

- нативный [Squeezebox](https://de.wikipedia.org/wiki/Squeezebox) ,
- Raspberry Pi с дополнительным аудиомодулем и небольшими прошивками на базе Linux, такими как [PicorePlayer](https://picoreplayer.org/) или [Max2Play](https://www.max2play.com) .
- WiiM Multiroom Audio ( [может взаимодействовать с сервером LMS/Lyrion](https://faq.wiimhome.com/en/support/solutions/articles/72000610226-how-to-stream-music-from-lms-to-your-wiim-device-with-squeezelite) )
- с плагинами Chromecast, AirPlay или`UPnP/DLNA` -Устройства

Он`LMS` - Сервер может управлять/предоставлять очень большие музыкальные коллекции на жестких дисках или`NAS` подключайтесь к различным потоковым сервисам, например:`Spotify` ,`Deezer` ,`Soundcloud` ,`shoutcast` ,`tunein` ,`napster` ,`pandora` ,`tidal` и многое другое

- Установите пакет

## Конфигурация

### Основные настройки

| Вариант          | По умолчанию | Описание                                                                                              |
| ---------------- | ------------ | ----------------------------------------------------------------------------------------------------- |
| Сервер LMS       | `0.0.0.0`    | Имя хоста или IP-адрес медиасервера Logitech/Lyrion. Можно выбрать автоматически обнаруженный сервер. |
| порт LMS         | `9000`       | HTTP-порт, используемый JSON-RPC или экспериментальным плагином WebSocket.                            |
| Тип подключения  | `JSON-RPC`   | Использует стабильный HTTP JSON-RPC или экспериментальный плагин LMS WebSocket.                       |
| URL WebSocket    | пустой       | Дополнительный независимый URL-адрес веб-сервера для плагина, например.`http://192.168.1.87/` .       |
| Порт Telnet LMS  | `9090`       | Порт CLI/Telnet. Используется только с JSON-RPC при включенной сигнализации Telnet.                   |
| Имя пользователя | пустой       | Имя пользователя LMS (необязательно).                                                                 |
| Пароль           | пустой       | Пароль LMS (необязательно).                                                                           |

Для работы режима WebSocket требуется экспериментальный [плагин LMS WebSocket](https://github.com/LMS-Community/slimserver/tree/d1d0a683d8301c04e64be0425e0aec51fc4e8397/Slim/Plugin/WebSocket) . Он передает команды и уведомления по одному и тому же соединению, поэтому настройки Telnet в этом режиме игнорируются. Обычный опрос плеера остается включенным в качестве резервного варианта на случай отсутствия или неполноты уведомлений. URL-адреса WebSocket HTTP(S) преобразуются в WS(S), и`/ws` Добавляется автоматически, если указан только корневой URL-адрес.

### Настройки таймера

| Вариант                             | По умолчанию | Минимум | Описание                                                  |
| ----------------------------------- | ------------ | ------- | --------------------------------------------------------- |
| Обновление сервера (в секундах)     | `30`         | `15`    | Интервал для обновления информации на сервере LMS.        |
| Обновление проигрывателя (мс)       | `950`        | `200`   | Интервал для обновления информации о статусе игрока.      |
| Избранное обновление (минуты)       | `720`        | `1`     | Интервал для обновления дерева избранных.                 |
| Обновление обнаружения (в секундах) | `30`         | `10`    | Интервал для поиска других серверов LMS в локальной сети. |

Короткие интервалы обновления увеличивают количество запросов, отправляемых в систему управления обучением (LMS).

### Настройки производительности

| Вариант                              | По умолчанию  | Описание                                                                                                                  |
| ------------------------------------ | ------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Предоставьте информацию о плейлисте. | включено      | Создает и обновляет`Playlist` JSON-состояние для каждого игрока.                                                          |
| Поиск других серверов LMS            | включено      | Позволяет обнаруживать другие серверы LMS в локальной сети.                                                               |
| Используйте сигнализацию Telnet.     | неполноценный | При использовании JSON-RPC применяется LMS CLI/Telnet для дополнительной сигнализации о подключении и отключении игроков. |
| Запросить избранное                  | включено      | Периодически получает дерево избранных элементов из системы управления обучением (LMS).                                   |

Отключите ненужную информацию, чтобы уменьшить количество запросов к LMS и обработку адаптера.

### Настройки объявлений

| Вариант                         | По умолчанию  | Описание                                                                                                                      |
| ------------------------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| URL-адрес веб-сайта ioBroker    | пустой        | Например, базовый URL веб-экземпляра ioBroker.`http://192.168.1.10:8082` Требуется только для объявлений из локальных файлов. |
| Том объявлений                  | `50`          | Уровень громкости, используемый во время воспроизведения объявления. Допустимый диапазон: от 0 до 100.                        |
| Используйте FadeTools           | неполноценный | Использует дополнительный [плагин LMS FadeTools](https://github.com/oweitman/LMS-FadeTools) до и после объявлений.            |
| Длительность затухания          | `2` с         | Прошли целые секунды`fadeout stop` Допустимый диапазон: от 1 до 60 секунд.                                                    |
| Длительность плавного появления | `2` с         | Прошли целые секунды`fadein play` Допустимый диапазон: от 1 до 60 секунд.                                                     |

Для локальных файлов объявлений LMS должна иметь доступ к настроенному веб-адресу ioBroker. URL-адреса объявлений HTTP(S) передаются непосредственно в LMS и не требуют этой настройки. Команды FadeTools отправляются только при включении этой опции. Без FadeTools все значения громкости устанавливаются напрямую и проверяются с помощью LMS.

### Настройки отладки

| Вариант                         | По умолчанию  | Описание                                                                   |
| ------------------------------- | ------------- | -------------------------------------------------------------------------- |
| Отладочный вывод игрока         | неполноценный | Включает дополнительные отладочные сообщения для обработки проигрывателем. |
| Нелепый вывод игрока            | неполноценный | Включает возможность отправки очень подробных сообщений игроку.            |
| Вывод отладки сервера           | неполноценный | Включает дополнительные отладочные сообщения для обработки на сервере LMS. |
| Сервер выдает нелепый результат | неполноценный | Позволяет отправлять очень подробные сообщения на LMS-сервер.              |

Отладка, и особенно бессмысленное логирование, как правило, должны оставаться отключенными и включаться только во время диагностики проблемы.

## Поиск неисправностей

### Игроки SLIMP3

Сообщается, что старые версии плееров SLIMP3 могут не подключаться к серверу, пока адаптер ищет новые серверы. Отключение поиска в разделе «Конфигурация экземпляра -> Настройки производительности -> Поиск других серверов LMS» должно позволить плееру подключиться.

Удаленные потоки восстанавливаются без перемотки, поскольку они, как правило, не поддерживают позицию воспроизведения.

#### Примечания к точкам данных в зависимости от настройки TPE2 в LMS.

В зависимости от настроек, точкам данных передаются разные MP3-теги. Названия, написанные заглавными буквами, — это названия MP3-тегов.

| Настройка TPE2 в LMS            | Художник  | Альбумартис | Трекартист        | Группа    |
| ------------------------------- | --------- | ----------- | ----------------- | --------- |
| как группа                      | ХУДОЖНИК  | пустой      | ИСПОЛНИТЕЛЬ ТРЕКА | АЛЬБОМИСТ |

## Команды SendTo

### getPlayerNames

Возвращает имена всех игроков, зарегистрированных в данный момент в адаптере. Возвращаемые имена — это отредактированные имена, использованные ниже.`squeezeboxrpc.<instance>.Players` .

```js
async function main() {
    const playerNames = await sendToAsync('squeezeboxrpc.0', 'getPlayerNames', {});
    console.log(JSON.stringify(playerNames));
}
main();
```

Пример результата:

```json
["Living_room", "Kitchen"]
```

### cmdGeneral

Эта команда может использоваться для отправки любой команды на сервер LMS для получения ответа.

Пример:

**Все плейлисты:**

```js
async function main() {
    let data = await sendToAsync('squeezeboxrpc.0', 'cmdGeneral', {
        playerid: '',
        cmdArray: ['playlists', '0', '999', 'tags:us'],
    });
    console.log(JSON.stringify(data));
}
main();
```

**Все избранные:**

Эта команда используется адаптером внутри системы для загрузки избранных элементов.

```js
async function main() {
    let data = await sendToAsync('squeezeboxrpc.0', 'cmdGeneral', {
        playerid: '',
        cmdArray: ['favorites', 'items', '0', '999', 'want_url:1', 'item_id:'],
    });
    console.log(JSON.stringify(data));
}
main();
```

## Разработка

### вис-1

- запустить dev-сервер с помощью`dev-server watch --noStart`
- Запуск адаптера с конфигурацией запуска "Запуск адаптера ioBroker по умолчанию"
- Запустите скрипт отслеживания в каталоге виджетов с помощью`npm run watch`
- открыть редактор vis-1 или среду выполнения
- Если вы внесете изменения в виджет vis-1, подождите несколько секунд, пока изменения будут загружены на сервер разработки.
- В vis-1 перезагрузите страницу vis-1.
- Если в файле squeeboxrpc.html произошли изменения, необходимо перезапустить адаптер vis-1.

### вис-2

- Для отладки виджета vis-2 необходимо запустить vis-2 во втором окне vis-2.
- Для установки и запуска следуйте инструкциям по адресу <https://github.com/ioBroker/ioBroker.vis-2#development-and-debugging>
- Запуск адаптера с конфигурацией запуска "Запуск адаптера ioBroker по умолчанию"
- Запустите сервер разработки Vite в каталоге src-widgets с помощью`npm run start`
- В административной панели iobroker, во вкладке «Объекты», в экспертном режиме отредактируйте объект.`system.adapter.squeezeboxrpc.0`
- Измените common.visWidgets.vis2vis-squeezeboxrpc.url с vis2squeezeboxrpc/customWidgets.js на <http://localhost:4173/customWidgets.js> — это адрес сервера VITE.
- Откройте vis в режиме редактирования или выполнения с помощью конфигурации запуска "vis2 edit 3000" или "vis2 runtime 3000".
- Если вы внесете изменения в код виджета vis-2, произойдет автоматическая перезагрузка страницы или вы нажмете клавишу F5 в браузере.

### финальный тест времени выполнения

- останавливаться`dev-server` и ваш адаптер в VS Code
- Создайте производственную сборку и загрузите её на сервер разработки с помощью команды сборки.`dev-server upload`
- запустить iobroker с помощью`npm run start`
- Отмените изменение в параметре system.adapter.squeezeboxrpc.0 до исходного значения.
- Откройте vis-1 или vis-2 в режиме редактирования или во время выполнения.

### дополнительное тестирование на реальном сервере iobroker

- В корневом каталоге создайте файл пакета npm, содержащий следующее:`npm pack`
- В iobroker на вкладке admin/adapter в экспертном режиме нажмите кнопку cat.
- В диалоговом окне выберите вкладку`from file`
- выберите созданный файл пакета
- нажмите установить
- Если что-то не работает, при запуске оболочки.`iobroker upload all`
