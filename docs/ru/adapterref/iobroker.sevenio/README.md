# IoBroker.sevenio
**Тесты:** ![Тестирование и выпуск](https://github.com/ipod86/ioBroker.sevenio/workflows/Test%20and%20Release/badge.svg)

## Адаптер ioBroker для seven.io
Этот адаптер подключает ioBroker к API SMS и связи [seven.io](https://www.seven.io). Отправляйте SMS-сообщения и запускайте голосовые вызовы с преобразованием текста в речь непосредственно из ваших автоматизаций, скриптов Blockly или JavaScript — с управлением контактами, отслеживанием доставки, опросом входящих SMS и мониторингом баланса счета.

---

## Функции
- **Отправка SMS** — запуск через точку данных, блок Blockly или `sendTo()`
- **Flash SMS** — сообщение отображается непосредственно на экране получателя.
- **Голосовые вызовы (TTS)** — чтение любого текста вслух во время автоматического вызова
- **Статус доставки** — автоматическая проверка примерно через 60 секунд после отправки, записывается в специальное состояние.
- **Управление контактами** — синхронизация контактов из seven.io как отдельных точек данных; создание новых контактов непосредственно из ioBroker.
- **Получатель по имени** — введите имя контакта вместо номера телефона; адаптер автоматически определит его.
- **Опрос баланса счета** — настраиваемый интервал, результат доступен в виде читаемого состояния.
- **Опрос входящих SMS-сообщений** — прием входящих SMS-сообщений (требуется арендованный виртуальный номер, см. ниже)
- **Блок Blockly** — готовый к использованию блок в категории «Отправить кому» с флажками для отправки SMS и/или голосовых вызовов.
- **API `sendTo()`** — полная поддержка скриптов для адаптера JavaScript.

## Требования
- Аккаунт на [seven.io](https://www.seven.io)
— Действительный ключ API (его можно найти в вашей панели управления seven.io в разделе *Разработчик → Ключи API*).

**Модель затрат:**

— Отправка SMS и голосовые звонки оплачиваются по факту использования — вы платите только за сообщение или звонок, без ежемесячной платы.
— Для получения входящих SMS-сообщений требуется виртуальный номер телефона, арендованный у seven.io (примерно 20 евро в месяц). Без арендованного номера входящий опрос недоступен.

> **Частные пользователи:** seven.io — это в первую очередь бизнес-сервис. При регистрации необходимо указать название компании. Частные пользователи могут просто ввести свое имя или слово *Privat* в это поле — seven.io подтвердил, что это допустимо.

## Входящие SMS
Для получения ответов по SMS вам нужен **цифровой отправитель** — буквенно-цифровые имена (например, `MyCompany`) не могут напрямую получать ответы. У вас есть два варианта:

### Вариант 1 — Общий бассейн (бесплатно, для тестирования и неинтенсивного использования)
Передайте `getReplies: true` для каждого сообщения (флажок Blockly или параметр `sendTo()`). seven.io автоматически назначает временный номер из общего пула в качестве отправителя, поэтому ответы работают даже с буквенно-цифровым идентификатором отправителя.

| | |
|---|---|
| **Стоимость** | Бесплатно — взимается только стандартная плата за отправку SMS |
| **Окно для ответа** | Через 48 часов после отправки |
| **Стабильность номера** | Повторная попытка подключения к одному и тому же номеру в течение 2 недель не гарантируется |
| **Доступные страны** | DE 🇩🇪 AT 🇦🇹 CH 🇨🇭 US 🇺🇸 PL 🇵🇱 |
| **Подходит для** | Тестирования, небольших объемов некритических уведомлений |

### Вариант 2 — Собственный входящий номер (~20 евро/месяц)
Арендуйте виртуальный номер для входящих звонков прямо в панели управления seven.io. Ответы будут поступать надежно и постоянно.

| | |
|---|---|
| **Стоимость** | ~20 евро/месяц |
| **Окно ответа** | Без ограничений |
| **Стабильность числа** | Фиксированное, всегда одно и то же число |
| **Доступные страны** | Многие — проверьте панель управления seven.io |
| **Подходит для** | Постоянного общения с клиентами, производственного использования |

> Настройте интервал опроса в параметрах адаптера. Установите значение `0`, чтобы отключить входящий опрос (например, если вы используете веб-хуки).

> **Несколько сообщений за цикл:** Если между двумя опросами поступает несколько SMS-сообщений, адаптер обрабатывает их все — начиная с самых старых. Каждое сообщение вызывает отдельное изменение состояния в `sms.inbound.text`, поэтому каждое правило Blockly или автоматизация JavaScript, отслеживающая это состояние, срабатывает один раз для каждого сообщения. Точки данных всегда отражают самое последнее сообщение после цикла.

## Блокли
После установки адаптера готовый к использованию блок появится в категории **sendTo** редактора Blockly в ioBroker.

```
┌─ seven.io  |  SMS ☑  Voice call ☐ ─────────────┐
│  sender (optional)  [ ""                  ]      │
│  recipient          [ "+491234567890"     ]      │
│  message            [ "Alarm!"            ]      │
│  flash SMS ☐  replies (shared pool) ☐           │
│  ring time (s)  30                               │
│  instance  sevenio.0 ▼                           │
└──────────────────────────────────────────────────┘
```

— Отметьте **SMS**, чтобы отправить текстовое сообщение.
— Установите флажок «Голосовой вызов», чтобы инициировать автоматический вызов с преобразованием текста в речь.
— Выберите **оба варианта**, чтобы одновременно отправить SMS и совершить звонок (параллельно, без дополнительной задержки).
- **Ответы (общий пул)** — если этот параметр включен, seven.io использует номер из общего пула в качестве отправителя, чтобы получатель мог ответить (см. [Входящие SMS](#inbound-sms))
— В поле ввода **получатель** принимается номер телефона или имя контакта из вашего списка контактов seven.io.

## Скрипт sendTo()
Все функции доступны через `sendTo()` в JavaScript-адаптере.

**Отправить SMS:**

```javascript
sendTo('sevenio.0', 'send', {
    to: '+491234567890',   // or a contact name: 'Max Mustermann'
    text: 'Door opened!',
    flash: false,          // optional
    getReplies: true,      // optional — enable shared pool so recipient can reply
}, result => {
    console.log(result.statusText); // e.g. 'Success'
});
```

**Инициировать голосовой вызов:**

```javascript
sendTo('sevenio.0', 'voice', {
    to: '+491234567890',
    text: 'Attention! Motion detected in the garage.',
    ringtime: 30,          // optional, 5–60 s
});
```

**Узнать баланс счета:**

```javascript
sendTo('sevenio.0', 'get_balance', {}, result => {
    console.log(result.amount, result.currency);
});
```

**Получить список контактов:**

```javascript
sendTo('sevenio.0', 'get_contacts', {}, contacts => {
    console.log(JSON.stringify(contacts));
});
```

**Создать контакт:**

```javascript
sendTo('sevenio.0', 'create_contact', {
    name: 'Max Mustermann',
    number: '491234567890',   // without +
});
```

**Тестовое SMS (отправьте тестовое сообщение для проверки ключа API):**

```javascript
sendTo('sevenio.0', 'test_sms', { to: '+491234567890' }, result => {
    console.log(result.statusText);
});
```

**Тестовый голосовой звонок:**

```javascript
sendTo('sevenio.0', 'test_voice', { to: '+491234567890' }, result => {
    console.log(result);
});
```

**Немедленно обновите статистику:**

```javascript
sendTo('sevenio.0', 'get_stats', {}, result => {
    console.log(result); // raw analytics data
});
```

В качестве альтернативы установите точку данных `sevenio.0.stats.refresh` в значение `true` — адаптер получит обновленную статистику и автоматически сбросит состояние до `false`.

**Отложенное SMS-сообщение (запланированная доставка):**

```javascript
sendTo('sevenio.0', 'send', {
    to: '+491234567890',
    text: 'Good morning!',
    delay: '2026-12-24 08:00:00', // ISO datetime or Unix timestamp (seconds)
}, result => {
    console.log(result.statusText);
});
```

Параметр `delay` передается непосредственно в API seven.io. Используйте строку даты и времени в формате ISO (`YYYY-MM-DD HH:MM:SS`) или метку времени Unix в секундах. Сообщение ставится в очередь seven.io и доставляется в указанное время.

## Коды состояния SMS
Состояние `sms.lastStatus` содержит удобочитаемый перевод кода состояния seven.io:

| Код | Значение |
|---|---|
| 100 | Успех |
| 101 | Передача в центр SMS не удалась |
| 201 | Неверный номер получателя |
| 202 | Неверный идентификатор отправителя |
| 301 | Недостаточно кредитов |
| 403 | Отправитель занесен в черный список |
| 500 | Неизвестная ошибка |
| 700 | Таймаут доставки по сети |
