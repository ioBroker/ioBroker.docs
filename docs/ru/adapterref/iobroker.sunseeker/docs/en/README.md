# ioBroker.sunseeker

[Вернуться к файлу README](/#/adapters/sunseeker)

## Конфигурация

В настройках адаптера доступны следующие поля:

| Поле                                 | Описание                                                                   |
| ------------------------------------ | -------------------------------------------------------------------------- |
| Имя пользователя / электронная почта | Вход в приложение Sunseeker                                                |
| Пароль                               | Пароль приложения Sunseeker (хранится в зашифрованном виде)                |
| Область                              | `EU` или `US` (актуально только для `New` API)                               |
| API                                  | `New` для текущих моделей (S/X/V/V1), `Old` для более старых устройств      |
| Интервал опроса                      | Интервал опроса REST в секундах (минимум 30)                               |
| Язык                                 | Язык пользовательского интерфейса и кода событий, например `de-DE`, `en-EN` |

Выбор API зависит от модели:

- `New`: все газонокосилки серий S, X, V и V1 (сервер) `wirefree-specific.sk-robot.com` /`wirefree-specific-us.sk-robot.com`)
- `Old`: старые устройства без маркировки Wirefree (сервер) `server.sk-robot.com`)

## Функции

- Вход через REST API (предоставление пароля OAuth2) с автоматическим обновлением токена для одного пользователя. `setInterval`.
- Опрос списка устройств для каждой учетной записи, а также их состояния/настроек с заданным интервалом.
- MQTT push:
  - `New` API: TLS MQTT (порт 1884 для SXV, 32884 для V1) с паролем, зашифрованным с помощью RSA. После подключения адаптера запускается `getDevAllProperties`, `getSelectRegionID`, `getAllPath`, `getConsumableItems` и `getFcState` с помощью `get_property` Опубликуйте сообщение, чтобы полная информация о состоянии дел была доступна немедленно.
  - `Old` API: обычный MQTT включен `mqtts.sk-robot.com:1883` с жестко заданным пользователем приложения.
- Классификация моделей на `S`, `X`, `V` (включая V18/V3) и `V1` Конечные точки и параметры (`cmdurl` (режим границы, путь к свойству) выбираются автоматически.
- Переведенные коды событий: в комплект входят 12 языковых вариантов из языковых файлов Home Assistant. `lib/eventcodes.json` и прикреплены как `common.states` к `event_code` и `errortype` (с учетом модели), поэтому пользовательский интерфейс ioBroker отображает читаемые метки.

## Дерево объектов

Для каждой газонокосилки (серийный номер) `<sn>` Адаптер создает следующие каналы:

- `<sn>.mower_raw` — Состояние газонокосилки (опрос **и** запись данных по протоколу MQTT в одну и ту же папку)
- `<sn>.settings` — настройки устройства
- `<sn>.remote` — кнопки управления
- `<sn>.schedule` — Еженедельный план (можно записывать, см. ниже)
- `<sn>.events` — Журнал событий кошения в формате JSON и кнопка ручного обновления.
- `<sn>.map` — данные карты (только для моделей S/X, если доступны):
  - `info` — необработанный ответ `/wireless_map/wireless_device/get` (размеры, увеличение, `mapModifyTime`, …)
  - `zones` — Информация о зонах
    - `change_active_map_name`
    - `delete_active_map_select`
    - `delete_active_map`
    - `save_active_map`
    - `merge_zone`
      - `xx.start_mowing_selected_area`
      - `xx.name`
      - `xx.split_zones`
  - `image` — тепловая карта (URL-адрес данных PNG; часто пуст, если облако ее не отобразило)
  - `wifi` — Тепловая карта сигнала Wi-Fi (URL данных в формате PNG)
  - `net` — Тепловая карта сигнала 4G (URL данных в формате PNG)
  - `texture` — Исходная текстурная карта рабочей области (URL данных WebP)
  - `mapData` — Геометрия карты в виде необработанной строки JSON (зоны, полигоны — тот же источник, который HA использует для отображения своей карты в реальном времени).
  - `pathData` — записанный путь кошения в виде необработанной строки JSON
  - `backup` — резервная копия карты в формате JSON (из `/wireless_map/backup_map/get`)
  - `livemap` — URL-адрес данных PNG, отображаемых адаптером (зоны, препятствия, записанный путь, положение зарядного устройства; отображается с помощью `pureimage`)
  - `livemap_update` - Включение/отключение отображения карты в реальном времени (включение = +80 МБ ОЗУ)
  - `map_settings` - Настройки карты в реальном времени
    - `region_channel_fill` -
    - `region_channel_stroke` -
    - `region_channel_lineWidth` -
    - `region_work_fill` -
    - `region_work_stroke` -
    - `region_work_lineWidth` -
    - `region_forbidden_fill` -
    - `region_forbidden_stroke` -
    - `region_forbidden_lineWidth` -
    - `region_placed_blank_fill` -
    - `region_placed_blank_stroke` -
    - `region_placed_blank_lineWidth` -
    - `region_obstacle_fill` -
    - `region_obstacle_stroke` -
    - `region_obstacle_lineWidth` -
    - `divide_area_work_stroke` -
    - `divide_area_work_lineWidth` -
    - `polyline_color` -
    - `polyline_lineWidth` -
    - `robot_path` -
    - `charger_path` -
    - `robot_charger_scale` -
  - `maps` - Все резервные карты
    - `mapName` — Изменить название карты
    - `useThisMap` — Восстановить карту
    - `delete_select` — Выберите, чтобы удалить резервную карту.
    - `delete` — Удалить резервную карту

Исходные данные (REST и MQTT) записываются через `json2iob` напрямую — параллельная модель данных на стороне адаптера не поддерживается.

## Записываемые настройки

Эти настройки доступны для записи непосредственно в разделе `<sn>.settings.*` Написание их вслух передает... `set_property` /`setProperty` (Зависящий от модели) запрос в облако:

| Состояние                      | Диапазон                                                                        | Единица | Примечания            |
| ------------------------------ | ------------------------------------------------------------------------------- | ------- | --------------------- |
| `bladeSpeed`                   | 2800 – 3000 (шаг 100)                                                           | об/мин  | Только для нового API |
| `bladeHeight`                  | 20 – 100 (шаг 5)                                                                | мм      | Только для нового API |
| `rainFlag`                     | логический                                                                      | —       | Старый + Новый API    |
| `rainDelayDuration`            | 0 – 720 (шаг 1)                                                                 | мин     | Старый + Новый API    |
| `night_work`                   | логический                                                                      | —       | Только для нового API |
| `recharge_mode`                | 0 = прямой путь<br> 1 = умный<br> 2 = вдоль края                                | —       | Только для нового API |
| `work_touch_mode`              | 0 = бесконтактно<br> 1 = медленное касание                                      | —       | Только для нового API |
| `auto_ride_edge_map_m`         | 0 = не включено<br> 1 = включено                                                | —       | Только для нового API |
| `dis_along_border`             | 0 = закрыть<br> 1 = далеко                                                      | —       | Только для нового API |
| `first_along_border`           | логический                                                                      | —       | Только для нового API |

| `gap`                          | 1 = узкий<br> 2 = стандарт<br> 3 = широкий                                      | —       | Только для нового API |
| `workSpeed`                    | 1 = медленно<br> 2 = стандарт<br> 3 = быстро                                    | —       | Только для нового API |
| `ai_sensitivity`               | 0 = низкий<br> 1 = высокий                                                      | —       | Только для нового API |
| `dev_name`                     | Изменить имя устройства                                                         | —       | Только для нового API |

| `firmware_current`             | Доступная прошивка (только для чтения)                                          | —       | Старый + Новый API    |

| `auto_upgrade`                 |                                                                                 | —       | Только для нового API |

| `reset_blade`                  |                                                                                 | —       | Только для нового API |

| `reset_smal_blade`             |                                                                                 | —       | Только для нового API |

При записи значений параметров лезвия адаптер отправляет данные. `{ id: "setDevBlade", key: "blade", method: "set_property", speed|height: <int> }` После 1,5 секунд запланировано обновление статуса; обычно значения также обновляются при отправке MQTT-сообщений.

Письмо `rainFlag` или `rainDelayDuration` Всегда отправляет оба значения в облако (отсутствующее считывается из текущего состояния). Конечная точка зависит от модели:

- `Old`: `POST /app_mower/device/setRain/{sn}/{appId}` с `rainFlag` +`rainDelayDuration`.
- `New` В1: `POST {cmdurl}setProperty` с `method: "setRain"`, `rainFlag`, `rainDelayDuration`.
- `New` S/X/V: `POST {cmdurl}set_property` с `id: "setDevRain"`, `key: "rain"`, `rain_flag`, `delay`.

## Расписание (`<sn>.schedule.*`)

Простой недельный план с одним окном в день. Состояния можно изменять, но облачное хранилище обновляется только тогда, когда... `set` срабатывает.

| Состояние                   | Тип                                                                                | Формат                                                                      |
| --------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `1_monday_1` …`0_sunday_1`  | нить                                                                               | `"HH:MM-HH:MM"` Для активного окна пустая строка отключает отображение дня. |
| `1_monday_2` …`0_sunday_2`  | нить                                                                               | `"HH:MM-HH:MM"` Для активного окна пустая строка отключает отображение дня. |
| `pauseSchedule`             | логический                                                                         | Приостановите расписание, не очищая окна.                                   |
| `setSchedule`               | кнопка                                                                             | Отправляет текущие значения в облако.                                       |
| `getSchedule`               | кнопка                                                                             | Загрузите текущее расписание                                                |
| `schedule_time_work_repeat` | кнопка                                                                             | Цикл кошения по расписанию                                                  |
| `schedule_mode`             | 0 = нет расписания</br> 1 = рекомендуется</br> 1 = пользовательский (только X и S) | Отправляет текущие значения в облако.                                       |
| `schedule_time_zone`        | число                                                                              | Часовой пояс                                                                |

Отправляемая полезная нагрузка зависит от модели:

- `Old` API: `POST /app_mower/device-schedule/setScheduling` с `deviceScheduleBOS` все 7 дней; `autoFlag` является обратным к `pause`.
- `New` В1: `POST {cmdurl}setProperty` с `method: "setSchedule"` и `deviceScheduleBOS` содержит только активные дни.
- `New` S/X/V: `POST {cmdurl}set_property` с `id: "setTimeTactics"`, `key: "time_tactics"` и а `time` массив (одна запись на каждый активный день, индекс дня Пн=1…Сб=6, Вс=0; начало/конец в секундах с полуночи).

## Известные ограничения

API Sunseeker предоставляет доступ к гораздо большему количеству полей, чем адаптер в настоящее время может записывать. Все настройки доступны только для чтения в виде необработанных данных. `<sn>.settings` Следующие состояния **пока не** доступны для записи:

- Настройки зон (скорость/высота лезвия для каждой зоны, порядок выполнения операций)
- Обновление OTA
- Записи о выполненных работах / история покоса травы
- Настройки, специфичные для версии V1: обратный путь, блокировка экрана, расстояние до границы, включение/выключение расписания.
- Настройки Gen2: auto\_ride\_edge, energy\_save, night\_work
- чувствительность ИИ, ПИН-код, операции с картой
