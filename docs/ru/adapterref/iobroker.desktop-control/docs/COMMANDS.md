# Справочник команд

_Deutsche Fassung: [COMMANDS.de.md](/#/docs/adapterref/iobroker.desktop-control/docs/COMMANDS.de.md)_

_Сгенерировано автоматически из `WinCtl.exe --dump-protocol` (протокол 1, версия 0.6.4). Не редактировать вручную._

Команды отправляются на `{base}/{id}/cmd/<command>` (Полезная нагрузка: объект JSON или — для команд в _сокращенной форме_ — обычная строка).

## Система

### `ping`

Признак жизни, ответы со временем и версия агента

### `get_state`

Повторно публикует все значения состояния.

### `reload_config`

Перезагружает конфигурацию агента и переподключается.

### `exit` _(⚠ имеет отношение к безопасности)_

Останавливает агента

### `list_commands`

Возвращает список всех команд.

### `check_update`

Проверяет наличие более новой версии агента (релизы GitHub).

### `update`

Устанавливает последнюю версию агента и перезапускает агент.

## Мощность и сессия

### `lock`

Блокирует экран (Win+L)

### `sleep`

Поддерживать

### `hibernate`

Впасть в спячку

### `shutdown`

Выключает компьютер\
&#x20;Краткая форма: полезная нагрузка `<text>` равно `{"delay": "<text>"}`.

Примеры:

```
60
{"delay":0,"force":true}
```

| Параметр | Тип         | Необходимый | По умолчанию | Описание                         |
| -------- | ----------- | ----------- | ------------ | -------------------------------- |
| `delay`  | целое число |             | 10           | Задержка в секундах              |
| `force`  | логический  |             | ЛОЖЬ         | Принудительное закрытие программ |

### `restart`

Перезагружает компьютер\
&#x20;Краткая форма: полезная нагрузка `<text>` равно `{"delay": "<text>"}`.

Примеры:

```
30
{"delay":0,"force":true}
```

| Параметр | Тип         | Необходимый | По умолчанию | Описание                         |
| -------- | ----------- | ----------- | ------------ | -------------------------------- |
| `delay`  | целое число |             | 10           | Задержка в секундах              |
| `force`  | логический  |             | ЛОЖЬ         | Принудительное закрытие программ |

### `logoff`

Выводит пользователя из системы.

### `cancel_shutdown`

Отменяет запланированное отключение/перезапуск

### `monitor_off`

Выключает мониторы

### `monitor_on`

Включает мониторы

### `screensaver`

Запускает заставку (ту, что установлена в Windows, или файл .scr).\
&#x20;Краткая форма: полезная нагрузка `<text>` равно `{"file": "<text>"}`.

Примеры:

```
{"file":"C:/Windows/System32/Mystify.scr"}
```

| Параметр | Тип  | Необходимый | По умолчанию | Описание                                                       |
| -------- | ---- | ----------- | ------------ | -------------------------------------------------------------- |
| `file`   | нить |             | ""           | Путь к файлу .scr (пустое значение = путь, заданный в Windows) |

### `keep_awake` _(требуется сеанс графического интерфейса пользователя)_

Предотвращает переход в спящий режим и включение заставки.\
&#x20;Краткая форма: полезная нагрузка `<text>` равно `{"state": "<text>"}`.

Примеры:

```
{"state":true,"display":false}
```

| Параметр  | Тип        | Необходимый | По умолчанию | Описание                         |
| --------- | ---------- | ----------- | ------------ | -------------------------------- |
| `state`   | логический |             | истинный     | вкл/выкл                         |
| `display` | логический |             | истинный     | Оставьте экран также включенным. |

## Программы и окна

### `run` _(⚠ имеет отношение к безопасности)_

Запускает программу (псевдоним из настроек агента).\
&#x20;Краткая форма: полезная нагрузка `<text>` равно `{"path": "<text>"}`.

Примеры:

```
notepad
{"path":"kodi","args":"--fullscreen","window":"maximized"}
```

| Параметр  | Тип         | Необходимый | По умолчанию | Описание                                                              |
| --------- | ----------- | ----------- | ------------ | --------------------------------------------------------------------- |
| `path`    | нить        | да          |              | Псевдоним (например, «блокнот») или путь к исполняемому файлу (.exe). |
| `args`    | нить        |             |              | Аргументы в виде строки или списка.                                   |
| `workdir` | нить        |             |              | Рабочий каталог                                                       |
| `hidden`  | логический  |             |              | Начните без окна.                                                     |
| `window`  | нить        |             |              | Состояние окна (обычное / свернутое / развернутое)                    |
| `admin`   | логический  |             |              | От имени администратора (с помощью запроса UAC на компьютере!)        |
| `wait`    | логический  |             |              | Дождитесь завершения и верните код выхода.                            |
| `timeout` | целое число |             | 60           | Время ожидания в секундах с помощью функции ожидания                  |
