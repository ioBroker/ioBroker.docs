# Виджеты Metro

Плитки в стиле Windows 8 («Metro UI»): цветные плитки со значком, полосой с подписью и иконкой, плитки, открывающие диалоговое окно, элементы управления диммерами, жалюзи и термостатами, а также ползунок, переключатель и флажок.

![Все виджеты](../../../../../en/adapterref/iobroker.vis-metro/docs/img/overview.png)

Адаптер поставляет каждый виджет дважды: для **vis** (vis-1), как и раньше, и для **vis-2** в виде виджетов React. Оба имеют одинаковые идентификаторы виджетов и одинаковые настройки, поэтому проект vis продолжает работать в vis-2 как обычно — vis-2 отрисовывает виджеты с помощью версии React, которая выглядит и ведет себя так же. Для виджетов React требуется vis-2 версии 2.12.8 или новее; более старые версии vis-2 используют виджеты vis-1.

Виджеты находятся в группе **Metro** палитры виджетов.

## Общие настройки

Плитка состоит из **фона** , **значка** посередине, **фирменной символики** — полосы внизу с надписью — и **значка** в правом конце полосы.

| Параметр                                  | Значение                                                                                                                                             |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Фон, Фон бренда, Фон значка               | Цвета палитры Metro: `bg-*` однотонные цвета, `ribbed-*` Полосатые. Редактор предлагает их в списке с примером.                                        |
| Класс значка, значок                      | Значок шрифта Metro (`icon-*`), выбранный из списка.                                                                                                |
| URL значка, URL бейджа                    | Вместо (или в дополнение к) шрифту иконок используется изображение. Ширина, высота и смещение сверху и слева задаются в процентах от размера плитки. |
| Этикетка                                  | Текст комикса. Надписи могут содержать HTML-код.                                                                                                     |
| Эффект наведения курсора                  | Кадр отображается, когда указатель мыши находится над плиткой.                                                                                       |
| Трансформация                             | Плитка наклоняется в сторону места нажатия.                                                                                                          |
| Выбрать по значению / Выбрать по значению | Рамка вокруг плитки, пока состояние истинно (или имеет значение).                                                                                    |

Многие плитки имеют два варианта каждого цвета, значка и метки: **... по умолчанию false** и **... по умолчанию true** . Плитка отображает вариант, соответствующий состоянию: false — это... `false`, `0`, `"0"`, `"false"`, пустое значение и отсутствие значения вообще - все остальное истинно.

Настройки **диалоговых** окон:

| Параметр                                         | Значение                                                                                                 |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| Заголовок                                        | Заголовок диалогового окна (допускается HTML). Для некоторых блоков вместо заголовка используется метка. |
| Ширина диалогового окна, Высота диалогового окна | Размер указывается в пикселях. Без указания размера диалоговое окно принимает размер своего содержимого. |
| Плоский дизайн                                   | Плоское окно без синей рамы.                                                                             |
| Тень                                             | Тень вокруг окна.                                                                                        |
| Перетаскиваемый                                  | Диалоговое окно можно перемещать, держа его за заголовок.                                                |
| Модальный                                        | Страница, расположенная за диалогом, затемнена.                                                          |
| URL иконки, класс иконки                         | Значок в строке заголовка.                                                                               |

Одновременно открыто только одно диалоговое окно. Пока оно открыто, страница за ним не реагирует — ни в модальном, ни в обычном режиме — и диалоговое окно закрывается, отображая крестик в строке заголовка.

## Плитки, которые переключаются

### Состояние плитки

![Состояние плитки](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileState.png)

`tplMetroTileState` — При нажатии записывается фиксированное значение; на плитке отображается, имеет ли состояние это значение.

| Параметр                     | Значение                                                                                                                                                                                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Удостоверение личности штата | Состояние, которое зафиксировано в письменном виде.                                                                                                                                                                                        |
| Ценить                       | Значение, которое записывает один клик. `true` /`false` записываются как логические значения, числа — как числа (`5`), все остальное в виде текста -`01` Например, текст "01" остается неизменным. Без значения записывается пустой текст. |
| Выберите значение            | Рамка, в то время как государство обладает ценностью.                                                                                                                                                                                      |

### Штат / Номер значка

![Штат / Номер значка](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileStateNumber.png)

`tplMetroTileStateNumber` — как в Tile State, где значение **идентификатора номера** отображается на значке.

### Переключить плитку

![Переключить плитку](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileToggle.png)

`tplMetroTileToggle` - щелчок переключает **идентификатор объекта** : `false` пустое значение или отсутствие значения становится `true`, `true` становится `false` Число становится `0` если значение равно 0,5 или больше, иначе `1`.

При использовании настроек группы **«Управление другими состояниями»** плитка переключает другие состояния:

| Параметр                                                                           | Значение                                                                                                                                                                               |
| ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Идентификатор объекта для значения true / Идентификатор объекта для значения false | Вместо идентификатора объекта указывается другой идентификатор; если **значение false не совпадает с идентификатором объекта,** то для обоих значений используется идентификатор true. |
| Значение для истинности / Значение для ложности                                    | Ценности, которые записаны.                                                                                                                                                            |
| URL для true / URL для false                                                       | Вызывается при клике; если **URL не равен false,** то оба раза вызывается URL, соответствующий значению true.                                                                          |

Какой из двух вариантов будет использован, зависит от идентификатора объекта: если он включен (`true`, `1`), используется сторона «false», в противном случае — сторона «true». Без идентификатора объекта плитка запоминает последний щелчок и меняет стороны при каждом щелчке.

### Переключить плитку / Номер значка

![Переключить плитку / Номер значка](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileToggleNumber.png)

`tplMetroTileToggleNumber` — как переключатель плиток, со значением **числового идентификатора** в значке.

### Плиточная навигация

![Плиточная навигация](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileNav.png)

`tplMetroTileNav` - открывает **представление для открытия** . Пока это представление отображается, плитка принимает свои активные цвета ( **активен фон** , **активен фон бренда** , **активен фон значка** ), а при **выборе текущего представления** также рамку. **Фон страницы** задает фон страницы при открытии представления.

## Плитки с диалогом

При нажатии на эти плитки открывается диалоговое окно. Сама плитка имеет один фон, один значок ( **класс Icon** или **URL значка** ), подпись и значок.

### Диалоговое окно "Плитка" (логическое значение)

![Диалоговое окно "Плитка" (логическое значение)](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileBoolDialog.png)

`tplMetroTileBoolDialog` - Тип данных Tile Bool, щелчок по которому открывает **представление в диалоговом окне** .

### Диалоговое окно плиток, вид

![Диалоговое окно плиток, вид](../img/tplMetroTileDialog.png)![Диалоговое окно плитки, вид / Номер значка](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileDialogNumber.png)

`tplMetroTileDialog`, `tplMetroTileDialogNumber` — Щелчок открывает **окно просмотра в диалоговом окне** . Во втором окне отображается значение **идентификатора номера** на значке, если оно больше 0.

### Диалоговое окно плитки, HTML

![Диалоговое окно плитки, HTML](../img/tplMetroTileDialogStatic.png)![Диалоговое окно плитки, HTML / Номер значка](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileStaticDialogNumber.png)

`tplMetroTileDialogStatic`, `tplMetroTileStaticDialogNumber` — Щелчок открывает диалоговое окно с фиксированным **содержимым (HTML)** . На плитке рядом со значком отображается значение **идентификатора содержимого (Content ID** ); на втором значке также отображается число.

### Диалоговое окно плитки, текст состояния

![Диалоговое окно плитки, текст состояния](../img/tplMetroTileDialogString.png)![Диалоговое окно плитки, текст состояния / Номер значка](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileStringDialogNumber.png)

`tplMetroTileDialogString`, `tplMetroTileStringDialogNumber` — Щелчок мышью открывает диалоговое окно со значением **идентификатора диалогового окна** (допускается HTML), **размером шрифта диалогового окна** , **отступами диалогового окна** и **выравниванием текста диалогового окна** . Диалоговое окно отслеживает изменения состояния во время его открытия.

### Плиточный диалог, iFrame

![Плиточный диалог, iFrame](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileFrameDialogNumber.png)

`tplMetroTileFrameDialogNumber` — Щелчок открывает **URL-адрес диалога** во фрейме; **Прокрутка в iFrame** позволяет прокручивать страницу. Значок отображает **текст значка** , а рядом с ним — **содержимое** плитки.

| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Мин, Макс                                               | Диапазон регулировки диммера. Переключатель выводит максимальное и минимальное значения. **Установите оба параметра** — без них ползунок не будет работать, как в vis-1. |
| Шаг                                                     | Значения ползунка округляются до этого значения.                                                                                                                         |

### Диалоговое окно диммера плитки

![Диалоговое окно диммера плитки](../img/tplMetroTileDimmerDialog.png)![Диалоговое окно диммера плитки, активная полоса](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileDimmerDialogactiv.png)

`tplMetroTileDimmerDialog`, `tplMetroTileDimmerDialogactiv` — Плитка с изображением лампы; щелчок открывает переключатель и ползунок в диалоговом окне. Без параметров min и max диапазон значений составляет от 0 до 1. **Десятичные знаки** заставляют ползунок записывать значение с соответствующим количеством знаков после запятой (в виде текста). Вторая плитка окрашивает свою полосу цветом **Brand background (true)** , когда диммер включен, и **Brand background (false),** когда он выключен.

Окно открыто на максимальном уровне и закрыто на минимальном. Пока **идентификатор рабочего состояния** равен true, переключатель сохраняет свое положение.

### Отопление плиткой

![Отопление плиткой](../../../../../en/adapterref/iobroker.vis-metro/docs/img/tplMetroTileHeating.png)

`tplMetroTileHeating` — Широкая плитка с указанием заданной и фактической температуры, положения клапана и влажности, а также ползунок для установки температуры. Каждая строка отображается только при выборе соответствующего состояния; без заданной температуры ползунок скрыт.

| Параметр                                                                                            | Значение                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## Отличия от vis-1

Виджеты vis-2 точно воспроизводят виджеты vis-1 — каждый виджет, открытое диалоговое окно и клик были сравнены с оригинальными шаблонами, пиксель за пикселем и запись за записью. Это включает в себя некоторые особенности vis-1, которые были сохранены, чтобы существующие проекты выглядели одинаково:

- В полях "Значок значка" для полей "Tile Bool", "Tile Bool Dialog" и "Tile Toggle" всегда используется **значение "Badge URL by false"** .
- Значок Tile Toggle определяется значением текста: тексты «false» и «0» отображают значок значения true, а все остальное на плитке — значение false.
- Переключатель диммера и жалюзи включен для всех значений, кроме 0, false и пустого значения — а не только для значений выше середины диапазона минимального и максимального значений.
- Функция Tile Dimmer не работает без параметров min и max (см. выше).
- Лампа и окно считаются `true` как 1, а не как максимум.
- Переключатель плитки с **идентификатором объекта (true)** , но без **значения (true)** выводит пустой текст.
- Диалоговое окно с текстом, отображающим состояние, показывает состояние `null` как "null"; так же, как и короткая строка диалогового окна отопления.
- Надпись по умолчанию "Установить температуру" в диалоговом окне отопления не переведена.

Некоторые настройки не действовали в vis-1 и больше не предлагаются; значения, сохраненные в проекте, сохраняются и просто игнорируются, как и раньше:

| Виджет                                          | Параметр                                                                                                            |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Штат / Номер значка                             | Фон значка, Скрыть на 0                                                                                             |
| Переключить плитку / Номер значка               | Скрыть на 0, Фон значка на false / на true                                                                          |
| Диалоговые плитки с номером бейджа              | Скрыть на 0                                                                                                         |
| Плиточная навигация                             | Эффекты изменения вида (эффект скрытия/отображения, длительность, параметры, синхронизация) - vis-2 сам меняет вид. |
| Ползунок по горизонтали и вертикали             | Цвет ползунка, идентификатор рабочего состояния                                                                     |
| Диалоговое окно диммера плитки, активная полоса | Фоновое изображение бренда, автоматическое закрытие диалога.                                                        |

В двух моментах по сравнению с vis-1 все работает лучше: диалоговое окно обогрева отображает значения даже тогда, когда состояние представлено текстом (vis-1 показывал пустое диалоговое окно), и ползунки снова измеряют свои значения при изменении размера виджета.
