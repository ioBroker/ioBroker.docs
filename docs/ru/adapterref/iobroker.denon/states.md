# Все точки данных

[← вернуться к файлу README](/#/adapters/denon)

Точка данных создается только тогда, когда получатель отвечает на соответствующий запрос. Таким образом, каждая модель получает только те точки данных, которые она способна обработать. (Клавиши (Ролик)) `button`) возникают вместе с ценностью, к которой они принадлежат.

### info – Информация об устройстве и текущем сигнале (только для чтения)

| Состояние                                       | Описание                                                                                            |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `connection`                                    | `true`, при условии установления соединения с приемником.                                          |
| `name`                                          | Название устройства, заданное в ресивере.                                                           |
| `model`, `brand`, `zones`                       | Модель (например) `AVR-X2200W`), бренд (`Denon` /`Marantz`), Количество зон, включая основную зону |
| `firmware`, `firmwareDts`                       | Версия прошивки ресивера и декодера DTS                                                             |
| `audioSignal`                                   | Аудиосигнал в текстовом формате, например. `Dolby TrueHD / Atmos`                                    |
| `audioSignalCode`, `audioSampleRate`            | Код аудиосигнала (таблица ниже) и частота дискретизации, например: `48K`                             |
| `videoInputResolution`, `videoOutputResolution` | Разрешение на входе и выходе HDMI, например. `1080p 24Hz`, `2160p 50/60Hz`, `no signal`             |
| `videoResolutionCode`                           | Исходный код разрешения видео (модели примерно до 2016 года)                                        |
| `soundModeGroup`                                | активная звуковая группа: `MOV` Фильм, `MUS` Музыка, `GAM` Игра, `PUR` Чистый                           |

Коды измеренных сигналов ресивера AVR-X2200W. Коды зависят от поколения модели; в более новых моделях могут использоваться другие значения:

| `audioSignalCode` | сигнал                                                                       |   | Число `videoResolutionCode` | разрешение     |
| ----------------- | ---------------------------------------------------------------------------- | - | -------------------------- | -------------- |
| `01`              | Режим ожидания / аналоговый                                                  |   | `0`                        | нет сигнала    |
| `02`              | PCM (стерео и многоканальный)                                                |   | `2`                        | 480p/576p      |
| `03`              | Dolby Digital                                                                |   | `6`                        | 720p           |
| `04`              | Dolby Digital Plus                                                           |   | `7`                        | 1080p 50/60 Гц |
| `05`              | Dolby TrueHD (также с Atmos)                                                 |   | `8`                        | 1080p 24 Гц    |
| `06`              | ДТС                                                                          |   | `9`                        | 2160p 24/25 Гц |
| `08`              | DTS-HD Высокое разрешение                                                    |   | `A`                        | 2160p 50/60 Гц |
| `09`              | DTS-HD Master Audio                                                          |   |                            |                |
| `12`              | Нет сигнала (при переключении, а также в режиме ожидания для Marantz Cinema) |   |                            |                |

Видеокод состоит из `0`, цифра для ввода и цифра для вывода, например. `088` = 1080p 24 Гц, включение и выключение.

## Многозонный усилитель (DENON POA-3012CI)

Многозонные усилители, такие как DENON POA-3012CI, используют другой протокол. В США `info.connection`, `system.power`, `expert.*` и `display.brightness` Они соответствуют описанным выше. Кроме того, для каждой зоны 2 ... 12 (четные числа) создаются следующие состояния:

| Состояние                                                      | тип        | Р/В | Описание                                                                                          |
| -------------------------------------------------------------- | ---------- | --- | ------------------------------------------------------------------------------------------------- |
| `zoneX.speakerOneVolume` /`zoneX.speakerTwoVolume`             | число      | Р/В | Громкость динамика 0 ... 99. В рабочем режиме. `BRIDGED` Оба процесса контролируются одновременно. |
| `zoneX.selectInputOne` /`zoneX.selectInputTwo`                 | нить       | Р/В | Ввод с динамика: `0` Автобус L, `1` Автобус R, `2` Автобус М, `3` AUX                                 |
| `zoneX.operationMode`                                          | нить       | Р/В | `0` НОРМАЛЬНЫЙ, `1` МОСТ                                                                           |
| `zoneX.lowCutFilterSpeakerOne` /`zoneX.lowCutFilterSpeakerTwo` | логический | Р/В | Фильтр нижних частот громкоговорителя                                                             |
| `zoneX.zoneTurnOnModeChange`                                   | нить       | Р/В | `0` навсегда, `1` Входной сигнал триггера, `2` Аудиосигнал `3` из                                    |
| `zoneX.triggerInput`                                           | логический | Р/В | Вход триггера                                                                                     |
| `zoneX.audioSignalInput`                                       | логический | Р/В | Вход аудиосигнала                                                                                 |
| `system.powerConfigurationChange`                              | нить       | Р/В | конфигурация питания                                                                              |
| `system.masterTriggerInput`                                    | логический | Р/В | Вход главного триггера                                                                            |

## Технические характеристики

- **Подключение:** Адаптер использует официальный протокол управления Telnet на порту 23. После потери соединения он автоматически переподключается (через 1 с, 2 с, 4 с ... до 60 с). Если приемник ничего не отправляет в течение 30 секунд, отправляется запрос; если ответа нет, соединение переподключается. Отклонение соединения отображается только как предупреждение через 30 секунд, поскольку даже приемник, находящийся в процессе загрузки, будет отклонять соединение в течение нескольких секунд.
- **Частота отправки команд:** Команды помещаются в очередь и отправляются с заданным интервалом. Пользовательские команды отправляются до любых ожидающих запросов. После включения питания следующая команда отправляется с задержкой в 1 секунду, как указано в протоколе.
- **Значения:** Значения, считываемые из списков выбора, представляют собой коды получателя (например, `BRI` Можно ввести код или отображаемое имя. Режимы объемного звучания, сообщаемые ресивером, но отсутствующие в списке, будут добавлены автоматически.
- **Denon и Marantz:** Функция Quick Select в Denon означает примерно следующее. `QUICK` в Marantz `SMART` Адаптер распознает марку и отправляет только соответствующую команду.
- **Изменения настроек в режиме ожидания:** при включении основной зоны адаптер повторно считывает все настройки.
