# Все штаты

[← вернуться к файлу README](/#/adapters/denon)

Состояние создается только после того, как получатель ответит на соответствующий запрос, поэтому каждая модель получает только те состояния, которые она поддерживает. Кнопки (роль) `button`) создаются вместе с ценностью, которой они принадлежат.

### info – устройство и текущий сигнал (только для чтения)

| Состояние                                       | Описание                                                                                            |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `connection`                                    | `true` при подключении к приемнику                                                                  |
| `name`                                          | имя устройства, заданное в ресивере                                                                 |
| `model`, `brand`, `zones`                       | модель (например) `AVR-X2200W`), бренд (`Denon` /`Marantz`), количество зон, включая основную зону |
| `firmware`, `firmwareDts`                       | версия прошивки приемника и декодера DTS                                                            |
| `audioSignal`                                   | аудиосигнал в виде текста, например `Dolby TrueHD / Atmos`                                           |
| `audioSignalCode`, `audioSampleRate`            | код аудиосигнала (таблица ниже) и частота дискретизации, например `48K`                              |
| `videoInputResolution`, `videoOutputResolution` | разрешение на входе и выходе HDMI, например `1080p 24Hz`, `2160p 50/60Hz`, `no signal`              |
| `videoResolutionCode`                           | Исходный код разрешения видео (модели примерно до 2016 года)                                        |
| `soundModeGroup`                                | активная группа звуковых режимов: `MOV` фильм, `MUS` музыка, `GAM` игра, `PUR` чистый                   |

Коды сигналов, измеренные на AVR-X2200W. Коды зависят от поколения модели; в более новых моделях могут использоваться другие значения:

| `audioSignalCode` | Сигнал                                                                               |   | Цифра `videoResolutionCode` | Разрешение     |
| ----------------- | ------------------------------------------------------------------------------------ | - | -------------------------- | -------------- |
| `01`              | режим ожидания / аналоговый                                                          |   | `0`                        | нет сигнала    |
| `02`              | PCM (стерео и многоканальный)                                                        |   | `2`                        | 480p/576p      |
| `03`              | Dolby Digital                                                                        |   | `6`                        | 720p           |
| `04`              | Dolby Digital Plus                                                                   |   | `7`                        | 1080p 50/60 Гц |
| `05`              | Dolby TrueHD (также с Atmos)                                                         |   | `8`                        | 1080p 24 Гц    |
| `06`              | ДТС                                                                                  |   | `9`                        | 2160p 24/25 Гц |
| `08`              | DTS-HD Высокое разрешение                                                            |   | `A`                        | 2160p 50/60 Гц |
| `09`              | DTS-HD Master Audio                                                                  |   |                            |                |
| `12`              | Нет сигнала (во время переключения Marantz Cinema также находится в режиме ожидания) |   |                            |                |

Видеокод состоит из `0` разряд входного сигнала и разряд выходного сигнала, например `088` = 1080p 24 Гц вход и выход.

## Многозонные усилители (DENON POA-3012CI)

Многозонные усилители, такие как DENON POA-3012CI, используют другой протокол. Штаты `info.connection`, `system.power`, `expert.*` и `display.brightness` равны указанным выше. Кроме того, для каждой зоны создаются следующие состояния 2 ... 12 (четные числа):

| Состояние                                                      | Тип        | Р/В | Описание                                                                                      |
| -------------------------------------------------------------- | ---------- | --- | --------------------------------------------------------------------------------------------- |
| `zoneX.speakerOneVolume` /`zoneX.speakerTwoVolume`             | число      | Р/В | Громкость динамика 0 ... 99. В рабочем режиме `BRIDGED` Оба динамика управляются одновременно. |
| `zoneX.selectInputOne` /`zoneX.selectInputTwo`                 | нить       | Р/В | Вводные данные говорящего: `0` Автобус L, `1` Автобус R, `2` Автобус М, `3` AUX                   |
| `zoneX.operationMode`                                          | нить       | Р/В | `0` НОРМАЛЬНЫЙ, `1` МОСТ                                                                       |
| `zoneX.lowCutFilterSpeakerOne` /`zoneX.lowCutFilterSpeakerTwo` | логический | Р/В | Фильтр нижних частот динамика                                                                 |
| `zoneX.zoneTurnOnModeChange`                                   | нить       | Р/В | `0` постоянный, `1` триггер в `2` аудиосигнал, `3` выключенный                                   |
| `zoneX.triggerInput`                                           | логический | Р/В | Вход триггера                                                                                 |
| `zoneX.audioSignalInput`                                       | логический | Р/В | Вход аудиосигнала                                                                             |
| `system.powerConfigurationChange`                              | нить       | Р/В | конфигурация питания                                                                          |
| `system.masterTriggerInput`                                    | логический | Р/В | Вход главного триггера                                                                        |

## Технические характеристики

- **Подключение:** адаптер использует официальный протокол управления Telnet на порту 23. После потери соединения он автоматически переподключается (через 1 с, 2 с, 4 с ... до 60 с). Если приемник ничего не отправляет в течение 30 секунд, отправляется запрос; если ответа нет, он переподключается. Отказ в соединении отображается только как предупреждение через 30 секунд, поскольку загружающийся приемник также отклоняет соединения в течение нескольких секунд.
- **Регулировка частоты выполнения команд:** команды ставятся в очередь и отправляются с заданным интервалом. Команды пользователя отправляются до ожидающих запросов. После включения следующая команда отправляется с задержкой в 1 секунду в соответствии с требованиями протокола.
- **Значения:** значения, считываемые из списков значений, представляют собой коды получателя (например, `BRI`). При записи принимается код или отображаемое имя. Режимы объемного звучания, сообщаемые ресивером и отсутствующие в списке, добавляются автоматически.
- **Denon и Marantz:** быстрый выбор вариантов использования `QUICK` на Denon и `SMART` На ресиверах Marantz. Адаптер определяет марку и отправляет только соответствующую команду.
- **Настройки изменяются в режиме ожидания:** при включении основной зоны все настройки считываются заново.
