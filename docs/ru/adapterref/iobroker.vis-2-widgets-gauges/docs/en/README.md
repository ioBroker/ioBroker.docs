## Общий

### Требования

Эти виджеты находятся в наборе виджетов **Gauges** редактора vis-2. Для их отображения необходим адаптер vis-2; vis (vis-1) их не отображает.

В таблицах ниже **«Setting»** — это метка в редакторе vis-2, а **«Attribute»** — имя, хранящееся в проекте. Используйте имя атрибута при редактировании проекта в формате JSON или копировании настроек между виджетами. **«Default»** — это значение, используемое виджетом, если поле пустое; для нового виджета редактор уже заполняет значения по умолчанию из настроек, отмеченных _(новый виджет)_ .

### Проекты из версии 2.0

В версии 2.0 индикаторы цвета, уровня воды и заряда батареи отображались с помощью библиотек react-gauge-chart, react-liquid-gauge и react-battery-gauge (все на основе d3). Эти библиотеки удалены, виджеты теперь представляют собой обычные SVG-изображения — они меньше, быстрее и совместимы с текущей версией React vis-2. Идентификаторы виджетов и все имена атрибутов остались прежними, поэтому существующие проекты сохраняют свои настройки. Некоторые вещи выглядят иначе:

- **Цветовая шкала** : значение отображается ниже оси иглы, а не позади нее. Минимальное и максимальное значения могут отображаться на концах шкалы. Теперь отображается _длина иглы_ . Радиус скругления углов, дугообразный отступ или поле. `0` Сейчас это действительно 0 — раньше было так. `0` имелось в виду значение по умолчанию.
- **Индикатор цвета** : пустой индикатор _единицы измерения_ не отображает единицу измерения. Отображается только виджет, единица измерения которого никогда не была задана. `%` как и прежде.
- **Индикатор уровня воды** : ранее значение отображалось со всеми цифрами; теперь максимум две, или столько, сколько указано в _поле «Цифры после запятой»_ . Во время анимации подъема уровень увеличивается вместе с жидкостью.
- **Индикатор заряда батареи** : текст остается горизонтальным при вертикальном положении батареи, индикатор зарядки находится в вертикальном положении.
- Значение, которое не является числом (например) `offline`) отображается в виде текста; состояние без значения показывает `–`.

### Цвета и уровни

Большинство индикаторов окрашивают свою шкалу или значение в соответствии с **уровнями** . Все виджеты описывают уровни одинаково:

| Параметр           | Атрибут                                    | Описание                                                                                                                                                                       |
| ------------------ | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Количество уровней | `levelsCount`                              | Количество уровней. Для каждого уровня существует группа _: Уровень 1_ , _Уровень 2_ , ...                                                                                     |
| Цвет               | `color1`... `colorN`                       | Цвет уровня. Если не каждый уровень имеет свой цвет, цвета идут от первого до последнего заданного; без каких-либо цветовых переходов от зеленого через желтый к красному.     |
| Пороговый уровень  | `levelThreshold1`... `levelThreshold(N-1)` | Абсолютное значение, при котором заканчивается этот уровень. Последний уровень всегда заканчивается на максимуме. Пустой порог равномерно распределяет оставшуюся часть шкалы. |

Дуга, линейный манометр, термометр и резервуар также имеют **цветовую маркировку** (`colorMode`):

| Ценить                         | Описание                                                 |
| ------------------------------ | -------------------------------------------------------- |
| Один цвет (`fixed`)           | Значение всегда отображается _цветом_ (`valueColor`).   |
| Цвет уровня (`levels`)        | Значение получает цвет уровня, на котором оно находится. |
| Градиент уровней (`gradient`) | Цвета уровней плавно перетекают друг в друга.            |

![Уровни](../../../../../en/adapterref/iobroker.vis-2-widgets-gauges/docs/img/levels.png)

Пример: концентрация CO₂ от 400 до 2000 ppm с четырьмя уровнями (`levelThreshold1` = 800, `levelThreshold2` = 1000, `levelThreshold3` = 1400) в дуговом калибре с каждой расцветкой, в сегментах и в виде цветовых полос радиального калибра.

### Анимация

Новые виджеты плавно перемещаются на новое значение:

| Параметр              | Атрибут           | По умолчанию        | Описание                                                                                                                                                         |
| --------------------- | ----------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Оживить               | `animate`         | на _(новый виджет)_ | Без этого стоимость резко возрастает.                                                                                                                            |
| Длительность анимации | `animateDuration` | зависит от виджета  | Длительность в мс.                                                                                                                                               |
| Сглаживание анимации  | `animationEasing` | зависит от виджета  | Ход движения: `linear`, `quadIn`, `cubicOut`, `backOut` (немного выходит за рамки дозволенного), `elasticOut` (качели), `bounceOut` (отскоки), ... - ослабление d3. |

### Темная тема

В темной теме vis-2 все незаданные цвета следуют теме: текст, шкалы, пустая дорожка дуги, циферблат радиального индикатора и компас. Заданные цвета остаются без изменений.
