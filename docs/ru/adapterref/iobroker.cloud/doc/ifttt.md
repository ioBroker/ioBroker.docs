# Как использовать IFTTT с ioBroker

Здесь вы узнаете, как использовать IFTTT с ioBroker, используя сервис Webhooks от IFTTT. Мы начнем с изучения взаимодействия ioBroker и IFTTT, создав апплет, отправляющий данные из ioBroker через IFTTT в Telegram. Конечно, это можно сделать и с помощью адаптера, что более прямой способ, но это хороший пример того, как это работает.

- [Отправка данных в IFTTT](#sending-data-to-ifttt)
- [Получение данных из IFTTT](#getting-data-from-ifttt)

---

## Отправка данных в IFTTT

Мы создадим апплет, используя следующую цепочку действий: ioBroker => Webhook (IFTTT) => Telegram

**1. Для этого начнём с создания нового апплета:**

![Изображение, демонстрирующее стартовую страницу создания апплета IFTTT.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_01.png)

**2. Теперь начните как обычно, нажав на "+это", а затем выберите в качестве службы веб-перехватчики.**

![Изображение, демонстрирующее выбор сервиса IFTTT с выбранными веб-перехватчиками сервиса.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_02.png)

**3. Выберите здесь единственный доступный вариант «Получить веб-запрос» в качестве триггера для цепочки.**

![Изображение, демонстрирующее страницу выбора триггера IFTTT.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_03.png)

**4. Теперь назовём наше событие, выбрав здесь то же имя, которое вы будете использовать позже в Blocky. В этом примере назовём его "state".**

![Изображение, демонстрирующее страницу поля триггера службы веб-перехватчика, с красной стрелкой, указывающей, куда следует ввести имя события.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_04.png)

**5. Поскольку мы закончили с частью апплета, отвечающей за запуск, теперь перейдем к действию. Для этого нажмите "+затем".**

![Изображение, демонстрирующее общий обзор апплета с выбранными веб-перехватчиками и выделенной частью "+".](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_05.png)

**6. Теперь найдите Telegram и нажмите на него (если ваш Telegram еще не подключен, вам нужно выполнить соответствующую процедуру; в этом руководстве предполагается, что это уже сделано).**

![Изображение, демонстрирующее выбор сервиса IFTTT для целевого сервиса с полем поиска, в которое введено слово Telegram.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_06.png)

**7. В качестве действия выберите "Отправить сообщение".**

![Изображение, показывающее страницу выбора действия, с красной стрелкой, указывающей на действие «Отправить сообщение».](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_07.png)

**8. Теперь настроим, куда должно быть отправлено сообщение и как оно будет выглядеть. Пожалуйста, заполните поля, как показано на рисунке. В этом примере Value1 будет ObjectID, Value2 — значением объекта, а Value3 — состоянием ACK (false/true).**

![Изображение, демонстрирующее полную страницу действий с заполненным полем сообщения для нашего примера, где в качестве ингредиентов указаны Value1/Value2/Value3.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_08.png)

**9. Создание апплета завершено, поэтому при желании переименуйте его и нажмите «Готово», чтобы завершить процесс создания апплета.**

![Изображение, демонстрирующее заключительную страницу процесса создания апплета.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_09.png)

**10. Теперь нам нужен ключ, который требуется сервису IFTTT Webhooks для отправки событий. Для этого перейдите по ссылке <https://ifttt.com/maker_webhooks> и нажмите кнопку «Документация». Затем на следующей странице, как показано ниже, вы найдете свой ключ; скопируйте его, так как он понадобится нам для ioBroker на следующем шаге.**

![Изображение, демонстрирующее документацию по веб-перехватчикам IFTTT, где можно получить ключ для веб-перехватчиков Maker.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_10.png)

**11. Теперь перейдите в ioBroker, затем на страницу настроек вашего экземпляра облачного адаптера, выберите вкладку «IFTTT и сервисы» и вставьте ключ в поле с надписью «Ключ IFTTT». (Даже не пытайтесь, ключ здесь случайный и просто для вида).**

![Изображение, демонстрирующее страницу конфигурации облачного адаптера с выбранной вкладкой «Сервисы и IFTTT».](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_11.png)

**12. Теперь мы можем отправлять данные в IFTTT с помощью Blocky. Вот как поля элемента "Отправить текст в IFTTT" (в разделе "Отправить в" в Blocky) соответствуют тем, которые мы настроили в качестве действия в IFTTT.**

![Изображение, демонстрирующее апплет в IFTTT и элемент IFTTT от Blocky.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_12.png)

**Если вы предпочитаете писать JavaScript напрямую, а не использовать Blocky, то используемая функция будет выглядеть следующим образом:**

```javascript
sendTo("cloud.0", "ifttt", {
    event: 'state',
    value1: 'value1',
    value2: 'value2',
    value3: 'value3'
});
```

**Также можно задать переменную.`cloud.0.service.ifttt` Если оно имеет какую-либо ценность, его тоже отправят.**

**13. В качестве простого примера приведем скрипт Blocky, который получает состояние дверного контакта HomeMatic и отправляет его в IFTTT при изменении состояния, а также соответствующее сообщение в Telegram.**

![Изображение, демонстрирующее упомянутый выше скрипт Blocky, и сообщение из Telegram, показывающее результат работы скрипта Blocky.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_13.png)

## Получение данных из IFTTT

Теперь, когда мы знаем, как отправлять данные в IFTTT и, следовательно, в другие сервисы, давайте посмотрим, как получать данные обратно из других сервисов. В этом примере мы поступаем наоборот и получаем данные из Telegram через IFTTT. Мы создадим апплет, выполняющий следующую цепочку: Telegram => Вебхук (IFTTT) => ioBroker

**1. Для начала создайте новый апплет в IFTTT, а затем нажмите «+это», чтобы начать выбор триггера.**

![Изображение, демонстрирующее стартовую страницу создания апплета IFTTT.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_send_01.png)

**2. Теперь выберите «Telegram» в качестве сервиса для этого апплета.**

![На изображении показан выбор сервиса, а в поле поиска введено слово «Telegram».](../../../../en/adapterref/iobroker.cloud/doc/ifttt_get_02.png)

**3. В качестве триггера выберите «Новое сообщение с ключевым этапом для @IFTTT».**

![Изображение, демонстрирующее выбор триггера, и красная стрелка, указывающая на "Новое сообщение с ключевым этапом для @IFTTT".](../../../../en/adapterref/iobroker.cloud/doc/ifttt_get_03.png)

**4. Теперь в качестве ключевого этапа укажите «состояние», а в качестве ответа в этом примере примем «ОК».**

![Изображение, демонстрирующее страницу настройки поля триггера с заполненными полями «Ключевой этап» и «Ответ».](../../../../en/adapterref/iobroker.cloud/doc/ifttt_get_04.png)

**5. Поскольку мы закончили с частью апплета, отвечающей за запуск, теперь перейдем к действию. Для этого нажмите "+затем".**

![Изображение, демонстрирующее общий обзор апплета с выбранными веб-хуками и выделенной частью "+", а затем "".](../../../../en/adapterref/iobroker.cloud/doc/ifttt_get_05.png)

**6. Выберите «Веб-перехватчики» в качестве службы действий.**

![На изображении, где показано поле выбора действия и поле поиска, в названии которого присутствует слово "Веб-хуки".](../../../../en/adapterref/iobroker.cloud/doc/ifttt_get_06.png)

**7. Здесь выберите единственный вариант «Отправить веб-запрос».**

![Изображение, демонстрирующее страницу выбора действия в службе веб-перехватчиков.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_get_07.png)

**8. Теперь нам нужен URL API (для этого требуется облачная учетная запись ioBroker, бесплатная или платная) со страницы облачного адаптера, он находится во вкладке "IFTTT и сервисы". (И не пытайтесь повторить, ключ на картинке поддельный)**

Если вы используете собственные сервисы, вам необходимо установить для параметра "Белый список для сервисов" значение "\*", чтобы разрешить все сервисы, или добавить "ifttt" в список разрешенных сервисов. Если вы не используете собственные сервисы, проигнорируйте это.

![Изображение, демонстрирующее страницу облачного адаптера с открытой вкладкой «IFTTT и сервисы» и красной стрелкой, указывающей на URL-адрес IFTTT.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_get_08.png)

**9. Вставьте скопированный из конфигурации облачного адаптера URL-адрес API в поле URL. Затем выберите действие «post», тип контента «text/plain» и в качестве ингредиента для тела запроса укажите «Text».**

![Изображение, демонстрирующее все поля действий со всеми заполненными/выбранными параметрами, как описано.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_get_09.png)

**10. Завершите процесс создания апплета.**

![Изображение, демонстрирующее финальную страницу создания апплета в IFTTT.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_get_10.png)

**11. Теперь, если мы отправим личное сообщение @IFTTT в Telegram, например, "state roflcopter", переменная`cloud.0.service.ifttt` будет содержать "roflcopter". Это можно перехватить с помощью любого Blocky- или Javascript-кода, который затем сможет действовать соответствующим образом.**

![Изображение, показывающее окно Telegram с сообщением, отправленным боту @IFTTT, и состоянием в ioBroker.](../../../../en/adapterref/iobroker.cloud/doc/ifttt_get_11.png)
