# ioBroker.ultimate-updater

🇩🇪 [Немецкая версия](/#/docs/adapterref/iobroker.ultimate-updater/README.de.md)

## Адаптер Ultimate Updater для ioBroker

Добавляет в ioBroker информацию о состоянии обновлений ваших хостов Proxmox, контейнеров LXC и виртуальных машин, позволяя запускать проверки и обновления одним нажатием кнопки.

Этот адаптер — клиент для **[Ultimate Updater](https://github.com/BassT23/Proxmox) от [@BassT23](https://github.com/BassT23)** . Ultimate Updater выполняет фактическую работу в вашем кластере Proxmox (выполнение обновлений, снимки/резервные копии, фильтры, модель состояния); этот адаптер только считывает его состояние через API интеграции v1 и запускает предлагаемые им действия. Название и иконка используются с разрешения [@BassT23](https://github.com/BassT23) — большое спасибо!

Значок адаптера — это оригинальный значок Ultimate Updater от BassT23, используемый с его разрешения ( [web-ui/assets/ultimate-updater-icon.png](https://github.com/BassT23/Proxmox/blob/master/web-ui/assets/ultimate-updater-icon.png) ).

> **Неофициальный адаптер от сообщества.** Он не связан с Ultimate Updater или Proxmox Server Solutions GmbH. Proxmox® является зарегистрированным товарным знаком Proxmox Server Solutions GmbH.

### Требования

- Node.js >= 22, js-controller >= 6.0.11, admin >= 7.8.23 (для менеджера учетных данных требуется admin 7.9)
- Ultimate Updater **5.2 или более поздняя версия** (до выхода версии 5.2: `develop` ветка) с включенным веб-интерфейсом (порт по умолчанию) `8765`)
- **API-токен** для интеграционного API версии 1. Работает только по HTTPS и имеет собственные права доступа. На хосте Proxmox:
  ```bash
  ultimate-updater-api-token enable
  ultimate-updater-api-token create iobroker --permissions read,logs,check,update,reboot,cancel
  ```
  Токен отображается только один раз. Не указывайте разрешения, которые вы не хотите предоставлять (например, `read,logs,check` (только для проверки статуса и проверки); соответствующие кнопки затем сообщают «доступ запрещен».

Вход через веб-интерфейс с использованием учетной записи Proxmox намеренно не поддерживается: для этого требуется учетная запись с полными правами администратора, а используемые конечные точки не представляют собой стабильный интерфейс.

### Конфигурация

| Параметр                                        | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| IP-адрес / имя хоста, порт, использовать HTTPS. | Адрес веб-интерфейса Ultimate Updater (API работает только по протоколу HTTPS)                                                                                                                                                                                                                                                                                                                                                                                            |
| API-токен                                       | **Введите данные здесь** (хранятся в зашифрованном виде) или **через менеджер учетных данных** в административной панели (Настройки → Учетные данные, ключ; требуется admin 7.9 и js-controller 7.2.2 или новее). Измененные учетные данные используются немедленно без перезапуска адаптера.                                                                                                                                                                             |
| Проверка TLS-сертификата                        | По умолчанию отключено, поскольку веб-интерфейс обычно использует самоподписанный сертификат Proxmox.                                                                                                                                                                                                                                                                                                                                                                     |
| Полное обновление статуса                       | Интервал для чтения всех целевых объектов (минуты, по умолчанию 60). После завершения задания статус обновляется немедленно.                                                                                                                                                                                                                                                                                                                                              |
| интервал опроса работы                          | Как часто проверяется список заданий: в режиме ожидания (по умолчанию 30 с) и во время выполнения задания (по умолчанию 2 с).                                                                                                                                                                                                                                                                                                                                             |
| Исключено из функции "обновить все"             | Виртуальные машины/контейнеры, которые пропускаются кнопками коллективного обновления (например, сам контейнер ioBroker), по-прежнему можно обновить по отдельности. Список загружается из работающего экземпляра.                                                                                                                                                                                                                                                        |
| В число коллективных обновлений входят:         | **Только запущенные виртуальные машины/контейнеры хранения** (по умолчанию) или **все виртуальные машины/контейнеры хранения** . Вариант «Все» работает только в том случае, если в Ultimate Updater также включено обновление остановленных гостевых систем. `STOPPED_CONTAINER` /`STOPPED_VM` в своем `update.conf` Затем программа запускает их для обновления и снова отключает. В противном случае Ultimate Updater пропускает их, и их задания завершаются с ошибкой. |
| Разрешить использование кнопок перезагрузки     | Создает `reboot` Кнопка для хостов/виртуальных машин/терминалов, требующих перезагрузки. По умолчанию отключена.                                                                                                                                                                                                                                                                                                                                                           |
| Удалите объекты, которые больше не существуют.  | Удаляет состояния хостов/виртуальных машин/терминалов, которые Ultimate Updater больше не отображает (например, удалены в Proxmox). Включено по умолчанию; если выключено, они сохраняются.                                                                                                                                                                                                                                                                               |
| Уведомления                                     | Новые обновления безопасности, требуется перезагрузка, задание завершилось с ошибкой/прервано — каждую из этих функций можно отключить.                                                                                                                                                                                                                                                                                                                                   |

| Состояние                                                                                    | Описание                                                                                                                                                                                                                                                                          |
| -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `info.connection`                                                                            | Подключение к веб-интерфейсу                                                                                                                                                                                                                                                      |
| `info.lastRefresh`, `info.targetCount`, `info.updaterVersion`, `info.updaterUpdateAvailable` | Общая информация                                                                                                                                                                                                                                                                  |
| `jobRunning`                                                                                 | Выполняется проверка/обновление.                                                                                                                                                                                                                                                  |
| `summary.text`                                                                               | Краткое описание на языке системы, например: "7 обновлений на 3 системах, требуется 1 перезагрузка".                                                                                                                                                                              |
| `summary.report`                                                                             | Отчет о состоянии в виде многострочного текста, аналогичного почтовому сообщению о состоянии от Ultimate Updater (обновления на узел, текущее, требуется перезагрузка, недоступно, ошибки, пропущено), заголовки на языке системы — например, для Telegram или карточки Markdown. |
| `summary.*`                                                                                  | Ожидаются обновления безопасности/обычные обновления, цели с обновлениями, недоступные цели, цели, требующие перезагрузки.                                                                                                                                                        |
| `targets.<name>_<id>.*`                                                                      | Все поля, предоставляемые Ultimate Updater для каждого хоста/LXC/VM (например) `security_updates`, `normal_updates`, `reboot_required`, `reachable`, `last_check`)                                                                                                                |
| `targets.<…>.jobState`, `targets.<…>.jobUnit`                                                | Состояние и идентификатор последнего задания этого целевого объекта (`none` (если его нет)                                                                                                                                                                                        |
| `widget.data`                                                                                | Все цели и задачи находятся в одном JSON-состоянии — считываются веб-компонентом.                                                                                                                                                                                                 |
| `jobs.<unit>.*`                                                                              | Выполняемые и недавно завершенные задания; для заданий, завершившихся с ошибкой, последние строки журнала сохраняются в `log`                                                                                                                                                      |

### Кнопки

| Кнопка                  | Действие                                                                                                                                                                                                                                                                                           |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `targets.<…>.checkNow`  | Проверьте этот хост/виртуальную машину/CT (нет обновлений)                                                                                                                                                                                                                                         |
| `targets.<…>.updateNow` | Обновите этот хост/виртуальную машину/терминал (хосты обновляются через Node.js, гостевые машины не затрагиваются).                                                                                                                                                                                |
| `checkAll`              | Проверьте все целевые объекты, включая хосты.                                                                                                                                                                                                                                                      |
| `updateAllVmsCts`       | Обновление всех виртуальных машин/терминалов, хостов и исключенных целевых объектов пропущено.                                                                                                                                                                                                     |
| `updateSecurityOnly`    | **Полное** обновление виртуальных машин/терминалов, для которых имеются ожидающие обновления безопасности, хостов и исключенных целевых объектов пропущено. В Ultimate Updater нет обновлений только для безопасности, поэтому устанавливаются все ожидающие обновления для этих целевых объектов. |
| `bulk.stop`             | Остановить выполняющееся коллективное обновление после достижения текущей цели                                                                                                                                                                                                                     |
| `targets.<…>.reboot`    | Перезагрузите этот хост/виртуальную машину/терминал — эта функция существует только в том случае, если кнопки перезагрузки разрешены и целевому устройству требуется перезагрузка.                                                                                                                 |
| `jobs.<unit>.cancel`    | Отменить это задание — оно существует только во время выполнения задания.                                                                                                                                                                                                                          |

Ничего не обновляется и не перезагружается автоматически — только при нажатии кнопки. Во время выполнения задачи дальнейшие действия отклоняются.

**Коллективные обновления выполняются последовательно:** Ultimate Updater отвечает сразу после _начала_ выполнения задания (HTTP 202), поэтому адаптер ждет завершения задания для одного целевого объекта, прежде чем начать следующее. Задания, запущенные в других местах (например, в веб-интерфейсе), также ожидают завершения. Ход выполнения отображается в `bulk.active` и `bulk.progress` (например `3/7: web` в конце, например `4 ok, 2 unchanged, 1 failed, 0 not started`; "без изменений" = состояние работы `skipped` (Обновлять было нечего).

### Виджет (веб-компонент) для AURA, vis-2 и других визуализаций.

Адаптер предоставляет виджет **«Таблица Ultimate Updater»** (веб-компонент, используемый в AURA, vis-2 и любой другой визуализации, поддерживающей веб-компоненты): все хосты, виртуальные машины и контейнеры в одной таблице с открытыми обновлениями (безопасность/другие), подсказкой о перезагрузке, состоянием задания и кнопками — такими же, как и состояния выше, готовыми для панели мониторинга. Он не требует скриптов и Simple-API: состояния кнопок записываются непосредственно через соединение с визуализацией.

![Таблица Ultimate Updater](https://raw.githubusercontent.com/ipod86/ioBroker.ultimate-updater/main/docs/widget_en.jpg)

- Сводная строка с отображением хода выполнения обновлений "Выбрать все" и коллективных обновлений, кнопки " _Выбрать все"_ , _"Обновить все виртуальные машины/контейнеры обмена данными"_ и _"Только с обновлениями безопасности"._
- Для каждой системы: индикатор состояния, тип и идентификатор, флаги (перезагрузка, работает, не удалось), кнопки проверки/обновления/перезагрузки в виде значков или текста.
- Неудачные задания: причина и последние строки журнала открываются ниже строки (журнал доступен только для чтения при открытии).
- Вопросы перед обновлениями и перезагрузками отображаются непосредственно под нажатой строкой.
- Дополнительная **нагрузка на ЦП, ОЗУ и дисковое пространство от [адаптера Proxmox](https://github.com/iobroker-community-adapters/ioBroker.proxmox)** для каждой системы, обозначенная оранжевым/красным цветом в зависимости от настраиваемых ограничений (диск: контейнеры; только виртуальные машины с гостевым агентом).
- Настройки: какие кнопки и системы отображаются (хост-системы, выключенные системы, только системы с обновлениями), порядок, высота строк, размер текста, полосы в строках и цвета.
- Новые или удалённые системы появляются сами по себе.

В AURA (версия 0.106.0 или новее) виджет отображается в списке виджетов после установки; установите **для параметра "Clicks" виджета значение "component"** , иначе кнопки не будут получать клики. Для vis-2 требуется версия 2.20.7 или новее.

### Уведомления

Адаптер использует менеджер уведомлений ioBroker, поэтому Telegram, электронная почта, Pushover и т.д. настраиваются централизованно в ioBroker. Уведомления отправляются только при изменениях и на языке системы:

- **Новые обновления безопасности** — количество обновлений безопасности для хоста/виртуальной машины/цикла контроля увеличилось.
- **Требуется перезагрузка** – хосту/виртуальной машине/терминалу требуется перезагрузка
- **Задание завершилось с ошибкой** – проверка/обновление/перезагрузка завершились неудачей или были прерваны (также сбои произошли во время остановки адаптера).

При первом запуске никаких уведомлений не отправляется; регистрируется только текущее состояние.

### Безопасность

- **API-токен** не предоставляет права на вход в Proxmox. Он работает только по протоколу HTTPS и обладает именно теми правами доступа, которые вы ему предоставляете. `read`, `logs`, `check`, `update`, `reboot`, `cancel` Предоставляйте только необходимые права и отзывайте их на хосте с помощью команды. `ultimate-updater-api-token revoke <id>`.
- Токен хранится в зашифрованном виде в ioBroker (или в центральном менеджере учетных данных). Любой, кто имеет доступ к административной панели ioBroker или его базе данных объектов, может использовать его, используя предоставленные ему права доступа.
- По умолчанию адаптер **не проверяет TLS-сертификат** , поскольку веб-интерфейс обычно использует самоподписанный сертификат Proxmox. Без проверки соединение шифруется, но злоумышленник в вашей сети может прочитать токен. Включите _проверку TLS-сертификата_ , если веб-интерфейс использует доверенный сертификат, и запускайте адаптер только в доверенной сети.
- Ограничьте доступ к веб-интерфейсу Ultimate Updater только тем хостам, которым он необходим (например, с помощью правил брандмауэра).

### Примечание к API

Адаптер использует документированный, версионированный API интеграции v1 из Ultimate Updater 5.2 (токен носителя, отдельные разрешения, только HTTPS), который был разработан совместно с BassT23 ( [BassT23/Proxmox#378](https://github.com/BassT23/Proxmox/issues/378) ).
