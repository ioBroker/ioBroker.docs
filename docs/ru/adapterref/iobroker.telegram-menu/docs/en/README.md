## ioBroker telegram-menu Adapter

Создавайте интерактивные меню Telegram для своего ioBroker.

Адаптер обеспечивает связь с ioBroker через Telegram: переключение точек данных, запрос значений, отправка изображений и диаграмм, запуск HTTP-запросов и многое другое. Меню организованы в группы и назначаются отдельным пользователям Telegram.

---

### Первые шаги

Справочные тексты можно получить непосредственно в адаптере, используя эту кнопку:![Вспомогательный текст кнопки](../../../../../en/adapterref/iobroker.telegram-menu/docs/pic/btnHelperTexte.png)

\*\*Важно:\*\* Для использования меню необходимо активировать хотя бы одно меню в разделе «Пользователи Telegram» (флажок справа).

## Навигация

![Навигация](../../../../../en/adapterref/iobroker.telegram-menu/docs/pic/nav.png)

- \*\*Строка 1 (зеленая)\*\* — это начальная навигация; она отправляется автоматически при запуске или перезагрузке адаптера и может быть вызвана вручную в любое время.
- Текст справа (например, «Выберите действие») можно свободно выделить, но он не может быть пустым.
- Кнопки, расположенные в ряд, помечены символом`,` разделены.
- Появится новая строка для кнопки.`&&` сгенерировано.

![Кнопки в Telegram](../../../../../en/adapterref/iobroker.telegram-menu/docs/pic/image-1.png)

Когда пользователь нажимает кнопку, Telegram отправляет текст кнопки в адаптер. Адаптер ищет соответствующую запись в конфигурации — **текст вызова должен точно совпадать и может встречаться только один раз** (во всех связанных меню).

- Можно использовать различные предопределенные подменю, например, B. Вкл/Выкл, проценты или числа (например, для управления рольставнями). Для каждого подменю в конфигурации действий автоматически создается новый триггер — подробнее об этом ниже.

### Несколько меню

Можно переключаться между меню. Это полезно, если два человека используют одно и то же меню, но одному из пользователей нужен доступ к дополнительному меню, недоступному другому. Соответствующая кнопка видна в обеих группах, но её функция актуальна только для одного из пользователей. Для этого **соответствующий пользователь должен быть зарегистрирован в обеих группах** .

Для корректной работы второго меню (подменю) необходимо отключить текст-триггер на главной странице подменю: просто оставьте ячейку «Триггер» пустой. После этого строка станет **оранжевой** , и появится сообщение о том, что это подменю. (A)`-` (В качестве заполнителя тоже по-прежнему подходит.)

\*\*Важно:\*\* Даже при наличии двух связанных меню текст вызова может отображаться только один раз. Однако два меню, не имеющие общих пользователей и не связанные друг с другом, могут использовать одни и те же пункты (например, «Свет» в обоих).

### Чистая история

Чтобы удалить все сообщения (аналогично функции «Удалить историю» в клиенте), введите в меню следующий пункт:

```
menu:deleteAll:Startseite
```

`Startseite` Это название меню, которое вызывается после удаления. Удалить можно только сообщения, которым менее 48 часов.

### Возвращаемый текст-заполнитель

Эти выражения можно использовать в любом месте возвращаемого текста в функциях Navigation, SetState и GetState.

#### <span id="status"></span> Показать статус точки данных

```
{status:'ID':true}
```

`ID` Замените на желаемый идентификатор точки данных. Выражение необходимо разместить непосредственно там, где должен отображаться статус. Второй параметр (`true` /`false` ) контролирует, является ли`change{...}` может быть применено к этому значению - актуально, если несколько`{status:...}` — Запросы отображаются в одном и том же возвращаемом тексте.

#### Обменная стоимость

```
change{"true":"an","false":"aus"}
```

Заменяет возвращаемое значение читаемым текстом. Может находиться сразу за ним.`{status:...}` или что`&&` — Заполнители остаются на месте.

#### Установите точку данных при открытии

```
{set:'id':'ID',val,ack}
```

Задает точку данных при открытии навигации.`ID` = идентификатор точки данных,`val` = значение, которое необходимо установить,`ack` = подтверждено (`true` ) или неподтвержденные (`false` ).

#### Отправить метку времени

Для последнего изменения точки данных:

```
{time.lc,(DD MM YYYY hh:mm:ss:sss),id:'ID'}
```

Для получения последней временной метки точки данных:

```
{time.ts,(DD MM YYYY hh:mm:ss:sss),id:'ID'}
```

Формат в скобках можно свободно настраивать. Ненужные заполнители можно удалить, но не переименовывать. Исключение:`YYYY` может как`YY` быть написано.

#### Преобразование метки времени Unix в время

```
{time}
```

Используется в возвращаемом тексте там, где должно отображаться преобразованное значение.

#### перенос строки

```
\n
```

#### Режим анализа

Позволяет использовать HTML-форматирование в сообщениях Telegram:

| Ярлык                    | Описание        |
| ------------------------ | --------------- |
| `<b>Text</b>`            | **фетт**        |
| `<i>Text</i>`            | _курсив_        |
| `<code>Text</code>`      | `Code`          |
| `<a href="URL">Link</a>` | Связанный текст |

В настройках соответствующей строки активируйте режим анализа и вставьте текст между тегами. Поддерживаются дополнительные теги.

## Подменю

![Подменю](../../../../../en/adapterref/iobroker.telegram-menu/docs/pic/image10.png)

Для вызова подменю необходимо ввести соответствующие данные в навигацию.`TRIGGER` должно быть уникальным (т.е. может встречаться только один раз) и ссылаться на триггер с тем же именем в конфигурации действия, где указан идентификатор, который нужно переключить.

### Предопределенные подменю

**Переключатель включения/выключения:**

```
menu:switch-on.true-off.false:TRIGGER:
```

`on` /`off` Это надписи на кнопках.`true` /`false` Они автоматически интерпретируются как логические значения, но могут быть заменены любым текстом.

---

**Процентные уровни:**

```
menu:percent10:TRIGGER:
```

Умереть`10` Определяет размер шага и является переменным параметром.

---

**Диапазон чисел:**

```
menu:number1-20-2-unit:TRIGGER:
```

`1`–`20` это диапазон (и наоборот)`20-1` возможный),`2` шаг`unit` единицу измерения. Для отрицательных размеров шага.`(-)` поместить впереди. Пример:`menu:number16-36-4-°C:temperaturXY:`

---

**Динамическое меню:**

```
menu:dynSwitch[Name1|value1, Name2|value2, value3]:TRIGGER:LengthOfRow:
```

Создает меню из массива.`Name|Wert` Определяет метку и значение соответствующей кнопки. Будет просто значением без каких-либо параметров.`|` Если уточнить, то оно также служит в качестве метки.`LengthOfRow` указывает количество кнопок на строке. В качестве значения могут использоваться десятичные числа (например,`2.5` Текущее значение точки данных также может использоваться в качестве имени кнопки:`{status:'ID':true}` – [Дополнительную информацию можно найти здесь](#status) .

---

**Назад:**

```
menu:back
```

Возвращает на последнюю просмотренную страницу (максимум 20 страниц).

## SetState

![SetState](../../../../../en/adapterref/iobroker.telegram-menu/docs/pic/setState.png)

- Die Checkbox\*\*"Switch"\*\*(right) переключает логическую точку данных между каждым вызовом`true` и`false` Название триггера должно точно соответствовать тексту кнопки, которая должна запускать действие.
- В поле «Wert» можно ввести любое значение. Для разных значений создайте отдельную запись SetState.
- Штаты по умолчанию`ack:false` Этот параметр необходим для управления другими адаптерами. Следует`ack:true` Можно установить напрямую, активировав флажок «Подтвердить».
- \*\*Подтверждение после`ack:true` :\*\*Как только указанный адаптер получит значение`ack:true` Подтверждено, будет отправлен ответный текст. Заполнитель для заданного значения в ответном тексте:`&&` .

**Не отправляйте установленное значение:**

Вводится в текст возврата, если значение не должно отображаться в подтверждении.<br>![нетценности](../../../../../en/adapterref/iobroker.telegram-menu/docs/pic/image5.png)

**Мгновенное подтверждение (без`ack:true` ждать):**

```
{confirmSet:Wert wurde gesetzt:noValue}
```

Отправляет мгновенный ответ. Это не означает, что адаптер фактически обработал значение.`noValue` Отключает отображение значения.

---

**Разрешите пользователю вводить динамические значения:**

```
{setDynamicValue:RequestText:Type:ConfirmText:ID}
```

После нажатия кнопки адаптер ожидает ввода текста пользователем, а затем записывает его в соответствующую точку данных. Полученные данные будут внесены в поле возврата.

| Параметр      | Описание                                                                                                                                                        |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `RequestText` | Подсказка, отправленная пользователю.                                                                                                                           |
| `Type`        | Тип данных:`boolean` ,`number` или `string`                                                                                                                     |
| `ConfirmText` | Текст подтверждения после установки (можно использовать свой собственный текст)                                                                                 |
| `ID`          | Необязательно: идентификатор другой точки данных, значение которой (в соответствии с`ack:true` ) отображается в подтверждающем тексте. Подстановочный знак:`&&` |

### Принять значение из подменю

Создайте подменю как обычно. Введите статическую часть в поле значения функции SetState и`{value}` Используйте в качестве заполнителя для значения из подменю.

### Сочетание статического и динамического значения

В поле значения статический текст может быть объединен с текущим значением точки данных:

```
{id:ID}
```

`ID` Замените на желаемый идентификатор точки данных.`&&` — Подстановочный знак в возвращаемом тексте указывает, куда будет вставлен результат. Без него.`&&` Результат прилагается в конце.

**Примеры:**

| вход                                                                       | Значение точки данных | выход          |
| -------------------------------------------------------------------------- | --------------------- | -------------- |
| `{id:0_userdata.0.Fenster_Status}`                                         | `true`                | `true`         |
| `{id:0_userdata.0.Count} {math:*2}`                                        | `5`                   | `10`           |
| `Test {id:0_userdata.0.Count} {math:*2} Test`                              | `5`                   | `Test Test 10` |
| `Test && {id:0_userdata.0.Count} {math:*2} Test`                           | `5`                   | `Test 10 Test` |
| `Status && {id:0_userdata.0.Count} {math:*2} change{"10":"an","20":"aus"}` | `5`                   | `Status an`    |

Результат всегда добавляется в конец текста, если не указано иное.`&&` Если значение установлено, то оно вставляется в позицию заполнителя.

## GetState

- Заполнитель`&&` Указывает, где полученное значение отображается в возвращаемом тексте.

- `change{"true":"an","false":"aus"}` – заменяет возвращаемое значение читаемым текстом.

- `{math:/10}` – применить математический расчет к значению (например)`/10` ,`*2` ,`+5` ).

  ![математика](../../../../../en/adapterref/iobroker.telegram-menu/docs/pic/image9.png)

- `{round:2}` – Округлите значение до N знаков после запятой.

- `{time}` – Преобразует метки времени Unix в местное время.

- Флажок «Новая строка»\*\* – если выполняется несколько одновременных запросов GetState, возвращаемый текст каждого запроса выводится на новой строке.

### Таблица

**Отображение JSON в виде текстовой таблицы:**

```json
{"tableData":[{"key":"value-1-inJSON","label":"Spalte 1"},{"key":"value-2-inJSON","label":"Spalte 2"}],"tableLabel":"Überschrift","type":"TextTable"}
```

1. В поле «ID» выберите точку данных, содержащую JSON-данные.
2. Измените JSON-код, как показано выше:`key` соответствует ключу в JSON-файле точки данных.`label` — это название столбца (будет)`label` опущено`key` используется в качестве имени столбца).
3. `tableLabel` Это заголовок таблицы (пустая строка = нет заголовка).
4. `type` должен`"TextTable"` и не должны быть изменены.

## Отправить изображение (Grafana)

- Сохраните токен Grafana в настройках.
- Создайте каталог с полными правами на запись (например,`/opt/iobroker/grafana/` ) для кэширования изображений.
- Введите URL-адрес отображения в поле действия. В Grafana его можно найти по пути: Диаграмма → Поделиться → Прямая ссылка на отрендеренное изображение. Отключите параметр "Заблокировать временной диапазон", чтобы всегда отправлялась текущая диаграмма.
- Если у вас несколько диаграмм, имя каждого файла должно быть уникальным, иначе изображения будут перезаписывать друг друга.
- Задерживать`0` → Изображение будет отправлено немедленно. Задержка > 0 → Изображение отправляется с задержкой в секундах, равной указанному значению.

## События

Встроенный обработчик событий: ожидает изменения статуса точки данных — если это задано (например, с помощью скрипта или адаптера), автоматически открывается предопределенное меню.

- Указанное условие проверено. Поддерживаемые операторы:`=` ,`!=` ,`<` ,`>` ,`<=` ,`>=` Если оператор не выбран, проверка на равенство выполняется по умолчанию.
- Это будет включено`ack` проверенной точки данных.

| **Одноразовая клавиатура**           | Клавиатура скрывается после однократного использования. Её можно снова отобразить с помощью специальной кнопки в поле ввода. Стандартная настройка:`false` ( [API Telegram](https://core.telegram.org/bots/api#replykeyboardmarkup) ) |
| **Токен Grafana**                    | Необязательно – необходимо для получения диаграмм Grafana.                                                                                                                                                                            |
| **каталог**                          | Кэш для изображений и диаграмм (Grafana и Echarts). Требуются полные права на запись.                                                                                                                                                 |
