# ioBroker.musiccast

адаптер для устройств Yamaha MusicCast, таких как WX-010/030, YSP-1600

## Настройки

На странице администратора кнопка «+» используется для ручного добавления IP-адреса, DeviceID, типа и имени устройства. Нажмите кнопку поиска для обнаружения. Если у вас несколько устройств, вам придется нажимать кнопку несколько раз, пока не будут обнаружены все устройства. К сожалению, при обнаружении возвращается только один объект за раз, и это может быть любое из ваших устройств MusicCast. Если результат совпадает с тем, что уже есть в таблице, вам придется нажать кнопку еще раз. Иногда помогает сохранить изменения и снова открыть страницу администратора.

В маловероятном случае, если два или более устройств передают один и тот же идентификатор, слегка измените один из идентификаторов. В противном случае адаптер не сможет различить эти два устройства.

Чтобы время воспроизведения треков обновлялось автоматически, пожалуйста, включите/отметьте соответствующий флажок. Обратите внимание, что это увеличивает количество сообщений (каждую секунду для каждого устройства происходит пинг-понг обновлений).
