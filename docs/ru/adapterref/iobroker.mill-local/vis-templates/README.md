# шаблоны визуализации для ioBroker.mill-local

Готовые виды для **vis 1** (`iobroker.vis` 1.x). Они используют только точки данных из `mill-local.0` и собственные виджеты vis адаптера (установите _mill-local_ ), поэтому они работают на любой установке этого адаптера: никаких скриптов, никакого адаптера диаграмм. Темный и светлый дизайн (каждый виджет по умолчанию соответствует настройкам браузера, атрибут « _Цветовая схема_ »), 1280 × 800 пикселей для планшетов и настольных компьютеров, а также ширина 390 пикселей для телефонов. Тексты берутся из виджетов и отображаются на языке vis (одиннадцать языков).

| Файл                                               | Содержание                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `view_Mill_Uebersicht.json`                        | Начальная страница: одна карточка на каждое устройство (температура в помещении, период работы или режим эксплуатации, целевое значение с обозначениями − / +, включено/выключено, текущая мощность, потребление энергии за сегодня), общая мощность и потребление энергии, а также периоды работы всех устройств за сегодняшний день. При нажатии на карточку открывается страница с подробной информацией о ней. |
| `view_Mill_Geraet1.json` …`view_Mill_Geraet4.json` | Подробная информация по каждому устройству: температура в помещении с указанием периода работы (например _, комфортный режим (22 °C) до 22:00_ ), целевое значение с обозначениями −/+, значения, режим работы, недельная программа в виде сетки (только для отображения) и график истории.                                                                                                                        |
| `view_Mill_Handy.json`                             | Телефон: одна компактная карта на устройство с символами − / +.                                                                                                                                                                                                                                                                                                                                                    |

## Импорт

1. Замените заполнители во **всех** файлах перед импортом (в любом текстовом редакторе нажмите «Заменить все»): `mill-local.0.DEVICE_1` …`mill-local.0.DEVICE_4` → ваши устройства, например `mill-local.0.94e686001234` (Объект устройства — это папка, расположенная непосредственно под ним) `mill-local.0` (его имя — это MAC-адрес). Меньше устройств: удалите виджеты отсутствующих; больше: скопируйте карточку и установите для нее атрибут устройства.
2. Откройте редактор визуализаций (`http://<iobroker>:8082/vis/edit.html` Для каждого представления: вкладка **«Представления»** → **«Импорт представления»** , вставьте содержимое `view_<Name>.json` и введите имя **точно** так же, как в имени файла (`Mill_Uebersicht`, `Mill_Geraet1` …, `Mill_Handy`). Карточки и обратная ссылка ведут к этим именам.
3. Сохранить. Открыть. `…/vis/index.html#Mill_Uebersicht` (таблетка) или `…#Mill_Handy` (телефон).

После установки или обновления адаптера vis перестраивает список виджетов при перезапуске (адаптер запрашивает перезапуск самостоятельно; если виджеты отсутствуют, перезапустите vis). `vis` один раз).

## Историческая диаграмма

На графике показаны температура в помещении, целевое значение, на которое регулирует устройство (ступенчатая линия), и текущая мощность (площадь, правая ось), а также влажность Wi-Fi-розеток в небольшой панели ниже — за последние 24 часа (исходные значения) или 7 дней (среднее значение за час). Считываются значения, записанные адаптером истории:

- **Источник данных:** атрибут _«История экземпляра_ виджета» – например. `history.0`, `influxdb.0` или `sql.0`; пусто = экземпляр истории по умолчанию системы ( _Системные настройки → История по умолчанию_ ).
- **Запись — на ваше усмотрение; адаптер не включает запись.** Включайте её для каждой точки данных в дереве объектов (значок шестеренки точки данных → ваш адаптер истории → включено; достаточно параметра "только изменения"):

  | Точка данных                              | Отображается как                                                                |
  | ----------------------------------------- | ------------------------------------------------------------------------------- |
  | `<device>.sensor.temperature`             | комнатная температура                                                           |
  | `<device>.status.activeTargetTemperature` | целевое значение (текущий период, пустое значение во время простоя)             |
  | `<device>.status.power`                   | текущая мощность                                                                |
  | `<device>.sensor.humidity`                | влажность (только для розетки Wi-Fi)                                            |
  | `<device>.control.targetTemperature`      | Необязательный параметр — целевой показатель «Нормальный» (полезен для оценок). |

  Без записи на диаграмме указано, какой именно показатель отсутствует.

## Что пишет, что только демонстрирует?

- Написание текста: кнопки − / + (`control.targetTemperature` с шагом 0,5 °C, 5 … 35 °C), включение/выключение (`control.power`) и режим работы (`control.operationMode`) – те же состояния, что и у карты устройства в административной панели, с теми же проверками.
- Отображается только еженедельная программа; редактировать её можно в административной панели на карточке устройства (кнопка календаря).

## немецкий

Fertige Ansichten for **1** , nur mit Datenpunkten aus `mill-local.0` и виджеты адаптеров (Satz _mill-local_ ) – один скрипт, один адаптер диаграммы. Dunkel und hell (виджет по стандарту браузера, схема _атрибутов_ ), 1280 × 800 пикселей и 390 пикселей для удобства. Текст доступен с помощью виджетов на вашем языке.

- **Ansichten:** `Mill_Uebersicht` (je Gerät eine Karte, Gesamtleistung, heutige Abschnitte aller Geräte), `Mill_Geraet1` …`Mill_Geraet4` (Raumtemperatur mit laufendem Abschnitt, Soll − / +, Werte, Betriebsart, Wochenprogramm als Raster zum Ansehen, Verlauf), `Mill_Handy`.
- **Импорт:** во все файлы `mill-local.0.DEVICE_1` …`DEVICE_4` durch die eigenen Geräteobjekte ersetzen (Ordner direkt unter `mill-local.0`, Name = MAC-адрес), dann im vis-Editor unter _Ansichten → Ansicht importieren_ jede Datei mit genau dem Namen aus dem Dateinamen anlegen.
- **Верлауф:** Raumtemperatur, Soll (Stufenlinie), aktuelle Leistung (Fläche, rechte Achse), bei der Steckdose die Luftfeuchte; 24 часа (Rohwerte) или 7 дней (Mittel je Stunde). Datenquelle im Widget-Attribut _Verlaufs-Instanz_ (`history.0`, `influxdb.0`, `sql.0` …; leer = Стандартная история систем). **Die Aufzeichnung schaltet der Anwender ein, der Adaptor tu es nicht:** im Objektbaum am Zahnrad des Datenpunkts, für `sensor.temperature`, `status.activeTargetTemperature`, `status.power`, `sensor.humidity` (Доза поштучно) и опционально `control.targetTemperature`.
- **Шрайбен** нур Солл − / +, Ein/Aus und Betriebsart. Эта рабочая программа будет доступна для управления и в режиме администратора с помощью стандартной карты.
