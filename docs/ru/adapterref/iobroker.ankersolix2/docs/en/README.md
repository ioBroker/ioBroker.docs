## Административный интерфейс

Обзор функций, доступных в административном интерфейсе.

### Параметры

![....](../../../../../en/adapterref/iobroker.ankersolix2/docs/de/media/adminoptions.png)

- Учетные данные для входа
  - Введите учетные данные для входа в свою учетную запись.\
    &#x20;Начиная с конца июля 2025 года, можно также использовать учетную запись администратора.\
    &#x20;поскольку разные устройства больше не мешают друг другу, используя свои токены.
  - В поле "Выбранный сервер" должны быть указаны как адрес сервера, так и код страны.\
    &#x20;там, где учетная запись была первоначально создана. В противном случае могут возникать ошибки при входе в систему.

- Варианты батарей
  - Поскольку Anker Cloud не предоставляет напрямую информацию о типе батареи (только о количестве),\
    &#x20;Вы можете вручную указать, сколько батарей каждого типа установлено.\
    &#x20;Этот параметр необходим для расчета общей энергии, запасенной в батарее.\
    &#x20;(точка данных:`battery_energy` (соответствующей солнечной батареи).

### Статистика

![....](../../../../../en/adapterref/iobroker.ankersolix2/docs/de/media/adminstat.png)

Здесь вы можете выбрать, какие статистические данные будут извлекаться из облака и как они будут отображаться.\
&#x20;Пожалуйста, снимите выделение со всех ненужных данных, чтобы уменьшить частоту запросов.

### Контроль

![....](../../../../../en/adapterref/iobroker.ankersolix2/docs/de/media/admincontrol.png)

- Для управления этим участком требуется установка солнечной батареи.\
  &#x20;Здесь выбирается только идентификатор объекта (Site ID), а не сам солнечный блок (Solarbank).\
  &#x20;Не беспокойтесь — если вы выберете Solarbank, в любом случае будет использоваться только идентификатор объекта (Site ID).

- Управление осуществляется с помощью пользовательской точки данных: этот параметр можно выбрать произвольно.\
  &#x20;При наличии соответствующей настройки адаптер отслеживает изменения в точке данных.\
  &#x20;При изменении значения адаптер переводит солнечную батарею в пользовательский режим с круглосуточной работой.\
  &#x20;и использует значение мощности из точки данных.\
  &#x20;Опция "Максимальная выходная мощность для управления адаптером (Вт)" позволяет установить дополнительное ограничение для этого значения.

- Если значение в точке данных превышает установленный предел, в облако Anker передается только это ограниченное значение.

  Внимание: Все пользовательские расписания, настроенные вручную, будут перезаписаны.\
  &#x20;В разделе «Энергетический план» описан обходной путь.

### Энергетический план

![....](../../../../../en/adapterref/iobroker.ankersolix2/docs/de/media/adminenergy.png)

- Как и в приложении Anker, здесь вы можете установить расписание.\
  &#x20;или считать существующий файл из облака и записать его обратно.
- Если эта функция включена, вы можете повторно активировать расписание извне через точку данных:\
  `ankersolix2.x.control.SetPowerplan`
- Опция «Установить при перезагрузке» гарантирует автоматическое применение настроенного плана.\
  &#x20;после перезагрузки адаптера.

### Индивидуальное расписание

![....](../../../../../en/adapterref/iobroker.ankersolix2/docs/de/media/adminenergy.png)

- Это позволяет адаптеру переключать режим работы солнечной батареи.\
  &#x20;по истечении указанного времени.

## Функции

- Считывание данных из облака Anker и их отображение в виде точек данных (без фильтрации).
- Получение статистических данных из облака Anker.
- Настройте расписания с автоматическим переключением режимов.
- Редактируйте тарифные планы на электроэнергию аналогично официальному приложению.

## Точки данных

### ankersolix2.0.\<Site-ID>

| Имя           | Описание                                                                                                                                                                   |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `\<Site-ID\>` | Под идентификатором сайта отображаются все данные, относящиеся к полученной системе. Все значения доступны только для чтения и не могут использоваться в целях управления. |

### ankersolix2.0.control.\*

| Имя            | Описание                                                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ACLoading`    | Позволяет внешним скриптам запускать зарядку устройств переменного тока от сети. Длительность фиксирована: 12 часов с момента установки.`true` . |
| `SetPowerplan` | Повторно применяет план электропитания, настроенный в административном интерфейсе.                                                               |
