# ioBroker.hp-ilo

\=================

# Адаптер HP ILO для ioBroker

Считывает данные о температуре серверов Hewlett-Packard с интегрированной системой автоматического отключения питания (ILO) в [ioBroker](https://www.iobroker.net) .

Поддержка интерфейсов МОТ, начиная с версии V2.
