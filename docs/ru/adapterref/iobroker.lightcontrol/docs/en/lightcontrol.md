# 1. Характеристики

- Группировка любого количества лампочек/лампочек
- Использование смешанных ламп/цветовых систем и преобразование цветовых систем (hex, rgb, xy)
- Возможность присваивать каждому источнику света значения по умолчанию (одинаковая яркость, несмотря на разную мощность источника света).
- Используйте любое количество датчиков движения на группу.
- Плавное изменение яркости (медленное приближение к целевому значению) для включения и выключения.
- Регулировка яркости
- Автоматическое отключение по времени / Отключение при движении;
- Автоматическое отключение в зависимости от яркости
- Автоматическое включение при переходе от определенного уровня яркости
- Автовключение в темноте
- Функция автоматического включения при увеличении яркости счетчика присутствия (приветственный свет при возвращении домой).
- Включение функции принудительной очистки (индикатор процесса очистки)
- Главный переключатель для одновременного включения и выключения всех групп (одновременная индикация включения всех групп).
- Информационный пункт для "любая группа является"
- мигающий (сигнализация, дверной звонок и т. д.)
- Адаптивная яркость (при яркости наружного освещения выше 1000 люкс — полная яркость (100%), включая линейное затемнение до 0 люкс (2%))
- Адаптивная цветовая температура (4 динамических режима: линейный (линейное повышение от восхода до полудня, затем линейное понижение до заката), солнечный (в соответствии с синусоидой высоты солнца, maxCt зависит от сезона), SolarInterpolished (как солнечная, но без сезонной зависимости), StartYourDay (линейное понижение от времени начала до заката)![adaptive\_Ct.png](../../../../../en/adapterref/iobroker.lightcontrol/docs/en/docs/de/img/adaptive_Ct.png)

# 4. Настройки группы

Окно конфигурации открывается автоматически с настройками групп, где создаются отдельные группы светильников.

## 4.1 Группы света

![Настройки экземпляра - LightGroups](../../../../../en/adapterref/iobroker.lightcontrol/docs/en/img/02_Instance_Settings_LightGroups.jpg)

Нажатие на кнопку «+» создаст новую строку.

- Описание: Здесь вы указываете название группы. Внимание: Не создавайте дубликаты!
- Индивидуальный датчик освещенности: Здесь вы определяете индивидуальный датчик освещенности. Идентификатор объекта можно ввести, нажав на три точки справа. Если поле оставить пустым, для группы источников света будет использоваться глобальный датчик освещенности, если таковой определен.

## 4.2 Общие настройки

![Настройки экземпляра — Общие](../../../../../en/adapterref/iobroker.lightcontrol/docs/en/img/01_Instance_Settings.jpg)

- **Глобальные настройки датчика освещенности**
  - Этот датчик используется повсеместно, за исключением случаев, когда в группе выбран отдельный датчик.
  - Необходимо выбрать числовую точку данных!
- **Настройки цветовой температуры**
  - Минимальное значение цветовой температуры в Кельвинах => стандарт: 2700
  - Максимальная цветовая температура в Кельвинах => Стандартная: 6500
- **Настройки затемнения**
  - Шаг регулировки яркости => По умолчанию: 10
  - Минимальная яркость при регулировке яркости с помощью параметра _DimmDown_ => По умолчанию: 10
- **Настройки присутствия**
  - Идентификатор объекта присутствия => Должно быть _true_ или _false_
  - Идентификатор объекта счетчика посещаемости => Должен быть числом.
- **Ведение журнала**
  - Расширенные возможности ведения журнала пользователей

# 5 источников света и датчиков

Все светильники и датчики добавляются в группы освещения через соответствующие точки данных:

![Пользовательская конфигурация](../../../../../en/adapterref/iobroker.lightcontrol/docs/en/img/07_customConfig_openSettings.jpg)

После открытия настроек необходимо активировать конфигурацию:

![Активировать пользовательскую конфигурацию](../../../../../en/adapterref/iobroker.lightcontrol/docs/en/img/03_activate_customConfig.jpg)

## 5.1 Освещение

![Настройки освещения](../../../../../en/adapterref/iobroker.lightcontrol/docs/en/img/04_customConfig_light.jpg)

- **Тип объекта** . Во многих случаях LightControl определяет, является ли объект источником света или датчиком; если нет, то параметр \_Licht\_is задан заранее.

- **Группа освещения.** Здесь вы выбираете ранее определенные группы освещения в настройках экземпляра (возможен множественный выбор -> ошибка).

- **Название источника света.** Задайте название для источника света. Для выбора предлагаются ранее заданные названия.

- **Функция объекта.** Во многих случаях LightControl определяет, какую функцию может выполнять объект. Если автоматическое определение не соответствует желаемому результату, выберите соответствующую функцию в выпадающем меню.

  <img src="img/06_customConfig_funcOfObject.jpg" width="200">

  - **Выключатель**

    - Значение Power On Value - _значение для exampletrue_
    - Значение параметра «Выключение питания» — _например, значение false._

  - **Яркость**

    - Значение минимальной яркости - _значение наименьшей яркости. Например, 0_
    - Значение максимальной яркости - _значение максимальной яркости, например, 100_
    - Значение/смещение яркости — _максимальное значение для регулировки яркости относительно других ламп в группе._
    - Используйте яркость для включения/выключения — _используйте состояние яркости лампы для ее включения/выключения вместо состояния питания._

  - **Цветовая температура**

    - Значение минимальной цветовой температуры - _минимальное значение точки данных. Например, 0._
    - Значение максимальной цветовой температуры - _максимальное значение точки данных. Например, 100._
    - Поведение цветовой температуры — _определение последовательности изменения цветовой температуры (от теплого к холодному белому, от холодного к теплому белому или Mired)._
    - Значение минимального значения в Кельвинах — соответствует значению минимального значения точки данных в Кельвинах. Например, 2700.
    - Значение максимального значения в Кельвинах — соответствует значению максимального значения точки данных в Кельвинах. Например, 6500.
    - Отображение цветовой температуры — _установка значения цветовой температуры даже при выключенной лампе._

  - **Насыщенность**

    - Значение минимальной насыщенности - _значение наименьшей насыщенности, например, 0._
    - Значение максимальной насыщенности - _значение максимальной насыщенности, например, 100_
    - Настройка насыщенности — _установка значения насыщенности даже при выключенном индикаторе._

  - **Переключатель режимов**

    - Значение для режима «Белый» — _например, false._
    - Значение для цветового режима — _значение для цветового режима, например, true._
    - Send ModeSwitch - _Установить значение переключателя режимов даже при выключенной лампе._

  - **Цвет**
    - Тип цвета - _Тип спецификации цвета (HEX => #FFFFFF // RGB => 255,255 // XY => \[0.4992,0.418])_
    - Значение по умолчанию для цвета _— например, #FFFFFF_
    - Функция «Передача цвета» — _установка значения цвета даже при выключенной лампе._

## 5.2 Датчики

### 4.2.1 Общие положения

- При срабатывании датчика включается свет (если он активен в точках данных).
- Процесс отключения запускается только тогда, когда ВСЕ датчики перестают регистрировать данные (если эта функция активирована в точках данных).

> Примечание: Теоретически, здесь также можно указать переключатели, при условии, что значения для включения/выключения будут разными. Однако процесс выключения зависит от настроек, например, свет гаснет через 60 секунд.

![Датчик с пользовательской конфигурацией](../../../../../en/adapterref/iobroker.lightcontrol/docs/en/img/08_customConfig_sensor.jpg)

- Значение для обнаружения движения — _значение, указывающее на обнаруженное движение; например, true._
- Значение параметра noMotion — _значение, указывающее на отсутствие движения, например, false._

# 6 точек данных

## 6.1 Данные по всем группам

- **Все**
  - **Питание:** Включение/выключение всех групп / индикатор включения всех групп
  - **anyOn:** _true,_ если хотя бы одна группа включена.

## 6.2 Показатели данных для каждой группы

- **Группа**

  - **autoOffLux:** Автоматическое отключение света при достижении порогового значения яркости.

    - **включено:** Включить/отключить автоматическое отключение при изменении яркости
    - **minLux:** минимальное значение освещенности
    - **dailyLock:** AutoOffTimed не работает, если false
    - **Оператор:** Сравнивает, следует ли отключать свет при уровне освещенности выше или ниже _minLux_ (например, > / < / >= / <=)

  - **autoOffTimed:** Автоматическое отключение по истечении заданного времени (только в связи с датчиками)

    - **включено:** Включить/Выключить автоматическое отключение
    - **autoOffTime:** Время автоматического выключения в секундах
    - \*noAutoOffWhenMotion:\*\* Функция автоматического отключения сбрасывается при повторном движении.
    - **noticeEnabled:** Включить/отключить подсказку для автоматического отключения (в настоящее время не работает)
    - **noticeBri:** Яркость в процентах до автоматического отключения
    - **noticeTime:** Время в секундах до автоматического отключения

  - **autoOnLux:** Автоматическое включение света при достижении определённого уровня освещенности (люкс).

    - **включено:** Включить/Выключить
    - **minLux:** Пороговое значение освещенности для переключения
    - **бри:** Яркость, с которой включается свет.
    - **цвет:** цвет, которым загорается свет
    - **switchOnlyWhenPresence:** Переключаться только тогда, когда кто-то находится дома.
    - **switchOnlyWhenNoPresence:** Переключаться только тогда, когда никого нет дома.
    - **dailyLock:** AutoOnLux не запускается, если значение равно false.
    - **Оператор:** Сравнивает, должен ли свет включаться выше или ниже _минимального уровня освещенности_ (например, > / < / >= / <=)

  - **autoOnMotion:** Автоматическое включение света при движении

    - **включено:** Включить/Выключить
    - **minLux:** Пороговое значение освещенности для переключения
    - **бри:** Яркость, с которой включается свет.
    - **цвет:** цвет, которым загорается свет

  - **autoOnPresenceIncrease:** Автоматически включает свет, когда значение счетчика посещаемости превышает последнее значение.

    - **включено:** Включить/Выключить
    - **minLux:** Пороговое значение освещенности для переключения
    - **бри:** Яркость, с которой включается свет.
    - **цвет:** цвет, которым загорается свет

  - **моргание:** моргание

    - **включено:** Начинает мигать в бесконечном цикле, => останавливает мигание
    - **Начало:** Начинает мигать до достижения нужного числа.
    - **частота:** частота мигания в секундах
    - **мигания:** количество индикаторов
    - **бри:** Яркость ламп при мигании
    - **цвет:** Цвет мигания лампочек

  - **rampOff:** Затемнение при выключении питания

    - **включено:** Включить/Выключить
    - **Время:** Время затемнения (не должно быть меньше 10 секунд)
    - **switchOutletsLast:** Светильники, которые включаются/выключаются последними?

  - **rampOn:** Высокая частота настройки при включении.

    - **включено:** Включить/Выключить
    - **Время:** время для высокого броска (не должно быть меньше 10 секунд)
    - **switchOutletsLast:** Светильники, которые включаются/выключаются последними?

  - **adaptiveBri:** Включение/выключение адаптивной яркости

  - **adaptiveCt:** Включение/выключение адаптивной цветовой температуры

  - \*адаптивный режим:\*\* режим адаптивной цветовой температуры
    - **Линейный** (восход солнца -> полдень -> закат солнца)
    - **Солнечная активность** (в соответствии с высотой Солнца, рассчитанной по синусоиде, максимальная температура Ct зависит от сезона)
    - **SolarInterpolished** (аналогично солнечной энергии, но без сезонной зависимости)
    - **StartYourDay** (линейное убывание от времени начала до захода солнца)

  - **adaptiveCtTime:** Время начала. Адаптивная цветовая температура в режиме: StartYourDay

  - **bri:** Установите яркость (0-100%)

  - **цвет:** Задайте цвет в виде шестнадцатеричного значения (#FFFFFF)

  - **ct:** Установить значение цвета в Кельвинах

  - **dimmAmount:** Шаги затемнения в %

  - **dimmDown:** Кнопка регулировки яркости

  - **dimmUp:** Кнопка высоких частот

  - \*isMotion:\*\* Включение/отключение датчиков

  - **Питание:** Включение/выключение питания

  - **powerCleaningLight:** подсветка для уборки (устанавливает яркость на 100% и цветовую температуру на холодный белый).
