# ioBroker.speedport

## Адаптер Telekom Speedport для ioBroker

Получает данные с маршрутизатора Telekom Speedport.

## Поддерживаемые устройства

- Спидпорт W 925V
- Спидпорт Смарт 3 (экспериментальный)
