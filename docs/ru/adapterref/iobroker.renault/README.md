# ioBroker.renault

**Этот адаптер использует библиотеки Sentry для автоматического сообщения разработчикам об исключениях и ошибках в коде.** Более подробную информацию, а также инструкции по отключению отправки сообщений об ошибках см. [в документации Sentry-Plugin](https://github.com/ioBroker/plugin-sentry#plugin-sentry) ! Система отчетности Sentry используется начиная с js-controller 3.0.

## Адаптер Renault / Dacia / Alpine для ioBroker

Этот адаптер подключает ioBroker к облаку [Renault](https://www.renault.com/) , [Dacia](https://www.dacia.com/) и [Alpine](https://www.alpinecars.com/) . Он считывает данные об автомобиле (аккумулятор, зарядка, климат-контроль, пробег, местоположение, давление в шинах и т. д.) и отправляет удаленные команды (климат-контроль, зарядка, ограничения заряда, звуковой сигнал и фары) для подключенных моделей, таких как Renault Zoe, Megane E-Tech, Renault 5, Dacia Spring и Alpine A290.

Адаптер подключается к учетной записи приложения **My Renault** , **My Dacia** или **My Alpine** . Автомобиль работает с адаптером, если им можно управлять в этом приложении.

## Установка / Вход

1. Установите адаптер через административный интерфейс ioBroker.
2. Откройте настройки адаптера и введите учетные данные вашей учетной записи **My Renault** (или **My Dacia** / **My Alpine** ): адрес электронной почты приложения и пароль приложения.
3. Выберите **марку** вашего приложения: `Renault / Dacia` для моего Renault и моей Dacia. `Alpine` для My Alpine. Все три приложения авторизуются в одной и той же службе Renault; производитель сам решает, какую учетную запись для входа в систему будет использовать адаптер.
4. Выберите **страну** , в которой находится ваш аккаунт, в приложении.
5. При желании можно установить **интервал** опроса в минутах и **ключ API** (оставьте поле пустым для автоматического определения).
6. Сохраните изменения, и экземпляр начнет опрос.

## Поддерживаемые модели

Информация о том, какие функции поддерживает каждая модель, берется из таблицы конечных точек [renault-api](https://github.com/hacf-fr/renault-api) (`src/renault_api/kamereon/models.py` (читайте 17.09.2026). `yes`: поддерживается, `no`: не поддерживается, поэтому адаптер не создает состояние и не отправляет запрос. `?`: renault-api не указывает, поэтому адаптер пытается выполнить запрос. Модель, которой нет в таблице, получает каждый запрос; тот запрос, который автомобиль отклоняет, запрашивается повторно раз в день. Код вашей модели находится в `general.vehicleDetails.model.code`.

## Пульт дистанционного управления

Каждое транспортное средство создается как устройство на основе его VIN-кода. Дистанционные команды отображаются в виде состояний в разделе `renault.0.<VIN>.remote.*`:

| Состояние               | Тип        | Роль                | Действие                                                                                         |
| ----------------------- | ---------- | ------------------- | ------------------------------------------------------------------------------------------------ |
| `climateStart`          | логический | `button.start`      | запустить климат-контроль                                                                        |
| `climateStop`           | логический | `button.stop`       | остановить климат-контроль                                                                       |
| `climateTemperature`    | число      | `level.temperature` | Целевая температура в °C для следующего запуска (по умолчанию 21)                                |
| `chargingStart`         | логический | `button.start`      | Начать зарядку (см. ниже)                                                                        |
| `chargingStop`          | логический | `button.stop`       | прекратить зарядку                                                                               |
| `chargeLimitMin`        | число      | `level`             | минимальный уровень заряда в %, от 15 до 45 с шагом 5.                                           |
| `chargeLimitTarget`     | число      | `level`             | Целевой уровень заряда в %, от 55 до 100 с шагом 5.                                              |
| `chargeMode`            | нить       | `text`              | `always`, `always_charging`, `schedule_mode` или `scheduled`; показывает режим работы автомобиля |
| `hornStart`             | логический | `button.start`      | подать звук рога                                                                                 |
| `lightsStart`           | логический | `button.start`      | мигать светом                                                                                    |
| `refreshLocation`       | логический | `button`            | считать местоположение из облака сейчас                                                          |
| `askForLocationRefresh` | логический | `button`            | Запросить у автомобиля данные о местоположении, считать местоположение через 30 секунд.          |
| `refreshAll`            | логический | `button`            | Опросить все данные о транспортных средствах прямо сейчас                                        |
| `refreshBattery`        | логический | `button`            | Теперь вы можете получать информацию о состоянии батареи из облака.                              |
| `refreshClimate`        | логический | `button`            | проверить состояние системы климат-контроля (`hvac-status`) из облака сейчас                    |
| `lastCommandError`      | нить       | `text`              | ошибка последней команды, пусто после успешной команды                                           |

Кнопка нажимается путем написания. `true` Адаптер сбрасывает его до... `false` с `ack: true` как только команда была обработана; `lastCommandError` Это показывает, приняло ли облачное хранилище Renault запрос. Затем автомобиль выполняет его, и данные показывают результат после следующего опроса, например. `hvac-status.hvacStatus` и `battery-status.chargingStatus`.

`chargeLimitMin` и `chargeLimitTarget` отправляются вместе, поэтому адаптеру требуется другое ограничение из `soc-levels` Считывание происходит один раз в час; сразу после запуска запись ожидает первого считывания. В обоих состояниях отображаются ограничения, сообщаемые автомобилем, даже после внесения изменений в приложение.

Он `refresh…` Кнопки считывают только то, что хранится в облаке; автомобиль загружает данные самостоятельно, например, после замены в зарядном устройстве или при выключении. `askForLocationRefresh` Сначала система запрашивает у автомобиля данные о его местоположении, что активирует её телематический блок; считывание данных происходит только после того, как облако примет этот запрос, и результат отображается в памяти устройства. `lastCommandError` Не нажимайте кнопку из скрипта в циклическом режиме, каждое нажатие активирует автомобиль и потребляет энергию от его 12-вольтовой батареи. Автомобиль нельзя запросить о состоянии батареи или системы климат-контроля: Zoe Phase 2 отвечает на запросы обновления, известные по другим проектам, ошибкой 404. Каждая кнопка требует одного прочтения вместо полного опроса, и одни и те же данные об автомобиле считываются не чаще, чем каждые три минуты.

Сценарий, который следует за нажатиями настенного блока. `refreshBattery` само собой, когда у автомобиля было время загрузить данные, например, через минуту после замены настенного зарядного устройства. Частое использование `refreshAll` может исчерпать квоту запросов учетной записи, что также блокирует приложение My Renault.

Какой запрос отправляет команда и какие данные об автомобиле запрашивает адаптер, зависит от модели. Адаптер использует таблицу конечных точек [renault-api](https://github.com/hacf-fr/renault-api) (код модели в `general.vehicleDetails.model.code`):

- Кнопка, которую модель не поддерживает, не создается. Модели, которые не могут дистанционно остановить зарядку, например, Megane E-Tech, Renault 4, Renault 5 и Alpine A290, не имеют такой кнопки. `chargingStop`.
- Для моделей Renault 4, Renault 5, Alpine A290, Scenic E-Tech и Master E-Tech зарядка осуществляется по расписанию. `chargingStart` **Отключает все программы зарядки** , как это делает приложение My Renault; включите их снова в приложении.
- Данные, которые модель не предоставляет, не опрашиваются, что позволяет сократить количество запросов.
- Если в списке поддерживаемых API Renault пока нет нужной модели, выполняются запросы по умолчанию: проверяется каждая команда и конечная точка, а запросы к неподдерживаемым конечным точкам отправляются повторно раз в день.

## Данные об автомобиле

Данные с каждого конечного пункта записываются в канал, расположенный ниже. `renault.0.<VIN>` названный, например, по названию конечной точки. `battery-status`, `cockpit` и `hvac-status` Большинство вопросов задаются в каждом опросе; они меняются медленно и задаются раз в час:

| Канал            | Содержание                                                       |
| ---------------- | ---------------------------------------------------------------- |
| `charge-history` | плата за день                                                    |
| `charges`        | разовые зарядные устройства                                      |
| `pressure`       | Давление в каждой шине (мбар) и код состояния.                   |
| `alerts`         | Предупреждения автомобиля (Renault 5); удаленное предупреждение. |
| `soc-levels`     | минимальный и целевой уровень заряда                             |

## Часто задаваемые вопросы

**В журнале отображается сообщение "Функция не найдена для… Игнорировать… в течение 24 часов".** Автомобиль или его пакет обновлений не предоставляют эти данные. Адаптер запрашивает данные повторно один раз в день, что обходится в один запрос.

**В журнале появляется сообщение "неверный логин или пароль", или вход в систему отклонен.** Установите новый пароль в приложении My Renault (My Dacia, My Alpine), введите его в настройках адаптера и перезапустите устройство. До тех пор адаптер не отправляет команды, поэтому он не может заблокировать учетную запись со старым паролем.

**В журнале указано, что квота запросов Renault исчерпана (429).** Учетная запись позволяет отправлять около 60 запросов в час, которые распределяются между приложением. Адаптер автоматически приостанавливается на 15, 30, а затем на 60 минут. Увеличьте интервал обновления и используйте `refreshAll` Редко; адаптер выдает предупреждение один раз, когда его настройки требуют больше запросов, чем позволяет квота.

** `chargingStart` Я отключил расписание зарядки.** На Renault 4, Renault 5, Alpine A290, Scenic E-Tech и Master E-Tech зарядка запускается именно так, приложение делает то же самое. Включите программы зарядки снова в приложении.

**Отсутствует удаленное состояние.** Модель не поддерживает команду согласно приведенной выше таблице; адаптер не создает ее и удаляет, если она была создана в более старой версии.
