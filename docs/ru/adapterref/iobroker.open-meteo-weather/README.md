# ioBroker.open-meteo-weather

![Тестирование и выпуск](https://github.com/H5N1v2/iobroker.open-meteo-weather/workflows/Test%20and%20Release/badge.svg)

## Важная информация:

В этот адаптер теперь интегрированы Open Meteo Weather и Open Meteo PV Forecast. Поддержка Open Meteo PV Forecast прекращена.

---

**Этот адаптер использует библиотеки Sentry для автоматического сообщения разработчикам об исключениях и ошибках в коде.** Для получения более подробной информации и инструкций по отключению отчетов об ошибках, пожалуйста, обратитесь к следующему разделу. [Документация по плагину Sentry](https://github.com/ioBroker/plugin-sentry#plugin-sentry)! Использование системы отчетности Sentry начинается с версии js-controller 3.0.

Я использую собственный сервер Sentry на базе Glitchtip.

**Адаптер сервиса прогнозирования погоды и солнечной активности Open-Meteo для ioBroker.**

Этот адаптер предоставляет точные данные о погоде, прогнозы, информацию о качестве воздуха, содержании пыльцы и прогнозы выработки солнечной энергии. [Open-Meteo.com](https://open-meteo.com/)Он бесплатен для некоммерческого использования (менее 10 000 вызовов API в день) и не требует регистрации ключа API, что делает процесс настройки чрезвычайно простым.

Если адаптер столкнется с такими проблемами, как тайм-ауты или ошибки сервера, вы можете проверить следующее: [Статус сервера Open-Meteo](https://status.open-meteo.com/).

## Особенности Погода

- **Текущие данные о погоде:** Получение данных о температуре, влажности, атмосферном давлении и ветре в режиме реального времени.
- **15-минутный прогноз** с максимальным количеством 16 наборов данных в течение следующих 4 часов.
- **Гибкие прогнозы:** Настраиваемое количество дней прогноза и почасовое разрешение.
- **Качество воздуха и пыльца:** Дополнительные данные по твердым частицам (PM2.5, PM10), а также различным типам пыльцы (ольха, береза, трава и т. д.).
- **Автоматическая очистка:** Адаптер автоматически очищает структуру объекта, если в конфигурации сокращаются или изменяются периоды прогнозирования.
- **Поддержка нескольких языков:** Поддерживает 11 языков (включая английский, немецкий, польский, русский, французский, китайский и др.).
- **Система единиц:** Плавное переключение между метрической (°C, км/ч) и имперской (°F, миль/ч) системами мер.
- **Несколько местоположений:** Добавьте несколько местоположений.
- **Ночные иконки:** Вы можете выбрать один из двух наборов ночных иконок: «Светлый» и «Темный». Это упростит подбор иконки под фон вашего помещения.

### Значки направления ветра

В настройках адаптера можно выбрать один из двух стилей отображения направления ветра:

- Направление ветра (куда дует ветер): это стандартная настройка. Стрелка указывает направление ветра. (Например: при северном ветре стрелка указывает на юг).

- Источник ветра (место, откуда дует ветер): В этом стиле используются значки из подпапки direct\_2. Стрелка указывает на источник ветра. (Например: северный ветер обозначается стрелкой, указывающей на север, или конкретным значком «источника»).

| Параметр                                  | Путь к иконке                                  | Поведение           |
| :---------------------------------------- | :--------------------------------------------- | :------------------ |
| Направление ветра (куда дует ветер)       | /icons/wind\_direction\_icons/\*.png           | Пункты назначения   |
| Источник ветра (место, откуда дует ветер) | /icons/wind\_direction\_icons/direct\_2/\*.png | Точки происхождения |

### Данные о качестве воздуха

Адаптер предоставляет актуальные данные о качестве воздуха и ежедневный прогноз на ближайшие дни (с возможностью настройки на 1, 3 или 6 дней).

Эффективная обработка данных: В то время как API Open-Meteo предоставляет только необработанные почасовые данные, этот адаптер интеллектуально агрегирует эти значения. Он автоматически рассчитывает суточные максимумы для всех загрязняющих веществ и уровней пыльцы. Это позволяет получить наиболее актуальные данные (пиковые уровни воздействия) без перегрузки базы данных сотнями почасовых точек данных.

Функции:

- Ежедневные пиковые значения: Получите максимально ожидаемые значения для PM2.5, PM10, озона и различных типов пыльцы.

- Удобочитаемый формат: Уровень пыльцы автоматически сопоставляется с описательными категориями (например, «Отсутствует», «Низкий», «Умеренный», «Высокий»).

- Интеллектуальная очистка: объекты для прогнозируемых дней автоматически создаются или удаляются в зависимости от ваших настроек, чтобы поддерживать чистоту дерева объектов.

## Конфигурация

После установки настройте следующие поля в параметрах экземпляра:

1. **Расположение:** Укажите ваше местоположение или желаемое название.
2. **Координаты (широта и долгота):** Добавьте свои координаты. Вы можете найти их, нажав кнопку «Найти координаты с помощью OpenStreetMap», или оставить поля пустыми, чтобы использовать системные координаты.
3. **Часовой пояс:** Выберите часовой пояс в выпадающем меню; по умолчанию установлено значение «Авто», которое автоматически подстраивается под ваши координаты.
4. **Интервал обновления:** Временной интервал в минутах (по умолчанию: 30 мин).
5. **Прогнозируемые дни:** Количество дней для ежедневного обзора (0–16 дней).
6. **Почасовой прогноз:** Включите или отключите эту опцию и задайте количество часов (например, следующие 24 часа). Например, hour0 — это текущий час, hour1 — следующий час и так далее.
7. **Дополнительные данные:** Флажки для отображения данных о пыльце и качестве воздуха.
8. **Единицы измерения:** Выберите между метрической и имперской системами мер.

## Виджет погоды

Этот адаптер предлагает два способа отображения данных о погоде в вашей визуализации:

### 1. Встроенный виджет (стандартный)

Начиная с версии **3.1.0**Адаптер может автоматически генерировать предварительно настроенный HTML-виджет для каждого местоположения.

**Способ применения:**

1. **Давать возможность:** Установите флажок "Создать виджет" в настройках экземпляра для вашего местоположения.
2. **Найти штат:** Адаптер создаст состояние под названием `htmlWidget` (под `open-meteo-weather.0.yourLocation.htmlWidget`).
3. **В VIS/VIS2:** \* Перетащите стандарт **виджет "HTML"** на ваш взгляд.
   - Установите свойство "HTML" этого виджета в соответствии с привязкой вашего состояния: `{open-meteo-weather.0.yourLocation.htmlWidget}`.
   - Отрегулируйте ширину и высоту контейнера виджета в соответствии с содержимым.

**Настройка:** Основные параметры, такие как размер шрифта, время и дни прогноза погоды, можно настраивать непосредственно в конфигурации адаптера.

**Лучше всего подходит для:** Пользователям, которым нужен быстрый, красивый и не требующий обслуживания дисплей.

**Примечание:** Для оптимального отображения в браузерах на настольных компьютерах не используйте дополнительные CSS-границы или тени в настройках редактора VIS. Виджет поставляется со своим собственным оптимизированным стилем.

### 2. Расширенный скрипт виджета (полная настройка)

Если вы хотите внести существенные изменения в дизайн, добавить собственный CSS-код или расширить логику:

- **Связь:** Используйте [VIS2-widget-script-om-weather](https://github.com/H5N1v2/VIS2-widget-script-om-weather).
- **Лучше всего подходит для:** Опытные пользователи, желающие получить полный контроль над каждым HTML-тегом и свойством CSS.

## Иконки и визуализация

Адаптер предоставляет динамические пути к значкам, которые можно использовать непосредственно в визуализациях, например: **vis, iQontrol или Jarvis**.

- **Значки погоды:** Найдено в `weather.current.icon_url`Адаптер автоматически различает день и ночь (например, Солнце и Луна).
- **Направление ветра:** Статические пути в `wind_direction_icon` Отобразить стрелку компаса, соответствующую значению градуса (направление отображения можно выбрать).
- **Предупреждение о порывах ветра:** Под `wind_gust_icon` для скорости ветра выше примерно 39 км/ч (Bft 6), с уровнями 0–4.
- **Иконки фаз Луны:** Значки Луны можно найти в разделе `moon_phase_icon` Они отображают фазы Луны.
- **Несколько значков:** Вы можете выбрать между статическим и анимированным режимом (с помощью [басмилиус](https://github.com/basmilius/meteocons)) иконки.

## Функция «Прогноз солнечной активности» (если включена)

- **Несколько местоположений:** Поддержка нескольких фотоэлектрических систем/мест установки, например, с ориентацией на восток/запад.
- **Почасовой прогноз:** Детальный прогноз выходной мощности, температуры, облачности и продолжительности солнечного сияния.
- **Ежедневный прогноз погоды:** Сводная таблица ожидаемого потребления энергии (Вт·ч) на срок до 14 дней.
- **Прогноз погоды на 15 минут:** 15-минутный прогноз погоды на текущий день и 24 часа.
- **Физическое моделирование:**
  - **Наклон и азимут:** Расчет интенсивности излучения на основе ориентации панели.
  - **Температура фотоэлектрического модуля:** Оценка температуры ячейки с учетом температуры окружающей среды, интенсивности излучения и скорости ветра (модель Файмана).
  - **Продолжительность солнечного сияния:** Перевод продолжительности солнечного сияния в минуты в час.
- **Агрегация:** Автоматическое суммирование данных по всем местоположениям (общий прогноз) на ежедневной, почасовой и 15-минутной основе.
- **Системная интеграция:** Автоматическое получение координат местоположения из конфигурации системы ioBroker, если они не заданы вручную.
- **Температура фотоэлектрического модуля:** Расчетная температура фотоэлектрического модуля, рассчитанная на основе модели Файмана.

## Конфигурация

### Основные настройки

- **Прогнозируемое время:** Временной интервал для почасового просмотра (от 3 до 48 часов).
- **Прогнозируемые дни:** Продолжительность прогноза погоды на сутки (от 3 до 14 дней).
- **Интервал обновления:** Частота обновления данных (15, 30, 60 минут или один раз перед восходом солнца).

### Настройки точек данных

- **Посменный или фиксированный график работы:** Если выбран параметр «Скользящий прогноз на часы», почасовой прогноз всегда будет показывать следующие часы, начиная с текущего. Если выбран параметр «Фиксированный прогноз на часы», почасовой прогноз будет показывать фиксированные временные интервалы (например, 00:00-23:00) независимо от текущего времени.
- **Прогноз погоды на 15 минут:** Если эта функция включена, для 15-минутного прогноза будут созданы дополнительные состояния (до 24 часов на текущий день). Обратите внимание, что доступность 15-минутных данных зависит от API Open-Meteo и может варьироваться в зависимости от местоположения или времени.

### Места расположения (таблица)

Для каждого местоположения необходимо задать следующие значения:

1. **Имя:** Уникальный идентификатор (прошедший очистку по идентификатору объекта).
2. **Широта/долгота:** Позиция GPS (необязательно: в противном случае используются системные значения).
3. **Наклон:** Угол наклона модулей (0° = горизонтальное положение, 90° = вертикальное положение).
4. **Азимут:** Ориентация (от -180° до 180°, 0° = юг, -90° = восток, 90° = запад).
5. **Мощность (кВт):** Установленная пиковая мощность системы.
6. **Часовой пояс:** Выбор местного часового пояса (по умолчанию: Авто).

![Логотип](../../../en/adapterref/iobroker.open-meteo-weather/admin/img/doc.png)

### Глобальные параметры, настраиваемые только при наличии нескольких местоположений!

- **Общая сумма (за день):** Создает канал `sum_peak_locations_Daily`суммируя выходы всех систем.
- **Общая сумма (почасовая):** Создает канал `sum_peak_locations_Hourly` за весь час работы.
- **Общая сумма (за 15 минут):** Создает канал `sum_peak_locations_15_Minutely` за все 15 минут прогноза.

## Технические характеристики и расчеты

### Модель температуры фотоэлектрической системы

Адаптер использует **Модель Файмана** для оценки температуры модуля. Эта модель учитывает ветровое охлаждение, которое напрямую влияет на эффективность:
`pvTemp = Ambient Temperature + Irradiance / (25 + 6.84 * Wind Speed)`.
