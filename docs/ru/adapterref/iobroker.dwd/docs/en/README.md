# Виджеты DWD

Он `dwd` Помимо самого адаптера, в комплект поставки входят еще три интерфейсных модуля:

| Где                              | Что                                                 |
| -------------------------------- | --------------------------------------------------- |
| **вис / вис-2**                  | тот `DWD warnings` виджет, в наборе виджетов `dwd`    |
| **ioBroker.devices**             | тот `DWD warning` плитка для приборной панели        |
| **Аура, администратор и другие** | веб-компонент `<iob-dwd-warnings>` см. веб-компонент |

Все они отображают одни и те же данные и настраиваются одинаково: выберите экземпляр адаптера и номер предупреждения. Все остальное необязательно.

В настройках экземпляра также отображаются текущие активные предупреждения (см. [раздел «Настройки экземпляра»)](#the-instance-settings) .

## Предупреждения адаптера

Адаптер записывает предупреждения из заданного региона в пронумерованные каналы:

```
dwd.0.warning.headline       Amtliche WARNUNG vor WINDBÖEN
dwd.0.warning.text           WINDBÖEN
dwd.0.warning.description    Es treten Windböen mit Geschwindigkeiten ...
dwd.0.warning.instruction    recommendation of the DWD, often empty
dwd.0.warning.severity       0, 1 … 4, 9, 11, 19, 49, 50
dwd.0.warning.begin          start, milliseconds since epoch
dwd.0.warning.end            end, may be empty
dwd.0.numberOfWarnings       how many warnings are currently active
```

** `warning` Это всегда самое серьезное предупреждение, которое в данный момент активно.** Список пересортируется при каждом запуске, поэтому виджет, указывающий на `warning` Всегда показывается самое важное событие — оно не сосредотачивается на каком-то одном конкретном событии. Другие каналы... `warning1`, `warning2` … — у первого нет номера, нет `warning0` Количество каналов задается в настройках адаптера ("Количество предупреждений", 1…10).

Если количество предупреждений меньше, чем количество каналов, оставшиеся каналы очищаются. В этом случае виджеты отображают надпись «Нет предупреждений».

### Предупреждения для одного муниципалитета (предупреждающая ячейка)

Регионы включают в себя районы, прибрежные и озерные зоны. Чтобы получить предупреждения для конкретного муниципалитета, дополнительно введите его **идентификатор системы оповещения** — 9 цифр, начинающихся с `8` (`7` (для районов Берлина и Гамбурга). Идентификатор указан в [списке предупреждений DWD](https://www.dwd.de/DE/leistungen/opendata/help/warnungen/cap_warncellids_csv.csv?__blob=publicationFile\&v=3) (CSV, строки с `8…` /`7…`; строки с `1…` являются районами и не принимаются).

Предупреждения из ячейки предупреждения считываются с геосервера DWD. `maps.dwd.de`) и, **помимо** каналов региона, записываются в отдельную папку, имеющую ту же структуру и то же количество каналов:

```
dwd.0.warncell.numberOfWarnings
dwd.0.warncell.warning.headline     most severe warning of the municipality
dwd.0.warncell.warning1.headline    second most severe
...
```

Что касается региона, то первый канал не имеет номера. Названия папок и каналов содержат название муниципалитета, которое адаптер находит в DWD. Без идентификатора warncell папка не существует; если идентификатор будет удален, адаптер удалит ее при следующем запуске. Карта (`map`) по-прежнему следует установленной федеральной системе координат.

### Цвет

Цвет фона определяется из `severity` и это одинаково как в обоих виджетах, так и в старом наборе виджетов vis-1:

| тяжесть | значение                                                 | цвет      |
| ------- | -------------------------------------------------------- | --------- |
| 0       | никто                                                    | —         |
| 1       | предупреждение о погоде                                  | `#ffeb3b` |
| 2       | предупреждение о неблагоприятных погодных условиях       | `#fb8c00` |
| 3       | Предупреждение о неблагоприятных погодных условиях       | `#e53935` |
| 4       | предупреждение об экстремально суровых погодных условиях | `#880e4f` |
| 9       | предупреждение о жаре                                    | `#c99afe` |
| 11      | без предупреждения                                       | `#c9f`    |
| 19      | Предупреждение об ультрафиолетовом излучении             | `#fe68fe` |
| 49      | сильный жар                                              | `#e966fe` |
| 50      | экстремальная жара                                       | `#f933fe` |

![Цвета интенсивности](../../../../../en/adapterref/iobroker.dwd/docs/img/severity-colors.svg)

_Отображается с учетом цвета текста, присвоенного каждому фоновому изображению._

Эти цвета несут в себе смысл предупреждения, поэтому они **не** соответствуют цветовой схеме «свет/тьма». `#880e4f` пребывание `#880e4f` В обоих случаях. Автоматически выбирается только цвет текста поверх них (черный или белый), поэтому текст остается читаемым в любом из вариантов оформления.

## vis-2: `DWD warnings` виджет

набор виджетов `dwd` виджет `DWD warnings`.

![Виджет в обоих макетах](../../../../../en/adapterref/iobroker.dwd/docs/img/vis2-widget.svg)

### Настройки

| Параметр                  | Значение                                                                                                                                                         |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Макет**                 | `Full warning` — заголовок, описание, точка и инструкция. `Compact` — одна строка с кратким предупреждающим текстом.                                              |
| **Пример**                | который `dwd` пример для чтения                                                                                                                                   |
| **Предупреждение**        | номер предупреждения. `0` является наиболее серьезным (каналом) `warning`), `1` означает `warning1` и так далее.                                                    |
| **Формат времени**        | Как печатаются слова «начало» и «конец». Заполнители: `YYYY`, `YY`, `MM`, `DD`, `hh`, `mm`, `ss`. По умолчанию `DD.MM hh:mm` Только в полном варианте оформления. |
| **Показать инструкцию**   | шоу `instruction` — рекомендация Департамента труда. Часто бывает пустым. Только при полной компоновке.                                                           |
| **Без карты** / **имени** | Обычная карточка vis-2 вокруг виджета                                                                                                                            |

В разделе **«Идентификаторы объектов»** есть еще один переключатель:

| Параметр                                     | Значение                                                                                                                                                                                                                           |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Задайте идентификаторы объектов вручную.** | Отключает вывод данных из экземпляра и номер предупреждения и позволяет направлять виджет на любые шесть состояний. Необходимо только в том случае, если состояния не получены из какого-либо конкретного экземпляра. `dwd` пример. |

### Прибывший из vis-1

В старом наборе виджетов было два шаблона. `tplDwdAdapter` (большой) и `tplDwdAdapterSmall` (компактный). Виджет vis-2 представляет собой **один** виджет, а два его варианта — это `Layout` параметр.

- Представления, которые использую&#x442;** `tplDwdAdapter` ** Идентификаторы объектов автоматически перехватываются виджетом vis-2 — он регистрируется под тем же идентификатором шаблона. Уже настроенные идентификаторы объектов продолжают использоваться, поэтому виджет отображает то же, что и раньше. Ничего не нужно менять вручную.
- Представления, которые использую&#x442;** `tplDwdAdapterSmall` ** Продолжайте использовать старый шаблон vis-1, который по-прежнему поставляется. Чтобы переместить их в виджет vis-2, разместите `DWD warnings` виджет и установить `Layout` к `Compact`.

> **Примечание к старому значению по умолчанию:** в виджете vis-1 поле для инструкции было предварительно заполнено значением `dwd.0.warning.hint` Такого состояния не существует, — пишет адаптер. `dwd.0.warning.instruction` Если ваша инструкция осталась пустой, то причина именно в этом. Виджет vis-2 использует правильное состояние при самостоятельном определении идентификаторов.

## ioBroker.devices: `DWD warning` плитка

На панели управления `ioBroker.devices` Добавьте виджет **с предупреждением DWD** .

![Плитка в трех размерах](../../../../../en/adapterref/iobroker.dwd/docs/img/devices-tiles.svg)

### Настройки

| Параметр                  | Значение                                                                                                      |
| ------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Пример**                | который `dwd` пример для чтения                                                                                |
| **Предупреждение**        | номер предупреждения. `0` является наиболее серьезным (каналом) `warning`), `1` означает `warning1` и так далее. |
| **Формат времени**        | Как печатаются слова «начало» и «конец», используются те же заполнители, что и выше.                          |
| **Период показа**         | показывает начало и конец предупреждения                                                                      |
| **Показать инструкцию**   | Отображает рекомендации DWD, по умолчанию отключены.                                                          |
| **Значок** / **Название** | обычный заголовок плитки                                                                                      |

### Три размера

Плитка адаптируется к размеру, который она получает на панели управления:

- **1×1** — значок и короткий предупреждающий текст.
- **2×0,5** — одна полоса: значок, предупреждающий текст цветом, соответствующим степени серьезности, и точка.
- **2×1 и 2×2** — строка заголовка с точкой, затем заголовок, описание и, если включено, инструкция.

Пока присутствует предупреждение, плитка помечается как «активная», и в качестве акцента используется цвет, соответствующий уровню серьезности предупреждения — таким образом, активное предупреждение видно на панели мониторинга без необходимости читать текст.

## Веб-компонент: `<iob-dwd-warnings>`

Адаптер также отображает предупреждение в виде [веб-компонента](https://github.com/ioBroker/web-components) : это элемент, который поддерживается каждым пользовательским интерфейсом ioBroker. `@iobroker/web-components` Отображает похожие элементы — Aura, администрирование, vis-2 и устройства. Это называется **предупреждением DWD** , как и плитка устройств, поэтому вместо него устройства отображают свою собственную плитку.

Отображается одно предупреждение в одном экземпляре: заголовок, точка, описание и, если включена опция, инструкция, в зависимости от цвета предупреждения — или, в компактном варианте, одна строка с кратким текстом предупреждения. Без предупреждения отображается «Нет предупреждения». Щелчок по предупреждению отображает его целиком в диалоговом окне. Элемент принимает цвета и шрифт страницы, на которой он отображается, и масштабируется в соответствии с размером своего блока.

| Параметр                | Значение                                                                                                                                                                |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Пример**              | который `dwd` пример для чтения                                                                                                                                          |
| **Предупреждения для**  | `Region` - область настроек экземпляра (`warning<n>`); `Municipality (warncell)` - идентификатор ячейки предупреждения в настройках экземпляра (`warncell.warning<n>`) |
| **Предупреждение**      | номер предупреждения. `0` является наиболее серьезным (каналом) `warning`), `1` означает `warning1` и так далее.                                                           |
| **Макет**               | `Full warning` или `Compact` как в виджете vis-2                                                                                                                         |
| **Имя**                 | отображается над предупреждением; пусто: ничего                                                                                                                         |
| **Период показа**       | показывает начало и конец предупреждения                                                                                                                                |
| **Формат времени**      | Как печатаются слова «начало» и «конец», используются те же заполнители, что и выше.                                                                                    |
| **Показать инструкцию** | Отображает рекомендации DWD, по умолчанию отключены.                                                                                                                    |

Настройки виджета vis-2 для идентификаторов объектов, заданных вручную, не имеют аналогов: они существуют для представлений, перенесенных из vis-1. Муниципалитет выбирается с помощью **предупреждений** .

## Настройки экземпляра

Ниже конфигурации в параметрах экземпляра перечислены предупреждения, которые в данный момент активны для указанного региона:

![Текущие предупреждения в настройках экземпляра](../../../../../en/adapterref/iobroker.dwd/docs/img/config-warnings.svg)

Значения считываются непосредственно из состояний, **а не** из процесса адаптера — адаптер работает в режиме планирования и активен всего несколько секунд каждые пять минут, поэтому любые запросы к работающему экземпляру обычно заканчивались таймаутом.

Предупреждение, заголовок которого пуст, скрыто, как и само предупреждение. `warning<n>` Каналы, которые не существуют, потому что параметр "Количество предупреждений" установлен ниже. Если предупреждений нет вообще, об этом сообщается в одной строке. Список обновляется автоматически, когда адаптер записывает новые значения — диалоговое окно не нужно открывать заново.

Если задан идентификатор ячейки предупреждения (warncell ID), то ниже в списке того же типа отображаются предупреждения, относящиеся к этой ячейке.

## Сборка из исходного кода

```bash
npm run build            # adapter + all front-ends
npm run build:widgets    # only the vis-2 widget set -> widgets/dwd/
npm run build:devices    # only the devices tile     -> admin/dm-widgets/
npm run build:wc         # only the web component    -> admin/webcomponents/
```

Источники находятся в `src-widgets/` (вис-2), `src-devices/` (панель управления устройствами) и `src-webcomponents/` (веб-компонент). Первые два компонента — это React + TypeScript, созданные с помощью vite и федерации модулей. Веб-компонент также создан с помощью React + TypeScript, собранный с помощью vite в один модуль ES, который получает React от хост-приложения. `lib/esm/react-19.js` Названия компонентов и URL-адрес повторяются в `io-package.json` под `common.visWidgets` и `common.deviceWidgets` — Добавление виджета означает касание `exposes` конфигурации Vite **и** этого блока.
