# Philips/Versuni CX3550/01

Вентилятор Philips/Versuni CX3550/01 поддерживается локальным зашифрованным протоколом CoAP, используемым в более новых устройствах Philips/Versuni HomeID. Адаптер взаимодействует напрямую с устройством в локальной сети и не использует облачный API.

## Протестированные функции

- Включение/выключение питания
- Скорость вращения вентилятора 1, 2 и 3
- спящий режим
- Естественный ветерок
- Включение/выключение колебаний
- Звуковой сигнал включения/выключения
- Считывание состояния через локальный CoAP
- Показания состояния таймера

## Ограничение по времени

Для этой модели управление таймером должно оставаться отключенным. Во время тестирования вентилятор принимал локальные данные для записи таймера, но затем прошивка изменилась.`D03102` к`0` выключив вентилятор.

Доступны только эти значения таймера, доступные только для чтения:

- `D03110` : код таймера
- `D03211` : минуты таймера

## Параметры

| Ключ     | Значение                     | Ценности                                                                                   |
| -------- | ---------------------------- | ------------------------------------------------------------------------------------------ |
| `D03102` | Власть                       | `1 = on` , `0 = off`                                                                       |
| `D03105` | Зависимое от модели значение | наблюдалось`100` на CX3550/01, намеренно не отображается в процентах вращения вентилятора. |
| `D0310C` | режим вентилятора            | `1 = speed1` ,`2 = speed2` ,`3 = speed3` ,`17 = sleep` , `-126 = naturalBreeze`            |
| `D0310D` | Заявленная текущая скорость  | `0 = off` ,`1 = speed1` ,`2 = speed2` , `3 = speed3`                                       |
| `D0320F` | Колебание                    | читать`23040 = on` , писать`90 = on` , `0 = off`                                           |
| `D03110` | Код таймера                  | только для чтения                                                                          |
| `D03211` | минуты таймера               | только для чтения                                                                          |
| `D03130` | Бип                          | `100 = on` ,`0 = off`                                                                      |

Идентификаторы наблюдаемых устройств:

- `D01S03 = Ventilator` (отображено к общему)`name` состояние)
- `D01S04 = Trident` (Сохраняется как текст, специфичный для платформы/устройства CX, до подтверждения общего значения)
- `D01S05 = CX3550/01` (отображено к общему)`modelId` состояние)
- `D01S12 = 0.1.7` (отображено к общему)`softwareVersion` состояние)
- версия Wi-Fi`AWS_Philips_AIR_Combo@86`
