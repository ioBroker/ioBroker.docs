# Philips/Versuni CX7550/01

Вентилятор Philips/Versuni CX7550/01 типа "умный башенный вентилятор серии 7000" поддерживается локальным зашифрованным протоколом CoAP, используемым более новыми устройствами Philips/Versuni HomeID. Адаптер взаимодействует напрямую с устройством в локальной сети и не использует облачный API.

Устройство сообщает о себе как о платформе.`Babel` (отчеты CX3550/01)`Trident` Он использует то же пространство имен D-кода, что и CX3550/01, но несколько кодов имеют разные значения, поэтому модель необходимо явно выбрать в настройках адаптера.

## Протестированные функции

- Включение/выключение питания
- Скорость вращения вентилятора от 1 до 12
- Автоадаптация
- спящий режим
- Естественный ветерок
- Включение/выключение колебаний
- Таймер от 1 до 12 часов (на данной модели предусмотрена возможность записи).
- Звуковой сигнал включения/выключения
- Яркость дисплея
- Включение/выключение отображения цветовой температуры
- Постоянно отображаемая информация (скорость вращения вентилятора или температура)
- Показания комнатной температуры

## Отличия от CX3550/01

| Функция                        | CX3550/01                                             | CX7550/01                                         |
| ------------------------------ | ----------------------------------------------------- | ------------------------------------------------- |
| Колебание на                   | читает`23040` пишет`90`                               | читает и пишет`80`                                |
| Скорость вращения вентиляторов | от 1 до 3                                             | от 1 до 12, плюс AutoAdapt                        |
| Таймер                         | Только для чтения (запись может выключить вентилятор) | записываемый                                      |
| Отображать                     | никто                                                 | яркость, цветовая температура, постоянный контент |
| Комнатная температура          | не сообщается                                         | `D03224`                                          |

## Параметры

| Ключ     | Значение                                                        | Ценности                                                                                                                                  |
| -------- | --------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `D03102` | Власть                                                          | `1 = on` , `0 = off`                                                                                                                      |
| `D03104` | Цветовое отображение температуры                                | `100 = on` , `0 = off`                                                                                                                    |
| `D03105` | Яркость дисплея                                                 | `0 = off` ,`115 = low` ,`123 = high` ; опускается до`115` автоматически при выключении вентилятора.                                       |
| `D0310C` | режим вентилятора                                               | `0 = AutoAdapt` ,`1` –`10 = speed1..speed10` ,`81 = speed11` ,`82 = speed12` ,`17 = sleep` , `-126 = naturalBreeze`                       |
| `D0310D` | Заявленная текущая скорость                                     | `0 = off` , иначе как`D0310C` без указанных режимов                                                                                       |
| `D03110` | Таймер                                                          | `0 = off` ,`2 = 1h` ,`3 = 2h` ,`4 = 3h` ,`5 = 4h` ,`6 = 5h` ,`7 = 6h` ,`8 = 7h` ,`9 = 8h` ,`10 = 9h` ,`11 = 10h` ,`12 = 11h` , `13 = 12h` |
| `D03130` | Бип                                                             | `100 = on` , `0 = off`                                                                                                                    |
| `D03211` | минуты таймера                                                  | Только для чтения, соответствует коду таймера.                                                                                            |
| `D03224` | Комнатная температура                                           | десятых долей градуса (`240 = 24.0 °C` ), изменяется самостоятельно                                                                       |
| `D0312A` | Постоянно отображаемый контент                                  | `7 = fan speed` , `5 = temperature`                                                                                                       |
| `D0312B` | Постоянно отображаемое содержимое (воспроизводимое устройством) | как`D0312A` , только для чтения                                                                                                           |
| `D0320F` | Колебание                                                       | `80 = on` ,`0 = off`                                                                                                                      |

Код таймера`1` Устройство никогда не генерирует этот код.`5` (4 ч) интерполировано из окружающей последовательности и не было подтверждено напрямую.

Идентификаторы наблюдаемых устройств:

- `D01S03 = Turmventilator` (отображено к общему)`name` состояние)
- `D01S04 = Babel` (платформа)
- `D01S05 = CX7550/01` (отображено к общему)`modelId` состояние)
- `D01S12 = 0.2.9` (отображено к общему)`softwareVersion` состояние)
- версия Wi-Fi`AWS_Philips_AIR_Combo@86` (аналогично CX3550/01)

## Всё ещё не расшифровано

`D0310A = 1` ,`D03133 = 1` ,`D03240 = 0` и`D0313B = 20` Они являются частью каждого окна состояния, но их значение неизвестно. Они намеренно остаются без отображения и отображаются только для чтения.`unknownStates.*` .

Источник декодирования: [проблема GitHub #372](https://github.com/iobroker-community-adapters/ioBroker.philips-air/issues/372) (DrBakterius, значения получены путем сравнения отладочного журнала приложения Philips с журналом отладки адаптера).
