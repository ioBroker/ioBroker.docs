# Руководство по миграции

## От версии 1.1.x до перезаписи

В результате переработки сохраняются корневые каталоги устройств с серийными номерами и существующие пути для записи.`<serial>.light.lights.0` Существующие параметры автоматизации для управления питанием, яркостью, температурой, оттенком, насыщенностью.`hex` и наследие`rgb` поэтому продолжайте работать.

При первом запуске,`native.devices` загружено. Если свойство еще не существует, адаптер считывает объекты устройств, принадлежащие устаревшему адаптеру, и импортирует их.`native.device.ip` /`port` Успешное соединение определяет стабильный серийный номер и сохраняет нормализованный список устройств в собственной конфигурации экземпляра. После этого`native.devices` Если устройство существует, оно является авторитетным для данного экземпляра; объекты устройств, не представленные его конфигурацией, удаляются только из этого экземпляра.

Важные исправления метаданных применяются с помощью`extendObject` :

- `hardwareRevision` Преобразуется из числа в строку.
- Цветовая температура используется`level.color.temperature` и Кельвин.
- RGB/шестнадцатеричный код используется`level.color.rgb` .
- Доступность, здоровье, батарея и возможности суммируются.

Удаление настроенного устройства также удаляет его запись во время выполнения и дерево объектов последовательного порта из этого экземпляра. Другие экземпляры адаптеров и их устройства остаются нетронутыми. Перед обновлением создайте резервную копию состояния объекта экземпляра и адаптера, затем подтвердите доступность устройства и цикл чтения/записи для каждой модели.

## Изменения конфигурации

В настройках устройства теперь используется обычная страница администрирования. Функция опроса сохранена.`native.interval` в секундах. Новые значения по умолчанию: время ожидания запроса 3000 мс, максимальная задержка 300 секунд, задержка записи 200 мс, время ожидания обнаружения 5000 мс и автоматическое добавление в процессе обнаружения отключено.

бывший рядовой`iobroker-react` Вкладка и встроенное в нее редактирование конфигурации удалены. Управление в режиме реального времени остается на вкладке адаптера; постоянная конфигурация относится к странице конфигурации экземпляра.

## Откат

Перед обновлением обязательно сделайте резервную копию ioBroker. Старый адаптер не распознает ioBroker.`native.devices` Для отката восстановите резервную копию конфигурации экземпляра/объекта или вручную добавьте устройства, используя старую вкладку.
