# ioBroker.energiefluss

## Функции

**Дизайн:**

- изменить цвет каждого предмета
- Можно выбрать элементы (круг или прямоугольник).
- Определите таймер для обмена значениями и описаниями внутри элемента.
- Текст внутри элементов можно изменять (\<br> работает как перенос строки)
- %-текст также может иметь разные цвета.
- задать разные цвета для каждой строки
- Линии можно скрыть, если для них не активна анимация.
- задать разные цвета для каждой анимации в строке
- изменить толщину элементов и линий
- Заполните элементы разными цветами (элементы со значениями в процентах можно закрасить в соответствии с их процентным значением; если цвет не выбран, элемент будет прозрачным).
- показать/скрыть тени элементов
- Можно задать тень для значений, описаний и значков.
- изменить радиус окружностей
- Изменить ширину, высоту и скругление углов прямоугольника.
- Задайте собственный цвет и прозрачность теней (поддерживается RGBA).
- Изменяйте шрифты значений и текста (можно импортировать собственные шрифты).
- Выровняйте текст, значения, значки, проценты и текст, отображающий состояние батареи (в большую или меньшую сторону).
- Измените размер шрифта для меток, значений и %-текста.
- Возможна прозрачность для значка, линии, текста, значения, процентного значения и текста об оставшемся заряде батареи.
- Задайте цвет для значка автомобиля, если он заряжается.
- Некоторые значения могут иметь разные цвета, если их значение ниже порогового значения (потребление, производство, сеть и батарея).
- Значок батареи может анимироваться во время зарядки или разрядки.
- Количество анимационных точек, расстояние между ними, длина, длительность, стиль и ширина выбираются.
- Автоматическая регулировка скорости анимации позволяет легко определить элементы с 1 по 11, потребление которых достигает максимума.
- Отображает оставшееся время зарядки аккумулятора (зависит от процента заряда и емкости).
- Возможна тонкая конструкция — уменьшает расстояние до элемента батареи.

**Технические характеристики:**

- Определите точки данных для каждого элемента (добавьте вторую точку данных к производству, дополнительное производство, потребление и используйте сетку для отображения, например, ежедневной сводки).
- Возможно подключение 3 солнечных элементов (при подключении 3 элементов функция Slim-Design будет отключена).
- Также подходит для автономных систем (линия от производства до сети может быть отключена).
- Отображение процента заряда батареи в автомобиле или на элементе батареи.
- использовать разные состояния для подачи электроэнергии в сеть или потребления из нее
- Если значения отрицательные, измените настройки на противоположные (для учета потребления, подачи электроэнергии в сеть, зарядки/разрядки аккумулятора).
- использовать положительные или отрицательные значения для потребления
- Если у вас нет счетчика электроэнергии, рассчитайте свое потребление, исходя из объемов производства и потребления электроэнергии из сети.
- используйте разные состояния для вашей батареи
- Добавьте 10 собственных элементов для устройства-потребителя с различным текстом, значениями и иконкой (2 элемента можно настроить как дополнительную зарядку для автомобиля, 2 элемента — как электростанцию на балконе).
- переведите все значения из Вт в кВт.
- Все значения могут быть указаны в Вт или кВт. Адаптер соответствующим образом преобразует значения.
- Выберите количество десятичных знаков, которые вы хотите отображать (0, 1, 2) — для значений и уровня заряда батареи.
- Выберите единицу измерения (свободный текст)
- Вычтите потребление топлива автомобилем и дополнительным оборудованием из потребления топлива в доме (выбирается пользователем).
- Все объекты можно выбрать через браузер объектов.
- Задайте пороговое значение, чтобы отображались только значения, превышающие его.

## Выполнение

Отображение возможно через ссылку на экземпляр. Затем его можно вставить в iFrame или HTML-виджет.
