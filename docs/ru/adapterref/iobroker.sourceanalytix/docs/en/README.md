# Документация SourceAnalytix

SourceAnalytix рассчитывает потребление, доставку и затраты за день, неделю, месяц, квартал и год на основе данных счетчиков или электроэнергии.

Документация построена вокруг вопросов, заданных пользователями на форуме и в разделе "Проблемы". Каждый заголовок соответствует одному из этих вопросов.

- **[Начало работы](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/01.erste-schritte/README.md) :** Установите SourceAnalytix и настройте свой первый измеритель.
- **[Руководства](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/02.anleitungen/README.md) :** Пошаговые руководства: настройка источников, корректировка показаний счетчика, ввод цен, оценка значений и обслуживание адаптера.
- **[Справочная информация](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/03.referenz/README.md) :** Все настройки, сгенерированные состояния, сообщения и записи журналов для поиска.
- **[Устранение неполадок](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/04.fehlerbehebung/README.md) :** наиболее распространенные сообщения об ошибках и неверные значения, а также способы их устранения.
- **[Введение](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/05.hintergrund/README.md) :** Кратко объясняется принцип работы адаптера при выполнении расчетов.

**Немецкий:** [Немецкая документация](https://github.com/DrozmotiX/ioBroker.sourceanalytix/blob/main/docs/de/README.md)
