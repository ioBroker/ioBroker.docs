## Что означает сообщение "Обнаружена перезагрузка устройства" и как работает обнаружение перезагрузки?

<!-- abschnitt: prio=A; gewicht=23; readme=partial; cluster=meter-readings-09,cumulative-power-16,meter-readings-10; features=source-reset-detection,reset-confirmation,reset-jitter-ignore,source-threshold,source-hidden-reset-keys -->

<!-- muss beantworten: Schwellwert, Bestätigung, Überlauf, Stromausfall. -->

**Вкратце:** «Обнаружен сброс устройства» — это предупреждение, а не ошибка. SourceAnalytix заметил, что показания вашего источника резко упали (перезапуск, сбой питания, переполнение или замена счетчика), и с этого момента счетчик продолжает отсчитывать данные поверх предыдущего значения. Потребление не теряется, и отрицательные значения не появляются.

<!-- quelle: code=main.js:3065@v0.6.1; code=lib/calculation.js:301-390@v0.6.1; forum=561385 -->

### Условия

Данные условия применяются ко всей документации.

| Срок                | Значение                                                                                                                                                                                                                                                                     |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Целевой блок        | Единица измерения цены, которую вы присвоили источнику, например, кВт·ч. SourceAnalytix рассчитывает все ее значения: общую сумму, начальные значения и пороговое значение.                                                                                                  |
| Значение устройства | Значение исходной точки данных, преобразованное в целевую единицу измерения. Возможно изменение значения в резервную систему, например, после перезагрузки устройства.                                                                                                       |
| Общий               | Собственные показания счетчика SourceAnalytix в штате `sourceanalytix.0.<device>.cumulativeReading` При включенной функции обнаружения сброса устройство никогда не отключается само по себе.                                                                                 |
| Компенсировать      | Значение `valueAtDeviceReset` В настройках SourceAnalytix источника. Правило: total = значение устройства + смещение. Без сброса оно равно 0. До версии 0.6.x диалоговое окно не отображало это. Начиная с версии 0.7.0, оно находится в источнике в разделе «Для экспертов». |
| Начальное значение  | Общая сумма на начало периода ("День", "Неделя", "Месяц", "Квартал", "Год"). Потребление за период = общая сумма − начальное значение.                                                                                                                                       |
| Порог               | Поле «Порог» в настройках источника. Максимальное падение уровня шума, которое всё ещё считается шумом измерения. В целевой единице измерения значение по умолчанию — 1.                                                                                                     |
| Перезагрузить       | Значение показаний устройства падает больше порогового значения. Причиной может быть перезагрузка, переполнение или замена счетчика.                                                                                                                                         |

### Как работает обнаружение

При каждом новом значении параметра устройства SourceAnalytix вычисляет значение параметра устройства + смещение и сравнивает результат с последней итоговой суммой:

1. **Равное или большее значение:** значение принимается.
2. **Ниже, но не более чем на пороговое значение:** это считается шумом измерения. Общее значение остается неизменным, а значение игнорируется.
3. **Значение ниже порогового:** это может указывать на сброс настроек. SourceAnalytix сохраняет итоговое значение, записывает в журнал сообщение "Ожидание следующего измерения перед подтверждением возможного сброса настроек устройства" и ожидает следующего значения.
4. **Следующее значение определяет:**
   - Если значение снова близко к старому (в пределах порогового значения) или поднялось более чем наполовину, то низкое значение является выбросом. Оно отбрасывается, и в журнале появляется сообщение «Отклонена возможная перезагрузка устройства».
   - Если значение равно или выше минимального, но всё ещё низкое, сброс подтверждается. SourceAnalytix устанавливает смещение равным старой сумме минус минимальное значение устройства и сообщает: «Обнаружен сброс устройства для… с сохранением кумулятивного значения… с новым смещением…». С этого момента значение устройства продолжает увеличиваться сверх старой суммы.
   - Если значение окажется ещё ниже, SourceAnalytix продолжит ждать.

<!-- quelle: code=lib/calculation.js:279-390@v0.6.1; code=main.js:3036-3078@v0.6.1; issue=#1199 -->

Пример с пороговым значением в 1 кВт·ч: после отключения электроэнергии счетчик показывает 1000 кВт·ч и обнуляется.

| Значение устройства | Компенсировать | Общий        | Бревно                                |
| ------------------- | -------------- | ------------ | ------------------------------------- |
| 1000 кВт·ч          | 0              | 1000 кВт·ч   | –                                     |
| 0 кВтч              | 0              | 1000 кВт·ч   | "Жду следующего прочтения…"           |
| 0,4 кВт·ч           | 1,000          | 1000,4 кВт·ч | "Обнаружена перезагрузка устройства…" |
| 1,0 кВт·ч           | 1,000          | 1001 кВт·ч   | –                                     |

<!-- quelle: code=lib/calculation.js:301-390@v0.6.1 -->

Потеряно лишь то, что устройство подсчитало в промежутке между последним значением перед сбросом и первым значением после него, поскольку само устройство больше не передавало эту информацию.

<!-- quelle: code=lib/calculation.js:348@v0.6.1; interview=4 -->

> \[!NOTE] Если первое значение после реального сброса уже поднялось более чем наполовину, SourceAnalytix считает его выбросом. Потребление с момента сброса в этом случае не учитывается, и в журнале появляется сообщение: «Отклонено возможное сбрасывание устройства… Если устройство действительно было сброшено, потребление с момента сброса не учитывалось». Вы можете исправить это, как описано в [разделе «Исправление неверных значений](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/02.anleitungen/02.zaehlerstaende-korrigieren.md#correct-wrong-too-high-negative) ».

<!-- quelle: code=lib/calculation.js:333-337@v0.6.1; code=main.js:3056-3060@v0.6.1; issue=#1227 -->

### Переполнение, сбой питания и перезапуск SourceAnalytix

- **Переполнение:** Если после достижения максимального значения счетчик обнуляется, это обычное сбрасывание SourceAnalytix.
- **Сбой питания устройства:** если устройство запускается с нулевым или меньшим значением, это также означает сброс.
- **Программа SourceAnalytix была остановлена:** итоговые данные сохранены в состоянии. `cumulativeReading` Сброс, произошедший в этот момент времени, обнаруживается по первому значению после начала, если значение устройства + смещение в этот момент все еще ниже сохраненной суммы более чем на пороговое значение.
- **Источники питания (Вт):** У них отсутствует функция обнаружения сброса. Они не предоставляют показания счетчика, которые SourceAnalytix мог бы сравнить.

<!-- quelle: code=main.js:1910@v0.6.1; code=main.js:3397-3435@v0.6.1; code=main.js:3031@v0.6.1; forum=897463 -->

### Когда функция обнаружения сброса отключена

Без флажка «Включено обнаружение сброса значений устройства» SourceAnalytix принимает каждое падение значения. При этом суммарные и периодические значения также падают, и потребление может стать отрицательным. Это предназначено только для источников, которым разрешено намеренно падать значения. В журнале при каждом падении значения отображаются как «Накопленные показания для … уменьшились, пока отключено обнаружение сброса».

<!-- quelle: code=lib/calculation.js:279-296@v0.6.1; code=main.js:3073@v0.6.1 -->

**До версии 0.6.1:** это сообщение регистрируется на уровне информации и может переполнять журнал для источников, которые отбрасываются. **Начиная с версии 0.6.2** , оно появляется только в журнале отладки ( [#1262](https://github.com/DrozmotiX/ioBroker.sourceanalytix/issues/1262) ).

<!-- quelle: code=main.js:3073@v0.6.1; issue=#1262; pr=#1274 -->

Старое сообщение "Обнаружен сброс устройства… функция отключена (или ниже порогового значения)" существовало только до версии v0.4.x. Начиная с версии v0.5.0, оно было заменено сообщениями, указанными выше. Если вы по-прежнему видите это сообщение, обновите SourceAnalytix.

<!-- quelle: code=main.js:3036-3075@v0.6.1; pr=#1178; forum=916495 -->

### Какие изменения произошли по сравнению с версией 0.6.2?

**Начиная с версии 0.6.2:** Подтвержденный сброс откатывается, если старое значение устройства возвращается за один шаг. Пример: устройство сообщает 1000, затем дважды 0, затем снова 1000. До версии 0.6.1 в этом случае общее значение удваивалось до 2000. Начиная с версии 0.6.2, SourceAnalytix восстанавливает старое смещение, общее значение остается равным 1000, а в журнале появляется сообщение «Откатил сброс устройства…» ( [#1258](https://github.com/DrozmotiX/ioBroker.sourceanalytix/issues/1258) ).

<!-- quelle: issue=#1258; pr=#1274; code=lib/calculation.js:368-405@ff9e352; code=main.js:3396-3412@ff9e352 -->

**Начиная с версии 0.6.2:** Если смещение превышает общее значение (обычно после ручной коррекции или замены счетчика), источник продолжает работу. SourceAnalytix выдает предупреждение «Знаменитое значение при сбросе устройства… больше известного кумулятивного значения…» и устанавливает смещение равным общему значению минус значение устройства при следующем значении. До версии 0.6.1 источник останавливался с ошибкой «Проверка настроек для… Известное значение при сбросе устройства… > известное кумулятивное значение… не может быть продолжена» ( [#1257](https://github.com/DrozmotiX/ioBroker.sourceanalytix/issues/1257) ).

<!-- quelle: issue=#1257; pr=#1274; code=main.js:1943-1952@v0.6.1; code=main.js:1979-1991@ff9e352; code=main.js:3380-3389@ff9e352 -->

## Счетчик, который обнуляется каждый день: что происходит внутри?

<!-- abschnitt: prio=B; gewicht=16; readme=partial; cluster=cumulative-power-15,periods-07,meter-readings-27,upgrade-migration-other-29; features=source-cumulative-meter,reset-confirmation,source-power-integration,source-reset-detection,source-threshold -->

<!-- muss beantworten: Tageszähler (z. B. Ertrag heute), Mitternacht, Abzug am Folgetag. -->

**Вкратце:** при включенном обнаружении сброса SourceAnalytix обрабатывает ночное падение как 0, подобно любому другому сбросу: он ждет следующего значения, затем устанавливает смещение и продолжает подсчет общего количества. Каждую ночь отсутствует лишь небольшой остаток. При выключенном обнаружении сброса SourceAnalytix принимает падение, и потребление предыдущего дня снова вычитается на следующий день.

<!-- quelle: code=lib/calculation.js:445-455; code=lib/calculation.js:508-597; code=main.js:3560-3602; interview=4; forum=948910 -->

### Что происходит ночью?

Пример с пороговым значением 0,1 кВт·ч. Вечером счетчик показал 4,2 кВт·ч, а смещение по сравнению с предыдущими ночами составляет 1000 кВт·ч.

| Время | Значение устройства | Компенсировать | Общий         | Что происходит                                                               |
| ----- | ------------------- | -------------- | ------------- | ---------------------------------------------------------------------------- |
| 23:58 | 4,2 кВт·ч           | 1,000          | 1004,2 кВт·ч  | –                                                                            |
| 0:00  | –                   | 1,000          | 1004,2 кВт·ч  | Перенос периода: начальное значение "Дня" становится равным 1004,2 кВт·ч.    |
| 0:01  | 0 кВтч              | 1,000          | 1004,2 кВт·ч  | Запись "Жду следующего прочтения…"                                           |
| 0:10  | 0,05 кВт·ч          | 1,004.2        | 1004,25 кВт·ч | В журнале событий указано: "Обнаружен сброс устройства…", сегодня 0,05 кВт·ч |

<!-- quelle: code=lib/calculation.js:508-597; code=main.js:3014-3016; code=main.js:2780-2786; code=main.js:3573; code=main.js:3586 -->

Сброс периода в 0:00 системного времени не зависит от устройства. Он устанавливает начальные значения равными общему значению, и поскольку общее значение не уменьшается, новый день начинается с нуля. Поэтому не имеет значения, сбросило ли устройство данные незадолго до или вскоре после полуночи. Упускается только то, что устройство подсчитало между последним значением перед сбросом и самим сбросом.

<!-- quelle: code=main.js:3014-3016; code=main.js:2780-2786; code=lib/calculation.js:508-597; interview=4 -->

### Когда что-то идёт не так

| Параметр                                                                                                 | Что происходит                                                                                                             | Результат                                                                             |
| -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Сбросить обнаружение в выключенном состоянии                                                             | Общая сумма уменьшается на величину суточного потребления устройства.                                                      | Суточная норма отрицательная, за месяц и год теряется потребление за предыдущий день. |

Для правильной настройки см. [раздел "Мой счетчик обнуляется каждый день"](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/02.anleitungen/02.zaehlerstaende-korrigieren.md#meter-restarts-after-power-loss) .

**Начиная с версии 0.7.0:** Мастер «Добавить источник» помечает точки данных, идентификатор или имя которых соответствует ежедневному значению, как «ежедневный счетчик». Если вы все же выберете такую точку, вам будет предложено ответить на вопрос «Значение иногда падает до 0?» утвердительно. Это включает обнаружение сброса. Если для источника, значение которого падает, эта функция отключена, на вкладке «Проблемы» появится сообщение «Значение счетчика падает до 0, обнаружение сброса отключено».

### Лучше: счётчик, который не опускается обратно.

Ежедневный счётчик подойдёт, но общий счётчик точнее. Если его нет, можно использовать в качестве источника потребляемую мощность устройства или создать собственный постоянно возрастающий счётчик с помощью скрипта и оценить его.
