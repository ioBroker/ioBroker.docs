# ioBroker.schlueter-thermostat

Облачный адаптер для **термостатов Schlüter / OJ Microline OWD5**

---

## 🌍 Обзор

Этот адаптер интегрирует **термостаты Schlüter / OJ Microline OWD5** в ioBroker через **официальные облачные API** .

Он поддерживает:

- 🌡 Мониторинг температуры
- 🎯 Заданные точки
- 🔄 Управление режимами
- ⏱ Таймеры комфорта и повышения мощности
- 🏖 Режим отпуска
- 📅 Полное расписание
- ⚡ Статистика энергетики
- 🔔 Дополнительные уведомления от адаптера (Telegram, Pushover, WhatsApp, Email, Signal, Matrix, Synology Chat)

> **Работает только в облаке** — локальный шлюз, Modbus или API локальной сети не требуются.

## 🖥️ Диспетчер устройств (Администратор)

Предыдущая пользовательская вкладка «Администрирование» была удалена и заменена официальным **менеджером устройств** ioBroker Admin.

Теперь каждый экземпляр адаптера отображается в Диспетчере устройств и показывает все термостаты этого экземпляра.

### Функции

| Область                              | Что вы можете сделать                                                                                                                                                                                                                            |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Список устройств**                 | Посмотреть все термостаты, сгруппированные по типу адаптера.                                                                                                                                                                                     |
| **Карта**                            | Значок подключения на карте, а также сводные значения в подробной информации о карте (температура в помещении/на полу, обогрев, режим регулирования, потребление).                                                                               |
| **Подробности (меню из трех точек)** | Откройте подробные сведения о термостате, используя вкладку **«Информация»** (идентификатор группы, идентификатор термостата, модель) и вкладку **«Управление».**                                                                                |
| **Контроль**                         | Установите ручные/комфортные параметры, запустите действия по применению расписания/эко/ручного/комфортного режима, настройте продолжительность повышения температуры и его применение, управляйте настройками отпуска и переименуйте термостат. |

### Откройте Диспетчер устройств

1. Откройте административную панель ioBroker.
2. Откройте раздел **«Диспетчер устройств»** .
3. Расширьте свои возможности`schlueter-thermostat.X` пример
4. Для открытия раздела "Подробности/Действия" используйте меню с тремя точками на карточке термостата.

## 🚀 Как начать

1. Установите адаптер в ioBroker.
2. Открыть конфигурацию экземпляра
3. Входить:

| Параметр              | Описание                                             |
| --------------------- | ---------------------------------------------------- |
| Имя пользователя      | Ваш логин в облаке Schlüter/OJ                       |
| Пароль                | Пароль облака                                        |
| Ключ API              | В большинстве случаев работает вариант по умолчанию. |
| Идентификатор клиента | Найдено в информации о термостате.                   |
| Версия клиентского ПО | Числовое значение с термостата                       |
| Интервал опроса       | По умолчанию: 60 секунд                              |

4. Сохраните и запустите адаптер.

## 🔄 Рабочий процесс адаптера

### При запуске

- Вход в облако
- Создать дерево объектов
- Начать опрос

### Цикл опросов

- Считывает данные по всем группам и термостатам.
- Обновляет температуру, режимы и заданные значения.
- Обновление времени окончания (комфорт/ускорение)
- Расписание чтения
- Считывает значения энергии

### Когда вы нажимаете кнопку «Применить»

- Адаптер формирует **полный набор данных для обновления термостата.**
- Отправляет в облако
- Облачные сервисы пересылают данные на термостат.

| apply.boost.apply    | Режим ускорения                      |
| apply.eco.apply      | Эко-режим                            |

## ⏱ Управление временем

- Время окончания указывается по **местному времени термостата.**
- Без суффикса часового пояса (нет)`Z` )
- Поддерживаются режимы Boost и Comfort (максимальное время работы в режиме Boost — 60 мин.).
- Смещение часового пояса термостата учитывается.

## 🔁 Резервный опрос

Когда облачное хранилище недоступно или **все** термостаты отключены, адаптер автоматически снижает частоту опроса для экономии ресурсов:

| Фаза                 | Поведение                                                                                             |
| -------------------- | ----------------------------------------------------------------------------------------------------- |
| Нормальный           | Опрос выполняется с заданным интервалом (по умолчанию: 60 с).                                         |
| Отступление          | При каждой последующей поломке интервал удваивается (60 с → 120 с → 240 с → … → 1 ч)                  |
| Фиксированный график | По истечении 1 часа опрос переключается на фиксированное расписание в **12:00** и **00:00.**          |
| Восстановление       | Как только хотя бы один термостат снова подключится к сети, интервал сбросится до заданного значения. |

## Вкладка «Уведомления»

Активирует push-уведомления для информирования о событиях на устройстве. Все уведомления будут отправляться на предварительно настроенном системном языке.

### Категории уведомлений

| # | Категория                                |
| - | ---------------------------------------- |
| 1 | **⚠️ Термостат отключен**                |
| 2 | **✅ Термостат онлайн**                   |
| 3 | **⚠️ Соединение с облаком потеряно**     |
| 4 | **✅ Подключение к облаку восстановлено** |

### Поддерживаемые поставщики

Каждый включенный провайдер поддерживает необязательный селектор экземпляра адаптера (`type:instance` ) в конфигурации экземпляра. Если оставить поле пустым, адаптер автоматически определит запущенный экземпляр и будет отдавать предпочтение экземпляру с наименьшим номером (`.0` ,`.1` , ...).

| Поставщик                      | Дополнительная конфигурация                         |
| ------------------------------ | --------------------------------------------------- |
| **Телеграмма**                 | Идентификатор пользователя или чата (необязательно) |
| **Слабак**                     | Название, Устройство (необязательно)                |
| **WhatsApp** (`whatsapp-cmb` ) | Номер телефона (необязательно)                      |
| **Электронная почта**          | Получатель, Субъект (необязательно)                 |
| **Сигнал** (`signal-cmb` )     | Номер телефона (необязательно)                      |
| **Матрица** (`matrix-org` )    | Дополнительная конфигурация не требуется.           |
| **Чат Synology**               | Название канала (обязательно)                       |
