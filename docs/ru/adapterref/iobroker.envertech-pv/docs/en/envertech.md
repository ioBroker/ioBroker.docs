# Информация об адаптере Envertech-PV

## Общая информация

Этот адаптер позволяет получать данные из облачного сервиса Envertech ( [www.envertecportal.com](http://www.envertecportal.com) ) путем регулярного опроса веб-сервиса. Все полученные данные хранятся в состояниях, доступных пользователям.

Доступ к порталу Envertech защищен комбинацией имени пользователя и пароля. Envertech поддерживает учетные записи конечных пользователей и учетные записи установок. Данный адаптер тестировался только с учетными записями конечных пользователей, которые предоставляют доступ только к одной установке на одну учетную запись. Каждой учетной записи конечного пользователя присваивается идентификатор станции (station-id) компанией Envertech. Адаптер позволяет использовать несколько идентификаторов станций на один экземпляр адаптера. Это позволяет отслеживать более одной установки в рамках одного экземпляра.

Данные, полученные с портала Envertech, структурированы следующим образом:

- Информация о станции идентифицируется по идентификатору станции.
- один или несколько шлюзов, связанных со станцией, идентифицируемых по серийному номеру шлюза.
- один или несколько инверторов, подключенных к этим шлюзам.

## Конфигурация

Как описано ранее, каждая станция идентифицируется своим идентификатором. Получить идентификатор станции, присвоенный учетной записи пользователя, можно, введя имя пользователя и пароль в соответствующие поля на вкладке «Конфигурация облака» и нажав кнопку «Получить идентификатор станции». Идентификатор станции будет отображен в поле «Идентификатор станции». Обратите внимание, что для корректной работы получения идентификатора экземпляр адаптера должен быть активен.

После получения нужного идентификатора станции вы можете настроить одну или несколько станций в таблице «Список облачных станций для мониторинга» — по одной на строку.

### Вкладка «Общие параметры»

Здесь вы указываете некоторые общие параметры.

<p align=center><img src="img/envertech_tab_options.jpg" width="600" /></p>

- Включить логирование HTTP-запросов<br> Включение этой опции активирует логирование HTTP-запросов и данных ответа при взаимодействии с веб-сервисом Envertech.

- Включить запись в журнал новых ключей данных<br> Включение этой опции активирует запись предупреждения в журнал, если веб-сервис envertech сообщает данные, которые еще не реализованы.

### Параметры эксперта TAB

Здесь вы можете указать некоторые специальные параметры. Рекомендуется оставлять все эти параметры без изменений, если не указано иное.

<p align=center><img src="img/envertech_tab_expert.jpg" width="600" /></p>

- URL-адрес облачного сервиса Envertech<br> Здесь можно изменить URL-адрес для доступа к облачному сервису Envertech.

- Таймаут HTTP-запроса (с)<br> Этот параметр задает общий тайм-аут для всех HTTP-запросов. Значение указывается в секундах.

- Минимальная задержка (с)<br> Эта опция определяла минимальную задержку в секундах между завершением цикла опроса и началом следующего цикла.

## Дополнительная информация

Если вы получаете идентификатор станции, используя имя пользователя и пароль в адаптере, то и таким способом вы сможете его получить:

- Войдите на сайт [www.envertecportal.com](http://www.envertecportal.com)
- Чтобы отобразить исходный код веб-страницы, щелкните правой кнопкой мыши и выберите «Показать исходный код».
- Найдите строку "var stationId = ...". Код должен выглядеть так: "var stationId = '3EH583732993048DDX706VT57F8708452';".
- Вам нужна строка справа ("3EH58373299348DDX706VT57F8708452").
- Введите эту строку в столбец таблицы с меткой Station-Id.
