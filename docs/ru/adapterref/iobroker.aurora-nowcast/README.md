## Адаптер Aurora Nowcast для ioBroker

Предоставляет **актуальные (прогнозируемые) данные** об активности северного и южного сияния для заданного местоположения на основе общедоступных данных Центра прогнозирования космической погоды NOAA (SWPC).

> **Примечание:**\
> &#x20;Данные о северном сиянии, полученные с помощью прибора OVATION, отражают _текущие условия (прогноз на данный момент)_ на основе измерений солнечного ветра в реальном времени, а не долгосрочный прогноз.\
> &#x20;Кроме того, данные индекса Kp предоставляют **72-часовой прогноз** для целей планирования.

---

## Функции

- Получает данные об активности полярного сияния в режиме реального времени (модель NOAA OVATION) как для северного, так и для южного полушария.
- Вычисляет вероятность видимости северного сияния в заданном местоположении.
- Предоставляет текущий индекс Kp (с интервалом в 1 минуту) и прогноз Kp на 72 часа.
- Предоставляет данные о солнечном ветре в реальном времени (Bz, полное поле, скорость, плотность) в качестве индикаторов раннего предупреждения о полярных сияниях.
- Предоставляет состояния ioBroker для автоматизации, визуализации и оповещений.
- Дополнительно можно использовать данные о местоположении системы или ввести широту/долготу вручную.
- Подходит для информационных панелей, уведомлений и сценариев «умного дома».

## Конфигурация

Вы можете сделать одно из двух:

- Используйте местоположение системы, указанное в ioBroker, или
- Укажите координаты вручную (широта/долгота в десятичных градусах).

Если определение местоположения системой отключено, необходимо ввести координаты вручную.

Примеры:

| Расположение | Широта | Долгота |
| ------------ | ------ | ------- |
| Берлин       | 52.5   | 13.4    |
| Буэнос-Айрес | -34.6  | -58.4   |
| Рейкьявик    | 64.1   | -21.9   |

Значения для северо-восточного направления положительные, значения для юго-западного направления отрицательные.

## Штаты

### Справочная информация: Индексы космической погоды

**Индекс Kp** — планетарный индекс K измеряет глобальную геомагнитную активность по шкале от 0 до 9 (0 = спокойная, 9 = сильная буря). Значения ≥ 5 указывают на условия геомагнитной бури (G1 и выше), при которых полярное сияние становится видимым в средних широтах, таких как Центральная Европа. Адаптер предоставляет как текущее значение Kp за 1 минуту, так и прогноз на 72 часа.

### ОВАЦИЯ — Вероятность северного сияния

| Состояние          | Тип   | Описание                                                                                                                           |
| ------------------ | ----- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `probability`      | число | Расчетная вероятность видимости северного сияния в указанном месте (%)                                                             |
| `observation_time` | число | Время наблюдений за солнечным ветром в направлении, восходящем потоке, используется в качестве входных данных для модели (UTC, мс) |
| `forecast_time`    | число | Время, для которого рассчитывается прогнозируемый геомагнитный отклик Земли (UTC, мс)                                              |

### индекс Кп

| Состояние              | Тип   | Описание                                                         |
| ---------------------- | ----- | ---------------------------------------------------------------- |
| `kp.value`             | число | Текущий индекс Kp (0–9, десятичная дробь, кормление за 1 минуту) |
| `kp.time`              | число | Время измерения текущего значения Kp (UTC, мс)                   |
| `kp.g_scale`           | число | Производная шкала G NOAA (0 = отсутствует, 1–5 = G1–G5)          |
| `kp.forecast_max`      | число | Максимальное значение Kp в прогнозе на 72 часа                   |
| `kp.forecast_max_time` | число | Время, когда достигается прогнозируемый максимум (UTC, мс)       |
| `kp.forecast`          | нить  | Полный 72-часовой прогноз Kp в виде массива JSON.`[{time, kp}]`  |

### Солнечный ветер

**Bz (GSM)** — z-компонента межпланетного магнитного поля в координатах GSM. Сильно отрицательное значение Bz (ориентация на юг) открывает магнитосферу Земли для энергии поступающего солнечного ветра и является наиболее надежным краткосрочным предвестником полярных сияний — обычно за 15–60 минут до видимой активности. **Bt** — это полная величина поля; Bz относительно Bt указывает, насколько сильно поле ориентировано на юг.

| Состояние                | Тип   | Единица | Описание                                                                    |
| ------------------------ | ----- | ------- | --------------------------------------------------------------------------- |
| `solar_wind.bz`          | число | нТ      | Компонент Bz в GSM-координатах (отрицательное значение = направление на юг) |
| `solar_wind.bt`          | число | нТ      | Суммарная напряженность межпланетного магнитного поля                       |
| `solar_wind.speed`       | число | км/с    | Скорость протонов в солнечном ветре                                         |
| `solar_wind.density`     | число | п/см³   | Плотность протонов солнечного ветра                                         |
| `solar_wind.mag_time`    | число | РС      | Время измерения магнитометром (UTC)                                         |
| `solar_wind.plasma_time` | число | РС      | Время измерения плазмы (UTC)                                                |

Эти состояния могут использоваться для:

- Уведомления (например, push-уведомления, когда Kp ≥ 5 или Bz ≤ −10 нТ)
- Визуализация панели мониторинга
- Правила автоматизации (например, активировать камеру при высокой вероятности северного сияния)

## Практическое руководство: как увидеть северное сияние

Наблюдение за северным сиянием осуществляется в два этапа: **планирование на основе** прогноза Kp и **реагирование в режиме реального времени** с использованием данных о солнечном ветре и данных OVATION.

### Этап 1 — План: ожидается ли шторм?

Использовать`kp.forecast_max` Проверить, ожидается ли геомагнитная буря в ближайшие 72 часа. Примерные пороговые значения видимости в зависимости от географической широты:

| `kp.forecast_max` | Уровень шторма | Видно до \~                                                   |
| ----------------- | -------------- | ------------------------------------------------------------- |
| < 5               | Никто          | только в высоких широтах                                      |
| 5 (G1)            | Незначительный | \~60° северной широты — северная Шотландия, южная Скандинавия |
| 6 (G2)            | Умеренный      | \~55° с.ш. — северная Германия, Польша                        |
| 7 (G3)            | Сильный        | \~50° с.ш. — Лондон, Франкфурт, Варшава                       |
| 8 (G4)            | Серьезный      | \~45° северной широты — Швейцария, Австрия, северная Италия   |
| 9 (G5)            | Экстремальный  | \~40° северной широты — центральная Франция, северная Испания |

`kp.forecast_max_time` Это позволяет узнать, _когда_ ожидается пик активности — полезно для таких уведомлений, как «Прогноз шторма G2 на сегодня вечером».

`kp.g_scale` Отражает текущий уровень шторма в реальном времени (0 = спокойно, 1–5 = G1–G5).

> **Примечание:** Это приблизительные географические широты Европы. Фактическая видимость сильно зависит от...`solar_wind.bz` (см. ниже), облачность и световое загрязнение.

### Этап 2 — Реакция: Аврора сейчас активна?

Даже при высоком значении Kp полярное сияние становится видимым только тогда, когда межпланетное магнитное поле (ММП) поворачивается **на юг** — что подтверждается сильным отрицательным значением Kp.`solar_wind.bz` Это наиболее надежный краткосрочный триггер.

| `solar_wind.bz`  | Значение                                                                           |
| ---------------- | ---------------------------------------------------------------------------------- |
| > 0 нТ           | На севере — магнитосфера в значительной степени замкнута, полярное сияние слабое.  |
| от 0 до −5 нТ    | Слабое продвижение на юг — маргинальные условия                                    |
| от −5 до −10 нТл | На юге — начинает нарастать активность северного сияния.                           |
| ≤ −10 нТ         | Направление сильно на юг — вероятно сильное северное сияние.                       |
| ≤ −20 нТ         | Экстремальное — интенсивное полярное сияние, наблюдаемое далеко в средних широтах. |

**Время опережения:** Bz измеряется в точке наблюдения L1 между Землей и Солнцем. Солнечному ветру требуется **15–60 минут** , чтобы пройти от L1 до Земли — это ваш предупреждающий период.

`solar_wind.bt` — это полная напряженность поля. Когда`|bz|` подходы`bt` Поле почти полностью направлено на юг. Например, bz = −18 нТл при bt = 20 нТл дает более сильный сигнал, чем bz = −10 нТл при bt = 30 нТл.

`solar_wind.speed` Усиливает эффект: сильный ветер (> 400 км/с) в сочетании с отрицательным значением Bz передает больше энергии в магнитосферу. Очень высокие скорости (> 600 км/с) могут вызывать полярное сияние даже при умеренном значении Bz.

`solar_wind.density` играет вспомогательную роль: высокая плотность (> 10 п/см³) увеличивает динамическое давление и может усиливать активность.

### Подтверждение местоположения: что это значит?`probability` добавлять?

Kp — это глобальный индекс, описывающий общую геомагнитную активность, а не то, что происходит над вашим местоположением.`probability` Это отличается от других методов: расчет производится специально для заданных вами координат с использованием **модели NOAA OVATION** , которая принимает в качестве входных данных измерения солнечного ветра в реальном времени и моделирует фактическую протяженность и интенсивность овального полярного сияния. Поэтому она реагирует на изменения Bz быстрее и точнее, чем производное значение Kp.

Для Центральной Европы (примерно 50–55° с.ш.) реалистичные диапазоны в условиях активной погоды:

| `probability` | Интерпретация                                                             |
| ------------- | ------------------------------------------------------------------------- |
| < 5 %         | В вашем местоположении отсутствует какая-либо значимая активность.        |
| 5–15 %        | «На высоте» — стоит посмотреть, особенно за пределами городов.            |
| 15–30 %       | Активное явление — северное сияние, вероятно, будет видно при ясном небе. |
| > 30 %        | Высокий уровень накладных расходов на деятельность                        |

Использовать`probability` В качестве подтверждения, специфичного для данного местоположения, помимо Kp и Bz. Рост значения наряду с резко отрицательным значением Bz является наиболее явным признаком того, что стоит выйти на улицу.

### Пример логики автоматизации

Практическая трехуровневая стратегия оповещения:

1. **Режим просмотра** —`kp.forecast_max` ≥ 5: «В ближайшие 72 часа ожидается шторм — следите за погодными условиями сегодня ночью»
2. **Тревога** -`kp.value` ≥ 5 И`solar_wind.bz` ≤ −10: «Активная гроза, направление Bz сильно южное — северное сияние вероятно через 15–60 минут»
3. **Подтверждение по верхнему краю** —`probability` ≥ 15: «Вероятно, северное сияние видно в вашем местоположении прямо сейчас»

Объединение всех трех слоев позволяет избежать ложных срабатываний: фильтр Kp подтверждает наличие реальной бури, фильтр Bz подтверждает открытость магнитосферы, а фильтр вероятности подтверждает активность именно в вашем местоположении.

## Источник данных

Этот адаптер использует общедоступные данные, предоставленные:

- Центр прогнозирования космической погоды NOAA (SWPC)\
  &#x20;<https://www.swpc.noaa.gov/>

В частности, для оценки активности полярных сияний в заданном местоположении используется модель прогнозирования полярных сияний OVATION и связанные с ней геомагнитные индексы в реальном времени.

---

## Отказ от ответственности

NOAA и SWPC не имеют отношения к этому проекту.

Данные, используемые этим адаптером, предоставлены NOAA для общественного пользования.\
&#x20;Точность, полнота и актуальность предоставленной информации не гарантируются.

Видимость северного сияния зависит от множества внешних факторов (например, облачность, световое загрязнение, ориентация межпланетного магнитного поля), которые выходят за рамки возможностей данного адаптера.
