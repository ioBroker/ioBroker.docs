# Виджеты VIS 2

[Вернуться к основному файлу README](/#/adapters/rssfeed#vis-2-widgets)

Набор виджетов VIS 2 предоставляет пять компонентов, которые считывают состояния JSON, созданные адаптером RSSFeed. В этом руководстве описаны все параметры, видимые в редакторе свойств VIS 2, и данные, доступные, если компонент поддерживает шаблон EJS.

## RSSWidget

Этот компонент, работающий с одной лентой новостей, считывает одно состояние RSSFeed, при необходимости ограничивает или фильтрует содержащиеся в ней статьи и отображает ленту с редактируемым шаблоном EJS.

| Параметр   | По умолчанию            | Диапазон или выбор | Описание                                                                                                                                                                           |
| ---------- | ----------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `oid`      | Никто                   | RSSFeed state      | Выбирает штат, содержащий данные RSSFeed в формате JSON.                                                                                                                           |
| `template` | Встроенный шаблон ленты | Шаблон EJS         | Управляет всем выводом HTML-кода. Кнопка редактирования открывает расширенный редактор шаблонов.                                                                                   |
| `max`      | `5`                     | `1` к`9999`        | Максимальное количество первых статей, передаваемых в шаблон.                                                                                                                      |
| `filter`   | Пустой                  | Текст              | Термины, разделённые точкой с запятой. Статья сохраняется, если хотя бы один термин встречается в её заголовке, описании или категориях. Сопоставление нечувствительно к регистру. |

### Данные шаблона

| Выражение      | Описание                                                                               |
| -------------- | -------------------------------------------------------------------------------------- |
| `rss.meta`     | Метаданные выбранного фида. Используйте RSSMetaHelper для их просмотра.                |
| `rss.articles` | Статьи, оставшиеся после применения лимита и фильтра.                                  |
| `widgetid`     | Идентификатор этого виджета VIS 2, полезный для CSS с ограниченной областью видимости. |
| `style`        | Настройки стиля VIS для этого виджета.                                                 |
| `vis`          | Объект среды выполнения VIS, включая такие функции, как`vis.formatDate(...)` .         |

Ограничение применяется до применения фильтра, поэтому результат может содержать меньше статей, чем указано.`max` Ошибки шаблона отображаются красным цветом. Если ни один штат не выбран, вместо пустого компонента отображаются прилагаемые примерные данные.

```ejs
<h2><%= meta.title || "" %></h2>
<% articles.forEach(function (item) { %>
    <article>
        <h3><%= item.title || "" %></h3>
        <div><%- item.description || "" %></div>
    </article>
<% }); %>
```

Для ознакомления с синтаксисом EJS и правилами безопасного вывода см. [раздел «Нотация шаблонов EJS»](/#/docs/adapterref/iobroker.rssfeed/docs/ejs-templates.md) .

## RSSMultiWidget

Этот компонент объединяет несколько лент, сортирует их статьи от самых новых к самым старым и отображает один общий шаблон EJS. Каждая лента может использовать отдельное имя, ограничение на количество статей и фильтр.

| Параметр    | По умолчанию                              | Диапазон      | Описание                                                                                |
| ----------- | ----------------------------------------- | ------------- | --------------------------------------------------------------------------------------- |
| `feedcount` | `1`                                       | `1` или более | Количество групп фидов, отображаемых в редакторе свойств.                               |
| `template`  | Встроенный шаблон для многократной подачи | Шаблон EJS    | Управляет полным выводом объединенного списка в формате HTML.                           |
| `dpcount`   | `1`                                       | `1` или более | Количество дополнительных полей данных, отображаемых в редакторе. См. ограничение ниже. |

### Настройки для каждого канала RSSMultiWidget

| Параметр           | По умолчанию | Диапазон      | Описание                                                                                                                                               |
| ------------------ | ------------ | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `feed-oid`         | Никто        | RSSFeed state | Выбирает состояние RSSFeed для этой группы.                                                                                                            |
| `feed-name`        | Пустой       | Текст         | Дополнительное название источника добавляется к каждой собранной статье.`meta_name` .                                                                  |
| `feed-maxarticles` | `10`         | `1` или более | Максимальное количество статей взято из этой ленты.                                                                                                    |
| `feed-filter`      | Пустой       | Текст         | Термины, разделённые точкой с запятой, без учёта регистра, сопоставляются с заголовком, описанием и категориями. Должен совпадать хотя бы один термин. |

### Дополнительная группа точек данных

| Параметр        | По умолчанию | Описание                                                                                                                                                                                                      |
| --------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `datapoint_oid` | Никто        | Текстовое поле, предназначенное для дополнительного идентификатора состояния ioBroker. В текущей реализации VIS 2 эти значения не передаются в шаблон EJS, поэтому их пока не следует использовать в шаблоне. |

### Шаблонные данные и поля собранной статьи

Шаблон получает`rss.articles` ,`widgetid` ,`style` , и`vis` Оно не получает ни одного значимого`rss.meta` Поскольку статьи поступают из разных источников, каждая собранная статья содержит только:

- `title` ,`description` ,`categories` ,`date` , и`link` из оригинальной статьи;
- `meta_name` из настроек виджета;
- `meta_title` и`meta_description` из исходного потока.

Другие оригинальные области, такие как`author` ,`guid` ,`image` ,`pubdate` , или`enclosures` В настоящее время данный компонент не копирует эти данные. Фильтрация применяется до достижения лимита для каждого потока данных. Если группа потоков данных еще не существует, используются пакеты образцов товаров.

```ejs
<% rss.articles.forEach(function (item) { %>
    <article>
        <strong><%= item.meta_name || item.meta_title || "" %></strong>
        <h3><%= item.title || "" %></h3>
        <div><%- item.description || "" %></div>
    </article>
<% }); %>
```

## RSSMetaHelper

Этот справочный компонент отображает метаданные одного фида в виде таблицы. Он помогает пользователям определить, какие значения фактически предоставляет выбранный ими издатель, прежде чем создавать шаблон.

| Параметр | По умолчанию | Описание                                                               |
| -------- | ------------ | ---------------------------------------------------------------------- |
| `oid`    | Никто        | Выбирает штат, содержащий данные RSSFeed в формате JSON, для проверки. |

В таблице показано`meta.title` ,`description` ,`link` ,`xmlurl` ,`date` ,`pubdate` ,`author` ,`language` ,`image.url` ,`image.title` ,`favicon` ,`copyright` ,`generator` , и`categories` Указанное свойство может оставаться пустым, поскольку форматы RSS и издатели предоставляют разные метаданные. Если ни один штат не выбран, отображаются сгруппированные примеры данных.

## RSSArticleHelper

Этот справочный компонент отображает известные свойства выбранной статьи. Он полезен для поиска названий полей и проверки реальных значений, передаваемых из фида.

| Параметр  | По умолчанию | Диапазон      | Описание                                                                                                               |
| --------- | ------------ | ------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `oid`     | Никто        | RSSFeed state | Выбирает штат, содержащий данные RSSFeed в формате JSON, для проверки.                                                 |
| `prefix`  | `item`       | Текст         | Префикс отображается перед каждым свойством, например:`item.title` Это изменяет только метки во вспомогательном файле. |
| `article` | `1`          | `1` к`9999`   | Номер статьи, начинающийся с единицы;`1` выбирает первую статью.                                                       |

Вспомогательные списки`title` ,`description` ,`summary` ,`link` ,`origlink` ,`permalink` ,`date` ,`pubdate` ,`author` ,`guid` ,`comments` ,`image.url` ,`image.title` ,`categories` ,`source` , и`enclosures` .`source` и`enclosures` Отображаются в формате JSON. Сообщается об окончании списка, если выбранное число слишком велико. При отсутствии выбранного состояния отображаются сгруппированные примеры данных.

Вспомогательная функция описывает полный исходный текст статьи. В настоящее время RSSMultiWidget копирует только меньший набор данных, перечисленных в отдельном разделе.

## RSSArticleMarquee5

Бегущая строка объединяет заголовки из нескольких источников в непрерывно движущуюся бегущую строку. Статьи отсортированы от самых новых к самым старым. При желании можно добавить временные метки и названия источников, а заголовки могут открывать исходные статьи.

| Параметр       | По умолчанию  | Диапазон или выбор      | Описание                                                                                          |
| -------------- | ------------- | ----------------------- | ------------------------------------------------------------------------------------------------- |
| `count`        | `1`           | `1` или более           | Количество групп фидов, отображаемых в редакторе свойств.                                         |
| `speed`        | `200`         | `1` или более           | Скорость движения измеряется в пикселях в секунду; чем больше значение, тем быстрее движение.     |
| `divider`      | `+++`         | Текст                   | Разделитель вставляется перед каждым заголовком.                                                  |
| `pauseonhover` | Включено      | Вкл/выкл                | Приостанавливает отображение тикера, пока указатель мыши находится над ним.                       |
| `opentype`     | `none`        | `none` ,`link` ,`popup` | Обычный текст, ссылка, открывающаяся в новой вкладке/окне, или диалоговое окно iframe внутри VIS. |
| `withtime`     | Неполноценный | Вкл/выкл                | Добавляет время публикации статьи.                                                                |
| `withdate`     | Неполноценный | Вкл/выкл                | Добавляет день и месяц.                                                                           |
| `withyear`     | Неполноценный | Вкл/выкл                | Добавляет двузначный год после дня и месяца.                                                      |
| `withname`     | Неполноценный | Вкл/выкл                | Добавляет заданное имя ленты или заголовок ленты, если имя пустое.                                |

### Настройки для каждого канала RSSArticleMarquee5

| Параметр           | По умолчанию | Диапазон      | Описание                                                                                                                   |
| ------------------ | ------------ | ------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `feed-oid`         | Никто        | RSSFeed state | Выбирает состояние RSSFeed для этой группы.                                                                                |
| `feed-name`        | Пустой       | Текст         | Необязательное имя источника, используемое при`withname` включено.                                                         |
| `feed-maxarticles` | `1`          | `1` или более | Максимальное количество статей взято из этой ленты.                                                                        |
| `feed-filter`      | Пустой       | Текст         | Термины, разделённые точкой с запятой и нечувствительные к регистру, сопоставляются с заголовком, описанием и категориями. |

Ограничение на количество лент применяется до применения фильтра. В режиме всплывающего окна страница издателя загружается во фрейм; издатели могут предотвратить это с помощью заголовков безопасности браузера. Если группа лент еще не существует, используются пакетные образцы данных.
