# Виджеты VIS 1

[Вернуться к основному файлу README](/#/adapters/rssfeed#vis-1-widgets)

Классический набор виджетов VIS 1 считывает состояния JSON, созданные адаптером RSSFeed. В этом руководстве описан каждый виджет и каждая опция, предлагаемая редактором свойств VIS. Названия опций указаны для того, чтобы существующие представления были понятны и их было легче перенести.

## Виджет RSS-ленты 2

Этот виджет для отображения одной ленты считывает состояние одной ленты RSSFeed, при необходимости ограничивает или фильтрует ее статьи и отображает результат с редактируемым шаблоном EJS. Используйте его, когда для одной ленты требуется полностью настраиваемый макет.

| Параметр          | По умолчанию            | Описание                                                                                                                                                                                         |
| ----------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `rss_oid`         | Никто                   | Выбирает штат, содержащий данные RSSFeed в формате JSON.                                                                                                                                         |
| `rss_template`    | Встроенный шаблон ленты | Управляет всем выводом HTML-кода. Редактор открывает расширенное диалоговое окно редактирования EJS.                                                                                             |
| `rss_maxarticles` | Все доступные статьи    | Ограничивает количество первых статей, передаваемых в шаблон. Значения ниже.`1` рассматриваются как`1` .                                                                                         |
| `rss_filter`      | Пустой                  | Поисковые запросы разделяются точкой с запятой. Статья сохраняется, если хотя бы один из терминов встречается в её заголовке, описании или категориях. Сопоставление нечувствительно к регистру. |

### Данные шаблона

| Выражение      | Описание                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `rss.meta`     | Метаданные выбранного фида. См. раздел «Помощник по метаданным» для получения информации о полях, предоставляемых фидом. |
| `rss.articles` | Массив статей, оставшихся после применения ограничения и фильтра.                                                        |
| `widgetid`     | Идентификатор этого виджета VIS. Полезно для CSS-селекторов, которые должны влиять только на этот виджет.                |
| `style`        | Настройки стиля VIS для этого виджета.                                                                                   |
| `vis`          | Объект среды выполнения VIS, например, для`vis.formatDate(...)` .                                                        |

Ограничение на количество статей применяется до применения фильтра. Поэтому фильтр может отображать меньшее количество статей, чем заданное максимальное значение. Ошибки шаблона отображаются красным цветом внутри виджета. Виджет автоматически обновляется при изменении выбранного состояния RSSFeed в текущем представлении.

```ejs
<h2><%= meta.title || "" %></h2>
<% articles.forEach(function (item) { %>
    <article>
        <small><%= vis.formatDate(item.pubdate || item.date, "TT.MM.JJJJ SS:mm") %></small>
        <h3><%= item.title || "" %></h3>
        <div><%- item.description || "" %></div>
    </article>
<% }); %>
```

`description` излучается с`<%-` Поскольку описания лент часто содержат HTML-код. Делайте это только для тех лент, которым вы доверяете. Информацию о самом языке EJS см. в [разделе «Нотация шаблонов EJS»](/#/docs/adapterref/iobroker.rssfeed/docs/ejs-templates.md) .

## RSS Feed Multi Widget 3

Этот виджет объединяет несколько лент в один список, сортирует все собранные статьи от новых к старым и отображает их с помощью одного шаблона EJS. Каждая лента может иметь собственное имя, ограничение и фильтр. Дополнительные состояния ioBroker также могут быть доступны для шаблона.

| Параметр        | По умолчанию                              | Описание                                                                                 |
| --------------- | ----------------------------------------- | ---------------------------------------------------------------------------------------- |
| `rss_feedCount` | `1`                                       | Количество групп фидов, отображаемых в редакторе свойств.                                |
| `rss_template`  | Встроенный шаблон для многократной подачи | Управляет полным выводом объединенного списка в формате HTML.                            |
| `rss_dpCount`   | `1`                                       | Количество дополнительных полей данных, отображаемых в редакторе свойств.                |
| `rss_dpN`       | Никто                                     | Выбирает дополнительный номер штата`N` Его текущая стоимость предоставляется через`dp` . |

### Настройки для каждого RSS-канала Многовиджет 3

`N` это номер подачи из`1` через`rss_feedCount` .

| Параметр           | По умолчанию         | Описание                                                                                                                                               |
| ------------------ | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `rss_oidN`         | Никто                | Состояние, содержащее JSON-данные RSSFeed для фида.`N` .                                                                                               |
| `rss_nameN`        | Пустой               | Необязательное отображаемое имя. Оно добавляется к каждой статье из этой ленты следующим образом:`meta_name` .                                         |
| `rss_maxarticlesN` | Все доступные статьи | Максимальное количество статей, взятых из этой ленты. Значения ниже.`1` рассматриваются как`1` .                                                       |
| `rss_filterN`      | Пустой               | Термины, разделённые точкой с запятой, без учёта регистра, сопоставляются с заголовком, описанием и категориями. Должен совпадать хотя бы один термин. |

### Шаблонные данные и поля с несколькими источниками подачи

| Выражение                  | Описание                                                                                                 |
| -------------------------- | -------------------------------------------------------------------------------------------------------- |
| `rss.articles`             | Объединенный массив, отсортированный по`date` от самых новых к самым старым.                             |
| `item.meta_name`           | Указано название источника.                                                                              |
| `item.meta_title`          | Оригинальное название взято из метаданных этого канала.                                                  |
| `item.meta_description`    | Исходное описание взято из метаданных этого канала.                                                      |
| `dp["state.id"]`           | Текущее значение дополнительно настроенного состояния, указываемое его полным идентификатором состояния. |
| `widgetid` ,`style` ,`vis` | Идентификатор виджета, стили VIS и объект среды выполнения VIS.                                          |

В отличие от виджета с одной лентой новостей, здесь используется один общий виджет.`rss.meta` Объект не может представлять все исходные потоки. Используйте три варианта.`meta_*` Вместо этого к каждой статье добавляются поля. VIS 1 сохраняет остальные исходные свойства статьи, поэтому можно использовать и поля, отображаемые в вспомогательном инструменте для статей. Ограничение применяется перед фильтром для каждой ленты.

```ejs
<% rss.articles.forEach(function (item) { %>
    <article>
        <strong><%= item.meta_name || item.meta_title || "" %></strong>
        <h3><%= item.title || "" %></h3>
        <div><%- item.description || "" %></div>
    </article>
<% }); %>
```

## Вспомогательная функция метаданных RSS-ленты

Meta Helper — это справочный виджет. Выберите фид, и он отобразит поля метаданных и их текущие значения в таблице. Это самый быстрый способ узнать, какие поля фактически предоставляет конкретный фид, прежде чем использовать их в шаблоне отдельного фида.

| Параметр  | По умолчанию | Описание                                                               |
| --------- | ------------ | ---------------------------------------------------------------------- |
| `rss_oid` | Никто        | Выбирает штат, содержащий данные RSSFeed в формате JSON, для проверки. |

В таблице показано`meta.title` ,`description` ,`link` ,`xmlurl` ,`date` ,`pubdate` ,`author` ,`language` ,`image.url` ,`image.title` ,`favicon` ,`copyright` ,`generator` , и`categories` Форматы RSS и издатели различаются, поэтому поле может быть пустым, даже если вспомогательная функция его отображает. Таблица обновляется при изменении выбранного состояния.

## Вспомогательная программа для RSS-лент статей 2

Вспомогательная функция для статей отображает все известные поля одной статьи в виде таблицы. Выберите номер статьи, просмотрите доступные значения и скопируйте название поля из левого столбца при создании шаблона.

| Параметр      | По умолчанию | Описание                                                                                                                        |
| ------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `rss_oid`     | Никто        | Выбирает штат, содержащий JSON-данные RSSFeed, для проверки.                                                                    |
| `rss_prefix`  | `item`       | Префикс отображается перед каждым именем поля, например:`item.title` Установите значение переменной, указанное в вашем шаблоне. |
| `rss_article` | `1`          | Номер статьи начинается с единицы.`1` Выбирает первую статью; значения ниже`1` рассматриваются как`1` .                         |

Вспомогательные списки`title` ,`description` ,`summary` ,`link` ,`origlink` ,`permalink` ,`date` ,`pubdate` ,`author` ,`guid` ,`comments` ,`image.url` ,`image.title` ,`categories` ,`source` , и`enclosures` .`source` и`enclosures` Отображаются в формате JSON. Когда запрошенное количество статей превышает конец ленты, вспомогательная функция сообщает количество доступных статей. Префикс изменяет только отображаемые метки; он не изменяет данные RSS.

## RSS-лента Заголовок Бегущая строка 5

Бегущая строка объединяет заголовки статей из одной или нескольких лент в непрерывно движущуюся бегущую строку. Все статьи отсортированы от самых новых к самым старым. В бегущую строку можно добавлять даты и названия источников, а также отображать заголовки с указанием источника.

| Параметр           | По умолчанию        | Описание                                                                                                                                                                      |
| ------------------ | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rss_feedCount`    | `1`                 | Количество групп фидов, отображаемых в редакторе свойств.                                                                                                                     |
| `rss_speed`        | `1` в новом виджете | Управляет скоростью движения. Длина текста делится на это значение для расчета продолжительности анимации, поэтому большее значение означает более высокую скорость движения. |
| `rss_divider`      | `+++`               | Текст вставляется перед каждым заголовком.                                                                                                                                    |
| `rss_pauseonhover` | Включено            | Приостанавливает отображение бегущей строки, пока указатель мыши находится над ней. Поведение на сенсорных устройствах может отличаться.                                      |
| `rss_opentype`     | `none`              | `none` отображает простой текст,`link` открывает статью в целевом объекте браузера, и`popup` открывает его в диалоговом окне iframe.                                          |
| `rss_withtime`     | Неполноценный       | Добавляет время публикации статьи.                                                                                                                                            |
| `rss_withdate`     | Неполноценный       | Добавляет день, месяц и время. Этот параметр имеет приоритет над другим.`rss_withtime` .                                                                                      |
| `rss_withyear`     | Неполноценный       | Добавляет день, месяц, двузначный год и время. Этот параметр имеет приоритет над другими вариантами выбора даты/времени.                                                      |
| `rss_withname`     | Неполноценный       | Добавляет`rss_nameN` или заголовок ленты, если имя не было введено, перед каждым заголовком.                                                                                  |

### Настройки для каждого канала RSS-ленты Заголовок Бегущая строка 5

| Параметр           | По умолчанию         | Описание                                                                                                                   |
| ------------------ | -------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `rss_oidN`         | Никто                | Состояние, содержащее JSON-данные RSSFeed для фида.`N` .                                                                   |
| `rss_nameN`        | Пустой               | Необязательное имя источника, используемое при`rss_withname` включено.                                                     |
| `rss_maxarticlesN` | Все доступные статьи | Максимальное количество статей, взятых из этой ленты. Значения ниже.`1` рассматриваются как`1` .                           |
| `rss_filterN`      | Пустой               | Термины, разделённые точкой с запятой и нечувствительные к регистру, сопоставляются с заголовком, описанием и категориями. |

Для бегущей строки фильтрация происходит до ограничения. В режиме всплывающего окна внешняя статья встраивается в iframe; издатели могут предотвратить это с помощью заголовков безопасности браузера. Бегущая строка использует цвета текста и фона VIS виджета и применяет большинство других настроенных стилей текста к своему движущемуся тексту.
