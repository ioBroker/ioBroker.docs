# Функциональные возможности

## Общий

Этот адаптер собирает данные через HTTP API с вашего зарядного устройства e-GoCharger по Wi-Fi.

## Установка

Вы можете просто добавить экземпляр в ioBroker с помощью адаптера go-e.

## Конфигурация оборудования

Для включения адаптера необходимо активировать HTTP-интерфейс через приложение.

1. Подключите мобильное устройство к точке доступа Wi-Fi на устройстве.
2. Откройте приложение go-eCharger.
3. перейти в облако
4. Расширенные настройки (erweiterte Einstellungen)
5. Активировать HTTP-интерфейс

## Настройка адаптера ioBroker

- Сервер или IP-адрес. Пожалуйста, введите здесь имя хоста или IP-адрес для подключения к go-eCharger. По умолчанию go-eCharger регистрируется с указанным именем хоста.

- Интервал обновления сервиса определяет, с каким интервалом будет отправляться запрошенный адаптером статус. Рекомендуемое значение: 30 секунд. Поставщик рекомендует минимум 5 секунд.

- Интервал обновления определяет, как часто адаптер должен разрешать перенастройку, например, максимального тока. Слишком частая перенастройка может привести к поломке оборудования и автомобиля!

## AmperePV

| атрибут go-e                                                                                       | Тип         | Единица | Пример: Изношенная позиция |
| -------------------------------------------------------------------------------------------------- | ----------- | ------- | -------------------------: |
| [АМХ](https://github.com/goecharger/go-eCharger-API-v1/blob/master/go-eCharger%20API%20v1%20EN.md) | целое число | ампер   |              go-e.0.ampere |

Этот атрибут аналогичен атрибуту Ampere, но не сохраняет данные постоянно. После перезагрузки эта информация теряется. Атрибут Ampere используется из-за того, что EEPROM устройства допускает запись только 100 000 раз. Если вы используете фотоэлектрическую систему с go-e, следует использовать этот атрибут вместо Ampere.

## Энергия

Отрегулируйте все параметры, касающиеся энергии. Этот узел недоступен для записи, но содержит несколько переключателей.

### Максимальная мощность

| атрибут go-e | Тип         | Единица | Пример: Изнурительная позиция |
| ------------ | ----------- | ------- | ----------------------------: |
| -            | целое число | ватты   |      go-e.0.energy.max\_watts |

Аппаратное обеспечение позволяет регулировать допустимый ток в амперах во время работы нагрузки. Любые фотоэлектрические устройства или приборы для измерения потребления говорят о ваттах, а не об амперах. Чтобы использовать количество ватт и произвести расчет с учетом подключенных фаз или адаптера, необходимо пересчитать значение в амперах.

Для этого набора`go-e.0.energy.max_watts` (0 — это ваш экземпляр адаптера) с максимально допустимой мощностью в ваттах. Обновление будет отправляться на устройство только каждые 30 секунд. Этот параметр можно изменить в меню настроек, но рекомендуется делать это не чаще. Дополнительная информация содержится в [официальном руководстве](https://github.com/goecharger/go-eCharger-API-v1/blob/master/go-eCharger%20API%20v1%20DE.md) .

## Режим разблокировки кабеля (состояние разблокировки)

Регулировка блокировки кабеля. Этот параметр определяет, когда кабель блокируется и разблокируется. 0: блокировка до тех пор, пока автомобиль подключен к зарядке (по умолчанию) 1: автоматическая разблокировка после зарядки 2: кабель всегда остается заблокированным

# Нагрузка не менее 6 А

Эта опция задает режим работы адаптера, позволяющий продолжать загрузку автомобиля с пониженной скоростью, даже если солнечной энергии недостаточно.

# phaseSwitchModeBuffer

По умолчанию: 500 Вт

Это буфер для настроек в параметре phaseSwitchWatts. Этот буфер уменьшает величину изменения при переключении между однофазным и трехфазным режимами работы. Чтобы отключить, установите значение 0.\
&#x20;Значение параметра phaseSwitchWatts по умолчанию равно 4200 (Вт).

'''Пример:''' Настройка: phaseSwitchWatts = 4200; phaseSwitchModeBuffer = 500;
