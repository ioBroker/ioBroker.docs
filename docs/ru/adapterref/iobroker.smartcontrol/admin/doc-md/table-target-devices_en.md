Введите здесь все целевые устройства, которые вы хотите переключить, как только сработает триггер и будут выполнены условия в зонах.

_Почему существуют разные состояния для включения и выключения?_ Обычно они одинаковы (ожидаются разные состояния).`true` /`false` ) для включения/выключения, но в некоторых случаях пользователям может потребоваться другое состояние и значение состояния для включения или выключения устройства. Например: fully-tablet-control.0.device.tablet\_bathroom.commands.screenOn и fully-tablet-control.0.device.tablet\_bathroom.commands.screenOff. Вы также можете добавить состояния, которые не являются логическими (`true` /`false` ), но строка или число.

Для каждой строки таблицы этот адаптер добавляет связанные состояния.`smartcontrol.x.targetDevices.xxx` При изменении этих состояний исходное целевое состояние изменяется соответствующим образом, и наоборот.
