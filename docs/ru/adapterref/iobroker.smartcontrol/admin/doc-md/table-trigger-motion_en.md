Здесь вы можете ввести данные о ваших датчиках движения. При желании вы также можете определить состояния яркости и соответствующие пороговые значения.

| Столбец                                                                                                                                       | Обязательный | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------- | :----------: | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![изображение](https://github.com/iobroker-community-adapters/ioBroker.smartcontrol/blob/master/admin/doc-md/img/check_box-24px.svg?raw=true) |      Да      | Включает/отключает эту строку таблицы. Если не активирована, адаптер игнорирует эту строку таблицы. В параметрах адаптера, в разделе «ДОПОЛНИТЕЛЬНЫЕ ПАРАМЕТРЫ > Проверка входных данных», можно настроить проверку на корректность даже отключенных строк.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Название датчика движения                                                                                                                     |      Да      | Любое название для датчика движения.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Датчик состояния движения                                                                                                                     |      Да      | Состояние датчика движения. Предполагается, что это логическое значение, поэтому установите его в значение true.`true` когда происходит движение и к`false` Когда нет движения, что характерно почти для всех датчиков движения. Если состояния вашего датчика движения отличаются, используйте псевдонимы. См. [обсуждение на форуме](https://forum.iobroker.net/post/492267) .                                                                                                                                                                                                                                                                                                                                |
| сек                                                                                                                                           |      Нет     | По истечении указанного количества секунд (и при отсутствии дальнейшего движения в течение этого времени) целевые устройства будут выключены.<br> Чтобы отключить: оставьте поле пустым или установите значение 0.<br> Дополнительная информация: Как только состояние датчика движения изменится на...`false` Если движение больше не обнаруживается, запускается таймер, отсчитывающий указанное здесь количество секунд. По истечении этого времени целевые устройства, определенные в соответствующей зоне (зонах), будут выключены. Если возникает новое движение (состояние датчика движения изменяется на...),`true` Пока таймер работает, он будет сброшен, а целевые устройства останутся включенными. |
| (значок: таймер выключен)                                                                                                                     |      Нет     | Если эта опция включена, таймер выключения для целевых устройств, которые уже были включены, устанавливаться не будет. Пример использования: [см. сообщение на форуме](https://forum.iobroker.net/post/433871) .                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

### Дополнительно: Яркость (люкс)

| Столбец           | Обязательный | Описание                                                                                                                                                                                                                                                              |
| ----------------- | :----------: | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Состояние яркости |      Нет     | Состояние, отражающее текущую яркость.                                                                                                                                                                                                                                |
| Порог             |      Нет     | Пороговое значение яркости. Если текущая яркость в поле «Состояние яркости» превышает это значение, движение игнорируется.<br> Обратите также внимание на опцию _«Не проверять яркость, если зона включена»_ в разделе «ДОПОЛНИТЕЛЬНЫЕ ПАРАМЕТРЫ > Датчики движения». |

### Дополнительно: Связанные устройства

| Столбец            | Обязательный | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------ | :----------: | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Связанные триггеры |      Нет     | Здесь вы можете выбрать «Другие триггеры»; они будут активировать соответствующую зону так же, как и датчик движения.<br> Создайте триггер в разделе «Другие триггеры» в таблице ниже и добавьте этот новый триггер в раздел «Датчик движения» в подразделе «Связанные триггеры».<br><br> _Пример использования:_ При включении настенного выключателя свет должен выключиться через x секунд при условии отсутствия движения (например, коридор с интеллектуальным настенным выключателем и датчиком движения в коридоре). Если движение обнаружено, таймер настенного выключателя отключается, и вступает в действие таймер датчика движения.<br><br> **Примечание:** Если вы только что создали раздел «Другие триггеры», и они не отображаются здесь сразу, переключитесь на другую вкладку, а затем вернитесь на эту (или сохраните и закройте экземпляр адаптера и откройте его снова). |
| сек                |      Нет     | Для параметра "Связанные триггеры": укажите количество секунд, по истечении которых зона выключится, если движение не обнаружено и если "Связанный триггер" активировал включение.<br> _Примечание:_ Вы можете установить это количество секунд отдельно здесь (и адаптер не будет брать указанное выше значение "Секунды"), поскольку это количество секунд вступает в силу только тогда, когда датчик движения перестает обнаруживать движение, а для устройств Xiaomi это занимает, например, 2 минуты. Поэтому вы можете установить другое время здесь.                                                                                                                                                                                                                                                                                                                                   |
| ✖                  |      Нет     | Для функции «Связанные триггеры»: если она активирована, зона включается только «Связанными триггерами» (например, настенными выключателями), но никогда не датчиком движения. Это означает, что устройство не включается при обнаружении движения. Но если зона включается настенным выключателем (установленным в разделе «Связанные устройства») и перед выключением обнаруживается движение, зона будет выключена, как только движение прекратится. Подробности см. в [выпуске № 42](https://github.com/Mic-M/ioBroker.smartcontrol/issues/42) .                                                                                                                                                                                                                                                                                                                                          |
