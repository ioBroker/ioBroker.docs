Эта таблица необязательна:<br> Здесь вы указываете дополнительные условия, которые должны (или не должны) применяться, например: Кто-то присутствует, Никто не присутствует, Сегодня выходной и т. д. Затем вы можете выбрать эти условия в соответствующих таблицах «Другие параметры».

| Столбец                                                                                                                                       | Обязательный | Описание                                                                                                                                                                                                                                                                                                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------- | :----------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![изображение](https://github.com/iobroker-community-adapters/ioBroker.smartcontrol/blob/master/admin/doc-md/img/check_box-24px.svg?raw=true) |      Да      | Включает/отключает эту строку таблицы. Если не активирована, адаптер игнорирует эту строку таблицы. В параметрах адаптера, в разделе «ДОПОЛНИТЕЛЬНЫЕ ПАРАМЕТРЫ > Проверка входных данных», можно настроить проверку на корректность даже отключенных строк.                                                                                                   |
| Название состояния                                                                                                                            |      Да      | Введите здесь любое название вашего состояния, например, «Сегодня отпуск».                                                                                                                                                                                                                                                                                    |
| Состояние                                                                                                                                     |      Да      | Укажите, например, для данного состояния.`javascript.0.Holiday.isHolidayToday` .                                                                                                                                                                                                                                                                              |
| Государственная стоимость                                                                                                                     |      Да      | Указывает значение условия, если оно должно применяться. Вы можете использовать`true` ,`false` числа, подобные`144` или строки. Все пробелы и кавычки (например,`"` Символы ) в начале и конце автоматически удаляются.<br> **Примечание** : Вы также можете использовать операторы сравнения.`<` ,`>` ,`>=` и`<=` перед цифрами, чтобы проверить их наличие. |
