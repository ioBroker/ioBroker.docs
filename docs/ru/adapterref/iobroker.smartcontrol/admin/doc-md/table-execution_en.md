Вы можете выбрать опцию **«Всегда выполнять»** , и тогда зона будет выполняться всегда, если будут выполнены какие-либо из ранее определенных условий.<br> Однако, если вы хотите задать больше условий, следует отключить эту опцию. После этого появится таблица со следующими параметрами:

| Столбец                                                                                                                                       | Обязательный | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------------------------------------------------------------------------------------------------------------------------------- | :----------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![изображение](https://github.com/iobroker-community-adapters/ioBroker.smartcontrol/blob/master/admin/doc-md/img/check_box-24px.svg?raw=true) |      Да      | Включает/отключает эту строку таблицы. Если не активирована, адаптер игнорирует эту строку таблицы. В параметрах адаптера, в разделе «ДОПОЛНИТЕЛЬНЫЕ ПАРАМЕТРЫ > Проверка входных данных», можно настроить проверку на корректность даже отключенных строк.                                                                                                                                                                                                                                                                                                                                                                  |
| Название зоны                                                                                                                                 |      Да      | Любое название зоны.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Начало/Конец                                                                                                                                  |      Да      | Как только срабатывает триггер, текущее время должно находиться в пределах указанного временного периода, чтобы целевые устройства были переключены.<br> Здесь вы можете ввести время в часах/минутах, например:`08:25` или`23:30` Вы также можете ввести астрологическое имя, например:`sunset` и добавить смещение в минутах, например`goldenHourEnd+30` или`sunset-60` .<br> Текущее астрономическое время можно найти в виде информационных состояний в этом адаптере:`smartcontrol.x.info.astroTimes` .<br> Например, время начала`sunset` и время окончания, например.`03:00` (то есть после полуночи) также возможно. |
| Пн-Вс                                                                                                                                         |      Да      | Если эти дни недели совпадают, целевые показатели меняются местами.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Дополнительные условия                                                                                                                        |      Нет     | Здесь вы можете ввести дополнительные условия, которые должны быть выполнены дополнительно, например: кто-то присутствует, сегодня праздник, бабушка спит и т. д.                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ![изображение](https://github.com/iobroker-community-adapters/ioBroker.smartcontrol/blob/master/admin/doc-md/img/done_all-24px.svg?raw=true)  |      Нет     | _Дополнительные условия_ : Если активировано, должны выполняться все условия («и»). Если отключено, достаточно, чтобы выполнялось хотя бы одно из условий.<br> Если вы выберете только одно условие, то не имеет значения, включите вы его или нет.                                                                                                                                                                                                                                                                                                                                                                          |
| Никогда не включайте, если...                                                                                                                 |      Нет     | Здесь вы можете ввести дополнительные условия, которые ни в коем случае не должны применяться, например: никого нет дома, радио включено и т. д.                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ![изображение](https://github.com/iobroker-community-adapters/ioBroker.smartcontrol/blob/master/admin/doc-md/img/done_all-24px.svg?raw=true)  |      Нет     | Для _параметра «Никогда не включайте, если...»_ : Если активировано, должны выполняться все условия («и»). Если отключено, достаточно, чтобы выполнялось хотя бы одно из условий.<br> Если вы выберете только одно условие, то не имеет значения, включите вы его или нет.                                                                                                                                                                                                                                                                                                                                                   |
