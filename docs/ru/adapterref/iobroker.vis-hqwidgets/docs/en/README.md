## Общий

### Требования и миграция

Виджеты находятся в наборе виджетов **hqWidgets** в списке виджетов редактора vis-2. Для описанных здесь версий React требуется **vis-2 2.12.8** или новее. Более старые версии vis-2 отображают виджеты vis-1.

Проекты, созданные с помощью vis-1, продолжают работать без изменений. Обе версии используют одни и те же идентификаторы виджетов. `tplHqButton`, `tplHqDimmer`, ...) и те же названия атрибутов, а vis-2 автоматически выбирает версию React. Все настройки сохраняются.

В таблицах ниже **«Setting»** — это метка в редакторе vis-2, а **«Attribute»** — это имя, хранящееся в проекте. Используйте имя атрибута при редактировании проекта в формате JSON или при копировании настроек между виджетами.

### Значения, введенные в редакторе

Некоторые параметры принимают значение, которое записывается в состояние, например, _значение «Вкл.»_ и _значение «Выкл.»_ виджета «Вкл./Выкл.» или _значение «Закрыть»_ замка. Редактор сохраняет их как текст, а виджет преобразует этот текст следующим образом:

| Введенный текст        | Письмо в адрес государства        |
| ---------------------- | --------------------------------- |
| `true` /`false`        | логический `true` /`false`         |
| `0`, `1`, `42.5`, ... | число                             |
| что-нибудь еще         | текст в том виде, в каком он есть |
| (пустой)               | значение по умолчанию             |

### Описания

Круглые виджеты, окно, дверь и замок могут отображать табличку с надписью слева от виджета. Круглые виджеты также могут отображать ее справа. Правая табличка круглых виджетов отображает значение, ваш собственный текст, положение клапана и время последнего изменения. Третий виджет на картинке [«Вкл/Выкл»](#onoff---tplhqbutton) отображает обе таблички.

### Показатели

![Показатели](../../../../../en/adapterref/iobroker.vis-hqwidgets/docs/img/button-indicators.png)

Небольшие маркеры над виджетом сообщают о проблемах. Слева направо на картинке:

- **Рабочий** (шестерёнка, верхний левый угол) - объект с _идентификатором «Рабочий»_ : `true` Без такого объекта шестеренка появляется, пока устройство еще не подтвердило состояние самого виджета. `ack = false` При переключении вы будете видеть это значение до тех пор, пока адаптер не подтвердит его.
- **Батарея** (вверху справа) - объект с _идентификатором «Батарея»_ — это `true`.
- **Сигнал** (внизу справа) — значение _идентификатора объекта «Сигнал»_ отображается в виде текста, например, уровень сигнала.
- **Нет значения** (красный крест) — состояние в _идентификаторе объекта_ пока не имеет значения.

Не каждый виджет предлагает все индикаторы. В таблицах виджетов указано, какие из них у них есть.

### Стили и эффекты изменений

Круглые виджеты и замок отображают свою поверхность с помощью одной из перечисленных ниже тем оформления. _Тема Normal_ используется, когда виджет выключен, _Active —_ когда он включен. Виджеты температуры не имеют темы оформления _Active_ .

![Скины](../../../../../en/adapterref/iobroker.vis-hqwidgets/docs/img/button-skins.png)

| Параметр                 | Атрибут          | Описание                                                                                                                                                                                                                                                              |
| ------------------------ | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Нормальный               | `styleNormal`    | Скин для выключенного состояния (см. рисунок).                                                                                                                                                                                                                        |
| Активный                 | `styleActive`    | Кожа для штата, в котором она находится.                                                                                                                                                                                                                              |
| Используйте стили jQuery | `usejQueryStyle` | Использует классы `ui-state-default` /`ui-state-active` Вместо скинов используется тема jQuery UI. Это имеет эффект только в том случае, если проект загружает такую тему.                                                                                             |
| Изменение эффекта        | `changeEffect`   | Анимация, которая запускается при изменении значения извне, например, при включении света на стене. На круглых виджетах клики внутри самого виджета её не запускают. Варианты: `waves`, `wobble`, `tada`, `swing`, `shake`, `rubberBand`, `pulse`, `flash`, `bounce`. |
| Волновой цвет            | `waveColor`      | Цвет колец `waves` эффект. По умолчанию: серый.                                                                                                                                                                                                                        |
| Тест                     | `testActive`     | Только для редактора: отображает виджет в обратном состоянии, позволяя проверить _активную_ тему оформления без переключения устройства.                                                                                                                              |

### Темная тема

В темной теме vis-2 все, что находится на экране, меняет цвет: индикаторы описания, след кольца, текст сигнала, а также всплывающие окна и кнопки блокировки. Сами виджеты сохраняют свои цвета в обеих темах, поскольку они представляют реальные объекты. Зажженная лампа ночью остается желтой.

![Темная тема](../../../../../en/adapterref/iobroker.vis-hqwidgets/docs/img/dark-theme.png)

## Вкл./Выкл. `tplHqButton`

![Вкл/Выкл](../../../../../en/adapterref/iobroker.vis-hqwidgets/docs/img/button.png)

Круглая кнопка для выключателя или лампы. Нажатие переключает значения между _«Выкл.»_ и _«Вкл.»_ . На картинке слева направо показаны: выключено, включено, включено с описанием и временем последнего изменения, а также прямоугольный виджет с подписью. Форма виджета определяется стилем виджета. По умолчанию используется стиль по умолчанию. `border-radius: 64px` Это делает его круглым; удалите его или уменьшите размер, чтобы получить прямоугольник.

**Как это работает**

- Виджет _включен_ , пока значение состояния равно _«Включено»_ , и _выключен_ в противном случае. Сравнение нестрогое, поэтому числовое значение `1` матчи `true`.
- **Кнопка** : нажатие записывает _значение «Вкл.»_ , отпускание записывает _значение «Выкл._ ». Это также работает, если указатель отпускается вне кнопки. Используйте это для дверных открывателей и звонков.
- **Только для чтения** : отображает состояние, но игнорирует клики.
- Виджет не реагирует на щелчки мыши в редакторе.

| --------------------------------- | ------------- | ------------ | ------------------------------------------------------------------------------------------- |
| Идентификатор объекта             | `oid`         |              | Состояние, в котором следует переключиться.                                                 |
| Идентификатор рабочего объекта    | `oid-working` |              | См. [Индикаторы](#indicators) .                                                             |
| Идентификатор объекта батареи     | `oid-battery` |              | См. [Индикаторы](#indicators) .                                                             |
| Идентификатор сигнального объекта | `oid-signal`  |              | См. [Индикаторы](#indicators) .                                                             |
| Только для чтения                 | `readOnly`    | выключенный  | Только для демонстрации.                                                                    |
| Сниженная стоимость               | `min`         | `false`      | Записывается при выключении.                                                                |
| По выгодной цене                  | `max`         | `true`       | Записывается при включении.                                                                 |
| Кнопка                            | `pushButton`  | выключенный  | При нажатии кнопки записывается _значение "Вкл_ .", а при отпускании _— значение "Выкл."_ . |

_Центр_ групп (значок по умолчанию) `img/bulb_off.png`), _Описания_ и _стили_ (по умолчанию) `vis-hq-button-base-normal` /`vis-hq-button-base-on`): см. [Общие положения](#general) .

**Группа «Дополнительное управление»** — больше действий на каждом переключателе:

| Параметр                                                                                 | Атрибут                         | Описание                                                                                                                                                                       |
| ---------------------------------------------------------------------------------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| URL для включения / URL для выключения                                                   | `urlTrue` /`urlFalse`           | Вызывается при включении/выключении. Без _URL-адреса для выключения_ , _URL-адрес для включения_ вызывается оба раза.                                                          |
| Идентификатор объекта для состояния «ВКЛ.» / Идентификатор объекта для состояния «ВЫКЛ.» | `oidTrue` /`oidFalse`           | Ещё одно состояние, которое записывается при включении/выключении. Без _идентификатора объекта для выключения_ , _идентификатор объекта для включения_ принимает оба значения. |
| Значение для ВКЛ / Значение для ВЫКЛ                                                     | `oidTrueValue` /`oidFalseValue` | Значения для этих состояний. Пусто: _значение «Включено»_ / _значение «Выключено»_ .                                                                                           |

## Диммер - `tplHqDimmer`

![Диммер](../../../../../en/adapterref/iobroker.vis-hqwidgets/docs/img/dimmer.png)

Круглая кнопка с кольцом, отображающим значение от _минимального_ до _максимального_ , обычно это яркость лампы. Кольцо появляется при наведении курсора на виджет или постоянно при выборе _параметра «Всегда показывать круг»_ . На изображении показаны значения 0%, 42% и 42% с видимым кольцом.

**Как это работает**

- **Перетащите ползунок** вдоль кольца, чтобы установить значение. Оно отобразится после того, как вы отпустите ползунок.
- Для переключения кратковременно **коснитесь** кольца (менее 300 мс, не двигаясь). При значении выше 5 % от диапазона переключение происходит на _минимальное значение_ , в противном случае — на _максимальное_ . При использовании _функции «Установить значение щелчком»_ касание отключается, когда значение превышает _минимальное_ , в противном случае значение устанавливается автоматически.
- В правой части экрана отображается значение с указанием единицы измерения. Виджет использует _активную_ тему оформления до тех пор, пока значение превышает _минимальное значение_ .

## Окна и ставни - `tplHqShutter`

![Окно и ставни](../../../../../en/adapterref/iobroker.vis-hqwidgets/docs/img/shutter.png)

Окно с шестью створками и рольставнями. На каждой створке указано, закрыта она, наклонена или открыта, а на рольставнях — её положение. На изображении показана одна закрытая створка, две створки (наклоненная и открытая) с указанием положения в правой части изображения и три створки с описанием положения слева.

Щелчок по окну открывает всплывающее окно управления:

![Неожиданно возникнуть](../../../../../en/adapterref/iobroker.vis-hqwidgets/docs/img/shutter-popup.png)

- **Стрелка вверх** открывает затвор, **стрелка вниз —** закрывает его.
- **Перетащите ползунок** , чтобы установить положение. Оно отобразится, когда вы отпустите ползунок.
- Всплывающее окно закрывается после нажатия кнопки, по _истечении времени ожидания для скрытия_ без взаимодействия или при щелчке в другом месте представления. В редакторе всплывающего окна нет.

**Положение и направление.** Без _функции «Инвертировать_ » _«Минимальное»_ означает полностью открытое положение, а _«Максимальное»_ — полностью закрытое (затвор опущен). Многие устройства и роль ioBroker. `level.blind` Посчитайте в обратном порядке (100 % = открыто). Для этого включите **функцию «Инвертировать»** .

## Одометр `tplHqOdometer`

![Одометр](../../../../../en/adapterref/iobroker.vis-hqwidgets/docs/img/odometer.png)

Механический счётчик, например, для счётчиков электроэнергии, газа или воды. При изменении значения цифры автоматически обновляются. Размер цифр соответствует размеру шрифта виджета (по умолчанию 24 пикселя). Только для отображения.

| Параметр                   | Атрибут        | По умолчанию | Описание                                                                                                                                                                                                                                                                                  |
| -------------------------- | -------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Идентификатор объекта      | `oid`          |              | Числовое состояние.                                                                                                                                                                                                                                                                       |
| Тема                       | `style`        | машина       | Посмотрите на прилавок: `car`, `default`, `digital`, `minimal`, `plaza`, `slot-machine`, `train-station` (см. рисунок).                                                                                                                                                                    |
| Формат                     | `format`       | `(ddd),dd`   | `d` обозначает цифру. Часть в скобках повторяется над целым числом вместе с разделителем. Далее следует десятичный разделитель и один знак после запятой. `d` с точностью до десятичной дроби. Примеры для 12345,67: `(.ddd),dd` →`12.345,67`, `(,ddd).dd` →`12,345.67`, `(ddd)` →`12346`. |
| Фактор                     | `factor`       | 1            | Полученное значение умножается на него, например, 0,001, чтобы отобразить Вт·ч в кВт·ч.                                                                                                                                                                                                   |
| Начальные нули             | `leadingZeros` | на           | Дополняет целочисленную часть нулями до ширины группы, например: `005`.                                                                                                                                                                                                                   |
| Длительность анимации (мс) | `duration`     | 3000         | Как долго будут длиться цифры, которые будут выпадать.                                                                                                                                                                                                                                    |

## Отличия от vis-1

Виджеты vis-2 не используют jQuery, используют jQuery UI. `jquery.knob` или `odometer.js` Проекты переносятся без изменений. Некоторые детали работают по-другому:

- **Флажок:** размер `small` Теперь этот параметр больше не изменяет размер виджета. Вместо этого переключатель центрируется внутри виджета.
- **Диалоговое окно диаграммы:** эффект отображения jQuery UI (`dialog_effect`) исчезло, и в диалоговом окне отсутствует заголовок.
- **Температурное кольцо:** цвет меняется от синего к красному. В образце vis-1 он прошел через фиолетовый центр.
- **Вкл/Выкл:** Теперь используются _значения ON_ и _OFF_ дополнительного элемента управления. vis-1 их игнорировал.
- **Новые настройки:** _Только для чтения_ для диммера, внутренней температуры и ручки. Цвет сигнала и дверного проема для двери. Индикаторы для ручки. Длительность анимации одометра. Цвет рамы и дверного полотна для окна и двери.
- **Всплывающие окна:** всплывающие окна окна и замка закрываются щелчком мыши в любом другом месте на экране.
