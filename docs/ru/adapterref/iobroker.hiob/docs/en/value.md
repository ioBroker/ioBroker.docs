## Ценить

### С помощью параметра Value вы можете, например, установить время.

- Проведите пальцем влево, чтобы удалить виджет.
- Нажмите на знак плюса в правом нижнем углу.

![веб-просмотр](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_button_done.png)

- Выпадающий список: выберите`Value` .
- Название: Название виджета
- Значение (необязательно): Отображаемый текст в виджете. Если ничего не указано, используется имя.
- Округлить до: Количество знаков после запятой для округления в большую сторону.
- Единица измерения (необязательно): Единица измерения стоимости.

![веб-просмотр](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_value.png)

- Устройство: Выберите нужный товар в списке.

![веб-просмотр](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_button_device.png)

- Точка данных: Выбор штатов из выбранного списка

![веб-просмотр](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_button_dp.png)

- Затем нажмите «Сохранить».
- Длительное нажатие на виджет переключает его в режим копирования. Здесь вы можете выбрать виджеты, с которых следует создать копию.

![веб-просмотр](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_value_done.png)

- Добавьте виджет на экран и используйте его для управления состоянием. Нажмите и удерживайте виджет, чтобы открылось всплывающее окно, в котором можно изменить значение.

![веб-просмотр](img/../../de/img/app_create_value_done.png)![веб-просмотр](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_value_done.png)
