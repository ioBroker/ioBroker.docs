## Веб-просмотр

### С помощью функции Web View можно отобразить веб-сайт.

- Проведите пальцем влево, чтобы удалить виджет.
- Нажмите на знак плюса в правом нижнем углу.

![веб-просмотр](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_division_done.png)

- Выпадающий список: выберите`Web View` .
- Название: Название виджета
- URL (необязательно): URL-адрес, например:`http://192.168.x.x:8082/iqontrol/index.html?namespace=iqontrol.0`
- Устройство: Выберите нужный товар в списке.
- Точка данных: Выбор состояния, в котором хранится веб-адрес. Изменение состояния приводит к обновлению или использованию адреса из этого состояния.
- Высота: Высота виджета. Если размер слишком мал, веб-сайт может быть обрезан.
- JavaScript включен: позволяет запускать скрипты JavaScript.

![веб-просмотр](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_web.png)

- Затем нажмите «Сохранить».
- Длительное нажатие на виджет переключает его в режим копирования. Здесь вы можете выбрать виджеты, с которых следует создать копию.

![веб-просмотр](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_web_done.png)

- Добавьте виджет на экран.

![веб-просмотр](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_web_screen.png)
