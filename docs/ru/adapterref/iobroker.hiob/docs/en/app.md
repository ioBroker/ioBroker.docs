## Установка и настройка приложения`ioBroker Settings`

# Шаг 1: Установка и настройка приложения

# Шаг 1: Настройки экземпляра

1. Пожалуйста, укажите свободный порт (по умолчанию 8090). Если выбранный порт занят, будет использован следующий свободный порт. Эта информация будет записана в журнал, который затем следует скопировать в конфигурацию.
2. Для графического виджета вам потребуется адаптер SQL или History для записи изменений состояний. Пожалуйста, выберите экземпляр SQL или History.
3. Теперь включите адаптер.

![instance.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/instance.png)

# Шаг 2: Создание пользователя (НЕОБЯЗАТЕЛЬНО)

## Для входа по паролю необходимо создать нового пользователя.

1. Выберите пользователей слева и добавьте пользователей справа.

![create\_user.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/create_user.png)

2. Введите здесь имя пользователя и пароль. Затем нажмите «Сохранить».

![create\_user\_with\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/create_user_with_pw.png)

# Шаг 3 с паролем: Вход с помощью пароля (локальный вход)

1. Введите здесь IP-адрес вашего ioBroker, порт, имя пользователя и пароль, а затем нажмите кнопку «Переподключиться».

![app\_login\_first.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_login_first.png)

2. Затем в разделе «Объекты» установите состояние.`approved` с правильного устройства, до истинного (без галочки «Подтверждено»)

![request\_approved\_wo\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/request_approved_wo_pw.png)

3. Пароль или имя пользователя не будут изменены с помощью Datenpunkt, если он будет ложным и в приложении будет отображаться текст`Login declined` ангезигт. Немного дайте имя пользователя и пароль, а затем введите данные.

4. Если все данные введены правильно, появится зеленый текст «Вход выполнен».

![app\_login\_with\_pw.png](../de/img/app_login_with_pw.png)![approved\_with\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/approved_with_pw.png)

5. (Необязательно) Теперь можно настроить переадресацию, чтобы можно было переключаться и за пределы сети. Предварительно приложение должно получить права доступа к «Местоположению». Затем введите сеть Wi-Fi и URL-адрес. Теперь настройте переадресацию в Fritzbox. Но это не рекомендуется! Лучше использовать VPN. Например, приложение «VpnCilla» (платное).

![app\_access.png](../de/img/app_access.png)![app\_second\_ip.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_second_ip.png)

# Шаг 3 без пароля: Вход с паролем (локальный вход)

1. Снимите флажок «Использовать пароль для входа», введите свой IP-адрес и порт из ioBroker и нажмите кнопку «Переподключиться».

![app\_login\_first\_wo\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_login_first_wo_pw.png)

2. Установить состояние`noPwdAllowed` установить значение true (без галочки «Подтверждено»), а затем установить`approved` установить значение true (без галочки «Подтверждено»).

![request\_approved\_wo\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/request_approved_wo_pw.png)

3. Если всё было реализовано правильно, то должно выглядеть вот так.

![app\_login\_wo\_pw\_suc.png](../de/img/app_login_wo_pw_suc.png)![approved\_wo\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/approved_wo_pw.png)

# Важная информация

- Если вы хотите заблокировать пользователя, просто установите для параметра «одобрено» значение false.
- При подключении в левом верхнем углу экрана появляется зеленая галочка.
- Если там мигает красный символ WLAN, значит, установить соединение невозможно. Либо вы находитесь не в одной сети, либо состояние «одобрено» неверно.
