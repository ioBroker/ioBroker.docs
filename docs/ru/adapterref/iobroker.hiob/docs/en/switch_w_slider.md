## Переключатель с ползунком

### С помощью Switch with Slider можно создать выключатель с диммером (опционально).

- Проведите пальцем влево, чтобы удалить виджет.
- Нажмите на знак плюса в правом нижнем углу.

![Переключатель с ползунком](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_value_done.png)

- Выпадающий список: выберите`Switch with Slider` .
- Название: Название виджета
- Значение (необязательно): Отображаемый текст в виджете. Если поле остается пустым, используется имя.
- Округлить до: знаков после запятой
- Единица измерения (необязательно): Единица стоимости
- Устройство: Выберите здесь нужный товар.
- Точка данных: Выбор штатов из выбранного списка - значение state должно быть логическим true/false!

![Переключатель с ползунком](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_widget_switch.png)

- Если требуется регулировка яркости, необходимо поставить галочку рядом с пунктом «Ползунок».
- Отображение ползунков: Названия ползунков.
- Мин: Минимальное значение (по умолчанию 0).
- Max: максимальное значение (по умолчанию 100).
- Этапы: На каких этапах можно вносить изменения (стандарт 10).
- Устройство: Выберите нужный товар в списке.
- Точка данных: Выбор штатов из выбранного списка - штат должен быть номером!

![Переключатель с ползунком](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_widget_slider.png)

- С помощью Reachable можно создать всплывающее окно для просмотра значения из состояния.
- Доступный дисплей: Название доступного элемента.
- Устройство: Выберите нужный товар в списке.
- Точка данных: Выбор штатов из выбранного списка - state должен быть логическим значением true/false!

![Переключатель с ползунком](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_widget_reach.png)

- Затем нажмите «Сохранить».
- Длительное нажатие на виджет переключает его в режим копирования. Здесь вы можете выбрать виджеты, с которых следует создать копию.

![Переключатель с ползунком](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_switch_done.png)

- Добавляет виджет на экран и использует его для управления состоянием. Длительное нажатие на виджет открывает всплывающее окно. Во всплывающем окне можно просмотреть текущий статус переключения или установить уровень.
