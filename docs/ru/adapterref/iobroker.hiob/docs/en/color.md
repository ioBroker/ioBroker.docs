## Цветовая палитра

### С помощью цветовой палитры шестнадцатеричный код можно передать в состояние.

- Проведите пальцем влево, чтобы удалить виджет.
- Нажмите на знак плюса в правом нижнем углу.

![app\_create\_graph\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_graph_done.png)

## Цветовой виджет

- Выпадающий список: Выберите`Color Palette`
- Название: Название виджета
- Значение (необязательно): Отображаемый текст в виджете. Если ничего не указано, используется имя.
- Устройство: Выберите перечисления
- Точка данных: Выбор штатов из перечислений — значение должно быть строкой.
- Шестнадцатеричный префикс (необязательно): например, 0x, # или пустое значение.
- Укажите значение альфа-канала: Alpha-Value - [ARGB](#argb)
- Выбор оттенков: Включить [оттенки](#shades)
- Основные и акцентные цвета: основные и акцентные цвета и их оттенки. [Цветовая палитра.](#primary--accent)
- Основные цвета: основные цвета и их оттенки. [Цветовая палитра.](#primary)
- Акцент: Акцентные цвета и их оттенки. [Цветовая палитра.](#accent)
- Черно-белый: [Цветовая палитра](#black--white) черно-белого изображения
- Цветовое колесо: [палитра](#wheel) цветов HSV

![add\_create\_color.png](../de/img/add_create_color.png)![add\_create\_color\_1.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_color_1.png)

- Затем нажмите «Сохранить».
- Длительное нажатие на виджет переключает его в режим копирования. Здесь вы можете выбрать виджеты, с которых следует создать копию.

![app\_create\_color\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_color_done.png)

- Создать экран

![app\_create\_color\_screen.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_color_screen.png)

- Добавить виджет на экран

![app\_create\_color\_add.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_color_screen_add.png)

- Готово! Нажмите на виджет, чтобы открыть цветовую палитру.

![app\_create\_color\_screen\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_color_screen_done.png)

- `R` Гниль
- `G` Грюн
- `B` Блау
- `ARGB` == FFFFFFFF
