## Сетевой медиаплеер

### Сетевой медиаплеер можно использовать для просмотра видеопотока с камеры.

- Проведите пальцем влево, чтобы удалить виджет.
- Нажмите на знак плюса в правом нижнем углу.

![app\_create\_color\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_color_done.png)

- Выпадающий список: Выберите`Network Media Player`
- Название: Название виджета
- URL медиафайла: URL из видеопотока с камеры, например, rtsp\://192.168.2.20:554/path
- Соотношение сторон: Соотношение сторон в режиме просмотра на экране.

![app\_create\_player\_widget.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_player_widget.png)

- Затем нажмите «Сохранить».
- Длительное нажатие на виджет переключает его в режим копирования. Здесь вы можете выбрать виджеты, с которых следует создать копию.

![app\_create\_player\_widget\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_player_widget_done.png)

- Создать экран

![app\_create\_player\_screen.png](../de/img/app_create_player_screen.png)![app\_create\_player\_screen\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_player_screen_done.png)

- Нажмите + и добавьте виджет.

![app\_create\_player\_screen\_add\_1.png](../de/img/app_create_player_screen_add_1.png)![app\_create\_player\_screen\_add.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_player_screen_add.png)

- Сделанный!

![app\_create\_player\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_player_done.png)
