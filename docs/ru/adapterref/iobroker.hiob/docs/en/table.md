## Стол

### С помощью таблицы можно отображать JSON.

- Проведите пальцем влево, чтобы удалить виджет.
- Нажмите на знак плюса в правом нижнем углу.

![app\_create\_web\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_web_done.png)

- Выпадающий список: выберите`Table` .
- Название: Название виджета
- Заголовок: Текст заголовка из таблицы
- Количество элементов на странице: число элементов, отображаемых на странице.
- Начальная сортировка: сортирует массив (первый элемент).
- Устройство: Выберите нужный товар в списке.
- Точка данных: Выбор штатов из выбранной коллекции — значение должно представлять собой массив с элементами JSON.

![add\_create\_table.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_table.png)

- Пример JSON

```json
[
  {
    "name": "Fenster Gäste WC",
    "zustand": "👈 geöffnet"
  },
  {
    "name": "Fenster Schlafzimmer",
    "zustand": "👈 geöffnet"
  },
  {
    "name": "Fenster Arbeitszimmer",
    "zustand": "☝️ gekippt"
  }
  {
    "name": "Dachfenster",
    "zustand": "🪟 geschlossen"
  }
]
```

- Добавить: Теперь создайте нужные столбцы. В примере это выглядит так:`name` и`state` Ключ из JSON-файла необходимо ввести в`column key` Вы можете присвоить имя в`column name` .

![add\_create\_table\_column\_1.png](img/../../de/img/add_create_table_column_1.png)![add\_create\_table\_column\_2.png](img/../../de/img/add_create_table_column_2.png)![add\_create\_table.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_table_column.png)

- Затем нажмите «Сохранить».
- Длительное нажатие на виджет переключает его в режим копирования. Здесь вы можете выбрать виджеты, с которых следует создать копию.

![app\_create\_table\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_table_done.png)

- Добавьте виджет на экран.

![app\_create\_table\_screen.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_table_screen.png)
