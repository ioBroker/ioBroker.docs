## Создать резервную копию`Config Sync`

- Здесь вы можете сохранить свои настройки (виджеты, экран и устройство) в ioBroker.
- Эти резервные копии можно удалить только в ioBroker. Полностью удалите нужное дерево объектов в разделе «Настройки».
- Нажмите на знак плюса в правом нижнем углу.

![app\_config\_sync.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_config_sync.png)

- Введите название папки для резервного копирования, которую необходимо создать.

![app\_config\_sync\_create.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_config_sync_create.png)

- Затем нажмите «Сохранить».

![app\_config\_sync\_create\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_config_sync_create_done.png)

- Теперь нажмите кнопку «Загрузить настройки», чтобы создать резервную копию. Теперь вы можете, например, загрузить эти настройки с помощью кнопки «Загрузить». Конечно, можно создать несколько резервных копий.

![config\_sync\_iobroker.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/config_sync_iobroker.png)
