## Расширенный/Гибкий

- Проведите пальцем влево, чтобы удалить виджет.
- Нажмите на знак плюса в правом нижнем углу.

![app\_template.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_template.png)

- `Name` : Название виджета
- `Value` (необязательно): Отобразить текст в виджете. Если ничего не указано, используется имя.

![app\_create\_advanced\_value.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_advanced_value.png)

- Основная часть: Выберите здесь нужный виджет.

- `Value` Это позволяет отобразить значение и установить новое значение для заданного значения.

- `Multi Selection` Здесь вы можете создать выпадающий список.

- `Slider` С помощью ползунка можно регулировать яркость освещения или управлять рольставнями.

- `Handle` Переключатель, в котором можно указать значение.

- `Button` В настоящее время для установки значения TRUE доступна только одна кнопка.

![app\_create\_advanced\_select.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_advanced_select.png)

### Виджет`Value`

- `Round to` Округлите до 30% после запятой.
- `Unit (optional)` : Единица измерения стоимости
- `Device` Выберите здесь нужный перечисление.
- `Datapoint` Выбор состояний из выбранного перечисления.
- `Text Rules` Чтобы создать правило, нажмите на`add` Введите значение в`Old Value` когда состояние следует перезаписать`New Value` Затем нажмите`add` и если новые не нужны, нажмите`exit` Когда значение достигает 10, состояние устанавливается на 20. Редактирование в дальнейшем невозможно. Правило можно удалить только с помощью свайпа.

![app\_create\_advanced\_value\_view.png](img/../../de/img/app_create_advanced_value_view.png)![app\_create\_advanced\_value\_popup.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_advanced_value_popup.png)

- `Popup Menu` Здесь можно создавать дополнительные виджеты. Длительное нажатие на виджет открывает всплывающее меню со списком созданных вами виджетов.
- Затем нажмите «Сохранить».
- Длительное нажатие на виджет переключает его в режим копирования. Здесь вы можете выбрать виджеты, с которых следует создать копию.

![app\_create\_advanced\_value\_popup\_create\_1.png](img/../../de/img/app_create_advanced_value_popup_create_1.png)![app\_create\_advanced\_value\_popup\_create\_2.png](img/../../de/img/app_create_advanced_value_popup_create_2.png)![app\_create\_advanced\_value\_popup\_view\_done\_1.png](img/../../de/img/app_create_advanced_value_popup_view_done_1.png)![app\_create\_advanced\_value\_popup\_view\_done\_2.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_advanced_value_popup_view_done_2.png)

### Виджет `Multi Selection`

![app\_create\_multi.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_multi.png)

- `Device` Выберите здесь нужный перечисление.
- `Datapoint` Выбор состояний из выбранного перечисления.

![app\_create\_multi\_device.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_multi_device.png)

Редактирование позже невозможно. Правило можно удалить только с помощью свайпа.

### Виджет`Slider`

- `Device` Выберите здесь нужный перечисление.
- `Datapoint` Выбор штатов из перечисления - штат должен иметь номер от 0 до x!

![app\_create\_advanced\_slider.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_advanced_slider.png)

- `Min` : Минимальное значение (по умолчанию 0).
- `Max` : Максимальное значение (по умолчанию 100).
- `Steps` На каком этапе могут быть внесены изменения (стандарт 10).
- `Popup Menu` Здесь можно создавать дополнительные виджеты. Длительное нажатие на виджет открывает всплывающее меню со списком созданных вами виджетов.
