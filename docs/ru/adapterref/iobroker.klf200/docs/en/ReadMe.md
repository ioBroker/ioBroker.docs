# документация на адаптер KLF-200

Этот адаптер предназначен для управления интерфейсом VELUX® KLF-200. Данный адаптер не является официальным продуктом VELUX и не поддерживается компанией-владельцем продукции VELUX.

Основное назначение этого адаптера — управление электрическими мансардными окнами и/или электрическими жалюзи или рольставнями. Хотя интерфейс KLF-200 позволяет подключаться и к другим устройствам, таким как светильники, выключатели, тканевые жалюзи и т. д., я не тестировал адаптер на работу с подобными устройствами. Тем не менее, должно быть возможно, что этими устройствами также можно будет управлять с помощью этого адаптера.

Адаптер работает с официальным интерфейсом TCP/IP устройства KLF-200, описанным в версии прошивки 2.0.0.71. Нет необходимости подключать входы и выходы устройства проводным способом, но KLF-200 нужно подключить к локальной сети с помощью кабеля Ethernet.

---

## Подготовьте интерфейс KLF-200.

Для использования этого адаптера необходимо настроить вашу приставку KLF-200 в **режиме интерфейса** . Он не будет работать, если вы используете приставку в качестве ретранслятора.

Адаптер будет работать только через порт LAN вашего KLF-200.

> Подробное описание того, как выполнить следующие задачи, см. в инструкциях, прилагаемых к вашему устройству.
>
> Предполагается, что вы успешно вошли в свою учетную запись в веб-браузере.

### Настройка продуктов

Каждый продукт, которым вы хотите управлять с помощью этого адаптера, необходимо зарегистрировать на странице «Мои продукты». Вы можете зарегистрировать новые продукты следующим образом:

- Копирование с другого пульта дистанционного управления
- Поиск товаров

Если все ваши товары зарегистрированы, вы должны увидеть список, похожий на следующий:

![Скриншот раздела «Мои продукты» интерфейса KLF-200](../../../../../en/adapterref/iobroker.klf200/docs/en/img/ProductList.PNG)

### Настройка сцен

> **Критические изменения:**
>
> **С новой прошивкой вам больше не нужно задавать сцену для каждого желаемого состояния продукта.**

Этот шаг необязателен. Вы можете записывать сценарии для смены различных продуктов за один шаг, например, вы можете определить сценарий для закрытия всех окон.

Для записи сцены необходимо нажать на кнопку.

![Кнопка записи программы](../../../../../en/adapterref/iobroker.klf200/docs/en/img/RecordProgramButton.PNG)

Откроется окно _«Запись идёт»_ . Теперь используйте пульт дистанционного управления, входящий в комплект вашего устройства, чтобы что-нибудь изменить, например, увеличить масштаб окна до 40%. Затем введите название программы и нажмите _«Сохранить программу»_ .

![Скриншот процесса записи](../../../../../en/adapterref/iobroker.klf200/docs/en/img/RecordingInProgress.PNG)

> НАМЕКАТЬ:
>
> - Присвойте своей программе осмысленное имя, хотя адаптер не использует никаких соглашений об именовании.

Если вы завершили запись программ, у вас получится список, подобный следующему:

![Скриншот списка программ](../../../../../en/adapterref/iobroker.klf200/docs/en/img/ProgramList.PNG)

### Настройка подключений

Этот последний шаг необязателен. Если вы не используете входные и выходные провода, вы могли заметить, что крошечный светодиод на корпусе постоянно мигает. Чтобы избавиться от надоедливого мигания, необходимо установить хотя бы одно соединение.

Вам нужно только установить его в коробке, никаких проводов подключать не нужно! Просто выберите то, что вам нравится.

## Настройте адаптер

![Скриншот конфигурации адаптера](../../../../../en/adapterref/iobroker.klf200/docs/en/img/AdapterConfiguration.PNG)

### Хозяин

Имя хоста вашего интерфейса KLF-200. Это то же самое имя, которое вы вводите в адресную строку веб-браузера для подключения к вашему устройству.

### Пароль

Пароль, необходимый для подключения к интерфейсу KLF-200. Для новых версий KLF-200 это пароль Wi-Fi, указанный на задней панели устройства. Если вы использовали KLF-200 с версией прошивки ниже 2.0.0.71 и обновили прошивку позже, это будет пароль, который вы использовали для входа в веб-интерфейс, если вы меняли его до обновления.

> Пароль по умолчанию для KLF-200 указан на задней панели устройства, но вам все равно следовало бы его изменить!

Если вы забыли свой пароль, вы можете выполнить сброс настроек KLF-200 до заводских:

- Пароль будет использоваться для сброса пароля Wi-Fi.
- **Все ваши устройства, сценарии, группы и другие настройки будут удалены с KLF-200, и их необходимо будет подключить заново. Если у вас нет другого пульта дистанционного управления, с которого можно скопировать ваши устройства, вам также потребуется сбросить настройки ваших устройств.**

> **ВАЖНЫЙ:**
>
> В каналах используются идентификаторы, поступающие из интерфейса KLF-200. При внесении изменений в список продуктов или список программ в вашем KLF-200 идентификаторы могут измениться.

Для запуска сцены можно установить либо параметр`run` состояние места происшествия`true` или вы можете установить`level` состояние продукта, соответствующее значению, которое устанавливается в сцене, где продукт находится на этом уровне.

### Примеры

Предположим, что ваше окно в ванной комнате имеет направляющую.`0` У вас есть сцена на канале.`10` Это закрывает все окна.

```javascript
// Example 1: Open the bathroom window at 40%:
await setStateAsync("klf200.0.products.0.targetPosition", 40);
/* 
    The following will happen:
    1. Several states will be changed to reflect the current operation, e.g. the remainingTime.
    2. Your window will start to move to 40% opening level. (If it's not blocked, e.g. by the rain sensor.)
    3. After your window has stopped (for whatever reason), several states will be changed again, including the currentPosition.
*/

// Example 2: Close all windows by running scene 10:
await setStateAsync("klf200.0.scenes.10.run", true);
/*
    The following will happen:
    1. All related products will receive updates to their states to reflect the current operation.
    2. All windows will start to move to 0% openening level.
    3. After the scene has finished, the run state is set to false, again.
*/
```

## Известные ограничения

- Если вы задаете новые сценарии в устройстве, вам потребуется перезагрузить адаптер, чтобы он их считал.
- Часовой пояс — центральноевропейское время (GMT+1/GMT+2 для перехода на летнее время).
