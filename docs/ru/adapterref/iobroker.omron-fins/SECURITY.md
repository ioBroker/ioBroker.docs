# Статус безопасности зависимостей

Проверено 03.11.2026 с использованием GitHub Dependabot и npm audit.

## Очистка

Все 23 оповещения Dependabot, открытые в начале этого технического обслуживания, обработаны обновленным файлом блокировки. В пакеты входят axios, follow-redirects, node-forge, moment, adm-zip, js-yaml, brace-expansion и @grpc/grpc-js. Для переопределения adm-zip теперь требуется как минимум версия 0.6.1. Дополнительные обновления касаются zod, diff и serialize-javascript. Ни одно оповещение не было отклонено, а результаты аудита не скрыты.

`npm audit --omit=dev` Сообщается **об отсутствии уязвимостей** в дереве зависимостей адаптера, используемом в производственной среде. При этом не проверяется отдельная установка ioBroker на хосте.

## Оставшиеся рекомендации по инструментам разработки

Полное дерево разработки по-прежнему содержит два основных замечания (24 умеренных замечания, включая зависимые пакеты):

- [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249) : расширение globparts в minimatch. В уведомлении отмечены версии ниже 11.0.1 как затронутые. Существующие пакеты lint и test зависят от нескольких более старых поколений API. Глобальное переопределение заменит вызываемый API minimatch 3 несовместимым экспортом/API, поэтому оно не применяется.
- [GHSA-3g3m-2fjr-6pw4](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4) : обход механизма отмены сигнала прерывания glob. Существующие инструменты требуют glob 10; опубликованное исправление содержится в glob 14. Эти инструменты и ограничения их зависимостей от вышестоящих версий нуждаются в скоординированном обновлении.

Эти пакеты являются зависимостями для разработки, а не зависимостями для производственного адаптера. Не используйте инструменты разработки с ненадежными репозиториями или шаблонами glob, предоставленными злоумышленниками. Держите Dependabot включенным и обновляйте инструменты, как только появятся совместимые исправления. Принудительное исправление в ходе аудита или удаление пакета не обеспечит совместимость и не устранит проблемы с базовыми пакетами.

## Валидация

- Node.js 22 и 24: Пройдены проверки TypeScript и все 60 функциональных/пакетных тестов.
- Node.js 24: Пройдены тесты ESLint и изолированная интеграционная/стартовая проверка ioBroker.
- Файл блокировки был сравнен с диапазонами, затронутыми всеми 23 исходными оповещениями; совпадений не обнаружено.
- Никаких изменений в действующих установках ioBroker или конфигурациях ПЛК не производилось.

Данное техническое обслуживание обновляет исходный код на GitHub; оно не включает публикацию нового релиза npm.
