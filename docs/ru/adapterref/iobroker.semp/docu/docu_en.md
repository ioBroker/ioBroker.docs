# Документация для iobroker.semp

## Настройки

### Основной

![Основной](../../../../en/adapterref/iobroker.semp/docu/settings/Settings_Main_de.PNG)

- IP-адрес: IP-адрес устройства, на котором запущен ioBroker.semp.

- UUID — уникальный идентификатор для идентификации шлюза SEMP.

- SEMP-Port — порт, через который адаптер доступен для Homemanager. По умолчанию: 9765

- SEMP-name — это просто имя для шлюза SEMP. Это имя будет отображаться в SunnyPortal.

- SEMP-Vendor — это просто название.

- Расширенное логирование, если включено, будет записывать каждое сообщение Telegram в Homemanager в лог ioBroker. **Внимание:** это значительно увеличит размер лога.

### Устройства

![Устройства](../../../../en/adapterref/iobroker.semp/docu/settings/Settings_Devices_de.PNG)

- Базовый идентификатор устройств. Должен состоять из 8 символов и содержать только цифры.

Изменять идентификаторы и имена устройств можно только здесь, в списке. В сведениях об устройстве эти два значения доступны только для чтения.

### Главное устройство

![Устройства](../../../../en/adapterref/iobroker.semp/docu/settings/Settings_Device_Main_de.PNG)

**Внимание!** Необходимо установить максимальную мощность. Значение 0 не допускается.

#### Счетчик устройств

![Устройства](../../../../en/adapterref/iobroker.semp/docu/settings/Settings_Device_Counter_de.PNG)

Если выбран параметр «Измерение», необходимо использовать идентификатор объекта для текущей мощности устройства. Единица измерения может быть Ватт \[Вт] или Киловатт \[кВт]. Если выбран параметр «Оценка», используется максимальная мощность из общих настроек.

#### Переключатель устройств

![Устройства](../../../../en/adapterref/iobroker.semp/docu/settings/Settings_Device_Switch_de.PNG)

Здесь мы определяем две функции:

- Состояние устройства (включено или выключено)
- Включать или выключать устройство в соответствии с рекомендациями по энергопотреблению от Homemanager.

Состояние устройства можно определить на основе следующих параметров:

- Идентификатор объекта: тогда нам нужен объект в ioBroker с текущим статусом.
- Текущая мощность: затем мы используем идентификатор объекта со страницы счетчика устройства. Можно задать пороговые значения, чтобы избежать скачков напряжения.
- всегда включено

#### Запросы на энергопотребление устройства

![Устройства](../../../../en/adapterref/iobroker.semp/docu/settings/Settings_Device_Timer_de.PNG)

Активация таймера: активирует запросы на энергоснабжение от SunnyHomeManager.

Отменить запрос на включение, если устройство не включается: опция. Если вы хотите отменить запрос на потребление энергии, когда вашему устройству не требуется энергия в течение определенного периода времени. Обычно SunnyHomeManager рекомендует включить устройство. Если устройство не включается, SunnyHomeManager продолжает попытки включения в течение всего периода времени. С помощью этой опции запрос на потребление энергии можно отменить.

#### Настенный бокс для устройства

![Устройства](../../../../en/adapterref/iobroker.semp/docu/settings/Settings_Device_Wallbox_de.PNG)

Емкость батареи \[Вт·ч]: используется для запросов энергии. Если батарея разряжена, для последовательности зарядки запрашивается вся ее емкость.

Максимальное время зарядки после подключения к розетке: время, в течение которого требуется энергия.

- 12 ч: запросить энергию для зарядки в течение следующих 12 часов
- 24 ч: запросить энергию для зарядки в течение следующих 24 часов
- endles: запрашивает энергию для зарядки, пока подключена вилка.
- Определяется пользователем: запрашивает энергию для зарядки на заданный пользователем период. Пользователь может задать время в точке данных 'semp.0.Devices.yourWallbox.MaxChargeTime'.

Имеет переключатель для включения трехфазной зарядки: некоторые настенные зарядные устройства могут использоваться с однофазным или трехфазным питанием. Если вы хотите переключаться между однофазным и трехфазным питанием, вы можете активировать эту опцию.

Ограничение для переключения на трехфазную зарядку \[Вт]: если рекомендуемая мощность от HomeManager превышает это ограничение, будет активирована трехфазная зарядка.

Задержка переключения на трехфазную зарядку \[мин]: чтобы избежать переключений между однофазной и трехфазной зарядкой, можно задать задержку, в течение которой мощность должна превышать допустимый предел.

Идентификатор объекта Plug Connected: это точка данных, где ваш настенный блок показывает, что ваш автомобиль подключен к настенному блоку. Должна быть true (логическое значение), если подключено. Адаптер считывает только эту точку данных. Если вилка подключена, адаптер запрашивает энергию у SunnyHomeManager. Если вилка отключена, запрос энергии немедленно отменяется.

object-ID Is Charging: это точка данных, где ваш настенный адаптер показывает, что ваш автомобиль заряжается. Должно быть true (логическое значение), если идет зарядка. Адаптер считывает только эту точку данных.

object-ID Is Error: это точка данных, где ваш Wallbox показывает, что находится в состоянии ошибки. Должна быть true (логическое значение), если произошла ошибка. Адаптер считывает только эту точку данных.

object-ID Charge Power: это точка данных, откуда ваш настенный зарядный адаптер получает информацию о мощности зарядки. Значение должно быть в ваттах \[Вт]. Адаптер записывает мощность на основе рекомендаций от SunnyHomeManager.

object-ID Start Charge: это точка данных, с которой начинается зарядка вашего настенного зарядного устройства. Адаптер устанавливает значение true, если рекомендации по зарядке доступны из SunnyHomeManager.

object-ID Stop Charge: это точка данных, в которой ваша настенная зарядная станция останавливается для зарядки. adapter устанавливает значение true, если рекомендация по остановке зарядки доступна в SunnyHomeManager.

object-ID 3Phase Charge enable: это точка данных для активации трехфазной зарядки. Используется только в том случае, если включен параметр «имеет переключатель для включения трехфазной зарядки».

object-ID 3Phase Charge disable: это точка данных для отключения трехфазной зарядки. Используется только в том случае, если включен параметр «имеет переключатель для включения трехфазной зарядки».

Все идентификаторы объектов могут иметь следующий тип:

- логический
- число
- URL

В случае использования URL-адреса, Set-/CheckValue не применяется.

## варианты использования

### Отмените запрос, если устройство не включится.

Иногда устройству не требуется запрашиваемая энергия (например, тепловому насосу). В этом случае может быть целесообразно отменить запрос на энергию в системе мониторинга состояния конструкции (SHM). Таким образом, SHM может перенаправить доступную энергию на другие устройства.

### многоэнергетических запросов

- Периоды запроса на электроэнергию не должны перекрываться (лучше, чтобы разница во времени составляла не менее пяти минут).
- Количество периодов подачи заявок на энергоснабжение не ограничено.
