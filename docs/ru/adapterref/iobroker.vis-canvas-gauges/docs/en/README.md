# Холщовые шаблоны для Vis-2

Набор виджетов включает пять индикаторов, отображающих число: **линейный** индикатор, **радиальный** индикатор, **циркуль** , **плоская** полоса и индикатор **выполнения** . На этой странице описывается версия **для vis-2** . В vis (vis-1) первые четыре индикатора имеют те же настройки; они отображаются с помощью той же библиотеки, поэтому выглядят одинаково. Индикатор выполнения существует только в vis-2.

## Общий

### Требования и миграция

Виджеты находятся в наборе виджетов **Canvas gauges** в списке виджетов редактора vis-2. Для описанных здесь версий React требуется **vis-2 2.12.8** или новее. В более старых версиях vis-2 вместо них отображаются виджеты vis-1.

Проекты, созданные с помощью vis-1, продолжают работать без изменений. Обе версии используют одни и те же идентификаторы виджетов. `tplCGlinearGauge`, `tplCGradialGauge`, `tplCGCompas`, `tplCGflatGauge`) и те же названия атрибутов, а vis-2 автоматически выбирает версию React. Все настройки сохраняются. `tplCGprogress` не имеет аналога в редакторе vis-1 и поэтому отображается только в редакторе vis-2.

В таблицах ниже **«Setting»** — это метка в редакторе vis-2, а **«Attribute»** — это имя, хранящееся в проекте. Используйте имя атрибута при редактировании проекта в формате JSON или при копировании настроек между виджетами.

**Пустое поле означает «значение по умолчанию библиотеки».** Практически все поля являются необязательными. Пока поле пустое, индикатор использует значение по умолчанию из [библиотеки canvas-gauges](https://canvas-gauges.com) , где также подробно описано значение каждой опции. Всегда отображаются только те настройки, которые отмечены значением по умолчанию в таблицах.

Размер индикатора соответствует размеру виджета. Изображение перерисовывается при каждом изменении размера виджета, поэтому индикатор можно свободно растягивать — круглые лучше всего смотрятся в квадратном блоке.

### Значение

| Параметр              | Атрибут       | По умолчанию | Описание                                                                                                                                                                 |
| --------------------- | ------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Идентификатор объекта | `oid`         |              | Состояние, значение которого отображается на индикаторе. При выборе состояния поля _Min_ , _Max_ , _Units_ и _Title_ заполняются данными из объекта, если они еще пусты. |
| Мин                   | `minValue`    | 0            | Начало шкалы.                                                                                                                                                            |
| Макс                  | `maxValue`    | 100          | Крайняя точка шкалы.                                                                                                                                                     |
| Единицы               | `units`       |              | Текст под значением, например: `°C`.                                                                                                                                     |
| Заголовок             | `title`       |              | Текст расположен посередине шкалы.                                                                                                                                       |
| Фактор                | `factor`      | 1            | Перед нанесением на карту значение штата умножается на это значение.                                                                                                     |
| Смещение стоимости    | `valueOffset` | 0            | ...и это добавляется позже. Вместе с _коэффициентом_ это преобразует единицу измерения, например. `1.8` /`32` от °C до °F.                                                |

Стрелка индикатора остается на _отметке Min_ до тех пор, пока состояние не имеет значения.

### Анимация

| Параметр                | Атрибут             | По умолчанию | Описание                                                                                                                                                     |
| ----------------------- | ------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Включено                | `animation`         | на           | Стрелка перемещается к новому значению, а не скачет.                                                                                                         |
| Продолжительность       | `animationDuration` | 500          | Длина пути в миллисекундах.                                                                                                                                  |
| Правило                 | `animationRule`     | `linear`     | Маршрут путешествия: `linear`, `quad`, `quint`, `cycle`, `bounce`, `elastic` и их `de...` аналоги, которые работают в обратном направлении.                    |
| Одушевленное значение   | `animatedValue`     | выключенный  | Число в ячейке значения увеличивается вместе со стрелкой.                                                                                                    |
| Анимировать при запуске | `animateOnInit`     | выключенный  | Стрелка начинает движение от _отметки Min_ и перемещается к текущему значению при открытии окна просмотра.                                                   |

### Цвета

Каждая часть индикатора имеет свой цвет, а пустое поле сохраняет цвет библиотеки. Параметр, заканчивающийся на _end,_ является вторым цветом градиента.

![Цвета](../../../../../en/adapterref/iobroker.vis-canvas-gauges/docs/img/colors.png)

| Параметр                                             | Атрибут                                                                     | Описание                                              |
| ---------------------------------------------------- | --------------------------------------------------------------------------- | ----------------------------------------------------- |
| Пластина / Торцевая часть пластины                   | `colorPlate`, `colorPlateEnd`                                               | Циферблат прибора.                                    |
| Крупные клещи / Мелкие клещи                         | `colorMajorTicks`, `colorMinorTicks`                                        | Линии шкалы.                                          |
| Удар клещей                                          | `colorStrokeTicks`                                                          | Линия на шкале, которую отмечает _отметка «Stroke»_ . |
| Название / Единицы измерения / Числа                 | `colorTitle`, `colorUnits`, `colorNumbers`                                  | Три текста на тарелке.                                |
| Игла / Конец иглы                                    | `colorNeedle`, `colorNeedleEnd`                                             | Игла, от основания до кончика.                        |
| Тень от иглы вверх/вниз                              | `colorNeedleShadowUp`, `colorNeedleShadowDown`                              | Тень, которую игла отбрасывает на пластину.           |
| Текст значения / Тень текста значения                | `colorValueText`, `colorValueTextShadow`                                    | Число в поле значения.                                |
| Граница: внешняя / средняя / внутренняя (+ _конец_ ) | `colorBorderOuter`, `colorBorderMiddle`, `colorBorderInner`, ...           | Три кольца вокруг тарелки.                            |
| Тень от границы                                      | `colorBorderShadow`                                                         | Тень под внешним кольцом.                             |
| Прямоугольник значения / фон / тень (+ _конец_ )     | `colorValueBoxRect`, `colorValueBoxBackground`, `colorValueBoxShadow`, ... | Обводка вокруг значения.                              |

### Темная тема

![Темная тема](../../../../../en/adapterref/iobroker.vis-canvas-gauges/docs/img/darktheme.png)

Те же два виджета в темном режиме, с включенным и выключенным переключателем.

| Параметр      | Атрибут       | По умолчанию | Описание                                                                            |
| ------------- | ------------- | ------------ | ----------------------------------------------------------------------------------- |
| Следуйте теме | `followTheme` | на           | В темной тематике vis-2 пластина, шкала, текст, кольца и полоса становятся темными. |

Материал, _из которого изготовлен_ инструмент, сохраняет свой цвет в обеих темах: игла остается лососевого цвета, красная игла плоского калибра остается красной, а цветная часть стержня сохраняет заданный вами цвет. Только то, что объединяет инструмент с видом снизу, следует теме. Зажженная лампа тоже не становится серой ночью.

**Измененный вами цвет остается неизменным.** Переключение цвета происходит только в том случае, если поле пустое или содержит предустановленный цвет, с которым был создан виджет — например, белый цвет плоской пластины индикатора. Как только вы выберете цвет самостоятельно, он будет преобладать в обеих темах.

**Виджеты, размещенные до появления этой настройки, не изменяются.** `followTheme` Этот параметр записывается в виджет при его создании, поэтому старый проект — и проект, перенесенный из vis-1 — сохраняет свой внешний вид до тех пор, пока вы не включите соответствующий переключатель.

Тема оформления также объясняет, почему компас почти не меняется: почти все его цвета входят в предустановленный набор и уже являются темными.

Измерительный прибор и компас добавляют цвета круга в центре: `colorNeedleCircleOuter`, `colorNeedleCircleOuterEnd`, `colorNeedleCircleInner` и `colorNeedleCircleInnerEnd`.

Линейный индикатор, плоский индикатор и индикатор выполнения добавляют цвета к полосе: `colorBarStroke`, `colorBar`, `colorBarEnd`, `colorBarProgress`, `colorBarProgressEnd` и `colorBarShadow`.

### Иголка

| Параметр       | Атрибут                    | Описание                                                                                                                                    |
| -------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Показать иглу  | `needle`                   | Функция «Выкл.» отображает индикатор без стрелки — это полезно, когда должна быть видна только полоса или поле со значением.                |
| Тень           | `needleShadow`             | Игла отбрасывает тень на пластину.                                                                                                          |
| Тип            | `needleType`               | `arrow` это конусообразный указатель, `line` прямая линия _шириной_ в пикселях.                                                              |
| Начало / Конец | `needleStart`, `needleEnd` | Начальная и конечная точки стрелки, выраженные в процентах от радиуса (от длины для линейного измерительного прибора). `0` является центром. |
| Ширина         | `needleWidth`              | Ширина иглы у основания.                                                                                                                    |

### Границы

![Границы](../../../../../en/adapterref/iobroker.vis-canvas-gauges/docs/img/borders.png)

Три кольца плюс тень обрамляют тарелку. Задается ширина. `0` скрывает это кольцо.

| Параметр                              | Атрибут                                                     | Описание                                  |
| ------------------------------------- | ----------------------------------------------------------- | ----------------------------------------- |

| Внешняя / Средняя / Внутренняя ширина | `borderOuterWidth`, `borderMiddleWidth`, `borderInnerWidth` | Ширина трех колец.                        |
| ширина тени                           | `borderShadowWidth`                                         | Ширина тени под внешним кольцом.          |

![шкала значений](../../../../../en/adapterref/iobroker.vis-canvas-gauges/docs/img/valuebox.png)

Поле под серединой, в котором отображается значение в виде числа.

| Параметр                      | Атрибут                | По умолчанию | Описание                                                                                                                                                                          |
| ----------------------------- | ---------------------- | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Включено                      | `valueBox`             | выключенный  | Показана коробка.                                                                                                                                                                 |
| Удар по коробке               | `valueBoxStroke`       |              | Ширина рамки вокруг коробки.                                                                                                                                                      |

| Текст                         | `valueText`            |              | Вместо значения отображается фиксированный текст. Он показывается только до тех пор, пока _идентификатор объекта_ не имеет значения, в противном случае приоритет имеет значение. |
| Тень текста                   | `valueTextShadow`      |              | Это число отбрасывает тень.                                                                                                                                                       |

На горизонтальной полосе этот параметр не работает — вместо него разместите рядом текстовый виджет.

### Шрифты

Семейство, размер, стиль и вес четырех текстов — _Числа_ (шкала), _Заголовок_ , _Единицы измерения_ и _Значение_ .

| Параметр                                        | Атрибут                                                              | Описание                                                                                                           |
| ----------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Числа / Название / Единицы измерения / Значение | `fontNumbers`, `fontTitle`, `fontUnits`, `fontValue`                 | Семейство шрифтов.                                                                                                 |
| ... размер                                      | `fontNumbersSize`, `fontTitleSize`, `fontUnitsSize`, `fontValueSize` | Размер. Он масштабируется в соответствии с индикатором, поэтому это относительное число, а не значение в пикселях. |
| ... стиль                                       | `fontNumbersStyle`, ...                                             | `normal`, `italic` или `oblique`.                                                                                  |
| ... масса                                       | `fontNumbersWeight`, ...                                            | `normal`, `bold`, `bolder`, `lighter` или число, например `600`.                                                   |

## Линейный - `tplCGlinearGauge`

![Линейный](../../../../../en/adapterref/iobroker.vis-canvas-gauges/docs/img/linear.png)

Вертикальный индикатор: пластина с рамкой, шкалой по бокам и полосой, заполняющейся до значения. Размер по умолчанию — 150 x 250 пикселей с радиусом скругления углов 10 пикселей — пластина повторяет этот радиус, поэтому индикатор сохраняет форму виджета.

Помимо указанных выше настроек, он предлагает следующую панель:

| Параметр      | Атрибут          | По умолчанию | Описание                                                                                                                      |
| ------------- | ---------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| Начало круга  | `barBeginCircle` |              | Диаметр закругленного конца в нижней части прутка, в процентах от ширины прутка. `0` Это прямая полоска; это колба термометра. |
| Ширина        | `barWidth`       |              | Ширина полосы в процентах от ширины полосы.                                                                                   |
| Длина         | `barLength`      |              | Длина стержня в процентах от длины пластины.                                                                                  |
| Ширина штриха | `barStrokeWidth` |              | Ширина линии вокруг барной стойки.                                                                                            |
| Тень          | `barShadow`      | 0            | Ширина тени, отбрасываемой полосой, в пикселях. Её цвет — \[указать цвет]. `colorBarShadow`.                                  |
| Прогресс      | `barProgress`    | на           | Заполняет полосу до заданного значения. Выключено, полоса остается пустой, и движется только стрелка.                         |

и где находится шкала:

| Параметр              | Атрибут           | По умолчанию | Описание                                                               |
| --------------------- | ----------------- | ------------ | ---------------------------------------------------------------------- |

## Отличия от vis-1

Виджеты React отображают одни и те же индикаторы с использованием одной и той же библиотеки, поэтому перенесенный проект выглядит так же. В процессе были исправлены некоторые ошибки:

- ** `Padding` Работа с делениями на шкале работает.** Виджет vis-1 написал _Padding_ into _Begin circle_ , поэтому настройка переместила закругленный конец шкалы, а не расстояние делений.
- ** `Value weight` Работает.** Виджет vis-1 добавил слово _«Value weight»_ в семейство шрифтов цифр, заменив шрифт шкалы словом «value weight». `bold`.
- **Шкала сохраняет свою последнюю метку.** При использовании количества _делений в качестве основного_ значения метки рассчитываются исходя из количества секций. Виджет vis-1 многократно добавлял шаг увеличения и удалял последнюю метку, как только сумма превышала максимальное значение из-за ошибки округления, например, при диапазоне от 0 до 0,3 и 4 метках.
- **Состояние, которое пусто при открытии представления, всё равно поступает.** Виджет vis-1 подписывается на состояние только тогда, когда у него уже есть значение, поэтому индикатор на только что запущенном адаптере остаётся на минимальном значении до перезагрузки представления.
- **Тип иглы радиального калибра: `arrow`.** Его значением по умолчанию для vis-1 было слово `select`, это название типа поля, которое перешло в значение по умолчанию. Библиотека всё равно нарисовала для него стрелку, поэтому в представлении ничего не меняется.
- _Поле "Основные деления"_ теперь во всех виджетах представляет собой текстовое поле. В vis-1 это был ползунок, за исключением компаса, поэтому список меток можно было ввести только там.
- _Количество делений малого деления_ увеличивается до 50 вместо 20 — по умолчанию компас имеет значение 22, которое его собственный ползунок не мог достичь.

В библиотеку были добавлены некоторые настройки, которых никогда не было в наборе атрибутов vis-1: _ширина секции_ и _концы секций_ подсветки, _точные деления_ , _поля чисел_ , _обводка делений_ , _ширина блока_ значения и _тень_ / _тень_ полосы. Все они являются необязательными и ничего не меняют, пока не будут заполнены.
