## фундаментальный

> Инструкции предназначены для версии 0.0.1

Во-первых, этот адаптер/домашняя страница предназначен только для Германии. Вы можете получить свой API (бесплатно) по адресу " <https://www.eiswarnung.de/rest-api/> ".

После установки этого адаптера он автоматически заполнит данные о долготе и широте из настроек iobroker (если вы заполните эти настройки). Если вы не заполните настройки iobroker, вы можете найти свои данные на [сайте https://www.gpskoordinaten.de/](https://www.gpskoordinaten.de/) .

Данные извлекаются каждый час.

Наслаждайтесь использованием адаптера.
