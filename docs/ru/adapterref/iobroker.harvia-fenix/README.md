# IoBroker.harvia-fenix
**[Hier geht es zur deutschen Version der Dokumentation.](README_de.md)**

![Тестирование и выпуск](https://github.com/meistermopper/ioBroker.harvia-fenix/workflows/Test%20and%20Release/badge.svg)

### Адаптер ioBroker для интеграции и управления блоком управления сауны **Harvia Fenix** через облачную инфраструктуру MyHarvia.
Для получения дополнительной информации о компании Harvia и их блоках управления сауной, пожалуйста, посетите раздел [официальный сайт Harvia](https://www.harvia.com).

## Установка
Адаптер доступен в официальном репозитории ioBroker `latest` (бета-версия). Вы можете установить его напрямую через веб-интерфейс ioBroker или на свой локальный компьютер через npm.

### На основе браузера (через административную панель ioBroker)
1. Откройте веб-интерфейс ioBroker в браузере (например, `192.168.1.33:8081`).
2. Убедитесь, что в настройках репозитория ioBroker установлено значение **`latest`** (бета-версия).
3. Перейдите на вкладку **Адаптеры**.
4. Введите "harvia-fenix" в фильтр.
5. Щелкните по трем точкам, а затем по символу «+» адаптера **Harvia Fenix**, чтобы добавить экземпляр.

### Локальная машина
Перейдите в папку ioBroker и выполните следующую команду:

```bash
npm i iobroker.harvia-fenix
```

## Настраивать
Помимо установки адаптера, необходимо настроить экземпляр адаптера, указав данные вашей учетной записи MyHarvia.

### Предварительные условия
1. **Node.js >= 22**
2. Зарегистрированный аккаунт в официальном приложении для смартфонов **MyHarvia 2**.
3. Ваши действительные учетные данные для входа:
   - **Адрес электронной почты**
   - **Пароль**

*Примечание: Мы рекомендуем создать отдельную учетную запись для ioBroker в приложении Harvia 2 и использовать эти учетные данные для входа в систему.*

### Конфигурация ioBroker
1. Откройте интерфейс ioBroker в браузере (например, `192.168.1.33:8081`).
2. Перейдите на вкладку **Экземпляры** и щелкните значок настроек вашего экземпляра `harvia-fenix.0`.
3. Введите свой **адрес электронной почты** и **пароль** вашей учетной записи MyHarvia.
4. Если вы оставите поле **Идентификатор устройства** пустым, адаптер автоматически выполнит поиск устройств, связанных с вашей учетной записью, при запуске. В качестве активного устройства будет использоваться первое найденное устройство.
5. Настройте дополнительные параметры: **Интервал опроса** (секунды), **Минимальный/максимальный предел целевой температуры** (°C) и **Максимальная продолжительность нагрева** (минуты).
6. Нажмите кнопку **Сохранить и закрыть**.

### Настройка устройства и поддержка нескольких устройств
#### Автоматическое обнаружение
Если оставить поле **Идентификатор устройства** в настройках адаптера пустым, адаптер автоматически выполнит поиск устройств, связанных с вашей учетной записью, при запуске. В качестве активного устройства будет использоваться первое найденное устройство. Обнаруженный идентификатор будет выведен в журнал ioBroker.

#### Идентификатор устройства, указанный вручную
Для большинства пользователей с одной сауной достаточно автоматического обнаружения. Однако рекомендуется скопировать обнаруженный ID из журнала и вставить его в конфигурацию, чтобы обеспечить стабильное соединение с конкретным оборудованием.

#### Несколько саун
Если ваша учетная запись MyHarvia управляет несколькими блоками управления (например, одним дома и одним в дачном домике):

1. Создайте отдельный экземпляр адаптера для каждой сауны (например, `harvia-fenix.0` и `harvia-fenix.1`).
2. Вручную введите конкретный **идентификатор устройства** для каждого блока в соответствующей конфигурации экземпляра.

Это позволяет отслеживать и контролировать обе сауны независимо друг от друга, используя собственный набор данных.

### Общие/Гостевые учетные записи и идентификатор партнера
#### Что такое идентификатор партнера?
Облачная инфраструктура MyHarvia разделяет устройства, пользователей и приложения на различные «партнерские организации». Например, официальное приложение для смартфонов **MyHarvia 2** соответствует идентификатору партнера `ORG/prod:0:6656:0`.

Обычно, когда пользователь входит в систему, адаптер декодирует его JSON Web Token (JWT) и автоматически извлекает идентификатор партнера из поля `custom:org`. Затем он запрашивает API облака Harvia, используя этот идентификатор, для обнаружения подключенных устройств.

#### Проблема с общими/гостевыми учетными записями
Если другой пользователь (владелец/основной пользователь) поделился с вами своей сауной в приложении MyHarvia 2:

1. Ваш токен учетной записи связан с другим идентификатором партнера-гостя (например, `ORG/prod:0:6749` или пользовательским идентификатором).
2. Если адаптер запросит список устройств под вашим гостевым идентификатором партнера, API Harvia Cloud вернет пустой список (`{"devices":[]}`), и вы не увидите сауну.
3. Для обнаружения и управления общей сауной запросы к API **необходимо отправлять, используя идентификатор партнера владельца**.

#### Как найти идентификатор партнера владельца?
Существует два способа определить партнерский идентификатор владельца:

1. **Стандартное приложение:** Если владелец использует официальное стандартное мобильное приложение **MyHarvia 2**, идентификатор партнера — **`ORG/prod:0:6656:0`**.
2. **Из лога ioBroker:** Если владелец уже использует адаптер `harvia-fenix`, он может проверить лог запуска ioBroker. При запуске адаптер выводит строку следующего вида:

`Using partner ID from user token: ORG/prod:0:XXXX` Владелец может просто скопировать этот идентификатор и поделиться им с гостевым пользователем.

#### Как настроить общий/гостевой аккаунт
1. Введите свое **имя пользователя/адрес электронной почты** и **пароль** (гостевые учетные данные) в настройках адаптера.
2. Введите **идентификатор партнера владельца** в поле **Идентификатор партнера (необязательно)**.
3. Если оставить поле **Идентификатор устройства** пустым, адаптер выполнит поиск общего устройства, используя идентификатор партнера владельца, и найдет его автоматически.

## Примечание о совместимости
* **Поддерживается:** Блоки управления **Harvia Fenix**, управляемые через мобильное приложение **MyHarvia 2**.
* **НЕ ПОДДЕРЖИВАЕТСЯ:** Серия **Harvia Xenio** (например, Xenio WiFi / CX001WIFI). Серия Xenio использует устаревшую аппаратную экосистему и старое приложение *"MyHarvia for Xenio"*, которое принципиально несовместимо с API, используемым этим адаптером.

## Использование
Адаптер преобразует облачные состояния вашей сауны в структурированные точки данных ioBroker в разделе `harvia-fenix.0.*`.

### Доступные точки данных
| Точка данных | Тип | Роль | Доступ | Описание |
|---|---|---|---|---|
| `info.connection` | логическое значение | `indicator` | Только для чтения | Состояние подключения адаптера к облаку MyHarvia. |
| `info.maxTemp` | номер | `value.temperature` | Только для чтения | Максимально допустимая целевая температура (`110 °C`). |
| `online` | логическое значение | `indicator.reachable` | Только для чтения | Состояние подключения блока управления к облаку. |
| `doorSafety` | логическое значение | `indicator.safety` | Только для чтения | Состояние контура безопасности (например, `true`, если дверь надежно закрыта / безопасна для использования). |
| `remoteControl` | логическое значение | `indicator` | Только для чтения | Состояние готовности к дистанционному запуску. Если `false`, дистанционный запуск обогревателя (через адаптер) блокируется. |
| `errorMsg` | строка | `text` | Только для чтения | Текущие сообщения об ошибках или текст состояния нагревателя. |

## Уведомления и автоматизация
Адаптер автоматически рассчитывает степень нагрева и предоставляет два индикатора, специально разработанных для запуска push-уведомлений (например, через Telegram, Pushover или Alexa).

Вы можете просто использовать базовый скрипт ioBroker (JavaScript или Blockly), который будет отслеживать изменение этих состояний на `true`:

```javascript
// Trigger for the 10-minute pre-warning
on({ id: 'harvia-fenix.0.readyNotified10Min', change: 'ne', val: true }, function () {
    const targetTemp = getState('harvia-fenix.0.targetTemp').val;
    sendTo('telegram.0', 'send', { text: `🧖 The sauna will reach its target temperature (${targetTemp}°C) in about 10 minutes.` });
});

// Trigger when the sauna is fully ready
on({ id: 'harvia-fenix.0.targetReachedNotified', change: 'ne', val: true }, function () {
    const targetTemp = getState('harvia-fenix.0.targetTemp').val;
    sendTo('telegram.0', 'send', { text: `♨️ The sauna has reached the target temperature of ${targetTemp}°C and is ready!` });
});
```

*Примечание: Эти состояния автоматически сбросятся до `false` при выключении обогревателя или начале нового сеанса обогрева.*

## Поиск неисправностей
### Типичные ошибки API и сообщения о состоянии в `errorMsg`
* **`Действие заблокировано (403 Запрещено). Возможно, не активирована авторизация дистанционного запуска (петля безопасности) на панели.`**
- **Причина:** Европейский стандарт безопасности требует, чтобы дистанционный запуск мог быть активирован только в том случае, если защитная петля/датчик двери замкнуты и дистанционный запуск физически активирован на панели управления сауны.
- **Решение:** Закройте дверь сауны и нажмите кнопку **Дистанционный запуск / Fernstart** на физической панели управления Harvia. Значок пульта на экране должен быть активен. После этого вы сможете управлять сауной через адаптер.
* **`Блокировка облака: устройство занято, команда отменена.` (Записано как отладочная информация)**
- **Причина:** API Harvia ограничивает скорость отправки команд, если они отправляются быстро одна за другой (например, при быстром нажатии кнопок в пользовательском интерфейсе), чтобы защитить оборудование.
- **Решение:** Подождите несколько секунд между командами. Адаптер автоматически отбрасывает команды, отправленные слишком быстро, чтобы предотвратить блокировку API.
