# Виджеты времени и погоды для vis-2

Виджеты времени и погоды включают семь элементов: часы, даты и погоду. На этой странице описывается версия **vis-2** . В версии vis (vis-1) используются те же виджеты с теми же настройками, но они выглядят немного иначе.

## Общий

### Требования и миграция

Виджеты находятся в наборе виджетов « **Время и погода»** в списке виджетов редактора vis-2. Для описанных здесь версий React требуется **vis-2 2.12.8** или новее. В более старых версиях vis-2 вместо них отображаются виджеты vis-1.

Проекты, созданные с помощью vis-1, продолжают работать без изменений. Обе версии используют одни и те же идентификаторы виджетов. `tplTwSimpleClock`, `tplTwCoolClock`, ...) и те же названия атрибутов, а vis-2 автоматически выбирает версию React. Все настройки сохраняются.

В таблицах ниже **«Setting»** — это метка в редакторе vis-2, а **«Attribute»** — это имя, хранящееся в проекте. Используйте имя атрибута при редактировании проекта в формате JSON или при копировании настроек между виджетами.

Часы показывают время устройства, отображающего изображение, а не время сервера ioBroker. Все часы переключаются одновременно, с точностью до секунды.

### Язык

Дни недели, названия месяцев и текст виджета погоды доступны на всех языках vis-2: английском, немецком, русском, португальском, голландском, французском, итальянском, испанском, польском, украинском и китайском. Виджеты используют язык vis-2. Для виджета погоды есть собственная настройка, позволяющая изменить его язык.

### Собственный CSS

Виджеты используют имена классов vis-1, и правила имеют тот же вес, что и там. Поэтому CSS, который вы написали для vis-1 в CSS проекта, по-прежнему применяется, например:

```css
/* grey background for the forecast days */
.weatherForecastItem { background-color: #444; }
/* red digits of the flip clock */
.flip-clock-wrapper ul li a div div.inn { color: #e53935; }
```

| Виджет        | Классы                                                                                                                                                                                                                                                                                              |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SimpleClock   | `clock` на виджете                                                                                                                                                                                                                                                                                  |
| SimpleDate    | `date` на виджете                                                                                                                                                                                                                                                                                   |
| ФлипКлок      | `flip-clock-wrapper`, `flip`, `play`, `flip-clock-before`, `flip-clock-active`, `up`, `down`, `inn`, `shadow`, `flip-clock-divider`, `flip-clock-dot`, `flip-clock-meridium`                                                                                                                        |
| WeatherCustom | `weatherFeed` на виджете, `weatherItem` (плюс) `day` или `night`), `weatherCity`, `weatherTemp`, `weatherDesc`, `weatherRange`, `weatherWind`, `weatherHumidity`, `weatherForecast`, `weatherForecastItem`, `weatherForecastDay`, `weatherForecastDate`, `weatherForecastText`, `weatherForecastRange` |

CSS-настройки виджета в редакторе (шрифт, цвет, граница и т. д.) применяются к самому виджету. Они имеют приоритет над остальными настройками. `clock`, `date` и `weatherFeed` которые располагаются на виджете. Внутренние части переворачивающихся часов и окна погоды сохраняют свои собственные цвета; их можно изменить с помощью правил, подобных приведенным выше. Размер шрифта виджета погоды масштабируется для всего окна. Цвета SVG-часов, CoolClock и Segment Clock являются настройками виджетов.

### Темная тема

Циферблаты часов и индикатор погоды сохраняют свои цвета в обеих темах vis-2. Меняется только то, что находится непосредственно на экране: точки и AM/PM на переворачивающихся часах. См. [FlipClock](#flipclock---tpltwflipclock) .

## SimpleClock - `tplTwSimpleClock`

![SimpleClock](../../../../../en/adapterref/iobroker.vis-timeandweather/docs/img/simple-clock.png)

Время в текстовом формате: `hh:mm:ss` или `hh:mm` Всегда с 24-часовым форматом и ведущими нулями. На картинке показаны часы по умолчанию, часы без секунд, а также часы _без стиля_ , со своим собственным шрифтом и цветом.

**Смотрите.** Виджет получает класс. `clock`: крупные серые жирные цифры с тенью (Trebuchet MS, 80 px). Настройки CSS виджета в редакторе переопределяют отдельные его свойства, например, только размер шрифта. Если вы хотите полностью стилизовать часы с помощью собственного класса, включите параметр _«Без стиля»_ : тогда виджет не будет иметь собственного внешнего вида.

| Параметр       | Атрибут       | По умолчанию | Описание                                                                   |
| -------------- | ------------- | ------------ | -------------------------------------------------------------------------- |
| Скрыть секунды | `hideSeconds` | выключенный  | Шоу `hh:mm`.                                                               |
| Моргнуть       | `blink`       | выключенный  | Только без секунд: двоеточие исчезает каждую секунду. Минуты не двигаются. |
| Без стиля      | `noClass`     | выключенный  | Удаляет класс `clock`, см. выше.                                           |

Размер по умолчанию: 316 x 92 пикселя.

## SimpleDate - `tplTwSimpleDate`

![SimpleDate](../../../../../en/adapterref/iobroker.vis-timeandweather/docs/img/simple-date.png)

Сегодняшняя дата в текстовом виде. Она меняется сразу после полуночи.

| Параметр                | Атрибут         | По умолчанию | Описание                                                                                                              |
| ----------------------- | --------------- | ------------ | --------------------------------------------------------------------------------------------------------------------- |
| Показать день недели    | `showWeekDay`   | выключенный  | День недели указывается в начале строки: `Thursday, ...`.                                                             |
| Короткий рабочий день   | `shortWeekDay`  | выключенный  | Только в _день недели, указанный в объявлении_ : `Thu`, `Do`, ...                                                     |
| Короткий год            | `shortYear`     | выключенный  | `26` вместо `2026`.                                                                                                   |
| Добавьте ноль в начало. | `prependZero`   | на           | `05` вместо `5` за день и месяц.                                                                                       |
| Месяц как слово         | `monthWord`     | выключенный  | `21st May, 2026` или `21. Mai 2026` вместо чисел.                                                                      |
| Короткий месяц          | `shortMonth`    | выключенный  | Только если _слово «месяц» образовано_ от первых трех букв, например: `Sep`.                                          |
| Американский формат     | `americanOrder` | выключенный  | Только на английском языке: месяц перед днем.                                                                         |
| Без стиля               | `noClass`       | выключенный  | Удаляет класс `date` (серый жирный текст, 26 пикселей), как _в стиле_ [SimpleClock](#simpleclock---tpltwsimpleclock) . |

Форматы зависят от языка vis-2:

|                 | Английский       | Американский формат (английский) | Все остальные языки |
| --------------- | ---------------- | -------------------------------- | ------------------- |
| Числа           | `21/05/2026`     | `05/21/2026`                     | `21.05.2026`        |
| Месяц как слово | `21st May, 2026` | `May 21st, 2026`                 | `21. Mai 2026`      |

Размер по умолчанию: 134 x 33 пикселя. Более длинные тексты, например, с указанием дня недели, переносятся на вторую строку, если ширина виджета недостаточна.

## CoolClock -`tplTwCoolClock`

Аналоговые часы с 21 вариантом оформления, нарисованные на холсте. Часы всегда круглые. Их диаметр равен меньшей стороне виджета, а редактор сохраняет виджет квадратным.

![Скины](../../../../../en/adapterref/iobroker.vis-timeandweather/docs/img/cool-clock-skins.png)

![Параметры](../../../../../en/adapterref/iobroker.vis-timeandweather/docs/img/cool-clock-options.png)

| Параметр       | Атрибут       | По умолчанию | Описание                                                                |
| -------------- | ------------- | ------------ | ----------------------------------------------------------------------- |
| Тема           | `theme`       | классический | Кожа, см. фото. Видно неизвестное название. `chunkySwiss`.              |
| Скрыть секунды | `noSeconds`   | выключенный  | Без секундной стрелки. Время на часах пересчитывается каждые 15 секунд. |
| Цифровые часы  | `showDigital` | выключенный  | Отображает время в виде текста под центром экрана, без указания секунд. |
| Показать ам/м  | `showAmPm`    | выключенный  | Только с _цифровыми часами_ : 12-часовой формат времени. `am` /`pm`.    |

Некоторые скины (`Sand`, `Sun`, `Tumb`, `Stone`, `Disc`) Выходят за пределы закругленной грани и обрезаются по краю виджета, как в vis-1. Размер по умолчанию: 150 x 150 пикселей.

## FlipClock - `tplTwFlipClock`

![ФлипКлок](../../../../../en/adapterref/iobroker.vis-timeandweather/docs/img/flip-clock.png)

Часы с откидными карточками для отображения часов, минут и секунд. При изменении цифры верхняя половина карточки откидывается.

| Параметр        | Атрибут | По умолчанию | Описание                                                                                                                                                          |
| --------------- | ------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Циферблат часов | `face`  | 24 часа      | `24 hours` (`TwentyFourHourClock`) или `12 hours (AM/PM)` (`TwelveHourClock` 12-часовой формат времени показывает с 12:00 до 11:59 и `AM` /`PM` отстаёт от секунд. |

Часы имеют фиксированный размер и не могут быть изменены: ширина 500 пикселей с 24-часовым форматом времени, 600 пикселей с 12-часовым форматом времени, высота около 110 пикселей. Как и в vis-1, карточки начинаются на 1 em правее и ниже верхнего левого угла виджета. Цвета можно изменить с помощью [собственных CSS-стилей](#own-css) .

В мрачной тематике vis-2 точки и `AM` /`PM` становятся светлыми, поэтому остаются видимыми в темноте:

![Тема оформления FlipClock в темноте](../../../../../en/adapterref/iobroker.vis-timeandweather/docs/img/flip-clock-dark.png)

## WeatherCustom - `tplTwWeather`

![WeatherCustom](../../../../../en/adapterref/iobroker.vis-timeandweather/docs/img/weather.png)

Текущая погода и прогноз на сегодня и на шесть дней вперед. Виджет получает свои значения из любых состояний, например, адаптеров _daswetter_ , _accuweather_ или _weatherunderground_ : вы выбираете одно состояние для каждого значения.

На рисунке, сверху вниз:

- город, текущая температура, погодные условия
- _Максимальная_ / _минимальная температура_ : максимум и минимум сегодня
- _Ветер_ : направление и скорость. Направление в градусах отображается по компасу. `255` →`WSW`), текст, подобный `SW` остается как есть.
- _Влажность_ в %
- Прогноз: одна строка в день с указанием дня недели, даты, погодных условий и температуры, начиная с сегодняшнего дня.

Значок « _Сейчас»_ служит фоновым изображением блока, значки дней расположены слева от каждой строки. Без значка « _Сейчас»_ блок имеет градиент от серого к тёмному. Виджет обрезает всё, что не помещается: при размере по умолчанию 250 x 107 пикселей видна только верхняя часть, поэтому сделайте виджет таким высоким, каким вы хотите его отобразить.

**Погодные условия.** Если какое-либо условие относится к одному из известных погодных терминов (`Cloudy`, `Rain`, `Wolkig`, `Regen`, `Облачно` (…) на любом языке текст отображается на языке виджета. Любой другой текст отображается точно так, как его предоставляет адаптер.

| Параметр         | Атрибут       | По умолчанию | Описание                                                                     |
| ---------------- | ------------- | ------------ | ---------------------------------------------------------------------------- |
| Город            | `city`        |              | Над температурой указано имя, написанное заглавными буквами.                 |
| Язык             | `language`    | как вис      | Язык, используемый для обозначения дней недели, месяцев, надписей и условий. |
| единицы скорости | `units_speed` | `km/h`       | Применяется к скорости ветра.                                                |

**Группа «Сейчас»** — сегодня и текущая погода:

| Параметр                                      | Атрибут                                          | Описание                                                 |
| --------------------------------------------- | ------------------------------------------------ | -------------------------------------------------------- |
| Идентификатор температуры                     | `temperature-0-oid`                              | Текущая температура.                                     |
| Идентификатор состояния                       | `condition-0-oid`                                | Текущая погода в текстовом виде.                         |
| Идентификатор влажности                       | `humidity-0-oid`                                 | Влажность в %.                                           |
| Минимальная/максимальная заданная температура | `temperature-min-0-oid` /`temperature-max-0-oid` | Минимальное и максимальное значение на сегодняшний день. |
| Определение скорости ветра                    | `wind-speed-0-oid`                               | Скорость ветра. Без неё не будет линии ветра.            |
| Определение направления ветра                 | `wind-dir-0-oid`                                 | Направление в градусах (0 = север) или в текстовом виде. |
| Идентификатор URL-адреса значка               | `icon-0-oid`                                     | Состояние, содержащее URL-адрес изображения.             |

**Группы «Завтра», «Послезавтра», «Через 3 дня» ... «Через 6 дней»** — прогноз, обозначающий названия дней. `1` = завтра ... `6`):

| Параметр                                      | Атрибут                                          | Описание                     |
| --------------------------------------------- | ------------------------------------------------ | ---------------------------- |
| Идентификатор состояния                       | `condition-1-oid`                                | Погодные условия в тот день. |
| Минимальная/максимальная заданная температура | `temperature-min-1-oid` /`temperature-max-1-oid` | Температура в тот день.      |
| Идентификатор URL-адреса значка               | `icon-1-oid`                                     | URL изображения за тот день. |

Прогноз заканчивается в первый день, когда нет ни температуры, ни погодных условий. Строки для значений, которые не заданы, опускаются. Вместо идентификатора объекта каждое поле также принимает привязку, например: `{weather.0.current.temp}`.

## Часы в формате SVG - `tplSvgClock`

![Часы в формате SVG](../../../../../en/adapterref/iobroker.vis-timeandweather/docs/img/svg-clock.png)

Аналоговые часы, нарисованные в формате SVG. Масштабируются до любого размера, линии сохраняют свою ширину в пикселях. Редактор сохраняет квадратную форму виджета.

| Параметр                  | Атрибут          | По умолчанию | Описание                                                               |
| ------------------------- | ---------------- | ------------ | ---------------------------------------------------------------------- |
| Четверть размера текста   | `quadSize`       | 60           | Размер чисел 12, 3, 6 и 9 относительно часов, состоящих из 900 единиц. |
| Цвет текста на четверть   | `quadColor`      | `#333`       | Цвет этих чисел.                                                       |
| Цвет четверти галочки     | `quadTickColor`  | `#333`       | Цвет отметок на отметке каждые пять минут.                             |
| Размер текста минут       | `textSize`       | 30           | Размер минутных цифр 0, 5, 10, ... за пределами кольца.                |
| Цвет текста протокола     | `textColor`      | `#555`       | Цвет минутных цифр.                                                    |
| Малый цвет клещей         | `tickColor`      | `#555`       | Цвет остальных клещей.                                                 |
| Показать подержанные вещи | `isSeconds`      | выключенный  | Показана секундная стрелка.                                            |
| Цвет рук                  | `handsColor`     | `#111`       | Цвет часовой и минутной стрелок.                                       |
| Цвет рук выпуклость       | `handsColorLine` | `#666`       | Цвет линии внутри ладоней.                                             |
| Цвет вторичного рынка     | `handsSecColor`  | `#be5639`    | Только на _Show, бывшие в употреблении_ .                              |
| Шрифт текста              | `textFont`       | Вердана      | Шрифт для всех чисел.                                                  |

Размер по умолчанию: 100 x 100 пикселей.

## Сегментные часы - `tplSegmentClock`

![Сегментные часы](../../../../../en/adapterref/iobroker.vis-timeandweather/docs/img/segment-clock.png)

Дисплей с 7, 14 или 16 сегментами на символ, как на радиочасах. Он отображает в следующем порядке:

1. значение _идентификатора объекта_ , если оно задано.
2. В противном случае используется _текст_ , если он задан.
3. В противном случае — время, если _функция «Включить часы»_ включена.
4. в противном случае `no oid, no text, no clock`.

Размеры экрана масштабируются под размер виджета и сохраняют свои пропорции: _высота цифры_ , _ширина цифры_ и другие размеры являются относительными, а не пикселями. Буквы отображаются настолько, насколько позволяют сегменты; 7 сегментов отображают только цифры и несколько букв, 16 сегментов — почти все. Верхний и нижний регистр выглядят одинаково.

**Группа «Общий»**

| Параметр              | Атрибут | По умолчанию | Описание                                                   |
| --------------------- | ------- | ------------ | ---------------------------------------------------------- |
| Идентификатор объекта | `oid`   |              | Состояние, значение которого указано.                      |
| Текст                 | `text`  |              | Фиксированный текст. Только без _идентификатора объекта_ . |

**Групповые часы**

| Параметр         | Атрибут   | По умолчанию | Описание                                                                                                                                          |
| ---------------- | --------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Включить часы    | `clock`   | на           | Отображает время, если не указаны ни _идентификатор объекта_ , ни _текст_ .                                                                       |
| Показать секунды | `seconds` | на           | `hh:mm:ss` вместо `hh:mm` Если он выключен и установлен шаблон по умолчанию. `##:##:##`, виджет использует `##:##` - также для значения или текста. |

**Группа «Стиль»**

| Параметр                         | Атрибут                     | По умолчанию         | Описание                                                                                                                                                                                                                                    |
| -------------------------------- | --------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Размер по умолчанию: 100 x 30 пикселей.

## Отличия от vis-1

Виджеты vis-2 не используют jQuery и ни одну из библиотек vis-1 (CoolClock, FlipClock.js, zWeatherFeed, segment-display.js). Отрисовка CoolClock и сегментного дисплея перенесена без изменений. Проекты переносятся без изменений. Некоторые детали работают по-другому:

- **Языки:** названия дней недели, месяцев и погоды присутствуют на всех языках vis-2. vis-1 знал только английский, немецкий и русский языки и демонстрировал `undefined` для других языков.
- **Погодные условия:** переводятся только точные термины, относящиеся к погоде. vis-1 также принимал термины, содержащие только текст, и показывал `Rain` _Смешанный дождь и снег_ , без осадков, как _при торнадо_ .
- **Погода:** значения, которые не заданы, не оставляют пустых строк, например `High: ° Low: °` Значки Yahoo!, которые vis-1 использовал в качестве запасного варианта вместо отсутствующего значка, исчезли, как и сам сервис.
- **Погода:** группы дней прогноза названы правильно. В vis-1 день через три дня был обозначен как _«Через 2 дня»_ .
- **SimpleDate:** Английские порядковые числительные корректно отображают 21-е, 22-е, 23-е и 31-е числа, также с ведущим нулем.
- **Часы в формате SVG:** несколько часов на одном изображении могут иметь разные цвета делений. В vis-1 все часы получили цвета первого из них.
- **CoolClock и Segment Clock:** четкое изображение на экранах высокого разрешения.
- Виджеты **HtcWeather** и **YahooWeather** из vis-1 недоступны, поскольку необходимый для них сервис погоды Yahoo! был отключен. Вместо них используйте _WeatherCustom_ с состояниями адаптера погоды.
