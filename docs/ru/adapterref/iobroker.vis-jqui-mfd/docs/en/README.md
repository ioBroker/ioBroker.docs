# jqui-mfd виджеты для vis-2

Виджеты jqui-mfd представляют собой 27 кнопок с иконками из [набора OpenAutomation](https://github.com/OpenAutomationProject/knx-uf-iconset) для освещения, розеток, жалюзи, навесов, клапанов, окон, дверей, отопления и камер. Многие из них открывают диалоговое окно для управления устройством. На этой странице описывается версия **vis-2** . vis (vis-1) имеет те же виджеты с теми же настройками.

## Общий

### Требования и миграция

Виджеты находятся в наборе виджетов **jQuery UI MFD** в списке виджетов редактора vis-2. Для их работы требуется **vis-2 версии 2.12.8** или новее.

Проекты, созданные с помощью vis-1, продолжают работать без изменений. Обе версии используют одни и те же идентификаторы виджетов. `tplMfdLight`, `tplMfdShutterDialog`, ...) и те же названия атрибутов, а vis-2 автоматически выбирает версию React. Все настройки сохраняются.

В таблицах ниже **«Setting»** — это метка в редакторе vis-2, а **«Attribute»** — это имя, хранящееся в проекте. Используйте имя атрибута при редактировании проекта в формате JSON или при копировании настроек между виджетами.

### тема vis-2 или внешний вид vis-1

![Тема vis-2, светлая](../../../../../en/adapterref/iobroker.vis-jqui-mfd/docs/img/mui-light.png)

![Тема vis-2, темная](../../../../../en/adapterref/iobroker.vis-jqui-mfd/docs/img/mui-dark.png)

| Параметр   | Атрибут | По умолчанию       | Описание                                                                                                                                                                                                                                                                                     |
| ---------- | ------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| тема vis-2 | `mui`   | на (новые виджеты) | Отображает виджет в цветах темы vis-2: кнопка представляет собой поверхность темы, при нажатии на неё принимается основной цвет, иконка — цвет текста. Диалоговые окна используют те же цвета. Выкл.: внешний вид jQuery UI из темы vis-1, см. [ниже](#the-button-and-the-jquery-ui-theme) . |

Для каждого виджета, созданного в vis-2, эта опция включена, и он следует теме vis-2 — светлой, темной или любой другой. Виджеты, созданные в vis-1, а также виджеты, созданные с помощью более старой версии этого адаптера, **не имеют для этой опции значения** и сохраняют внешний вид vis-1, поэтому существующий проект не изменяется. Редактор отображает такое отсутствующее значение как значение по умолчанию, отмеченное галочкой, и выделяет поле красным: снимите галочку и поставьте галочку, чтобы переключить виджет на тему vis-2.

С темой оформления vis-2:

- Иконки принимают цвет текста темы — темный в светлой теме, белый в темной. При нажатии кнопки они принимают цвет текста основного цвета; без _прямоугольника кнопки_ виджет, который включен или открыт, отображает свою иконку основным цветом. Всегда используется настроенный _цвет иконки_ .
- _Функция инвертирования значка_ не нужна; оставьте её выключенной.
- Тема jQuery UI для данного представления не влияет на эти виджеты.

### Кнопка и тема jQuery UI

Каждый виджет представляет собой иконку на кнопке. В режиме vis-1 ( _тема vis-2_ отключена или не задана) кнопка отрисовывается с помощью **темы jQuery UI представления** (настройки представления, _Тема_ ), точно так же, как и в vis-1: виджет имеет соответствующие классы. `ui-widget ui-button ui-corner-all ui-state-default` Тема оформления определяет цвета, градиент и углы. Измените тему, и все кнопки изменятся вместе с ней.

| Редмонд                              | ui-lightness                                   | темный улей                                | ui-darkness                                  |
| ------------------------------------ | ---------------------------------------------- | ------------------------------------------ | -------------------------------------------- |
| ![Редмонд](../img/theme-redmond.png) | ![ui-lightness](../img/theme-ui-lightness.png) | ![темный улей](../img/theme-dark-hive.png) | ![ui-darkness](../../../../../en/adapterref/iobroker.vis-jqui-mfd/docs/img/theme-ui-darkness.png) |

Значки белые. В светлой теме оформления, например, как _у Microsoft,_ включите функцию **инвертирования значков** или выберите **цвет значков** .

![Параметры кнопки](../../../../../en/adapterref/iobroker.vis-jqui-mfd/docs/img/button-options.png)

| Параметр             | Атрибут       | По умолчанию | Описание                                                                                  |
| -------------------- | ------------- | ------------ | ----------------------------------------------------------------------------------------- |
| Прямоугольная кнопка | `asButton`    | на           | Отображает кнопку — в теме jQuery UI или в теме vis-2. Выкл.: отображается только иконка. |
| Инвертировать значок | `invert_icon` | выключенный  | Инвертирует значок: белый становится чёрным.                                              |

**Нажата и зависает.** Кнопка отображается как нажатая (`ui-state-active`) Пока устройство включено или открыто — лампа загорается, розетка подключена, окно открыто. Виджеты, реагирующие на щелчок, также подсвечиваются под курсором мыши. `ui-state-hover` В таблицах виджетов отображается информация о нажатии на виджет.

К кнопке добавляется CSS-класс, указанный в общих настройках виджета, поэтому ваши собственные правила CSS продолжают работать.

### Значки и цвета значков

Иконки представляют собой SVG-изображения и сохраняют четкость при любом размере виджета. Размер виджета по умолчанию составляет 76 x 76 пикселей. Лампа, ставни, жалюзи и клапан — это вовсе не изображения: они отрисованы с учетом точного значения, поэтому 37% действительно отображает 37%.

![Цвета иконок](../../../../../en/adapterref/iobroker.vis-jqui-mfd/docs/img/icon-colors.png)

| Параметр                            | Атрибут                       | Описание                                                                                                                                                                                                                                              |
| ----------------------------------- | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Цвет значка                         | `iconColor`                   | Например, цвет значка. `#e17009` или `orange` Пусто: белый.                                                                                                                                                                                             |
| Цвет значка 0% ... Цвет значка 100% | `iconColor0`... `iconColor10` | Цвета виджетов, отображающих значение (свет, ставни, клапан, жалюзи), каждый для диапазона значений: `iconColor0` ниже 10%, `iconColor1` от 10%, ..., `iconColor10` В _Max_ — шаги обработки изображений vis-1. Пустой элемент принимает _цвет значка_ . |

Белый цвет иконки заменяется другим цветом. Ваши собственные иконки также можно раскрасить, если это SVG-изображения, нарисованные белым цветом. Другие изображения (PNG, JPG) отображаются как есть.

### Значения, введенные в редакторе

_Минимальное_ и _максимальное_ значения, а также значения состояний ( _значение для «ОТКРЫТО»_ , _значение для «ВКЛ._ » и т. д.) вводятся в виде текста. Виджеты преобразуют их следующим образом:

| Введенный текст        | Значение                          |
| ---------------------- | --------------------------------- |
| `true` /`false`        | логический `true` /`false`         |
| `0`, `1`, `42.5`, ... | число                             |
| что-нибудь еще         | текст в том виде, в каком он есть |
| (пустой)               | значение по умолчанию             |

Значение состояния и заданное значение сравниваются приблизительно: `1`, `"1"` и `true` Они одинаковые.

### Диалоги

Виджеты с _приставкой "+ dialog"_ в названии открывают диалоговое окно при щелчке. Диалоговое окно занимает всё пространство экрана, его можно перемещать за заголовок, и оно закрывается нажатием кнопки **"x"** , клавиши **Escape** или — если настроено — автоматически. Оно использует цвета темы vis-2 — при отключенной _теме vis-2_ виджет имеет свой собственный светлый или тёмный вид. В редакторе диалоговые окна не открываются, щелчок по виджету выделяет его.

Пусто: идентификатор объекта (камеры: без заголовка).                                                                                                                                                        |

**В диалоговых окнах выбора значений** (диммер, жалюзи, шторы, клапан, Custom10, отопление) имеется ряд кнопок для фиксированных значений, ползунок и строка со значением:

## Свет/Диммер, Выключатель света, Диммер + диалог

`tplMfdLight`, `tplMfdLightCtrl`, `tplMfdLightDialog`

Лампа отображает яркость без ступенчатого изменения: при уровне ниже 1% она выключена, при уровне выше этого значения лучи загораются один за другим по часовой стрелке снизу слева — каждые 10% один луч добавляется, а промежуточный увеличивается.

![Легкие шаги](../../../../../en/adapterref/iobroker.vis-jqui-mfd/docs/img/light-steps.png)

- **Свет/Диммер** (`tplMfdLight`) отображает только состояние.
- **Выключатель света** (`tplMfdLightCtrl` Переключение происходит по щелчку мыши: от _Min_ к _Max_ , от _Max_ к _Min_ . Значение между ними переходит от Min к _Max (_ от середины диапазона вверх) и от _Max к Max (_ ниже него). Без _Min_ и _Max_ переключение происходит между ними. `false` и `true` (число: к `0` от 0,5 и выше, до `1` (см. ниже). **Для регулировки яркости от 0 до 100 введите _Min_ = 0 и _Max_ = 100.**
- **Диммер + диалог** (`tplMfdLightDialog` Открывается диалоговое окно с диапазоном значений: _выключено / 25% / 50% / 75% / 100%,_ а также ползунок от _Min_ до _Max_ с шагом 1%.

| Параметр                                                | Атрибут                       | По умолчанию | Описание                                                                                                             |
| ------------------------------------------------------- | ----------------------------- | ------------ | -------------------------------------------------------------------------------------------------------------------- |
| Идентификатор объекта                                   | `oid`                         |              | Состояние лампы. `true` считается как _Макс_ , `false` как _Мин_ .                                                     |
| Мин / Макс                                              | `min` /`max`                  | 0 / 100      | Диапазон значений. В выключателе света они используются в качестве значений включения/выключения, см. выше.          |
| Инвертировать значок, Прямоугольник кнопки, Цвет значка |                               |              | См. [Общие положения](#general) .                                                                                    |
| Цвет значка 0% ... 100%                                 | `iconColor0`... `iconColor10` |              | Цвет для каждых 10% диапазона. `iconColor0` также для выключенной лампы.                                              |
| Идентификатор рабочего объекта                          | `oid-working`                 |              | Диммер + диалоговое окно (см. [Диалоговые окна](#dialogs) ).                                                         |
| Настройки диалога                                       |                               | 470 x 210    | Диммер + диалоговое окно (см. [Диалоговые окна](#dialogs) , разделы _«Показать значение»_ и _«Единицы измерения»_ ). |

Кнопка нажимается, когда значение превышает _Min_ . Под курсором мыши загораются выключатель света и диммер.

Кнопка нажимается, когда розетка подключена.

**Выключатель розетки** (`tplMfdSocketCtrl` Переключается по нажатию, как выключатель света: между _Min_ и _Max_ , или между `false` и `true` без них. Подсветка появляется под курсором мыши. Группа **«Управление»** заменяет это другими действиями:

| Параметр                                             | Атрибут                         | Описание                                                                                                                                                                            |
| ---------------------------------------------------- | ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| URL для включения / URL для выключения               | `urlTrue` /`urlFalse`           | Эти URL-адреса вызываются при включении или выключении. Их вызывает сервер ioBroker, а не браузер. Пустой _URL для выключения_ : URL для включения.                                 |
| Идентификатор объекта для включения / для выключения | `oidTrue` /`oidFalse`           | Эти объекты записываются при включении или выключении, вместо идентификатора объекта. Пустой _идентификатор объекта для выключенного состояния_ : объект для включенного состояния. |
| Значение для ВКЛ / Значение для ВЫКЛ                 | `oidTrueValue` /`oidFalseValue` | Записанные в них значения. Пусто: _Максимальное значение_ или `true`, _Незначительный_ `false`.                                                                                     |

При использовании URL-адресов или объектов для включения/выключения и **без** идентификатора объекта виджет запоминает свое состояние самостоятельно — после перезагрузки страницы он начинается с выключенного состояния.

## Отличия от vis-1

Виджеты React ведут себя аналогично виджетам vis-1. Вот основные отличия:

- **Тема vis-2.** Новые виджеты следуют теме vis-2 вместо темы jQuery UI (см. [тему vis-2 или внешний вид vis-1)](#vis-2-theme-or-vis-1-look) . Виджеты из vis-1 сохраняют свой внешний вид до тех пор, пока не будет включена _тема vis-2_ .

- **Диалоговые окна jQuery UI больше не используются.** Теперь у диалоговых окон собственный дизайн, соответствующий светлой и темной теме vis-2. Их можно перемещать, закрывать с помощью _клавиши Escape_ , а щелчок по темной области модального окна закрывает его. Они не открываются в редакторе.

- **Ползунок записывает значение один раз** , после чего отпускает его. vis-1 отправлял значение для каждого шага во время перемещения ползунка.

- **Автоматическое закрытие 0 означает выключение.** vis-1 закрыл диалоговое окно через одну секунду при значении 0.

- **Рабочий идентификатор объекта работает.** vis-1 считал неверный атрибут и проигнорировал его.

- **Лампа, ставень, жалюзи и клапан отображаются с точным значением,** а не с одним из одиннадцати (жалюзи: пять) изображений — при 37% больше не отображается изображение 30%. При 10%, 20%, ... отображается изображение vis-1. Цвета по-прежнему меняются с шагом vis-1.

- **Цвета иконок распространяются на каждую иконку.** vis-1 не раскрашивал иконки с помощью `fill` Атрибуты, например, выключенная лампа, полностью исчезли, а при задании цвета иконка в формате PNG стала полностью недоступной. Теперь иконки всегда в формате SVG.

- **Отображение активного фона** жалюзи, штор, клапана и Custom10 сравнивается с _Max_ виджета. vis-1 по сравнению с 1, поэтому жалюзи с диапазоном от 0 до 100 нажимались почти всегда.

- **Переключатель розетки:** при нажатии _состояние инвертируется,_ как и у значка. Без идентификатора объекта меняется и значок, а не только кнопка.

- **Окно с поворотным регулятором:** отображаются собственные значки для каждого состояния. vis-1 предложил их, но проигнорировал.

- **Кнопки диалогового окна** с логическим состоянием подсвечиваются: `true` соответствует кнопке со значением `true` или `1`.

- **Значение для включения/выключения** выключателя розетки: пустое значение. Запись _Max_ / _Min_ . vis-1 записала пустой текст.

- **Нагрев, как показано в тексте.** `--` вместо `NaN` при этом не имея никакой ценности.

- Версии, _полученные из объекта_ снимка и камеры MJPEG, больше не предоставляют _URL-адрес_ . В vis-1 это не имело никакого эффекта.
