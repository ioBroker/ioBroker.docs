# Датчики / Устройства

Каждый датчик или устройство передает огромное количество информации. В ioBroker вы видите всю информацию о состоянии, которую также можно увидеть в приложении Lupusec. В ioBroker есть та же функциональность, что и в приложении Lupusec, для управления такими устройствами, как переключатели, реле, жалюзи и т.д. Однако изменить настройки датчиков и устройств Lupusec в ioBroker невозможно. Технически это возможно, но я думаю, что пока это не имеет смысла.

## Общая информация

Все датчики и устройства обладают следующими состояниями.

| состояние   | описания                                                                                                                                            | чтение/запись |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| область     | зона системы сигнализации                                                                                                                           | читать        |
| battery\_ok | Состояние будет ложным, если батарея датчика разряжена или находится в низком состоянии.                                                            | читать        |
| объезд      | Это действие позволяет активировать или деактивировать функцию обхода выбранного датчика. Данное действие применимо только к датчикам сигнализации. | читать        |
| cond\_ok    | Состояние датчика в порядке.                                                                                                                        | читать        |
| имя         | название датчика                                                                                                                                    | чтение/запись |
| rssi        | Значение уровня принимаемого сигнала. Индикация датчика.                                                                                            | читать        |
| tamper\_ok  | Несанкционированное вмешательство в контакт допустимо. Это действие может быть применено только к датчикам сигнализации.                            | читать        |
| тип         | тип датчика как число                                                                                                                               | читать        |
| type\_name  | тип датчика в текстовом виде                                                                                                                        | читать        |
| зона        | сенсорная зона                                                                                                                                      | читать        |
