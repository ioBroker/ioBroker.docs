# ioBroker.openmeteo-notify

**Тесты:**![Тестирование и выпуск](https://github.com/ipod86/ioBroker.openmeteo-notify/workflows/Test%20and%20Release/badge.svg)

## Адаптер ioBroker для прогнозов погоды Open-Meteo

Этот адаптер получает данные прогноза погоды из бесплатного [API Open-Meteo](https://open-meteo.com) и предоставляет их в виде точек данных ioBroker. Ключ API не требуется. Он отправляет индивидуальные уведомления о настраиваемых погодных событиях (штормы, грозы, официальные предупреждения) и предоставляет несколько независимо настраиваемых HTML-виджетов для каждого местоположения.

## Основные моменты

### Уведомления о погоде через менеджер уведомлений ioBroker

Адаптер отправляет индивидуальные уведомления о настраиваемых погодных событиях — предупреждениях о штормах, оповещениях о грозах и официальных предупреждениях национальных метеорологических служб (DWD для Германии, MeteoAlarm для Европы). Все адреса уведомлений (Telegram, электронная почта, Pushover и т. д.) настраиваются централизованно через **менеджер уведомлений ioBroker** — отдельная настройка для каждого адаптера не требуется.

### Настраиваемый HTML-виджет

Адаптер генерирует готовую к использованию точку данных в формате HTML (`widget` ), который можно встроить непосредственно в VIS, vis-2 или любую панель управления ioBroker — без использования внешних инструментов или ручного CSS. Тема (светлая/темная), прозрачность фона, прозрачность карточки, размер шрифта и цвет карточки — все это можно настроить непосредственно в параметрах адаптера.

### Анимированные обои/заставка с изображением погоды

Адаптер генерирует автономные анимированные обои с погодными условиями для каждого местоположения — полноэкранную анимацию на холсте (дождь, снег, туман, молния, солнечные блики, звезды), управляемую реальными текущими погодными условиями, а не вручную, что идеально подходит в качестве заставки для планшета, крепящейся на стену, или фона для приборной панели/дисплея.

- **Реальные погодные эффекты** — направление/скорость ветра влияют на перенос осадков и тумана, количество осадков масштабируется в зависимости от интенсивности частиц, положение Солнца и Луны (и фаза Луны) соответствуют реальным астрономическим данным (SunCalc) для заданного местоположения.
- **Официальный предупреждающий баннер** — активные предупреждения DWD/MeteoAlarm отображаются в виде настраиваемого текстового баннера, элементы наложения, которые могут столкнуться с препятствием, автоматически смещаются в сторону.
- **Для каждого местоположения используется собственное фоновое изображение** — по умолчанию устанавливается фотография, которую можно заменить в любое время через Администрирование → Файлы, при этом файл называется в соответствии с местоположением.
- **Самообновление без REST API** — загружает небольшой сопутствующий JSON-файл из той же папки, полная перезагрузка страницы не требуется.
- **Дополнительная функция карусели местоположений** — переключение между несколькими настроенными местоположениями с помощью стрелок влево/вправо.
- **Независимый интервал обновления в реальном времени** — обновляется только информация о текущих условиях и обои (0/5/10/15/30 мин), отдельно от основного интервала обновления прогноза.
- Настраивается через специальную **вкладку «Обои» в административной панели** (положение, цвета, размеры шрифтов, часы, предупреждения) с предварительным просмотром в реальном времени, имитирующим распространенные разрешения экрана.
- Доступен напрямую по URL-адресу для каждого экземпляра веб-сайта (`current.wallpaper_url_<instance>` ) — привязка VIS не требуется

### Поиск по адресу в полном тексте

Местоположение не обязательно вводить в виде прямых координат. В пользовательском интерфейсе настроек доступен **поиск по адресу в свободной текстовой форме** — просто введите город, адрес или регион, и координаты будут определены автоматически. Для каждого местоположения отображается предварительный просмотр в OpenStreetMap. Можно настроить несколько местоположений одновременно.

### Прогноз на срок до 16 дней

В зависимости от выбранной метеорологической модели, доступны ежедневные прогнозы на срок до **16 дней** — значительно больше, чем типичные 5–7 дней у большинства адаптеров.

### Сводные тексты о погоде

Адаптер генерирует сводки погоды на естественном языке.`current.summary` ,`dayX.summary_day` ,`dayX.summary_night` ) на **11 языках** , с использованием стандартных пороговых значений DWD для температуры, ветра и осадков, включая риск гроз на основе CAPE.

## Функции

- **Бесплатно и без ключа API** – Open-Meteo — это бесплатный API для прогноза погоды с открытым исходным кодом.
- **Несколько местоположений** — настройте столько местоположений, сколько вам нужно, для каждого из которых будет доступен поиск адреса и предварительный просмотр карты.
- **Резервный вариант определения местоположения системы** — использует координаты системы ioBroker, если местоположение не указано.
- **Настраиваемый диапазон прогноза** – до 16 дней в сутки, до 16 дней в час.
- **Настраиваемый интервал обновления** – 60 мин, 120 мин или ежедневно в 01:00.
- **Единицы измерения** : температура (°C / °F), скорость ветра (км/ч, м/с, миль/ч, узлов), количество осадков (мм / дюйм).
- **5 наборов иконок погоды** с предварительным просмотром в реальном времени в настройках:
  - Метеоконтраст от Баса Милиуса – статический PNG (по умолчанию)
  - Метеоконтансы от Баса Милиуса – анимированный SVG-файл
  - Анимированные иконки погоды amCharts в формате SVG _(дождь/снег/гром: нет варианта день/ночь)_
  - Иконки погоды amCharts – статический SVG _(дождь/снег/гроза: нет варианта день/ночь)_
  - Метеорологические символы ВМО OGC – Папуа-Новая Гвинея
- **Значки дня/ночи** – значки Meteocons и amCharts с прозрачной/облачной погодой переключаются на ночные варианты в зависимости от погоды.`is_day`
- **Направление ветра** – градусы, текст компаса (С/СВ/В/…), эмодзи стрелки (⬆️↗️…), иконка стрелки в формате SVG.
- **Сила ветра** – шкала Бофорта (0–12) с иконками Бофорта от Meteocons.
- **`info.lastUpdate`** – метка времени последнего успешного обновления

### Дополнительные группы данных (переключаемые индивидуально, каждая с опцией "также почасовая")

| Группа                                        | По умолчанию | Точки данных                                                                                                                                                     |
| --------------------------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Качество воздуха**                          | на           | european\_aqi, PM10, PM2.5, NO₂, CO, dust, ozone →`current.air_quality` /`hXX.air_quality`                                                                       |
| **Астрономия**                                | на           | восход солнца, закат солнца, солнечный полдень, максимальная высота солнца над горизонтом, фаза луны, восход луны, закат луны →`dayX.astronomy` /`hXX.astronomy` |
| **Сельское хозяйство / Солнечная энергетика** | выключенный  | солнечное излучение, CAPE, температура почвы, освещенность →`*.agriculture`                                                                                      |
| **Индексы комфорта**                          | выключенный  | индекс жары, ветровое охлаждение, индекс влажности, УФ-индекс →`*.comfort`                                                                                       |
| **Пыльца**                                    | выключенный  | ольха, береза, трава, полынь, олива, амброзия с текстом разного уровня →`dayX.pollen` /`hXX.pollen`                                                              |
| **Предупреждения DWD**                        | выключенный  | Официальные предупреждения Deutscher Wetterdienst (только для Германии) →`location.warnings.*`                                                                   |

Когда группа отключена, каналы с данными, относящиеся к ней, автоматически удаляются при следующем обновлении.

### Официальные предупреждения о погоде

Адаптер интегрирует официальные предупреждения о погоде от национальных метеорологических служб. Включите их с помощью переключателя **«Официальные предупреждения о погоде»** . Служба выбирается автоматически на основе координат местоположения:

| Страна        | Услуга                                             | Покрытие                                                        |
| ------------- | -------------------------------------------------- | --------------------------------------------------------------- |
| Германия (DE) | [DWD](https://www.dwd.de) – Deutscher Wetterdienst | Все типы предупреждений, 4 уровня серьезности                   |
| страны ЕС     | [Метеосигнал](https://www.meteoalarm.org)          | Все типы предупреждений, сопоставление на основе полигонов.     |
| Другой        | —                                                  | Недоступно (используйте рассчитанные предупреждения Open-Meteo) |

Предупреждения хранятся в`location.warnings.*` независимо от источника. А`warnings.source` точка данных показывает`"DWD"` или`"MeteoAlarm"` .

## Установка

Установите через административный интерфейс ioBroker (найдите "openmeteo-notify").

## Отказ от ответственности

Этот адаптер использует данные из следующих сторонних сервисов:

- **[Open-Meteo](https://open-meteo.com)** – данные прогноза погоды. Название и логотип Open-Meteo являются собственностью соответствующих владельцев.
- **[DWD](https://www.dwd.de)** (Deutscher Wetterdienst) – официальные предупреждения о погоде для Германии. Название и данные DWD являются собственностью Deutscher Wetterdienst.
- **[MeteoAlarm](https://www.meteoalarm.org)** – официальные метеорологические предупреждения для европейских стран. Название и данные MeteoAlarm являются собственностью соответствующих владельцев.

Этот адаптер является независимым проектом сообщества и не связан ни с одним из вышеперечисленных сервисов и не поддерживается ими.
