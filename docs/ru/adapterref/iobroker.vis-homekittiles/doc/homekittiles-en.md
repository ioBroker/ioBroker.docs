## 🇺🇸 HomeKit-Tiles для ioBroker-VIS

Homekit Tiles — это набор виджетов, основанный на дизайне Apple HomeKit. Особенность виджетов заключается в том, что они не содержат элементов с фиксированным стилем, а всё форматируется с помощью CSS. В результате в редакторе VIS нет отдельных настроек для положения и/или размера значков, подписей и т. д. Дизайн корректируется путем изменения CSS-кода. Для этого используется CSS-код из файла`/widgets/homekittiles/css/style.css` Может использоваться в качестве шаблона. Код вставляется во вкладку CSS в редакторе VIS и может быть настроен по желанию. Также можно добавить собственные CSS-классы через редактор VIS в разделе «Общие» виджетов.

Эти виджеты разработаны для VIS 1.x.

**Примечание:** По лицензионным причинам в этот адаптер не включены значки. Хорошие источники значков:

- <https://www.flaticon.com>
- <https://icons8.com>

## Типы виджетов

### hkt-Уведомление

<img src="/doc/img/hkt-Notification.png" width="120" />

Функция уведомлений позволяет отображать оповещения (подобно красным пузырькам в мобильных приложениях) и размещать их в любом месте. Она идеально подходит для использования в сочетании с кнопкой навигации, чтобы указывать на сбои/ошибки/важную информацию на соответствующем экране. Поддерживается 5 точек данных, а также 5 различных цветов для уведомлений. Вы можете использовать флажки, чтобы выбрать, следует ли отображать уведомления вместе с соответствующим значением.`0` .

### hkt-Радиокнопки

<img src="/doc/img/hkt-Radiobuttons.png" height="100" />

Переключатели (радиокнопки) в основном используются для переключения предопределенных значений состояния. Расположение кнопок (рядом друг с другом или одна под другой) не происходит автоматически, а должно быть указано с помощью флажка. Количество кнопок можно установить по мере необходимости, а значения, которые должны быть записаны в состояние, можно свободно выбрать. Кроме того, каждую кнопку можно снабдить меткой и/или значком. Дополнительные функции:

- **Подтвержденное изменение:** отображает значок, если флаг подтверждения состояния не установлен (=неподтвержденное изменение). Логику можно изменить, используя флажок, чтобы значок появлялся, когда флаг подтверждения установлен (=подтвержденное изменение). С помощью другого флажка значок может вращаться постоянно (класс CSS).`spin` (добавлено). Значок подтверждения (Ack) добавляется к каждой кнопке в исходном коде, но в прилагаемом исходном коде он отображается только на активной кнопке.

### hkt-Switch-Bool

<img src="/doc/img/hkt-Switch-Bool.png" height="120" />

Виджет Switch-Bool служит простым переключателем включения/выключения для состояний определённого типа.`boolean` и отображает иконку. Она содержит две группы меток и блокировку операций, которые работают следующим образом с помощью прилагаемого CSS-кода:

- **Группа меток 1:** отображается внизу виджета. «Метка» (строка 1) — это фиксированный текст. Вторая строка может быть определена с помощью «Метки 2» и состоять из нескольких элементов (вводный статический текст, значение точки данных, единица измерения значения (добавляется к значению без пробелов), дополнительный текст в конце).
- **Группа меток 2:** отображается в правом верхнем углу виджета и может содержать до 3 дополнительных элементов информации, настраиваемых аналогично «Метки 2». В зависимости от размера виджета пространство ограничено, но вполне достаточно для отображения технической информации (например, «U: 230V, P: 12W»).
- **Кнопка «Приращение значения»** отображается в правом верхнем углу виджета и содержит две дополнительные кнопки с надписями (+) и (-). Нажатием этих кнопок можно увеличить или уменьшить значение любого состояния. Это идеально подходит, например, для изменения заданного значения, отображаемого в группе меток 1.
- **Блокировка работы:** Эта настройка позволяет предотвратить работу виджета, если значение состояния равно нулю.`true` или`false` Таким образом, например, устройство с этим виджетом можно только выключить, но не включить (или наоборот). Активировав оба флажка, можно полностью предотвратить работу виджета, и он будет служить только для отображения состояния. При желании, при блокировке работы может отображаться дополнительный значок. «Блокировка работы» также влияет на «Значение приращения».
- **Подтвержденное изменение:** отображает значок, если флаг подтверждения состояния не установлен (=неподтвержденное изменение). Логику можно изменить, используя флажок, чтобы значок появлялся, когда флаг подтверждения установлен (=подтвержденное изменение). С помощью другого флажка значок может вращаться постоянно (класс CSS).`spin` добавлено).

**Примечание:** приведенный CSS-код не позволяет одновременно использовать «Группу меток 2», «Увеличение значения», «Операцию блокировки» и «Подтвержденное изменение». Однако это возможно путем расширения виджета и/или адаптации кода.

### hkt-ViewInWidget-Dialog

<img src="/doc/img/hkt-ViewInWidget-Dialog.png" height="120" />

Виджет открывает диалоговое окно, отображающее другой вид. У диалогового окна нет собственной кнопки закрытия. Её необходимо вставить в отображаемый вид. При открытии и закрытии можно установить любое состояние; значения, которые записываются, можно свободно выбирать. Однако обратите внимание, что значение устанавливается только при закрытии диалогового окна с помощью кнопки закрытия диалогового окна, но не при полной перезагрузке виджета.

Приведённый CSS-код работает следующим образом:

Вторая строка может быть определена с помощью «Метки 2» и состоять из нескольких элементов (вводный статический текст, значение точки данных, единица измерения значения (добавляется к значению без пробелов), дополнительный текст в конце).

- **Диалог:** определяет свойства диалогового окна. Свойства «Высота диалогового окна» и «Ширина диалогового окна» относятся к содержимому отображаемого представления. Заголовок добавляется к общей высоте. С помощью свойства «Показать стрелку в диалоговом окне» можно добавить стрелку к краю диалогового окна, создавая впечатление речевого пузыря.

### hkt-Button-DialogClose

<img src="/doc/img/hkt-Button-DialogClose.png" height="50px" />

### hkt-Button-Set

<img src="/doc/img/hkt-Button-Set.png" height="50px" />

Этот виджет создает регулируемое количество кнопок, при этом каждая кнопка может управлять своим собственным состоянием. Для каждой кнопки можно задать отображаемое значение. При активации флажка «Закрыть диалоговое окно» диалоговое окно, в котором он размещен, будет закрыто при нажатии кнопки. Виджет также можно разместить вне диалогового окна, но тогда функция «Закрыть диалоговое окно» будет недоступна.

### hkt-Button-Set-Navigation

<img src="/doc/img/hkt-Button-Set-Navigation.png" height="30px" />

Виджет создает регулируемое количество кнопок для навигации между различными представлениями. С помощью прилагаемого CSS-кода можно переключать расположение кнопок между горизонтальным и вертикальным с помощью флажка. При горизонтальном расположении ширина каждой кнопки устанавливается на 120 пикселей; при вертикальном расположении высота каждой кнопки устанавливается на 30 пикселей.

### hkt-ViewInWidget-Swipe

Этот виджет представляет собой контейнер для дочерних представлений, переключение между которыми осуществляется прокруткой. С помощью прилагаемого CSS-кода достаточно переместить в видимую область только часть дочернего представления, а функция привязки к прокрутке позаботится об остальном.
