# Установите ioBroker

ioBroker — это сервер. Он работает круглосуточно, ожидает событий и управляет устройствами — даже когда им никто не пользуется. Поэтому установка сводится к двум решениям: **где** он должен работать и **как** его следует установить.

В этой главе рассматриваются оба варианта по порядку.

## Путь через эту главу

1. [Требования](/docs/install/requirements.md) — что должна иметь система: оперативная память, место на диске, операционная система.
2. [Аппаратное обеспечение](/docs/install/hardware.md) — какое устройство подходит именно вам и каких подводных камней следует избегать.
3. Сама установка зависит от выбранного метода (см. ниже).
4. [Обновление](/docs/install/update.md) — это то, что необходимо будет регулярно делать в дальнейшем.

**Для начала: Linux без каких-либо промежуточных слоев.** Debian, Ubuntu или Raspberry Pi OS в серверной версии, с установочным скриптом поверх них. Каждый дополнительный слой — Docker, виртуализация — вносит свои особенности, которые могут стать препятствием на пути к решению проблемы в случае ошибки. Миграция всегда возможна позже; резервную копию можно перенести с любого из этих путей на любой другой.

## Команда установки

Во всех системах Linux используется одна и та же команда:

```bash
curl -sLf https://iobroker.net/install.sh | bash -
```

Программа загружает недостающие пакеты, устанавливает подходящую версию Node.js и выполняет настройку пользователя.`iobroker` Он подключает и настраивает сервис. Предварительная установка Node.js вручную **не** требуется.

Скрипт будет запускаться от имени **обычного пользователя** , а не от имени учетной записи пользователя.`root` а не с`sudo` Пользователь, от имени которого запускается система, управляет ею в дальнейшем. Подробности можно найти в разделе [Linux](/docs/install/linux.md) .

## Завершенные изображения

Для Raspberry Pi и некоторых одноплатных компьютеров раньше существовали готовые образы с предустановленным ioBroker. Сейчас они больше не поддерживаются — содержащиеся в них операционные системы уже много лет не имеют поддержки безопасности. В настоящее время используется следующий метод: самостоятельно установить актуальную операционную систему, а затем запустить скрипт установки.

## После установки

- [Административный интерфейс](/docs/admin/README.md) — структура администрирования.
- [Адаптеры и экземпляры](/docs/basics/adapter.md) — способы подключения устройств и сервисов.
- [Резервное копирование](/docs/config/backup.md) — создайте первое резервное копирование до начала первоначальной настройки.
