# Установите ioBroker

ioBroker — это сервер. Он работает круглосуточно, ожидает событий и управляет устройствами — даже когда им никто не пользуется. Поэтому при установке необходимо принять два решения: **после чего** ему следует бежать и **Как** Оно установлено там.

В этой главе рассматриваются оба варианта по порядку.

## Путь через эту главу

1. [Требования](/docs/install/requirements.md) — Что должна предоставлять система: оперативная память, место на диске, операционная система.
2. [Аппаратное обеспечение](/docs/install/hardware.md) - Какое устройство полезно и какие существуют недостатки.
3. Сама установка зависит от выбранного метода (см. ниже).
4. [Обновлять](/docs/install/update.md) — что необходимо будет делать регулярно в дальнейшем.

Миграция возможна в любое время позже; резервную копию можно перенести с одного из этих методов на другой.

## Команда установки

Во всех системах Linux используется одна и та же команда:

```bash
curl -sLf https://iobroker.net/install.sh | bash -
```

Программа загружает недостающие пакеты, устанавливает подходящую версию Node.js и выполняет настройку пользователя. `iobroker` Поэтому необходимо установить Node.js и настроить сервис. **нет**
Необходимо предварительно установить вручную.

!> Сценарий считается **обычный пользователь** выполнено, а не как `root` а не с `sudo`Пользователь, под чьей учетной записью работает система, управляет ею в дальнейшем. Подробности доступны по ссылке \[link/reference].
[Linux](/docs/install/linux.md).

## Завершенные изображения

Для Raspberry Pi и некоторых одноплатных компьютеров раньше существовали готовые образы с предустановленным ioBroker. Сейчас они больше не поддерживаются — содержащиеся в них операционные системы уже много лет не имеют поддержки безопасности. В настоящее время используется следующий метод: самостоятельно установить актуальную операционную систему, а затем запустить скрипт установки.
