# Обновить js-контроллер

js-контроллер — это ядро ioBroker: он поддерживает базы данных, запускает адаптеры и отслеживает их работу. Он обновляется редко — всего несколько раз в год — и поскольку от него зависит всё, этот этап необходимо подготовить заранее.

## Ранее

1. **Безопасный.** `iob stop`, `iob backup`, `iob start`Кроме того, делается снимок виртуальной системы.
2. **Сначала обновите адаптер.** Для более новых контроллеров JavaScript иногда требуются более новые адаптеры. См.
   [Обновить адаптер](/docs/install/updateadapter.md).
3. **Ознакомьтесь с изменениями.** При переходе на новую основную версию в список могут входить моменты, которые могут вызвать проблемы: требуемая версия Node.js, удаленная настройка.
4. **Планируйте соответственно.** Не непосредственно перед отъездом.

## Обновлять

Как только в репозитории появится новая версия, в панели администратора появится уведомление; обновление также можно инициировать там. В консоли:

```bash
iob update          # zeigt, welche Version das Repository führt
iob upgrade self    # aktualisiert den js-controller
```

Эта команда останавливает ioBroker во время процесса обновления и перезапускает его после этого.

?> `iob upgrade self` следует настроенному репозиторию. Если это приводит к...
**ниже** Также происходит понижение версии — это способ вернуться к предыдущей версии, если она вызывает проблемы, а также причина предварительно проверить репозиторий.

## Впоследствии

- Всё снова работает? _Пример_ Красных записей быть не должно.
- Прочитайте журнал за первые несколько минут. Сообщения об устаревших запросах обычно относятся к одному адаптеру, которому необходимо обновиться.
- `iob diag` Обобщает ситуацию и является основой каждого вопроса в
  [форум](https://forum.iobroker.net).

## Если что-то пойдет не так

Первый
[ioBroker больше не работает.](/docs/trouble/RunsNoMore.md) Наиболее распространенные причины перечислены там в порядке убывания. Если это не поможет, самым быстрым решением будет описанный ранее резервный метод:

```bash
iob restore <datei>
```
