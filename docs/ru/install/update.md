# Выполните обновления

Установка ioBroker состоит из трех слоев, которые обновляются отдельно. Такой порядок оказался эффективным:

|   | Что                                          | Как часто                                          |
| - | -------------------------------------------- | -------------------------------------------------- |
| 1 | [адаптер](/docs/install/updateadapter.md)    | часто — что-то случается каждую неделю             |
| 2 | [js-контроллер](/docs/install/updateself.md) | редко — несколько раз в год                        |
| 3 | [Node.js](/docs/install/updatenode.md)       | Редко — когда срок службы версии подходит к концу. |

Кроме того, существует сама операционная система, которая поставляется в соответствии со своими собственными правилами.`sudo apt update && sudo apt full-upgrade`).

## Перед каждым обновлением: делайте резервную копию.

Неудачное обновление без резервной копии может занять несколько дней. С резервной копией это займет полчаса.

```bash
iob stop
iob backup
iob start
```

Резервная копия сохраняется в виде ZIP-файла с указанием даты в соответствующей директории. `backups` В папке ioBroker. Те, у кого есть адаптер. _резервная копия_ Если всё идёт по плану, стоит проверить, действительно ли последняя резервная копия свежая и находится ли она вне устройства.

В виртуализированной системе наиболее удобным способом обеспечения безопасности является создание снимка состояния перед обновлением; в случае сомнений предыдущее состояние можно восстановить за минуту.

## Хронологический порядок

**Сначала адаптеры, затем js-контроллер.** Для новых js-контроллеров иногда требуются более новые адаптеры; обратное направление обеспечивает лучшую совместимость.

**Node.js использовался в последнюю очередь и исключительно по собственному желанию.** Наиболее значительным изменением является изменение основной версии Node.js. Для этого существуют свои предварительные требования, и этому посвящена отдельная страница:
[Обновите Node.js и npm.](/docs/install/updatenode.md).

**Не все в один вечер.** Если после трех одновременных обновлений что-то идет не так, причину трудно найти. Первый шаг — краткое наблюдение, затем следующий.

## Где отображаются обновления

В административной панели, в _адаптер_ Каждая запись показывает, доступна ли более новая версия в репозитории. Эта информация отображается в консоли.

```bash
iob update --updatable
```

Всё сразу, без каких-либо изменений.

## Стабильная и новейшая версия

Существует два репозитория. **Стабильный** включает версии, которые широко зарекомендовали себя; **Последний** В нём содержится всё, что доступно сразу после релиза. Для системы, требующей надёжной работы, подходит стабильная версия, а последняя — для тех, кто хочет находить и сообщать об ошибках. Подробнее по ссылке:
[Репозитории](/docs/basics/repositories.md).

## Если после обновления что-то зависло

- [ioBroker больше не работает.](/docs/trouble/RunsNoMore.md)
- [Ошибка адаптера](/docs/trouble/adapter.md)
- `iob diag` Сводная информация о состоянии: репозиторий, версия узла, состояние системы, последние записи в журнале.
