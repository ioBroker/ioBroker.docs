# Обновление и понижение версии адаптеров

Адаптеры — это та часть ioBroker, которая меняется чаще всего. Они обновляются по отдельности — нет смысла заменять их все сразу, и есть несколько веских причин против этого.

## В административной панели

В разделе _«Адаптер»_ для каждой записи отображается установленная версия и версия, доступная в репозитории. Если доступна более новая версия, появляется стрелка обновления. Нажатие на эту стрелку сначала отобразит изменения в новой версии — этот список стоит прочитать, так как он указывает, требуются ли в новой версии какие-либо функции или удаляются ли из нее.

Подробное описание управления адаптером можно найти в [руководстве по управлению адаптером](/docs/tutorial/adapter.md) .

## На консоли

```bash
iob update --updatable      # zeigt nur, was aktualisierbar ist - ändert nichts
iob upgrade <adapter>       # aktualisiert genau diesen Adapter
iob upgrade                 # aktualisiert alle Adapter (nicht den js-controller)
```

?>`iob update` **Это ничего не меняет** . Программа только считывает содержимое репозитория. Изменения вносятся только с помощью...`iob upgrade` .

## Понижение в должности

Иногда последняя версия нежелательна: либо потому, что в ней есть недостаток, либо потому, что требуется более старая версия, пока не появится другой адаптер.

`iob upgrade <adapter>` Устанавливает для адаптера версию, указанную в выбранном репозитории, — **даже если это более старая версия** . Репозиторий также можно указать непосредственно в команде:

```bash
iob upgrade <adapter> <repository-url>
```

То же самое автоматически происходит при переключении с _последней версии_ обратно на _стабильную_ .

Откат к предыдущей версии не является чистым возвратом к предыдущей. Точки данных и настройки, созданные более новой версией, сохраняются, и старая версия о них не знает. Поэтому перед откатом [обязательно сделайте резервную копию данных](/docs/install/update.md) и внимательно отслеживайте состояние системы после этого.

## Установить из GitHub

Если исправление ошибки еще не выпущено, адаптер можно установить непосредственно из исходного кода — в панели администратора через _функцию «Установить адаптер с пользовательского URL»_ в экспертном режиме.

Эти версии являются предварительными. Они **не** обновляются в рамках обычного процесса обновления и остаются активными до тех пор, пока вы не обновите их вручную. Такой подход не подходит для повседневного использования, однако он уместен для тестирования во вторичной среде.

## После обновления

- Экземпляр снова запущен? В разделе _«Экземпляры»_ должен отображаться зеленый индикатор.
- Есть ли что-нибудь в журнале? Предупреждения, появляющиеся сразу после обновления, чаще всего указывают на изменение настроек.
- Получаются ли значения? Достаточно беглого взгляда на объекты адаптера.
