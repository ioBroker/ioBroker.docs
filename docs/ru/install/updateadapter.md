# Обновление и понижение версии адаптеров

Адаптеры — это та часть ioBroker, которая меняется чаще всего. Они обновляются по отдельности — нет смысла обновлять их все сразу, и есть несколько веских причин против этого.

## В административной панели

Под _адаптер_ В каждой записи отображается установленная версия и версия, доступная в репозитории. Если доступна более новая версия, появляется стрелка обновления. Нажатие на эту стрелку сначала покажет изменения в новой версии — этот список стоит прочитать, так как он указывает, когда в версии требуются или удаляются новые функции.

Подробное описание управления адаптером можно найти в
[Руководство по управлению адаптерами](/docs/tutorial/adapter.md).

## На консоли

```bash
iob update --updatable      # zeigt nur, was aktualisierbar ist - ändert nichts
iob upgrade <adapter>       # aktualisiert genau diesen Adapter
iob upgrade                 # aktualisiert alle Adapter (nicht den js-controller)
```

?> `iob update` **Ничего не меняется**Программа считывает только содержимое репозитория. Изменения вносятся только при наличии... `iob upgrade`.

## Понижение в должности

Иногда последняя версия нежелательна: либо потому, что в ней есть недостаток, либо потому, что требуется более старая версия, пока не появится другой адаптер.

`iob upgrade <adapter>` Устанавливает для адаптера версию, которая находится в настроенном репозитории. **даже если это более низкий показатель**Репозиторий также можно указать напрямую с помощью команды:

```bash
iob upgrade <adapter> <repository-url>
```

При переключении с _Последний_ обратно к _Стабильный_ То же самое происходит автоматически.

Понижение версии не является чистым возвратом к предыдущей. Данные и настройки, созданные более новой версией, сохраняются, и старая версия о них не знает. Поэтому, прежде чем понижать версию...
[безопасный](/docs/install/update.md)а затем внимательно понаблюдайте за этим случаем.

## Установить из GitHub

Если исправление еще не выпущено, адаптер можно установить непосредственно из исходного кода — в панели администратора через _Установите адаптер по пользовательскому URL-адресу._ в экспертном режиме.

Такие версии являются предварительными. Они будут... **нет** Процесс обновления автоматически повторяется и остается в режиме ожидания до тех пор, пока не будет запущен вручную. Для повседневного использования такой подход не подходит, однако он уместен для тестирования во вторичной среде.

## После обновления

- Экземпляр снова запущен? _Пример_ Оно должно быть зелёным.
- Есть ли что-нибудь в журнале? Предупреждения, появляющиеся сразу после обновления, чаще всего указывают на изменение настроек.
- Получаются ли значения? Достаточно беглого взгляда на объекты адаптера.
