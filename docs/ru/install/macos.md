# ioBroker на macOS

ioBroker работает на macOS, потому что там используется Node.js. Однако это не тот способ, который предполагался для его непрерывной работы.

**Для надежной системы домашней автоматизации macOS — неподходящий выбор.** Скрипт установки, инструкции на форуме и инструменты устранения неполадок разработаны для Debian и его производных. Если у вас Mac, лучше использовать [Docker](/docs/install/docker.md) или виртуальную машину с Linux, чем устанавливать систему напрямую.

macOS полезна в двух целях: для экспериментов и для разработки адаптеров.

## Для экспериментов и разработок

Необходимым условием является наличие актуальной LTS-версии Node.js, которую проще всего получить через [Homebrew](https://brew.sh) или систему контроля версий, например...`nvm` Рекомендуемую версию можно найти в разделе [Node.js и npm](/docs/install/updatenode.md) .

Затем в отдельной директории:

```bash
mkdir iobroker && cd iobroker
npm install iobroker.js-controller
npx iobroker setup first
npx iobroker start
```

Интерфейс административного адаптера находится в следующем порядке:`http://localhost:8081` Доступно после установки и запуска:

```bash
npx iobroker add admin
```

?> The`iob` Ярлык создается не таким образом. Поэтому команды перенаправляются через...`npx iobroker ...` из каталога установки.

## Чего ожидать

- Адаптеры, использующие инструменты Linux или`systemd` Доступ невозможен или возможен лишь частично.
- Подключенное оборудование — беспроводные адаптеры, последовательные адаптеры — ведет себя по-разному в macOS и практически не освещается на форуме.
- Автоматический запуск при загрузке системы необходимо настраивать вручную.

## Лучший способ на Mac

Разработка собственного адаптера в любом случае не требует полной установки, а скорее...`dev-server` Эта программа создает инкапсулированную среду ioBroker ровно для одного адаптера. Для домашнего использования требуется выделенное энергоэффективное устройство под управлением Linux — см. [раздел «Оборудование»](/docs/install/hardware.md) .
