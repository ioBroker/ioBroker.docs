# ioBroker на macOS

ioBroker работает на macOS, потому что там используется Node.js. Однако это не тот способ, который предполагался для его непрерывной работы.

!> **Для системы домашней автоматизации, требующей надежной работы, macOS — неподходящий выбор.** Скрипт установки, инструкции на форуме и инструменты для устранения неполадок разработаны специально для Debian и его производных. Пользователи Mac могут продолжить...
[докер](/docs/install/docker.md) Использование виртуальной машины с Linux лучше, чем прямая установка операционной системы на компьютер.

macOS полезна в двух целях: для экспериментов и для разработки адаптеров.

## Для экспериментов и разработок

Для работы требуется актуальная LTS-версия Node.js, которую проще всего получить через \[ссылка на версию Node.js].
[Домашнее пиво](https://brew.sh) или система контроля версий, например `nvm`Рекомендуемую версию можно найти по ссылке \[link/section].
[Node.js и npm](/docs/install/updatenode.md).

Затем в отдельной директории:

```bash
mkdir iobroker && cd iobroker
npm install iobroker.js-controller
npx iobroker setup first
npx iobroker start
```

Интерфейс административного адаптера находится в следующем порядке:
`http://localhost:8081` Доступно после установки и запуска:

```bash
npx iobroker add admin
```

?> The `iob`Ярлык создается не таким образом. Поэтому команды перенаправляются через... `npx iobroker ...` из каталога установки.

## Чего ожидать

- Адаптеры, использующие инструменты Linux или `systemd` Доступ невозможен или возможен лишь частично.
- Подключенное оборудование — беспроводные адаптеры, последовательные адаптеры — ведет себя по-разному в macOS и практически не освещается на форуме.
- Автоматический запуск при загрузке системы необходимо настраивать вручную.

## Лучший способ на Mac

Разработка собственного адаптера в любом случае не требует полной установки, а скорее... `dev-server`, которая создает инкапсулированную среду ioBroker ровно для одного адаптера. Для домашнего использования это означает выделенное энергоэффективное устройство под управлением Linux — см.
[Аппаратное обеспечение](/docs/install/hardware.md).
