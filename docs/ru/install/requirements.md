# Системные требования

## Системные требования

| Операционная система                         | Варианты                                                      | Аппаратные среды (например)                                                                                   | Минимальные требования для ioBroker                           | Рекомендуемые ресурсы для ioBroker (2)                                |
| -------------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------- |
| [Дистрибутивы Linux](/docs/install/linux.md) | Рекомендация: Debian, включая соответствующие производные (1) | Raspberry Pi, одноплатный компьютер, мини-ПК (например, NUC), аппаратное обеспечение со средой виртуализации. | 2 ГБ оперативной памяти, 32 ГБ встроенной памяти              | >= 4 ГБ (лучше 6–8 ГБ) оперативной памяти, >= 64 ГБ встроенной памяти |
| [докер](/docs/install/docker.md)             |                                                               | Мини-ПК (например, NUC), NAS (3)                                                                              | 2 ГБ оперативной памяти, 32 ГБ встроенной памяти              | >= 4 ГБ (лучше 6–8 ГБ) оперативной памяти, >= 64 ГБ встроенной памяти |
| [Windows](/docs/install/windows.md)          |                                                               | ПК, мини-ПК (например, NUC)                                                                                   | 4 ГБ оперативной памяти, 50 ГБ встроенной памяти (включая ОС) | 8 ГБ оперативной памяти, 100 ГБ встроенной памяти (включая ОС)        |

(1) Рекомендуется устанавливать ioBroker на дистрибутивы Linux на основе Debian/Ubuntu (серверная версия без среды рабочего стола!). Установка на другие дистрибутивы Linux, как правило, возможна (при условии поддержки соответствующей версии Node.js), но требует специальных знаний, поскольку стандартные скрипты и инструкции по установке/обслуживанию адаптированы для Debian.

(2) Эти значения основаны на опыте типичной средней установки системы ioBroker с \~40 активными адаптерами, Grafana и внешней базой данных.

(3) Для установки на NAS применяются требования Docker, а также дополнительные ресурсы для собственных задач NAS.

### В целом

- ioBroker можно установить на все системы, где доступен Node.js.
- Требуемый объем оперативной памяти и хранилища увеличивается, если, например, данные сохраняются в истории (например, с помощью адаптера истории, который хранит текстовые файлы в системе) или если на этой системе дополнительно устанавливаются и запускаются базы данных, такие как InfluxDB, MySQL или другие приложения.
- При выборе оборудования обращайте внимание на его энергопотребление, поскольку ioBroker будет работать круглосуточно (24/7). Даже небольшая разница в потребляемой мощности со временем окупится.
