# Установка ioBroker на Linux

В системах Linux, включая Raspberry Pi, ioBroker устанавливается одной командой. Скрипт проверяет систему, загружает недостающие пакеты, устанавливает подходящую версию Node.js, создает службу и запускает ее.

Следовательно, Node.js должен **нет** Предварительно установка должна производиться вручную. Всем, кто уже это сделал, следует сначала ознакомиться со следующими инструкциями:
[Node.js](/docs/install/nodejs.md) Проверьте, какая версия разрешена.

## Проверьте заранее.

Достаточна ли аппаратная начинка и какие системы поддерживаются, можно узнать в разделе \[ссылка на раздел, содержащий информацию о поддерживаемых системах].
[Требования](/docs/install/requirements.md).

Пять основных причин сбоев в большинстве установок:

- **Не так `root` установить.** Сценарий описывается следующим образом: **обычный пользователь**
  выполнено без `sudo` До этого. Этот пользователь будет управлять системой позже. Он не должен. `iobroker` Это означает: скрипт создает этого пользователя самостоятельно.
- **Нет настольного компьютера.** Используйте серверную версию операционной системы. ioBroker работает круглосуточно и управляется через консоль; графический интерфейс потребляет только память.
- **Debian или Ubuntu.** Или что-то, что является его основой, например, Raspberry Pi OS или Armbian. Другие дистрибутивы часто работают, но о них мало кто знает на форуме.
- **В начале работы промежуточных смен нет.** Docker и Proxmox имеют своё место, но каждый дополнительный уровень инфраструктуры стоит между проблемой и решением в случае ошибки. Миграция всегда возможна позже с помощью резервной копии.
- **При использовании Raspberry Pi обратите внимание на блок питания.** Слабый источник питания, например, старое зарядное устройство для мобильного телефона, приводит к сбоям, которые выглядят как программные ошибки, но таковыми не являются.

## Установка

**1. Установите операционную систему.** и обновить:

```bash
sudo apt update && sudo apt full-upgrade
```

**2. Установите ioBroker:**

```bash
curl -sLf https://iobroker.net/install.sh | bash -
```

Отсутствующий `curl`Оно будет установлено заранее: `sudo apt install curl`.

Скрипт выполняется в четыре видимых шага и занимает несколько минут в зависимости от устройства:

```
Installing prerequisites (1/4)
Creating ioBroker user and directory (2/4)
Installing ioBroker (3/4)
Finalizing installation (4/4)
```

Итоговый результат:

```
ioBroker was installed successfully
Open http://localhost:8081 in a browser and start configuring!
```

**3. Получите доступ к интерфейсу.** С вашего компьютера под
`http://<adresse-des-servers>:8081`Адрес — это адрес компьютера ioBroker, а не... `localhost`если браузер запущен в другом месте.
