# Установка ioBroker на Linux

В системах Linux, включая Raspberry Pi, ioBroker устанавливается одной командой. Скрипт проверяет систему, загружает недостающие пакеты, устанавливает подходящую версию Node.js, создает службу и запускает ее.

Предварительная установка Node.js вручную **не** требуется. Однако тем, кто уже установил Node.js, следует обратиться к документации [Node.js](/docs/install/nodejs.md) , чтобы определить, какая версия совместима.

## Проверьте заранее.

Информация о достаточности оборудования и поддерживаемых системах содержится в разделе [«Требования»](/docs/install/requirements.md) .

Пять основных причин сбоев в большинстве установок:

- **Не так`root` Установите.** Скрипт будет запускаться от имени **обычного пользователя** без каких-либо изменений.`sudo` До этого. Этот пользователь будет управлять системой позже. Он не должен.`iobroker` Это означает: скрипт создает этого пользователя самостоятельно.
- **Нет настольной версии.** Используйте серверную версию операционной системы. ioBroker работает круглосуточно и управляется через консоль; графический интерфейс только потребляет память.
- **Debian или Ubuntu.** Или что-то на их основе, например, Raspberry Pi OS или Armbian. Другие дистрибутивы тоже часто работают, но о них мало кто знает на форуме.
- **В начале нет промежуточного слоя.** Docker и Proxmox имеют своё место, но каждый дополнительный слой стоит между проблемой и решением в случае ошибки. Миграция всегда возможна позже с помощью резервной копии.
- **При использовании Raspberry Pi обращайте внимание на блок питания.** Слабый блок питания, например, от старого зарядного устройства для мобильного телефона, может вызывать сбои, которые выглядят как программные ошибки, но таковыми не являются.

## Установка

**1. Установите операционную систему** и обновите её до последней версии:

```bash
sudo apt update && sudo apt full-upgrade
```

**2. Установите ioBroker:**

```bash
curl -sLf https://iobroker.net/install.sh | bash -
```

Отсутствующий`curl` Оно будет установлено заранее:`sudo apt install curl` .

Скрипт выполняется в четыре видимых шага и занимает несколько минут в зависимости от устройства:

```
Installing prerequisites (1/4)
Creating ioBroker user and directory (2/4)
Installing ioBroker (3/4)
Finalizing installation (4/4)
```

Итоговый результат:

```
ioBroker was installed successfully
Open http://localhost:8081 in a browser and start configuring!
```

**3. Получите доступ к интерфейсу.** Со своего компьютера по адресу:`http://<adresse-des-servers>:8081` Адрес — это адрес компьютера ioBroker, а не...`localhost` если браузер запущен в другом месте.

## После установки

Команда`iobroker` Доступно только после **нового входа в систему** . Те, что появляются сразу после установки.`iobroker` Если при вводе команды вы видите сообщение «команда не найдена», выйдите из системы и войдите снова. Также работает более короткий вариант.`iob` .
