# Блокли

Blockly — это графический редактор: логика собирается из строительных блоков, которые просто встают на свои места. Как только вы связали триггер с действием, вы написали работающую программу, не набрав ни одной строчки кода.

Blockly является частью
[JavaScript-адаптер](/adapters/javascript)Новый скрипт типа _Блокли_ находится в административной панели. _Сценарии_ созданный.

## Как устроен скрипт Blockly

Практически каждый сценарий начинается с **курок** И зависит от того, что должно произойти. Наиболее распространенным триггером является изменение состояния, вторым по распространенности — время суток.

Скрипт может иметь несколько триггеров. Компоненты, находящиеся вне триггера, выполняются ровно один раз: при запуске скрипта. Обычно это место для ввода начальных значений.

## Группы строительных блоков

Палитра слева отсортирована по задачам. Основные группы:

| группа                                         | За что                                                                               |
| ---------------------------------------------- | ------------------------------------------------------------------------------------ |
| Курок                                          | Триггеры: изменение состояния, расписания, астрономические события, такие как закат. |
| Системные блоки                                | Чтение и запись состояний, создание объектов, запрос состояний                       |
| Блоки действий                                 | Вывод логов, HTTP-запросы, команды операционной системы, электронная почта           |
| SendTo                                         | Сообщения другим адаптерам, таким как Telegram, Pushover или Signal.                 |
| Тайм-ауты                                      | Задержки, повторяющееся исполнение, отмены                                           |
| Дата и время                                   | Сравнивать и форматировать временные точки, создавать разности во времени.           |
| Конвертация                                    | Преобразование текста в число, число в текст, округление, форматы времени            |
| Логика, циклы, математика, текст, списки, цвет | Обычные программные блоки                                                            |
| Переменные и функции                           | Промежуточные значения и настраиваемые, многократно используемые блоки.              |

Полное описание каждого отдельного компонента можно найти в

## Самый важный компонент: спусковой механизм.

Блок запуска для состояний запрашивает три параметра: **какое условие**,
**после чего** Необходимо дать ответ, и **Когда**.

В случае с «что», различие между _изменение_ и _обновлять_
Важно отметить, что обновление происходит каждый раз, когда адаптер записывает значение — даже если оно остается неизменным. Изменение происходит только в том случае, если значение действительно отличается. Датчик температуры, который сообщает одно и то же значение каждые 30 секунд, запускает обновление, если... _обновлять_ 2880 раз в день и в
_изменение_ только если изменится температура.

Триггер также различает **ack = false** (команда устройству) и **ack = true** (обратная связь от устройства). Любой, кто реагирует на оба типа обратной связи, создает петли обратной связи. Как правило: реагируйте на обратную связь (`ack = true`) react, команды (`ack = false`Отправьте это сами.

## От строительного блока к коду

Вкладка над рабочей областью отображает сгенерированный JavaScript-код для каждого скрипта Blockly. Это не просто рекламный трюк:

- В случае появления сообщения об ошибке в журнале отображается номер строки сгенерированного кода, а не номер компонента.
- Любой, кто захочет продолжить работу над скриптом Blockly на JavaScript, получит шаблон. Обратное невозможно — JavaScript нельзя использовать для создания строительных блоков.

## Когда Блокли перестаёт носить

Блокли становится неудобным в использовании, как только

- Эту же цепочку пришлось бы повторить для десяти ламп.
- Данные хранятся в списках или таблицах.
- Рабочее пространство можно просмотреть только при сильном увеличении.

Затем переход к
[JavaScript](/docs/logic/javascript.md)
Срок выполнения. Нет необходимости полностью переносить скрипт: скрипты Blockly и JavaScript-скрипты работают параллельно и обмениваются информацией о своем состоянии.
