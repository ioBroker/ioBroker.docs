# Блокли

Blockly — это графический редактор: логика собирается из строительных блоков, которые просто встают на свои места. Как только вы связали триггер с действием, вы написали работающую программу, не набрав ни одной строчки кода.

Blockly является частью [JavaScript-адаптера](/adapters/javascript) . Новый скрипт _Blockly_ создается в разделе «Администрирование» в подразделе _«Скрипты»_ .

## Как устроен скрипт Blockly

Практически каждый скрипт начинается с **триггера** , за которым следует описание того, что должно произойти. Наиболее распространенным триггером является изменение состояния, вторым по распространенности — изменение времени.

Скрипт может иметь несколько триггеров. Компоненты, находящиеся вне триггера, выполняются ровно один раз: при запуске скрипта. Обычно это место для ввода начальных значений.

## Группы строительных блоков

Палитра слева отсортирована по задачам. Основные группы:

| группа                                         | За что                                                                               |
| ---------------------------------------------- | ------------------------------------------------------------------------------------ |
| Курок                                          | Триггеры: изменение состояния, расписания, астрономические события, такие как закат. |
| Системные блоки                                | Чтение и запись состояний, создание объектов, запрос состояний                       |
| Блоки действий                                 | Вывод логов, HTTP-запросы, команды операционной системы, электронная почта           |
| SendTo                                         | Сообщения другим адаптерам, таким как Telegram, Pushover или Signal.                 |
| Тайм-ауты                                      | Задержки, повторяющееся исполнение, отмены                                           |
| Дата и время                                   | Сравнивать и форматировать временные точки, создавать разности во времени.           |
| Конвертация                                    | Преобразование текста в число, число в текст, округление, форматы времени            |
| Логика, циклы, математика, текст, списки, цвет | Обычные программные блоки                                                            |
| Переменные и функции                           | Промежуточные значения и настраиваемые, многократно используемые блоки.              |

Полное описание каждого отдельного компонента можно найти в [справочнике Blockly для JavaScript-адаптера](/adapters/javascript) .

## Самый важный компонент: спусковой механизм.

Блок запуска состояний запрашивает три параметра: **какое состояние выбрать** , на **что** реагировать и **когда** .

В контексте вопроса «что» различие между _изменением_ и _обновлением_ имеет решающее значение. Обновление происходит каждый раз, когда адаптер записывает значение — даже если оно остается неизменным. Изменение происходит только тогда, когда значение действительно отличается. Датчик температуры, который сообщает одно и то же значение каждые 30 секунд, сработает 2880 раз в день, если это _обновление_ , и только когда температура изменится, если это _изменение_ .

Триггер также различает **ack = false** (команда устройству) и **ack = true** (ответ устройства). Реагирование на оба варианта создает петли обратной связи. Как правило, следует реагировать на обратную связь (`ack = true` ) react, команды (`ack = false` Отправьте это сами.

## От строительного блока к коду

Вкладка над рабочей областью отображает сгенерированный JavaScript-код для каждого скрипта Blockly. Это не просто рекламный трюк:

- В случае появления сообщения об ошибке в журнале отображается номер строки сгенерированного кода, а не номер компонента.
- Любой, кто захочет продолжить работу над скриптом Blockly на JavaScript, получит шаблон. Обратное невозможно — JavaScript нельзя использовать для создания строительных блоков.

## Когда Блокли перестаёт носить

Блокли становится неудобным в использовании, как только

- Эту же цепочку пришлось бы повторить для десяти ламп.
- Данные хранятся в списках или таблицах.
- Рабочее пространство можно просмотреть только при сильном увеличении.

Затем настало время переключиться на [JavaScript](/docs/logic/javascript.md) . Полностью переходить на JavaScript не обязательно: скрипты Blockly и JavaScript работают параллельно и обмениваются информацией о своем состоянии.

## Помощь в строительстве

Адаптер JavaScript включает в себя генератор кода ИИ, который также может генерировать скрипты Blockly. Для его работы требуется доступ к языковой модели, которая настраивается в параметрах экземпляра; помимо OpenAI, можно использовать и другие провайдеры, а также локально размещенные модели. Процесс настройки описан в [документации к адаптеру](/adapters/javascript) .

Сгенерированный код является рекомендацией, а не результатом. Его следует прочитать и протестировать в тестовом экземпляре, прежде чем развертывать в системе отопления.
