# Системные интеграторы

Те, кто профессионально использует ioBroker и создает системы для клиентов, задают другие вопросы, чем те, кто автоматизирует свой собственный дом. Дело не в разных технологиях, а в других ограничениях: несколько систем вместо одной, незнакомые сети, гарантии и люди, которые не пишут на форумах, когда что-то идет не так, а звонят.

В этой главе собраны дополнительные моменты, которые следует учитывать. Сама методика описана в других главах.

## Что доказало свою эффективность на практике

**Создавайте каждую систему одинаковым образом.** Та же версия операционной системы, та же версия Node.js, тот же набор адаптеров, те же названия комнат и функций. Систему, которая выглядит как любая другая, можно поддерживать по телефону.
[Категории](/docs/basics/enums.md) Они важнее, чем кажется: на них основаны визуализация и голосовое управление.

**Проверка безопасности перед передачей объекта.** меблированный
[резервное копирование данных](/docs/config/backup.md)
Наличие цели за пределами спортивного комплекса — это часть усилий, а не новогоднее обещание. Это разница между половиной рабочего дня и целой неделей работы.

**Отдельные входы.** Клиент получает собственную учетную запись пользователя с необходимыми правами, а не учетную запись администратора. Инструкции по настройке можно найти по адресу \[ссылка/название раздела].
[Управление доступом](/docs/config/userrights.md)
и
[аутентификация](/docs/config/login.md).

**Открытый порт отсутствует.** Для внешнего доступа маршрут проходит через
[адаптер для Интернета вещей](/docs/cloud/iot.md) или предоставляется VPN-решение. Переадресация портов на систему клиента сопряжена с риском юридической ответственности.

**Замороженные версии.** В системе клиента репозиторий находится в
_стабильны&#x439;_&#x43D;е на _бет&#x430;_&#x438; уж точно не адаптер с GitHub. См.
[Репозитории](/docs/basics/repositories.md).

## Более крупные объекты

Когда система достигает пределов возможностей компьютера, есть два варианта корректировки:

- [Редис](/docs/config/redis.md) для базы данных статусов, когда большое количество значений очень часто меняется.
- [Многохостовый](/docs/config/multihost.md)для распределения задач между несколькими компьютерами, например, когда устройство необходимо подключить в определенном месте.

Многохостовый режим распределяет нагрузку, но это делает систему... **нет** Система защиты от сбоев. Если компьютер с базами данных выйдет из строя, всё остановится.

## Лицензия и гарантия

ioBroker — это программное обеспечение с открытым исходным кодом, бесплатное для использования. Однако существуют ограничения на коммерческое использование, которые следует уточнить перед началом первого проекта с клиентом: **Для этого требуется платная лицензия vis-2.**&#x42D;то относится к использованию в проектах заказчиков, в предоставлении услуг, а также к эксплуатации компаниями, органами власти или другими учреждениями. Подробную информацию можно найти по ссылке \[link/reference]. [Лицензии адаптера](/docs/licenses/adapter.md).

Данное руководство не является подходящим источником информации по вопросам ответственности и гарантии.
