# Блок ссылок

Link-Box — это VPN-решение, позволяющее получить доступ к системам без открытия порта в их сети. Оно предназначено для пользователей, управляющих несколькими установками в разных местах.

## Строительство

Решение состоит из трех частей:

| Часть               | Где он бегает                                                                     |
| ------------------- | --------------------------------------------------------------------------------- |
| **Облачный сервер** | На дежурстве. Выступаю посредником между обеими сторонами.                        |
| **блок ссылок**     | На компьютере пользователя, использующего операционную систему Windows или Linux. |
| **адаптер**         | В системе, к которой осуществляется доступ.                                       |

Обе стороны налаживают связь. **изнутри наружу** к серверу. Это означает, что ничего не нужно открывать ни в сети клиента, ни в его собственной сети. Конфигурация адаптера определяет, какие соединения разрешены; все остальное остается закрытым.

Для доступа требуется учетная запись. [ioBroker.pro](https://iobroker.pro) заранее.

## Демаркация

|                   | Блок ссылок                      | [адаптер для Интернета вещей](/docs/cloud/iot.md) |
| ----------------- | -------------------------------- | ------------------------------------------------- |
| Предназначено для | Управление несколькими объектами | Доступ к вашей собственной системе                |
| Проникает сквозь  | Любые связи                      | Пользовательские интерфейсы и голосовые помощники |
| Целевая аудитория | Интеграторы                      | пользователь                                      |

Для удалённого доступа к вашей собственной установке более простым вариантом будет IoT-адаптер. Link Box стоит приобрести, если вы регулярно подключаетесь к внешним сетям и вам требуется нечто большее, чем просто веб-интерфейс.
