# Адреса и услуги

С ioBroker связано несколько интернет-адресов. Некоторые из них — это веб-сайты, другие же используются вашей системой в фоновом режиме. На этой странице указана категория каждого адреса, чтобы было понятно, куда ведет клик или соединение.

## Два основных адреса

| адрес            | За что                                                                                                                                                                                 |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **iobroker.net** | Этот веб-сайт предоставляет документацию, обзор адаптера, статистику и файлы для скачивания. Здесь также размещен бесплатный аккаунт, используемый для управления лицензиями адаптера. |
| **iobroker.pro** | Платный облачный сервис. Удаленный доступ, голосовые помощники, уведомления. Управление лицензиями доступа осуществляется там.                                                         |

Эти два аккаунта являются отдельными. Подробную информацию о том, какой аккаунт к какому аккаунту относится, можно найти в разделе [«Лицензии»](/docs/licenses/README.md) .

## Форум

**forum.iobroker.net** — это центральный ресурс для вопросов, сообщений об ошибках и объявлений о проектах. Как эффективно задавать вопросы на форуме, объясняется в разделе [«Как задавать вопросы на форуме»](/docs/trouble/forum.md) .

## Что ваша система получает в фоновом режиме

Работающая система ioBroker взаимодействует самостоятельно с несколькими адресами. Все они безвредны, но в закрытой сети их необходимо знать.

| адрес                     | По какой причине                                                                                                                                                                                          |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **download.iobroker.net** | Список адаптеров. Оттуда администратор получает _стабильные_ и _бета-_ репозитории, то есть информацию о том, какие адаптеры существуют в какой версии. См. [Репозитории](/docs/basics/repositories.md) . |
| **registry.npmjs.org**    | Сами адаптеры. Установка осуществляется через npm, поэтому программный код берется оттуда, а не из ioBroker.                                                                                              |
| **github.com**            | Только если адаптер установлен из отдельного источника или если в экземпляре используется версия для разработчиков.                                                                                       |
| **iobroker.org**          | Получает анонимную статистику использования, если эта функция включена. См. раздел [«Статистика использования»](/docs/ecosystem/statistics.md) .                                                          |
| **iobroker.live**         | Предоставляет небольшие графические элементы состояния ( _значки_ ), отображающие текущий статус версии в описаниях адаптеров.                                                                            |

После запуска облачного сервиса устанавливается соединение с **iobroker.pro** . Это позволяет создать экземпляр изнутри, поэтому настраивать порты в маршрутизаторе не требуется.

## Инструменты для разработчиков

Эти адреса размещены на **iobroker.in** . Они используются вручную в браузере, а не вашей установкой.

| адрес                           | По какой причине                                                                                                                                                                          |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **adapter-creator.iobroker.in** | Создает базовую структуру нового адаптера. См. [рекомендации](/docs/dev/bestpractices.md) .                                                                                               |
| **adapter-check.iobroker.in**   | Перед публикацией проверьте репозиторий адаптера на наличие распространенных ошибок. См. [раздел «Публикация адаптеров»](/docs/dev/adapterpublish.md) .                                   |
| **translator.iobroker.in**      | Переводит текст адаптера на поддерживаемые языки.                                                                                                                                         |
| **weblate.iobroker.net**        | Платформа для перевода проекта. Тексты из основного кода и адаптеров хранятся там без необходимости знания программирования. См. раздел [«Принять участие»](/docs/community/project.md) . |

## Если адрес недоступен

Если администратор не может получить доступ к списку адаптеров, вкладка _«Адаптеры»_ останется пустой или будет отображать устаревшие версии. Это почти всегда проблема с именованием или сетью, а не ошибка в ioBroker. Поэтому первым делом нужно проверить, не является ли это ошибкой.`download.iobroker.net` Эта проблема решается на компьютере ioBroker. Дополнительную информацию можно найти в разделе [«Проблемы с адаптером»](/docs/trouble/adapter.md) .
