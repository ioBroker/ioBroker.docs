# Адреса и услуги

С ioBroker связано несколько интернет-адресов. Некоторые из них — это веб-сайты, другие же используются вашей системой в фоновом режиме. На этой странице указана категория каждого адреса, чтобы было понятно, куда ведет клик или соединение.

## Два основных адреса

| адрес            | За что                                                                                                                                                                                 |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **iobroker.net** | Этот веб-сайт предоставляет документацию, обзор адаптера, статистику и файлы для скачивания. Здесь также размещен бесплатный аккаунт, используемый для управления лицензиями адаптера. |
| **iobroker.pro** | Платный облачный сервис. Удаленный доступ, голосовые помощники, уведомления. Управление лицензиями доступа осуществляется там.                                                         |

Эти два аккаунта являются отдельными. Подробную информацию о том, какой аккаунт к какому аккаунту относится, можно найти по ссылке \[название ссылки/раздела].
[Лицензии](/docs/licenses/README.md).

## Что ваша система получает в фоновом режиме

Работающая система ioBroker взаимодействует самостоятельно с несколькими адресами. Все они безвредны, но в закрытой сети их необходимо знать.

| адрес                     | По какой причине                                                                                                                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **download.iobroker.net** | Список адаптеров. Администратор получает оттуда репозитории. _стабильный_ и _бета_, то есть информация о том, какие адаптеры доступны в какой версии. См. [Репозитории](/docs/basics/repositories.md). |
| **registry.npmjs.org**    | Сами адаптеры. Установка осуществляется через npm, поэтому программный код берется оттуда, а не из ioBroker.                                                                                           |
| **github.com**            | Только если адаптер установлен из отдельного источника или если в экземпляре используется версия для разработчиков.                                                                                    |
| **iobroker.org**          | Получает анонимную статистику использования, если эта функция включена. См. [Статистика использования](/docs/ecosystem/statistics.md).                                                                 |
| **iobroker.live**         | Предоставляет небольшие графики состояния (_Значки_), которые отображают текущий статус версии в описаниях адаптеров.                                                                                  |

После того, как облачный сервис будет запущен, соединение с **iobroker.pro** Это означает, что экземпляр создается изнутри наружу, поэтому в маршрутизаторе не нужно создавать порты.

## Инструменты для разработчиков

Эти адреса работают в рамках **iobroker.in**Они используются вручную в браузере, а не вашей установкой.

| адрес                           | По какой причине                                                                                                                                                            |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **adapter-creator.iobroker.in** | Создаёт базовую структуру нового адаптера. См. [Рекомендации](/docs/dev/bestpractices.md).                                                                                  |
| **adapter-check.iobroker.in**   | Перед публикацией проверьте репозиторий адаптера на наличие распространенных ошибок. См. [публиковать адаптеры](/docs/dev/adapterpublish.md).                               |
| **translator.iobroker.in**      | Переводит текст адаптера на поддерживаемые языки.                                                                                                                           |
| **weblate.iobroker.net**        | Платформа для перевода проекта. Тексты из основного кода и адаптеров хранятся там без необходимости знания программирования. См. [Участвовать](/docs/community/project.md). |

## Если адрес недоступен

Если администратор не может получить доступ к списку адаптеров, вкладка остается активной. _адаптер_ Если файл пуст или отображает устаревшие версии, это почти всегда проблема с именованием или сетью, а не ошибка в ioBroker. Поэтому первая проверка заключается в том, чтобы убедиться, что...
`download.iobroker.net` Как это решается компьютером ioBroker. Дополнительная информация по адресу: [Проблемы с адаптером](/docs/trouble/adapter.md).
