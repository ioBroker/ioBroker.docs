# Разработка с использованием dev-сервера.

Худший способ разработки адаптера — это создание его на собственной системе домашней автоматизации. Каждая неудачная попытка парализует работающую систему, каждое изменение необходимо загружать в систему, а приостановка работы адаптера в отладчике означает, что в это время ничего не контролируется.

Он **dev-сервер** Это решает проблему. Он устанавливает отдельную небольшую версию ioBroker в папку проекта, которая распознает только этот один адаптер. У нее есть собственная административная панель, собственный каталог, собственные объекты, и она ни с чем не конфликтует.

## Меблировать

dev-сервер запускается в папке адаптера, то есть там, где...
`io-package.json` ложь.

```bash
npm install --global @iobroker/dev-server
dev-server setup
```

В процессе установки загружаются js-контроллер и административная панель, которые помещаются в подпапку. `.dev-server` В первый раз это занимает несколько минут, но потом — уже нет.

Полезная информация для настройки:

- `--adminPort <nummer>`: на случай, если настройка по умолчанию конфликтует с чем-либо еще.
- `--jsController <version>` и `--admin <version>`: разрабатывать для конкретной версии, например, для самой старой, которую должен поддерживать адаптер.
- `--backupFile <datei>`Это позволяет настроить среду на основе резервной копии ioBroker. Это дает возможность воспроизвести ошибку, о которой сообщил пользователь.

Папка `.dev-server` принадлежит к `.gitignore`В фреймворке, созданном с помощью Adapter Creator, это уже есть.

## Работа

| команда             | Эффект                                                                                                                                                |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dev-server watch`  | С этого все начинается и **Перезапускает адаптер при каждом изменении кода**Это нормальный ход событий в процессе разработки.                         |
| `dev-server run`    | Запускает среду, но оставляет адаптер работающим. Это позволяет работать с интерфейсом конфигурации.                                                  |
| `dev-server debug`  | Запустите адаптер таким образом, чтобы отладчик мог подключиться. `--wait` Он ждёт прибытия отладчика.                                                |
| `dev-server upload` | Передает текущее состояние в окружающую среду. Необходимо после изменений в... `io-package.json`, потому что он считывается только во время загрузки. |
| `dev-server update` | Обновляет js-контроллер и административную панель среды.                                                                                              |

Журнал событий отображается в терминале. Это позволяет сразу увидеть, что делает ваш сетевой адаптер, без необходимости искать журнал в панели администратора.

!> После изменения в `io-package.json` Одной перезагрузки недостаточно.
`dev-server upload` Вводит в среду новые объекты экземпляра, измененные параметры конфигурации или новый режим работы.

## Множественные среды

С **Профили** Можно запускать несколько сред одновременно, например, одну с самой старой поддерживаемой версией js-контроллера, а другую — с самой новой.

```bash
dev-server profile
```

Эта команда отображает список существующих профилей. Остальные команды принимают имя профиля и затем работают в этой среде.

## Требования и ограничения

Сервер разработки работает на Windows, Linux и macOS и требует как минимум Node.js 14. Все открываемые им порты подключены к сети. `127.0.0.1` Ограниченный доступ означает, что территория недоступна снаружи.

Это не заменяет собой реальное тестирование на исправной системе. Зато заменяет необходимость двадцатикратной загрузки данных между проверками.

## Остальная часть ящика с инструментами

Помимо сервера разработки, `@iobroker/adapter-dev` в проект. Он предоставляет скрипты для перевода и создания:

```bash
npm run translate          # übersetzt neue englische Texte in alle Sprachen
npm run build              # baut TypeScript und React-Oberflächen
```

Оба компонента уже включены в фреймворк Adapter Creator. См.
[io-package.json](/docs/dev/iopackage.md) для работы с переводами и
[Тесты адаптера](/docs/dev/adaptertesting.md) к включенным тестам.
