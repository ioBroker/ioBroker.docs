# Визуализация через облако

Визуализация, работающая в домашнем браузере, изначально недоступна удаленно. Очевидное решение — открытие порта в маршрутизаторе — является наихудшим из возможных: интерфейс в этом случае будет открыт для интернета, и единственной защитой будет пароль.

Запланированный маршрут проходит через
[адаптер для Интернета вещей](/docs/cloud/iot.md)Соединение устанавливается изнутри наружу. Маршрутизатор остается закрытым, но интерфейс по-прежнему доступен по адресу сервиса.

## Как всё это взаимосвязано

Сама визуализация осуществляется экземпляром `web`Адаптер IoT поставляется с этой информацией. Адаптер IoT передает этот конкретный экземпляр дальше. Его конфигурация позволяет выбрать, какой именно экземпляр использовать. `web`-это тот случай, который должен быть.

Это означает, что к внешнему доступу применяются те же правила, что и к доступу из дома: тот же интерфейс, те же пользователи, те же права.

## Продолжить

1. Он [адаптер для Интернета вещей](/docs/cloud/iot.md)
   Настройте его и проверьте, установлено ли соединение.
2. В своей конфигурации `web`— Выберите экземпляр, в котором будет выполняться визуализация.
3. В этот момент `web`-пример
   [Регистрация](/docs/config/login.md)
   Включите эту функцию и создайте пользователей для соответствующих категорий людей.
4. Попробуйте использовать мобильную сеть, а не собственную сеть Wi-Fi. В противном случае вы будете проверять маршрут только внутри своего дома.

Без включенной авторизации интерфейс будет доступен любому, кто знает адрес. Ниже описано, что пользователь может видеть и контролировать.
[Управление доступом](/docs/config/userrights.md).

## границы

- Использование сервиса занимает некоторое время. Это незаметно при работе с переключателями или считывании значений, но заметно при работе с видеоизображениями в реальном времени.
- Встроенный контент из локальной сети не работает извне. Любой, кто встраивает изображение с камеры в свою визуализацию, используя её локальный адрес, увидит пустое поле при удалённом просмотре.
- Количество запросов ограничено в зависимости от пакета. Интерфейс, который перезагружает значения каждую секунду, потребляет больше ресурсов, чем тот, который ожидает изменений.

Тем, кто преимущественно использует этот интерфейс на своем телефоне, стоит обратить на него внимание.
[официальное приложение](/docs/cloud/app.md)
Посмотрите. Он работает по тому же принципу, но разработан для телефона.
