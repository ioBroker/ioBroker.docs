# Облачные сервисы и приложения

ioBroker работает в вашей собственной сети, и это стандартная конфигурация: данные остаются у вас дома, и всё продолжает работать без доступа к интернету. Однако вашей собственной сети недостаточно для трёх вещей:

- **Доступ из любой точки мира**, не открывая порт в маршрутизаторе.
- **Голосовые помощники**Потому что Alexa и Google Home отправляют свои запросы из интернета.
- **Внешние сервисы**которые должны передавать информацию в ioBroker, например, веб-хук.

Для этого и существует облако ioBroker. Ключевой момент здесь заключается в том, что соединение... **изнутри наружу** Настройка. Ваш маршрутизатор остается закрытым, переадресация портов не требуется, и ваша установка недоступна из интернета.

## Адаптеры

| адаптер            | За что                                                                                              |
| ------------------ | --------------------------------------------------------------------------------------------------- |
| **Интернет вещей** | Современный подход. Голосовые помощники, удаленный доступ и сервисы — все в одном.                  |
| **облако**         | Предшественник. Все еще в эксплуатации, но для новых объектов он предназначен. `iot` запланировано. |

Для обоих вариантов требуется учетная запись. Одной учетной записи достаточно для бесплатного удаленного доступа.
[ioBroker.net](https://iobroker.net)Для голосовых помощников и расширенного удаленного доступа используется один из них. [ioBroker.pro](https://iobroker.pro) Б/у. Различия между ними описаны ниже.
