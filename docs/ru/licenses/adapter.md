# Лицензии адаптера

Из более чем 800 адаптеров в настоящее время требуется всего 100. **три** лицензия даже на осуществление деятельности:

| адаптер                 | За что                          |
| ----------------------- | ------------------------------- |
| **вис-2**               | Визуализация                    |
| **KNX**                 | Интеграция систем KNX           |
| **JägerDesign Widgets** | Набор виджетов для визуализации |

Все остальные адаптеры бесплатны. Лицензия на адаптер распространяется на адаптер, установленный на вашем собственном сервере; она не имеет никакого отношения к облачным сервисам.

## Связано с серийным номером

К адаптеру прилагается лицензия. **UUID** Установка привязана к идентификатору, который ioBroker генерирует во время настройки. Он находится в...
[Системные настройки](/docs/admin/settings.md) а также может быть запрошен через командную строку:

```bash
iobroker uuid
```

При переустановке ioBroker UUID изменяется, вместо того чтобы оставаться одним фиксированным значением.
[Безопасность](/docs/config/backup.md) Чтобы восстановить его. Процесс восстановления сохраняет данные, а ручная переустановка — нет. Это одна из причин, почему стоит иметь рабочую резервную копию.

Лицензию можно перенести при переходе на другое оборудование. Частота и порядок переноса описаны в \[документе/разделе/и т. д.]. [Обзор лицензии](/productoverview).

## vis-2: частный и коммерческий

Для **вис-2** Компания ioBroker GmbH предоставляет бесплатную лицензию для частного использования. Платная лицензия требуется, если vis-2 используется в контексте коммерческой или деловой деятельности, например:

- использование в проектах заказчиков.
- использование в контексте услуг или платных систем.
- Деятельность компаний, органов власти или других учреждений.

Для системных интеграторов это решающий момент. Другие аспекты подробно описаны ниже.
[Системные интеграторы](/docs/integrators/README.md).

## Автономная лицензия

Бесплатная лицензия vis-2 проверяется в облаке и, следовательно, требует подключения к интернету. **Автономная лицензия** Можно обойтись и без этого. Оно того стоит в двух случаях:

- Интернет-соединение нестабильно или ограничено. Система управления останется локально доступной в любое время.
- В принципе, никакая информация не должна передаваться третьим лицам. Визуализации и данные остаются исключительно в собственной системе компании.

## Введите лицензионный ключ

Лицензионные ключи хранятся централизованно, а не для каждого адаптера отдельно: в административной панели.
**система**, всадник **Лицензии**Адаптер автоматически найдет его оттуда. Вкладка находится в...
[Системные настройки](/docs/admin/settings.md) описано.

В всаднике [адаптер](/docs/admin/adapter.md) В списке для каждого адаптера также отображается его лицензия. Это позволяет вам увидеть, с чем вы имеете дело, прежде чем устанавливать его.
