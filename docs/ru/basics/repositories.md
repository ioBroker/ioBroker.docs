# Что такое репозиторий?

Репозиторий — это централизованное хранилище программного обеспечения. Адаптеры, которые администратор предлагает для установки, берутся из такого репозитория.

ioBroker поставляется с двумя:

| Репозиторий    | Содержание                                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **стабильный** | Протестированные и пригодные для использования в производственной системе версии адаптера. Предварительно настроены.                |
| **бета**       | Версии, которые всё ещё находятся на стадии тестирования и могут содержать ошибки. Ранее этот репозиторий назывался... _последний_. |

Для обеспечения надежной работы системы необходимо следующее: **всегда** Поддержка стабильной версии прекращена. Версии в бета-версии могут содержать ошибки, затрагивающие всю систему.

## Выберите репозиторий

Действие происходит в
[Системные настройки](/docs/admin/settings.md)
всадник **Репозитории**Они открываются через точку **система** в самом низу панели административного меню.

<img src="media/repository_einstellungen.png" alt="Der Reiter Repositories in den Basiseinstellungen" width="900" />

| Нет. | Расколоть                                                                                                                |
| ---- | ------------------------------------------------------------------------------------------------------------------------ |
| 1    | **Активный**Здесь вы выбираете, какой репозиторий будет использоваться.                                                  |
| 2    | **Стабильный**: устанавливается автоматически при первом прочтении, если ioBroker распознает репозиторий как стабильный. |
| 3    | **Автоматическое обновление**: можно ли обновлять адаптеры из этого репозитория независимо друг от друга.                |
| 4    | **имя**: свободно выбираемый.                                                                                            |
| 5    | **связь**: адрес списка адаптеров.                                                                                       |

В верхнем левом углу находится **+** Другой репозиторий. Кнопка со стрелкой рядом с ней задаёт пути к файлам. _стабильный_ и _бета_ Возвращает настройки к значениям по умолчанию и удаляет все репозитории, которые вы добавили самостоятельно.

Пути по умолчанию:

- стабильный: `http://download.iobroker.net/sources-dist.json`
- бета: `http://download.iobroker.net/sources-dist-latest.json`

Если бета-версия репозитория активна, вкладка это указывает.

## Один адаптер из бета-репозитория

Раньше это означало переключение со стабильной версии на бета-версию, установку адаптера, а затем возвращение обратно, хотя последний шаг часто забывали. Теперь это не требуется.

- Он **Экспертный режим** Включите его (значок в левом нижнем углу строки меню).
- В всаднике **адаптер** на **Установите из собственного источника.** Вперёд. Символ с осьминогом.
- В всаднике **Из npm** Выберите необходимый адаптер.

<img src="media/repository_npm.png" alt="Der Dialog Installieren aus eigener Quelle, Reiter Von npm" width="820" />

Это позволяет установить последнюю версию отдельного адаптера без необходимости изменения репозитория. Все остальные адаптеры по-прежнему будут поступать из стабильного репозитория.

!> **При использовании этого метода проверка зависимостей не производится.** И вы можете установить адаптер непосредственно из GitHub только в том случае, если разработчик явно запросит это, например, для тестирования или исправления ошибок. Такие версии все еще находятся в разработке и могут даже временно не работать.

## Как адаптер попадает в репозиторий

Задолго до появления адаптера в административной панели разработчик отправляет запрос на его включение. Опытные разработчики изучают исходный код и дают обратную связь о том, что еще нужно доработать.

Новый адаптер сначала появится в продаже. **бета**-репозиторий и тестируется там тестировщиками. После исправления обнаруженных ошибок версия перемещается в основной репозиторий.
**Стабильный**-Репозиторий. После существенного изменения функциональности адаптер обычно проходит тот же процесс снова.
