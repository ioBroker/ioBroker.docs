# Что такое репозиторий?

Репозиторий — это централизованное хранилище программного обеспечения. Адаптеры, которые администратор предлагает для установки, берутся из такого репозитория.

ioBroker поставляется с двумя:

| Репозиторий    | Содержание                                                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **стабильный** | Протестированные и пригодные для использования в производственной системе версии адаптера. Предварительно настроены.           |
| **бета**       | Версии, которые всё ещё находятся на стадии тестирования и могут содержать ошибки. Ранее этот репозиторий назывался _latest_ . |

Для надежной установки **всегда** используйте стабильный репозиторий. Версии в бета-репозитории могут содержать ошибки, затрагивающие всю систему.

## Выберите репозиторий

Этот параметр находится в [системных настройках](/docs/admin/settings.md) на вкладке **«Репозитории»** . Доступ к нему можно получить через меню **«Система»** в самом низу панели меню администратора.

<img src="media/repository_einstellungen.png" alt="Der Reiter Repositories in den Basiseinstellungen" width="900" />

| Нет. | Расколоть                                                                                                                          |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **Активный** : здесь вы выбираете, какой репозиторий будет использоваться.                                                         |
| 2    | **Статус «Стабильный»** : устанавливается автоматически при первом прочтении, если ioBroker распознает репозиторий как стабильный. |
| 3    | **Автоматическое обновление** : позволяет ли обновлять адаптеры из этого репозитория автоматически.                                |
| 4    | **Название** : выбирается произвольно.                                                                                             |
| 5    | **Ссылка** : адрес списка адаптеров.                                                                                               |

Кнопка **«+»** в верхнем левом углу создает еще один репозиторий. Кнопка со стрелкой рядом с ней сбрасывает пути для _стабильной_ и _бета-версий_ до значений по умолчанию, а также удаляет все репозитории, которые вы добавили самостоятельно.

Пути по умолчанию:

- стабильный:`http://download.iobroker.net/sources-dist.json`
- бета:`http://download.iobroker.net/sources-dist-latest.json`

Если бета-версия репозитория активна, на вкладке [«Адаптер»](/docs/admin/adapter.md) отобразится предупреждение:

<img src="media/repository_warnung.png" alt="Die Warnung im Adapter-Reiter, wenn das Beta-Repository aktiv ist" width="900" />

## Один адаптер из бета-репозитория

Раньше это означало переключение со стабильной версии на бета-версию, установку адаптера, а затем возвращение обратно, хотя последний шаг часто забывали. Теперь это не требуется.

- Включите **экспертный режим** (значок в левом нижнем углу строки меню).
- На вкладке **«Адаптеры»** выберите **«Установить из локального источника»** . Значок — Octocat.
- На вкладке **«Из npm»** выберите нужный адаптер.

<img src="media/repository_npm.png" alt="Der Dialog Installieren aus eigener Quelle, Reiter Von npm" width="820" />

Это позволяет установить последнюю версию отдельного адаптера без необходимости изменения репозитория. Все остальные адаптеры по-прежнему будут поступать из стабильного репозитория.

**Проверка зависимостей этим методом не выполняется.** Адаптер следует устанавливать непосредственно из GitHub только в том случае, если разработчик явно этого требует, например, для тестирования или отладки. Такие версии находятся в процессе разработки и могут даже не работать в это время.

## Как адаптер попадает в репозиторий

Задолго до появления адаптера в административной панели разработчик отправляет запрос на его включение. Опытные разработчики изучают исходный код и дают обратную связь о том, что еще нужно доработать.

Новый адаптер сначала помещается в **бета-** репозиторий, где его тестируют рецензенты. После исправления обнаруженных ошибок версия перемещается в **стабильный** репозиторий. После внесения существенных изменений в функциональность адаптер обычно проходит тот же процесс снова.
