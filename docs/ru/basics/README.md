# Основы работы с ioBroker

ioBroker — это чисто программное решение для объединения различных IoT-систем в единую интегрированную систему. Поэтому каждой системе по-прежнему требуется центральный узел (шлюз/интерфейс) для интеграции своих устройств.

В особых случаях такой центральный блок может быть скопирован с помощью программного обеспечения или подключен к серверу ioBroker в качестве аппаратного обеспечения (USB-накопитель или аналогичное устройство).

## Модульность

ioBroker имеет модульную структуру. Эти модули в ioBroker называются _**адаптерами**_ .\
&#x20;Существует более 800 [адаптеров](/adapters) для подключения различного оборудования или интеграции широкого спектра информации, такой как погода, календарь и т. д.

Таким образом, в систему необходимо устанавливать только те адаптеры, которые требуются для конкретных нужд. Это экономит место для хранения данных и вычислительную мощность.

Для каждого адаптера создаются так называемые _**экземпляры**_ . Это «рабочие версии» адаптеров. В зависимости от адаптера может быть создано любое количество экземпляров для разделения различных подсистем или различных областей задач друг от друга.

Соответствующая конфигурация происходит в этих случаях.

## архитектура

### сервер

Особенностью ioBroker является **возможность** распределения задач между несколькими серверами. В таком случае _**система называется многохостовой**_ . Причины такого распределения могут быть географическими или связанными с распределением ресурсов.

### Требования к оборудованию

Сервер ioBroker можно установить практически на любое оборудование. Единственное требование — наличие актуальной версии [Node.js](https://nodejs.org/en/download/) для соответствующей операционной системы.

ioBroker рекомендует использовать версию **Node.js 22** с долгосрочной поддержкой (LTS). Использовать версии Node.js с нечетными номерами нельзя. Подробнее см. в разделе [«Установка Node.js»](/docs/install/nodejs.md) .

Минимальные требования: 2 ГБ оперативной памяти и 32 ГБ хранилища; рекомендуется 4 ГБ (в идеале от 6 до 8 ГБ) оперативной памяти и 64 ГБ хранилища. Для тестирования достаточно Raspberry Pi 4; для нескольких адаптеров в многохостовой системе потребуется меньше. Полную таблицу требований можно найти в разделе [«Требования»](/docs/install/requirements.md) .

### программное обеспечение

ioBroker управляет данными в базе данных. Структура данных организована соответствующим образом.

Каждый адаптер имеет так называемое пространство имен, которое содержит все данные для экземпляра адаптера. Соответственно, пространство имен может быть, например, _**AdapterName.0.**_

В этой области ioBroker создает устройства, их каналы, а следовательно, и точки данных с их значениями (состояниями).

Более подробная информация находится в разделе [«Объекты](/docs/basics/objects.md) и [состояния»](/docs/basics/states.md) .
