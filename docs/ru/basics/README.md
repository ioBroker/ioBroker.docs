# Основы работы с ioBroker

ioBroker — это чисто программное решение для объединения различных IoT-систем в единую интегрированную систему. Поэтому каждой системе по-прежнему требуется центральный узел (шлюз/интерфейс) для интеграции своих устройств.

В особых случаях такой центральный блок может быть скопирован с помощью программного обеспечения или подключен к серверу ioBroker в качестве аппаратного обеспечения (USB-накопитель или аналогичное устройство).

## Модульность

ioBroker имеет модульную структуру. Эти модули называются... _**адаптер**_.\
Их более 800. [адаптер](/adapters) для подключения различного оборудования или интеграции широкого спектра информации, такой как погода, календарь и т. д.

Таким образом, в систему необходимо устанавливать только те адаптеры, которые требуются для конкретных нужд. Это экономит место для хранения данных и вычислительную мощность.

Каждый адаптер поставляется с так называемым _**Пример**_ Это «рабочие версии» адаптеров. В зависимости от адаптера можно создать любое количество экземпляров для разделения различных подсистем или различных областей задач.

Соответствующая конфигурация происходит в этих случаях.

## архитектура

### сервер

Одной из особенностей ioBroker является возможность распределения задач между несколькими серверами. **может**В таком случае говорят о _**Многохостовая система**_&#x41F;ричины разделения могут быть связаны с пространственными факторами или распределением рабочей нагрузки.

### Требования к оборудованию

Сервер ioBroker можно установить практически на любое оборудование. Единственное требование — наличие актуальной версии ioBroker для соответствующей операционной системы. [Node.js](https://nodejs.org/en/download/) дает.

ioBroker рекомендует версию LTS. **Node.js 22**Использовать нечетные версии Node.js нельзя. Подробности можно найти по ссылке \[link/reference]. [Установите Node.js](/docs/install/nodejs.md).

Минимальные требования: 2 ГБ оперативной памяти и 32 ГБ хранилища; рекомендуется 4 ГБ (предпочтительно от 6 до 8 ГБ) оперативной памяти и 64 ГБ хранилища. Для тестирования достаточно Raspberry Pi 4; даже более компактный вариант подойдет в качестве дополнительного хоста для нескольких адаптеров в многохостовой системе. Полная таблица доступна по ссылке \[ссылка на таблицу]. [Требования](/docs/install/requirements.md).

### программное обеспечение

ioBroker управляет данными в базе данных. Структура данных организована соответствующим образом.

Каждый адаптер имеет так называемое пространство имен, которое содержит все данные для экземпляра адаптера. Соответственно, имя пространства имен может быть, например, следующим: _**AdapterName.0**_

В этой области ioBroker создает устройства, их каналы, а следовательно, и точки данных с их значениями (состояниями).
