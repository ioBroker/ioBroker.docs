# Вкладка "Пользователь"

Здесь осуществляется управление пользователями и группами. Группы отображаются слева, пользователи — справа; пользователь назначается в группу путем перетаскивания курсора мыши на соответствующую группу.

<img src="media/admin_benutzer.png" alt="Der Reiter Benutzer mit Gruppen und Benutzern" width="900" />

С завода доступны две группы компонентов:

| группа                                            | верно                                                 |
| ------------------------------------------------- | ----------------------------------------------------- |
| **Администратор** (`system.group.administrator` ) | Разрешено всё. Пользователь находится здесь.`admin` . |
| **Пользователи** (`system.group.user` )           | Ограниченные права.                                   |

Новый пользователь создается с помощью кнопки в правом верхнем углу, а новая группа — с помощью кнопки слева. Значок карандаша открывает интерфейс редактирования: имя, описание, значок, цвет и, для пользователей, пароль. Там же устанавливаются права доступа для групп, отдельно для объектов, состояний, пользователей, файлов и некоторых специальных разрешений. Значение каждого разрешения объясняется в разделе [«Управление доступом»](/docs/config/userrights.md) .

Эти пользователи **не** являются пользователями операционной системы. Они применяются только внутри ioBroker: для входа в административный интерфейс, интерфейс визуализации и веб-адаптеры.

Права доступа, которые получают **вновь созданные** объекты, указываются в [системных настройках](/docs/admin/settings.md) в разделе _«Стандартный список контроля доступа» (Standard ACL_ ).

При новой установке вход в административный интерфейс отключен. Доступ к интерфейсу имеет любой пользователь в сети. Чтобы сделать ioBroker доступным за пределами домашней сети, включите аутентификацию в конфигурации административного экземпляра и назначьте пароль.`admin` Более подробная информация содержится в разделе [«Права пользователя»](/docs/config/userrights.md) .
