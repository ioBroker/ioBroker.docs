# Вкладка "Пользователь"

Здесь осуществляется управление пользователями и группами. Группы отображаются слева, пользователи — справа; пользователь назначается в группу путем перетаскивания курсора мыши на соответствующую группу.

<img src="media/admin_benutzer.png" alt="Der Reiter Benutzer mit Gruppen und Benutzern" width="900" />

С завода доступны две группы компонентов:

| группа                                           | верно                                                 |
| ------------------------------------------------ | ----------------------------------------------------- |
| **Администратор** (`system.group.administrator`) | Разрешено всё. Пользователь находится здесь. `admin`. |
| **пользователь** (`system.group.user`)           | Ограниченные права.                                   |

Новый пользователь создается с помощью кнопки в правом верхнем углу, а новая группа — с помощью кнопки слева. Значок карандаша открывает интерфейс редактирования: имя, описание, значок, цвет и, для пользователей, пароль. Там же устанавливаются права доступа для групп, разделенные по объектам, состояниям, пользователям, файлам и некоторым специальным разрешениям. Значение каждого разрешения объяснено ниже.
[Управление доступом](/docs/config/userrights.md).

Эти пользователи **нет** Пользователи операционной системы. Они применяются только в рамках ioBroker: для входа в административный интерфейс, vis и веб-адаптеры.

Какие права **недавно созданный** Получение объектов указано в
[Системные настройки](/docs/admin/settings.md)
под _Стандартная передняя крестообразная связка_.

При новой установке вход в административный интерфейс отключен. Доступ к интерфейсу имеет любой пользователь в сети. Чтобы сделать ioBroker доступным за пределами домашней сети, включите аутентификацию в конфигурации административного экземпляра и назначьте пароль. `admin`Более подробную информацию можно найти по адресу:
[Права пользователя](/docs/config/userrights.md).
