# Адаптер для водителя

На этой странице перечислены все доступные адаптеры для ioBroker: установленные и более 800 других. Здесь можно устанавливать, обновлять и удалять адаптеры.

## Вид плитки

Каждый адаптер получает плитку с его названием, описанием, количеством экземпляров, а также доступными и установленными версиями. Кнопка с тремя точками переворачивает плитку; команды находятся на обратной стороне.

<img src="media/admin_adapter_kachel.png" alt="Eine Adapterkachel und ihre Rueckseite" width="630" />

| Нет. | функция                                                                                           |
| ---- | ------------------------------------------------------------------------------------------------- |
| 1    | **Добавить экземпляр.** Если адаптер еще не установлен, он будет установлен в процессе установки. |
| 2    | **Политика автоматического обновления** для этого адаптера.                                       |
| 3    | **Прочитай меня**: открывает документацию адаптера.                                               |
| 4    | **Загрузка файла.**                                                                               |
| 5    | **Удалите адаптер.** Существующие экземпляры и их объекты будут потеряны в процессе.              |
| 6    | **Установите определенную версию**: например, вернуться к более старой версии.                    |

Мелкими буквами под названием адаптера обозначены следующие символы: **Как** Адаптер работает, а не состояние его установки:

| Знак                          | Значение                                                                             |
| ----------------------------- | ------------------------------------------------------------------------------------ |
| Облако с линией посередине    | Адаптеру не требуется облачное хранилище; он взаимодействует напрямую с устройством. |
| Облако                        | Для работы адаптера требуется облачный сервис производителя.                         |
| Стрелка вниз (_толкать_)      | Устройство автоматически сообщает об изменениях.                                     |
| Стрелка вверх (_голосование_) | ioBroker регулярно запрашивает данные с устройства.                                  |
| Зелёные горы                  | Адаптер сообщает о сбоях своему разработчику через Sentry.                           |

?> _толкать_ Это более приятный случай: значения поступают мгновенно, без необходимости для ioBroker выполнять запросы каждую секунду.

Ниже названия адаптера вы также увидите оценку до пяти звезд. Это рейтинг пользователей, установивших адаптер. Нажав на него, вы откроете оценки и комментарии, а также сможете проголосовать сами. См.
[обзоры адаптеров](/docs/ecosystem/rating.md).

## Установите из собственного источника.

Кнопка с изображением осьминога открывает диалоговое окно с четырьмя вариантами:

<img src="media/admin_adapter_eigene_quelle.png" alt="Der Dialog zum Installieren aus eigener Quelle" width="820" />

- **Из npm**: бета-версия или последняя версия, полученная непосредственно из npm.
- **Из GitHub**: последняя предварительная версия из репозитория разработчика.
- **Пользовательский**: любой URL.
- **Из файла**: локально доступный пакет.

Эти методы обходят проверенный репозиторий. Версии могут быть не полностью протестированы, и **Зависимости не проверяются.**&#x412; системах, требующих непрерывной работы, используйте это решение только в случае крайней необходимости; в противном случае дождитесь стабильной версии.

Вариант _Создайте экземпляр, если он еще не существует._ Это настройка по умолчанию. Если она отключена, экземпляр необходимо будет создать вручную.
