# Адаптер для водителя

На этой странице перечислены все доступные адаптеры для ioBroker: установленные и более 800 других. Здесь можно устанавливать, обновлять и удалять адаптеры.

Адаптер изначально представляет собой только программу. Для выполнения каких-либо действий ему необходим **экземпляр** . Он также создается здесь и затем настраивается на вкладке [«Экземпляры»](/docs/admin/instances.md) .

## Панель инструментов

| 2    | **Проверьте наличие обновлений для сетевых адаптеров.** Это происходит автоматически при запуске администратора; здесь же это можно запустить вручную. |
| 3    | **Временная метка репозитория. Время** создания и последней загрузки списка адаптеров.                                                                 |
| 4    | **Отображать только установленные адаптеры.**                                                                                                          |
| 5    | **Показать только адаптеры с обновлениями.**                                                                                                           |
| 6    | **Установите из собственного источника** (см. ниже).                                                                                                   |
| 7    | **Фильтр по имени.**                                                                                                                                   |
| 8    | **Выберите категорию** : освещение, энергоснабжение, связь и так далее.                                                                                |
| 9    | **Сортировать по** : Заголовку, Имени, Популярное в первую очередь, Недавно обновленное, Недавно созданное.                                            |
| 10   | Столбец счетчика. При нажатии на него открывается статистика: доступные, установленные и обновленные адаптеры за последний месяц.                      |

Если над списком появляется желтое предупреждение, указывающее на то, что текущий репозиторий является _последним (бета-версией)_ , это означает, что ioBroker распространяет предварительные версии. Для надежной работы системы следует выбрать _стабильный_ репозиторий. Это можно изменить в [системных настройках](/docs/admin/settings.md) .

## Вид плитки

Каждый адаптер получает плитку с его названием, описанием, количеством экземпляров, а также доступными и установленными версиями. Кнопка с тремя точками переворачивает плитку; команды находятся на обратной стороне.

<img src="media/admin_adapter_kachel.png" alt="Eine Adapterkachel und ihre Rueckseite" width="630" />

| Нет. | функция                                                                                           |
| ---- | ------------------------------------------------------------------------------------------------- |
| 1    | **Добавить экземпляр.** Если адаптер еще не установлен, он будет установлен в процессе установки. |
| 2    | **Политика автоматического обновления** для этого адаптера.                                       |
| 3    | **Readme** : открывает документацию адаптера.                                                     |
| 4    | **Загрузка файла.**                                                                               |
| 5    | **Удалите адаптер.** Существующие экземпляры и их объекты будут потеряны.                         |
| 6    | **Установите определённую версию** : например, чтобы вернуться к более старой версии.             |

Маленькие символы под названием адаптера описывают **принцип** его работы, а не состояние его установки:

| Знак                       | Значение                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------ |
| Облако с линией посередине | Адаптеру не требуется облачное хранилище; он взаимодействует напрямую с устройством. |
| Облако                     | Для работы адаптера требуется облачный сервис производителя.                         |
| Стрелка вниз ( _нажатие_ ) | Устройство автоматически сообщает об изменениях.                                     |
| Стрелка вверх ( _опрос_ )  | ioBroker регулярно запрашивает данные у устройства.                                  |
| Зелёные горы               | Адаптер сообщает о сбоях своему разработчику через Sentry.                           |

?> _Функция push_ — более приятный вариант: значения поступают немедленно, без необходимости отправлять запрос в ioBroker каждую секунду.

Под названием адаптера вы также увидите оценку до пяти звезд. Это рейтинг пользователей, установивших адаптер. Нажав на него, вы откроете оценки и комментарии, а также сможете проголосовать. Посмотреть [оценки адаптера](/docs/ecosystem/rating.md) .

## Список

В списке адаптеры сгруппированы по категориям. В каждой строке указаны установленные и доступные версии, а также лицензия; справа отображаются те же команды, что и на обратной стороне плитки.

<img src="media/admin_adapter_liste.png" alt="Die Listenansicht mit aufgeklappter Kategorie" width="900" />

Этот режим удобен для просмотра: в заголовке каждой группы отображается количество уже установленных адаптеров данной категории.

## Установите из собственного источника.

Кнопка с изображением осьминога открывает диалоговое окно с четырьмя вариантами:

<img src="media/admin_adapter_eigene_quelle.png" alt="Der Dialog zum Installieren aus eigener Quelle" width="820" />

- **Из npm** : бета-версия или последняя версия, доступная непосредственно из npm.
- **Из GitHub** : последняя предварительная версия из репозитория разработчика.
- **Пользовательский** : любой URL.
- **Из файла** : локально сохраненный пакет.

Эти методы обходят проверенный репозиторий. Версии могут быть не полностью протестированы, и **зависимости не проверяются** . В системе, которая должна работать, используйте этот метод только в случае срочной необходимости исправления; в противном случае дождитесь стабильной версии.

По умолчанию выбрана опция _создания экземпляра, если он еще не существует_ . Если она отключена, экземпляр необходимо будет создать вручную.

## Если обновление отклонено

Для работы адаптера может потребоваться определённая версия административного компонента или контроллера JavaScript. Если эта версия отсутствует, в диалоговом окне обновления зависимость отображается красным цветом, и обновление не будет выполнено. В этом случае правильная процедура такова: сначала обновите необходимый компонент, а затем адаптер. В системе с несколькими хостами это относится к каждому хосту, на котором запущен экземпляр.

## Устройства и сервисы находят

_Функция обнаружения_ адаптеров сканирует сеть на наличие устройств и служб и предлагает подходящие адаптеры. Во время работы функции в заголовке отображается **значок глаза** ; этот значок показывает, сколько предложений еще ожидают подтверждения, то есть ни созданных, ни отклоненных.

Процесс диалога работает следующим образом: _кнопка «Обнаружить»_ запускает поиск, кнопка « _Далее»_ переносит результаты предыдущего поиска. Для каждой найденной информации вы можете создать соответствующий экземпляр или отклонить предложение; значок учитывается при этом. Если от последнего поиска остались незавершенные предложения, диалог открывается непосредственно на странице результатов.

Межсетевые экраны и системы анализа трафика могут мешать сканированию: сканирование отправляет запросы в сеть, на которые некоторые устройства отвечают только в том случае, если между ними нет других устройств. Отключите их на время сканирования, а затем снова включите.
