# Протоколы вкладок

Здесь отображаются системные сообщения. Самое новое находится вверху. Если что-то не работает, это первое место, куда следует обратиться.

Отображается ли этот пункт меню? **Протоколы** Красный цвет указывает на ошибку. Число рядом с ней указывает количество ошибок.

## Панель инструментов

<img src="media/admin_protokolle_leiste.png" alt="Die Werkzeugleiste des Reiters Protokolle" width="900" />

| Нет. | функция                                                                                                                                                                             |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **Журнал обновлений.**                                                                                                                                                              |
| 2    | **Приостановить вывод.** Вместо символа отображается количество новых, неотображаемых сообщений. Это полезно, если вы хотите прочитать определенную строку в удобное для вас время. |
| 3    | **Удалить журнал**: очищает экран только в браузере.                                                                                                                                |
| 4    | **Безвозвратно удалить с диска**: удаляет файл журнала на хосте.                                                                                                                    |
| 5    | **Показать/скрыть идентификатор процесса.**                                                                                                                                         |
| 6    | **Показать/скрыть цвета**: выделяет ошибки красным цветом, а предупреждения — желтым.                                                                                               |
| 7    | **Обратное направление выходного сигнала**: Самое новое сообщение вверху или внизу.                                                                                                 |
| 8    | **Показывать только ошибки.** Число рядом указывает количество обнаруженных ошибок.                                                                                                 |
| 9    | **Отображение ошибок и предупреждений.**                                                                                                                                            |
| 10   | **Скачать журнал**: загружает полный файл за день `/opt/iobroker/log`.                                                                                                              |
| 11   | Он **Размер** Текущий файл журнала.                                                                                                                                                 |

Ведущий стоит справа. В
[Многохостовая система](/docs/config/multihost.md)
Система переключается между хостами. Отображаются только сообщения от выбранного хоста.

## Список

<img src="media/admin_protokolle_liste.png" alt="Die Protokollliste mit Quelle, Zeit, Stufe und Nachricht" width="900" />

Колонны **источник** (экземпляр или хост), **Время**, то
**Уровень лога** и **Новости**Поля в заголовке позволяют осуществлять фильтрацию: по источнику, по минимальному уровню логирования и по тексту внутри сообщения.

Уровни ведения журнала от наиболее подробного до наиболее краткого:

| Уровень                      | За что                                                              |
| ---------------------------- | ------------------------------------------------------------------- |
| `silly` (в диалоге) **Все**) | Абсолютно каждый отчет. Только если `debug` этого недостаточно.     |
| `debug`                      | Внутренние процессы тоже. Для устранения неполадок выполните сброс. |
| `info`                       | Стандартная процедура: Запуск, Остановка, Подключения.              |
| `warn`                       | Что-то не так, но это продолжается.                                 |
| `error`                      | Что-то пошло не так.                                                |

Уровень отображается для каждого экземпляра на вкладке.
[Пример](/docs/admin/instances.md)
прекращена работа, возникла необходимость в новых экземплярах.
[Системные настройки](/docs/admin/settings.md).

Длинные строки в списке обрезаются. Чтобы разобраться в сути сообщения, следует загрузить файл журнала и посмотреть там. Часто истинная причина кроется в строках, предшествующих сообщению.

## Если в журнале обнаружена ошибка

Почти всегда помогают две вещи:

1. **Ищите первое сообщение об ошибке, а не последнее.** Одна ошибка часто влечет за собой другие ошибки; начало этой цепочки весьма интересно.
2. **Уровень детализации логов затронутого экземпляра находится на `debug` место**Перезапустите экземпляр и снова просмотрите сообщения.

Если это не поможет, то вот что может помочь.
[форум](https://forum.iobroker.net/)Именно туда следует прикрепить выдержку из загруженного файла журнала, а не скриншот списка.
