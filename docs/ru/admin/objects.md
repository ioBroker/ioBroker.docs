# вкладка «Объекты»

На этой вкладке представлены все объекты, управляемые ioBroker. Каждый экземпляр создает здесь собственное пространство имен, содержащее свои устройства, каналы и точки данных. Объекты также можно создавать, редактировать и удалять вручную, а целые поддеревья можно сохранять в виде файлов JSON и восстанавливать.

Что представляют собой объекты и состояния на самом деле, объясняется ниже.
[объекты](/docs/basics/objects.md) и
[Условия](/docs/basics/states.md).

## Панель инструментов

Наиболее важные команды расположены вверху. У каждой иконки есть всплывающая подсказка; просто наведите на неё курсор мыши на мгновение.

<img src="media/admin_objekte_leiste.png" alt="Die Werkzeugleiste des Reiters Objekte" width="900" />

| Нет. | функция                                                                                                        |
| ---- | -------------------------------------------------------------------------------------------------------------- |
| 1    | **Обновить дерево.** Если недавно созданные объекты еще не отображаются, нажмите здесь, чтобы получить помощь. |
| 2    | **Настроить.** Указывает, какие столбцы отображает таблица и какой ширины они будут.                           |
| 3    | **Откройте или закройте все узлы.**                                                                            |
| 4    | **Расширить на один уровень.**                                                                                 |
| 5    | **Сложите один уровень вниз.**                                                                                 |
| 6    | **Отображение состояния переключателя** (см. ниже).                                                            |
| 7    | **Показать/скрыть описания объектов.** Отображает текст описания объекта в дополнение к его названию.          |
| 8    | **Добавить новый объект** (см. ниже).                                                                          |
| 9    | **Добавить дерево объектов из JSON-файла.**                                                                    |
| 10   | **Сохраните дерево объектов в виде JSON-файла.** Выбранное в данный момент поддерево сохраняется.              |

Количество объектов и состояний, а также значок гаечного ключа расположены в правой части панели инструментов. **Редактировать пользовательскую конфигурацию**Это изменит настройки записи для **все** Были заданы точки данных, точно соответствующие критериям фильтра.

Перед тем как нажать на значок гаечного ключа, обязательно проверьте, какие фильтры установлены. В противном случае настройки будут применены к гораздо большему количеству точек данных, чем предполагалось.

## Содержимое страницы

Объекты перечислены в таблице. Поля ввода и меню выбора под заголовками столбцов фильтруют отображаемый список.

<img src="media/admin_objekte_spalten.png" alt="Die Spalten der Objekttabelle" width="900" />

| Нет. | Расколоть         | Значение                                                                                                                                                                                           |
| ---- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **ИДЕНТИФИКАТОР** | Иерархия объектов. Наверху находятся пространства имен, ниже — устройства, каналы и точки данных. Поле фильтра может содержать... `*` Они используются в качестве заполнителей.                    |
| 2    | **имя**           | Название объекта, перед которым стоит символ, указывающий на его уровень иерархии. Название можно редактировать напрямую.                                                                          |
| 3    | **тип**           | Устройство, канал, состояние или каталог. Меню выбора можно использовать, например, для ограничения поиска определенными состояниями.                                                              |
| 4    | **роль**          | Сообщает таким поверхностям, как vis, что представляет собой точка данных (`switch.lock`, `indicator.alarm`, `button` …). Редактируемый, со списком подсказок; допускается ввод свободного текста. |
| 5    | **Космос**        | Назначенная комната. Нажатие на поле открывает список созданных комнат.                                                                                                                            |
| 6    | **функция**       | Назначенная профессия, например, освещение или отопление.                                                                                                                                          |
| 7    | **Ценить**        | Для точек данных отображается текущее значение. **Красный** означает: еще не подтверждено устройством (`ack = false`).                                                                             |
| 8    | **верно**         | Права доступа к объекту выражаются в восьмеричном формате, аналогично правам доступа к файлам в Linux.                                                                                             |
| 9    |                   | Кнопки в ряду (см. ниже).                                                                                                                                                                          |

Вкладка «Помещения и виды работ» содержит список.
[Категории](/docs/admin/enums.md) созданный.

## Отображение состояния

символ **6** Для каждого состояния отображаются дополнительные столбцы: кто последний раз его установил, его качество, временная метка и время последнего изменения.

<img src="media/admin_objekte_status.png" alt="Die Statusansicht mit Qualitaet und Zeitstempeln" width="900" />

?> `0x00 - good` Это означает, что значение корректно. Другие значения указывают на проблему, например... `0x20 - substitute` для определения стоимости замены.

## Создать новый объект

символ **8** Создает объект под выбранной в данный момент записью.

<img src="media/admin_objekte_neu.png" alt="Der Dialog Neues Objekt hinzufuegen" width="820" />

Как тип **Состояние**, **канал**, **Устройство** и **каталог** Для состояний доступен следующий тип: логическое значение, число, строка, список значений, поле, объект или их комбинация. Допускаются следующие структуры: каталог → состояние, каталог → канал → состояние, каталог → устройство → канал → состояние, устройство → канал → состояние и канал → состояние.

Без экспертного режима пользовательские объекты можно использовать только в следующих условиях: `0_userdata.0` и `alias.0`
Они будут созданы. Это не ограничение, а скорее правильное место: объекты в пространствах имен адаптеров будут перезаписаны при следующем их запуске.

## Кнопки в ряд

<img src="media/admin_objekte_zeile.png" alt="Rechte und Schaltflaechen einer Tabellenzeile" width="700" />

1. Он **верно** объекта.
2. Он **Карандаш** Открывает редактор объектов со всеми свойствами. Изменения вступают в силу немедленно. Используйте эту функцию только в том случае, если понимаете последствия.
3. Он **мусорное ведро** Эта операция удаляет объект и все, что находится ниже него в иерархии. Перед этим появится запрос на подтверждение.
4. Он **механизм** открывает _Пользовательские настройк&#x438;_&#x412; этом разделе определяется, будет ли и каким образом записываться данная точка данных. Он отображается только в том случае, если установлен хотя бы один экземпляр history, InfluxDB или SQL.
