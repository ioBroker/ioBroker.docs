# Пользовательский интерфейс

**Административный** адаптер — это базовый адаптер, используемый для управления всей установкой ioBroker. Он предоставляет веб-интерфейс, который можно найти по адресу:`http://<IP-Adresse des Servers>:8081` его вызывают.

Этот адаптер создается во время установки ioBroker; ручная установка не требуется.

Эта страница содержит общий обзор. Подробные описания можно найти на страницах, ссылки на которые приведены в отдельных разделах.

## Строительство

Интерфейс разделён на три области: **1)** строка меню, **2)** главное окно и **3)** панель инструментов в нижней части строки меню.

<img src="media/admin_aufbau.png" alt="Der Aufbau des Admin: Menueleiste, Hauptfenster, Symbolleiste" width="900" />

## 1 Панель меню

Панель меню ведет к отдельным страницам административной панели. При новой установке это следующие страницы:

| Пункт меню                                | Содержание                                                                                                       |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| [Обзор](/docs/admin/overview.md)          | Состояние системы, данные об аппаратном обеспечении хоста, активные сетевые адаптеры и последние строки журнала. |
| [Быстрый доступ](/docs/admin/overview.md) | Плитки для всех адаптеров с собственным веб-интерфейсом, а также для хостов.                                     |
| [адаптер](/docs/admin/adapter.md)         | Доступные и установленные адаптеры, установка и обновление.                                                      |
| [Пример](/docs/admin/instances.md)        | Запускайте и останавливайте созданные экземпляры с сохранением их конфигурации.                                  |
| [объекты](/docs/admin/objects.md)         | Дерево объектов, содержащее все устройства, каналы и точки данных.                                               |
| [Категории](/docs/admin/enums.md)         | Комнаты, обмен и избранное. Раньше этот раздел назывался «Списки».                                               |
| [Протоколы](/docs/admin/log.md)           | Журнал ошибок. В случае ошибки пункт меню выделяется красным цветом.                                             |
| [пользователь](/docs/admin/users.md)      | Пользователи и группы, включая их права.                                                                         |
| [Хозяева](/docs/admin/hosts.md)           | На компьютерах запущен ioBroker. Если будет доступна новая версия js-контроллера, здесь появится уведомление.    |
| [файлы](/docs/admin/files.md)             | Файловый менеджер для файлов, управляемых ioBroker.                                                              |
| [Резервная копия](/docs/config/backup.md) | Создавайте, просматривайте и восстанавливайте резервные копии.                                                   |

При установке адаптеров появляются дополнительные пункты меню, такие как _скрипты_ (javascript), _календарь_ (fullcalendar), _устройства_ (devices) или _события_ (eventlist). В самом низу находится **раздел «Система»** : здесь настраиваются [системные параметры](/docs/admin/settings.md) .

### Уменьшить размер меню

Панель меню можно переключать с помощью стрелки в верхнем левом углу. Она имеет три состояния: с подписями, только со значками и полностью скрыта. В скрытом состоянии её можно снова открыть с помощью значка с тремя линиями. Это освобождает больше места для главного окна на небольших экранах.

<img src="media/admin_menue_zustaende.png" alt="Die drei Zustaende der Menueleiste: beschriftet, nur Symbole, ausgeblendet" width="292" />

## 2 основных окна

В главном окне отображается содержимое выбранного в данный момент пункта меню. Подробную информацию о том, что там отображается, можно найти на страницах, ссылки на которые приведены в таблице выше.

Значения отображаются **красным цветом** в дереве объектов до тех пор, пока не будут подтверждены получателем.`ack = false` ).

## 3 Панель инструментов

В нижней части панели меню расположены четыре кнопки:

| символ                           | функция                                                                                                                                                                                                  |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| колокол                          | Системные **уведомления** . Число рядом с ними указывает количество непрочитанных сообщений.                                                                                                             |
| контраст                         | **Смена цветовой темы** : переключение между цветовыми темами (см. ниже).                                                                                                                                |
| Символ головы, белый или зелёный | **Переключитесь в экспертный режим** . Зеленый цвет означает, что он включен. В этом режиме отображаются дополнительные объекты, настройки и столбцы, и он применяется только к текущей сессии браузера. |
| Подключенные окна                | **Синхронизировать настройки между всеми открытыми окнами браузера** .                                                                                                                                   |

### Две кнопки снаружи этой панели

Две вещи расположены не в строке меню, а на краю окна:

- **Значок глаза** в заголовке открывает [поиск устройств](/docs/admin/adapter.md#geräte-und-dienste-finden) . Он появляется только тогда, когда запущен _поиск_ адаптеров, и отображает значок, показывающий количество предложений, которые еще не были созданы или отклонены.
- [Искусственный интеллект-помощник](/docs/admin/assistant.md) находится в правом нижнем углу экрана. По умолчанию он отключен.

Многие описания в этой документации предполагают использование экспертного режима. Если описанная кнопка отсутствует, стоит сначала проверить соответствующий переключатель.

<img src="media/admin_expertenmodus.png" alt="Der Hinweis beim Einschalten des Expertenmodus" width="700" />

Экспертный режим применяется только к текущей сессии браузера. Его можно включить навсегда в [системных настройках](/docs/admin/settings.md) .

### Цветовые темы

Переключатель контрастности изменяет цветовую тему. Доступны варианты **modernLight** и **modernBlue** . Оба отображают одно и то же содержимое; они отличаются только цветом.

<img src="media/admin_farbthemen.png" alt="Die Farbthemen modernLight und modernBlue im Vergleich" width="900" />

Цветовая схема применяется ко всем браузерам, а не ко всем пользователям. Пользователи, получающие доступ к панели администратора с разных устройств, должны настраивать её индивидуально на каждом устройстве.
