# Системные настройки

Системные настройки применяются ко всей установке. Доступ к ним осуществляется через пункт **«Система»** в самом низу строки меню; они разделены на несколько вкладок.

## система

Вот основные настройки, на которые также ссылаются адаптеры.

<img src="media/admin_einstellungen_system.png" alt="Der Reiter System der Basiseinstellungen" width="900" />

| Отношение                           | Значение                                                                                                                                                                                                  |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название растения**               | Отображается в шапке административной панели. Полезно при управлении несколькими установками ioBroker.                                                                                                    |
| **Системный язык**                  | Язык интерфейса. Не все адаптеры полностью переведены.                                                                                                                                                    |
| **единица измерения температуры**   | °C или °F. Некоторые адаптеры используют оба варианта.                                                                                                                                                    |
| **Символ валюты**                   | Например`€` .                                                                                                                                                                                             |
| **Формат даты**                     | Применяется к администраторам и посетителям.                                                                                                                                                              |
| **Символы плавающего делителя**     | Запятая или точка для десятичных чисел.                                                                                                                                                                   |
| **Стандартная история**             | Какой экземпляр записывает значения при установке нескольких экземпляров history, SQL или InfluxDB?                                                                                                       |
| **Экспертный режим**                | Включен ли уже экспертный режим при открытии административного интерфейса. Переключатель в левом нижнем углу строки меню применяется только к текущей сессии браузера; эта настройка является постоянной. |
| **Стандартный уровень протокола**   | Уровень логирования, который получают **новые** экземпляры. Существующие экземпляры остаются без изменений.                                                                                               |
| **Воскресенье**                     | Для отображения календаря и расписания.                                                                                                                                                                   |
| **Страна, город, широта и долгота** | Местоположение системы. В комплект входят адаптеры для определения времени восхода и захода солнца, погодных условий или астрономических расписаний. Карта рядом с ней приведена только для справки.      |

Тем, кто использует расписания, например, «через полчаса после захода солнца», следует сначала указать правильное местоположение, иначе ioBroker будет использовать предустановленное местоположение.

## Репозитории

ioBroker получает список адаптеров из репозитория. По умолчанию включены два адаптера:

<img src="media/admin_einstellungen_repos.png" alt="Der Reiter Repositories" width="900" />

- **Стабильные** : протестированные версии. Это правильный выбор для системы, которая должна работать надежно.
- **бета** (также _Latest_ ): последние версии, еще не прошедшие полное тестирование.

Флажок в столбце **«Активный»** определяет, какой репозиторий используется. Если активна _бета-версия_ , на вкладке «Адаптер» появится соответствующее предупреждение.

Если имеются дополнительные записи из старой установки, их следует удалить. Они больше не поддерживаются.

Параметр " **Разрешить только автоматическое выполнение следующих обновлений"** определяет, разрешено ли адаптеру ioBroker обновляться самостоятельно и до какого уровня версии.

## Сертификаты

Сертификаты для HTTPS находятся здесь. Они используются в admin, web, simple-api и socketio.

<img src="media/admin_einstellungen_zertifikate.png" alt="Der Reiter Zertifikate" width="900" />

Ex-works`defaultPrivate` и`defaultPublic` Эти сертификаты по умолчанию одинаковы во всех установках и, следовательно, **небезопасны** : они позволяют установить только зашифрованное соединение без возможности проверки подлинности. Для внешнего доступа вам потребуются собственные сертификаты, сгенерированные самостоятельно, приобретенные или полученные от Let's Encrypt.

Сертификат можно сохранить в виде файла или указать в виде абсолютного пути, например.`/opt/certs/cert.pem` .

!> Сначала попробуйте использовать новые сертификаты с **веб-** адаптером, а не с административным адаптером. В противном случае вы можете заблокировать себе доступ.

### Права доступа к файлам сертификатов

Если указан путь, пользователь должен`iobroker` получить разрешение на чтение файла:`644` для файла,`755` для родительских каталогов. Если необходимые разрешения отсутствуют, в журнале будет указано что-то вроде:

```
web.0 (24704) Cannot create webserver: Error: error:0909006C:PEM routines:get_name:no start line
```

Это может проверить пользователь.`iobroker` :

```bash
su iobroker
ls -l /pfad/zum/zertifikat
```

В начале линии,`-rw-r--r--` стой. В противном случае как`root` :

```bash
chmod 644 /pfad/zum/zertifikat
chmod 755 /pfad/zum
```

Если запись указывает на символическую ссылку, применяются права целевой компании.

## Let's Encrypt SSL

[Let's Encrypt](https://letsencrypt.org/) выпускает бесплатные сертификаты. ioBroker может запрашивать и автоматически продлевать их; эта опция доступна практически в каждом адаптере, запускающем веб-сервер с HTTPS.

Процесс: ioBroker создает учетную запись с указанным здесь адресом электронной почты и запускает небольшой веб-сервер на **порту 80** при первом обращении к этому адресу. Let's Encrypt сохраняет там строку подтверждения и считывает ее из...`http://<adresse>/.well-known/acme-challenge/` Затем система отправляет сертификат. Он действителен приблизительно 90 дней, после чего автоматически продлевается.

Порт 80 должен быть свободен и доступен извне. Если его использует другая служба, проверка завершится неудачей.

Если это не сработает или не нужно открывать порты: для доступа из любого места [адаптер IoT](/adapters/iot) — более простой способ, поскольку он не требует открытия портов.

## Стандартная передняя крестообразная связка

Определяет, какие права получают **вновь созданные** объекты, состояния и файлы, с разбивкой по владельцу, группе и всем остальным.

<img src="media/admin_einstellungen_acl.png" alt="Der Reiter Standard ACL" width="900" />

Эта страница не изменяет права доступа существующих объектов. Сами пользователи и группы управляются на вкладке [«Пользователи»](/docs/admin/users.md) .

## статистика

ioBroker может отправлять анонимную статистику использования в проект.

<img src="media/admin_einstellungen_statistik.png" alt="Der Reiter Statistik mit der Vorschau der gesendeten Daten" width="900" />

Слева вы выбираете объем передаваемых данных; справа вы найдете четкое описание того, что фактически будет передано: от идентификатора установки и версии узла до платформы и списка установленных адаптеров. Персональные данные не включаются. Этот анализ помогает проекту определить, какие адаптеры и платформы фактически используются.

## Другие мотоциклисты

- **Лицензии** : Здесь хранятся лицензионные ключи для платных адаптеров. Информацию о том, для каких адаптеров требуется лицензия и к чему она привязана, можно найти в разделе [«Лицензии на адаптеры»](/docs/licenses/adapter.md) .
- **Данные доступа** : централизованные данные для входа в систему, к которым могут получить доступ несколько адаптеров, вместо их индивидуального хранения.
