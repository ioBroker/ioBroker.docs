# вкладка «Файлы»

Помимо объектов и состояний, ioBroker также управляет файлами: значками, изображениями, конфигурациями адаптера и страницами визуализации. Эта вкладка является файловым менеджером для них.

<img src="media/admin_dateien.png" alt="Der Reiter Dateien mit den Verzeichnissen der Adapter" width="900" />

Каждый адаптер получает свою собственную директорию, обычно `<adapter>.admin` для файлов его конфигурационного интерфейса. В самом верху находится **Данные пользователя**
(`0_userdata.0`Здесь должны храниться ваши собственные файлы, например, изображения для визуализации.

Справа от каждой записи указано количество содержащихся файлов и права доступа.

## Панель инструментов

<img src="media/admin_dateien_leiste.png" alt="Die Werkzeugleiste des Dateimanagers" width="380" />

| Нет. | функция                                                                                                    |
| ---- | ---------------------------------------------------------------------------------------------------------- |
| 1    | **Переключить вид** между списком и плитками.                                                              |
| 2    | **Скрыть пустые каталоги.**                                                                                |
| 3    | **Перезагрузка.**                                                                                          |
| 4    | **Создайте новую директорию.**                                                                             |
| 5    | **Загрузить файл**Также путем перетаскивания.                                                              |
| 6    | **Переключить фон предварительного просмотра**, чтобы можно было оценивать изображения с прозрачным фоном. |

Каталоги адаптеров принадлежат соответствующему адаптеру. При обновлении он перезапишет свои файлы. Поэтому храните свои файлы в соответствующем каталоге.
**Данные пользователя** Они будут храниться там.

Файлы также можно читать и записывать из скрипта. Как это сделать, объясняется ниже.
[Хранилище файлов](/docs/dev/filestorage.md).
