# Обзор и быстрый доступ

## Обзор вкладок

Обзор — это домашняя страница администратора. Он позволяет с первого взгляда оценить работоспособность системы и содержит ссылки на соответствующие вкладки.

<img src="media/admin_uebersicht.png" alt="Der Reiter Uebersicht in Admin 8" width="900" />

В правом верхнем углу отображается имя хоста, к которому относится данное сообщение, а рядом с ним указывается, находится ли он **в сети** . Ниже расположены четыре плитки:

| плитка            | Значение                                                                                                  |
| ----------------- | --------------------------------------------------------------------------------------------------------- |
| Состояние системы | Совокупное сообщение от запущенных экземпляров, хранилища и журнала.`OK` Это означает: ошибок больше нет. |
| адаптер           | Сколько адаптеров установлено и сколько из них активно используется.                                      |
| Пример            | Сколько экземпляров было создано и сколько из них запущено.                                               |
| объекты           | Количество объектов и их описываемых состояний.                                                           |

В блоке **«Информация о системе»** отображаются данные хоста: платформа, архитектура, версия Node.js и NPM, время работы с момента последнего перезапуска, а также текущее использование оперативной памяти и процессора.

Если индикатор использования оперативной памяти постоянно показывает максимальное значение или версия Node.js не соответствует [рекомендованной версии LTS](/docs/install/nodejs.md) , то это первое, с чего следует начать поиск проблемы.

Ниже представлены **активные сетевые адаптеры** с указанием их версии и статуса, а также последние несколько строк из **системного журнала** . Нажатие кнопки _«Показать все»_ переведет вас к полному [списку экземпляров](/docs/admin/instances.md) или к [журналам](/docs/admin/log.md) .

## Вкладки быстрого доступа

Функция быстрого доступа отображает все адаптеры, имеющие собственный веб-интерфейс, в виде плиток. Щелчок по плитке открывает этот интерфейс по адресу, указанному в нижней части плитки.

<img src="media/admin_schnellzugriff.png" alt="Der Reiter Schnellzugriff mit den Kacheln der Weboberflaechen" width="900" />

Наконец, для каждого хоста в системе предусмотрен отдельный блок. В стандартной установке это единственный сервер ioBroker; в [многохостовой системе](/docs/config/multihost.md) это главный сервер и все остальные хосты. Кнопка **«Информация»** в этом блоке раскрывает информацию об оборудовании и системе хоста.

<img src="media/admin_schnellzugriff_hostinfo.png" alt="Die Info-Ansicht einer Host-Kachel" width="340" />

## Настройте плитку

Вы можете свободно выбирать, какие плитки будут отображаться. Для этого нажмите на значок карандаша в правом нижнем углу. После этого каждая плитка будет отмечена галочкой, которую можно выбрать или снять отметку.

<img src="media/admin_schnellzugriff_edit.png" alt="Der Schnellzugriff im Bearbeitungsmodus" width="900" />

В режиме редактирования в правом нижнем углу расположены три кнопки:

- **+** создает отдельный элемент, например, для устройства в сети, которое не работает через ioBroker.
- **Флажок** сохраняет выбранный вариант.
- **X** их отвергает.
