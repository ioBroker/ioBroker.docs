## Что такое Redis, и когда его использование становится оправданным?

ioBroker поддерживает две базы данных: одну для **объекты** (структура) и одна для **Условия** (значения). Значение по умолчанию для обоих случаев: `jsonl`, это файл, который хранится в памяти во время работы.

**Редис** Это альтернатива штатам. Целесообразно использовать его, если многие значения меняются очень часто, в качестве приблизительного ориентира, начиная с нескольких тысяч штатов с частыми изменениями, или если... `memRss` Разработка js-контроллера заметно расширяется.

Пожалуйста, обрати внимание:

- Редис должен **сохраняется** В противном случае, настройки будут потеряны после перезагрузки.
- Резервная копия должна включать Redis. BackItUp может это сделать.
- Для объектов, как правило, `jsonl` лучший выбор.

Для типичной домашней установки настроек по умолчанию вполне достаточно. Изменение их без возникновения каких-либо проблем обычно лишь вносит дополнительный потенциальный источник ошибок.
