## Что такое Redis, и когда его использование становится оправданным?

ioBroker использует две базы данных: одну для **объектов** (структуры) и одну для **состояний** (значений). Настройки по умолчанию для обеих баз данных следующие...`jsonl` , это файл, который хранится в памяти во время работы.

**Redis** — это альтернатива для управления состояниями. Он целесообразен, если многие значения меняются очень часто, в качестве приблизительного ориентира, начиная с нескольких тысяч состояний с частыми изменениями, или если`memRss` Разработка js-контроллера заметно расширяется.

Пожалуйста, обрати внимание:

- Необходимо **обеспечить сохранение данных** в Redis, иначе состояния будут потеряны после перезагрузки.
- Резервная копия должна включать Redis. BackItUp может это сделать.
- Для объектов, как правило,`jsonl` лучший выбор.

Для типичной домашней установки настроек по умолчанию вполне достаточно. Изменение их без возникновения каких-либо проблем обычно лишь вносит дополнительный потенциальный источник ошибок.
