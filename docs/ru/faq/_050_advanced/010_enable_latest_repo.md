## Как получить бета-версию?

Иногда вас просят протестировать версию, которой ещё нет в репозитории. Обычно это относится к бета-версии адаптера.

Для системы, требующей надежной работы, бета-версия не подходит. Версии, размещенные там, еще не прошли полное тестирование, а возврат к предыдущей версии требует ручных действий.

### Лучший способ: использовать только один адаптер.

Начиная с версии Admin 5, это обязательно. **нет** Будет преобразован весь репозиторий:

- Он **Экспертный режим** Включите его. Значок находится в левом нижнем углу строки меню.
- В всаднике **адаптер** на **Установите из собственного источника.** вперед (символ с осьминожкой).
- В всаднике **Из npm** Выберите и установите необходимый адаптер.

Все остальные адаптеры по-прежнему поставляются из _стабильный_.

### Измените весь репозиторий.

Если когда-либо возникнет необходимость: В
[Системные настройки](/docs/admin/settings.md)
всадник **Репозитории** в колонке _Активный_ на **бета** выключатель.

<img src="media/faq_repositories.png" alt="Der Reiter Repositories in den Basiseinstellungen" width="900" />

Затем на вкладке «Адаптер» обновите список. Если активна бета-версия, появится предупреждение. Это сделано намеренно и служит напоминанием о необходимости вернуться к предыдущей версии.

Подробности: [Что такое репозиторий?](/docs/basics/repositories.md)
