## Что такое многохостовая система?

Несколько компьютеров вместе образуют установку ioBroker. Один из них является **главным** : на нем размещены две базы данных. Остальные компьютеры получают данные оттуда и запускают только свои собственные экземпляры.

Это имеет смысл прежде всего по двум причинам:

- **В пространственном отношении** : второй компьютер расположен там, где должен находиться беспроводной адаптер.
- **Балансировка нагрузки** : ресурсоемкие адаптеры работают на собственном оборудовании.

Все управление осуществляется через административную панель главного сервера; вкладка [«Экземпляры»](/docs/admin/instances.md) позволяет фильтровать по хосту, а вкладка [«Хосты»](/docs/admin/hosts.md) отображает каждый компьютер с его значениями.

Главный сервер — это единственная точка, от которой зависит всё. Если он выйдет из строя, вся система отключится. Многохостовая конфигурация **не** делает установку более отказоустойчивой, она просто увеличивает её первоначальный размер.
