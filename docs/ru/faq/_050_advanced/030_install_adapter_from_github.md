## Как установить адаптер из GitHub?

Только если разработчик явно запросит это. Всё, что находится на GitHub, — это незавершённая работа, и со временем она может стать непригодной для использования. Зависимости не затрагиваются таким типом установки. **нет** проверено.

- Он **Экспертный режим** включать.
- В всаднике **адаптер** на **Установите из собственного источника.** идти.
- В всадника **Из GitHub** Переключитесь и выберите адаптер.

<img src="media/faq_von_github.png" alt="Der Dialog Installieren aus eigener Quelle, Reiter Von GitHub" width="820" />

Всадник **Пользовательский** Принимает любой адрес, например, адрес конкретной ветки или репозитория другого разработчика. **Из файла**
Устанавливает локально доступный пакет.

### Снова здесь

Адаптер, загруженный с GitHub, не будет автоматически заменен следующим обновлением из репозитория. Его номер версии обычно выше официального. Вы можете вернуться назад через... _Установите определенную версию_ на обратной стороне переходной пластины.
