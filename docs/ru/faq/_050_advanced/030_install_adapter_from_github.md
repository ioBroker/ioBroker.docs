## Как установить адаптер из GitHub?

Только по явному запросу разработчика. Всё, что находится на GitHub, — это незавершённая работа, и в данный момент может быть непригодно для использования. При таком типе установки зависимости **не** проверяются.

- Включите **экспертный режим** .
- На вкладке **«Адаптер»** выберите **«Установить из локального источника»** .
- Перейдите на вкладку **«Из GitHub»** и выберите адаптер.

<img src="media/faq_von_github.png" alt="Der Dialog Installieren aus eigener Quelle, Reiter Von GitHub" width="820" />

Вкладка **«Пользовательские настройки»** позволяет указать любой адрес, например, конкретную ветку или репозиторий другого разработчика. «Установить **из файла»** устанавливает локально сохраненный пакет.

### Снова здесь

Адаптер, загруженный из GitHub, не будет автоматически заменен следующим обновлением из репозитория. Его номер версии обычно выше официального. Вы можете вернуться к предыдущей версии, выбрав _«Установить определенную версию»_ на обратной стороне значка адаптера.
