## В каких случаях следует устанавливать что-либо вручную с помощью npm?

Обычно: **совсем нет.**

ioBroker управляет собственными адаптерами.`npm install` вручную в каталоге`/opt/iobroker` Это создаёт файлы, о которых ioBroker не знает. Изменения будут потеряны при следующем обновлении; в худшем случае, установка будет повреждена.

Все необходимые действия выполняются через административную панель или другим способом.`iob` в командной строке. Команды перечислены в разделе [«Командная строка»](/docs/config/cli.md) .

Исключением являются дополнительные модули Node, для которых требуется собственный JavaScript-скрипт. Они не устанавливаются вручную, а вводятся в конфигурацию экземпляра JavaScript; затем ioBroker позаботится об этом.
