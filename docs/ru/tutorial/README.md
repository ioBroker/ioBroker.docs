# Учебные пособия

Главы [Основы](/docs/basics/README.md),
[установка](/docs/install/README.md) и
[Административный интерфейс](/docs/admin/README.md)
В них описывается, что представляет собой ioBroker и где находится каждая функция в панели администратора. Они предназначены для ознакомления.

Учебные пособия используют другой подход. Они берут задачу и проводят вас через весь процесс от начала до конца, при этом шаги выполняются в указанной последовательности. Каждое учебное пособие является самодостаточным и может быть пройдено за один раз. При последовательном чтении они показывают путь от только что установленной системы до полностью функциональной.

Требуется работающая установка. Тем, у кого её ещё нет, следует начать с... [установка](/docs/install/README.md)
к.
