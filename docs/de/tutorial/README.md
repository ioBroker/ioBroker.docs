# Tutorials

Die Kapitel [Grundlagen](/docs/basics/README.md),
[Installation](/docs/install/README.md) und
[Admin-Oberfläche](/docs/admin/README.md)
beschreiben, was ioBroker ist und wo im Admin welche Funktion sitzt. Sie sind
zum Nachschlagen gedacht.

Die Tutorials gehen den anderen Weg. Sie nehmen eine Aufgabe und führen sie von
Anfang bis Ende durch, mit den Handgriffen in der Reihenfolge, in der sie
anfallen. Jedes ist für sich abgeschlossen und in einer Sitzung zu schaffen. Der
Reihe nach gelesen ergeben sie einen Weg von der frisch installierten Anlage bis
zu einer, die etwas tut.

?> Vorausgesetzt wird eine laufende Installation. Wer noch keine hat, fängt bei
der [Installation](/docs/install/README.md)
an.

## Der Weg

| Schritt | Worum es geht |
| --- | --- |
| 1. [Die ersten Schritte](/docs/tutorial/setup.md) | Systemeinstellungen, Passwort, Datensicherung, erster Adapter. |
| 2. [Rundgang durch die Oberfläche](/docs/tutorial/admin.md) | Welche Reiter Sie täglich brauchen und welche selten. |
| 3. [Adapter verwalten](/docs/tutorial/adapter.md) | Adapter und Instanz, installieren, aktualisieren, zurückstufen. |
| 4. [Die erste Automatisierung](/docs/tutorial/logic.md) | Aus Werten Verhalten machen, mit Blockly. |
| 5. [Die erste Visualisierung](/docs/tutorial/viz.md) | Eine Oberfläche für die, die den Admin nie sehen wollen. |
| 6. [Werte aufzeichnen](/docs/tutorial/history.md) | Damit es später einen Verlauf gibt. |
| 7. [Diagramme](/docs/tutorial/flot.md) | Den Verlauf sichtbar machen. |
| 8. [Updates einspielen](/docs/tutorial/updates.md) | Was regelmäßig wiederkommt, und in welcher Reihenfolge. |
| 9. [Restore](/docs/tutorial/restore.md) | Der Ernstfall: eine Sicherung auf ein neues System zurückspielen. |

?> Wenn Sie nur zwei davon lesen: den ersten und den letzten. Die Datensicherung
einzurichten und einmal ausprobiert zu haben, sie zurückzuspielen, ist der
Unterschied zwischen einem Hobby und einem Ärgernis.
