# Mitmachen

ioBroker entsteht in der Freizeit von Freiwilligen. Es gibt keine Firma, die
Adapter in Auftrag gibt, und niemanden, der für das Beantworten von Fragen
bezahlt wird. Alles, was funktioniert, funktioniert, weil jemand sich die Mühe
gemacht hat.

Mitmachen setzt dabei kein Programmieren voraus. Die Liste ist nach Aufwand
sortiert, nicht nach Wichtigkeit:

| Beitrag | Was dafür nötig ist |
| --- | --- |
| **Fragen beantworten** | Erfahrung mit dem eigenen System. Wer ein Problem gerade selbst gelöst hat, kann es dem nächsten erklären. |
| **Lösungen nachtragen** | Fünf Minuten. Ein Forumsbeitrag, der mit „hat sich erledigt" endet, hilft niemandem. |
| **Fehler melden** | Sorgfalt beim Beschreiben. Siehe [Fehler melden](/docs/trouble/issue.md). |
| **Übersetzen** | Eine zweite Sprache. Adapter und Oberflächen brauchen laufend Übersetzungen. |
| **Dokumentation schreiben** | Ein Texteditor und ein GitHub-Konto. Siehe [Artikel schreiben](/docs/community/doc.md). |
| **Adapter entwickeln** | JavaScript oder TypeScript. Siehe [Adapterentwicklung](/docs/dev/adapterdev.md). |
| **Spenden** | Nichts weiter. Viele Adapter haben einen Spendenknopf in ihrer Konfiguration. |

## Wo das stattfindet

**Das [Forum](https://forum.iobroker.net)** ist der Ort für alles, was mit dem
Betrieb zu tun hat: Fragen, Lösungen, Ankündigungen, Diskussionen über neue
Adapter. Wie man dort gelesen wird, steht unter
[Forum](/docs/trouble/forum.md).

**[GitHub](https://github.com/ioBroker)** ist der Ort für den Quelltext: die
Adapter, der js-controller, der Admin, die Installationsskripte und diese
Dokumentation. Dorthin gehören Fehlerberichte und Verbesserungsvorschläge.

## Der einfachste Anfang

Wer nicht weiß, wo er anfangen soll: das nächste Mal, wenn Sie selbst ein
Problem gelöst haben, schreiben Sie die Lösung auf. In den Forumsbeitrag, in dem
Sie gefragt haben, oder in die Dokumentationsseite, auf der die Antwort
gefehlt hat. Das ist wenig Arbeit und genau das, was den meisten Leuten fehlt,
wenn sie suchen.
