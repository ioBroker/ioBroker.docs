## grundlegend

> Die Anweisungen beziehen sich auf Version 0.0.1.

Zunächst einmal ist dieser Adapter/diese Homepage nur für Deutschland. Ihre API (kostenlos) erhalten Sie unter " <https://www.eiswarnung.de/rest-api/> ".

Nach der Installation dieses Adapters werden Längen- und Breitengrad automatisch aus den iobroker-Einstellungen übernommen (sofern Sie diese Einstellungen vorgenommen haben). Falls Sie die iobroker-Einstellungen nicht ausfüllen, finden Sie Ihre Daten unter <https://www.gpskoordinaten.de/> .

Die Daten werden stündlich abgerufen.

Viel Spaß mit dem Adapter.
