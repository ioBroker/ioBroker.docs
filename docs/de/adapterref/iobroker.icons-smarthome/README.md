# ioBroker.icons-smarthome

## Icons-Smarthome-Adapter für ioBroker

Symbole, die von ioBroker-Visualisierungen wie webui, vis usw. verwendet werden können, wurden aus ioBroker.habpanel extrahiert.

Symbole, die von ioBroker-Visualisierungen wie webui, vis usw. verwendet werden können, extrahiert aus ioBroker.habpanel ( <https://github.com/iobroker-community-adapters/ioBroker.habpanel/tree/master/src/assets/icons> )
