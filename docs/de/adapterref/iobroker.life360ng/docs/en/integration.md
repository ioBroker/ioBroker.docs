# Registerkarte: Integration

Auf der Registerkarte **„Integration“** steuern Sie, welche Life360-Daten vom Adapter verarbeitet und als ioBroker-Objekte erstellt werden.

**Merkmale:**

- **Kreise, Orte, Personen:** Sie können individuell auswählen, ob Life360-Kreise, -Orte und -Personen importiert und synchronisiert werden sollen.
- **Standortverfolgung:** Aktivieren Sie diese Option, um festzulegen, ob die aktuellen Standorte von Personen kontinuierlich aktualisiert werden sollen.
- **Unbekannter Ort:** Definieren Sie einen Namen für Orte, die von Life360 nicht erkannt werden (z. B. „Unbekannt“).

**Hinweis:** Diese Einstellungen helfen Ihnen, die Anzahl Ihrer Adapterobjekte und den Datenverkehr auf ein Minimum zu reduzieren und eine klare Übersicht zu bewahren.
