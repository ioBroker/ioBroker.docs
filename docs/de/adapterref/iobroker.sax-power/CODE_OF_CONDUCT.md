# Verhaltenskodex

## Unsere Standards

Von den Projektteilnehmern wird Folgendes erwartet:

- Kommunizieren Sie respektvoll und konstruktiv.
- nützlichen technischen Kontext bereitstellen
- unterschiedliche Erfahrungsniveaus akzeptieren
- Kritik sollte sich auf Code und Verhalten beziehen, nicht auf Personen.
- Schutz privater und sicherheitsrelevanter Informationen
- Vermeiden Sie Belästigungen, Diskriminierung, Bedrohungen oder persönliche Angriffe.

## Umfang

Dieser Verhaltenskodex gilt für Projektdiskussionen, Issues, Pull Requests, Reviews und andere Bereiche, die das Projekt repräsentieren.

## Durchsetzung

Unangemessenes Verhalten kann zur Entfernung von Inhalten, zu vorübergehenden Einschränkungen oder zum dauerhaften Ausschluss aus den Projektbereichen führen.

Bedenken sollten vertraulich dem Projektverantwortlichen mitgeteilt und nicht öffentlich diskutiert werden.
