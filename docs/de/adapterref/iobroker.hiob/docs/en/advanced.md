## Fortgeschritten/Flexibel

- Wischen Sie nach links, um ein Widget zu löschen.
- Drücken Sie das Pluszeichen unten rechts.

![app\_template.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_template.png)

- `Name` Name des Widgets
- `Value` (optional): Zeigt den Text im Widget an. Wenn nichts angegeben wird, wird der Name verwendet.

![app\_create\_advanced\_value.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_advanced_value.png)

- Hauptteil: Wählen Sie hier das gewünschte Widget aus.

- `Value` Dies ermöglicht es, einen Wert anzuzeigen und für einen gegebenen Wert einen neuen Wert festzulegen.

- `Multi Selection` Hier können Sie ein Dropdown-Menü erstellen.

- `Slider` Mit dem Schieberegler können Sie Lampen dimmen oder Rollläden steuern.

- `Handle` Ein Schalter, bei dem der Wert angegeben werden kann.

- `Button` Aktuell gibt es nur eine Schaltfläche, um den Wert auf WAHR zu setzen.

![app\_create\_advanced\_select.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_advanced_select.png)

### Widget`Value`

- `Round to` : Nach dem Komma aufrunden
- `Unit (optional)` : Werteinheit
- `Device` Wählen Sie hier die gewünschte Aufzählung aus.
- `Datapoint` : Auswahl von Staaten aus der ausgewählten Aufzählung
- `Text Rules` Um eine Regel zu erstellen, klicken Sie auf`add` Geben Sie den Wert ein in`Old Value` wenn der Zustand dann überschrieben werden sollte mit`New Value` Drücken Sie dann`add` und falls keine neuen benötigt werden, drücken Sie`exit` Sobald der Wert 10 erreicht, wird der Status auf 20 gesetzt. Eine spätere Bearbeitung ist nicht mehr möglich. Die Regel kann nur durch Wischen gelöscht werden.

![app\_create\_advanced\_value\_view.png](img/../../de/img/app_create_advanced_value_view.png)![app\_create\_advanced\_value\_popup.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_advanced_value_popup.png)

- `Popup Menu` Hier können weitere Widgets erstellt werden. Durch langes Drücken auf ein Widget öffnet sich ein Popup-Menü mit den erstellten Widgets.
- Klicken Sie anschließend auf Speichern.
- Durch langes Drücken auf ein Widget wird der Kopiermodus aktiviert. Hier können Sie die Widgets auswählen, von denen eine Kopie erstellt werden soll.

![app\_create\_advanced\_value\_popup\_create\_1.png](img/../../de/img/app_create_advanced_value_popup_create_1.png)![app\_create\_advanced\_value\_popup\_create\_2.png](img/../../de/img/app_create_advanced_value_popup_create_2.png)![app\_create\_advanced\_value\_popup\_view\_done\_1.png](img/../../de/img/app_create_advanced_value_popup_view_done_1.png)![app\_create\_advanced\_value\_popup\_view\_done\_2.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_advanced_value_popup_view_done_2.png)

### Widget `Multi Selection`

![app\_create\_multi.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_multi.png)

- `Device` Wählen Sie hier die gewünschte Aufzählung aus.
- `Datapoint` : Auswahl von Staaten aus der ausgewählten Aufzählung

![app\_create\_multi\_device.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_multi_device.png)

- `Selections` Um eine Liste zu erstellen, klicken Sie auf`add` Geben Sie einen Namen für die Auswahl ein in`Display Value` und geben Sie den Wert ein, der in den Zustand verschoben werden soll.`File Point Value` Die Auswahl kann später durch langes Drücken sortiert werden. Eine Bearbeitung ist später nicht mehr möglich. Die Regel kann nur durch Wischen gelöscht werden.
- `Popup Menu` Hier können weitere Widgets erstellt werden. Durch langes Drücken auf ein Widget öffnet sich ein Popup-Menü mit den erstellten Widgets.
- Klicken Sie anschließend auf Speichern.
- Durch langes Drücken auf ein Widget wird der Kopiermodus aktiviert. Hier können Sie die Widgets auswählen, von denen eine Kopie erstellt werden soll.

![app\_create\_multi\_option.png](img/../../de/img/app_create_multi_option.png)![app\_create\_multi\_option\_1.png](img/../../de/img/app_create_multi_option_1.png)![app\_create\_multi\_option\_2.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_multi_option_2.png)
