## Wert

### Mit dem Wert können Sie beispielsweise eine Zeit festlegen.

- Wischen Sie nach links, um ein Widget zu löschen.
- Drücken Sie das Pluszeichen unten rechts.

![Webansicht](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_button_done.png)

- Dropdown-Menü: auswählen`Value` Die
- Name: Name des Widgets
- Wert (optional): Im Widget anzuzeigender Text. Wenn nichts angegeben wird, wird der Name verwendet.
- Runden auf: Auf wie viele Stellen nach dem Komma soll aufgerundet werden?
- Einheit (optional): Werteinheit.

![Webansicht](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_value.png)

- Gerät: Wählen Sie den gewünschten Eintrag aus.

![Webansicht](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_button_device.png)

- Datenpunkt: Auswahl von Staaten aus der ausgewählten Liste

![Webansicht](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_button_dp.png)

- Klicken Sie anschließend auf Speichern.
- Durch langes Drücken auf ein Widget wird der Kopiermodus aktiviert. Hier können Sie die Widgets auswählen, von denen eine Kopie erstellt werden soll.

![Webansicht](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_value_done.png)

- Füge das Widget einem Bildschirm hinzu und nutze es, um einen Zustand zu steuern. Halte das Widget gedrückt, um das Popup-Fenster zu öffnen, in dem der Wert geändert werden kann.

![Webansicht](img/../../de/img/app_create_value_done.png)![Webansicht](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_value_done.png)
