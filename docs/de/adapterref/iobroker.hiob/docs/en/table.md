## Tisch

### Mit Table können Sie JSON anzeigen.

- Wischen Sie nach links, um ein Widget zu löschen.
- Drücken Sie das Pluszeichen unten rechts.

![app\_create\_web\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_web_done.png)

- Dropdown-Menü: auswählen`Table` Die
- Name: Name des Widgets
- Kopfzeile: Kopfzeilentext aus der Tabelle
- Elemente pro Seite: Wie viele Elemente pro Seite angezeigt werden.
- erste Sortierung: Sortiert das Array (erstes Element)
- Gerät: Wählen Sie den gewünschten Eintrag aus.
- Datenpunkt: Auswahl von Zuständen aus der ausgewählten Sammlung - Der Wert muss ein Array mit JSON-Elementen enthalten.

![add\_create\_table.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_table.png)

- Beispiel-JSON

```json
[
  {
    "name": "Fenster Gäste WC",
    "zustand": "👈 geöffnet"
  },
  {
    "name": "Fenster Schlafzimmer",
    "zustand": "👈 geöffnet"
  },
  {
    "name": "Fenster Arbeitszimmer",
    "zustand": "☝️ gekippt"
  }
  {
    "name": "Dachfenster",
    "zustand": "🪟 geschlossen"
  }
]
```

- Hinzufügen: Erstellen Sie nun die gewünschten Spalten. Hier im Beispiel lautet das:`name` Und`state` Der Schlüssel aus dem JSON muss eingegeben werden.`column key` Sie können einen Namen zuweisen in`column name` Die

![add\_create\_table\_column\_1.png](img/../../de/img/add_create_table_column_1.png)![add\_create\_table\_column\_2.png](img/../../de/img/add_create_table_column_2.png)![add\_create\_table.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_table_column.png)

- Klicken Sie anschließend auf Speichern.
- Durch langes Drücken auf ein Widget wird der Kopiermodus aktiviert. Hier können Sie die Widgets auswählen, von denen eine Kopie erstellt werden soll.

![app\_create\_table\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_table_done.png)

- Füge das Widget einem Bildschirm hinzu.

![app\_create\_table\_screen.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_table_screen.png)
