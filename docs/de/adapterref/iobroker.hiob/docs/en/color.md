## Farbpalette

### Mit der Farbpalette kann ein HEX-Wert an einen Zustand übergeben werden.

- Wischen Sie nach links, um ein Widget zu löschen.
- Drücken Sie das Pluszeichen unten rechts.

![app\_create\_graph\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_graph_done.png)

## Farb-Widget

- Dropdown-Menü: Auswählen`Color Palette`
- Name: Name des Widgets
- Wert (optional): Im Widget anzuzeigender Text. Wenn nichts angegeben wird, wird der Name verwendet.
- Gerät: Auswahl von Aufzählungen
- Datenpunkt: Auswahl von Zuständen aus Aufzählungen - Der Wert muss ein STRING sein.
- Hexadezimalpräfix (optional): Präfix, z. B. 0x, # oder leer
- Alpha-Wert einschließen: Alpha-Wert - [ARGB](#argb)
- Farbtöne auswählen: [Farbtöne](#shades) aktivieren
- Primär- und Akzentfarben: Sowohl Primär- als auch Akzentfarben und ihre Nuancen. [Farbpalette](#primary--accent)
- Primärfarben: Primärfarben und ihre Schattierungen [Farbpalette](#primary)
- Akzent: Akzentfarben und ihre Nuancen [Farbpalette](#accent)
- Schwarzweiß: Schwarzweiß- [Farbpalette](#black--white)
- Farbrad: HSV-Farbauswahl [Farbpalette](#wheel)

![add\_create\_color.png](../de/img/add_create_color.png)![add\_create\_color\_1.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_color_1.png)

- Klicken Sie anschließend auf Speichern.
- Durch langes Drücken auf ein Widget wird der Kopiermodus aktiviert. Hier können Sie die Widgets auswählen, von denen eine Kopie erstellt werden soll.

![app\_create\_color\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_color_done.png)

- Bildschirm erstellen

![app\_create\_color\_screen.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_color_screen.png)

- Widget zum Bildschirm hinzufügen

![app\_create\_color\_add.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_color_screen_add.png)

- Fertig! Klicken Sie auf das Widget, um die Farbpalette zu öffnen.

![app\_create\_color\_screen\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/add_create_color_screen_done.png)
