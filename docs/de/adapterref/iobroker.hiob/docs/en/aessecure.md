# Schritt 1: AES-Zustände

- `hiob.0.devices.xxx.aesKey` Geben Sie diesen Schlüssel in die App ein.
- `hiob.0.devices.xxx.aesKey_active` Für Verschlüsselung auf „true“ setzen.
- `hiob.0.devices.xxx.aesKey_new` Generieren Sie einen neuen Schlüssel und geben Sie ihn in der App ein.
- `hiob.0.devices.xxx.aesKey_view` Den AES-Schlüssel 30 Sekunden lang sichtbar machen (Bild 2).

![aes\_iobroker.png](img/aes_iobroker.png)![aes\_iobroker.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/aes_iobroker_decrypt.png)

# Schritt 2: App-Einstellungen

- Aktivieren Sie das Kontrollkästchen „AES-Verschlüsselung verwenden“.
- Geben Sie den AES-Schlüssel von ioBroker ein.
