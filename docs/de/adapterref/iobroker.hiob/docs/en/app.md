## Installation und App-Einrichtung`ioBroker Settings`

# Schritt 1: Installation und App-Einrichtung

# Schritt 1: Instanzeinstellungen

1. Bitte geben Sie einen freien Port an (Standard ist 8090). Ist der gewählte Port belegt, wird der nächste freie Port verwendet. Diese Information wird im Protokoll gespeichert und muss anschließend in die Konfigurationsinstanz kopiert werden.
2. Für das Grafik-Widget benötigen Sie entweder den SQL- oder den History-Adapter, um Zustandsänderungen aufzuzeichnen. Bitte wählen Sie entweder eine SQL- oder eine History-Instanz aus.
3. Schalten Sie nun den Adapter ein.

![instance.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/instance.png)

# Schritt 2: Benutzer erstellen (OPTIONAL)

## Für die Passwortanmeldung muss ein neuer Benutzer angelegt werden.

1. Wählen Sie links Benutzer aus und fügen Sie rechts Benutzer hinzu.

![create\_user.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/create_user.png)

2. Geben Sie hier den Benutzernamen und das Passwort ein. Klicken Sie anschließend auf Speichern.

![create\_user\_with\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/create_user_with_pw.png)

# Schritt 3 mit Passwort: Mit Passwort anmelden (lokale Anmeldung)

1. Geben Sie hier die IP-Adresse Ihres ioBrokers, den Port, den Benutzernamen und das Passwort ein und drücken Sie die Schaltfläche „Wiederverbinden“.

![app\_login\_first.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_login_first.png)

2. Legen Sie anschließend unter „Objekte“ den Zustand fest.`approved` vom richtigen Gerät auf wahr (ohne das Häkchen bei Bestätigt)

![request\_approved\_wo\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/request_approved_wo_pw.png)

3. Stimmt das Passwort oder der Benutzername nicht, wechselt der Datenpunkt wieder auf false und in der APP wird ein roter Text`Login declined` angezeigt. Bitte dann den Benutzernamen und das Passwort überprüfen und den Datenpunkt erneut auf true setzen.

4. Wenn alles korrekt eingegeben wurde, erscheint nun der grüne Text „Angemeldet“.

![app\_login\_with\_pw.png](../de/img/app_login_with_pw.png)![approved\_with\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/approved_with_pw.png)

5. (Optional) Nun kann eine Weiterleitung eingerichtet werden, um auch außerhalb des Netzwerks zu surfen. Die App benötigt dafür die Berechtigung für den Standortzugriff. Geben Sie anschließend das WLAN-Netzwerk und die URL ein. Richten Sie nun eine Weiterleitung in der Fritz!Box ein. Davon wird jedoch abgeraten! Ein VPN-Zugang ist besser. Nutzen Sie beispielsweise die kostenpflichtige App „VpnCilla“.

![app\_access.png](../de/img/app_access.png)![app\_second\_ip.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_second_ip.png)

# Schritt 3 ohne Passwort: Mit Passwort anmelden (lokale Anmeldung)

1. Deaktivieren Sie das Kontrollkästchen „Passwort-Login verwenden“, geben Sie Ihre IP-Adresse und Ihren Port von ioBroker ein und drücken Sie die Schaltfläche „Neu verbinden“.

![app\_login\_first\_wo\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_login_first_wo_pw.png)

2. Den Zustand festlegen`noPwdAllowed` auf „wahr“ setzen (ohne das Häkchen bei „Bestätigt“) und dann die`approved` auf „wahr“ setzen (ohne das Häkchen bei „Bestätigt“).

![request\_approved\_wo\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/request_approved_wo_pw.png)

3. Wenn alles korrekt umgesetzt wurde, sollte es so aussehen.

![app\_login\_wo\_pw\_suc.png](../de/img/app_login_wo_pw_suc.png)![approved\_wo\_pw.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/approved_wo_pw.png)

# Wichtige Informationen

- Wenn Sie einen Benutzer blockieren möchten, setzen Sie einfach den Status „genehmigt“ auf „false“.
- Wenn Sie verbunden sind, erscheint nun oben links im Fenster ein grünes Häkchen.
- Wenn dort ein rotes WLAN-Symbol blinkt, kann keine Verbindung hergestellt werden. Entweder befinden Sie sich nicht im selben Netzwerk oder der Status „genehmigt“ ist falsch.

![app\_connection\_on.png](../de/img/app_connection_on.png)![app\_connection\_off.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_connection_off.png)
