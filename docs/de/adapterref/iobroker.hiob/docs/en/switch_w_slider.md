## Schalter mit Schieberegler

### Mit „Schalter mit Schieberegler“ können Sie einen Schalter mit Dimmfunktion (optional) erstellen.

- Wischen Sie nach links, um ein Widget zu löschen.
- Drücken Sie das Pluszeichen unten rechts.

![Schalter mit Schieberegler](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_value_done.png)

- Dropdown-Menü: auswählen`Switch with Slider` Die
- Name: Name des Widgets
- Wert (optional): Anzeigetext im Widget. Bleibt das Feld leer, wird der Name verwendet.
- Runden auf: Stellen nach dem Komma
- Einheit (optional): Werteinheit
- Gerät: Wählen Sie hier den gewünschten Eintrag aus.
- Datenpunkt: Auswahl von Zuständen aus der ausgewählten Liste - Zustand muss ein boolescher Wert (wahr/falsch) sein!

![Schalter mit Schieberegler](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_widget_switch.png)

- Soll die Helligkeit reduziert werden, muss ein Häkchen neben „Schieberegler“ gesetzt werden.
- Slider-Anzeige: Namen der Schieberegler.
- Min: Minimalwert (Standardwert 0).
- Max: Maximalwert (Standardwert 100).
- Schritte: In welchen Schritten Änderungen vorgenommen werden können (Standard 10).
- Gerät: Wählen Sie den gewünschten Eintrag aus.
- Datenpunkt: Auswahl von Bundesstaaten aus der ausgewählten Liste - der Bundesstaat muss eine Nummer sein!

![Schalter mit Schieberegler](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_widget_slider.png)

- Mit Reachable kann ein Popup erstellt werden, um einen Wert aus einem Zustand anzuzeigen.
- Erreichbares Element: Name des erreichbaren Elements.
- Gerät: Wählen Sie den gewünschten Eintrag aus.
- Datenpunkt: Auswahl von Zuständen aus der ausgewählten Liste - Zustand muss ein boolescher Wert (wahr/falsch) sein!

![Schalter mit Schieberegler](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_widget_reach.png)

- Klicken Sie anschließend auf Speichern.
- Durch langes Drücken auf ein Widget wird der Kopiermodus aktiviert. Hier können Sie die Widgets auswählen, von denen eine Kopie erstellt werden soll.

![Schalter mit Schieberegler](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_switch_done.png)

- Fügt das Widget einem Bildschirm hinzu und verwendet es zur Steuerung eines Zustands. Durch langes Drücken auf das Widget öffnet sich das Popup-Fenster. Im Popup kann der aktuelle Schaltstatus angezeigt oder ein Wert festgelegt werden.

![Schalter mit Schieberegler](img/../../de/img/app_create_switch_screen.png)![Schalter mit Schieberegler](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_switch_screen_popup.png)
