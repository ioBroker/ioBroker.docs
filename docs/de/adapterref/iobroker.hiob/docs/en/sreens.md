## Bildschirme erstellen`Screen Settings`

- Hier können nun Header-Screens erstellt und Widgets hinzugefügt werden. Widgets können nicht doppelt in Screens hinzugefügt werden.

- Wischen Sie nach links, um einen Bildschirm zu löschen. Sobald der letzte Bildschirm gelöscht ist, erscheint automatisch ein neuer Bildschirm mit der Bezeichnung „Vorlage“.

- Drücken Sie das Pluszeichen unten rechts, um einen neuen Bildschirm zu erstellen, oder klicken Sie auf „Vorlage“, um den Namen zu ändern.

![app\_create\_screen.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_screen.png)

- Geben Sie einen Namen ein, der in der Kopfzeile angezeigt werden soll, und wählen Sie ein Symbol aus. Klicken Sie anschließend auf Speichern.

![app\_create\_screen\_new.png](img/../../de/img/app_create_screen_new.png)![app\_create\_screen\_new\_pic.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_screen_new_pic.png)

- In diesem Bildschirm können Sie Gruppen erstellen, zusätzliche Untergliederungen und Widgets hinzufügen.
- Der Bildschirm kann mithilfe des Kontrollkästchens deaktiviert/aktiviert werden.`Enabled` Die
- Durch Klicken auf das Kreuz unten links werden Widgets hinzugefügt. In diesem Popup können Sie die Kategorien erweitern und mit einem Häkchen auswählen.

![app\_create\_screen\_widget.png](img/../../de/img/app_create_screen_widget.png)![app\_create\_screen\_widget\_select.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_screen_widget_select.png)

- Eine Gruppe kann durch Klicken auf die mittlere Schaltfläche erstellt werden.

![app\_create\_scen\_group.png](img/../../de/img/app_create_sceen_group.png)![app\_create\_screen\_group\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_screen_group_done.png)

- Widgets und Untergruppen können nun zu dieser Gruppe hinzugefügt werden.
- Mit`Expanded` Sie können festlegen, ob die Gruppe geöffnet oder geschlossen angezeigt wird.
- Es ist auch möglich, ein Symbol auszuwählen.

![app\_create\_screen\_group\_widget.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_screen_group_widget.png)

- Sie können eine Unterteilung erstellen, indem Sie die dritte Schaltfläche von links drücken. Alternativ lässt sich eine Unterteilung auch mithilfe eines Widgets erstellen. Legen Sie die Höhe fest und klicken Sie auf „Hinzufügen“.

![app\_create\_screen\_division.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_screen_division.png)

- Durch Drücken und Halten eines Widgets kann dessen Position geändert werden.

![app\_create\_screen\_change.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_screen_change.png)

- Die erstellten Bildschirme sollten nun so aussehen.

![app\_create\_screen\_done\_2.png](img/../../de/img/app_create_screen_done_2.png)![app\_create\_screen\_done\_1.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_screen_done_1.png)

- Wechseln Sie nun zur Bildschirmübersicht und drücken Sie das Haussymbol oben rechts, um die Bildschirme anzuzeigen.

![app\_create\_screen\_done\_3.png](img/../../de/img/app_create_screen_done_3.png)![app\_overview\_1.png](img/../../de/img/app_overview_1.png)![app\_overview\_2.png](img/../../de/img/app_overview_2.png)![app\_overview\_3.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_overview_3.png)
