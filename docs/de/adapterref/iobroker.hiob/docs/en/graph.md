## Graph (nur SQL-Adapter)

### Mit Graph können Sie Diagramme von Zuständen erstellen, die von SQL- oder Verlaufsadaptern aufgezeichnet wurden.

- Wischen Sie nach links, um ein Widget zu löschen.
- Drücken Sie das Pluszeichen unten rechts.

![app\_create\_table\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_table_done.png)

- Zuerst sollte eine Aufzeichnung gestartet werden. In den beiden Abbildungen wurde der SQL-Adapter als Beispiel verwendet. Klicken Sie auf „Benutzerdefinierte Einstellungen“ und aktivieren Sie SQL.

![create\_watch\_sql.png](img/create_watch_sql.png)![create\_watch\_sql\_activ.png](../../../../../en/adapterref/iobroker.hiob/docs/en/img/create_watch_sql_activ.png)

- Dropdown-Menü: auswählen`Graph (only sql Adapter)` Die
- Name: Name des Widgets
- Titel: Kopfzeile des Diagramms
- Y-Achse: Öffnen Sie die Gruppe „Y-Achse“ und drücken Sie die Schaltfläche „Y-Achse hinzufügen“.

![app\_create\_graph.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_graph.png)

- Wischen Sie nach links, um eine Y-Achse zu löschen.
- Es können mehrere Y-Achsen (vertikale Linien) erstellt werden, die dann beim Erstellen der Linie ausgewählt werden können.
- Beschreibung: Beschreibung der Skalierung
- min: Skalierung starten. Hier beginne ich mit 1.
- max: Ende der Saklation. Im Beispiel 100
- Intervall: Skalierungsintervall. Im Beispiel wird 10 eingegeben. Daher wird 1, 11, 22, 33, xxx angezeigt.

![app\_create\_graph\_y\_add.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_graph_y_add.png)

- Wischen Sie nach links, um eine X-Achse zu löschen.
- X-Achse: Öffnen Sie die X-Achsen-Gruppe und drücken Sie`Button Add X Axis` Die
- Es können mehrere X-Achsen (horizontale Linien) erstellt werden, die dann beim Erstellen der Linie ausgewählt werden können.
- Beschreibung: Beschreibung der Skalierung
- Achsenende: Ende der Skalierung (siehe Abbildung für Optionen).
- Bereich: Wie oft die Bereichseinheit angezeigt werden soll. Wenn Sie jetzt eingeben`hour` Unter „Einheit für den Geltungsbereich“ wird eine Stunde angezeigt. Wenn Sie 4 eingeben, werden 4 Stunden angezeigt.
- Bereichseinheit: Wählen Sie hier die Einheit aus (siehe Abbildung für Optionen).

![app\_create\_graph\_x\_add.png](img/../../de/img/app_create_graph_x_add.png)![app\_create\_graph\_x\_add\_end.png](img/../../de/img/app_create_graph_x_add_end.png)![app\_create\_graph\_x\_add\_unit.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_graph_x_add_unit.png)

- Wischen Sie nach links, um eine Zeile zu löschen.
- Linien: Öffnen Sie die Gruppe „Linien“ und klicken Sie auf die Schaltfläche „Linie hinzufügen“.
- Es können mehrere Linien (das Diagramm) erstellt werden.
- Name: Dieser Name wird im Diagramm als Überschrift angezeigt.
- Gerät: Wählen Sie den gewünschten Eintrag aus.
- Datenpunkt: Auswahl des von SQL überwachten Zustands.
- Linientyp: Wählen Sie den Linientyp (siehe Abbildung für Optionen).
- x-Achse: Auswahl aller x-Achsen.
- y-Achse: Auswahl aller y-Achsen.
- Mindestzeit für das nächste Update: Zeitpunkt, zu dem das Update spätestens erfolgen sollte. Es wird beim Start der App automatisch aktualisiert.
- Datenpunkt anzeigen: Der Name des Bundesstaates wird angezeigt.

![app\_create\_graph\_line.png](img/../../de/img/app_create_graph_line.png)![app\_create\_graph\_line\_type.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_graph_line_type.png)

- Kugelverfolgung: Auf „Ein“ stellen, wenn Markierungen eingestellt werden sollen.

![app\_create\_graph\_tracking.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_graph_tracking.png)

- Klicken Sie anschließend auf Speichern.
- Durch langes Drücken auf ein Widget wird der Kopiermodus aktiviert. Hier können Sie die Widgets auswählen, von denen eine Kopie erstellt werden soll.

![app\_create\_graph\_done.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_graph_done.png)

- Fügt das Widget einem Bildschirm hinzu.

![app\_create\_graph\_screen.png](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_graph_screen.png)
