## Webansicht

### Mit Web View können Sie eine Webseite anzeigen.

- Wischen Sie nach links, um ein Widget zu löschen.
- Drücken Sie das Pluszeichen unten rechts.

![Webansicht](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_division_done.png)

- Dropdown-Menü: auswählen`Web View` Die
- Name: Name des Widgets
- URL (optional): Eine URL wie z. B.:`http://192.168.x.x:8082/iqontrol/index.html?namespace=iqontrol.0`
- Gerät: Wählen Sie den gewünschten Eintrag aus.
- Datenpunkt: Auswahl des Zustands, in dem eine Webadresse gespeichert ist. Durch Ändern des Zustands wird die Adresse aus diesem Zustand aktualisiert oder verwendet.
- Höhe: Die Höhe des Widgets. Ist die Größe zu klein, wird das Bild der Webseite möglicherweise abgeschnitten.
- JavaScript aktiviert: Ermöglicht die Ausführung von JavaScript-Dateien.

![Webansicht](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_web.png)

- Klicken Sie anschließend auf Speichern.
- Durch langes Drücken auf ein Widget wird der Kopiermodus aktiviert. Hier können Sie die Widgets auswählen, von denen eine Kopie erstellt werden soll.

![Webansicht](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_web_done.png)

- Füge das Widget einem Bildschirm hinzu.

![Webansicht](../../../../../en/adapterref/iobroker.hiob/docs/de/img/app_create_web_screen.png)
