# KLF-200 Adapterdokumentation

Dieser Adapter dient zur Steuerung einer VELUX® KLF-200 Schnittstelle. Er ist weder ein offizielles VELUX Produkt noch wird er vom Hersteller der VELUX Produkte unterstützt.

Dieser Adapter dient primär der Steuerung elektrischer Dachfenster und/oder elektrischer Jalousien oder Rollläden. Obwohl die KLF-200-Schnittstelle auch den Anschluss weiterer Geräte wie Lampen, Schalter, Stoffrollos usw. ermöglicht, habe ich den Adapter nicht mit solchen Geräten getestet. Es sollte jedoch möglich sein, diese Geräte ebenfalls mit diesem Adapter zu steuern.

Der Adapter funktioniert mit der offiziellen TCP/IP-Schnittstelle des KLF-200, die mit der Veröffentlichung der Firmware-Version 2.0.0.71 dokumentiert wurde. Die Ein- und Ausgänge des Geräts müssen nicht verkabelt werden, der KLF-200 muss jedoch über ein Ethernet-Kabel mit einem LAN verbunden werden.

---

## Bereiten Sie Ihre KLF-200-Schnittstelle vor.

Um diesen Adapter zu verwenden, müssen Sie Ihre KLF-200-Box im **Schnittstellenmodus** einrichten. Er funktioniert nicht, wenn Sie Ihre Box als Repeater verwenden.

Der Adapter funktioniert nur über den LAN-Anschluss Ihres KLF-200.

> Eine detaillierte Anleitung zur Durchführung der folgenden Aufgaben finden Sie in den Handbüchern, die Ihrer Verpackung beilagen.
>
> Es wird davon ausgegangen, dass Sie sich erfolgreich über einen Webbrowser in Ihr System eingeloggt haben.

### Produkte einrichten

Jedes Produkt, das Sie mit diesem Adapter steuern möchten, muss auf der Seite „Meine Produkte“ registriert werden. Sie können neue Produkte entweder durch

- Von einer anderen Fernbedienung kopieren
- Produkte suchen

Wenn alle Ihre Produkte registriert sind, sollten Sie eine Liste wie die folgende sehen:

![Screenshot der „Meine Produkte“-Oberfläche des KLF-200](../../../../../en/adapterref/iobroker.klf200/docs/en/img/ProductList.PNG)

### Szenenaufbau

> **Wichtige Änderungen:**
>
> **Mit der neuen Firmware müssen Sie nicht mehr für jeden gewünschten Produktzustand eine Szene definieren.**

Dieser Schritt ist optional. Sie können Szenen aufzeichnen, um verschiedene Produkte mit einem einzigen Schritt zu ändern, z. B. können Sie eine Szene definieren, die alle Fenster schließt.

Um eine Szene aufzunehmen, müssen Sie auf die Schaltfläche klicken.

![Aufnahmetaste](../../../../../en/adapterref/iobroker.klf200/docs/en/img/RecordProgramButton.PNG)

Dadurch öffnet sich das Fenster _„Aufnahme läuft“_ . Verwenden Sie nun Ihre mitgelieferte Fernbedienung, um eine Änderung vorzunehmen, z. B. das Fenster auf 40 % zu vergrößern. Geben Sie anschließend einen Namen für das Programm ein und klicken Sie auf _„Programm speichern“_ .

![Screenshot der laufenden Aufnahme](../../../../../en/adapterref/iobroker.klf200/docs/en/img/RecordingInProgress.PNG)

> HINWEIS:
>
> - Geben Sie Ihrem Programm einen aussagekräftigen Namen, auch wenn der Adapter keine Namenskonventionen verwendet.

Wenn Sie die Programmaufzeichnungen abgeschlossen haben, erhalten Sie eine Liste wie die folgende:

![Screenshot der Programmliste](../../../../../en/adapterref/iobroker.klf200/docs/en/img/ProgramList.PNG)

### Verbindungen einrichten

Dieser letzte Schritt ist optional. Falls Sie die Eingangs- und Ausgangsleitungen nicht verwenden, ist Ihnen möglicherweise aufgefallen, dass die kleine LED am Gehäuse ständig blinkt. Um das störende Blinken zu beseitigen, müssen Sie mindestens eine Verbindung herstellen.

Sie müssen es nur in der Box einrichten, Sie brauchen nichts zu verkabeln! Wählen Sie einfach, was Ihnen gefällt.

## Konfigurieren Sie den Adapter

![Screenshot der Adapterkonfiguration](../../../../../en/adapterref/iobroker.klf200/docs/en/img/AdapterConfiguration.PNG)

### Gastgeber

Hostname Ihrer KLF-200-Schnittstelle. Dies ist derselbe Name, den Sie in die Adresszeile Ihres Webbrowsers eingeben, um eine Verbindung zu Ihrem Gerät herzustellen.

### Passwort

Das Passwort, das Sie für die Verbindung zu Ihrer KLF-200-Schnittstelle benötigen. Bei neueren Versionen der KLF-200 ist es das WLAN-Passwort, das auf der Rückseite des Geräts aufgedruckt ist. Falls Sie die KLF-200 mit einer Firmware-Version vor 2.0.0.71 verwendet und anschließend ein Upgrade durchgeführt haben, ist es das Passwort, mit dem Sie sich in der Weboberfläche angemeldet haben, sofern Sie dieses vor dem Upgrade geändert hatten.

> Das Standardpasswort des KLF-200 ist auf der Rückseite des Geräts aufgedruckt, aber Sie sollten es trotzdem geändert haben!

Falls Sie Ihr Passwort vergessen haben, können Sie Ihr KLF-200 auf die Werkseinstellungen zurücksetzen:

- Das Passwort wird auf das WLAN-Passwort zurückgesetzt.
- **Alle Ihre Produkte, Szenen, Gruppen und sonstigen Einstellungen werden vom KLF-200 gelöscht und müssen erneut verbunden werden. Falls Sie keine andere Fernbedienung besitzen, von der Sie Ihre Produkte kopieren können, müssen Sie auch Ihre Produkte zurücksetzen.**

Um eine Szene auszuführen, können Sie entweder die`run` Lage der Szene zu`true` oder Sie können die`level` den Zustand des Produkts auf einen Wert setzen, der einer Szene entspricht, die das Produkt auf dieses Niveau setzt.

### Beispiele

Angenommen, Ihr Badezimmerfenster ist ein Kanal`0` Du hast eine Szene auf Kanal`10` Dadurch werden alle Fenster geschlossen.

```javascript
// Example 1: Open the bathroom window at 40%:
await setStateAsync("klf200.0.products.0.targetPosition", 40);
/* 
    The following will happen:
    1. Several states will be changed to reflect the current operation, e.g. the remainingTime.
    2. Your window will start to move to 40% opening level. (If it's not blocked, e.g. by the rain sensor.)
    3. After your window has stopped (for whatever reason), several states will be changed again, including the currentPosition.
*/

// Example 2: Close all windows by running scene 10:
await setStateAsync("klf200.0.scenes.10.run", true);
/*
    The following will happen:
    1. All related products will receive updates to their states to reflect the current operation.
    2. All windows will start to move to 0% openening level.
    3. After the scene has finished, the run state is set to false, again.
*/
```

## Bekannte Einschränkungen

- Wenn Sie neue Szenen im Gerät definieren, müssen Sie den Adapter neu starten, damit die neuen Szenen eingelesen werden.
- Die Zeitzone ist auf Mitteleuropäische Zeit (MEZ) festgelegt (GMT+1/GMT+2 für die Sommerzeit).
