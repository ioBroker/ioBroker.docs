# vis-2-widgets-inventwo — Dokumentation

Dieser Ordner enthält die Benutzerdokumentation für das **inventwo** Widget-Set für ioBroker VIS 2.

Mit den Widgets können Sie direkt im VIS 2-Editor vollständig gestaltete Dashboards erstellen – Schaltflächen, Schieberegler, Tabellen, Dropdown-Menüs, scrollenden Text und mehr – ohne eine einzige Zeile Code schreiben zu müssen.
