# Universelles Widget – Styling und Formen

Das Universal-Widget bietet vielfältige Gestaltungsmöglichkeiten, die direkt in der Seitenleiste des VIS 2-Editors konfiguriert werden können. Die Stile sind in benannten Gruppen organisiert. Die meisten Gruppen verfügen über ein Feld **„Von Widget“** , mit dem Sie Einstellungen von einem anderen Universal-Widget kopieren können.

---

## Wie Staaten und Styling zusammenwirken

Die **Standardzustandsgruppe** und jede nummerierte **Zustandsgruppe** definieren, wie die Kachel aussieht, wenn ein bestimmter Datenpunktwert aktiv ist. Innerhalb jedes Zustands legen Sie Folgendes fest:

- **Hintergrundfarbe**
- **Inhaltsfarbe** (Symboltönung, Bildfilter)
- **Textfarbe**
- **Rahmenfarbe**
- **Farben des äußeren/inneren Schattens**
- **Inhaltsblinkintervall** (Blinkgeschwindigkeit in ms — 0 = kein Blinken)
- **Klick deaktivieren, wenn aktiv** – Wenn diese Option für einen Zustand aktiviert ist, wird ein Klick auf die Kachel ignoriert, solange dieser Zustand aktiv ist. Nützlich für Navigationskacheln (verhindert erneutes Klicken auf die bereits aktive Ansicht) oder Mehrfachauswahlfelder (verhindert die erneute Eingabe desselben Werts). Nicht verfügbar für den Typ **„Schreibgeschützt“** .
- **Spiegelung** – Spiegelungsüberschreibung pro Zustand: **Standard (vom Inhalt)** verwendet die globale Spiegelungseinstellung der Inhaltsstilgruppe; **Ja** erzwingt die Spiegelung des Inhalts in diesem Zustand; **Nein** verhindert die Spiegelung.
- Das anzuzeigende Symbol, Bild, der Text oder die eingebettete Ansicht

In der Gruppe **„Inventwo Widget Design“** (die angezeigt wird, wenn Sie auf die Statusgruppen klicken) werden diese Farben pro Status konfiguriert.

---

## Stilgruppen

### inventwo — Text

Steuert das Erscheinungsbild der Textbeschriftung innerhalb der Kachel.

| Einstellung                            | Was es tut                                         |
| -------------------------------------- | -------------------------------------------------- |
| **Textdekoration**                     | Unterstreichen, Überstreichen oder Durchstreichen. |
| **Textausrichtung**                    | Horizontale Textausrichtung: Anfang, Mitte, Ende.  |
| **Rand oben / unten / links / rechts** | Platz um den Text innerhalb der Kachel herum.      |

Schriftart, -größe, -stärke und -farbe werden in den Standard-CSS-Einstellungen des VIS-Widgets und in den **Textfarbfeldern** pro Bundesstaat festgelegt.

---

### inventwo — Inhalt

Steuert die Größe und Positionierung des Inhalts (Symbol, Bild usw.) innerhalb der Kachel.

| Einstellung                                 | Was es tut                                                                                     |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Inhaltsgröße**                            | Größe des Symbols oder Bildes. Kann ein Pixelwert oder ein Prozentsatz der Kachelgröße sein.   |
| **Drehung**                                 | Dreht den Inhalt um einen beliebigen Winkel (Grad).                                            |
| **Spiegel**                                 | Spiegelt den Inhalt horizontal.                                                                |
| **Skalieren Sie die Größe entsprechend an** | _(Nur im Widget anzeigen)_ Skaliert die eingebettete Ansicht so, dass sie in die Kachel passt. |
| **Fülltyp**                                 | _(Nur Bildinhalt)_ So füllt das Bild die Kachel: Umschließen, Abdecken, Füllen, Wiederholen.   |
| **Position**                                | _(Nur Bildinhalt)_ Bildposition innerhalb der Kachel.                                          |

---

### inventwo — Ausrichtung

Steuert, wie Inhalt und Text innerhalb der Kachel zueinander angeordnet sind.

| Einstellung                              | Was es tut                                                                                    |
| ---------------------------------------- | --------------------------------------------------------------------------------------------- |
| **Inhalt ausrichten**                    | Horizontale Ausrichtung des Inhaltselements: Start, Mitte, Ende, Abstand dazwischen.          |
| **Textausrichtung (Ausrichtungsgruppe)** | Vertikale oder horizontale Ausrichtung des Textes.                                            |
| **Reihenfolge umkehren**                 | Vertauscht die Reihenfolge von Inhalt und Text (z. B. Text über dem Symbol anstatt darunter). |

---

### inventwo — Transparenz

| Einstellung              | Was es tut                                                                               |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| **Hintergrunddeckkraft** | Deckkraft des Kachelhintergrunds (0 = vollständig transparent, 1 = vollständig deckend). |
| **Inhaltstransparenz**   | Deckkraft des Inhaltselements (Symbol, Bild usw.).                                       |

---

### inventwo — Abstand

Legt den inneren Abstand der Kachel fest – den Raum zwischen dem Kachelrand und ihrem Inhalt.

| Einstellung                                  | Was es tut                                                                  |
| -------------------------------------------- | --------------------------------------------------------------------------- |
| **Polsterung oben / unten / links / rechts** | Abstand vom Rand der Kachel bis zum Inhalt innerhalb der Kachel, in Pixeln. |

---

### inventwo — Randradius

Steuert die Form der Fliesenecken. Jede Ecke kann unabhängig konfiguriert werden.

| Einstellung                                               | Was es tut                                                                                                                              |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **Eckstil**                                               | Wie die Ecken gestaltet sind: **Abgerundet** (Standard – sanfte Kurve) oder **Abgeschrägt** (gerader 45°-Schnitt).                      |
| **Oben links / Oben rechts / Unten rechts / Unten links** | Eckengröße in Pixeln. Bei _abgerundeten Ecken_ entspricht dies dem Kurvenradius; bei _abgeschrägten_ Ecken der Länge des Fasenschnitts. |

> **Hinweis:** Wenn eine Polygonform aktiv ist, haben die Einstellungen für den Eckenradius keine Auswirkung. Verwenden Sie stattdessen die Einstellung **für den Eckenradius** in der Gruppe **„Form“ von inventwo** .

---

### inventwo — Grenze

Fügt einen Rahmen um die Fliese hinzu.

| Einstellung                             | Was es tut                                                                                                         |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Rahmenstil**                          | Linienart: Keine, Durchgezogen, Gestrichelt, Gepunktet, Doppelt, Nut, Grat, Einzug.                                |
| **Größe oben / unten / links / rechts** | Rahmenstärke pro Seite in Pixeln.                                                                                  |
| **Rahmenfarbe**                         | Standard-Rahmenfarbe (wird auch pro Bundesstaat in den Gruppen „Standard-Bundesstaat“ / „Bundesstaat“ festgelegt). |

---

### inventwo — Äußerer Schatten

Fügt einen Schlagschatten außerhalb der Kachel hinzu.

| Einstellung                     | Was es tut                                                                                                                                                                                      |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Farbe des äußeren Schattens** | Schattenfarbe (Standardzustand). Kann auch pro Zustand in den Zustandsgruppen festgelegt werden.                                                                                                |
| **X-Offset**                    | Horizontaler Schattenversatz in Pixeln.                                                                                                                                                         |
| **Y-Offset**                    | Vertikaler Schattenversatz in Pixeln.                                                                                                                                                           |
| **Verwischen**                  | Radius der Schattenunschärfe.                                                                                                                                                                   |
| **Größe**                       | Größe des Schattenwurfs.                                                                                                                                                                        |
| **Zusätzliche Schatten**        | Anzahl (0–5) weiterer Schatten. Jeder Schatten hat einen eigenen X/Y-Versatz, eine eigene Unschärfe, Größe und Farbe; der erste Schatten wird darüber gezeichnet. Versätze können negativ sein. |

---

### inventwo — Innerer Schatten

Fügt einen eingelassenen Schatten innerhalb der Fliese hinzu (erzeugt einen vertieften/gepressten Effekt).

Die Einstellungen entsprechen denen des äußeren Schattens, einschließlich zusätzlicher Schatten (z. B. ein heller Schatten oben links und ein dunkler unten rechts für einen neumorphen Effekt). In den Zustandsgruppen kann eine Farbe pro Zustand festgelegt werden.

---

### inventwo — Form

Das Formsystem ermöglicht es Ihnen, die Kachel in eine geometrische Form zuzuschneiden. Alle Formen außer Rechteck verwenden CSS clip-path, sodass Hintergrund, Rahmen und Schatten in der ausgewählten Form weiterhin sichtbar sind.

![Übersicht des Formsystems](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_shapes.png)

| Einstellung                          | Was es tut                                                                                                                                                                                                                             |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Form**                             | Die Form der Kachel: Rechteck (Standard, kein Clipping), Dreieck, Raute, Fünfeck, Sechseck, Siebeneck, Achteck, Stern, Benutzerdefiniert.                                                                                              |
| **Formrotation**                     | Dreht die Polygon-Clip-Form. Unabhängig von der Inhaltsdrehung.                                                                                                                                                                        |
| **Eckradius**                        | Rundet die Ecken von Polygonformen ab. Die Standardeinstellung für den Rahmenradius von **inventwo – Rahmenradius** wird für Polygonformen ignoriert – verwenden Sie stattdessen diese Option.                                         |
| **Benutzerdefinierte Polygonpunkte** | _(Nur benutzerdefinierte Formen)_ Durch Kommas getrennte X%/Y%-Paare im Uhrzeigersinn, z. B. `40% 0%, 100% 50%, 40% 100%, 0% 50%`. Der `%` Das Zeichen ist optional. Ist der Pfad ungültig, wird die Kachel durch ein Rechteck ersetzt. |

> **Tipp:** Erstellen Sie mithilfe des Tools unter [bennettfeely.com/clippy](https://bennettfeely.com/clippy/) visuell benutzerdefinierte Polygonformen und fügen Sie das Ergebnis in **Custom polygon points** ein.

---

### Feedback zum Klick

Beim Anklicken kann die Kachel kurz in einer anderen Farbe aufleuchten, um dem Benutzer eine visuelle Bestätigung zu geben, dass der Klick registriert wurde.

| Einstellung                     | Was es tut                                                   |
| ------------------------------- | ------------------------------------------------------------ |
| **Hintergrund**                 | Hintergrundfarbe während des Drückens.                       |
| **Inhaltsfarbe**                | Farbe des Inhalts (Symbols) im Moment des Drückens.          |
| **Textfarbe**                   | Textfarbe während des Druckvorgangs.                         |
| **Rahmenfarbe**                 | Rahmenfarbe im Moment des Drückens.                          |
| **Farbe des äußeren Schattens** | Farbe des äußeren Schattens im Moment des Drückens.          |
| **Farbe des inneren Schattens** | Farbe des inneren Schattens im Moment des Drückens.          |
| **Dauer**                       | Wie lange die gedrückte Farbe in Millisekunden sichtbar ist. |

## Stilwiederverwendung mit „Vom Widget“

Die meisten Stilgruppen verfügen oben über eine Option **„Von Widget“** . Wenn Sie hier ein anderes universelles Widget auswählen, werden alle Einstellungen dieser Gruppe zur Laufzeit vom ausgewählten Widget kopiert.

**So verwenden Sie es:**

1. Erstellen Sie ein universelles „Master“-Widget und konfigurieren Sie dessen Aussehen genau nach Ihren Wünschen.
2. Wählen Sie auf allen anderen Kacheln das jeweilige Master-Widget in jedem „ **Von“-Widget-** Feld aus.
3. Immer wenn Sie den Stil des Master-Widgets ändern, werden alle Kacheln, die darauf verweisen, automatisch aktualisiert.

Dies ist die empfohlene Vorgehensweise für Dashboards mit vielen einheitlich aussehenden Kacheln – den Stil einmal konfigurieren, überall wiederverwenden.
