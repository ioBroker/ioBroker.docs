# Universelles Widget – Inhaltstypen

Die Einstellung **„Inhaltstyp“** (in der Gruppe „ **Allgemein** “) definiert, was in der Kachel des Universal-Widgets angezeigt wird. Inhalt und Darstellung können für jeden Status separat konfiguriert werden.

![Übersicht der Inhaltstypen](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_types.png)

---

## Symbol

**Verwendungszweck:** Symbolische visuelle Darstellung eines Zustands – eine Glühbirne für ein/aus, ein Schloss für gesichert/entriegelt, ein Thermometer für Heizung usw.

**So funktioniert es:** Sie wählen eine Symboldatei aus der ioBroker-Symbolbibliothek aus (oder laden Ihre eigene hoch). Das Symbol wird in der Kachel gerendert und kann in jeder beliebigen Farbe eingefärbt werden.

![Symbolinhaltstyp](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_icon.png)

**Einstellungen pro Bundesstaat (in den Gruppen „Standardstatus“ / „Bundesstaaten“):**

- **Symbol** — Wählen Sie das Symbol aus, das in diesem Zustand angezeigt werden soll.
- **Inhaltsfarbe** — Die in diesem Zustand auf das Symbol angewendete Farbtönung.
- **Inhaltsfarbe true** — _(getrennte Schaltflächen / Zustand mit wahrem Wert)_ Farbton für den aktiven Zustand.

**Inhaltsgestaltung (in der Gruppe „inventwo - Inhalt“):**

- **Inhaltsgröße** — Größe des Symbols in Pixeln oder als Prozentsatz der Kachel.
- **Drehung** — Das Symbol kann um einen beliebigen Winkel gedreht werden.
- **Spiegeln** – Das Symbol horizontal spiegeln.

---

## Bild

**Verwendungszweck:** Fotos, Hintergrundgrafiken, benutzerdefinierte Illustrationen oder beliebige Bilddateien als visueller Inhalt der Kachel.

**So funktioniert es:** Sie geben eine URL oder einen Dateipfad zu einem Bild ein, und dieses wird innerhalb der Kachel angezeigt.

![Bildinhaltstyp](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_image.png)

**Einstellungen pro Bundesstaat:**

- **Bild** — URL oder Pfad zur Bilddatei für diesen Zustand.
- **Bild true** — Bild, das im aktiven/wahren Zustand verwendet wird (für Schalterkacheln).

**Bildstyling (in der Gruppe „inventwo - Content“):**

- **Fülltyp** – Wie das Bild die Kachelfläche ausfüllt:
  - **Contain** — Das Bild passt vollständig in die Kachel (es kann Leerraum lassen).
  - **Cover** — Das Bild füllt die Kachel vollständig aus (Ränder können beschnitten werden).
  - **Füllen** — Das Bild wird so gestreckt, dass es die Kachel exakt ausfüllt.
  - **Wiederholung** — Das Bild wird gekachelt (wiederholt), um die Fläche auszufüllen.
- **Position** — Die Position des Bildes innerhalb der Kachel (wird mit Contain verwendet).

---

## HTML-Text

**Verwendungszweck:** Anzeige von formatiertem Text, Werten oder einfachem HTML-Inhalt innerhalb einer Kachel.

**So funktioniert es:** Sie geben Text oder HTML-Markup in das **Textfeld** ein. Der Inhalt wird als HTML innerhalb der Kachel gerendert.

![Bildinhaltstyp](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_html.png)

**Einstellungen pro Bundesstaat:**

- **Text** – Der Text- oder HTML-Inhalt für diesen Zustand. Sie können verwenden `<b>`, `<i>`, `<span style="...">` und ähnliche Tags.
- **Text true** — Textinhalt für den aktiven/wahren Zustand.

**Die Textformatierung** wird über die **inventwo - Textgruppe** gesteuert (Schriftgröße, -stärke, Ausrichtung, Dekoration, Ränder).

> **Sicherheitshinweis:** Verwenden Sie im HTML-Textfeld ausschließlich vertrauenswürdige Inhalte. Geben Sie keine nicht validierten Benutzereingaben direkt in dieses Feld ein.

---

## Im Widget anzeigen

**Verwendungszweck:** Einbetten einer anderen VIS-Ansicht als Inhalt einer Kachel – zum Beispiel einer Mini-Übersicht oder eines Unterpanels.

**So funktioniert es:** Wählen Sie einen VIS-Ansichtsnamen aus, und dieser wird innerhalb der Kachel gerendert.

**Einstellungen pro Bundesstaat:**

- **In Widget anzeigen** — Die VIS-Ansicht, die in diesen Zustand eingebettet werden soll.
- **Im Widget anzeigen true** — Im aktiven/true-Zustand eingebettete Ansicht.

**Inhaltsgestaltung:**

- **Anpassen** – Skaliert die eingebettete Ansicht so, dass sie in die Kachel passt. Aktivieren Sie diese Option, wenn die eingebettete Ansicht größer als die Kachelgröße ist.

---

## Farbauswahl

**Verwendungszweck:** Interaktive Farbsteuerung – Steuerung von RGB-Leuchten, LED-Streifen oder beliebigen Geräten, die Farbsignale empfangen.

**So funktioniert es:** Innerhalb der Kachel wird eine interaktive Farbauswahl dargestellt. Die ausgewählte Farbe wird in einem oder mehreren Datenpunkten gespeichert.

![Inhaltstyp der Farbauswahl](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_colorpicker.png)

**Einstellungen (in der Gruppe „Widget-Inhalt – Farbauswahl“):**

| Einstellung                    | Was es tut                                                                                                                                                                                                    |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Objekt-ID (Farbauswahl)**    | Hauptdatenpunkt, in den die Farbe geschrieben wird (im Format, das Ihrem Farbmodell entspricht).                                                                                                              |
| **Oid-Wert 1 / 2 / 3**         | Zusätzliche Datenpunkte für einzelne Farbkomponenten (z. B. R, G, B separat).                                                                                                                                 |
| **Farbmodell**                 | Das Format des angegebenen Wertes: **HSV** , **HSL** , **RGB** , **RGB (Skaliert)** , **CIE** , **Hex** , **Hex 8** (Hex mit Alpha).                                                                          |
| **Maximalwert**                | _(Nur RGB (skaliert))_ Der Maximalwert für jeden R-, G- und B-Kanal. Standardwert: 1023. Verwenden Sie diesen Wert für 10-Bit-Controller (0–1023) oder Geräte, die keine Standardwerte von 0–255 akzeptieren. |
| **Showrad**                    | Zeigt den kreisförmigen Farbkreis.                                                                                                                                                                            |
| **Showbox**                    | Zeigt das Farb-/Sättigungsfeld an.                                                                                                                                                                            |
| **Farbton anzeigen**           | Zeigt den Farbtonregler an.                                                                                                                                                                                   |
| **Farbsättigung anzeigen**     | Zeigt den Sättigungsregler an.                                                                                                                                                                                |
| **Wert anzeigen**              | Zeigt den Helligkeitsregler (Wertregler) an.                                                                                                                                                                  |
| **Rot / Grün / Blau anzeigen** | Zeigt die einzelnen R-, G- und B-Regler an.                                                                                                                                                                   |
| **Alpha anzeigen**             | Zeigt den Deckkraft-/Alpha-Regler an.                                                                                                                                                                         |
| **Zeig Kelvin**                | Zeigt den Schieberegler für die Farbtemperatur (Kelvin).                                                                                                                                                      |
| **Breite**                     | Breite des Farbwählers in Pixeln.                                                                                                                                                                             |
| **Griffgröße**                 | Größe der Griffe des Farbwählers.                                                                                                                                                                             |
| **Griffmarge**                 | Rand um die Griffe.                                                                                                                                                                                           |
| **Komponentenbereich**         | Vertikaler Abstand zwischen den Farbauswahlkomponenten.                                                                                                                                                       |
| **Rahmenbreite / Rahmenfarbe** | Fügt einen Rahmen um die Farbauswahlkomponenten hinzu.                                                                                                                                                        |
| **Richtung**                   | Layoutrichtung: **Horizontal** oder **Vertikal** .                                                                                                                                                            |

**Tipp für RGB-Leuchten:** Stellen Sie **das Farbmodell** auf **Hex** ein und verbinden Sie **die Objekt-ID (Farbauswahl)** mit dem Farbdatenpunkt Ihres Lichtadapters. Aktivieren Sie nur die von Ihrer Leuchte unterstützten Steuerelemente – z. B. nur das Farbrad für den Farbton und den Helligkeitsregler.

## Analoge Uhr

**Verwendungszweck:** Anzeige der aktuellen Ortszeit in den Uhrkacheln des Dashboards.

**So funktioniert es:** Eine analoge Echtzeituhr wird in die Kachel integriert und aktualisiert sich jede Sekunde. Es ist keine Datenpunktverbindung erforderlich.

![Inhaltstyp der analogen Uhr](../../../../../../../en/adapterref/iobroker.vis-2-widgets-inventwo/docs/en/img/preview_content_clock.png)

**Einstellungen (in der Gruppe „Widget-Inhalt – Analoge Uhr“):**

**Zifferblatt:**

| Einstellung          | Was es tut                                                                                                                                                                                                                             |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Design**           | Schriftart: **Klassisch** (Zahlen + lange Striche), **Modern** (minimalistische Striche), **Minimal** (sehr übersichtlich, keine Zahlen), **Striche** (nur Striche), **Benutzerdefiniert** (Striche und Zahlen manuell konfigurieren). |
| **Gesichtsfarbe**    | Farbe der Elemente des Zifferblatts (Striche, Zahlen).                                                                                                                                                                                 |
| **Hintergrundfarbe** | Füllfarbe hinter dem Zifferblatt.                                                                                                                                                                                                      |

**Benutzerdefinierte Gesichtseinstellungen** (nur wenn **Design** auf **Benutzerdefiniert** eingestellt ist):

| Einstellung         | Was es tut                                                                                                            |
| ------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Tickintervall**   | Welche Optionen sollen angezeigt werden: **Nur Stunden** , **Beides** (Stunden und Minuten).                          |
| **Zeckendicke**     | Dicke der Minutenstriche.                                                                                             |
| **Hauptdicke**      | Dicke der Stundenstriche.                                                                                             |
| **Ticklänge**       | Länge der Minutenticks.                                                                                               |
| **Hauptticklänge**  | Länge der Stunden-Ticks.                                                                                              |
| **Zahlen anzeigen** | Welche Zahlen sollen angezeigt werden: **Alle Zahlen** (alle 12), **Nur die Hauptstunden** (12, 3, 6, 9), **Keine** . |
| **Zahlengröße**     | Schriftgröße der Stundenzahlen.                                                                                       |
| **Nummernversatz**  | Abstand der Zahlen von den Teilstrichen.                                                                              |

**Uhrschlag:**

| Einstellung   | Was es tut                                       |
| ------------- | ------------------------------------------------ |
| **Showring**  | Zeichnet einen Kreis um das gesamte Zifferblatt. |
| **Ringdicke** | Dicke des Rings.                                 |

**Zeiger** (Stunde, Minute, Sekunde – jeweils unabhängig):

| Einstellung | Was es tut                                                                                                                                      |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Zeigen**  | Ob diese Hand sichtbar ist.                                                                                                                     |
| **Design**  | Zeigerform: **Klassisch** (standardmäßig spitz zulaufende Zeigerform), **Modern** (dünne rechteckige Zeigerform), **Pfeil** (Pfeilspitzenform). |
| **Farbe**   | Farbe dieser Hand.                                                                                                                              |
