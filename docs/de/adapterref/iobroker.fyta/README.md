# ioBroker.fyta

## FYTA-Adapter für ioBroker

Inoffizieller Adapter zur Verbindung von ioBroker mit [FYTA-Pflanzensensoren.](https://fyta.de/) Sensoren sind im [FYTA-Shop](https://fyta.de/collections/all) erhältlich.
