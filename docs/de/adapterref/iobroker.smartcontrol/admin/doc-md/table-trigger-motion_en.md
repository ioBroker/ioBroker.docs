Hier können Sie Ihre Bewegungsmelder eingeben. Optional können Sie auch Helligkeitsstufen und entsprechende Schwellenwerte definieren.

| Spalte                                                                                                                                 | Obligatorisch | Beschreibung                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------------------------------------------------------------------------------------------------------------- | :-----------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ![Bild](https://github.com/iobroker-community-adapters/ioBroker.smartcontrol/blob/master/admin/doc-md/img/check_box-24px.svg?raw=true) |       Ja      | Aktiviert/deaktiviert diese Tabellenzeile. Ist sie nicht aktiviert, wird sie vom Adapter ignoriert. In den Adapteroptionen unter „WEITERE OPTIONEN > Eingabevalidierung“ können Sie festlegen, dass auch deaktivierte Zeilen auf Gültigkeit geprüft werden.                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Name des Bewegungssensors                                                                                                              |       Ja      | Beliebige Bezeichnung für den Bewegungsmelder.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Bewegungssensor                                                                                                                        |       Ja      | Status des Bewegungssensors. Es wird erwartet, dass dieser Status ein boolescher Wert ist, also auf „true“ setzen.`true` wenn Bewegung vorhanden ist und zu`false` Wenn keine Bewegung erkannt wird, was bei fast allen Bewegungsmeldern der Fall ist. Sollten die Zustände Ihrer Bewegungsmelder abweichen, verwenden Sie bitte Aliase. Siehe [Forumdiskussion](https://forum.iobroker.net/post/492267) .                                                                                                                                                                                                                                                                                                               |
| Abschnitt                                                                                                                              |      NEIN     | Nach Ablauf dieser Anzahl von Sekunden (und sofern in der Zwischenzeit keine weitere Bewegung festgestellt wird) werden die Zielgeräte ausgeschaltet.<br> Zum Deaktivieren: Feld leer lassen oder auf 0 setzen.<br> Weitere Informationen: Sobald der Bewegungssensor auf „“ eingestellt ist`false` Wenn keine Bewegung mehr erkannt wird, startet ein Timer mit der hier angegebenen Zeit in Sekunden. Nach Ablauf dieser Zeit werden die in den jeweiligen Zonen definierten Zielgeräte abgeschaltet. Wenn eine neue Bewegung auftritt (Bewegungsmelderstatus auf „Aktiviert“), wird der Timer wieder aktiviert.`true` Während der Timer läuft, wird der Timer zurückgesetzt und die Zielgeräte bleiben eingeschaltet. |
| (Symbol: Timer aus)                                                                                                                    |      NEIN     | Wenn diese Option aktiviert ist, wird für die bereits eingeschalteten Zielgeräte kein Ausschalttimer eingestellt. Anwendungsbeispiel: [siehe Forenbeitrag](https://forum.iobroker.net/post/433871) .                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

### Optional: Helligkeit (Lux)

| Spalte             | Obligatorisch | Beschreibung                                                                                                                                                                                                                                                                                   |
| ------------------ | :-----------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Helligkeitszustand |      NEIN     | Zustand, der die aktuelle Helligkeit widerspiegelt.                                                                                                                                                                                                                                            |
| Schwelle           |      NEIN     | Schwellenwert für die Helligkeit. Wenn die aktuelle Helligkeit unter „Helligkeitsstatus“ diesen Wert überschreitet, wird die Bewegung ignoriert.<br> Bitte beachten Sie auch die Option _„Helligkeit nicht überprüfen, wenn Zone aktiviert ist“_ unter „WEITERE OPTIONEN > Bewegungssensoren“. |

### Optional: Verknüpfte Geräte

| Spalte              | Obligatorisch | Beschreibung                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------- | :-----------: | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Verknüpfte Auslöser |      NEIN     | Hier können Sie „Andere Auslöser“ auswählen; diese lösen die entsprechende Zone auf die gleiche Weise aus wie der Bewegungssensor.<br> Erstellen Sie den Auslöser unter „Andere Auslöser“ in der unten stehenden Tabelle und fügen Sie diesen neuen Auslöser unter „Bewegungssensor“ unter „Verknüpfte Auslöser“ hinzu.<br><br> _Anwendungsbeispiel:_ Wird ein Wandschalter eingeschaltet, soll das Licht nach x Sekunden ausgehen, sofern keine Bewegung erkannt wird (Beispiel: ein Flur mit einem intelligenten Wandschalter und einem Bewegungsmelder). Wird eine Bewegung erkannt, wird der Timer des Wandschalters deaktiviert und der Timer des Bewegungsmelders aktiviert.<br><br> **Hinweis:** Falls Sie gerade „Andere Trigger“ erstellt haben und diese nicht sofort hier angezeigt werden, wechseln Sie zu einem anderen Tab und dann wieder zurück zu diesem Tab (oder speichern und schließen Sie die Adapterinstanz und öffnen Sie sie erneut). |
| Abschnitt           |      NEIN     | Für „Verknüpfte Auslöser“: Geben Sie die Anzahl der Sekunden ein, nach denen die Zone ausgeschaltet wird, wenn keine Bewegung erkannt wird und ein „Verknüpfter Auslöser“ das Einschalten ausgelöst hat.<br> _Hinweis:_ Sie können diese Sekundenanzahl hier separat einstellen (der Adapter übernimmt dann nicht die oben angegebene Sekundenanzahl), da diese erst dann wirksam wird, wenn der Bewegungssensor keine Bewegung mehr erkennt. Bei Xiaomi-Geräten dauert dies beispielsweise 2 Minuten. Sie können hier also eine andere Zeit einstellen.                                                                                                                                                                                                                                                                                                                                                                                                       |
| ✖                   |      NEIN     | Bei „Verknüpften Auslösern“ gilt: Ist diese Option aktiviert, wird die Zone nur durch verknüpfte Auslöser (z. B. Wandschalter) eingeschaltet, niemals jedoch durch den Bewegungsmelder. Das bedeutet, dass das Gerät nicht eingeschaltet wird, wenn eine Bewegung erkannt wird. Wird die Zone jedoch über einen Wandschalter (eingestellt unter „Verknüpfte Geräte“) eingeschaltet und wird vor dem Ausschalten eine Bewegung erkannt, schaltet sich die Zone aus, sobald keine Bewegung mehr festgestellt wird. Weitere Informationen finden Sie in [Problem #42](https://github.com/Mic-M/ioBroker.smartcontrol/issues/42) .                                                                                                                                                                                                                                                                                                                                 |
