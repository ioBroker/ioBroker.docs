Sie können die Option **„Immer ausführen“** auswählen. Dann wird die Zone immer ausgeführt, wenn eine der zuvor definierten Bedingungen erfüllt ist.<br> Wenn Sie jedoch weitere Bedingungen definieren möchten, sollten Sie diese Option deaktivieren. Anschließend wird eine Tabelle mit den folgenden Optionen angezeigt:

Ist sie nicht aktiviert, wird sie vom Adapter ignoriert.
