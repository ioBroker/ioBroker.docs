Ist sie nicht aktiviert, wird sie vom Adapter ignoriert. In den Adapteroptionen unter „WEITERE OPTIONEN > Eingabevalidierung“ können Sie festlegen, dass auch deaktivierte Zeilen auf Gültigkeit geprüft werden.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

| Zustand                                                                                                          |       Ja      | Ein bestehender Zustand als Auslöser.<br><br> Wenn Sie die SC-Option aktivieren, wird der Status unter erstellt`smartcontrol.x.userstates` , d.h. wenn Sie z.B. eingeben`Bath.Radio.on` Der Staat wird wie folgt geschaffen:`smartcontrol.x.userstates.Bath.Radio.on` Diesen können Sie dann als Auslöser verwenden, indem Sie den entsprechenden **Statuswert** festlegen. Der Status wird standardmäßig vom Typ „String“ erstellt, sofern Sie nichts anderes angeben.`true` oder`false` Im Feld „Statuswert“ wird dieser als „Boolescher Wert“ angelegt. Anwendungsfall: Angenommen, Sie benötigen einen Status, der ausgelöst werden soll, z. B. „Heimkino an“, der von Alexa aktiviert wird. Dadurch entfällt die manuelle Erstellung von Statuswerten. |
| Zustandswert                                                                                                     |       Ja      | Sobald der Statuswert diesem Wert entspricht, wird der Auslöser aktiviert. Sie können verwenden`true` ,`false` Zahlen wie`144` oder Zeichenketten wie`ABCDEF` Die<br> Außerdem können Sie Vergleichsoperatoren verwenden.`<` ,`>` ,`>=` ,`<=` , Und`!=` oder`<>` vor den Zahlen. Um beispielsweise eine Aktion auszulösen, wenn die Temperatur über 20 °C liegt, geben Sie Folgendes ein:`>20` Die<br> Alle Leerzeichen und Anführungszeichen (`"` etc.) am Anfang und Ende werden automatisch entfernt.                                                                                                                                                                                                                                                    |
| Ziel aus                                                                                                         |      NEIN     | Normalerweise werden die Zielgeräte beim Auslösen eingeschaltet (1. ZIELGERÄTE > 'Zustand zum Einschalten des Geräts' / 'Wert für Ein'). Wenn Sie diese Option aktivieren, wird das Gerät nicht eingeschaltet, sondern ausgeschaltet (1. ZIELGERÄTE > 'Zustand zum Ausschalten des Geräts' / 'Wert für Aus').<br> Hinweis: Wenn **die Option „Umschalten“** aktiviert ist, wird diese Option ignoriert.                                                                                                                                                                                                                                                                                                                                                     |
| Umschalten                                                                                                       |      NEIN     | Ist diese Option aktiviert, kann ein Schalter als Auslöser verwendet werden. Sind die Zielgeräte ausgeschaltet, schaltet der Auslöser sie ein und umgekehrt (sind sie eingeschaltet, schaltet der Auslöser sie aus). Der Adapter verwendet die Einstellung „Status zum Einschalten des Geräts“ unter „1. ZIELGERÄTE“, um festzustellen, ob das Gerät bereits eingeschaltet ist.<br> Hinweis: Wenn die Option **„Ziel aus“** gleichzeitig aktiviert ist, wird die Option **„Ziel aus** “ ignoriert, da dies sonst für eine „Umschaltoption“ keinen Sinn ergeben würde.                                                                                                                                                                                       |
