Dokumentation zur Installation von ioBroker und zur Verbindung mit HA

# ioBroker-Installation

ioBroker installieren

- Wenn Sie Proxmox verwenden, nutzen Sie das Proxmox-Skript <https://tteck.github.io/Proxmox/#iobroker-lxc>
- Manuelle Installation unter Linux: curl -sLf <https://iobroker.net/install.sh> | bash -
- Oder finden Sie hier weitere Informationen [: https://www.iobroker.net/#en/download](https://www.iobroker.net/#en/download)

Nach der Installation müssen Sie die IP-Adresse und den Port 8081 aufrufen.

Nach dem Begrüßungsbildschirm folgen die Authentifizierung und weitere Anpassungsschritte.

Schließlich werden Sie sehen:

Gehen Sie zur Konfigurationsseite des Adapters.

![beenden](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-24%20um%2021.48.02.png)

Klicken Sie auf Fertigstellen!

Sie können IOB Ihr Zuhause erkennen lassen und die Installation passender Adapter anfordern. Sie können diesen Schritt überspringen, indem Sie direkt auf „Schließen“ klicken.

# Installation des ecoflow-mqtt-Adapters

Sie sollten mit dem Abschnitt „Adapter“ in der Seitenleiste beginnen.

Geben Sie im Suchfeld ecoflow ein.

Eine Karte erscheint; klicken Sie auf die 3 Punkte.

![Adapter](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-24%20um%2021.51.08.png)

Klicken Sie auf das Pluszeichen, um den Adapter zu installieren und eine Instanz hinzuzufügen.

![Adapter](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-24%20um%2021.52.08.png)

Nach der Installation öffnet sich direkt die Administrationsseite des Adapters.

![Adapter](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-24%20um%2021.55.45.png)

Sie müssen die 3 Registerkarten ausfüllen.

- ANMELDEDATEN & DEBUG-EINSTELLUNGEN -> Zugriff auf den EF MQTT-Server (Ihre Anmeldedaten von der EF-App)
- GERÄTEKONFIGURATION -> Gerätetyp und Seriennummer Ihres Geräts
- HOME ASSISTANT -> Zugriff auf den HA MQTT-Server

Mit SPEICHERN UND SCHLIESSEN wird der Adapter gestartet oder neu gestartet.

# Ecoflow-Einstellungen

Sie benötigen die Zugangsdaten für den EF MQTT-Server. Dafür haben Sie drei Möglichkeiten:

1. per Skript <https://github.com/mmiller7/ecoflow-withoutflow/blob/main/cloud-mqtt/ecoflow_get_mqtt_login.sh>
2. von der Website <https://energychain.github.io/site_ecoflow_mqtt_credentials/>
3. durch den eigenen Algorithmus des Adapters (Drücken des Knopfes), hierfür sind der Benutzername und das Passwort der Ecoflow-APP erforderlich.

Bei der dritten Methode werden die Anmeldeinformationen direkt an den MQTT-Authentifizierungsbereich übertragen.

Andernfalls müssen Sie die Werte in die Felder kopieren und einfügen.

- mqtt userId (Ihre E-Mail-Adresse, umgewandelt in eine ID, letzter Teil der mqtt clientId) z. B. 151.......
- Der MQTT-Benutzername (MQTT User) beginnt mit app-.
- mqtt pwd (MQTT-Passwort)
- mqtt clientId (MQTT Client ID (Beispiel)) z. B. ANDROID\_666498788\_1....

Hinweis: Gegebenenfalls muss die Standardserveradresse (mqtts\://mqtt-e.ecoflow\.com) geändert werden. Die Überprüfung kann über die Website <https://energychain.github.io/site_ecoflow_mqtt_credentials/> erfolgen, indem die Serveradresse überprüft wird.

# HA-Einstellungen

Aktivieren Sie das HA-Kommunikationsgateway.

![ha\_enable](../../../../../../en/adapterref/iobroker.ecoflow-mqtt/doc/en/IOB_HA/Bildschirmfoto%202025-01-24%20um%2022.32.14.png)

Die IP-Adresse der HA-Installation muss angegeben werden, die anderen Einstellungen sollten mit ihren Standardwerten funktionieren.

Sie können den ursprünglichen HA-Benutzer oder einen anderen Benutzer für die MQTT-Verbindung verwenden. Der Benutzer, der in den HA-MQTT-Authentifizierungseinstellungen eingegeben wird, muss mit der HA-MQTT-Konfiguration übereinstimmen.
