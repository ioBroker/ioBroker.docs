## Was benötigt SourceAnalytix (Node.js, js-Controller, Admin)?

<!-- abschnitt: prio=B; gewicht=12; readme=partial; cluster=logs-install-26,upgrade-migration-other-14; features=req-versions,req-admin-ui-i18n -->

<!-- muss beantworten: Mindestversionen von Node.js, js-controller und Admin; Admin-Versionen, mit denen die Oberfläche läuft. -->

**Kurz gesagt:** Ab Version 0.7.0 benötigt SourceAnalytix Node.js 22, js-controller 6.0.11 und Admin 8.0.0 oder neuer. Admin 8 ist erforderlich, da die Seite mit den Instanzeinstellungen und den Registerkarten „Übersicht“ und „Probleme“ auf Komponenten von Admin 8 basiert.

<!-- quelle: code=io-package.json:161-170; code=package.json:11-13; issue=#1269 -->

|               | ab Version 0.7.0  | Version 0.6.0 bis 0.6.x |
| ------------- | ----------------- | ----------------------- |
| Node.js       | 22 oder neuer     | 22 oder neuer           |
| js-Controller | 6.0.11 oder neuer | 6.0.11 oder neuer       |
| Administrator | 8.0.0 oder neuer  | 7.8.23 oder neuer       |

<!-- quelle: code=io-package.json:161-170; code=package.json:11-13; code=io-package.json:161-170@v0.6.1; code=package.json:11-13@v0.6.1 -->

Überprüfen Sie die Versionen in der Konsole mit `iobroker -v` (js-controller) und `node -v` (Node.js). Falls Ihr System eine Anforderung nicht erfüllt, aktualisieren Sie bitte zuerst die entsprechende Komponente und anschließend SourceAnalytix. Versionen 0.6.0 bis 0.6.x sind mit Admin 7.8 und Admin 8 kompatibel. Ältere Aussagen aus dem Forum, wie z. B. „funktioniert mit Admin 6“, sind nicht mehr gültig.

<!-- quelle: code=.github/ISSUE_TEMPLATE/BugReport.md:31-32; code=io-package.json:161-170@v0.6.1; issue=#1202; forum=938927 -->

### Wenn SourceAnalytix nach einem Node.js-Update nicht startet

Wenn das Protokoll anzeigt `TypeError: Class extends value … is not a constructor or null` Nach einem Node.js-Update ist der js-Controller meist veraltet. Aktualisieren Sie den js-Controller und führen Sie ihn anschließend aus. `iob fix` Starten Sie die Instanz in der Konsole neu. Falls ioBroker in Docker ausgeführt wird, aktualisieren Sie stattdessen das Container-Image und stellen Sie gegebenenfalls Ihr Backup wieder her.

<!-- quelle: forum=1195593; forum=218835 -->

**Siehe auch:** [Wie aktualisiere ich SourceAnalytix (und was ist ein Downgrade)?](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/02.anleitungen/05.betrieb-und-wartung.md#update-sourceanalytix-downgrade) · [Probleme bei der Installation und der Admin-Ansicht](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/04.fehlerbehebung/01.log-meldungen.md#installation-admin-display-problems)

## Wie installiere ich SourceAnalytix und erstelle eine Instanz?

<!-- abschnitt: prio=B; gewicht=12; readme=missing; cluster=logs-install-24,setup-ui-03; features=req-versions,req-admin-ui-i18n -->

<!-- muss beantworten: Installation über den Admin-Store oder GitHub; danach Instanz anlegen (nur eine Instanz nötig). -->

**Kurz gesagt:** In den ioBroker-Systemeinstellungen das Repository auf „Neueste“ (Beta) umstellen und SourceAnalytix auf dem Tab „Adapter“ installieren. Der Administrator erstellt die Instanz. `sourceanalytix.0` Öffnen Sie anschließend die Instanzeinstellungen und richten Sie Ihre erste Quelle auf der Registerkarte „Übersicht“ ein.

<!-- quelle: interview=21; forum=1133140; forum=215063 -->

SourceAnalytix ist derzeit nur im Repository „latest“ verfügbar, nicht in „stable“. Nach einer Testphase wird es in „stable“ verschoben. Wenn „stable“ ausgewählt ist, wird es nicht in der Adapterliste angezeigt.

<!-- quelle: interview=21; forum=1133140 -->

### So geht's (ab Version 0.7.0)

1. Prüfen Sie die [Anforderungen](#requirements-sourceanalytix-have-node-js) , insbesondere Admin 8.
2. Öffnen Sie im Admin-Bereich die Systemeinstellungen und wählen Sie unter „Repositories“ das „neueste“ (Beta-)Repository als aktives Repository aus.
3. Öffnen Sie den Tab „Adapter“, aktualisieren Sie die Adapterliste und suchen Sie nach „SourceAnalytix“.
4. Installieren Sie den Adapter. Der Administrator erstellt die Instanz. `sourceanalytix.0` und startet es.
5. Öffnen Sie auf der Registerkarte „Instanzen“ die Einstellungen von `sourceanalytix.0` Auf der Registerkarte „Übersicht“ wird die Karte „SourceAnalytix einrichten“ mit den Schritten „Preis erstellen“, „Quelle hinzufügen“ und „Werte anzeigen“ angezeigt.
6. Erstellen Sie auf der Registerkarte „Preisdefinitionen“ mindestens eine Preisdefinition, beispielsweise für Strom in kWh, und speichern Sie diese. Durch das Speichern wird der Adapter neu gestartet.
7. Klicken Sie auf der Registerkarte „Übersicht“ auf „Erste Quelle hinzufügen“. Weitere Informationen finden Sie [unter Wo konfiguriere ich SourceAnalytix für einen Datenpunkt?](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/01.erste-schritte/02.erster-zaehler.md#configure-sourceanalytix-datapoint)

<!-- quelle: interview=21; forum=1133140; forum=953340; code=admin/jsonConfig.json:1-45; code=src-admin/src/SourcesApp.tsx:245-279; code=src-admin/src/Wizard.tsx:553-595; code=src-admin/src/i18n/de.json -->

![Direkt nach der Installation befindet sich die Registerkarte „Übersicht“ mit der Karte „SourceAnalytix einrichten“.](../../../../../../en/adapterref/iobroker.sourceanalytix/docs/en/01.erste-schritte/img/einrichten.png)

Die Registerkarten „Übersicht“ und „Probleme“ benötigen eine laufende Instanz. Ist diese gestoppt, erscheint oben die Meldung „Instanz läuft nicht“ mit einer Schaltfläche „Starten“. Alle mit ⚡ markierten Aktionen sind bis dahin gesperrt.

<!-- quelle: code=src-admin/src/SourcesApp.tsx:111-140; code=src-admin/src/SourcesApp.tsx:474-476; code=src-admin/src/Wizard.tsx:955-961 -->

### Es gibt keinen Fall

Wenn Sie SourceAnalytix über die Konsole mit npm oder über eine GitHub-URL installiert haben, erstellt ioBroker keine Instanz. Erstellen Sie diese manuell über das Plus-Symbol im Adminbereich. Eine Instanz genügt für alle Quellen.

<!-- quelle: forum=1133140; forum=953340; forum=1143623; forum=215074; forum=378273 -->

> \[!HINWEIS] Die Installation über eine GitHub-URL ist nur zu Testzwecken und auf Anweisung des Entwicklers vorgesehen. Administratoren sehen keine Aktualisierungen für eine solche Installation. Informationen zum „neuesten“ Repository finden Sie unter [Wie aktualisiere ich SourceAnalytix (und was ist ein Downgrade)?](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/02.anleitungen/05.betrieb-und-wartung.md#update-sourceanalytix-downgrade)

<!-- quelle: forum=213055; forum=938927; interview=21 -->

**Bis Version 0.6.x:** Die Instanzeinstellungen enthalten nur „Haupteinstellungen“ und „Preisdefinitionen“. Quellen werden dort aktiviert, am Datenpunkt auf der Registerkarte „Objekte“, der mit dem Schraubenschlüssel-Symbol gekennzeichnet ist.

<!-- quelle: code=admin/jsonConfig.json:1-8@v0.6.1; code=admin/jsonConfig.json:142-143@v0.6.1; code=main.js:106-137@v0.6.1 -->

## Benötige ich mehrere Instanzen oder Versionen nebeneinander?

<!-- abschnitt: prio=B; gewicht=5; readme=missing; cluster=setup-ui-16,upgrade-migration-other-23; features=source-enable -->

<!-- muss beantworten: Eine Instanz reicht für alle Datenpunkte; zwei Versionen parallel sind nicht möglich; Instanz löschen. -->

**Kurz gesagt:** Nein. Eine Instanz kann beliebig viele Quellen mit jeweils eigenen Einstellungen verarbeiten. Es ist nicht möglich, zwei Versionen von SourceAnalytix parallel auszuführen, da ioBroker jeweils nur eine Version jedes Adapters installiert.

<!-- quelle: code=main.js:126-145; forum=969466; issue=#158 -->

### Eine Instanz für alles

Die Einstellungen einer Quelle gelten pro Instanz. Sie werden im Datenpunkt unter `common.custom.sourceanalytix.<instance>` Jede Instanz berechnet nur die für sie aktivierten Quellen. Die Registerkarten „Übersicht“ und „Probleme“ zeigen ebenfalls nur die Quellen dieser Instanz an. Eine zweite Instanz bietet keine Vorteile, es sei denn, Sie wünschen bewusst separate Ordner. `sourceanalytix.0` Und `sourceanalytix.1` Die

<!-- quelle: code=main.js:126-145; code=main.js:4426-4433; code=main.js:4624-4632; forum=969466 -->

Mehrere Instanzen verwenden immer dieselbe installierte Version. Daher können Sie eine neue Version nicht parallel zur alten testen. Installieren Sie sie als Update, nachdem Sie eine Sicherungskopie erstellt haben. Informationen zum Downgrade, falls etwas schiefgeht, finden Sie unter [„Downgrade“](/#/docs/adapterref/iobroker.sourceanalytix/docs/en/02.anleitungen/05.betrieb-und-wartung.md#update-sourceanalytix-downgrade) .

<!-- quelle: issue=#158 -->

### Entfernen einer zusätzlichen Instanz

Ein zweites Auftreten bleibt oft unbemerkt, beispielsweise wenn Sie SourceAnalytix nach einer GitHub-Installation erneut aus dem Repository installieren. Zur Bereinigung:

1. Überprüfen Sie auf der Registerkarte „Objekte“, welche Instanz Ihre Werte enthält, d. h., ob sich Ihre Ordner unter befinden. `sourceanalytix.0` oder unter `sourceanalytix.1` Die
2. Löschen Sie auf der Registerkarte „Instanzen“ die zusätzliche Instanz mit dem Papierkorbsymbol.

<!-- quelle: forum=938949; forum=567818 -->

> \[!VORSICHT] Durch das Löschen einer Instanz werden auch die zugehörigen Ordner mit allen Werten entfernt. Löschen Sie niemals die Instanz, die Ihre Daten enthält. Wenn Sie nur eine einzelne Datenquelle deaktivieren möchten, verwenden Sie die Aktion „Deaktivieren“ für diese Datenquelle.
