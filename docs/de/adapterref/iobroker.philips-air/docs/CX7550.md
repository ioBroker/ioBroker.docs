# Philips/Versuni CX7550/01

Der Philips/Versuni Turmventilator CX7550/01 („Smart Tower Fan 7000 Serie“) wird über das lokale, verschlüsselte CoAP-Protokoll unterstützt, das von neueren Philips/Versuni HomeID-Geräten verwendet wird. Der Adapter kommuniziert direkt mit dem Gerät im lokalen Netzwerk und nutzt keine Cloud-API.

Das Gerät meldet sich als Plattform`Babel` (die CX3550/01-Berichte)`Trident` Es teilt sich den Raw-D-Code-Namensraum mit dem CX3550/01, aber mehrere Codes tragen unterschiedliche Werte, daher muss das Modell in den Adaptereinstellungen explizit ausgewählt werden.

## Getestete Funktionen

- Ein-/Ausschalten
- Lüfterstufen 1 bis 12
- Automatische Anpassung
- Schlafmodus
- Natürliche Brise
- Oszillation ein/aus
- Timer 1 bis 12 Stunden (beschreibbar bei diesem Modell)
- Piepton ein/aus
- Displayhelligkeit
- Temperaturanzeige ein/aus
- Permanenter Anzeigeinhalt (Lüftergeschwindigkeit oder Temperatur)
- Raumtemperaturanzeige

## Unterschiede zum CX3550/01

| Funktion                | CX3550/01                                                   | CX7550/01                                      |
| ----------------------- | ----------------------------------------------------------- | ---------------------------------------------- |
| Schwingung auf          | liest`23040` schreibt`90`                                   | liest und schreibt`80`                         |
| Lüftergeschwindigkeiten | 1 bis 3                                                     | 1 bis 12, plus AutoAdapt                       |
| Timer                   | Nur lesbar (ein Schreibvorgang kann den Lüfter ausschalten) | beschreibbar                                   |
| Anzeige                 | keiner                                                      | Helligkeit, Farbtemperatur, permanenter Inhalt |
| Raumtemperatur          | nicht gemeldet                                              | `D03224`                                       |

## Parameter

| Schlüssel | Bedeutung                                           | Werte                                                                                                                                     |
| --------- | --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `D03102`  | Leistung                                            | `1 = on` , `0 = off`                                                                                                                      |
| `D03104`  | Farbanzeige der Temperatur                          | `100 = on` , `0 = off`                                                                                                                    |
| `D03105`  | Displayhelligkeit                                   | `0 = off` ,`115 = low` ,`123 = high` ; sinkt auf`115` von selbst, wenn der Lüfter ausgeschaltet ist                                       |
| `D0310C`  | Lüftermodus                                         | `0 = AutoAdapt` ,`1` –`10 = speed1..speed10` ,`81 = speed11` ,`82 = speed12` ,`17 = sleep` , `-126 = naturalBreeze`                       |
| `D0310D`  | Gemeldete aktuelle Geschwindigkeit                  | `0 = off` , andernfalls als`D0310C` ohne die genannten Modi                                                                               |
| `D03110`  | Timer                                               | `0 = off` ,`2 = 1h` ,`3 = 2h` ,`4 = 3h` ,`5 = 4h` ,`6 = 5h` ,`7 = 6h` ,`8 = 7h` ,`9 = 8h` ,`10 = 9h` ,`11 = 10h` ,`12 = 11h` , `13 = 12h` |
| `D03130`  | Piep                                                | `100 = on` , `0 = off`                                                                                                                    |
| `D03211`  | Timer-Minuten                                       | Schreibgeschützt, entspricht dem Timercode                                                                                                |
| `D03224`  | Raumtemperatur                                      | Zehntel eines Grades (`240 = 24.0 °C` ), ändert sich von selbst                                                                           |
| `D0312A`  | Inhalte der Daueranzeige                            | `7 = fan speed` , `5 = temperature`                                                                                                       |
| `D0312B`  | Permanenter Anzeigeinhalt (vom Gerät wiedergegeben) | als`D0312A` , schreibgeschützt                                                                                                            |
| `D0320F`  | Schwingung                                          | `80 = on` ,`0 = off`                                                                                                                      |

Timer-Code`1` wird vom Gerät niemals ausgegeben. Code`5` (4 h) ist aus der umgebenden Sequenz interpoliert und wurde nicht direkt bestätigt.

Beobachtete Geräte-IDs:

- `D01S03 = Turmventilator` (zugeordnet dem gemeinsamen`name` Zustand)
- `D01S04 = Babel` (Plattform)
- `D01S05 = CX7550/01` (zugeordnet dem gemeinsamen`modelId` Zustand)
- `D01S12 = 0.2.9` (zugeordnet dem gemeinsamen`softwareVersion` Zustand)
- WLAN-Version`AWS_Philips_AIR_Combo@86` (identisch mit dem CX3550/01)
