# Philips/Versuni CX3550/01

Der Ventilator Philips/Versuni CX3550/01 wird über das lokale, verschlüsselte CoAP-Protokoll unterstützt, das von neueren Philips/Versuni HomeID-Geräten verwendet wird. Der Adapter kommuniziert direkt mit dem Gerät im lokalen Netzwerk und nutzt keine Cloud-API.

## Getestete Funktionen

- Ein-/Ausschalten
- Lüfterstufe 1, 2 und 3
- Schlafmodus
- Natürliche Brise
- Oszillation ein/aus
- Piepton ein/aus
- Statusablesung über lokales CoAP
- Timer-Statusanzeige

## Zeitbegrenzung

Die Timersteuerung muss für dieses Modell deaktiviert bleiben. Während der Tests akzeptierte der Lüfter lokale Timer-Schreibvorgänge, die Firmware änderte sich jedoch anschließend.`D03102` Zu`0` , den Ventilator ausschalten.

Es werden nur diese schreibgeschützten Timerwerte angezeigt:

- `D03110` : Timer-Code
- `D03211` : Timer-Minuten

## Parameter

| Schlüssel | Bedeutung                          | Werte                                                                             |
| --------- | ---------------------------------- | --------------------------------------------------------------------------------- |
| `D03102`  | Leistung                           | `1 = on` , `0 = off`                                                              |
| `D03105`  | Modellabhängiger Wert              | beobachtet`100` Bei CX3550/01 absichtlich nicht als Lüfterprozentsatz zugeordnet. |
| `D0310C`  | Lüftermodus                        | `1 = speed1` ,`2 = speed2` ,`3 = speed3` ,`17 = sleep` , `-126 = naturalBreeze`   |
| `D0310D`  | Gemeldete aktuelle Geschwindigkeit | `0 = off` ,`1 = speed1` ,`2 = speed2` , `3 = speed3`                              |
| `D0320F`  | Schwingung                         | lesen`23040 = on` , schreiben`90 = on` , `0 = off`                                |
| `D03110`  | Timer-Code                         | Nur lesbar                                                                        |
| `D03211`  | Timer-Minuten                      | Nur lesbar                                                                        |
| `D03130`  | Piep                               | `100 = on` ,`0 = off`                                                             |

Beobachtete Geräte-IDs:

- `D01S03 = Ventilator` (zugeordnet dem gemeinsamen`name` Zustand)
- `D01S04 = Trident` (wird bis zur Bestätigung der allgemeinen Bedeutung als plattform-/gerätespezifischer CX-Text beibehalten)
- `D01S05 = CX3550/01` (zugeordnet dem gemeinsamen`modelId` Zustand)
- `D01S12 = 0.1.7` (zugeordnet dem gemeinsamen`softwareVersion` Zustand)
- WLAN-Version`AWS_Philips_AIR_Combo@86`
