# ioBroker.cloudflare

## Cloudflare-Adapter für ioBroker

Aktualisiert automatisch den bei Cloudflare registrierten Domainnamen mit Ihrer öffentlichen IP-Adresse für Ihren ioBroker. Dynamisches DNS
