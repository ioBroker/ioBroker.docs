# Installationsanleitung

## Treiber installieren

- Öffnen Sie die Registerkarte „Adapter“.
- Unterstützung für das Noolite-F-Geräteprotokoll auswählen
- Klicken Sie (+)
- Nach der Installation des Adapters öffnet iobroker automatisch das Setup-Fenster.
- Geräteliste erstellen. Details [zur Gerätekonfigurationsliste](/#/docs/adapterref/iobroker.noolitef/docs/devices.md) anzeigen.
- Für jedes Gerät sollten Sie Folgendes beachten:
- Klicken Sie auf das (+) Symbol
- Gerätetyp auswählen
- Kanalnummer auswählen. Muss für Fernbedienungsgeräte und Relais eindeutig sein.
- Wählen Sie das Protokoll _Noolite-F_ . Verwenden Sie _Noolite_ ausschließlich für Bindungs-/Lösungsvorgänge.
- Geben Sie den Gerätenamen ein. Es können beliebige Symbole ohne Leerzeichen verwendet werden.
- Beschreibung ausfüllen. Alle Informationen zu diesem Gerät, zum Beispiel „Lampe im Zimmer“.
- Zum Verbinden mit einem Hardwaregerät drücken Sie die Verbindungstaste und folgen Sie den Anweisungen für Ihr Noolite-Gerät.
