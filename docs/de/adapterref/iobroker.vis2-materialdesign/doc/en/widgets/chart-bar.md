# Balkendiagramm
[Benutzerhandbuch](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Widget-Katalog](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) › [Charts](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) · [Deutsch](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/chart-bar.md)

Vergleicht aktuelle Werte als vertikale oder horizontale Balken.
Vorlagen-ID: `tplVis2-materialdesign-Chart-Bar`.

## Datenquelle
- **Eingabe des Editors:** Jeder Datensatz referenziert seinen eigenen Zustand. Die Anzahl der Datensätze erzeugt die indizierten Gruppen.
- **JSON-Zeichenkette/Objekt:** Die Objekt-ID verweist auf einen Zustand, der ein JSON-Array enthält. Datensätze und deren Darstellung stammen aus diesem Zustand.
- **Diagrammtyp:** horizontal vertauscht Kategorie- und Wertachse; Min/Max gelten weiterhin für die Wertachse.

Nach Eingabe durch den Editor enthält jede Datensatzgruppe eine Objekt-ID, eine Achsenbeschriftung, optional eine Farbe, einen Ersatzwerttext und Tooltip-Texte. Ohne festgelegte Achsenbegrenzungen skaliert das Widget automatisch und schließt den Nullpunkt mit ein.

## Editoreinstellungen
Die Benutzeroberfläche des Editors ist in der Systemsprache von ioBroker gehalten, daher sind die Screenshots auf Deutsch. Die unten nicht aufgeführten Einstellungen sind selbsterklärend.

<img src="../../media/vis2_chart_bar_editor.png" width="340" alt="Allgemeine Optionen für Balkendiagramme und Balkenlayout">

- **Allgemein** - Datenquelle (Editor-Datensätze oder ein JSON-Status), Anzahl der Datensätze, Objekt-ID und **Diagrammtyp** (vertikal oder horizontal). Pro Editor-Datensatz fügt eine indizierte Gruppe die Objekt-ID, die Achsenbeschriftung, die Farbe und die Tooltip-Texte hinzu.
- **Layout des Balkendiagramms** - Balkenstärke und -abstand.

<img src="../../media/vis2_chart_bar_editor_2.png" width="340" alt="Optionen für Balkendiagrammachsen und Tooltips">

- **Y-Achse** - Achsentitel, Position (links/rechts), Gitternetzlinien und Sichtbarkeit der Achse/Beschriftung. Die **Minimal-/Maximalwerte** der Wertachse befinden sich in der Diagrammlayoutgruppe (leer = automatische Skalierung).
- **Tooltip** - Aktivieren Sie den Tooltip und legen Sie seine Farben fest; ein datensatzspezifischer `tooltipText` überschreibt den generierten Text.

Die Wertbeschriftungen der Balken befinden sich in der Gruppe **Balkendiagrammwerte-Layout:**, siehe [Im Diagramm eingezeichnete Werte](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md#values-drawn-on-the-chart).

Die gemeinsamen Gruppen für **Diagrammlayout**, **Legende** und Farbschema aus [Diagramme](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) gelten auch hier.

## JSON-Format
Der Zustand muss ein Array enthalten. Fehlende Darstellungswerte greifen auf das Farbschema und die globalen Widget-Einstellungen zurück.

| Eigenschaft | Bedeutung |
| --- | --- |
| `label` | Kategorieachsenbeschriftung |
| `dataColor` | Farbe dieses Balkens |
| `valueText` | Benutzerdefinierter Werttext in der automatisch generierten QuickInfo |
| `valueAppendix` | Suffix nach dem Tooltip-Werttext |
| `tooltipTitle` | Benutzerdefinierter Tooltip-Titel |
| `tooltipText` | Benutzerdefinierter Tooltip-Text |
| `tooltipText` | Benutzerdefinierter Tooltip-Text |

```json
[
    { "label": "PV", "value": 4.8, "dataColor": "#f9a825", "valueAppendix": " kW" },
    { "label": "Grid", "value": 1.2, "dataColor": "#44739e", "tooltipTitle": "Grid import" }
]
```

## Relevante Layoutoptionen
Minimal- und Maximalwerte begrenzen die Werteachse. Leere Felder behalten die automatische Skalierung bei.
- Der Tooltip-Text pro Datensatz ersetzt die automatisch generierte Beschriftung.
- Bei der horizontalen Darstellung werden die X- und Y-Achse funktional vertauscht: X enthält Werte, Y enthält Kategorien.
