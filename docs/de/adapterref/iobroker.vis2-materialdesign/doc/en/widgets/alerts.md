# Warnmeldungen

[Benutzerhandbuch](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Widget-Katalog](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) · [Deutsch](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/alerts.md)

Zeigt eine JSON-Warnungswarteschlange im Material-Design-Stil an. Warnungen können geschlossen werden, und die aktualisierte Warteschlange wird im Status gespeichert. Vorlagen-ID:`tplVis2-materialdesign-Alerts` Die

<img src="../../media/vis2_alerts_runtime.png" alt="Material Design alerts in VIS 2">

## Editor-Einstellungen

Der Screenshot zeigt die erweiterten Gruppen **„Allgemein“** und **„Layout“** . Die unten nicht aufgeführten Einstellungen sind selbsterklärend. Die Benutzeroberfläche des Editors verwendet die Systemsprache von ioBroker, daher sind die Screenshots auf Deutsch.

<img src="../../media/vis2_alerts_editor_overview.png" width="340" alt="Alerts general and layout options">

**Gemeinsam**

- **Objekt-ID** – Status, der das JSON-Alert-Array enthält.
- **Maximale Anzahl der gleichzeitig angezeigten Benachrichtigungen** – wie viele Benachrichtigungen gleichzeitig angezeigt werden, Standardwert: 3. Leer oder`0` zeigt alle Benachrichtigungen in der Warteschlange an (maximal 100).
- **Unterhalb dieser Bildschirmbreite ausblenden \[px]** – Das Widget wird unterhalb dieser Bildschirmbreite ausgeblendet. Diese Regel gilt nur für dieses Widget, daher können mehrere Benachrichtigungs-Widgets in einer Ansicht unterschiedliche Breiten verwenden.

**Layout**

- **Layout** –`normal` ,`outlined` oder`tile` Die Werte sind im Editor nicht übersetzt:`outlined` zeichnet eine Umrandung anstelle einer gefüllten Fläche.`tile` Entfernt die abgerundeten Ecken.
- **schlank / Schatten / Abstand zwischen Benachrichtigungen** – Kompaktheit (standardmäßig aktiviert), Schattentiefe 0–24 und der Abstand unterhalb jeder Benachrichtigung in Pixeln.
- **Rahmen** – auf welcher Seite jede Benachrichtigung den 6 Pixel breiten farbigen Streifen erhält`borderColor` : keine, oben, rechts, links oder unten.
- **Schließen-Symbol** / **Schließen-Symbolfarbe** / **Schließen-Symbolfarbe beim Drücken / ausgewählt** – das Schließen-Symbol, seine Farbe und die Farbe beim Gedrückthalten. Durch Schließen wird die Benachrichtigung entfernt.

```json
[
    {
        "text": "Window is open",
        "icon": "alert-outline",
        "backgroundColor": "#fff8e1",
        "borderColor": "#ffc107",
        "iconColor": "#ffc107",
        "fontColor": "#333333"
    }
]
```

Alle Eigenschaften sind optional.`text` kann HTML enthalten (`<b>` ,`<br>` Links); Skripte und Ereignisattribute werden vor der Anzeige entfernt.`borderColor` hat nur eine Auswirkung, solange **der Frame** nicht auf eingestellt ist.`none` Die

Der Status muss ein JSON-Array enthalten. Ungültiges JSON wird im Widget als Fehler angezeigt. Ein leerer Status zeigt gar nichts an.
