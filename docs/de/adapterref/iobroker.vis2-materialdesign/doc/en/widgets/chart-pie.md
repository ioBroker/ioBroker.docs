# Kreisdiagramm

[Benutzerhandbuch](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Widget-Katalog](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) › [Diagramme](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) · [Deutsch](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/chart-pie.md)

Zeigt die aktuellen Werte als Teile eines Kuchens oder Donuts an. Vorlagen-ID:`tplVis2-materialdesign-Chart-Pie` Die

## Datenquelle

- **Editor-Eingabe:** Jedes Segment liest seinen eigenen Zustand.
- **JSON-Zeichenkette/Objekt:** Ein Zustand stellt alle Segmente als JSON-Array bereit.
- **Donut:** Die Ausstanzung bestimmt die Größe des leeren Zentrums in Prozent.

Negative Eingabewerte werden angezeigt als`0` Verwenden Sie Balken- oder JSON-Diagramme für Daten, die positive und negative Werte enthalten.

## Editor-Einstellungen

Die Benutzeroberfläche des Editors ist in der Systemsprache von ioBroker gehalten, daher ist der Screenshot auf Deutsch. Die unten nicht aufgeführten Einstellungen sind selbsterklärend.

<img src="../../media/vis2_chart_pie_editor.png" width="340" alt="Pie chart general and pie layout options">

- **Allgemein** – Datenquelle (Editorsegmente oder ein JSON-Zustand), Segmentanzahl, Objekt-ID, **Typ** (Kreis- oder Donutdiagramm) und die Größe **des Ausschnitts** , der die leere Mitte bestimmt. Pro Editorsegment fügt eine indizierte Gruppe ihre Objekt-ID, Bezeichnung und Farbe hinzu.

Die Wertbeschriftungen der Segmente befinden sich in der **Wertegruppe des Kreisdiagramms;** siehe [Auf dem Diagramm dargestellte Werte](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md#values-drawn-on-the-chart) .

Das gemeinsame **Diagrammlayout** , **die Legende** und **die Tooltip-** Gruppen aus [Diagrammen](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) gelten auch hier.

## JSON-Format

Das Format entspricht [Balkendiagramm-](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/chart-bar.md) Datensätzen, mit der Ausnahme, dass Kreisdiagramme keine solche Anpassung benötigen.`valueText` Die

| Eigentum        | Bedeutung                         |
| --------------- | --------------------------------- |
| `label`         | Segmentname und Legendeneintrag   |
| `value`         | numerischer, nicht-negativer Teil |
| `dataColor`     | Farbe dieses Segments             |
| `valueAppendix` | Suffix nach dem Tooltip-Wert      |
| `tooltipTitle`  | benutzerdefinierter Tooltip-Titel |
| `tooltipText`   | benutzerdefinierter Tooltip-Text  |

```json
[
    { "label": "Self-consumption", "value": 68, "dataColor": "#43a047" },
    { "label": "Export", "value": 32, "dataColor": "#f9a825" }
]
```

## Relevante Layoutoptionen

- Die Farbe eines einzelnen Segments hat Vorrang vor dem Farbschema und der globalen Farbe.
- Tooltips mit minimalem und maximalem Dezimalzahlenformat formatieren nur automatisch generierte Werte. Ein benutzerdefiniertes Format.`tooltipText` ersetzt diese Ausgabe.
- Legende und Diagramm teilen sich den verfügbaren Platz. Verwenden Sie für viele Segmente eine obere oder untere Legende mit einem breiteren Widget.
