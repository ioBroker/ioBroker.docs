# Liste

[Benutzerhandbuch](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Widget-Katalog](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) · [Deutsch](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/list.md)

Eine konfigurierbare VIS 2-Liste mit Textzeilen, Schaltflächen, Schaltern oder Kontrollkästchen. Die Zeilen können aus indizierten Editorfeldern oder einem JSON-Zustand stammen. Vorlagen-ID:`tplVis2-materialdesign-List` Die

<img src="../../media/vis2_list_runtime.png" alt="Material Design list in VIS 2">

## Editor-Einstellungen

Die Screenshots zeigen die listenweiten Gruppen und einen indizierten Zeileneintrag. Die unten nicht aufgeführten Einstellungen sind selbsterklärend. Die Benutzeroberfläche des Editors verwendet die Systemsprache von ioBroker, daher sind die Screenshots auf Deutsch.

<img src="../../media/vis2_list_editor_overview.png" width="340" alt="List layout and data options">

**Layout der Liste**

- **Listentyp** – gilt für jede Zeile:`text` ,`Button State` ,`toggle Button` ,`toggle Button (read only)` ,`Button Navigation` ,`Button Link` ,`switch` ,`Switch (read only)` ,`checkbox` oder`checkbox (read only)` Die schreibgeschützten Varianten zeigen den Zustand an, schreiben aber nichts.
- **Layout** –`standard` ,`card` oder`cardOutlined` Die
- **Trennstil** –`standard` ,`padded` oder`inset` Die

**Listenkopf**

- **Kopfzeile** – Überschrift oberhalb der Liste mit eigener Ausrichtung, Höhe, Abständen, Farbe, Schriftart und Symbol. Wird sie leer gelassen, wird keine Kopfzeile angezeigt.

**Daten der Liste**

- **Eingabemethode für die Listendaten** –`via editor` (indexierte Zeilengruppen) oder`JSON string` (Jeder Staat trägt jede Zeile).
- **Editor: Anzahl der Listenelemente** – wie viele indizierte Zeilengruppen existieren.
- **JSON-String: Objekt-ID** – der Zustand, der das JSON-Array enthält, nur für die`JSON string` Verfahren.

Jede Zeile ist in ihrem eigenen indizierten **Layout der Listenelementgruppe \[n]** konfiguriert:

<img src="../../media/vis2_list_editor_2.png" width="340" alt="Indexed list item entry">

- **oid** – Zustand, der von der Zeile (Schalter, Kontrollkästchen, Schaltfläche) gesteuert wird. Es wird kein Wert angezeigt – fügen Sie dazu eine Datenbindung in einen der Texte ein, siehe [Werte in Texten anzeigen](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md#show-values-inside-texts) .
- **Überschrift** – Gruppierungsüberschrift oberhalb dieser Zeile, um eine Liste in Abschnitte zu unterteilen.
- **Beschriftung / zweiter Text / Text rechts / zweiter Text rechts** – die vier Texte einer Zeile.
- **Symbol / Symbolfarbe** und **Symbol aktiv / Symbolfarbe aktiv** – Zeilensymbol, das im aktiven Zustand vertauscht wird. Ohne aktives Symbol bleibt das normale Symbol erhalten.
- **Trennlinie** – Trennlinie unterhalb dieser Zeile.
- **Schaltflächenstatus: Wert** – der Wert a`Button State` Zeile schreibt.
- **Schaltflächennavigation: Ansicht** – Zielansicht von`Button Navigation` Reihe.
- **Schaltflächenlink: URL** – Adresse eines`Button Link` Reihe.

Mit dem`JSON string` Die Methode speichert den Zustand als ein Array von Objekten, deren Schlüssel anders benannt sind als die Felder des Editors:

```json
[{ "objectId": "0_userdata.0.light", "text": "Light", "subText": "Living room", "image": "lightbulb" }]
```

| Schlüssel                         | Editorfeld                        |
| --------------------------------- | --------------------------------- |
| `objectId`                        | oid                               |
| `text` /`subText`                 | Beschriftung / zweiter Text       |
| `rightText` /`rightSubText`       | Text rechts / zweiter Text rechts |
| `image` /`imageColor`             | Symbol / Symbolfarbe              |
| `imageActive` /`imageActiveColor` | Symbol aktiv / Symbolfarbe aktiv  |
| `header`                          | Überschrift                       |
| `showDivider`                     | Trennwand                         |
| `buttonStateValue`                | Schaltflächenstatus: Wert         |
| `buttonNavView`                   | Schaltflächennavigation: Ansicht  |
| `buttonLink`                      | Link zum Button: URL              |

Schlüssel, die man liegen lässt, bleiben leer; ohne`text` Eine Zeile lautet:`Item n` Alles über 100 Einträge hinaus wird abgeschnitten, und ungültiges JSON zeigt anstelle der Liste eine rote Fehlerzeile an.
