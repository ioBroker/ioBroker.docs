# Widget-Katalog

[Benutzerhandbuch](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) · [Deutsch](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/README.md)

Wählen Sie ein Widget je nach Aufgabe aus. Die für den Editor sichtbaren Varianten bleiben bewusst getrennt, damit jedes Widget leicht zu finden und zu konfigurieren ist.

Historische Vorlagen-IDs bleiben für bestehende Projekte stabil. Namen wie beispielsweise`Adition` ,`Vuetify` oder`view-in-widget8` Beschreiben keine aktuellen Abhängigkeiten und dürfen nicht geändert werden.

Jede Option, die eine **Anzahl** angibt – Datensätze, Menüeinträge, Spalten, Listenelemente, Auswahlwerte, Objekt-IDs, Ansichten – zählt: 3 bedeutet drei Einträge in den Gruppen \[0] bis \[2]. VIS 1 speicherte dort den letzten Index, wobei 3 vier Einträge bedeutete. Überprüfen Sie daher den Wert einmalig beim Neuerstellen eines VIS-1-Widgets.

## Wechseln und navigieren

- [Schaltflächen](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/buttons.md) – eine Ansicht oder einen Link öffnen oder einen Status schreiben
- [Vertikale Schaltflächen](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/buttons-vertical.md) – dieselben Funktionen wie im vertikalen Layout
- [Symbolschaltflächen](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/icon-buttons.md) – kompakte Aktionen nur mit Symbolen
- [Kontrollkästchen](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/checkbox.md) – boolesche oder benutzerdefinierte Ein-/Aus-Werte umschalten
- [Schalter](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/switch.md) – einen Zustand als Schalter betreiben
