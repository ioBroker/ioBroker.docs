# JSON-Diagramm

[Benutzerhandbuch](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) › [Widget-Katalog](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/README.md) › [Diagramme](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) · [Deutsch](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/chart-json.md)

Erstellt ein Balken-, Linien- oder gemischtes Diagramm aus einem JSON-Zustand. Vorlagen-ID:`tplVis2-materialdesign-Chart-JSON` Die

## Datenformat

Der unter Objekt-ID ausgewählte Staat muss ein Objekt mit folgender Information enthalten:`axisLabels` Und`graphs` Die`axisLabels` Namen teilen sich Positionen auf der X-Achse. Jeder Eintrag in`graphs` erstellt einen Datensatz.

```json
{
    "axisLabels": ["Mon", "Tue", "Wed", "Thu"],
    "graphs": [
        {
            "type": "bar",
            "legendText": "Consumption",
            "color": "#44739e",
            "data": [4.2, 5.1, 4.8, 6.0],
            "barIsStacked": true,
            "barStackId": 1
        },
        {
            "type": "line",
            "legendText": "PV",
            "color": "#f9a825",
            "data": [2.1, 4.7, null, 5.4],
            "line_spanGaps": false,
            "line_Thickness": 3
        }
    ]
}
```

Ungültige JSON-Anzeigen`Error in JSON string` Fehlende, leere oder nicht-numerische Datenwerte werden als Lücken behandelt.

## Editor-Einstellungen

Der Großteil dieses Diagramms wird durch den JSON-Status bestimmt; der Editor legt lediglich die Quell- und globalen Standardwerte fest. Die Benutzeroberfläche des Editors verwendet die Systemsprache von ioBroker, daher ist der Screenshot auf Deutsch.

<img src="../../media/vis2_chart_json_editor.png" width="340" alt="JSON chart general and chart layout options">

- **Allgemein** – die Objekt-ID des oben beschriebenen JSON-Zustands und der globale **Diagrammtyp** (`bar` oder`line` ) von Datensätzen ohne eigene`type` Die

- **x-Achse** / **y-Achse** – Titel, Position, Farben, **Gitternetzlinien anzeigen** und **Gitternetzlinienfarbe** . **Der Versatz der Gitternetzlinien auf der x-Achse** platziert die Linien zwischen den Kategorien anstatt durch sie hindurch – genau das, was Balken benötigen.

- **Wertelayout für Balkendiagramme:** – Schreibt die Werte auf die Balken und Punkte, siehe [„Im Diagramm dargestellte Werte“](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md#values-drawn-on-the-chart) . Standardmäßig ist dies aktiviert.`no` Hier wird also ein Diagramm, bei dem keine dieser Optionen eingestellt ist, weiterhin ohne Beschriftungen angezeigt.

Das Kartenlayout und die gemeinsam genutzten **Legenden-** und **Tooltip-** Gruppen aus [den Diagrammen](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) werden übernommen; die Darstellung pro Datensatz ergibt sich aus den unten stehenden JSON-Eigenschaften.

## Eigenschaften des Datensatzes

| Eigentum                 | Bedeutung                                                                                           |
| ------------------------ | --------------------------------------------------------------------------------------------------- |
| `data`                   | Werte übereinstimmen`axisLabels` Bestellung; Nummer oder `{ "y": number }`                          |
| `type`                   | `bar` oder`line` ; überschreibt den globalen Diagrammtyp                                            |
| `legendText`             | In der Legende abgebildete Bezeichnung                                                              |
| `color`                  | Linien- oder Balkenfarbe                                                                            |
| `line_Thickness`         | Linienbreite; alternativ auch für die Balkenrahmenbreite                                            |
| `line_steppedLine`       | Verbindet Linienwerte mithilfe von Schritten                                                        |
| `line_spanGaps`          | verbindet Punkte über`null` Lücken                                                                  |
| `line_UseFillColor`      | füllt den Bereich unterhalb einer Linie aus                                                         |
| `line_FillColor`         | benutzerdefinierte Füllfarbe; andernfalls eine transparente Variante `color`                        |
| `barBorderWidth`         | Balkenrahmenbreite                                                                                  |
| `barIsStacked`           | ermöglicht das Stapeln des Datensatzes und seiner Y-Achse                                           |
| `barStackId`             | Datensätze mit derselben ID bilden einen Stapel.                                                    |
| `yAxis_id`               | Datensätze mit derselben ID teilen sich eine Y-Achse; ausgelassene Werte verwenden alle die ID. `0` |
| `yAxis_position`         | platziert diese Y-Achse links oder rechts                                                           |
| `yAxis_min` ,`yAxis_max` | Feste Grenzwerte für diese Y-Achse; leere Werte behalten die automatische Skalierung bei.           |

## Gemischte Diagramme und Achsen

Der globale Diagrammtyp gilt nur für Datensätze ohne eigene`type` Dies ermöglicht die Darstellung von Balken und Linien in einem Diagramm. Gestapelte Balken benötigen die gleichen Einstellungen.`barStackId` Datensätze ohne Stapelung bleiben getrennt.

Weisen Sie unterschiedliche`yAxis_id` Werte in verschiedenen Einheiten, zum Beispiel`0` für kW auf der linken Seite und`1` für Prozentangaben auf der rechten Seite. Datensätze mit derselben Einheit sollten eine gemeinsame ID verwenden, um doppelte Achsen zu vermeiden.

Das Widget verwendet`axisLabels` als Kategorien. Verwenden Sie [ein Linienverlaufsdiagramm](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/chart-line-history.md) für eine Echtzeitachse, die direkt aus einer Verlaufsinstanz geladen wird.
