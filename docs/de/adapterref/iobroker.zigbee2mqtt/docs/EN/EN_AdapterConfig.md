### Konfiguration des Adapters

| Option                                                                                     | Wert/Beschreibung                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Zigbee2MQTT-Verbindung auswählen und konfigurieren**                                     |                                                                                                                                                                                                                                                                                                                                                                     |
| Zigbee2MQTT-Verbindung auswählen                                                           | Empfohlene Einstellung „Websocket“                                                                                                                                                                                                                                                                                                                                  |
| Schema                                                                                     | Wählen Sie zwischen WebSocket (WS) über HTTP oder HTTPS (WS SSL).                                                                                                                                                                                                                                                                                                   |
| Websocket-IP-Adresse                                                                       | IP- oder DNS-Name des Zigbee2MQTT-Servers (in unserem Fall die IP-Adresse des Docker-Hosts)                                                                                                                                                                                                                                                                         |
| Websocket-Port                                                                             | 8080 ist der Standardport. Wenn dieser in der Konfiguration von Zigbee2MQTT geändert wird, muss er auch hier geändert werden.                                                                                                                                                                                                                                       |
| Auth-Token verwenden                                                                       | Aktivieren Sie die Option zum Speichern eines Authentifizierungstokens/Passworts auf der Konfigurationsseite. !!! ACHTUNG !!! Sonderzeichen werden nicht unterstützt. Weitere Informationen finden Sie unter [Zigbee2MQTT.](https://www.zigbee2mqtt.io/guide/configuration/frontend.html#advanced-configuration)                                                    |
| Erstellen eines Dummy-MQTT-Servers für Zigbee2MQTT                                         | Da wir für Zigbee2MQTT einen MQTT-Server benötigen, können wir dieses Kontrollkästchen setzen und haben dann die Möglichkeit, hier im Adapter einen zu erstellen.                                                                                                                                                                                                   |
| MQTT-Server-IP-Adresse/MQTT-Server-Port binden                                             | Diese Einstellungen werden nur angezeigt, wenn der Dummy-MQTT-Server aktiviert ist. Falls kein anderer MQTT-Server auf dem ioBroker vorhanden ist, können die Standardeinstellungen beibehalten werden; andernfalls muss zumindest der Port geändert werden. Diese Einstellungen sollten anschließend auch in der Konfiguration von Zigbee2MQTT gespeichert werden. |
| Konfiguration der Zigbee2MQTT-Web-UI-Verbindung                                            | Hier kann die Verbindung konfiguriert werden, d. h. wie die Zigbee2MQTT-Weboberfläche in den ioBroker integriert werden soll. Wichtig: Wird der ioBroker über HTTPS aufgerufen, muss hier ebenfalls eine HTTPS-Verbindung hergestellt werden. Andernfalls tritt folgender Fehler auf: ( <https://github.com/arteck/ioBroker.zigbee2mqtt/issues/12> )                |
| **Konfiguration der Zigbee2MQTT WebUI-Verbindung**                                         |                                                                                                                                                                                                                                                                                                                                                                     |
| Farbtemperatur mit Farbe synchronisieren                                                   | Diese Einstellung sorgt dafür, dass beispielsweise in einem VIS wie Lovelace die Farbe der Lampe auf die eingestellte Farbe wechselt.                                                                                                                                                                                                                               |
| Verwenden Sie Kelvin-Werte anstelle von Mired.                                             | Einstellen der Farbtemperaturen, z. B. für Lampen                                                                                                                                                                                                                                                                                                                   |
| **Zustandskonfigurationen**                                                                |                                                                                                                                                                                                                                                                                                                                                                     |
| Erzeugt einfache Halte- und Freigabezustände                                               | Bei der Aktivierung werden die Datenpunkte „Halten“ und „Freigeben“ kombiniert, wobei der Datenpunkt „Halten“ so lange wahr bleibt, bis das Ereignis „Freigeben“ eintritt.                                                                                                                                                                                          |
| Erzeugt einfache Zustände „Bewegen“ und „Stoppen“.                                         | Bei Aktivierung werden die Datenpunkte „Move“ und „Stop“ kombiniert, wobei der Datenpunkt „Move“ so lange wahr bleibt, bis das Ereignis „Stop“ eintritt.                                                                                                                                                                                                            |
| Erzeugen Sie einfache "Drücken"- und "Loslassen"-Zustände.                                 | Wenn diese Funktion aktiviert ist, werden die Zustände „Drücken“ und „Loslassen“ kombiniert, und der Datenpunkt „Drücken“ bleibt so lange wahr, bis das Ereignis „Loslassen“ eintritt.                                                                                                                                                                              |
| Die Helligkeitsregelung sollte auch das Licht ein- oder ausschalten.                       | Wenn diese Funktion aktiviert ist, schaltet sich die Lampe aus, sobald die Helligkeit über den Helligkeitsregler auf 0 eingestellt wird. Und wenn die Lampe ausgeschaltet ist, schaltet sie sich wieder ein.                                                                                                                                                        |
| Die Helligkeitsstufe sollte auch das Ein- oder Ausschalten des Lichts ermöglichen.         | Wenn die Helligkeit über den Helligkeitsregler auf 0 eingestellt ist, schaltet sich die Lampe aus. Und wenn die Lampe ausgeschaltet ist, schaltet sie sich wieder ein.                                                                                                                                                                                              |
| **Geräte-Image-Konfigurationen**                                                           |                                                                                                                                                                                                                                                                                                                                                                     |
| Laden Sie Gerätebilder von Zigbee2Mqtt herunter und verwenden Sie diese als Objektsymbole. | Bei dieser Einstellung wird das Vorschaubild von zigbee2MQTT heruntergeladen, komprimiert und anschließend im entsprechenden Objekt gespeichert. ACHTUNG: Der erste Start nach der Aktivierung dieser Einstellung dauert je nach Anzahl der Geräte länger.                                                                                                          |
| Größe der Objektsymbole in Pixeln                                                          | Die Bildgröße beträgt standardmäßig 28 Pixel. Eine Vergrößerung erfolgt auf eigenes Risiko.                                                                                                                                                                                                                                                                         |
| **Andere Konfigurationen**                                                                 |                                                                                                                                                                                                                                                                                                                                                                     |
| Automatische Überprüfung auf fehlende Router im Speicher des Koordinators.                 | Diese Option prüft alle Geräte, die theoretisch als Router im ZigBee-Netzwerk fungieren könnten, und listet alle auf, die dies nicht tun. Weitere Informationen finden Sie unter <https://www.zigbee2mqtt.io/guide/usage/mqtt_topics_and_messages.html#zigbee2mqtt-bridge-request-coordinator-check>                                                                |
| Zigbee2MQTT-Protokolle an ioBroker-Protokolle weiterleiten                                 | Überträgt Protokolle von Zigbee2MQTT an das ioBroker-Protokoll.                                                                                                                                                                                                                                                                                                     |
