# Wiki

Dies ist ein kleines Wiki für den ioBroker-Adapter Zigbee2MQTT.

zigbee2mqtt ist ein Open-Source-Projekt, das den direkten Zugriff auf ZigBee-Geräte über MQTT ermöglicht, ohne dass eine Herstellerbrücke erforderlich ist.
