# ioBroker.myenergi

## MyEnergi-Adapter für ioBroker

Adapter für Myenergi-Geräte

## Login:

Geben Sie die Seriennummer und den API-Schlüssel Ihres Myenergie Hubs ein. Die Seriennummern finden Sie unter <https://myaccount.myenergi.com/> im Bereich „Myenergie-Produkte“. Dort muss auch ein API-Schlüssel für den Hub generiert werden. Klicken Sie dazu auf „Erweitert“ und anschließend auf „Schlüssel generieren“.
