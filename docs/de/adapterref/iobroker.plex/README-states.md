## Mit erweiterter Einrichtung

### entweder mit Plex Pass oder Tautulli

Die folgenden Zustände werden empfangen, wenn ein Ereignis vom Webhook empfangen wird - entweder mit Plex Pass oder mit eingerichtetem Tautulli.

**Hinweis:** Nach der Einrichtung von Tautulli lassen sich die Zustände nahezu beliebig anpassen. Die [Anleitung zur Einrichtung des Webhooks finden Sie in Schritt 4](https://github.com/iobroker-community-adapters/ioBroker.plex#1222-webhook) .

Bei der Standardkonfiguration von Plex Pass oder Tautulli werden die folgenden Zustände empfangen und erstellt:

- \* Zeigt an, dass der Status nur bei Verwendung von Plex Plass angegeben wird.
- \*\* Zeigt an, dass der Zustand nur bei Verwendung von Tautulli angegeben wird.
