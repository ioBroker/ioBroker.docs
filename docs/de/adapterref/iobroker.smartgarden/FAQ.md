# ioBroker.smartgarden

## Häufig gestellte Fragen

| Frage                                                                                                                                                                                         | Antwort                                                                                                                                                                                                                                              |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ich bekomme immer`Error: 401`                                                                                                                                                                 | Bitte überprüfen Sie erneut Benutzernamen, Passwort und API-Schlüssel.                                                                                                                                                                               |
| Ich habe meinen js-Controller auf Version 3.xy aktualisiert, seitdem erhalte ich eine Fehlermeldung.`.... required adapter "@jpgorganizer/utils" not found!'`                                 | Am einfachsten lässt sich das Problem beheben, indem man den Adapter deinstalliert und anschließend neu installiert.                                                                                                                                 |
| Ich erhalte keine Werte für die Vorhersage der Mäh- oder Ladezeit.                                                                                                                            | Datenpunkte löschen`info.saveMowingHistory` Und`info.saveChargingHistory` und beginnen Sie von vorn. Stellen Sie sicher, dass Sie mindestens einen Mäh-/Ladezyklus ohne Fehler durchführen.                                                          |
| Nach einem Update von Version < 0.5.0 auf Version >= 0.5.0 haben sich alle IDs geändert.                                                                                                      | Ja, dies war aufgrund der Unterstützung des History-Adapters notwendig. Weitere Informationen finden Sie im Changelog.                                                                                                                               |
| Ich hätte gerne mehr/andere Werte für meine Geräte.                                                                                                                                           | Bitte lesen Sie das Kapitel _„Wünsche nach Datenpunkten“_ in [der README-Datei.](/#/adapters/smartgarden)                                                                                                                                            |
| Ich bekomme`invalid date` für jeden Zeitstempel                                                                                                                                               | Dieses Verhalten sollte in Versionen > 0.6.0 behoben sein.                                                                                                                                                                                           |
| Ich bekomme immer`Error: getlocations: no data`                                                                                                                                               | Dieser Fehler wurde durch die Gardena Smart API verursacht und von Gardena behoben.                                                                                                                                                                  |
| Benötige ich die Gardena Bridge oder kann das Gardena Smart-System auch ohne die Bridge betrieben werden?                                                                                     | Sie benötigen die Bridge. Die Bridge verbindet Ihre Geräte mit der Gardena-Cloud, und der Smartgarden-Adapter kommuniziert mit der Gardena-Cloud.                                                                                                    |
| Meine Geräte, wie zum Beispiel mein Rasenmäher, reagieren nicht auf meine Befehle.                                                                                                            | Bitte überprüfen Sie, ob Sie den Wert für den Befehl mit`ack=false` Siehe [Kapitel „Befehle und Status“ im Leitfaden für Adapterentwickler](https://github.com/ioBroker/ioBroker.docs/blob/master/docs/en/dev/adapterdev.md#commands-and-statuses) . |
| Warum läuft mein Rasenmäher / mein Ventil / meine Steckdose eine Minute lang, obwohl ich einen anderen Befehl eingestellt habe, wie zum Beispiel?`PARK_UNTIL_NEXT_TASK` für einen Rasenmäher. | Es ist sehr wahrscheinlich, dass Sie den Befehl falsch geschrieben haben. Wenn der Adapter den Befehl nicht erkennt, startet das Gerät für 60 Sekunden.                                                                                              |
| Ich kann kein Anwendungsgeheimnis eingeben. Das Feld ist inaktiv.                                                                                                                             | Bitte löschen Sie Benutzername und Passwort. Es kann nur entweder das Anwendungsgeheimnis oder Benutzername und Passwort eingegeben werden.                                                                                                          |
