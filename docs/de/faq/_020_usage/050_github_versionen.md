## Wann sollte ich eine Version direkt von GitHub installieren?

**Nur dann, wenn ein Entwickler ausdrücklich darum bittet**: etwa im Forum oder
in einem Issue, um eine Korrektur zu testen.

Was auf GitHub liegt, ist Arbeitsstand. Es kann funktionieren, muss aber nicht,
und Abhängigkeiten werden bei dieser Installationsart nicht geprüft.

Wer selbst ausprobieren möchte, tut das auf einem Testsystem, nicht auf dem, an
dem die Heizung hängt.

Wie es geht, steht unter *Fortgeschritten*.
