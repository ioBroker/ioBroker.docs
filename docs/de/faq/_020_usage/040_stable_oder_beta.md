## Was ist der Unterschied zwischen stable und beta?

**stable** enthält die geprüften Adapterversionen. **beta** (früher *latest*)
enthält die neuesten. Die können noch Fehler enthalten.

Auf einem System, das zuverlässig laufen soll, gehört **stable** eingestellt.

Wird trotzdem einmal eine neuere Version eines einzelnen Adapters gebraucht, muss
man dafür **nicht** das Repository umstellen: Der Dialog *Installieren aus eigener
Quelle* im Reiter Adapter kann einen einzelnen Adapter direkt von npm holen.

Ausführlich: [Was ist ein Repository?](/docs/basics/repositories.md)
