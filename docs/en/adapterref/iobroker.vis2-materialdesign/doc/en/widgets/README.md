# Widget catalog

[User guide](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/README.md) · [Deutsch](https://github.com/typhosj/ioBroker.vis2-materialdesign/blob/master/doc/de/widgets/README.md)

Choose a widget by task. Editor-visible variants deliberately remain separate so
that every widget is easy to find and configure.

Historical template IDs remain stable for existing projects. Names such as
`Adition`, `Vuetify` or `view-in-widget8` do not describe current dependencies
and must not be changed.

Every option that names a **count** — data sets, menu entries, columns, list
items, select values, object ids, views — is a count: 3 gives three entries, in
the groups [0] to [2]. VIS 1 stored the last index there, where 3 meant four
entries, so check the value once when rebuilding a VIS 1 widget.

## Switch and navigate

- [Buttons](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/buttons.md) – open a view or link, or write a state
- [Buttons Vertical](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/buttons-vertical.md) – same actions with vertical layout
- [Icon Buttons](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/icon-buttons.md) – compact icon-only actions
- [Checkbox](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/checkbox.md) – switch boolean or custom off/on values
- [Switch](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/switch.md) – operate a state as a switch

## Enter values

- [Input](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/input.md) – enter text or numbers
- [Select and Autocomplete](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/select.md) – choose a value from a list
- [Slider](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/slider.md) – change a numeric value horizontally or vertically
- [Slider Round](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/slider-round.md) – change a numeric value on a circular control

## Display values and content

- [Value](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/value.md) – display one formatted state
- [HTML Card](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/html-card.md) – combine title, text, image and action
- [Progress](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/progress.md) – display a value as linear progress
- [Progress Circular](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/progress-circular.md) – display a value as circular progress
- [Material Design Icons and Utilities](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/material-design-icons-and-images.md)

## Display data

- [List](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/list.md) – rows with text, buttons, switches or checkboxes
- [IconList](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/iconlist.md) – state-dependent icons in a grid
- [Table](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/table.md) – JSON rows in columns
- [Charts](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/charts.md) – bar, pie, JSON or line history
- [Calendar](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/calendar.md) – JSON events in month, week or day views
- [Alerts](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/alerts.md) – display and acknowledge a message queue

## Views and layout

- [Top App Bar](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/top-app-bar.md) – navigation with app bar and drawer
- [Responsive Layout](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/responsive-layout.md) – multiple views in masonry or grid
- [Advanced View in Widget](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/html-widgets.md) – select one child view by state
- [Dialog](/#/docs/adapterref/iobroker.vis2-materialdesign/doc/en/widgets/dialog.md) – open a view or iFrame in a dialog
