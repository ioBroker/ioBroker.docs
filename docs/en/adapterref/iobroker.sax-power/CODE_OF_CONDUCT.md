# Code of conduct

## Our standards

Project participants are expected to:

- communicate respectfully and constructively
- provide useful technical context
- accept differing levels of experience
- focus criticism on code and behavior, not people
- protect private and security-sensitive information
- avoid harassment, discrimination, threats, or personal attacks

## Scope

This code of conduct applies to project discussions, issues, pull requests, reviews, and other spaces representing the project.

## Enforcement

Unacceptable behavior may result in content removal, temporary restriction, or permanent exclusion from project spaces.

Concerns should be reported privately to the project maintainer rather than discussed publicly.
